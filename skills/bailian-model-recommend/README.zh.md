# 百炼模型推荐

> [English →](README.md)

**阿里云百炼**平台的模型选型与推荐 Skill —— 分析你的 AI 场景需求，从百炼模型市场中推荐最合适的模型，附带 tradeoff 对比和可直接使用的调用示例代码。

## 功能简介

告诉 Agent 你想做什么，这个 Skill 会：

1. **理解需求** —— 从你的描述中提取模态、能力、预算和质量偏好
2. **筛选候选** —— 在百炼模型全量目录中按模态、能力、上下文窗口和语义相关性过滤
3. **推荐 3 个模型** —— 最佳推荐、次优选择、备选参考，每个都有清晰的 tradeoff 说明
4. **提供调用示例** —— OpenAI 兼容 Python SDK 和 cURL 示例代码

## 适用场景

**显式选型：**
- "推荐一个做 XX 的模型"
- "用什么模型好？"
- "帮我对比 A 模型和 B 模型"

**隐式选型（描述目标，Skill 帮你选模型）：**
- "我想做一个智能客服机器人"
- "帮我实现图片生成功能"
- "文本摘要场景有什么 AI 方案？"

**技术选型：**
- "低成本 / 高并发 / 高精度场景怎么选模型？"
- "A 模型和 B 模型哪个更适合做 YY？"

**不适用：**
- 已确定模型，只需要调用方式 → 直接使用 `bailian-cli`
- 纯粹查模型参数/价格 → 使用 `bailian-docs-llm-wiki`

## 使用示例

```
我想做一个中英双语的智能客服，需要支持 function calling，
成本越低越好。
```

Skill 会推荐 3 个模型，附带推荐理由：

| # | 策略 | 示例理由 |
|---|------|---------|
| **1 — 最佳推荐** | 性价比高 + 支持工具调用 | "支持中英双语，原生工具调用能力，同档位 token 单价最低" |
| **2 — 次优选择** | 能力更强，成本适中 | "推理能力更强，处理复杂问题更好，成本约为 #1 的 2 倍" |
| **3 — 备选参考** | 不同视角的选择 | "开源可自部署，大规模调用无按次计费，灵活度更高" |

每条推荐包含：模型名称、模型 ID、关键规格（上下文窗口、定价）和可复制的调用示例代码。

## 前置要求

- 已安装 [`bailian-docs-llm-wiki`](../bailian-docs-llm-wiki/) Skill（提供模型数据目录）
  - 未安装时自动执行安装：`npx skills add modelstudioai/skills --skill bailian-docs-llm-wiki -y`

## 内部工作流程

确定性流程全部由脚本完成（移植自 bailian-cli `bl advisor recommend` 引擎）：
召回、打分、排序、席位分配都在 `scripts/recall-rank.mjs` 中，不依赖 LLM 做决策。
LLM 只负责两件事：把用户需求提取成结构化 intent JSON，以及为最终结果撰写
推荐理由。

```
用户请求
  → LLM：提取 intent JSON（模态、能力、预算、场景、点名模型）
  → scripts/recall-rank.mjs（确定性）：
      快照去重 → 硬过滤（模态+能力，能力约束永不丢弃）
      → notSuitableFor 负面排除 → 公式打分 → 档位/价格/厂商排序
      → 同家族软上限 → 席位分配（primary / runner-up / exploration）
  → scripts/get-samples.mjs（确定性）：从 group 文件提取调用示例
  → LLM：基于脚本输出撰写推荐理由
  → 输出自然语言推荐 + 规格 + 代码
```

候选列表不会被 LLM 增删或重排。所有推荐均基于实际模型目录数据，不凭记忆推荐。
