# 创建自定义评测任务

介绍如何创建自定义评测任务：选择评测模型与任务类型（文本生成、视觉理解、文生图、图生图、图生视频（首帧/首尾帧））、配置数据来源、关联评测维度，并设置并发数与单样本推理次数。多模态任务暂仅支持人工评估维度。

<a id="创建自定义评测任务概述"></a>

<a id="h2-cc-overview"></a>

## 创建自定义评测任务概述

自定义评测基于业务效果，使用您的数据集和自定义维度评测模型。创建任务前，请确认已创建至少一个评测维度（参见[评测维度](../evaluation-metrics.md)），并已在数据管理模块上传评测数据集（参见[训练集与评测集](../training-set-and-evaluation-set.md)）。

在[百炼控制台的模型评测页面](https://bailian.console.aliyun.com/cn-beijing/model/evaluate/task/creation)，选择**评测任务**页签，单击**创建评测任务**，选择自定义评测。

<a id="选择评测模型"></a>

<a id="h2-cc-model"></a>

## 选择评测模型

从控制台模型列表中选择要评测的目标模型。支持预置模型和调优后的模型，具体支持的模型请参见[预置模型列表](../../model-high-speed-inference/model-deployment-index/model-deployment-introduction.md)。模型选择弹层支持按官方模型/我的模型切换，并按能力（Function Calling、结构化输出等）筛选；灰色显示的模型表示当前不支持评测。

<a id="选择任务类型"></a>

<a id="h2-cc-tasktype"></a>

## 选择任务类型

选择模型后需选择**任务类型**，可选项由所选模型的能力决定，不支持的任务类型呈置灰状态：

-   **文本生成**：文本生成类模型及具备理解能力的多模态模型可选；图片生成、视频生成模型不可选（置灰）。
-   **视觉理解**：具备图片与视频理解能力的模型可选（如 Qwen4-Max）。
-   **文生图**、**图生图**：图片生成模型可选。
-   **图生视频（首帧）**、**图生视频（首尾帧）**：视频生成模型可选。

任务类型与数据管理中评测集场景的命名存在差异：任务类型**文生图**、**图生图**对应评测集场景**文生图片**、**图生图片**（场景选项命名以创建数据集页面为准）。

任务类型为多模态（视觉理解、文生图、图生图、图生视频（首帧/首尾帧））时，有两项限制：

-   数据来源仅支持**评测数据集**，推理结果集不可用。
-   评测维度仅支持**人工评估**类型的自定义维度，大模型评估与规则评估维度（无论自定义创建还是出自预置模板）均不可选，预置模板整体呈禁用状态。创建维度请参见[人工评估维度](../evaluation-dimension-introduction/evaluation-dimension-manual.md)。

<a id="配置数据来源"></a>

<a id="h2-cc-data"></a>

## 配置数据来源

数据来源支持两种方式：

-   **评测数据集**：支持**文本生成（prompt&completion）**单轮格式（Prompt 与 Completion）与**文本生成（ChatML-messages）**多轮对话格式（参考答案为最后一条 assistant 消息）。系统调用被评测模型推理生成 Output 后再评分，会产生推理费用；多轮对话数据以完整对话送评，默认以最后一轮 user 消息作为当前问题。须为评测集（EvaluationSet）类型且已发布版本，在数据管理模块提前上传。任务类型为多模态时，须上传对应场景的多模态评测集（Zip 压缩包），字段结构见[评测集格式](../../fine-tuning/fine-tune-text-generation-model/text-generation-tuning-data-upload-rules.md#sec-eval-set)，上传方式请参见[训练集与评测集](../training-set-and-evaluation-set.md)。
-   **推理结果集**：已包含模型 Output，系统直接评分不调用模型推理，不产生推理费用。适用于已有模型输出想降低成本的场景。

| 对比项 | 评测数据集 | 推理结果集 |
| --- | --- | --- |
| 数据内容 | 包含 Prompt 和 Completion | 已包含模型 Output |
| 推理调用 | 系统调用被评测模型推理 | 不调用模型推理 |
| 推理费用 | 产生 | 不产生 |
| 适用场景 | 首次评测、标准流程 | 已有模型输出，降低成本 |
| 数据要求 | 评测集类型且已发布版本 | 按模板上传文件 |

数据量建议：小规模验证 50-100 条，正式评测 200-500 条，全面评估 500 条以上。

<a id="关联维度与任务配置"></a>

<a id="h2-cc-config"></a>

## 关联维度与任务配置

从已创建的评测维度中多选要关联的维度，可混用自定义评测维度与预置模板，须提前在评测维度页面创建。

推理参数按所选模型动态加载，可配置项包括 System Prompt（不超过 5000 字符，为被评测模型设定角色定位，大多数场景可留空）、推理模式（enable\_thinking）、核采样（top\_p）、温度（temperature）、停止词（stop）、联网搜索（enable\_search）与思维链长度（thinking\_budget）。

**并发数**默认为 8，可设置 1~20，影响评测任务的执行速度，不改变评测结果。

**单样本推理次数**默认为 1。设置为大于 1 时，每条样本推理多次并基于多次采样结果计算 Pass@K 等聚合指标，用于判断样本难度与模型表现稳定性（推理与评分费用随推理次数相应增加）。

是否参与排行开关默认关闭。开启后须选择一个排行榜，评测结果将加入排行参与排名。排行榜绑定维度为空时系统将阻止提交并显示错误提示。

清空评测维度时系统会自动清空排行榜选择。任务名称最长 50 字符（默认自动填充为“评测\_日期时间”）。配置完成后，单击**开始评测**提交任务，费用以实际发生为准（详见[计费说明](../model-evaluation-overview.md#ta12pj4r2re00)），提交前可查看计算详情。

任务提交后进入执行流程，状态流转与结果查看请参见[查看评测结果](view-evaluation-results.md)。

<a id="h2-cc-faq"></a>

## 常见问题

<a id="accordion-问题-创建评测任务时选错了被评测模型-想更换模型"></a>

问题：创建评测任务时选错了被评测模型，想更换模型。

任务一旦提交不可更换目标模型。处理方式：删除任务后重建。已消耗的 Token 费用不可追回。

<a id="accordion-问题-提交评测任务后状态显示失败"></a>

问题：提交评测任务后状态显示失败。

请依次检查：数据集必须为评测集（EvaluationSet）类型并已发布版本（训练集不可用于评测），模型是否可选（灰色表示暂不支持），数据格式是否正确（prompt&completion 格式须包含 Prompt 和 Completion 列，ChatML 格式须为包含 messages 数组的合法 jsonl）。

<a id="accordion-问题-多模态评测任务无法关联大模型评估或规则评估维度"></a>

问题：多模态评测任务无法关联大模型评估或规则评估维度。

任务类型为视觉理解、文生图、图生图、图生视频（首帧/首尾帧）时，评测维度仅支持人工评估类型，大模型评估与规则评估维度及预置模板均呈禁用状态，属预期行为。相关能力即将上线。
