## 创建基线评测任务概述

基线评测内置覆盖通用知识、数学、代码、上下文推理、领域专项 5 大类共 13 个公开标准基线，自动评测模型基础能力，无需自行准备数据集或配置评测维度，快速获得基准分数。

**重要**

> 基线评测仅北京地域可用。其他地域不显示此选项，属正常现象。

## 基线库

基线库按 5 大类组织：

-   **通用知识**：评估模型在多学科专业知识、多语言理解、指令遵循等通用能力上的表现。
-   **数学**：评估模型的数学推理与竞赛数学能力。
-   **代码**：评估模型的代码生成能力。
-   **上下文推理**：评估模型在长文本中的检索、理解与推理能力。
-   **领域专项**：评估模型在金融、医学等领域专业场景的能力。

## 创建流程

1.  在[百炼控制台](https://bailian.console.aliyun.com/cn-beijing/model/evaluate/task/creation)，选择**评测任务**页签，单击**创建评测任务**。
2.  评测方式选择**基线评测**。
3.  选择要评测的目标模型。支持选择**官方模型**（千问系列商业模型与开源模型）和**我的模型**（已部署的调优模型）。
4.  选择基线评测数据。基线库按 5 大类分 tab 展示，卡片含 benchmark 名称、标签、说明和题目数量，可多选。部分 benchmark 支持**评测维度**勾选，默认全部选中，可自定义取消只跑指定子维度数据。
5.  （可选）开启**数据采样百分比**开关，按百分比采样评测数据以缩短评测耗时；关闭则跑全量数据。
6.  单击**开始评测**提交任务。费用按实际推理与评分消耗计算，提交前可查看计算详情。

## 与自定义评测的区别

-   基线评测不使用自定义评测维度，系统使用预设标准自动评分。
-   基线评测不支持推理结果集数据来源，仅使用平台预设的公开数据集。
-   基线评测任务在任务列表中显示综合得分，不显示维度详情列（显示短横线）。
-   基线评测任务不可进入人工标注页面。

自定义评测的创建请参见[创建自定义评测任务](raw/model-user-guide/model-evaluation-introduction/evaluation-task-introduction/create-custom-evaluation-task.md)。

## 常见问题

问题：创建评测任务时看不到基线评测选项。

基线评测仅限北京地域使用。如果您在其他地域，评测方式只显示自定义评测，这是预期行为。
