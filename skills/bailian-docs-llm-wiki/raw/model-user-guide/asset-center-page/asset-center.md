# 资产中心

资产中心是阿里云百炼为您提供的生成资产管理入口，开通后可统一管理模型生成的图片和视频，并提供筛选、收藏、删除、OSS 转存等功能。

**重要**资产中心目前处于邀测阶段，平台存储免费开放。

## 什么是资产中心

资产中心用于集中管理百炼模型为您生成的图片和视频资产，支持按类型、模型、时间或提示词筛选，以及收藏、删除、OSS 转存等操作。

生成的资产默认保存在平台存储中。您也可以配置 OSS 转存规则，将资产自动同步到自己的阿里云 OSS Bucket，并选择是否同时保留平台存储副本。

首次使用前，请登录[阿里云百炼控制台](https://bailian.console.aliyun.com/)，在左侧导航栏选择**工作台 > 资产中心**并点击**立即开通**。

## 支持的模型

当前资产中心支持的模型包括：`qwen-image-2.0-pro-2026-06-22`、`qwen-image-2.0-pro-2026-04-22`、`z-image`、`wan2.7-image-pro`、`wan2.7-image`、`wan2.7-videoedit`、`wan2.7-r2v`、`wan2.7-i2v`、`wan2.7-t2v`。支持的模型范围可能随产品迭代调整，请以控制台资产中心页面实际展示为准。

> 当前资产中心支持管理图片和视频资产，暂不支持音频资产。

## 配置 OSS 转存

为避免平台存储容量超限，您可以将资产自动转存到自己的阿里云 OSS Bucket。转存后，您可以选择是否释放平台存储副本。在资产中心页面右上角，点击**绑定 OSS**，按以下步骤完成配置：

1.  **授权 SLR**：一键授权服务关联角色 `AliyunServiceRoleForBailianAssetForward`，无需提供 AccessKey。若当前账号已授权，该步骤会自动完成。
2.  **Bucket 与路径**：选择目标地域、OSS Bucket 和目录，并确认路径模板，系统默认路径模板为 `{workspace}/{yyyy}/{mm}/{model}/{id}.{ext}`，其中 `{workspace}` 为业务空间标识。
3.  **转存范围**：选择转存全部资产，或仅转存 N 天前的资产，并选择转存完成后是否**释放平台存储**，然后完成绑定。若选择释放平台存储（不保留副本），资产将不再显示在资产中心。

绑定成功后，页面右上角按钮会变为**OSS 转存配置**。点击后可查看当前绑定状态、Bucket 信息、转存范围、转存日志，并支持编辑配置或解绑。对于转存失败的任务，系统会自动重试。您也可以在转存日志中查看失败原因。

**说明**OSS 转存配置为全局设置，不随业务空间切换而变化。

**说明**绑定 OSS 后，若未选择保留平台存储副本，资产会直接同步到 OSS，不会在资产中心展示。

## 查看资产列表

进入资产中心后，页面顶部会展示当前业务空间下的资产统计信息，包括资产总数、图片数量、视频数量以及已用平台存储容量。您可以点击**前往模型体验**，在模型体验中心生成图片或视频，相关资产将自动汇总到资产中心。您可以通过以下方式筛选资产：

-   **类型**：全部类型、图片或视频。
-   **模型**：选择生成资产时使用的模型。
-   **日期范围**：按生成时间区间筛选。
-   **搜索提示词**：输入提示词或文件名关键词进行搜索。

## 管理资产

-   **收藏资产**：将鼠标悬停在资产卡片上，点击右上角的星形图标即可收藏或取消收藏。勾选页面右上方的**只看收藏**，可仅展示已收藏资产。
    
-   **删除资产**：将鼠标悬停在资产卡片上，勾选复选框后点击删除按钮；勾选多个资产后，可点击批量操作栏中的**删除**批量删除。
    
    删除后的资产会进入**回收站**，而非立即永久删除。点击页面右上方的**回收站**按钮可查看已删除资产，回收站中的资产默认保留 30 天。在回收站中，您可以单选或批量选择资产并执行**永久删除**。
    
-   **查看资产详情**：点击任意资产卡片，会弹出资产详情弹窗，展示该资产的完整信息，包括提示词、生成参数、模型名称、生成时间等。
    

## 在 API 中使用资产

每个资产都有唯一的资产 ID（asset\_id），可在资产详情中查看。点击任意资产卡片，在弹窗右侧的**资产 ID** 字段中获取。

在调用生图或生视频模型 API 时，可通过 asset\_id 直接引用资产中心中已有的图片或视频作为输入，无需传入 URL 或 Base64 编码：

-   生图模型：图片输入参数（如参考图、控制图等）支持 `asset_id` 字段，与 `image_url` / `image_base64` 三选一。
-   生视频模型：视频/图片输入参数（如首帧图、参考视频等）支持 `asset_id` 字段，与 URL / Base64 二选一。

## 平台存储与计费

资产中心页面顶部展示当前业务空间的平台存储使用情况，格式为**已用容量 / 免费额度**，例如：**0.00 / 5 GB**。点击**平台存储**旁的信息图标，可查看容量明细。

资产中心目前处于邀测阶段，平台存储免费开放，正式商用后将按量计费。

## 常见问题

**切换业务空间后，资产会变化吗？**

会。资产中心仅展示当前业务空间下的生成资产，但 OSS 转存配置是全局的，不会因业务空间切换而改变。

**回收站中的资产多久会被清理？**

回收站中的资产默认保留 30 天，到期后系统会自动清理。您也可以在回收站中手动永久删除。
