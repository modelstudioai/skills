# 在线策略蒸馏概览

介绍在线策略蒸馏（OPD）的概念、能力与使用入口

在线策略蒸馏（Online Policy Distillation，简称 OPD）是百炼提供的模型在线调优能力，通过教师模型引导学生模型学习，实现模型能力的在线优化与蒸馏。

## 能力概述

OPD 支持纯蒸馏（无需编写函数组件）与在线策略优化两种模式，覆盖训练配置、可观测、Agent 开发等完整链路。
