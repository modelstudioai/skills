# qwen3-vl-32b-instruct

Qwen3-VL系列最大尺寸Dense模型的非推理版本，综合表现仅次于Qwen3-VL-235B-Instruct，文档识别和理解能力出色，空间感知与万物识别能力强，视觉2D检测/空间推理能力达到SOTA，适合通用场景下的复杂感知任务。

## 推理服务供应商

`qwen3-vl-32b-instruct`模型的推理服务供应商为阿里云百炼。
