# qwen3-vl-32b-thinking

Qwen3-VL系列最大尺寸Dense模型的推理版本，多模态推理能力仅次于Qwen3-VL-235B-Thinking，STEM&数学类解题能力、通用图像和视频理解能力出众，多模态Agent能力达到SOTA，适合做复杂多模态推理任务。

## 推理服务供应商

`qwen3-vl-32b-thinking`模型的推理服务供应商为阿里云百炼。
