# qwen-vl-plus

千问VL-Plus（qwen-vl-plus），即千问大规模视觉语言模型增强版。大幅提升细节识别能力和文字识别能力，支持超百万像素分辨率和任意长宽比规格的图像。在广泛的视觉任务上提供卓越的性能。该模型版本功能等同于快照模型 qwen-vl-plus-2025-08-15。

## 推理服务供应商

`qwen-vl-plus`模型的推理服务供应商为阿里云百炼。
