# qwen-vl-max

千问VL-Max（qwen-vl-max），即千问超大规模视觉语言模型。相比增强版，再次提升视觉推理能力和指令遵循能力，提供更高的视觉感知和认知水平。在更多复杂任务上提供最佳的性能。该模型版本功能等同于快照模型 qwen-vl-max-2025-08-13。
