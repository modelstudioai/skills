# qvq-max

千问QVQ视觉推理模型，支持视觉输入及思维链输出，在数学、编程、视觉分析、创作以及通用任务上都表现了更强的能力。该模型版本功能等同于快照模型 qvq-max-2025-03-25。

## 推理服务供应商

`qvq-max`模型的推理服务供应商为阿里云百炼。
