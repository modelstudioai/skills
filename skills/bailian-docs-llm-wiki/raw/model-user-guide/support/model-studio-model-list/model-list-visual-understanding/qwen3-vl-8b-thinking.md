# qwen3-vl-8b-thinking

Qwen3-VL系列8B Dense模型的Thinking版本，占用显存更低，能够完成多模态理解与推理；支持长视频长文档等超长上下文、视觉2D/3D定位；全面升级图像/视频理解、空间感知与万物识别能力。

## 推理服务供应商

`qwen3-vl-8b-thinking`模型的推理服务供应商为阿里云百炼。
