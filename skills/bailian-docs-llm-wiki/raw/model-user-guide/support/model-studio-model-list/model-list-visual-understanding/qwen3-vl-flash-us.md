# qwen3-vl-flash-us

Qwen3系列小尺寸视觉理解模型，实现思考模式和非思考模式的有效融合，效果优于开源版Qwen3-VL-30B-A3B，响应速度快。全面升级图像/视频理解，支持长视频长文档等超长上下文、空间感知与万物识别；具备视觉2D/3D定位能力，胜任复杂现实任务。该模型版本功能等同于快照模型 qwen3-vl-flash-2026-01-22-us。

## 推理服务供应商

`qwen3-vl-flash-us`模型的推理服务供应商为阿里云百炼。
