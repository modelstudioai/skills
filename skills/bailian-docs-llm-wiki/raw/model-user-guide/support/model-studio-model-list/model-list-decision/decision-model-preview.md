# decision-model-preview

面向高频业务判断的结构化决策模型，可根据文本或业务状态并行完成分类、是非判断与评分，并返回概率分布和置信度，适用于工单分流、内容审核、智能体路由与结果校验等场景。

## 推理服务供应商

`decision-model-preview` 模型的推理服务供应商为阿里云百炼。
