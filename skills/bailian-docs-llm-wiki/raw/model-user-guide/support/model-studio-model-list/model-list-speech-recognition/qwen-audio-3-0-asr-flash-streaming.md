# qwen-audio-3.0-asr-flash-streaming

qwen-audio-3.0-asr-flash-streaming是通义实验室专为低延迟、高并发实时交互场景打造的旗舰级语音识别模型。它不仅能实现“边说边出字”的极致流畅体验，并深度集成了 Context（上下文增强）能力，还针对垂直行业专业词汇进行了深度强化训练，是构建实时会议同传、智能客服坐席辅助、语音助手等应用的首选。

## 推理服务供应商

`qwen-audio-3.0-asr-flash-streaming`模型的推理服务供应商为阿里云百炼。
