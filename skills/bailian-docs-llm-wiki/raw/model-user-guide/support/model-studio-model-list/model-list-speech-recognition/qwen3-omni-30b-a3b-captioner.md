# qwen3-omni-30b-a3b-captioner

千问3-Omni-30b-a3b-Captioner是一款强大的音频细粒度分析模型，专为在复杂多变的音频场景中生成精准、全面的内容描述而设计，可自动解析并描述从复杂语音、环境声到音乐、影视声效等各类音频内容，能够在多声源、混合化的环境中亦保持稳定而可信的输出。
