# paraformer-realtime-v1

Paraformer中文实时语音识别模型，支持16kHz及以上采样率的视频直播、会议等实时场景下的语音识别。

## 推理服务供应商

`paraformer-realtime-v1`模型的推理服务供应商为阿里云百炼。
