# fun-asr-flash-8k-realtime

通义百聆推出的新一代轻量级实时语音识别模型，依托自研的先进语音技术架构，具备强大的上下文理解能力。专为中文电话客服场景设计：覆盖多地区方言口音，在低采样率、低信噪比环境下实现低延迟、高准确率的流式转写，满足高效部署需求。该模型版本功能等同于快照模型 fun-asr-flash-8k-realtime-2026-01-28。
