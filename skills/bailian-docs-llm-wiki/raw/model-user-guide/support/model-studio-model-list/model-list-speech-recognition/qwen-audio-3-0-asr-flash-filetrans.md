# qwen-audio-3.0-asr-flash-filetrans

qwen-audio-3.0-asr-flash-filetrans是专为非实时、整段音视频文件设计的高性能转写模型。它不仅集成了 Context（上下文增强）能力，还强化了垂直行业热词的识别精度，非常适合短视频字幕、客服质检和金融双录场景。

## 推理服务供应商

`qwen-audio-3.0-asr-flash-filetrans`模型的推理服务供应商为阿里云百炼。
