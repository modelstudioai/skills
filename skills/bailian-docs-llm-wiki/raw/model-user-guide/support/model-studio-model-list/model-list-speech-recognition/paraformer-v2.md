# paraformer-v2

推荐使用 Paraformer最新语音识别模型，支持多个语种的语音识别。可以通过language\_hints参数选择语种获得更准确的识别效果，支持任意采样率。 支持的语言包括：中文（含粤语等各种方言）、英文、日语、韩语。可支持热词。
