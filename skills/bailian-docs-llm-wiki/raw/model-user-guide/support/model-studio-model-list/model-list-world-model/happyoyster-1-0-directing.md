# happyoyster-1.0-directing

HappyOyster Directing 是实时交互、可沉浸演绎的开放式世界模型。基于多模态（文本/图像）输入即可生成的世界场景，在任意时刻通过文本驱动世界实时演绎生成。

## 推理服务供应商

`happyoyster-1.0-directing`模型的推理服务供应商为阿里云百炼。
