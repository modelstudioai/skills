# qwen3.6-plus

Qwen3.6原生视觉语言系列Plus模型，展现出与当前顶尖前沿模型相媲美的卓越性能，模型效果相较3.5系列显著提升。模型在Agentic coding、前端编程、Vibe coding等代码能力、多模态万物识别、OCR、物体定位等能力上显著增强。该模型版本功能等同于快照模型 qwen3.6-plus-2026-04-02。

## 推理服务供应商

`qwen3.6-plus`模型的推理服务供应商为阿里云百炼。
