# deepseek-v3

DeepSeek-V3 为自研 MoE 模型，671B 参数，激活 37B，在 14.8T token 上进行了预训练，在长文本、代码、数学、百科、中文 能力上表现优秀。

## 推理服务供应商

`deepseek-v3`模型的推理服务供应商为阿里云百炼。
