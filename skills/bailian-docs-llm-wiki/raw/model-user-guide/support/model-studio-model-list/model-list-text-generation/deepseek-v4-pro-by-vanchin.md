# vanchin/deepseek-v4-pro

DeepSeek-V4系列是强大的混合专家（MoE）语言模型，包含DeepSeek-V4-Pro（1.6T总参数，49B激活参数）。支持高达100万（1M）token的上下文长度，是在超过32T高质量多样化token上预训练的开源模型。

## 推理服务供应商

`vanchin/deepseek-v4-pro`模型的推理服务供应商为快手万擎。
