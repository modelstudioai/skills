# qwen-mt-lite-us

基于Qwen3全面升级的基础级文本翻译大模型，支持31个语种互译，模型性能和翻译效果全面升级，并提供更稳定的术语定制、格式还原度、领域提示能力，让译文更精准、自然。

## 推理服务供应商

`qwen-mt-lite-us`模型的推理服务供应商为阿里云百炼。
