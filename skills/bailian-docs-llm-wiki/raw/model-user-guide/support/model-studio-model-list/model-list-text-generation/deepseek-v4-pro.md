# deepseek-v4-pro

旗舰级 MoE 大模型，总参1.6T、激活 49B，原生支持百万级超长上下文。依托海量高质量训练数据，具备顶尖数学逻辑、复杂推理、专业代码与长文本深度解析能力，适配高阶科研、复杂办公、深度智能代理等高难度场景。

## 推理服务供应商

`deepseek-v4-pro`模型的推理服务供应商为阿里云百炼。
