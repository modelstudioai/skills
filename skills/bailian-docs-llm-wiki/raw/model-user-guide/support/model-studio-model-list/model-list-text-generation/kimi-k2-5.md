# kimi-k2.5

kimi-k2.5是月之暗面迄今发布最全能的模型，原生多模态架构设计，同时支持视觉与文本输入、思考与非思考模式、对话与Agent任务。

## 推理服务供应商

`kimi-k2.5`模型的推理服务供应商为阿里云百炼。
