# deepseek-v4-flash

高效轻量化MoE模型，总参284B，激活13B，原生支持百万超长上下文能力。推理速度快、延迟低、调用成本低廉，综合能力均衡，主打高并发、轻量化任务，适合日常对话、内容创作、基础 RAG、批量文案处理等普惠刚需场景。该模型对应深度求索的 DeepSeek-V4-Flash 预览版（deepseek-v4-flash-preview），正式版请使用 deepseek-v4-flash-0731。

## 推理服务供应商

`deepseek-v4-flash`模型的推理服务供应商为阿里云百炼。
