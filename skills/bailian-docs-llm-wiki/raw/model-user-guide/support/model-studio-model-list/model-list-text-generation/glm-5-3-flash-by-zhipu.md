# ZHIPU/GLM-5.3-Flash

智谱原厂直供，GLM-5 系列首个原生多模态模型。GLM-5.3-Flash 采用稀疏注意力与线性注意力混合架构，以更低成本提供超越 GLM-5.2 的智能水平，支持 1M 上下文，并原生支持图像、视频与文件输入。

## 推理服务供应商

`ZHIPU/GLM-5.3-Flash`模型的推理服务供应商为智谱AI。
