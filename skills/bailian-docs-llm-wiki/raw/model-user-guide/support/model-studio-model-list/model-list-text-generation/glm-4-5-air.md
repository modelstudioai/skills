# glm-4.5-air

GLM-4.5-Air采用混合专家（MoE）架构，总参数量为1060亿，激活参数120亿，相较GLM-4.5更紧凑、轻量，适用于对模型规模和资源消耗有一定限制的场景。

## 推理服务供应商

`glm-4.5-air`模型的推理服务供应商为阿里云百炼。
