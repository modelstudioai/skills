# kimi-k2.6

kimi-k2.6是Kimi最新最智能的模型，具备更强更稳的长程代码编写能力，指令遵循和自我纠错能力显著提升，同时支持文本、图片与视频输入，思考与非思考模式，对话与Agent任务。

## 推理服务供应商

`kimi-k2.6`模型的推理服务供应商为阿里云百炼。
