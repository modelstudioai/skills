# unisound/unisound-u2

云知声直供的推理模型，默认开启思考模式，可通过 thinking 参数开启或关闭思考模式，并通过 reasoning\_effort 控制思考强度。仅支持文本输入。

## 推理服务供应商

`unisound/unisound-u2`模型的推理服务供应商为云知声。
