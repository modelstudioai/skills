# qwen3-30b-a3b-instruct-2507

基于Qwen3的非思考模式开源模型，相较上一版本（千问3-30B-A3B）中英文和多语言整体通用能力有大幅提升。主观开放类任务专项优化，显著更加符合用户偏好，能够提供更有帮助性的回复。

## 推理服务供应商

`qwen3-30b-a3b-instruct-2507`模型的推理服务供应商为阿里云百炼。
