# qwen3-next-80b-a3b-instruct

基于Qwen3的新一代非思考模式开源模型，相较上一版本（千问3-235B-A22B-Instruct-2507）中文文本理解能力更佳、逻辑推理能力有增强、文本生成类任务表现更好。

## 推理服务供应商

`qwen3-next-80b-a3b-instruct`模型的推理服务供应商为阿里云百炼。
