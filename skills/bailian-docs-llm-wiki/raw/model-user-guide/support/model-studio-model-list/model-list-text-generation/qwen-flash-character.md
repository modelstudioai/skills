# qwen-flash-character

千问系列多语言角色扮演模型，本模型是动态更新版本，模型更新会提前通知，适合拟人化的角色扮演，同时优化了限定人设指令遵循、话题推进、倾听共情等能力，支持个性化角色的深度还原。

## 推理服务供应商

`qwen-flash-character`模型的推理服务供应商为阿里云百炼。
