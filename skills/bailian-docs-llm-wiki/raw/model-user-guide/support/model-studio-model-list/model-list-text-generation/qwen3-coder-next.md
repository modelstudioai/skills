# qwen3-coder-next

Qwen3系列新一代代码生成模型，效果接近Qwen3-Coder-Plus兼具更优性能。模型重点优化仓库级别理解、支持多轮工具交互、提升对于agentic coding类工具的适配能力。

## 推理服务供应商

`qwen3-coder-next`模型的推理服务供应商为阿里云百炼。
