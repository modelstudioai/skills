# qwen3.8-27b

Qwen3.8系列27B原生视觉语言Dense模型，模型效果相较3.6-27B重点提升了文本和视觉模态下的编程和办公场景能力，能更可靠地端到端完成复杂任务，输出值得信赖的成果。

## 推理服务供应商

`qwen3.8-27b`模型的推理服务供应商为阿里云百炼。
