# qwen3.8-max

2.4万亿参数的MoE架构旗舰模型，在编程与办公场景能力提升，适用于法律、金融、设计等专业任务。具备原生视觉理解能力，支持超长文档与长视频的语义解析，并支持长程任务的自主规划与迭代。

模型调用 ID（`model` 参数取值）：`qwen3.8-max`
