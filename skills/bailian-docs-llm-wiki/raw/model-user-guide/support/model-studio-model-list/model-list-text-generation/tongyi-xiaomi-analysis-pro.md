# tongyi-xiaomi-analysis-pro

伶鹊-对话分析-pro是专注于高阶复杂分析，如针对具备复杂业务逻辑的复杂质检规则等分析需求的模型，支持自定义更细粒度的分析标准，具备更强的多轮上下文建模、深层语义理解与推理能力。

## 推理服务供应商

`tongyi-xiaomi-analysis-pro`模型的推理服务供应商为阿里云百炼。
