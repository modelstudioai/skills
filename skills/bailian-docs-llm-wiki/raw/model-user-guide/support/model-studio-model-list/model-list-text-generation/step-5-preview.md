# stepfun/step-5-preview

Step 5 Preview，一款面向真实世界 Agentic 任务的旗舰基座模型。Step 5 Preview 在 AI 编程、软件工程、专业知识工作等任务上达到前沿水平，并在金融领域展现出尤为突出的能力。采用稀疏 MoE 架构，总参数量 600B，每个 Token 激活 27B 参数，支持 1M Token 上下文窗口和视觉输入。

## 推理服务供应商

`stepfun/step-5-preview`模型的推理服务供应商为阶跃星辰。
