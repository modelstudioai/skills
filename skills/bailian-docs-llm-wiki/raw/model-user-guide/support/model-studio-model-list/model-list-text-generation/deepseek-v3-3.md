# deepseek-v3.2

DeepSeek-V3.2是引入DeepSeek Sparse Attention（一种稀疏注意力机制）的正式版模型，也是DeepSeek推出的首个将思考融入工具使用的模型，同时支持思考模式与非思考模式的工具调用。

## 推理服务供应商

`deepseek-v3.2`模型的推理服务供应商为阿里云百炼。
