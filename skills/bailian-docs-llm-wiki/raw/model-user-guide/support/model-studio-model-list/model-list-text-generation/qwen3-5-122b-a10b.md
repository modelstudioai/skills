# qwen3.5-122b-a10b

Qwen3.5系列122B-A10B原生视觉语言模型，基于混合架构设计，融合了线性注意力机制与稀疏混合专家模型，实现了更高的推理效率。该模型的综合表现仅次于Qwen3.5-397B-A17B，文本能力显著优于Qwen3-235B-2507，视觉能力优于Qwen3-VL-235B。

## 推理服务供应商

`qwen3.5-122b-a10b`模型的推理服务供应商为阿里云百炼。
