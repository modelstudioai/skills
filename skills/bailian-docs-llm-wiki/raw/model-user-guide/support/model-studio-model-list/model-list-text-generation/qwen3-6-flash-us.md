# qwen3.6-flash-us

Qwen3.6原生视觉语言系列Flash模型，模型效果相较3.5-Flash显著提升。本模型重点提升agentic coding能力（在多项代码智能体基准上大幅超越前代）、数学推理和代码推理能力；视觉方面在空间智能能力上显著增强，物体定位与目标检测提升尤为突出。

## 推理服务供应商

`qwen3.6-flash-us`模型的推理服务供应商为阿里云百炼。
