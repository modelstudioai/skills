# qwen-max

千问2.5系列千亿级别超大规模语言模型，支持中文、英文等不同语言输入。随着模型的升级，qwen-max将滚动更新升级。如果希望使用固定版本，请使用历史快照版本。该模型版本功能等同于快照模型 qwen-max-2025-01-25。
