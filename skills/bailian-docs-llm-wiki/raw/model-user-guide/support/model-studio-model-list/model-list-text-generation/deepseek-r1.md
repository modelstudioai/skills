## vanchin/deepseek-r1

DeepSeek-R1 是深度求索于 2025 年 1 月开源的 6710 亿参数混合专家（MoE）推理模型，推理时仅激活 370 亿参数。作为首个通过纯强化学习（无监督微调）训练的千亿级模型，实现了链式思维（CoT）的自然涌现。模型在 RL 前加入冷启动数据解决了 R1-Zero 的重复和混语问题，在数学、代码、推理任务上达到 OpenAI o1 水平。
