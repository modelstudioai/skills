# deepseek-v3.1

DeepSeek-V3.1为混合推理架构模型，同时支持思考模式与非思考模式，具备更高的推理效率和更强的Agent能力。

## 推理服务供应商

`deepseek-v3.1`模型的推理服务供应商为阿里云百炼。
