# qwen-audio-3.0-realtime-plus

千问实时语音大模型 是一款登顶全球权威评测的下一代实时双工语音大模型，它在全球权威第三方评测平台 Artificial Analysis Speech-to-Speech子项中取得综合排名第一。千问实时语音大模型 兼顾了模型智商与双工对话节奏,在保持流畅、自然的实时交互体验的同时,语音推理能力不打折扣;并通过并行推理和全向流式等工程优化,将端到端响应时延控制在低水平,实现"又快又聪明"的对话体验。标准版更注重高质量的回复结果。

## 推理服务供应商

`qwen-audio-3.0-realtime-plus`模型的推理服务供应商为阿里云百炼。
