# tongyi-embedding-vision-plus

Embedding-Vision是基于LLM底座的视觉多模态表征模型，具有以视觉为中心、领域性能优异（电商、 安防、相册/图库、自驾等）、高性价比的特点。兼容文本、图像、视频3种模态，可应用于以图搜图、以文搜图、以文搜视频，以视频搜视频等下游任务场景。

## 推理服务供应商

### tongyi-embedding-vision-plus-2026-03-06
