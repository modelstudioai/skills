# qwen3.7-text-embedding

是通义实验室基于Qwen3.7训练的多语言文本统一向量模型，相较text-embedding-v4版本在文本检索、聚类、分类性能大幅提升；在MTEB多语言、中英、Code检索等评测任务上效果提升20%；支持256~2560维用户自定义向量维度。

## 推理服务供应商

`qwen3.7-text-embedding`模型的推理服务供应商为阿里云百炼。
