# text-embedding-async-v1

通用文本向量的批处理接口，通过这个接口客户可以以文本方式一次性的提交大批量的向量计算请求，在系统完成所有的计算之后，大模型服务平台会将结果信息存储在结果文件中供客户下载解析。

## 推理服务供应商

`text-embedding-async-v1`模型的推理服务供应商为阿里云百炼。
