# qwen3-vl-rerank

Qwen3-VL-Rerank重排模型，它能够深入理解文本、图片、视频的丰富多模态信息。在初步检索获得结果后，Qwen3-VL-Rerank 能够运用其先进的跨模态关联能力，对候选项目进行智能化的二次排序，将最相关的结果置于显要位置。通用用于提升跨模态搜索的准确率、优化图搜和视频检索的精准度、辅助图像聚类的分组质量、以及实现复杂多模态信息的高效检索和精确打标。
