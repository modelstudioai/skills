# qwen-tts

千问系列首个语音合成模型，支持中文、英文、中英混合输入。自适应根据输入文本调整输出语气，音色真实自然，支持流式输出。

## 推理服务供应商

`qwen-tts`模型的推理服务供应商为阿里云百炼。
