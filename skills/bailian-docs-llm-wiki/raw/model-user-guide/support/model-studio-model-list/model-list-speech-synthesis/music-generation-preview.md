# fun-music-preview

百聆音乐生成preview版大模型（Fun音乐大模型）支持输入开放性歌曲的创作要求或歌词，生成整首男/女声演唱的中文或英文歌曲。歌曲通俗易懂，情绪由浅入深，是人类灵感与大模型能力的完美结合。本次版本为预览快照版

## 推理服务供应商

`fun-music-preview`模型的推理服务供应商为阿里云百炼。
