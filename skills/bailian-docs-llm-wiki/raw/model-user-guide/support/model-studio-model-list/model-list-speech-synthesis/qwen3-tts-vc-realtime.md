# qwen3-tts-vc-realtime-2026-01-15

千问3-TTS-Flash模型是通义最新推出的实时语音合成大模型，可对qwen-voice-enrollment服务复刻的声音进行高保真实时语音合成，且同一音色支持11个语种的语音输出。该模型经过海量数据训练，合成音频可以根据文本自适应调节语气，对复杂文本合成也有较好的处理能力。该模型为2026年01月15日快照版本模型。

## 推理服务供应商
