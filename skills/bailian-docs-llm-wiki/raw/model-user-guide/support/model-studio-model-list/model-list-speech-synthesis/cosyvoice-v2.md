# cosyvoice-v2

cosyvoice-V2是通义实验室依托大规模预训练语言模型，在深度融合文本理解和语音生成的新一代生成式语音合成大模型，支持文本至语音的实时流式合成。

## 推理服务供应商

`cosyvoice-v2`模型的推理服务供应商为阿里云百炼。
