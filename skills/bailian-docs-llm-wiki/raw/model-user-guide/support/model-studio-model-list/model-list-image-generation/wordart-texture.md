# wordart-texture

WordArt锦书-文字纹理生成可以对输入的文字内容或文字图片进行创意设计，根据提示词内容对文字添加材质和纹理，实现立体凸显或场景融合的效果，生成效果精美、风格多样的艺术字，结合背景可以直接作为文字海报使用。

## 推理服务供应商

`wordart-texture`模型的推理服务供应商为阿里云百炼。
