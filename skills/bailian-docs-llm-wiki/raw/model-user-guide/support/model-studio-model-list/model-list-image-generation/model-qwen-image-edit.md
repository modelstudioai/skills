# qwen-image-edit

千问系列首个图像编辑模型，成功将Qwen-Image的文本渲染能力拓展到编辑任务上。支持精准的中英双语文字编辑、视觉外观与语义双重编辑、具备强大的跨基准性能表现。

## 推理服务供应商

`qwen-image-edit`模型的推理服务供应商为阿里云百炼。
