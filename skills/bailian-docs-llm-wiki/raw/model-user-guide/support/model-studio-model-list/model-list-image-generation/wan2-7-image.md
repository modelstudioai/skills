# wan2.7-image

万相2.7-图像生成与编辑，支持文生图、文生组图、图生组图、图像编辑、多图参考生成、交互式编辑，在文字渲染、主体一致性、复杂指令遵循上都有更强表现

## 推理服务供应商

`wan2.7-image`模型的推理服务供应商为阿里云百炼。
