# qwen-image-max

千问图像生成模型Max系列，在各类生成任务中表现出色，相较Plus系列大幅度降低生成图片的AI感，提升图像真实性；具备更真实的人物质感、更细腻的自然纹理、更美观的文字渲染。该模型版本功能等同于快照模型 qwen-image-max-2025-12-30。
