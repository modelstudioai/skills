# qwen-image-2.1-turbo

Qwen-Image-2.1-Turbo 是目前 Qwen-Image 系列中综合表现与性价比最优的开源图像生成模型，具备四大核心优势：模型轻量，性能强劲，性价比卓越。原生透明，生成与编辑一体化。灵活编辑：支持多参考图、局部控制、高保真还原与全面编辑能力。真实质感，优雅排版，精美人像。
