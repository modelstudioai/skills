# qwen-image-2.0-pro

Qwen-Image-2.0系列满血版模型，实现了图片生成和图片编辑的融合；具备更专业的文字渲染1k token指令支持能力、更细腻的真实质感，细腻刻画写实场景、更强的语义遵循能力。满血版具备2.0系列最强的文字渲染能力和真实质感。该模型版本功能等同于快照模型 qwen-image-2.0-pro-2026-04-22。

## 推理服务供应商
