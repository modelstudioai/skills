# wan3.0-video

Wan3.0-Video是全能参考视频生成模型（All-in-One），支持文本、图像、视频、音频等多模态输入，统一实现文生视频、图生视频（首帧/首尾帧）和参考生视频等能力。支持480P、720P和1080P分辨率输出，最长可生成30秒视频。

## 推理服务供应商

`wan3.0-video`模型的推理服务供应商为阿里云百炼。
