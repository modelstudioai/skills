# happyhorse-1.0-video-edit

HappyHorse-1.0-Video-Edit支持视频编辑，自然语言指令编辑视频，可参考最多5张图片局部或全局编辑视频元素，能够精准复刻视频动态过程，实现更强表现能力。

## 推理服务供应商

`happyhorse-1.0-video-edit`模型的推理服务供应商为阿里云百炼。
