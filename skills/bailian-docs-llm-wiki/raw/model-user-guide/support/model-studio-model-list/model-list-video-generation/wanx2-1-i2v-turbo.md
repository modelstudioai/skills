# wanx2.1-i2v-turbo

万相2.1-图生视频-Turbo，让图片变为动态视频。支持大幅度复杂运动、物理规律遵循、丰富艺术风格和影视级画面质感，指令遵循能力进一步提升，生成速度更快。

## 推理服务供应商

`wanx2.1-i2v-turbo`模型的推理服务供应商为阿里云百炼。
