# pixverse/pixverse-motioncontrol

Motion Control 支持从参考视频中提取动作，并迁移到目标人物图片上，生成角色复现相同动作的新视频。

## 推理服务供应商

`pixverse/pixverse-motioncontrol`模型的推理服务供应商为PixVerse。
