# pixverse/pixverse-v6-t2v

V6是PixVerse在26年3月底推出的新模型，t2v（文字生成视频）模型可通过提示词精准控制视频画面，精确还原各类镜头语言，推、拉、摇、移、跟随等运镜方式流畅自然，视角切换精准可控。支持15秒长视频、音乐和视频直出、支持多种语言文字。

## 推理服务供应商

`pixverse/pixverse-v6-t2v`模型的推理服务供应商为PixVerse。
