# pixverse/pixverse-upscale

Upscale 支持将不同分辨率的视频超分至 4K，提升画面清晰度与细节表现，适合高质量展示与二次分发。

## 推理服务供应商

`pixverse/pixverse-upscale`模型的推理服务供应商为PixVerse。
