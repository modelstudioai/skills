# wan2.2-animate-move

wan2.2-animate-move图生动作是一款角色动画生成模型，用户只需上传一张角色照片和一段参考表演视频，即可将视频中的表情和动作迁移到图片角色上，生成高保真的动画视频。

## 推理服务供应商

`wan2.2-animate-move`模型的推理服务供应商为阿里云百炼。
