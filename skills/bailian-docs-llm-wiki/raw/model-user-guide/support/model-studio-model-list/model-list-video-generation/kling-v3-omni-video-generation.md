# kling/kling-v3-omni-video-generation

新增“全能参考”，支持3-8秒视频或多图锚定角色元素。可匹配原声及口型驱动，实现角色本色呈现。视频一致性更强，表现更灵动。支持音画同步、智能分镜。

## 推理服务供应商

`kling/kling-v3-omni-video-generation`模型的推理服务供应商为可灵AI。
