# vidu/viduq3_reference2video

输入1-7张参考图片与文本描述，生成视频。ViduQ3支持智能切镜，多机位一致性更出色。ViduQ3参考生视频为剧而生，万物可参，声画同出：6大特效（粒子 / 流体 / 动力学 / 运镜 / 转场 / 光影）、5大音效（环境 / 动态 / 氛围 / 拟音 / 情绪）、4大场景（短剧 / 漫剧 / 影视剧 / 广告）全面融合，轻松驾驭短剧、漫剧、广告等多元创作。

## 推理服务供应商
