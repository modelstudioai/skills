# happyhorse-1.1-i2v

HappyHorse-1.1-I2V支持图生视频，进一步提升画面质感、动态表现与跨片段一致性。模型能够更精准地理解输入图像并延续创作意图，在人物皮肤质感、ID跨片段保持、动作流畅度、文字渲染稳定性以及音画同步上带来显著改善，输出更真实自然、细节丰富且一致性更高的高质量视频。

## 推理服务供应商

`happyhorse-1.1-i2v`模型的推理服务供应商为阿里云百炼。
