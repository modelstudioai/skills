# vidu/viduq3-pro_start-end2video

输入首帧图、尾帧图与文本描述，生成视频。ViduQ3-Pro首尾帧生视频是旗舰级音视频原生模型。支持长达16秒的音画同步生成，实现多镜头自由切换，精准把控节奏、情绪与叙事连贯性。参数量领先，画质、人物一致性及情绪表现卓越，达电影级标准。适用于广告（电商、TVC、效果投放）、漫剧、真人剧及游戏等专业生产场景。
