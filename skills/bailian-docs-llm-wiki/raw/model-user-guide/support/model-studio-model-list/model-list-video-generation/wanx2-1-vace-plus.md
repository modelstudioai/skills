# wanx2.1-vace-plus

万相2.1-VACE-Plus，视频编辑统一模型。支持局部编辑、视频重绘、背景扩展、时长延展、图片参考等多种视频编辑与生成任务，支持文本、图像、视频等多模态条件控制。

## 推理服务供应商

`wanx2.1-vace-plus`模型的推理服务供应商为阿里云百炼。
