# pixverse/pixverse-v6-r2v-omni

V6-r2v-omni是PixVerse在26年8月推出的新模型，是在现有 Video (T2V/I2V)、Transition (首尾帧)、Extend 基础上新增的能力，支持视频与图片混合输入生成视频。

## 推理服务供应商

`pixverse/pixverse-v6-r2v-omni`模型的推理服务供应商为PixVerse。
