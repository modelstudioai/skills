# wan2.6-r2v

万相2.6-参考生视频，支持指定人物或任意物品进行参考，精准保持形象和声音的一致性，支持多角色参考合拍。提醒：当使用视频进行参考时，输入视频也会计入费用，详见模型计费文档。

## 推理服务供应商

`wan2.6-r2v`模型的推理服务供应商为阿里云百炼。
