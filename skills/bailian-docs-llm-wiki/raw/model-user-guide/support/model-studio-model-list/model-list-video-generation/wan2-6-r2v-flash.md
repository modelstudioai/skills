# wan2.6-r2v-flash

万相2.6-参考生视频-Flash，生成更快性价比更高。支持指定人物或任意物品进行参考，精准保持形象和声音的一致性，支持多角色参考合拍

## 推理服务供应商

`wan2.6-r2v-flash`模型的推理服务供应商为阿里云百炼。
