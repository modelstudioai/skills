# happyhorse-1.0-r2v

HappyHorse-1.0-R2V支持参考生视频，更加稳定的主体与场景参考，支持最多9张图片参考，能够精准保持创作意图，实现更强表现能力。

## 推理服务供应商

`happyhorse-1.0-r2v`模型的推理服务供应商为阿里云百炼。
