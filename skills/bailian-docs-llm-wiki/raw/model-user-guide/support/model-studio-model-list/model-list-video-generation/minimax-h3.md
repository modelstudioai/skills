# MiniMax/MiniMax-H3

MiniMax-H3 支持文生视频、图生视频（首帧/尾帧/首尾帧）和多模态参考生视频，支持 768P 和 2K 分辨率输出。

## 推理服务供应商

`MiniMax/MiniMax-H3`模型的推理服务供应商为 MiniMax。
