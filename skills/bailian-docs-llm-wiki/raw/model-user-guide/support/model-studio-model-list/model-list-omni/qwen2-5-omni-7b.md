# qwen2.5-omni-7b

基于Qwen2.5训练的全新多模态理解生成大模型，支持文本, 图像，语音，视频输入理解和混合输入理解，具备文本和语音同时流式生成能力，多模态内容理解速度显著提升，提供了4种自然对话音色。

## 推理服务供应商

`qwen2.5-omni-7b`模型的推理服务供应商为阿里云百炼。
