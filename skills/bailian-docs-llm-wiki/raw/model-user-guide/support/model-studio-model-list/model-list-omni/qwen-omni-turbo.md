# qwen-omni-turbo

千问全新多模态理解生成大模型，支持文本, 图像，语音，视频输入理解和混合输入理解，具备文本和语音同时流式生成能力，多模态内容理解速度显著提升，提供了4种自然对话音色。该模型版本功能等同于快照模型 qwen-omni-turbo-2025-03-26。
