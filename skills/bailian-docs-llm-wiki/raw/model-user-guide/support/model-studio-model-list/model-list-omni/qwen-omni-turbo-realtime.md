# qwen-omni-turbo-realtime

千问全新多模态理解生成大模型实时版，适合实时音频交互场景。支持音频伴随文本、图像、视频混合输入理解，具备语音和文本同时流式生成能力，提供了4种自然对话音色。该模型版本功能等同于快照模型 qwen-omni-turbo-realtime-2025-05-08。

## 推理服务供应商

`qwen-omni-turbo-realtime`模型的推理服务供应商为阿里云百炼。
