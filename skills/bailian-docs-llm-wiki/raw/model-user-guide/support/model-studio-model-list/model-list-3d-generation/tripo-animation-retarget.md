# Tripo/Tripo-AnimationRetarget

Tripo动画重定向提供 100 套预制动画，可将标准动作快速重定向至已绑定骨骼的模型，自动适配不同角色的骨骼结构与体型差异，无需手动调整动画数据，快速生成可直接使用的角色动画。

## 推理服务供应商

`Tripo/Tripo-AnimationRetarget`模型的推理服务供应商为Tripo。
