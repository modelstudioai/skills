# Tripo/Tripo-Retopology

Tripo重拓扑可将高模快速减面，满足不同 LOD 制作需求，在降低模型面数的同时保持原有几何结构与细节。生成拓扑合理的网格，支持四边面，便于后续编辑与动画制作。

## 推理服务供应商

`Tripo/Tripo-Retopology`模型的推理服务供应商为Tripo。
