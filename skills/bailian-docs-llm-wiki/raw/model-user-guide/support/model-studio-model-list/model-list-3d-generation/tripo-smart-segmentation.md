# Tripo/Tripo-SmartSegmentation

Tripo智能分割支持图片或者模型的输入，提供端到端的模型分割能力；适用于需要按照语义控制进行更精准分割的场景，例如指定拆分特定部件、控制分割范围或调整分割精度。推荐在需要更高可控性的工作流中使用。

## 推理服务供应商

`Tripo/Tripo-SmartSegmentation`模型的推理服务供应商为Tripo。
