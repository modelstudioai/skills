# Tripo/Tripo-MeshCompletion

Tripo网格补全支持对拆分后的模型部件进行 AI 自动补齐，保证拆分后部件的完整性，提升后续 3D 打印、游戏资产、动画等工作流的处理效率。

## 推理服务供应商

`Tripo/Tripo-MeshCompletion`模型的推理服务供应商为Tripo。
