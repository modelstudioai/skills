# Tripo/Tripo-RigCheck

Tripo可绑骨检查可智能检测模型是否满足自动绑骨要求，并根据模型的形体结构与特征，自动判断适用的骨骼类型，为后续骨骼绑定与动画制作提供准确的前置判断。

## 推理服务供应商

`Tripo/Tripo-RigCheck`模型的推理服务供应商为Tripo。
