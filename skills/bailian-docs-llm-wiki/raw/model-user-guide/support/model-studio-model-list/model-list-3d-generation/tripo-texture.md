# Tripo/Tripo-Texture

Tripo AI 贴图支持输入文字或上传图片，通过 AI 算法自动为白模生成材质贴图。支持 PBR/8K 材质，提供更精致的高保真材质细节，显著提升纹理、金属等细节表现。

## 推理服务供应商

`Tripo/Tripo-Texture`模型的推理服务供应商为Tripo。
