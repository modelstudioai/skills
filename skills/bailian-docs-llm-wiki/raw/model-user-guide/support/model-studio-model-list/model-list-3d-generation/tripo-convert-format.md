# Tripo/Tripo-ConvertFormat

Tripo AI 格式转换支持多种主流 3D 模型格式之间的快速转换，自动完成模型数据解析与格式适配，确保模型结构与材质信息完整保留，满足不同 3D 软件、引擎及生产工作流的使用需求。

## 推理服务供应商

`Tripo/Tripo-ConvertFormat`模型的推理服务供应商为Tripo。
