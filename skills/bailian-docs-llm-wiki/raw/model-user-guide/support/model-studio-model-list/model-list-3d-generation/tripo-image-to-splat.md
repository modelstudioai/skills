# Tripo/Tripo-ImageToSplat

Tripo根据单张图片生成 3D Gaussian Splat（.splat 格式）。Gaussian Splatting 是一种新型 3D 表示方式，适用于高质量实时渲染与真实感场景重建。输出的 .splat 文件可用主流 Gaussian Splat 查看器与渲染器加载。

## 推理服务供应商

`Tripo/Tripo-ImageToSplat`模型的推理服务供应商为Tripo。
