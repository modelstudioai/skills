# Tripo/Tripo-Segmentation

Tripo AI 网格分割通过 AI 算法自动识别并完成模型部件分割，无需分件或拓扑经验。支持三档分割精度灵活选择，精准适配 3D 打印、游戏资产、动画等多种工作流。

## 推理服务供应商

`Tripo/Tripo-Segmentation`模型的推理服务供应商为Tripo。
