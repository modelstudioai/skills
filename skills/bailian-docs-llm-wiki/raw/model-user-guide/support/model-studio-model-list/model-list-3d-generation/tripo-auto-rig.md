# Tripo/Tripo-AutoRig

Tripo绑骨基于Tripo自研的 UniRig 算法，可智能解析模型形体结构，自动完成骨骼生成、定位与蒙皮绑定。精准识别脊椎弯曲路径等关键运动维度，实现更合理的骨骼位置与蒙皮权重分配，快速生成可用于动画制作的角色模型。

## 推理服务供应商

`Tripo/Tripo-AutoRig`模型的推理服务供应商为Tripo。
