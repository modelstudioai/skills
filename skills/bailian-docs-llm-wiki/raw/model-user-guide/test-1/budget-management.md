# 预算管理

为账号、业务空间或 API Key 设置模型推理的月度预算与预警，支持达预算后自动停止按量调用。

## 功能概述

预算管理允许您设置月度模型推理的预算上限与预警，并可在预算用尽后自动限制模型推理服务的按量调用，灵活管控账号、业务空间或 API Key 的费用。

登录[百炼控制台](https://bailian.console.aliyun.com/)，在左侧导航栏选择**费用用量** > [**预算管理**](https://bailian.console.aliyun.com/cn-beijing/costing-balance/budget)，进入预算管理页面。

支持按**账号**、**业务空间**、**API Key** 三个粒度分别设置预算，详见[预算维度](#dimensions)。

## 预算范围与统计周期

-   **预算范围**：仅包含阿里直供模型的 API 按调用量付费费用。三方直供模型产生的费用，以及模型训练、预置吞吐（PTU）、模型单元（DTU）等费用，不计入预算金额。模型供应方式可在[模型广场](https://bailian.console.aliyun.com/cn-beijing/model/market)的模型卡片上通过“阿里直供”或“三方直供”标签确认。
-   **统计周期**：每个自然月，如 9 月 1 日 00:00 至 9 月 30 日 24:00。

## 预算维度

支持以下三个维度独立设置预算：

**维度**

**适用范围**

**说明**

账号

整个主账号下全部业务空间和 API Key

设置账号级总预算，汇总该账号下阿里直供模型的按调用量付费费用。

业务空间

单个业务空间

为指定业务空间设置独立预算，仅统计该空间内阿里直供模型的按调用量付费费用。

API Key

单个 API Key

为指定 API Key 设置独立预算，仅统计该 Key 产生的阿里直供模型按调用量付费费用。

## 设置预算与告警

在预算管理页面，点击表格中某条记录的**编辑**，或点击表格上方的**设置预算**按钮，在弹出的**设置预算与告警**面板中配置以下选项：

-   **预算对象**：展示预算对应的维度信息，如主账号（全部业务空间）及账号 ID。
    
-   **月度预算管理**：开启后可设置预算金额。
    
-   **当前预算**：编辑时显示已有的预算额度；首次设置时显示"未设置"。
    
-   **新预算**：输入当月预算上限（单位：元）。
    
-   **达到预算后立即停止**：开启后，当费用达到预算额度时，系统自动限制该维度的按量调用。
    
    **警告****生产环境不建议开启“达到预算后立即停止”**。开启后达到预算额度将自动停止 API 调用，可能导致业务中断。
    
-   **告警阈值**：设置达到预算额度的百分比（如 80%），当费用达到该比例时发送通知。如果设置或调整阈值时，当月累计费用占比已达到或超过该阈值，当月不会发送该阈值的告警，下个自然月重新判断。阈值会根据预算金额自动计算告警金额，如预算 ￥10,000、阈值 80% 时显示"当消费达预算的 80%（￥8,000.00）时发送通知"。可点击[设置通知方式](https://notifications2.console.aliyun.com/subscribeMsg?spm=a2ty07.costing-balance_budget.0.0.342174a1Rwd3sU)配置通知渠道。预算告警通知仅支持基本接收（站内信、短信、邮件）与机器人接收，暂不支持语音接收。
    

## 达到预算后的行为

### 预算预警

当费用达到您设置的告警阈值（如预算额度的 80%）以及预算用尽（100%）时，系统发送通知提醒。

**说明**预算告警通知按通知渠道限制每天的发送条数，单个主账号 UID 每天最多接收：站内信 5 条、邮件 5 条、短信 10 条、Webhook（机器人）10 条。告警阈值和预算用尽的告警共用这些上限，达到上限后当天不再发送后续告警。

### 达预算即停

若开启了**达到预算后立即停止**，当费用达到预算额度时，系统自动限制该维度的按量调用，调用将返回 429 错误。错误信息示例：

> 您在“预算管理”中设置的预算额度已用尽。在提高或重置预算额度前，您将无法继续调用 API。

英文环境下的错误信息：

> The budget configured in Budget Management has been exhausted. You will be unable to make further API calls until the budget limit is increased or reset.

关于该错误的详细说明，请参见[错误码](https://help.aliyun.com/zh/model-studio/error-code#budget-exhausted)。

**说明**开启“达到预算后立即停止”前，请注意以下限制：

-   三方直供模型的费用不计入预算金额。当阿里直供模型的累计费用达到预算额度后，通过 API 直接调用三方直供模型也会被限制。相关说明参见[常见问题](#faq)。
-   **PTU 溢出部分**和通过应用产生的调用暂不支持自动停止。
-   若已达预算阈值触发停机后，又发放了免费额度，停机**不会自动恢复**，需手动调整预算阈值后方可恢复调用。
-   服务停止存在一定延迟，延迟时段内产生的费用仍将正常收取。

## 常见问题

预算管理是否包含模型训练费用？

不包含。预算管理仅统计阿里直供模型的 API 按调用量付费费用，不含模型训练、预置吞吐（PTU）、模型单元（DTU）等费用。

三方直供模型的费用是否计入预算？

三方直供模型是由第三方模型服务商直接提供的模型，与由阿里云提供的阿里直供模型相对。在[模型广场](https://bailian.console.aliyun.com/cn-beijing/model/market)中，模型卡片上带“三方直供”标签的模型即为三方直供模型。三方直供模型的费用不计入预算金额：预算金额仅累计阿里直供模型的 API 按调用量付费费用，仅调用三方直供模型时预算不会累积。开启“达到预算后立即停止”后，阿里直供模型的累计费用达到预算额度时，通过 API 直接调用三方直供模型也会被限制。

达到预算后如何恢复调用？

可通过以下方式恢复：

1.  在[预算管理](https://bailian.console.aliyun.com/cn-beijing/costing-balance/budget)页面提高预算额度。
2.  关闭“达到预算后立即停止”开关。
3.  若因发放免费额度后未自动恢复，需手动调整预算阈值。

为什么达到预算额度后仍在产生费用？

服务停止存在一定延迟，延迟时段内产生的费用仍将正常收取。建议在告警阈值（如 80%）时及时关注并处理，避免超出预算。
