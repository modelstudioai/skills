# 预算管理

为账号、业务空间或 API Key 设置模型推理的月度预算与预警，支持达预算后自动停止按量调用。

## 功能概述

预算管理允许您设置月度模型推理的预算上限与预警，并可在预算用尽后自动限制模型推理服务的按量调用，灵活管控账号、业务空间或 API Key 的费用。

登录[百炼控制台](https://bailian.console.aliyun.com/)，在左侧导航栏选择**费用用量** > [**预算管理**](https://bailian.console.aliyun.com/cn-beijing/costing-balance/budget)，进入预算管理页面。

支持按**账号**、**业务空间**、**API Key** 三个粒度分别设置预算，详见[预算维度](#dimensions)。

## 预算范围与统计周期

-   **预算范围**：仅包含 API 按调用量付费产生的费用，不含模型训练、预置吞吐（PTU）、模型单元（DTU）等费用。
-   **统计周期**：每个自然月，如 9 月 1 日 00:00 至 9 月 30 日 24:00。

## 预算维度

支持以下三个维度独立设置预算：

**维度**

**适用范围**

**说明**

账号

整个主账号下全部业务空间和 API Key

设置账号级总预算，汇总该账号下全部按调用量付费费用。

业务空间

单个业务空间

为指定业务空间设置独立预算，仅统计该空间内的按调用量付费费用。

API Key

单个 API Key

为指定 API Key 设置独立预算，仅统计该 Key 产生的按调用量付费费用。

## 设置预算与告警

在预算管理页面，点击表格中某条记录的**编辑**，或点击表格上方的**设置预算**按钮，在弹出的**设置预算与告警**面板中配置以下选项：

-   **预算对象**：展示预算对应的维度信息，如主账号（全部业务空间）及账号 ID。
    
-   **月度预算管理**：开启后可设置预算金额。
    
-   **当前预算**：编辑时显示已有的预算额度；首次设置时显示"未设置"。
    
-   **新预算**：输入当月预算上限（单位：元）。
    
-   **达到预算后立即停止**：开启后，当费用达到预算额度时，系统自动限制该维度的按量调用。
    
    **警告****生产环境不建议开启「达到预算后立即停止」**。开启后达到预算额度将自动停止 API 调用，可能导致业务中断。
    
-   **告警阈值**：设置达到预算额度的百分比（如 80%），当费用达到该比例时发送通知。阈值会根据预算金额自动计算告警金额，如预算 ￥10,000、阈值 80% 时显示"当消费达预算的 80%（￥8,000.00）时发送通知"。可点击[设置通知方式](https://notifications2.console.aliyun.com/subscribeMsg?spm=a2ty07.costing-balance_budget.0.0.342174a1Rwd3sU)配置通知渠道。
    

## 达到预算后的行为

### 预算预警

当费用达到您设置的告警阈值（如预算额度的 80%）以及预算用尽（100%）时，系统发送通知提醒。

### 达预算即停

若开启了**达到预算后立即停止**，当费用达到预算额度时，系统自动限制该维度的按量调用，调用将返回 429 错误。错误信息示例：

> 您在「预算管理」中设置的预算额度已用尽。在提高或重置预算额度前，您将无法继续调用 API。

英文环境下的错误信息：

> The budget configured in Budget Management has been exhausted. You will be unable to make further API calls until the budget limit is increased or reset.

关于该错误的详细说明，请参见[错误码](https://help.aliyun.com/zh/model-studio/error-code#budget-exhausted)。

**警告**开启「达到预算后立即停止」前请注意以下限制：

-   服务停止存在一定延迟，延迟时段内产生的费仍将正常收取。

## 常见问题

预算管理是否包含模型训练费用？

不包含。预算管理仅统计 API 按调用量付费产生的费用，不含模型训练、预置吞吐（PTU）、模型单元（DTU）等费用。

达到预算后如何恢复调用？

可通过以下方式恢复：

1.  在[预算管理](https://bailian.console.aliyun.com/cn-beijing/costing-balance/budget)页面提高预算额度。
2.  关闭「达到预算后立即停止」开关。

为什么达到预算额度后仍在产生费用？

服务停止存在一定延迟，延迟时段内产生的费仍将正常收取。建议在告警阈值（如 80%）时及时关注并处理，避免超出预算。
