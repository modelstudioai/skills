## 提示词要素写作

wan3.0 一句话即可成片，但描述越完整、精确，成片越贴近预期。全模态场景下推荐使用下面这套**完整提示词公式**，想控制什么就写上，写不到的板块直接跳过。

```
提示词 = [总体描述]
       + [参考素材引用：图 N / 视频 N / 音频 N]
       + [分镜 N（起-止秒）：主体 + 场景 + 运动 + 美学控制]
       + [台词：xx 说："xxxx"]
       + [音效 / BGM]
       + [风格 / 情绪]
       + [负向清单]
```

### 参考素材引用

素材按上传顺序编号，图片、视频、音频分别计数：第 1 张图是图1、第 2 张图是图2，视频、音频同理写视频N、音频N。因此图1与视频1可以同时存在。

-   **在提示词里直接写图N、视频N、音频N来引用对应素材**，编号必须和上传顺序一致，否则会引用错素材。
-   **只有一个素材时**可简写为参考图片、参考视频；两个及以上必须写明编号。
-   **同一素材可多处引用**，形象、动作、音色、场景等不同用途分开各引一次。

### 分镜与时间戳

多镜头视频靠「序号 + 时间戳 + 分镜内容」串成连贯叙事，并在镜头间保持主体、场景、氛围一致。

**提示词 = 总体描述 + 镜头序号 + 时间戳 + 分镜内容**

-   总体描述：一句话交代主题、视角、叙事风格与整体情绪。
-   镜头序号：给每个镜头编号，区分先后。
-   时间戳：紧跟序号标出起止时间；各镜头首尾相接、不跳段不重叠，每段 2–5 秒。
-   分镜内容：描述主体动作、台词、表情、场景细节，写法与单镜头一致；避免写模型控不住的高频动作（如「一秒摇头 3 次」）。

序号与时间戳格式不拘，`[起-止]` 与 `（起-止）` 通用，选一种通篇沿用即可：

写法

示例

序号 + 时间戳

`第1个镜头[0-3秒] xxxx`、`分段1[0-5秒]：xxxx`、`分镜1（00:00-00:03）：xxxx`

只标序号，不标时间

### 台词

台词按「角色 + 说话动词 + 冒号 + 引号内容」书写，例如 `xx说："内容"`、`她低语道："内容"`。

-   多人对话：逐句书写并标明说话人，如 `图1说："xxxx"`；`图2回答："xxxx"`。
-   音色克隆：追加 `音色参考 音频N`，只需写一次即对该角色的全部台词生效。
-   口型对齐：追加 `口型同步` 或 `Lip sync.`。
-   旁白、独白：格式相同，如 `画外音："xxxx"`；`女声吟诵："xxxx"`。
-   不要台词：显式写 `无台词` 或 `No dialogue.`，否则模型会自行决定是否加入台词。

### 音效/BGM

**环境音自动匹配**：只要画面里写清动作、材质、气象(`战旗猎猎`、`鼻息白气`、`积水踩踏`)，模型会自动补齐对应音效。

**指定音效**单独成句，可带时间戳：

```
枪鸣音效 + 狐火粒子特效
色块滑入时'嗖'的 whoosh 声、数字跳动时轻键盘'咔嗒'声
第 8 秒起，女声吟诵："xxxx"
```

**BGM 三档控制：**

-   保守放开：什么都不写，由模型自选。
-   明确指定：`BGM 转入低音区，大提琴以极轻力度缓缓加入`、`史诗交响 + 电子音效混合，节奏与镜头切换同步`。
-   完全不要：`无 bgm，只生成环境音和动作音` 或 `No background music.`。
