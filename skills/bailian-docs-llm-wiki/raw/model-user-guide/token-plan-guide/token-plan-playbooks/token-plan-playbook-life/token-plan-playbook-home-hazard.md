给家里拍张照交给视觉理解模型，连空间关系一起看，三段式排查隐患。

**说明**

**免责声明**：本页展示内容均为 AI 模型生成，仅供参考，不构成任何效果承诺；实际产出效果与 Credits 消耗以控制台「用量详情」为准。

本篇用一张含 5 处隐患的室内演示照跑通居家安全排查：让模型按隐患清单 / 需现场确认 / 一句话提醒三段输出。插排是不是靠着水槽、电线有没有横在走道、暖气片上是不是堆了报纸、通道有没有被纸箱堵住，模型会连空间关系一起看，比照着清单自查更容易发现问题。

调用链：`wan2.7-image`（生成一张含隐患的室内图作占位演示，不使用真实私人照片）→ `qwen3.7-plus`（视觉理解，按隐患清单 / 需现场确认 / 一句话提醒三段输出）。

## 步骤：三段式安全排查

把室内照片连同下面的提示词发给 `qwen3.7-plus`：

```
你是一位居家安全评估员。这是我给爸妈家拍的一张照片，请帮我看看有没有安全隐患。

请按下面结构输出：

一、隐患清单（按危险程度从高到低）
每条给出：
- 隐患是什么、在画面的哪个位置
- 为什么危险（说清可能导致什么后果）
- 危险等级（高 / 中 / 低）
- 具体怎么改（一句话能执行的动作）

二、这张照片里没看清但需要现场确认的
比如被遮挡、光线不足、角度看不到的地方，列出你无法判断但值得去现场查的项。

三、给爸妈的一句话提醒
用他们听得懂的话，说一件最该马上改的事。

要求：只说照片里真实看得见的东西，不确定的明确写"不确定"；不要为了凑数编造隐患。
```

## 说明

-   **消耗**：本玩法涉及图片生成 + 视觉理解，生图与看图是两次独立调用、各自计费。看图这步照片本身转成 image\_tokens 占输入绝大部分，文字提示词占比很小；家里拍多张的话建议一张一张问，一次塞很多图输入会成倍上涨。
-   **边界**：本玩法只做基于照片的隐患提示，不替代专业安全检测。燃气、电路、承重等问题请找持证人员上门检查。它擅长看物体之间的位置关系，比如挨着、横穿、堆在上面，这类「整体不对劲」比照清单逐项自查更容易发现；但「需现场确认」那部分别跳过，那是照片看不到的风险。
-   **隐私**：演示照片由 `wan2.7-image` 生成（右下角带"AI 生成"标识），非真实住宅。用于真实排查时注意照片可能含隐私，自行判断是否上传。
