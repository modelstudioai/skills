把下面的需求发给 `qwen3.8-max`：

```
用一句话需求给我一个可玩的单文件小游戏（纯 HTML+CSS+JS，Canvas 手绘，无外部依赖）：
做一个「贪吃蛇」：方向键/WASD 控制、吃食物加分变长、撞墙或撞自己结束并可重开、
顶部显示得分与最高分(存 localStorage)、配色清爽治愈。只输出完整可运行单文件 HTML。
```
