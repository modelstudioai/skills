## 步骤一：一句话需求

在 Qoder 里把下面的需求发给 `qwen3.7-max`：

```
帮我做一个单文件 HTML 记账本：
支持记录 日期/分类/金额/备注，数据存 localStorage，
顶部显示本月支出总额和分类饼图（不用外部库，Canvas 手绘），
手机浏览器可用，配色清爽治愈系。输出完整可运行的单文件 HTML。
```

## 步骤二：自审修复（Agent 循环关键步）

```
请你以严格代码审查者身份自查上面的代码：找出功能缺陷、边界问题
（如金额非法输入、localStorage 解析失败、饼图无数据时的显示），
修复后输出最终完整单文件 HTML。只输出最终版。
```

## 说明

-   **消耗**：本玩法涉及 2 轮编码循环（出码 → 自审修复），第 2 轮要回读全部代码，所以明显比第 1 轮贵。
