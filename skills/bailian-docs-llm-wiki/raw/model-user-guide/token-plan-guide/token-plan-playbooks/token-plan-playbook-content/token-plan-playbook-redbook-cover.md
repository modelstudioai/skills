本篇以「夏日清凉系家居布置」为主题跑通两步：先让文本模型写出标题、正文与话题标签，再用文生图出一张 3:4 竖版封面，并把标题文字直接渲染进画面。

调用链：`qwen3.7-plus`（标题 + 正文 + 标签）→ `wan2.7-image`（3:4 封面，含标题文字渲染）。

## 步骤一：生成爆款文案

将主题发给 `qwen3.7-plus`，产出标题、正文与话题标签：

```
你是小红书爆款写手，就【夏日清凉系家居布置】写一篇笔记：
1个吸睛标题（≤20字，带emoji），正文200字左右，分3-4段，口语化，
结尾3个话题标签
```

## 步骤二：文生图出封面

把标题与画面描述发给 `wan2.7-image`，尺寸 768\*1024 竖版：

```
小红书封面图，竖版3:4，夏日清凉系家居布置场景：白色亚麻沙发、薄荷绿抱枕、藤编凉席、
玻璃茶几上一杯加冰柠檬水与薄荷叶，窗边白纱帘被微风吹起、阳光洒进来，龟背竹绿植点缀，
画面上方醒目手写风标题文字「夏日清凉系家居」，清爽冷色调，ins风，高级感，留白构图
```

查看步骤一的文案原始输出（qwen3.7-plus）

## 说明

-   **消耗**：本玩法涉及文案生成（`qwen3.7-plus`）与封面图生成（`wan2.7-image`，768\*1024 竖版，含标题文字渲染）两部分。
-   **文字渲染**：把标题写进画面提示词，可让封面直接带上文字，省去后期加字。
