## 说明

-   消耗：本玩法涉及文本生成（qwen3.8-flash，开启思考）。输入是几封邮件的原文、输出是一张表格，单次消耗不高。

-   注意：本次指令只要求四列表格，产出就是纯表格；要「表格 + 总结 + 下周计划」需在指令里明写。
-   数据边界：示例邮件中的人名、项目与进度均为演示用虚构数据。真实汇报进上下文意味着内容会发送到服务端，涉及未公开项目信息时请先脱敏。
