## 步骤：一题变交互网页

把题目连同下面的指令发给 `qwen3.8-max`：

```
你是一位耐心的初中数学老师。把这道题做成单文件交互式讲解网页（纯 HTML+CSS+JS）：
「长方形花园，长比宽多 4 米，周长 28 米，求长宽与面积」。
要求：分步讲解默认折叠、点击逐步展开；拖动滑块猜测宽度实时校验、命中答案高亮祝贺；
底部给标准答案与面积。只输出完整可运行的单文件 HTML。
```
