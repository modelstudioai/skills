# qwen4-max（最新模型）

Qwen4-Max 是通义千问新一代旗舰多模态模型，融合文本生成、图片与视频理解及深度思考能力，适用于编程开发、办公、前端设计与复杂智能体任务。模型支持联网搜索、工具调用和结构化输出，兼容 OpenAI 与 Anthropic API，帮助开发者构建具备多模态理解与任务执行能力的智能应用

模型调用 ID（`model` 参数取值）：`qwen4-max`

> **说明**
>
> qwen4-max-preview 已下线，原模型 ID 的请求自动路由至 qwen4-max，并按 qwen4-max 标准价格计费；预览期的限时折扣不再适用。

## 使用说明

<a id="显式缓存"></a>

### 显式缓存

复用系统提示词、工具说明和参考文档等公共输入前缀，降低重复输入的成本。支持 OpenAI Chat Completions、Responses 和 Anthropic Messages，TTL 支持 `5m` 和 `1h`。配置与计费见 [显式缓存](../model-experience/text-generation-model/explicit-cache-qwen4.md)。

### 思维链摘要与加密
