# glm-5.3

GLM-5.3 是智谱旗舰大语言模型，编程与智能体能力全面进阶，内部编程基准较上代提升 50%，可端到端交付生产级成果。涌现网络安全能力，在漏洞发现基准 CyberGym 上展现漏洞发现能力。支持 1M 上下文、128K 输出与三档深度思考，胜任长程复杂任务。

<a id="推理服务供应商"></a>

## 推理服务供应商

`glm-5.3`模型的推理服务供应商为阿里云百炼。
