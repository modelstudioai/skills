# deepseek-v4.1-flash

DeepSeek-V4.1-Flash 是 DeepSeek 全新架构系列中的轻量旗舰模型，以 552B 总参数 MoE 实现越级智能，在多项基准上超越包括 DeepSeek-V4-Pro 在内的主流旗舰模型。采用 Causal Encoder-Decoder 非对称架构，输入激活仅 8B、输出激活 16B，并具备原生多模态视觉理解能力。KV Cache 压缩至上一代 HBM 的 1/4、SSD 的 1/8，显著降低长上下文与 Agent 任务成本。支持 1M 上下文与 384K 最大输出，兼顾高吞吐、低延迟与极致性价比。

### `deepseek-v4.1-flash-1017`

DeepSeek-V4.1-Flash-1017 是 V4.1-Flash 的最新迭代版本，通过基于自反馈的强化学习（RL）训练，在 Terminal-Bench 4.0、DeepSWE v1.1、ProgramBench 等多项基准上较上版显著提升，同时缩短任务运行时间与输出长度，在多个 Harness 下达到新的性能–费用帕累托最优。模型从零构建完整项目的能力进一步增强，可支持游戏开发、3D 建模等“许愿式”编程任务，延续上一版的 552B 总参数 MoE、原生多模态视觉理解、1M 上下文与 384K 最大输出。
