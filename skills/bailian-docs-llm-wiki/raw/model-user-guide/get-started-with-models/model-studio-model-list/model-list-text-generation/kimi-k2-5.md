# kimi-k2.5

kimi-k2.5是月之暗面模型，原生多模态架构设计，同时支持视觉与文本输入、思考与非思考模式、对话与Agent任务。

<a id="推理服务供应商"></a>

<a id="h-490b2834e6"></a>

## 推理服务供应商

`kimi-k2.5`模型的推理服务供应商为阿里云百炼。

<a id="模型能力"></a>

<a id="h-77230e94b5"></a>

## 模型能力

| 能力项 | 支持情况 | 能力项 | 支持情况 |
| --- | --- | --- | --- |
| 输入模态 | **Text** **Image** **Video** | 输出模态 | **Text** |
| 模型体验 | 支持 | Function Calling | 支持 |
| 结构化输出 | 不支持 | 联网搜索 | 不支持 |
| 前缀续写 | 不支持 | 上下文缓存 | 支持 |
| 批量推理 | 不支持 | 模型调优 | 不支持 |
