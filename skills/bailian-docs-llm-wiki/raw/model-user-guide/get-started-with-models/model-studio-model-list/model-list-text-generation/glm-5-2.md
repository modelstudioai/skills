# glm-5.2

GLM-5.2是智谱AI推出的面向长程任务（Long Horizon Task）设计的旗舰模型，支持1M超长上下文。拥有强大逻辑推理、长文本理解与代码生成能力、兼顾性能与推理效率；在多任务基准中表现优异，适用于智能交互、企业应用、开发辅助等场景。
