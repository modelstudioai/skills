# pixverse/pixverse-c1-kf2v

C1是PixVerse在26年3月底推出的影视行业大模型，kf2v（首尾帧生成视频）模型可将任意两张图片衔接，视频转场更加流畅自然，支持15秒长视频、音乐和视频直出、支持多种语言文字。

<a id="推理服务供应商"></a>

<a id="h-490b2834e6"></a>

## 推理服务供应商

`pixverse/pixverse-c1-kf2v`模型的推理服务供应商为PixVerse。
