# pixverse/pixverse-v6-max-it2v

V6-max是PixVerse推出的视频生成模型，it2v（图片生成视频）模型可根据输入图片和提示词生成视频，支持15秒长视频、有声视频以及360P～1080P多种分辨率。

## 推理服务供应商

`pixverse/pixverse-v6-max-it2v`模型的推理服务供应商为PixVerse。
