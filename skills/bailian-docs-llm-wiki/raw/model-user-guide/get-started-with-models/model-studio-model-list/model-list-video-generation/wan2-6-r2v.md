# wan2.6-r2v

万相2.6-参考生视频，支持指定人物或任意物品进行参考，精准保持形象和声音的一致性，支持多角色参考合拍。提醒：当使用视频进行参考时，输入视频也会计入费用，详见模型计费文档。

<a id="推理服务供应商"></a>

<a id="h-490b2834e6"></a>

## 推理服务供应商

`wan2.6-r2v`模型的推理服务供应商为阿里云百炼。

## 模型价格

本文仅展示模型调用原价，不包含限时优惠等活动信息，请前往[百炼控制台](https://bailian.console.aliyun.com/cn-beijing/model/market)查看活动优惠。

计费规则：输入视频和输出视频均按**秒数**计费，价格由输出视频的分辨率决定。计费时长 = 输入视频时长（上限 5 秒）+ 输出视频时长。
