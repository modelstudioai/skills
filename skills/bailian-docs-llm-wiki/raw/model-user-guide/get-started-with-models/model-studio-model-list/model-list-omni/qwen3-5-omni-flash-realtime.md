# qwen3.5-omni-flash-realtime

Qwen3.5-Omni是Qwen全模态大模型，支持文本，图片，音频，音视频理解与交互。作为 Qwen3-Omni 的全面进化版本，支持60+种语言音频输入，30+语言语音输出以及可控语音对话，WebSearch和复杂FunctionCall的调用，并且具备智能语义打断的交互能力，广泛应用于文本创作、语音助手、多媒体分析等场景，提供自然流畅的多模态交互体验。该模型版本功能等同于快照模型 qwen3.5-omni-flash-realtime-2026-03-15。
