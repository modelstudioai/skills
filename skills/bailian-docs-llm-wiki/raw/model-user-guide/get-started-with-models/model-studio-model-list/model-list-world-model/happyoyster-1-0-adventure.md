# happyoyster-1.0-adventure

HappyOyster Adventure 是实时交互、可探索互动的开放式世界模型。基于多模态（文本/图像）输入即可生成的世界场景，通过实时交互、位移和镜头控制进行沉浸式无边探索。

## 推理服务供应商

`happyoyster-1.0-adventure`模型的推理服务供应商为阿里云百炼。
