# happyoyster-1.0-acting

HappyOyster Acting 是实时交互的角色演绎模型。基于多模态（文本/图像）输入生成指定人设风格的角色和场景，在任意时刻通过文本驱动角色实时演绎互动。

**重要**该模型目前处于邀测阶段。

## 推理服务供应商

`happyoyster-1.0-acting`模型的推理服务供应商为阿里云百炼。
