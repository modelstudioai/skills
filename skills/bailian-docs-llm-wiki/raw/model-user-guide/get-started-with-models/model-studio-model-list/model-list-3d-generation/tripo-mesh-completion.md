# Tripo/Tripo-MeshCompletion

Tripo网格补全支持对拆分后的模型部件进行 AI 自动补齐，保证拆分后部件的完整性，提升后续 3D 打印、游戏资产、动画等工作流的处理效率。

<a id="推理服务供应商"></a>

<a id="h-490b2834e6"></a>

## 推理服务供应商

`Tripo/Tripo-MeshCompletion`模型的推理服务供应商为Tripo。

<a id="模型能力"></a>

<a id="h-77230e94b5"></a>

## 模型能力

| 能力项 | 支持情况 | 能力项 | 支持情况 |
| --- | --- | --- | --- |
| 输入模态 | **3D Model** | 输出模态 | **3D-Generation** |
| 模型体验 | 不支持 | Function Calling | 不支持 |
| 结构化输出 | 不支持 | 联网搜索 | 不支持 |
| 前缀续写 | 不支持 | 上下文缓存 | 不支持 |
| 批量推理 | 不支持 | 模型调优 | 不支持 |
