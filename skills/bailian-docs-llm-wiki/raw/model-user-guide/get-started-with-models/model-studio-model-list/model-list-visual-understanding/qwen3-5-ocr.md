# qwen3.5-ocr

Qwen3.5系列OCR模型，在文档解析、文本定位、关键信息提取等方面全面升级，在真实场景的业务卡证（如国内国际身份证、驾驶证等业务场景中）抽取上效果显著提升。

<a id="推理服务供应商"></a>

<a id="h-490b2834e6"></a>

## 推理服务供应商

`qwen3.5-ocr`模型的推理服务供应商为阿里云百炼。
