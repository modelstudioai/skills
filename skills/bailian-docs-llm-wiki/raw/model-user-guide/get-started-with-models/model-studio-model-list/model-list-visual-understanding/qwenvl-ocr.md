# qwen-vl-ocr

千问VL-OCR（qwen-vl-ocr），即基于Qwen-VL训练的OCR识别大模型。通过统一模型的方式聚合多种图文识别、解析、处理类任务，提供强大的图文识别能力。该模型版本功能等同于快照模型 qwen-vl-ocr-2025-11-20。

## 推理服务供应商

`qwen-vl-ocr`模型的推理服务供应商为阿里云百炼。
