# qwen-image-2.1-pro

Qwen-Image-2.1-Pro 是通义千问（Qwen）系列中一个统一的文本到图像生成与图像编辑模型。其视觉生成组件仅包含 70 亿参数（32 层单流 DiT），在生成质量、推理效率和多功能性之间取得了良好平衡。本次发布包含四项关键改进：紧凑高效：采用轻量级架构，结合混合粒度注意力机制和前缀 KV 缓存复用，在低计算开销下实现高质量图像生成。原生透明支持，统一生成与编辑：可从文本生成普通或透明（RGBA）图像，编辑透明图层，并从照片中提取主体——全部由单一模型完成。多功能编辑：支持最多 10 张参考图像，可通过圆形、手绘标注或独立蒙版指定局部编辑区域，并保留人物与产品的身份特征。逼真纹理与精细美学：改进字体排印、人像光照和细节表现，生成更具视觉吸引力的结果。
