# qwen-image-3.0

指令理解清晰：支持最大 4.5k token 输入，复杂图文指令一次生成到位。 文字渲染稳定：10px 小字、12 国语言、多种字体原生渲染，信息图和界面直接可用。 批量产出趁手：海报、网页、界面等日常任务可批量生成，成本更优，适合持续创作。 Qwen-Image-3.0 不只在追求生成效果，更在追求日常创作里的顺手与省心——让图像生成成为可持续的内容生产力。
