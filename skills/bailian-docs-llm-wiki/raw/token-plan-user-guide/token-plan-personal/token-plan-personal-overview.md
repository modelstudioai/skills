## 订阅管理

### 升级

支持从低档位升级到更高档位。套餐升级不重置当前订阅周期：按当前订阅周期剩余天数补缴差价，当前周期仅按额度差折算发放新增 Credits，自下一个订阅月起按新档位月额度计量。

补差金额、新增额度的折算公式和示例见[用量与额度·升级额度计算](https://help.aliyun.com/zh/model-studio/token-plan-usage-quota#tpuq-h-upgrade)。

升级后 Harness 权益的剩余额度计算详见[Harness 权益·升级后权益计算](https://help.aliyun.com/zh/model-studio/token-plan-harness-benefits#tphb-h-upgrade)。

### 续费

个人版支持包月、包季、包年订阅；续费支持切换续费周期，也可一次续费多个周期。

-   **手动续费**：支持选择不同续费时长，可续费多个周期。
-   **自动续费**：开启后到期前系统自动扣款续费。

续费不增加当前订阅周期的额度，规则见[用量与额度·额度规则](https://help.aliyun.com/zh/model-studio/token-plan-usage-quota#tpuq-h-reset)。

### 其他

-   个人版暂不支持退订。
-   个人版不支持降配，如需更换为更低档位，可在订阅到期后重新购买。
-   订阅到期后 API Key 变为不可用；重新购买成功后，原 API Key 恢复可用，无需在工具中重新配置。
