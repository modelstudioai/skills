# 业务流程

本文为您介绍通义听悟-购车客户画像 Agent 的业务流程案例。

## 业务流程

**① 采集录音：**通过电话外呼系统、智能工牌、工作手机、车载拾音设备等采集销售服务过程录音文件。

![21](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3979894571/p996402.webp)

![22](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3979894571/p996403.webp)

![23](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3979894571/p996404.webp)

![24](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3979894571/p996405.webp)

**② 录音管理：**明确录音文件对应的购车客户信息，将录音数据进行统一管理，便于后续API接入时的数据上传。

![25](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3979894571/p996407.webp)

![26](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3979894571/p996409.webp)

**③ 录音上传分析：**开通并接入通义听悟-购车客户画像 Agent 的API，上传录音进行客户画像与需求分析，您可在控制台页面进行在线调试并体验分析效果，配置完毕后将自动更新控制台**API接入**页面的参考代码。

![31](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3979894571/p996411.webp)

![32](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3979894571/p996412.webp)

**④ 结果呈现：**基于通义听悟-购车客户画像 Agent 的API返回的数据，在您的客户管理系统中呈现商机评级、线索评分、购车意向等多维度的数据分析结果。
