# 2025年1月24日更新

2025年1月24日泛企业线索挖掘功能更新公告。

**说明**体验地址：[泛企业线索挖掘产品控制台](https://bailian.console.aliyun.com/?spm=5176.29619931.J__Z58Z6CX7MY__Ll8p1ZOR.1.74cd59fcHNZmnE#/app/app-market/quanmiao/voc)。

### 1\. 新增消费者行为分析场景和企业合作信息挖掘场景示例

功能说明：新增“家具购买的消费者行为分析场景”和“企业合作信息挖掘场景”场景示例。

在百炼平台**效果调试**页面的场景Tab中可切换至新增场景。该场景支持上传对话素材、选择模型（如**通义千问-Max**）、设置内容标签（如客户信息、家庭状况、兴趣爱好、购物时间限制等），单击**开始挖掘**后自动输出客户画像分析结果（包括空间布局、售后期望、沟通风格、环保偏好、功能需求等标签）。

### 2\. 新增批量添加内容标签功能

功能说明：支持用户批量添加内容标签，便于用户操作。

在**设置内容标签**步骤中，**线索标签定义**区域以表格形式列出各标签名称及含义取值，包括客户信息、家庭状况、兴趣爱好、购物时间限制、购物经历、空间布局等类别。单击右上方**批量输入**即可批量添加内容标签。

在**全部线索标签**弹窗中，左侧展示已有标签列表（包含标签名称和标签含义与取值），右侧为批量粘贴输入区域，支持一键粘贴所有标签名、标签值和解释并自动识别。每行为一组标签，每组标签内用2个空格隔开标签名、标签值和标签含义。分隔符支持**制表符Tab**（适用于Excel）、**@@@**或**自定义**。粘贴后单击**识别结果并在左侧预览**按钮进行预览，确认后单击**确认**按钮完成批量添加。

### 3\. 优化线索挖掘生成的格式

功能说明：优化线索挖掘输出结果的格式，用户复制生成结果即可复用到 Excel表中。

优化后的挖掘结果以每行一条 **标签名: 值** 的格式输出（如 `客户信息: 女性`、`客户的家庭状况: 有女儿`、`客户家里的空间布局: 碧桂园1栋801` 等），整体为结构化文本，可直接复制粘贴到 Excel 单元格中。

### 4\. 增加批处理接口

功能说明：输入待挖掘文件或多段文本，后台会创建一个任务，并使用任务ID轮询任务的状态、直到任务结束后，返回结果。

在应用页面顶部选择**API**页签，然后选择**批处理API**，下方代码区域将展示对应的 Java SDK 调用代码示例（包含 Maven 依赖配置及调用方法），可切换**Java**或**Python**语言，并单击代码区右上角的复制按钮获取代码。
