# vidu/vidu-image-pro_reference2image

输入0-14张参考图片或文本描述，支持参考生图、文生图、图片编辑，对中英文字的精准渲染、UI/图表等设计细节的像素级还原，适合制作海报、信息图等。

## 推理服务供应商

`vidu/vidu-image-pro_reference2image`模型的推理服务供应商为Vidu。
