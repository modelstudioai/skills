# qwen3.7-text-rerank

基于Qwen3.7底座训练的多语言通用文本重排序模型。相较qwen3-rerank，在通用与Web检索、代码检索、指令遵循、Agentic与Memory检索等方面大幅提升；在MTEB、websearch等评测任务上均取得更优效果，其中websearch相对提升约35%。

<a id="推理服务供应商"></a>

<a id="h-490b2834e6"></a>

## 推理服务供应商

`qwen3.7-text-rerank`模型的推理服务供应商为阿里云百炼。
