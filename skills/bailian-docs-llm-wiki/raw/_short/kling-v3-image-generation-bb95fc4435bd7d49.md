# kling/kling-v3-image-generation

支持最多10张参考图，可锁定主体、元素和色调，保证风格一致。融合风格转绘、人像/角色参考、多图融合及局部重绘，操作灵活。人像细节真实，整体画面细腻丰富，色彩氛围兼具影视感。
