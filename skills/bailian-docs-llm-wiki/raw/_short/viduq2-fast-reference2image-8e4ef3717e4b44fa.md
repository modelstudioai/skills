# vidu/viduq2-fast_reference2image

输入0-14张参考图片或文本描述，支持参考生图、文生图、图片编辑，语义理解能力大幅提升，支持更多风格。

<a id="推理服务供应商"></a>

<a id="h-490b2834e6"></a>

## 推理服务供应商

`vidu/viduq2-fast_reference2image`模型的推理服务供应商为Vidu。
