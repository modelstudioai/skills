# 合同体检 · 挑出对我不利的条款

让模型把关联条款串起来看，挑出对己方不利的组合型风险。

**说明**

**免责声明**：本页展示内容均为 AI 模型生成，仅供参考，不构成任何效果承诺；实际产出效果与 Credits 消耗以控制台「用量详情」为准。

签合同前想让 AI 先过一遍，揪出对自己不利的地方。真正的坑很少是单独一条写得多离谱——而是每一条单看都正常，几条组合起来才成立：定义、正文、附件互相引用，绕一圈把你架空。所以关键是让它把关联条款串起来看。

调用链：`qwen3.8-max`（长文本 + 深度思考）· 一份 SaaS 采购合同（约 6,800 字，11 条正文 + 4 个附件、含定义条款与交叉引用）· 让它站在甲方立场，把对我不利的条款逐条挑出来、指明关联条款、并给出可直接谈的改法。

产出一句：**只要乙方发《上线通知》，甲方在验收前就已付 90% 款项——建议付款改 10/30/30/30、验收前累计不超 70%**——展开看评审意见原文与改法。

## 步骤：逼它找组合型问题

把合同全文连同下面的指令发给 `qwen3.8-max`：

```
我是甲方（采购方）的法务助理，下面这份 SaaS 采购合同是乙方拟的稿子，我要在评审会上提修改意见。请做一次彻底的体检。
一、对我方不利的条款清单（按风险从高到低），每一条必须包含：
1. 涉及的条款编号（可能不止一条——很多风险是几条条款组合起来才成立的，务必把关联条款一起指出来）
2. 这几条组合在一起会产生什么实际后果（讲清楚乙方可以怎么利用它）
3. 风险等级：高／中／低
4. 我方应该怎么改（给出可以直接拿去谈的具体表述，不要只说"建议修改"）
二、合同里缺失、但应该有的条款
三、注意附件（尤其附件与主合同之间是否存在冲突或架空关系）
四、评审会上先提哪三条，为什么
要求：引用条款编号必须与原文一致；不要编造法律条文或司法解释，要引用法律只在确定时引用，
否则从商业合理性角度论述；不确定的地方明确写"不确定"；只说真实存在的问题，不要凑数。
合同全文：【粘贴合同 + 附件】
```

查看实测产出 · 评审意见原文节选（qwen3.8-max）

```
## 1. 上线、验收、付款节点组合后，甲方可能未验收即付大部分款项并丧失异议权

涉及条款编号： 1.3、1.4、3.4、3.5、3.6、4.3（b）、4.3（c）

组合后果：
- 1.3 把「上线」定义为乙方"向甲方发送《上线通知》之日"，不要求甲方确认系统真正
  具备上线条件；
- 4.3 约定上线付 60%、签约已付 30% —— 只要乙方发出上线通知，甲方在尚未验收前
  就可能已支付合同总额的 90%；
- 3.4 又约定甲方五个工作日内未提书面异议即视为验收合格；
- 3.6 进一步约定验收前实际投入使用也视为验收合格；
- 结果：即使系统仍有缺陷，甲方也已付掉大部分款项，只剩 10% 尾款牵制，谈判空间
  大幅削弱。

风险等级： 高

我方应该怎么改（可直接拿去谈）：
> 1.3 改为：「上线」指乙方完成部署，经甲方书面确认具备上线条件、并由双方签署
>   《上线确认书》之日；乙方单方发送《上线通知》不构成上线。
> 3.4 改为：甲方应在收到完整交付物与验收申请后十五个工作日内验收并书面反馈；
>   未反馈的，乙方应书面催告，甲方在催告后十个工作日内仍未反馈方视为验收合格。
> 4.3 付款改为 10/30/30/30：签约 10%、上线确认后 30%、验收合格后 30%、
>   质保期满后 30%（验收前累计付款不超过 70%，保留 10-20% 尾款）。

—— 以上为第 1 条，报告共列出 18 条这样的条款分析 + 7 条缺失条款 + "评审会先提哪三条"。

【它还做对的两件事】
· SLA 那条它主动折算成钱："5% 补偿按年费 48 万算 ≈ 每月 2000 元，且是唯一救济" ——
  一句话点破 SLA 形同虚设
· 附件四那条它揪出：附件自称"与主合同不一致以本协议为准"，却放开了数据转委托 ——
  用一个附件把主合同的数据保护绕过去了
```

## 说明

-   **消耗**：本玩法涉及长文本 + 深度思考（`qwen3.8-max`，流式），6,800 字合同进上下文，产出约 2 万字评审报告。合同类任务思考量很大（它要反复交叉比对条款间关系），耗时明显长于普通问答；输入含完整合同文本，商业合同请注意其中的敏感信息。
-   **边界（必读）**：AI 合同体检不构成法律意见，不能替代律师。它擅长的是"把对你不利的地方系统列出来、把条款间的勾连挑明"，适合谈判前的自查与准备；是否签、怎么定性，仍需专业律师判断。
-   **虚构素材**：本次素材为虚构合同（文件内已标注"测试用虚构样本"），非真实合同。用它审真实合同时，注意合同文本会发送到服务端，涉密商业合同请谨慎。
-   **提示词要点**：提示词里"不要编造法律条文，不确定就说不确定"这句务必保留——这是把法律幻觉摁住的关键，实测它确实做到了。
