# paraformer-8k-v2

Paraformer中文语音识别模型，模型结构升级，具有更好的识别效果,支持8kHz电话语音识别，仅支持中文热词。

<a id="推理服务供应商"></a>

<a id="h-490b2834e6"></a>

## 推理服务供应商

`paraformer-8k-v2`模型的推理服务供应商为阿里云百炼。
