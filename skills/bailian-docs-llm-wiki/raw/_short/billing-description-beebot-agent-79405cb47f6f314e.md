# 计费说明（客服对话Agent）

下面文档是关于客服对话Agent的计费规则和内容。

<a id="1-计费规则"></a>

<a id="a98679a521t2m"></a>

## 1\. 计费规则

-   超出免费调用额度部分**按照实际调用次数进行计费**。如果仅开通服务，不会产生费用，费用发生以实际调用为准。
-   用户发起一次提问算一次调用。

<a id="2-计费内容"></a>

<a id="8d90125e36ajn"></a>

## 2\. 计费内容

-   客服对话Agent为每个阿里云UID账号**提供1000次免费调用体验机会**，免费调用使用完以后根据实际调用次数后付费。

| 模型 | 单次调用价格 |
| --- | --- |
| 伶鹊对话大模型 | 0.015元/次调用 |
