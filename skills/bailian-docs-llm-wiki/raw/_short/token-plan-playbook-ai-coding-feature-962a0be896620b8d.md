## 步骤：一句话加功能

在 Qoder 里把现有代码连同下面的指令发给 `qwen3.7-max`：

```
这是我现有的 CRM 系统代码（见下方）。请在不改动现有功能（搜索、状态筛选）
的前提下，新增「客户跟进提醒」功能：
1. 超过 7 天未跟进的客户整行标红置顶（已成交、已流失客户不参与提醒）；
2. 页面顶部显示统计条「待跟进提醒：N 位客户超过 7 天未跟进」；
3. 新增「距上次跟进」列，显示天数并对提醒客户标红加粗；
保持现有代码风格，输出完整修改后的文件。
【现有代码】{粘贴文件内容}
```

## 说明

-   **消耗**：本玩法涉及单轮增量开发（Qoder 工具内，需读入现有代码全文）。存量开发的消耗与代码库大小正相关——现有代码要进上下文，代码越大单轮输入越高。
-   **一致性**：功能一次通过，超期置顶标红、成交与流失客户正确排除、恰好 7 天不误报。
