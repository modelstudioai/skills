# 电影级空镜短片 · 一条提示词出 30 秒 1080P 素材

输入一句场景创意，wan3.0-video 一次生成 30 秒、1080P、16:9 的电影级空镜，运镜、光影与配乐原生同步生成。

宣传片、发布会开场需要高质感空镜，却没有航拍与实拍条件。输入一句场景创意，让 `wan3.0-video` 一次生成 30 秒、1080P 的电影级长镜头，运镜、光影推移、配乐与环境音都由模型原生产出，不用后期剪辑合成。本篇以「仙山云海」为例，方法同样适用于山河、城市、季节质感与品牌氛围开场。

## 步骤：一句创意到 30 秒成片

两点通用设置：全部视频命令加 `--watermark false` 关闭 CLI 叠加角标（模型仍原生保留右下角「AI 生成」标识，避免双重水印）；30 秒 1080P 长片的生成时长在十分钟量级，用 `--async` 先取 task\_id，再手动轮询，避免客户端轮询超时。

设置 Token Plan 的 Base URL 和 API Key：

```
export BASE_URL="https://token-plan.cn-beijing.maas.aliyuncs.com"
export API_KEY="sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

### ①（可选）把主题创意扩写成电影感提示词

```
# 按「场景与光线 → 主体与事件 → 镜头运动 → 收尾画面 → 风格质感 → 负面约束」的顺序扩写成一段连续文字，直接用于文生视频。
# 把 message 中的主题替换为自己的题材（山河航拍、城市天际线、季节质感、品牌氛围开场等），结构不变。
bl text chat --api-key "$API_KEY" --base-url "$BASE_URL" --model qwen3.8-flash --message \
  "我在用文生视频模型 wan3.0-video 生成一条 30 秒、1080P、16:9 的国风仙侠电影级短片，主题是「云海赴宴，仙山入画」：仙山云海之上有一座仙宫正在设宴，镜头最终拉远升高，收束于楼阁隐入群峰的云海朝阳远景。请把它扩写成一段可直接用于文生视频模型的中文提示词：按「场景与光线 → 主体与事件 → 镜头运动（推进/穿过云层/拉远升高）→ 收尾画面 → 风格与质感关键词 → 负面约束（无对白、无字幕、无人物特写）」的顺序写成一段连续文字，不要分点，150-250 字。"
```

### ② 一次生成 30 秒 1080P 成片

```
# 纯文本输入（不传 --image 即为文生视频）；--duration 30 为单次生成上限，--resolution 1080P，--ratio 16:9。
# 场景描述替换为自己的题材，保留同一条提示词内的运镜时序与末尾负面约束。
# --async 先取 task_id：30 秒长片生成约十分钟量级，默认同步等待会触发客户端轮询超时。
bl video generate --api-key "$API_KEY" --base-url "$BASE_URL" --model wan3.0-video \
  --prompt "国风仙山云海电影级空镜长镜头：清晨，层层叠叠的青黑色山峰从翻涌的云海中升起，金色晨曦穿透薄雾洒在山巅，一群仙鹤低飞掠过云浪，崖边古松挂满云雾、随山风轻轻摇动；镜头自高空缓慢向前推进，穿过云层，可见最高峰顶一座白玉栏杆环绕的仙宫楼阁，楼阁门楣洁净、不悬挂匾额与题字，阁前长案宴席铺陈、玉盏微微发光，紫金色云气在席位间环绕流动，花瓣随风飘落案上；随后镜头缓缓拉远升高，楼阁隐入群峰之间，云海、群峰与初升的朝阳在眼前铺展为辽阔的青绿山水远景，画面在光影流动中缓缓定格。整体为东方仙侠美学、35 毫米胶片质感、超高细节、体积光与丁达尔效应、云海自然流动、史诗级运镜，无对白、无字幕、无人物特写，画面中不出现任何可辨识文字、书法、题识、落款、印章与匾额题字，无任何画框、边框、卷轴与挂轴元素。" \
  --resolution 1080P --duration 30 --ratio 16:9 --watermark false --async --output json

# 返回 {"task_id": "<任务ID>"}，轮询直到 SUCCEEDED：
curl -s -H "Authorization: Bearer $API_KEY" "$BASE_URL/api/v1/tasks/<任务ID>"

# SUCCEEDED 后从返回的 output.video_url 下载成片（链接有效期 24 小时，及时落盘）：
curl -s -L "<output.video_url>" -o xianshan_30s.mp4
```

## 说明

-   **按一条 30 秒整片设计叙事**：30 秒是 `wan3.0-video` 的单次生成上限。更长的成片需要多次生成再拼接，而每次生成会自动配上不同的配乐与环境音，跨调用的配乐与画面风格不保证一致，拼接处音画会突变。
-   **空镜要显式约束「无对白」**：提示词末尾没有写「无对白、无字幕、无人物特写」时，模型可能自行生成人声或字幕。需要画外音时，把台词直接写进提示词，由模型原生生成人声与口型。
-   **合规边界**：演示中的仙山、云海、仙宫宴席均为模型生成的虚构画面，不含真实人物肖像、真实地标与第三方商标。`--watermark false` 只关闭 CLI 叠加角标，成片右下角「AI 生成」为模型原生合规标识，不要去除。
