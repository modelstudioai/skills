# 睡前故事配音

语音合成模型把童话文本念成温柔人声，输出睡前故事音频。

**说明**

**免责声明**：本页展示内容均为 AI 模型生成，仅供参考，不构成任何效果承诺；实际产出效果与 Credits 消耗以控制台「用量详情」为准。

给故事、文案、群日报配上自然人声。与「儿童趣味动物视频生成」联动：同一段童话文本，视频与配音一次备齐，也可为小红书笔记、日报长图生成口播音频。本篇把一段狐獴童话文本念成一段睡前故事音频。这段文本可直接复用其他玩法的产出：配上视频就是动画样片，配上语音就是睡前故事，一份文本两用。

调用链：`qwen-audio-3.0-tts-plus`（语音合成，经工具 Skill / 扩展机制接入）。

## 步骤：合成语音

将下面的指令发给已接入语音合成模型的工具：

```
把下面这段童话故事合成为睡前故事音频：温柔亲切、语速稍慢，
像妈妈在床边给孩子讲故事。输出 mp3。
【故事文本】小狐獴米米捡到一颗发光种子。它把种子埋进沙里，每天唱歌。
不久，长出一朵小太阳花。米米抱着花，和朋友们在阳光下开心跳舞，真温暖！
```

## 说明

-   **消耗**：本玩法涉及语音合成（`qwen-audio-3.0-tts-plus`）。语音合成按字符数计量，与文本模型的 tokens 口径不同，Credits 换算以控制台「用量详情」为准。
-   **音色**：`qwen-audio-3.0-tts-plus` 没有内置系统音色，需先用音色克隆或音色设计接口创建音色 ID 再传入；若想直接用系统音色，可改用 `cosyvoice-v3-flash`（如音色 `longanyang`）。
