# 业务流程

本文为您介绍通义听悟-汽车销售服务洞察 Agent 的业务流程案例。

## 业务流程

**① 采集录音：**通过电话外呼系统、智能工牌、工作手机、车载拾音设备等采集销售服务过程录音文件。

![21](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5779894571/p996392.webp)

![22](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5779894571/p996393.webp)

![23](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5779894571/p996394.webp)

![24](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5779894571/p996395.webp)

**② 录音管理：**明确录音文件对应的销售人员信息，将录音数据进行统一管理，便于后续 API 接入时的数据上传。

![25](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5779894571/p996396.webp)

![26](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5779894571/p996398.webp)

**③ 录音上传分析：**开通并接入通义听悟-汽车销售服务洞察 Agent 的 API，上传录音进行服务质量评估，您可在控制台页面进行在线调试并体验分析效果，配置完毕后将自动更新控制台**API接入**页面的参考代码。

![27](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5779894571/p996399.webp)

![28](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5779894571/p996400.webp)

**④ 结果呈现：**基于通义听悟-汽车销售服务洞察 Agent 的 API 返回的数据，在您的销售管理系统中呈现单次服务洞察分析、销售人员服务情况、门店业务信息等多维度的数据分析结果。
