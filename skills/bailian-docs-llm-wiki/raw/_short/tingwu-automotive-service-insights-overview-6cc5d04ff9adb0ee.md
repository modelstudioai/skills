# 产品概述

本文介绍通义听悟-汽车销售服务洞察 Agent 的核心功能、产品优势、应用场景及计费规则。

## 产品简介

通义听悟汽车销售洞察 Agent 运用人工智能技术提升汽车销售与服务效率。

采用汽车行业专用语音识别（ASR）和微调模型（SFT），分析全流程场景：电话邀约、门店接待、试乘试驾、售后服务，对话内容涵盖服务流程、业务要求、竞品应对等，帮助企业优化服务流程并挖掘商机。

支持电话、手机、智能工牌及车载设备等录音输入，通过多语言识别与分析，助力企业实现精细管理和精准营销，提升业务增长与客户满意度。

## 产品优势

**全面覆盖汽车销售环节**

-   采用汽车行业专用智能语音识别与数据分析技术，自动捕捉关键销售行为与服务细节，评估销售顾问表现。
-   覆盖电话邀约、门店接待至试乘试驾全流程，确保各触点服务质量，帮助企业建立标准化销售流程。

**标准化服务流程和接待规范检测**

-   系统梳理并规范服务全流程关键节点，检测沟通语言、服务态度及问题解决能力。
-   帮助团队掌握沟通技巧，提升客户满意度与业务成果，推动“销售驱动”向“服务驱动”升级。

**精准产品介绍和交易推动服务洞察**

-   实时监测销售关键环节，识别问题并优化策略，确保流程高效合规。
-   帮助销售人员提升潜在客户转化率与成交率，推动业绩增长。
-   通过质检分析，管理层及时掌握团队表现并针对性培训，提升整体效能。

## 应用场景

面向汽车制造商与经销商信息中心，覆盖汽车销售运营全流程业务场景。

## 计费规则

### 音频文件处理

**0.73**元/小时

**说明**阿里云账号下所有录音时长汇总后，按秒计算，（实际录音秒数/3600）\* 0.73 = 实际出账金额。

### 纯文本处理

**1.9**元/千次

**说明**根据输入文本量统计，输入内容每150个tokens计为1次，不满150个也计为1次。（如：输入文字=400个tokens，则计为3次。）
