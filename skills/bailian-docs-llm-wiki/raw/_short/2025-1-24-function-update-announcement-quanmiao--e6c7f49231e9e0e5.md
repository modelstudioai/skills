# 2025年1月24日更新

2025年1月24日全妙轻应用（网络内容安全审核）新增文章校对场景示例和批处理接口。

**说明**体验地址：[网络内容安全审核产品控制台](https://bailian.console.aliyun.com/?spm=5176.29619931.J__Z58Z6CX7MY__Ll8p1ZOR.1.74cd59fcHNZmnE#/app/app-market/quanmiao/network-content-audit)。

### 1\. 新增“文章校对场景”示例

功能描述：新增“文章校对场景”示例，能帮助用户审核素材是否有错别字、标签错误、语句不通顺、病句等问题。

在百炼平台**效果调试**页面，选择**通义千问-Max**模型和**文章校对场景**示例，左侧配置三个安全审核维度：

-   **错别字检测**：识别文本中的错别字
-   **语病审核**：检测语句结构混乱等语病
-   **标点错误审核**：检查多余或缺失的标点符号

输入待审核素材后单击**开始审核**，右侧输出结果按三个维度分别列出具体错误及修改建议。

### 2\. 增加批处理接口

功能描述：输入待审核文件或多段文本，后台会创建一个任务，并使用任务ID轮询任务的状态、直到任务结束后，返回结果。

在应用页面单击**API**标签页，选择**批处理API**。下方提供 Java SDK 调用示例，需添加 Maven 依赖 `alibababcloud-quanmiaolightapp20240801` 和 `lombok`，使用 `com.aliyun.sdk` 相关包完成调用。
