# ZHIPU/GLM-5.3-FlashX

智谱原厂直供的高速模型。GLM-5.3-FlashX 推理速度达 200 tokens/s，支持 1M 上下文，原生支持图像、视频与文件输入，提供更快、更流畅的模型体验。

## 推理服务供应商

`ZHIPU/GLM-5.3-FlashX`模型的推理服务供应商为智谱AI。
