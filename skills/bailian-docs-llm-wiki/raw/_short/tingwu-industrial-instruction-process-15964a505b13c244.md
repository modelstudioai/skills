# 业务流程

本文为您介绍通义听悟-工业生产指令转写 Agent 的业务流程案例。

## 业务流程

**①上传指令集：**收集并整理生产场景中的常用语音指令，包括专业术语、中英文缩写及操作口令，形成标准化指令集。将指令集上传至通义听悟-工业生产指令转写 Agent，用于模型优化与个性化适配，提升领域识别准确率。

![401](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7025297571/p1004394.webp)

![404](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7025297571/p1004396.webp)

**②车间设备对接：**将通义听悟 API 对接至工控设备、语音采集终端或自动化系统，完成身份与设备绑定。系统基于已学习的指令集进行实时语音识别，支持高并发、低延迟的工业级语音交互响应。

![41](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7025297571/p1004404.webp)

![413](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7025297571/p1004406.webp)

**③结果呈现：**设备端首先接收原始语音转写结果，Agent 随即进行语义理解与上下文纠错，输出修正后指令。转写结果可实时刷新并推送至您的业务系统，确保指令执行准确，提升作业效率与安全性。
