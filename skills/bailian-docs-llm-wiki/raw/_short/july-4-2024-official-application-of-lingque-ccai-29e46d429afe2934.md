# 2024年7月4日官方应用伶鹊CCAI-对话分析AIO上线通告

本文档介绍伶鹊CCAI-对话分析AIO上线功能。

伶鹊CCAI-对话分析AIO是基于深度调优的对话大模型，为营销服类产品提供智能化升级所需的生成式摘要总结、质检、分析、培训等能力应用。

本期上线支持生成式摘要、质检和分析。

#### **序号**

#### **功能清单**

#### **功能简介**

1

伶鹊CCAI-对话分析AIO

-   在新建弹窗编辑应用名称点击确认完成应用创建。
    

2

应用调试

-   选择模型配置、指令模板，使用预置指令模板，或在预置指令模板基础上自定义模板，点击“测试”对指令进行调试。
    

页面左栏包含**模型配置**（如选择伶鹊对话大模型-Turbo）、**指令信息**（提示词模板中可通过 `$(dialogue)` 和 `$(fields)` 引用对话内容与质检维度）和**对话信息**输入区；右栏**效果测试**区域展示 JSON 格式的多维度质检结果，每个维度包含 `is_match`（是否命中）和 `remarks`（说明）字段，底部显示调用次数及输入/输出 token 用量。

3

自定义指令模板

-   可根据实际业务需要，编辑官方预置模板或自定义指令模板。
    

修改指令后，单击保存时弹出保存方式选择对话框，可选择**新增指令模板**或**覆盖已有指令模板**。若选择新增，需在**指令模板名称**输入框中填写名称（不超过20个字符），然后单击**确定**完成保存。

4

应用API

-   通过API服务输出给客户，方便客户进行集成和使用官方预置模板或自定义模板，客户自定义前端样式。
    

百炼平台提供应用配置与测试界面：左侧可配置模型（如**伶鹊对话大模型-Turbo**）、编写指令信息（支持通过 `${dialogue}` 等变量引用对话内容）、设置对话信息和字段信息，单击**测试**按钮后右侧展示 JSON 格式的执行结果。右侧**应用API**面板提供 Python、Java、Curl 代码示例，Python 示例使用 `dashscope` 库的 `Application.call` 方法调用应用，便于集成。

5

管理应用

-   进入调试页面，开发者可在本页面进行指令效果等测试。
    

在阿里云百炼平台的**我的应用**页面，已创建的应用以卡片网格形式展示，每张卡片包含应用名称、应用ID、应用模板信息，以及**管理**、**调用量**、**调用**等操作入口。页面顶部提供**查看我的API-KEY**链接及**新增应用**按钮，可单击目标应用卡片进入应用详情。

6

调用量

-   支持查询某天或某个日期区间调用量数据。
    

在**我的应用**页面，单击目标应用卡片上的**调用量**按钮，右侧弹出调用量统计面板。面板支持按**所属空间**、**选择模型**、**应用**、**数据来源**进行筛选，时间范围可选**昨天**、**近3天**、**近七天**、**近15天**，下方以折线图展示调用次数统计。
