本篇以一张参考人像跑通换装组照：逐套换服装、换场景，人脸始终保持一致。直接让模型重画，每张脸都不一样，正确做法是给一张参考图，把「身份锁定」写成最高优先级，只允许它改服装、场景、光线。

调用链：`wan2.7-image` 文生图（出参考人像）→ `wan2.7-image` 参考图编辑（逐套换装换景，每次都把身份锁定写在最前面）。

## 步骤：身份锁定放在第一句

参考图出一次后，每套造型把参考图传入 `wan2.7-image` 做一次编辑，身份锁定写在提示词最前面：

```
严格保持画面中这位{人物}的五官、脸型、发型、发色、肤质完全不变，是同一个人。
只把她的服装换成{服装，例：藏青色职业西装外套配白衬衫}，
场景换成{场景，例：明亮的现代办公室落地窗前}，
光线为{光线，例：清晨柔和自然光}。
保持高写实人像质感，{景别，例：正面半身}构图。
不要改变长相、不要卡通化、不要多余肢体。
```

查看一致性核对 · 让视觉模型交叉比对三张图（qwen3.7-plus）

```
把参考图与两张组照一起交给 qwen3.7-plus 做交叉比对，它的判断：

第二张（商务装）：是同一人
  「五官特征（眼型、鼻梁高度、嘴唇形状）、脸型（略长的鹅蛋脸）以及发型
    （黑色齐肩中分直发）与第一张图高度一致。眼镜的款式（细金属圆框）
    也完全保留了下来。」

第三张（休闲装）：是同一人
  「同样保留了第一张图的核心面部特征，包括眉眼间距、鼻翼宽度和嘴角的弧度。」

瑕疵检查：两张均无明显五官漂移、无体型突变、无多余肢体；
  西装那张肩线更挺、毛衣那张上身更厚实，属于衣物剪裁与厚度的正常差异。

（说明：这是让视觉模型做的交叉比对，不是权威人脸识别，重要用途请自己再核。）
```

## 说明

-   **消耗**：本玩法涉及图片生成 + 图像编辑，参考图出一次，之后每套造型一次编辑调用。想出一组 5 套造型就是 1+5 次调用，比视频便宜得多，适合批量出图。
-   **一致性**：身份锁定这句必须放在提示词最前面，并明确「是同一个人、不要改变长相」，放在末尾容易被后面的服装、场景描述冲掉。多套造型分多次生成时，每次都用同一张参考图，而不是拿上一张产出继续改，否则误差会逐张累积、越改越不像。
-   **合规**：用真人照片做换装务必获得本人同意，不得用于伪造身份、误导性宣传。演示图为 AI 生成的虚构人物。
