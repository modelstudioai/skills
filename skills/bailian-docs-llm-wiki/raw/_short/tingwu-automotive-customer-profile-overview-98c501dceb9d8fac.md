# 产品概述

本文介绍通义听悟-购车客户画像 Agent 的核心功能、产品优势、应用场景及计费规则。

## 产品简介

通义听悟购车客户画像 Agent 运用人工智能技术洞察并构建高质量客户画像，通过 ccai-pro 模型强化语义理解与指令遵循能力。它分析电话沟通、门店交流、试驾体验等全流程场景，解析客户购车咨询问题，自动生成客户画像与销售建议。

智能解析服务录音，输出深度客户画像：涵盖车型配置、乘坐体验、用车成本、竞品反馈、订单优惠等关注点。为运营和销售团队提供精准跟进策略，提升成单转化率。

## 产品优势

**精准挖掘客户关注点**

通过智能数据分析生成客户偏好画像，帮助销售人员实施个性化销售策略，提升客户体验与成交率：

-   提供精准车型推荐与定制服务
-   锁定客户对功能、配置和安全性的需求

**揭示潜在价格敏感性和购车动机**

基于实时客户画像与购车意向分析，销售团队可制定针对性策略，从而有效提升成交率：

-   对价格敏感客户：推荐金融方案或限时折扣
-   对品牌导向客户：突出产品优势与专属服务

**全面了解客户对售后服务的期待**

系统收集分析售后反馈，帮助企业：

-   精准把握客户期望，发现服务短板
-   优化服务流程，提升满意度与忠诚度
-   持续改进售后体系，赢得长期信任

## 应用场景

面向汽车制造商与经销商信息中心，覆盖汽车销售运营全流程业务场景。

## 计费规则

### 音频文件处理

-   转写费用：**0.6**元/小时
-   线索评分/ 试驾意向评分/一句话画像：**0.064**元/小时
-   客户详细关注点分析：**0.13**元/小时

**说明**阿里云账号下所有录音时长汇总后，按秒计算。（实际录音秒数/3600）\* 模型价格汇总 = 实际出账金额。

### 纯文本处理

线索评分/ 试驾意向评分/一句话画像：**0.95**元/千次

客户详细关注点分析：**1.9**元/千次

**说明**根据输入文本量统计，输入内容每150个tokens计为1次，不满150个也计为1次。（如：输入文字=400个tokens，则计为3次。）
