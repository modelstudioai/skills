# 0代码构建私有知识问答应用

大语言模型无法直接回答私有知识领域的问题。借助阿里云百炼的智能体应用构建能力和私有知识文档，可以零代码构建一个能回答私有领域问题的大模型问答应用。

## 为什么大模型无法回答私有知识

大语言模型（LLM）的知识来源于训练数据，不包含私有、特定领域或最新的信息。因此，直接向其提问特定产品或内部知识的问题，会得到不准确或虚构的回答。

检索增强生成（Retrieval-Augmented Generation，RAG）将外部知识库与大语言模型结合，通过检索相关信息并提供给模型，使模型基于给定的私有知识回答。核心原理如下：

1.  **数据处理与向量化**：上传的文档经过自动化处理，系统将其切分成数据块（Chunks），再使用嵌入模型（Embedding Model）把每个数据块转换为数学向量，存储于向量数据库中。
2.  **检索**：接收到问题时，系统同样将问题向量化，然后在向量数据库中检索与问题向量最相似的 Top-k 个文档数据块。
3.  **生成**：系统将原始问题和检索到的文档片段组合成提示词（Prompt），提交给模型生成答案。

## 创建私有知识问答应用

本教程使用新版智能体应用（Agent 2.0）。在当前控制台中，点击**创建智能体**后默认创建的即为 Agent 2.0 应用；如需创建旧版（Agent 1.0）应用，点击创建弹窗底部的**旧版 Agent 创建入口**，页面将跳转至旧版百炼控制台。

### 创建智能体

1.  **创建应用**：访问[应用管理](https://bailian.console.aliyun.com/flow-agent/app-center)页面，点击**创建智能体**，填写**应用名称**（本教程以“阿里云百炼手机选购向导”为例），点击**立即创建**。创建完成后自动进入应用配置页面。
    
2.  **选择模型**：在应用配置页面的**规划**区域，点击模型选择器选择大语言模型：
    
    -   **智能模式**：由平台自动取得成本与效果的平衡，无需手动挑选模型，推荐新手选择。其中 **AUTO** 档位会根据任务复杂度自动路由到合适的性能档。
    -   **指定模型**：直接选择具体模型。为确保多步规划效果，推荐选用具备强工具调用能力的模型，如 `千问-Max` 系列模型；点击**更多模型**可选择其他模型。
    
    **说明**使用大模型会产生计费。阿里云百炼提供限时免费额度，可在[模型广场](https://bailian.console.aliyun.com/cn-beijing?tab=model#/model-market/all)点击各模型卡片的**查看详情**查询。
    
3.  **设计 Prompt（提示词）**：在**规划**区域的提示词输入框中，定义应用的角色和任务。建议设置为：
    
    > 你是一位阿里云百炼手机导购，任务是帮助客户对比手机参数，分析客户需求，推荐个性化建议。
    
    支持在系统提示词中嵌入变量：点击提示词右上方的**新建变量**进行设置，输入 `/` 即可引用已配置的变量。
    
4.  **测试应用**：在右侧对话框中输入问题（如“阿里云百炼手机有哪些款式？”）发起提问。
    
    **说明**由于缺少“阿里云百炼手机”的相关知识，应用的回答较为笼统，甚至可能无中生有。接下来为应用关联知识库。
    

### 创建知识库

1.  在左侧导航栏选择**数据接入** > **知识管理**，进入[知识管理](https://bailian.console.aliyun.com/cn-beijing/rag/knowledge/list)页面，点击**创建**。
    
2.  填写**名称**和**描述**，知识库类型选择**文档搜索**，使用场景选择**基础文档问答**，点击**下一步**。
    
3.  数据来源选择**上传文件**，拖拽或点击上传一份“阿里云百炼手机”相关文档（支持 PDF、Word、Markdown 等格式），可下载示例文件[阿里云百炼系列手机产品介绍.docx](https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/zh-CN/20250603/duuuxk/%E9%98%BF%E9%87%8C%E4%BA%91%E7%99%BE%E7%82%BC%E7%B3%BB%E5%88%97%E6%89%8B%E6%9C%BA%E4%BA%A7%E5%93%81%E4%BB%8B%E7%BB%8D.docx)。
    
4.  索引设置保持默认，点击**创建知识库**。
    
    **说明**系统会自动完成解析、切片、向量化与索引构建，知识库状态变为**已就绪**后即可用于检索。知识库类型、使用场景、切片策略等完整配置说明参见[创建和使用知识库](raw/application-user-guide/agent-context/knowledge-base/data-connection-overview/rag-knowledge-base.md)。
    

### 创建并发布知识检索服务

新版智能体通过关联**知识检索服务**使用知识库。一个知识检索服务可以包含一个或多个知识库，关联前需先完成创建与发布。

1.  在左侧导航栏选择**知识服务** > **知识检索**，进入[知识检索](https://bailian.console.aliyun.com/cn-beijing/rag/retrieval/list)页面，点击右上角**创建检索服务**，填写**服务名称**（本教程填写“阿里云百炼手机检索”），点击**确认**。
    
2.  创建成功后自动进入配置页面。点击\*\*+ 添加\*\*，绑定上一步创建的“阿里云百炼手机”知识库。如绑定多个知识库，可为每个知识库设置权重，权重越大，其检索结果在最终排序中的优先级越高。
    
3.  在右侧对话窗口中输入查询内容（如“拍照效果最好的手机是哪款？”），确认返回的切片结果符合预期后，点击右上角**发布**。发布后该检索服务才可被应用关联。
    
    **说明**检索服务配置（知识库路由、混排模型、召回数量等）在本教程中保持默认即可，完整说明参见[知识检索](raw/application-user-guide/agent-context/knowledge-base/service/rag-knowledge-retrieval.md)。
    

### 为智能体关联知识检索服务

1.  访问[应用管理](https://bailian.console.aliyun.com/flow-agent/app-center)页面，找到已创建的“阿里云百炼手机选购向导”应用，点击**配置**，进入应用配置页面。
2.  在**知识库**下找到**检索策略**区域。首次配置时页面提示尚未配置知识检索服务，点击**立即配置**打开服务选择面板；也可以点击该区域右上角的**配置**进入。
3.  在**配置检索服务**面板中，使用搜索框查找已发布的“阿里云百炼手机”检索服务，根据服务名称、版本、包含的知识库及知识库数量确认关联对象，点击目标服务右侧的**关联**，即可将该知识检索服务关联到当前应用。

### 测试与发布

1.  回到应用配置页面，在右侧对话框中重新提问，例如：“请你帮我挑选一款拍照效果最好的阿里云百炼手机，价格在3000元以内。”引入知识检索增强后，应用能够基于知识库中的内容准确回答选购问题。
    
2.  点击页面右上角的**发布**，在弹出的**发布版本**窗口中确认版本信息，点击**确认发布**。
    
    **说明**版本 ID 从 V1.0 开始递增，每个应用最多保存 10 个版本。发布是后续通过 API 或 SDK 调用应用的前提条件。

## 常见问题

为什么应用回答不准确，或没有使用知识库中的知识回答？

可能由 RAG 管道中的多个环节导致：

1.  文档分块时破坏了语义完整性。
2.  嵌入模型未能准确捕捉文本的核心语义。
3.  检索环节未能召回最相关的文档片段。

可尝试以下方案调优：

1.  使用结构化较好的文档，如 Markdown、JSON。
2.  在知识库配置时选择**自定义**配置模式，通过选择不同的嵌入模型、设置不同的排序配置来调试回答效果。

如何让模型在知识库里找不到答案时明确告知“不知道”，而不是编造答案？

可以开启**干预智能体回复**功能，并设置知识库无结果时智能体的干预回复。
