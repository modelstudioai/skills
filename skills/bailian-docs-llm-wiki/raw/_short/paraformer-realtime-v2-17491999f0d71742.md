# paraformer-realtime-v2

推荐使用 Paraformer实时语音识别模型，支持多个语种自由切换的视频直播、会议等实时场景的语音识别。可以通过language\_hints参数选择语种获得更准确的识别效果。支持任意采样率。 支持的语言包括：中文（含粤语等各种方言）、英文、日语、韩语。 可支持热词。
