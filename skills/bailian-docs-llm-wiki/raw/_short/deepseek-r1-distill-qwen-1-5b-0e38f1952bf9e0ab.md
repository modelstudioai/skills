# deepseek-r1-distill-qwen-1.5b

DeepSeek-R1-Distill-Qwen-1.5B是一个基于Qwen2.5-Math-1.5B的蒸馏大型语言模型，使用了 DeepSeek R1 的输出。

<a id="推理服务供应商"></a>

<a id="h-490b2834e6"></a>

## 推理服务供应商

`deepseek-r1-distill-qwen-1.5b`模型的推理服务供应商为阿里云百炼。
