# 商品图变展示视频 · 静图秒变主图短视频

一张商品图，让产品不动、只有光影流转，生成主图展示短视频。

**说明**

**免责声明**：本页展示内容均为 AI 模型生成，仅供参考，不构成任何效果承诺；实际产出效果与 Credits 消耗以控制台「用量详情」为准。

电商详情页、抖音带货、朋友圈广告，会动的商品视频比静图点击率高得多，但实拍要搭棚、找模特、请摄制。这里只要一张商品图，就能让它保持产品纹丝不动、只有影棚光影缓缓流转，生成一段质感高级、可直接用在主图 / 详情页的展示短视频。本篇以一张磨砂玻璃精华瓶主图为例。

两步出片：(1) `wan2.7-image` 生成（或直接用你自己的）商品主图 → (2) `happyhorse-1.1-i2v` 固定机位，产品完全锁定不动，只让影棚光影在瓶身缓缓流动、形成高级光泽。

## 步骤：主体全静，只让光影动

把商品主图连同下面的提示词发给 `happyhorse-1.1-i2v`。关键是把「主体全静、只让光影动」写死：

```
真实照片级质感的静物广告镜头，机位完全锁定，总时长5秒。
整个画面几乎静止：{商品，例：磨砂玻璃精华瓶}、标签、瓶盖、{台面，例：大理石台面}、{陪衬物，例：绿叶}
全部保持原样、位置和大小完全不变、绝不缩放或抖动。
唯一的动态是柔和的影棚灯光从画面左侧向右侧极缓慢扫过，
在{材质，例：磨砂玻璃与金色瓶盖}上形成缓缓移动的高光与柔和阴影，营造高级质感。
不要旋转、不要镜头运动、不要文字水印、不要任何物体变形消失或出现、不要标签闪烁。
```

## 说明

-   **消耗**：本玩法涉及图片生成 + 图生视频，两次独立调用（有自己的商品图可跳过第一步、直接喂图）。视频消耗明显高于出图，且异步任务完成后统一结算；主图视频 5 秒 / 720P 已够用，先试跑确认主体不崩再考虑加时长或提分辨率。
-   **商品类最怕主体崩**（瓶子转着转着变形、标签闪烁、台面消失）：实测发现，让商品旋转 / 移动时最容易崩，而产品完全锁定、只让光影流动反而最稳最高级——这也是化妆品大片常用的手法。本次成片产品全程零变形，只有背景光影在呼吸。
-   **用自己的真实产品照最稳**：直接把商品照片喂给第二步（i2v 支持传入本地图），比先生成更能保证和实物一致；提示词里务必写死"主体不变形、不移位、机位锁定"。
-   **带文字/logo 的包装要注意**：AI 可能把标签文字改乱，涉及品牌字样的建议后期用真实产品图叠回，或在提示词里让标签保持"留白/不可辨识"再自行贴字。
