# 产品概述

通义听悟工业生产指令转写 Agent 运用人工智能技术，对工业生产场景中产品质检或设备语音输入进行指令修正，面向专业词汇使用全链路大模型提升准确率，释放工人双手、提高生产效率。支持电话、手机、智能工牌及车载设备等录音输入，通过多语言识别与分析，助力企业提升生产效率和操作精准度。

## 产品优势

**专为工业场景打造，高噪环境下精准识别**

-   基于深度降噪算法与工业声学模型，有效过滤车间噪音，精准捕捉关键语音指令。
-   适配质检、装配、巡检等复杂环境，显著提升操作准确率与作业效率。

**支持多语言与专业术语，覆盖广泛指令场景**

-   可识别中、英、粤、韩、日、德、法、俄、意大利、西班牙语及行业缩写，兼容超1000条常用工业指令语句。
-   面向跨语言团队与高专业度场景，实现术语级准确理解与无缝交互体验。

**大模型驱动，转写准确率行业领先**

-   实时监测销售关键环节，识别问题并优化策略，确保流程高效合规。
-   帮助销售人员提升潜在客户转化率与成交率，推动业绩增长。
-   通过质检分析，管理层及时掌握团队表现并针对性培训，提升整体效能。

## 应用场景

面向工业生产过程中的设备交互、语音输入结果的质检等业务场景。
