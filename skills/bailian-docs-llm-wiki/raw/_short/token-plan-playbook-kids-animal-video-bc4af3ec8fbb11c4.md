# 儿童趣味动物视频生成

一个动物词生成儿童童话与三拍脚本，再文生视频出 5 秒动画。

**说明**

**免责声明**：本页展示内容均为 AI 模型生成，仅供参考，不构成任何效果承诺；实际产出效果与 Credits 消耗以控制台「用量详情」为准。

本篇以动物词「狐獴」跑通一条文本转视频的链路：先让文本模型写出一个儿童友好的童话故事和三拍分镜脚本，再把合并后的提示词交给文生视频模型，输出一段 5 秒温暖动画样片。

调用链：`qwen3.7-plus`（故事 + 脚本 + 视频提示词）→ `happyhorse-1.1-t2v`（5s / 720P / 16:9）。

## 步骤一：生成故事、三拍脚本与视频提示词

用 `qwen3.7-plus` 一次性产出故事、分镜脚本和可直接喂给视频模型的提示词。将以下内容发给模型：

```
动物词：狐獴。请为3-6岁儿童创作一个温暖友好的童话小故事（100字以内），
并规划三拍视频脚本（每拍一句画面描述）。
最后单独一行以「视频提示词：」开头，给出一条合并的5秒文生视频提示词
（含画面主体、动作、光线、温暖治愈3D动画风格）。
```

## 步骤二：文生视频

将上一步的视频提示词发给 `happyhorse-1.1-t2v`。该模型为异步接口，约 90 秒出片：

```
温暖治愈3D动画风格，一只可爱的小狐獴抱着发光的太阳花和朋友们开心跳舞，
温暖的金色阳光洒在它们身上，画面明亮柔和
```

视频提示词：一只毛茸茸的可爱小狐獴站在沙丘上踮脚张望，随后一只小蝴蝶停在它的鼻尖，小狐獴露出微笑迎着夕阳向前走，柔和温暖的夕阳逆光，温暖治愈3D动画风格，皮克斯渲染，细节丰富。

## 说明

-   **消耗**：本玩法涉及文本生成（`qwen3.7-plus`）与视频生成（`happyhorse-1.1-t2v`，5s / 720P / 16:9）。视频生成的 Credits 消耗明显高于文本，且随时长与分辨率上升。
-   **建议**：首次以较短时长、较低分辨率试跑，通过控制台[「用量详情」](https://bailian.console.aliyun.com/cn-beijing/subscription/token-plan/personal)确认单次消耗后再加量。
