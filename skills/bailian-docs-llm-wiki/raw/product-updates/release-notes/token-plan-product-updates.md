# Token Plan 功能更新

Token Plan 的功能上线、模型支持、工具接入和计费权益调整记录。

### 2026-11-16

新增

#### Qwen4-Max 上线

Qwen4-Max 正式上线，个人版和团队版均支持该模型。详见[个人版支持的模型](https://help.aliyun.com/zh/model-studio/token-plan-personal-overview#tppo-h-models)和[团队版支持的模型](https://help.aliyun.com/zh/model-studio/token-plan-team-overview#tpto-h-models)。

### 2026-11-11

新增

#### Qwen4-Max-Preview 上线

预览期为 2026 年 11 月 11 日 10:00 至 11 月 25 日 24:00（UTC+8），期间 Credits 消耗低至 2 折，个人版每晚 22:00 - 次日 08:00 再享 4 折。个人版和团队版均支持该模型，详见[个人版支持的模型](https://help.aliyun.com/zh/model-studio/token-plan-personal-overview#tppo-h-models)和[团队版支持的模型](https://help.aliyun.com/zh/model-studio/token-plan-team-overview#tpto-h-models)。

### 2026-11-09

计费

#### 个人版套餐额度上调、Pro 套餐降价

四档套餐额度上调，Pro 套餐目录价及官网折扣价下调。详见[《Token Plan 个人版套餐降价通知》](https://www.aliyun.com/notice/118815)。

### 2026-10-29

新增

#### 语音识别模型接入

支持 `qwen-audio-3.0-asr-flash`，可提交本地音频或音频 URL 并返回转写文本。详见[接入语音识别模型](raw/token-plan-user-guide/token-plan-best-practice/token-plan-speech-recognition.md)。

### 2026-10-22

新增

#### 实时语音对话模型接入

支持 `qwen-audio-3.0-realtime-plus`，由 Agent 工具创建并运行语音客户端。详见[接入实时语音对话模型](raw/token-plan-user-guide/token-plan-best-practice/token-plan-realtime-voice.md)。

### 2026-10-19

新增

#### 新增 DeepSeek-V4.1-Flash

`deepseek-v4.1-flash-1017` 加入支持的模型，限时夜间五折。详见[个人版支持的模型](https://help.aliyun.com/zh/model-studio/token-plan-personal-overview#tppo-h-models)。

### 2026-10-10

新增

#### 新增万相视频模型

个人版和团队版模型表新增 `wan3.0-video`。详见[个人版支持的模型](https://help.aliyun.com/zh/model-studio/token-plan-personal-overview#tppo-h-models)。

### 2026-09-09

权益

#### Harness 权益

Standard 与 Pro 套餐附赠 Harness 权益，覆盖 AgentStudio 工具的每月免费额度和后付费折扣，不占用套餐 Credits。详见[Harness 权益](raw/token-plan-user-guide/token-plan-personal/token-plan-harness-benefits.md)。
