# 记忆审计

按记忆库、实体、时间和记忆 ID 查询变更记录，对照快照追溯记忆的新增、更新、软删除、恢复和删除。

## 适用场景

需要确认某条记忆何时被修改、由记忆抽取还是用户操作触发，以及变更前后的内容时，使用记忆审计。它覆盖事实记忆、用户画像和技能记忆的变更记录，包括自动抽取与手动操作。

需要将原始对话与该会话关联的抽取、更新结果对照时，使用[记忆观测](raw/application-user-guide/agent-context/memory-library-overview/observability/observation.md)。

## 前提条件

进入目标记忆库所在的业务空间，并已有记忆变更记录。需要筛选某个实体或某条记忆时，准备对应的实体 ID 或记忆 ID，可在记忆库的**记忆详情**中获取，参见[管理记忆](raw/application-user-guide/agent-context/memory-library-overview/create-memory/manage-memory.md)。

## 查询变更记录

1.  进入[百炼控制台](https://bailian.console.aliyun.com/cn-beijing/memory/playground)，在 **Memory** 中选择**观测与审计 > 记忆审计**。
2.  选择记忆库。默认查看**全部记忆库**；下拉列表可筛选已存在记忆的记忆库。
3.  需要筛选具体实体时，先选择具体记忆库，再从**全部记忆实体**下拉列表中选择目标实体。
4.  选择时间范围：**最近7天**、**最近30天**或**最近90天**。
5.  需要追溯单条记忆时，在**请输入记忆ID**输入框中输入记忆 ID，按回车键执行搜索。
6.  查看匹配记录和总条数；记录较多时通过分页查看。

记录列表包含以下信息：

字段

说明

时间

该条记忆发生变更的时间

事件

新增、更新、软删除、恢复或删除等变更类型

记忆库

变更所属的记忆库

记忆类型

事实记忆、用户画像或技能记忆

记忆实体

记忆关联的实体 ID

记忆ID

用于查询同一条记忆的多次变更

触发原因

区分记忆抽取与用户操作等来源

耗时

本条变更记录展示的处理耗时，单位为毫秒

操作

点击**快照**查看变更前后内容

**说明**选择具体记忆库后才能筛选记忆实体。查询结果为空时，检查记忆 ID、时间范围和所选记忆库、实体是否匹配，再调整条件搜索。

## 解读变更事件

事件

对应行为

新增

记忆抽取生成新的记忆

更新

记忆抽取更新已有内容，或用户手动编辑内容

软删除

用户关闭记忆详情中的启用开关，记忆显示为**未启用**

恢复

用户重新开启启用开关，记忆显示为**已启用**

删除

用户确认删除记忆

关闭启用开关与删除记忆是不同操作。软删除后可通过启用开关恢复；点击**删除**并确认后无法恢复。操作步骤参见[管理记忆](raw/application-user-guide/agent-context/memory-library-overview/create-memory/manage-memory.md)。

例如，一条饮品偏好先由对话抽取生成，再由用户编辑、关闭启用开关并重新开启，可按同一记忆 ID 查询到新增、更新、软删除和恢复记录。**触发原因**帮助区分自动抽取与用户手动操作。

## 查看变更快照

1.  在目标记录的**操作**列点击**快照**。
2.  对照展开区域的**变更前**与**变更后**，查看该次变更记录的内容或状态。
3.  需要定位记录时，复制展开区域显示的**变更 ID**；查看结束后点击**收起**。

快照按该次变更展示数据。新增记录的变更前、删除记录的变更后可显示为 `-`；恢复记录可能只展示恢复后的状态。快照中的字段随记忆类型和操作变化，不一定在两侧重复展示完整记忆字段。

例如，用户画像更新可显示 `content` 从旧偏好变为新偏好；事实记忆手动编辑可显示修改前后的内容；删除记录可用于核对被删除的内容。查看快照不会修改或恢复记忆。

## 从记忆详情进入审计

1.  在记忆库的**记忆详情**标签页，找到实体并点击**查看**。
2.  将鼠标移到目标记忆卡片的历史图标上，查看**最近变更历史**。
3.  点击**更多**，在新标签页打开记忆审计。

该入口自动带入记忆库与实体条件。若只查询目标记忆的变更，在审计页面继续输入它的记忆 ID。
