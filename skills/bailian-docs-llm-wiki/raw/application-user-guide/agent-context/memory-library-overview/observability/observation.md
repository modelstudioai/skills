# 记忆观测

在控制台查看会话内容及关联的记忆变更，追溯事实记忆、用户画像和技能记忆的抽取与更新。

## 适用场景

当需要检查一段对话产生了哪些记忆，或某次对话如何更新已有记忆时，使用记忆观测。页面将会话消息与关联的记忆变更放在同一视图中，便于对照原始对话检查抽取结果。

需要查询所选时间范围内某条记忆的变更记录，包括手动编辑、停用、恢复和删除时，使用[记忆审计](raw/application-user-guide/agent-context/memory-library-overview/observability/audit.md)。

## 前提条件

-   已有可用的记忆库，并已完成对话记忆抽取。可通过 Playground 对话产生记忆；创建与规则配置参见[创建记忆库](raw/application-user-guide/agent-context/memory-library-overview/create-memory.md)和[配置记忆规则](raw/application-user-guide/agent-context/memory-library-overview/create-memory/configure-rules.md)。
-   进入产生记忆时使用的业务空间。

使用 Playground 体验时，先选择记忆库和记忆规则，再发送对话。体验会消耗免费额度或产生按量费用，参见[计费说明](raw/application-user-guide/agent-context/memory-library-overview/integration-overview/billing.md)。

**说明**记忆抽取异步进行。对话回复完成后，可等待抽取结束，再查看观测记录和记忆详情，确认实际保存的内容。

## 查看会话与记忆变更

1.  进入[百炼控制台](https://bailian.console.aliyun.com/cn-beijing/memory/playground)，在 **Memory** 中选择**观测与审计 > 记忆观测**。
2.  在页面顶部选择记忆库。默认查看**全部记忆库**，也可选择具体记忆库缩小范围。
3.  选择时间范围：**最近7天**、**最近30天**或**最近90天**。需要重新加载数据时，点击时间筛选右侧的刷新图标。
4.  在左侧**会话列表**中选择要检查的会话。列表展示记忆实体、会话摘要、时间和关联的记忆变更数量；同一实体的不同会话分别列出。
5.  对照中间的用户与助手消息，查看右侧**记忆变更历史**。可通过消息导航按钮跳转到对应消息。
6.  找到目标变更，点击**查看详情**查看记忆内容。

记忆变更历史展示以下信息：

信息

用途

时间

确认该条记忆发生变更的时间

ID

定位关联记录

记忆类型

区分事实记忆、画像记忆和技能记忆；其中画像记忆对应用户画像

事件

判断该次变更是新增还是更新等操作

内容

查看关联记忆的内容；技能记忆展示技能名称和描述

## 如何解读观测结果

-   **按会话检查抽取结果**：例如，用户在一段对话中表达饮品偏好，可对照消息与事实记忆、用户画像的新增记录；后续会话改变偏好时，查看新会话关联的更新记录。
-   **区分历史内容与当前内容**：观测中的变更详情展示该次变更关联的内容。记忆后续被编辑或删除后，早先会话中的历史内容仍可能与当前记忆状态不同。当前内容在[管理记忆](raw/application-user-guide/agent-context/memory-library-overview/create-memory/manage-memory.md)的记忆详情中查看。
-   **检查实际抽取结果**：助手的对话回复可能包含未保存到记忆中的信息。以记忆详情和变更记录确认实际保存、更新了哪些内容。
-   **追溯手动操作**：会话关联的变更历史不包含该实体的所有手动操作。需要查看这些操作时，进入[记忆审计](raw/application-user-guide/agent-context/memory-library-overview/observability/audit.md)，按实体或记忆 ID 筛选。

## 未看到预期记录

页面显示**暂无数据**时，检查业务空间、记忆库和时间范围是否与产生记忆时一致。若对话刚结束，等待记忆抽取完成后刷新。

已有会话但尚未选择时，从左侧选择会话后再查看消息和变更历史；需要核对当前记忆是否存在时，进入记忆库的**记忆详情**标签页查看对应实体。
