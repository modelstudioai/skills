# OSS

通过服务关联角色连接对象存储 OSS，让智能体访问 Bucket 中的文件。

OSS 连接器让智能体访问你自己的 OSS Bucket 中的文件。数据保留在 OSS，调用时实时读取，不产生副本。

## 前置条件

-   已创建 OSS Bucket。
-   已开通向量检索服务。
-   当前账号具备目标 Bucket 的读取权限。

## 授权方式

OSS 连接基于阿里云服务关联角色访问你的 Bucket，不需要配置 AccessKey。

**说明**首次使用前需要初始化服务关联角色。连接对话框中的 **立即授权** 会引导你完成这一步。

## 连接步骤

1.  **打开连接对话框**：在 **Apps** 页面找到 **OSS** 卡片，单击 **连接**。
    
2.  **填写基本信息**：
    
    字段
    
    是否必填
    
    说明
    
    连接器名称
    
    是
    
    使用易于识别的名称，最多 64 个字符
    
    连接器描述
    
    否
    
    说明这个 Bucket 存了什么内容
    
3.  **完成授权**：首次连接时单击 **立即授权**，按界面提示初始化服务关联角色。
    
4.  **选择存储 Bucket**：在 **存储 Bucket 选择** 下拉列表中选择目标 Bucket。列表只展示当前账号有权限访问、且已完成授权的 Bucket。下拉列表为空时，先确认授权是否完成、Bucket 标签是否已添加。
    
5.  **确认创建**：单击 **确认** 完成连接。
    

## Bucket 标签要求

阿里云百炼通过 Bucket 标签判断是否允许访问。Bucket 必须带上这个标签：

用途

标签键

标签值

作为 OSS 连接器访问 Bucket 文件，或作为文件连接器的 OSS 批量导入来源

`bailian-datahub-access`

`read`

**警告**标签缺失或值写错时，Bucket 不会出现在下拉列表中，或连接创建失败。报错信息有时会指向跨域配置，实际原因通常是标签问题，先核对标签再排查其他方向。

标签在 OSS 控制台的 Bucket 管理页面添加，具体步骤见[旧版数据连接文档的 OSS 章节](https://help.aliyun.com/zh/model-studio/data-connection#b8de517ce557x)。

## 自动生成的工具

连接成功后，Connector 会生成访问 Bucket 文件的工具。在 App 详情页的 **可用的工具** 区域展开工具即可查看实际的入参与出参。

## 关于流量费用

从 OSS 读取数据会产生 OSS 侧的下行流量费用，由 OSS 按其计费规则收取，与 Connector 的用量分开计算。同一 Bucket 被频繁读取时，这部分费用会比较明显。
