# 风险与审计

风险与审计页面展示账号下全部 Agent 的风险事件和审计记录，支持筛选、搜索、详情与 Trace 查看，帮助定位风险来源并追溯影响范围。

## 页面入口

在控制台导航栏点击 **Security**，左侧菜单选择 **高级防护 > 风险与审计**，进入风险与审计页面。

**说明**此页面展示该账号下全部 Agent 的风险及日志详情，暂不区分业务空间。

## 功能说明

风险与审计页面集中展示安全检测产生的风险事件和审计记录。通过筛选、搜索、风险详情和 Trace 等信息，可以调查风险的来源及影响范围，并导出相关证据。

**说明**当前页面提供风险查看、分析和证据导出能力，暂不支持自动处置风险。

## 风险概览

**说明**只有开通了安全策略防护，风险与审计模块才会有数据。

页面顶部展示风险统计数据：

指标

说明

**风险累计数**

从当前日期往前追溯一年的风险累计数

**高风险数**

风险等级为高的风险事件数量

**中风险数**

风险等级为中的风险事件数量

**低风险数**

风险等级为低的风险事件数量

风险等级根据风险置信度和危害程度联合研判后划定，分为高、中、低三档。

## 风险列表

风险列表展示每条风险事件的详细信息，支持按风险等级、风险节点类型筛选，并支持搜索。

### 筛选条件

筛选项

说明

**风险等级**

按高、中、低等级筛选，或展示全部等级

**风险节点类型**

按风险发生的节点类型筛选，包括 Agent、身份、模型、工具、技能、知识库、记忆、渠道

### 列字段说明

字段

说明

**级别**

风险等级，分为高、中、低

**风险名称**

风险事件的名称

**Agent 名称**

产生风险的 Agent 名称

**Agent 节点**

产生风险的 Agent 节点，与 Agent 资产中的节点类型一致

**状态**

风险处理状态，未处理或已处理

**操作**

支持对风险项进行处理或忽略

## 审计日志

页面同时记录 Agent 的操作日志，包括输入记录、输出记录、工具调用记录及其参数和结果，可用于风险回溯、合规审计和行为分析。
