# Agent 计费

## 费用构成

Agent 的费用取决于实际使用的运行时、模型和组件。模型调用费用与组件费用分别核对，免费额度只抵扣其指定的计费项。

## 计费与免费额度

各服务的价格、地域、免费额度有效期、抵扣顺序和超出额度后的行为见上表详情。组合多个组件时，分别核对实际调用和规格费用。
