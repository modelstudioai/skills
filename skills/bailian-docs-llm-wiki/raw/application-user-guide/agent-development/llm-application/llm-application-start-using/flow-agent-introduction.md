# 概述

了解 Flow Agent 的应用类型、扩展能力和使用方法。

## 什么是 Flow Agent

Flow Agent 是阿里云百炼提供的可视化应用开发平台，支持构建、调试和发布智能体应用和工作流应用。

## 应用类型

应用类型

说明

适用场景

[智能体应用](raw/application-user-guide/agent-development/llm-application/new-single-agent-application.md)

自然语言配置（零代码），可调用知识库、MCP 服务等工具完成任务

智能客服、知识问答、任务助理

[工作流应用](raw/application-user-guide/agent-development/llm-application/workflow-application.md)

可视化节点编排（低代码），将多步骤任务串联为稳定可控、可复现的执行链路

报告生成、订单处理、多步骤审批

## 扩展能力

能力

说明

适用场景

[文件问答](raw/application-user-guide/agent-development/llm-application/file-q-a.md)

对文档、图片、音视频等文件进行内容理解和问答，提供全文引用、切片检索和自定义处理三种模式

长文档问答、资料检索、图片和音视频内容理解

[Prompt](raw/application-user-guide/agent-development/llm-application/prompt.md)

管理可复用的 Prompt 模板，支持样例库、自动优化和反馈优化

沉淀常用提示词、持续优化回答效果

[插件](raw/application-user-guide/agent-development/llm-application/plug-in.md)

通过官方插件和自定义插件扩展应用能力

联网搜索、代码执行、业务系统调用

[任务中心](raw/application-user-guide/agent-development/llm-application/flow-agent-task-center.md)

查看异步调用产生的后台任务，包括执行状态、输入输出和时间信息

长耗时任务的进度跟踪与结果查询
