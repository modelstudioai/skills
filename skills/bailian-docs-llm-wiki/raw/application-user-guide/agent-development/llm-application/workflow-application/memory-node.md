# 记忆库节点

在工作流中对记忆库执行记忆的增加和检索，支持从对话中提取记忆或直接写入。

## 功能说明

通过该节点，工作流可以在执行过程中将关键信息沉淀到记忆库，或在后续流程中检索历史记忆作为上下文。
