# 连接的账户

在一个 App 下管理多个连接：新增、改名、查看详情、删除。

连接建好之后，都归集在 App 详情页的 **已连接的用户** 区域，可以在这里新增、改名、查看详情和删除。

## 找到已有连接

在 **Apps** 页面单击一个 App 卡片进入详情页。页面分两块：

区域

内容

已连接的用户（N）

该 App 下的全部连接，N 是数量

可用的工具

该 App 生成的工具及各自的入参出参

每张连接卡片显示名称、状态和创建时间，例如已连接、创建时间：2026-08-25 14:40:32。

## 同一个 App 连多个账号

一个 App 下可以建多个连接，互不干扰。常见用法：

场景

例子

环境隔离

一个 MySQL 连接指向测试库，另一个指向生产库

内容分区

一个文件连接器放产品文档，另一个放内部制度

账号区分

一个语雀连接用团队账号，另一个用个人账号

权限分级

一个连接只读，另一个可写

单击 **已连接的用户** 区域的 **连接新用户** 卡片即可再建一个。流程和第一次连接完全相同。

**说明**需要身份验证配置的 App，多个连接可以共用同一个配置，也可以各用一个。用不同配置的典型场景是两个账号的凭证不同。

## 改名

连接名称是区分同类连接的主要依据，建好之后随时可以改。

单击连接名称右侧的编辑图标，名称变为可编辑状态，改完确认即可。输入框右下角有字数计数，上限 64 个字符。

**重要**名称写得具体一点。产品文档库比连接器1有用得多，尤其是同一个 App 下有好几个连接的时候。

## 查看详情

把鼠标移到连接卡片上，卡片下方出现 **详情** 与 **删除** 两个按钮。单击 **详情** 查看这个连接的完整信息。

**说明**这两个按钮只在鼠标悬停时出现，卡片静止状态下看不到。

## 删除

1.  **悬停卡片**：把鼠标移到要删除的连接卡片上，等按钮出现。
2.  **单击删除**：单击 **删除**。控制台弹出确认框，标题是删除已关联的账户，提示为此操作将永久断开该账户的连接。您稍后可以重新连接，但现有的任何配置可能会丢失。
3.  **确认**：确认无误后单击弹窗中的 **删除**。删除成功后连接从列表中消失。要取消操作，单击 **取消**。

**警告**删除不可撤销。连接删除后，依赖它的智能体和客户端会立刻失去对应工具，正在运行的任务可能报错。生产环境操作前先确认没有正在使用这个连接的任务。

删除连接不会删除它使用的身份验证配置，配置仍留在 **身份验证配置** 列表中，可以给新连接复用。

## 状态与失效

状态

含义

处理

已连接

凭证有效，工具可用

无需处理

已过期

凭证失效，工具调用会失败

更新身份验证配置中的凭证，然后重建连接

凭证失效的常见原因是对方系统里的 Token 过期、密钥被轮转，或 OAuth 应用被停用。排查思路见[OAuth 2.0 配置](raw/application-user-guide/overview/auth-guide/oauth.md)与[API Key 配置](raw/application-user-guide/overview/auth-guide/api-key.md)。
