# 腾讯文档

通过腾讯文档的授权窗口连接腾讯文档，让智能体读取、创建和编辑你的在线文档。

腾讯文档连接后，智能体可以访问你的腾讯文档，覆盖文档的读取、创建编辑和管理。

连接过程不需要身份验证配置，也不需要你准备任何凭证。单击 **连接** 后浏览器会打开腾讯文档的授权窗口，登录并同意授权即可。

## 连接前准备

只要一个条件：浏览器能正常访问腾讯文档（`docs.qq.com`）。授权在腾讯文档侧完成，需要登录你的腾讯文档账号（QQ 或微信）。

**说明**授权用的是授权窗口里登录的腾讯文档账号。要用别的账号连接，先在授权窗口里切换登录状态。

## 连接步骤

1.  **打开连接**：在控制台左侧导航单击 **Apps**，找到 **腾讯文档** 卡片，单击 **连接**。
    
2.  **在授权窗口中确认**：浏览器会**新开一个独立窗口**，地址在 `docs.qq.com`。这是腾讯文档的授权页面，按页面提示登录并确认授权。
    
    页面申请的权限对应文档的读取、创建编辑和管理，以授权页实际显示为准。
    
    **警告**如果没有看到这个窗口，先检查浏览器是否拦截了弹窗。允许该站点弹窗后重新单击 **连接**。
    
    授权窗口被关闭或未完成授权时，控制台会提示 **「腾讯文档」授权窗口已关闭，请重试**，重新单击 **连接** 即可。
    
3.  **完成授权**：在授权窗口中同意授权。窗口关闭后回到 App 详情页，**已连接的用户** 区域会出现一个新连接，状态为 **已连接**。
    

## 自动生成的工具

连接成功后自动生成一批腾讯文档相关的工具，在 App 详情页的 **可用的工具** 区域查看。能力范围与授权范围一致，覆盖文档的读取、创建编辑和管理，具体工具列表以页面显示为准。

## 多个账号

同一个腾讯文档 App 下可以建多个连接。需要用其他腾讯文档账号连接时，在授权窗口中切换登录账号，再单击 **连接新用户** 走一遍授权，用连接名称区分。

管理方式见[连接的账户](raw/application-user-guide/overview/auth-guide/connected-accounts.md)。

## 撤销授权

在 Connector 控制台删除连接只是删掉这一侧的连接记录，删除后平台不再持有可用的授权。授权关系本身由腾讯文档账号侧维护。

## 排查

现象

常见原因

单击连接后没有任何反应

浏览器拦截了弹窗，允许弹窗后重试

提示「腾讯文档」授权窗口已关闭，请重试

授权窗口被中途关闭或未完成授权，重新单击 **连接** 并走完全部授权步骤

授权窗口打不开或一直加载

当前网络无法访问 `docs.qq.com`（例如办公网拦截），更换网络环境后重试

连接显示已过期

授权已在腾讯文档侧失效或被撤销，重新走一遍授权流程

工具调用提示无权限

该腾讯文档账号对目标文档没有访问权限，在腾讯文档侧调整文档权限

**重要**腾讯文档不需要准备任何凭证，授权窗口里确认即可，流程和[云效](raw/application-user-guide/overview/apps-guide/yunxiao.md)类似。
