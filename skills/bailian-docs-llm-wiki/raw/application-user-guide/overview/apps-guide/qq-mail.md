# QQ邮箱

用邮箱地址和授权码连接 QQ 邮箱，让智能体通过 IMAP/SMTP 协议访问邮件。

QQ 邮箱连接后，智能体可以通过 IMAP/SMTP 协议访问你的邮箱，处理邮件数据。

连接过程不需要身份验证配置。连接对话框里只有两个字段：**邮箱地址** 和 **授权码**。

## 连接前准备

授权码不是 QQ 密码，而是 QQ 邮箱为第三方客户端单独签发的凭证。获取路径：

1.  登录 [QQ 邮箱网页版](https://mail.qq.com)，进入 **设置** → **账号与安全** → **安全设置**。
2.  开启 **IMAP/SMTP 服务**。
3.  单击 **生成授权码**，按提示完成扫码或密码验证，复制生成的授权码。

详细说明见 QQ 邮箱官方帮助：[如何生成授权码，在第三方客户端使用 POP/IMAP/SMTP 等协议登录](https://help.mail.qq.com/detail/106/985)。

**警告**授权码等同于密码，不要泄露。修改 QQ 密码后已生成的授权码会失效，需要重新生成并用新授权码重建连接。

## 连接步骤

1.  **打开连接对话框**：在控制台左侧导航单击 **Apps**，找到 **QQ邮箱** 卡片，单击 **连接**。对话框标题是 **连接App**，认证区显示 **QQ邮箱认证**，并注明：邮箱地址和授权码将被加密存储，仅用于建立邮件连接。
2.  **填写邮箱地址**：填入完整的 QQ 邮箱地址，形如 `yourname@qq.com`。必填。
3.  **填写授权码**：填入上一步在 QQ 邮箱设置中生成的授权码。该字段为密码框，输入内容不回显。必填。
4.  **提交**：单击 **提交**。注意这里的按钮是 **提交**，不是需要身份验证配置的 App 的 **确认**。

对话框里没有连接器名称和描述字段，连接名称由平台生成，可以在连接建成后改名。

## 自动生成的工具

连接成功后自动生成邮件相关的工具，在 App 详情页的 **可用的工具** 区域查看，具体工具列表以页面显示为准。

## 多个账号

同一个 QQ邮箱 App 下可以建多个连接，每个连接对应一个邮箱账号及其授权码。连接多个邮箱时，分别生成授权码并各建一个连接，用连接名称区分。

管理方式见[连接的账户](raw/application-user-guide/overview/auth-guide/connected-accounts.md)。

## 凭证安全

-   授权码和邮箱地址由平台加密存储，仅用于建立邮件连接。
-   不要把授权码贴到聊天群、代码仓库或工单里。
-   授权码泄露后，在 QQ 邮箱的 **安全设置** 中重新生成授权码，再用新授权码重建连接。

## 排查

现象

常见原因

提交后提示认证失败

授权码错误、多余空格，或授权码已失效（修改 QQ 密码后旧授权码失效），重新生成后再试

提示邮箱地址不正确

没有填完整地址，需要包含 `@qq.com` 后缀

连接建成但读不到邮件

QQ 邮箱的 IMAP/SMTP 服务未开启或被关闭，在 **安全设置** 中确认服务状态

原本可用的连接突然失效

授权码被重新生成或 QQ 密码被修改，用当前有效的授权码重建连接

**重要**授权码是一次性展示的凭证，生成后建议立即完成连接，避免临时存放带来泄露风险。
