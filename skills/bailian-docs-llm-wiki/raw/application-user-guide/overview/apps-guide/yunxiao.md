# 云效

通过云效的授权确认窗口连接云效，让智能体读取 Codeup 代码库、分支、提交与合并请求。

云效连接后，智能体可以读取云效组织下的 Codeup 代码库、分支、文件、提交和合并请求。

连接过程不需要身份验证配置，也不需要你准备任何凭证。单击 **连接** 后云效会弹出授权确认窗口，同意授权即可。

## 连接前准备

只要一个条件：当前浏览器已登录云效，且该账号在目标云效组织内有访问权限。

**说明**授权用的是你当前登录的云效账号。要用别的账号连接，先在浏览器里切换云效登录状态。

## 连接步骤

1.  **打开连接**：在控制台左侧导航单击 **Apps**，找到 **云效** 卡片，单击 **连接**。
    
2.  **在授权窗口中确认**：浏览器会**新开一个独立窗口**，标题是 **授权确认**，地址在 `account-devops.aliyun.com`。
    
    窗口里显示请求方是 `bailian-connector-runtime`，下面是你当前的云效账号，以及它要申请的两项权限：
    
    权限
    
    含义
    
    访问你的云效账号基本信息
    
    读取账号标识，用于建立连接归属
    
    代表你调用云效开放接口
    
    后续工具调用以你的身份访问云效数据
    
    **警告**如果没有看到这个窗口，先检查浏览器是否拦截了弹窗。允许该站点弹窗后重新单击 **连接**。
    
3.  **同意授权**：单击 **同意授权**。窗口关闭后回到 App 详情页，**已连接的用户** 区域会出现一个新连接，状态为 **已连接**。
    
    连接名称由平台自动生成，形如 `YUNXIAO-9475`，可以单击名称旁的铅笔图标改名。
    

## 自动生成的工具

连接成功后自动生成一批 Codeup 相关的工具，在 App 详情页的 **可用的工具** 区域查看。覆盖的能力包括：

类别

能做什么

代码库

列出代码库、查看代码库详情

分支

列出分支、查看分支详情、创建分支

文件

列出文件树、读取文件内容

提交

列出提交、查看提交详情、比较两个引用的差异

合并请求

列出与查看合并请求、查看版本列表与评论

单击工具下方的 **展开** 可以看到该工具的入参说明。工具描述里通常写明了调用顺序上的注意事项，例如读取文件内容前要先确认分支名。

## 多个账号

同一个云效 App 下可以建多个连接。需要用不同账号或访问不同云效组织时，先在浏览器切换云效登录状态，再单击 **连接新用户** 走一遍授权，用连接名称区分。

管理方式见[连接的账户](raw/application-user-guide/overview/auth-guide/connected-accounts.md)。

## 撤销授权

在 Connector 控制台删除连接只是删掉这一侧的连接记录。要彻底收回授权，还需要去云效的个人设置里撤销 `bailian-connector-runtime` 的访问权限。

**说明**授权窗口底部也写明了这一点：授权后你可以随时在云效个人设置中撤销此应用的访问权限。

## 排查

现象

常见原因

单击连接后没有任何反应

浏览器拦截了弹窗，允许弹窗后重试

授权窗口提示账号无权限

当前云效账号不在目标组织内，或组织管理员限制了第三方应用授权

连接显示已过期

授权已在云效侧被撤销，重新走一遍授权流程

工具能列出代码库但读不到文件

该账号对目标代码库只有部分权限，在云效侧补齐后重试

**重要**云效是少数完全不需要准备凭证的 App，适合用来第一次体验 OAuth 类连接的流程。
