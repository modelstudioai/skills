# 网易邮箱

用邮箱地址和授权码连接网易 163 邮箱，让智能体通过 IMAP/SMTP 协议访问邮件。

网易邮箱连接后，智能体可以通过 IMAP/SMTP 协议访问你的邮箱，处理邮件数据。

连接过程不需要身份验证配置。连接对话框里只有两个字段：**邮箱地址** 和 **授权码**。

## 连接前准备

授权码不是邮箱登录密码，而是网易邮箱为第三方客户端单独签发的凭证。获取路径：

1.  登录 [163 邮箱网页版](https://mail.163.com)，进入 **设置** → **POP3/SMTP/IMAP**。
2.  开启 **IMAP/SMTP 服务**。
3.  单击 **新增授权密码**，按提示完成验证，复制生成的授权码。

详细说明见网易邮箱官方帮助：[如何新增授权码](https://help.mail.163.com/faqDetail.do?code=d7a5dc8471cd0c0e8b4b8f4f8e49998b374173cfe9171305fa1ce630d7f67ac286624f309a1a7089)。

**警告**授权码**只显示一次**，生成后立即复制保存。授权码等同于密码，不要泄露。

## 连接步骤

1.  **打开连接对话框**：在控制台左侧导航单击 **Apps**，找到 **网易邮箱** 卡片，单击 **连接**。对话框标题是 **连接App**，认证区显示 **163邮箱认证**，并注明：邮箱地址和授权码将被加密存储，仅用于建立邮件连接。
2.  **填写邮箱地址**：填入完整的 163 邮箱地址，形如 `yourname@163.com`。必填。
3.  **填写授权码**：填入上一步在网易邮箱设置中生成的授权码。该字段为密码框，输入内容不回显。必填。
4.  **提交**：单击 **提交**。注意这里的按钮是 **提交**，不是需要身份验证配置的 App 的 **确认**。

对话框里没有连接器名称和描述字段，连接名称由平台生成，可以在连接建成后改名。

## 自动生成的工具

连接成功后自动生成邮件相关的工具，在 App 详情页的 **可用的工具** 区域查看，具体工具列表以页面显示为准。

## 多个账号

同一个网易邮箱 App 下可以建多个连接，每个连接对应一个邮箱账号及其授权码。连接多个邮箱时，分别生成授权码并各建一个连接，用连接名称区分。

管理方式见[连接的账户](raw/application-user-guide/overview/auth-guide/connected-accounts.md)。

## 凭证安全

-   授权码和邮箱地址由平台加密存储，仅用于建立邮件连接。
-   不要把授权码贴到聊天群、代码仓库或工单里。
-   授权码泄露后，在网易邮箱的 **POP3/SMTP/IMAP** 设置中停用旧授权码并新增一个，再用新授权码重建连接。

## 排查

现象

常见原因

提交后提示认证失败

授权码错误、多余空格，或授权码已被停用，重新新增授权码后再试

提示邮箱地址不正确

没有填完整地址，需要包含 `@163.com` 后缀

连接建成但读不到邮件

网易邮箱的 IMAP/SMTP 服务未开启或被关闭，在 **POP3/SMTP/IMAP** 设置中确认服务状态

原本可用的连接突然失效

授权码被停用或重置，用当前有效的授权码重建连接

**重要**授权码只在生成时显示一次，建议生成后立即完成连接，避免临时存放带来泄露风险。
