# 表格连接器

托管 XLSX、XLS 等结构化表格数据，供智能体查询表结构与内容。

表格连接器用于管理结构化的表格数据。表格导入后由平台解析，智能体通过自动生成的工具获取表结构，再据此查询数据。

和文件连接器一样，它不需要外部系统的凭证。

## 创建连接器

1.  **打开连接对话框**：在 **Apps** 页面找到 **表格连接器** 卡片，单击 **连接**。
    
2.  **填写基本信息**：
    
    字段
    
    是否必填
    
    说明
    
    连接器名称
    
    是
    
    使用易于识别的名称，最多 64 个字符
    
    连接器描述
    
    否
    
    说明表格内容与用途，例如月度销售报表与客户台账
    
3.  **确认存储位置**：**存储位置** 目前只有 **使用平台存储** 一个选项，选中即可。数据存储在阿里云百炼平台提供的存储空间中，提供最大 200,000 个文件、1 TB 存储额度，限时免费，详见[配额与限制](raw/application-user-guide/overview/overview/limits.md)。
    
4.  **确认创建**：单击 **确认**。创建后连接器类型不可更改。
    

## 自动生成的工具

连接器创建成功后自动生成 1 个工具：

工具

功能

入参

获取表结构

按表文件的 ID 获取表文件的 schema 信息

`tableId`（string）：表文件的 ID  
`fuzzyTableName`（string）：表的名称，支持模糊查询

两个入参均非必填。知道具体表 ID 时传 `tableId`；只记得表名或需要按名称查找时传 `fuzzyTableName`。

**说明**获取表结构返回的是字段定义，不是表中的数据行。智能体通常先用它了解表有哪些字段，再决定后续如何查询。

## 支持的表格格式

支持 XLSX 和 XLS 格式。

**警告**不支持直接导入 CSV、JSON、YAML 格式。请先用 Excel 或其他工具转换为 XLSX 或 XLS，再导入。

## 导入数据

表格同样通过类目组织，导入方式与文件一致，见文件连接器页的[类目](https://help.aliyun.com/zh/model-studio/connector/apps/file#%E7%B1%BB%E7%9B%AE)与[导入数据](https://help.aliyun.com/zh/model-studio/connector/apps/file#%E5%AF%BC%E5%85%A5%E6%95%B0%E6%8D%AE)。
