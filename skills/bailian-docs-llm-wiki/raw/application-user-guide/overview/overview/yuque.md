# 语雀

通过 API Key 身份验证配置连接语雀，让智能体访问语雀文档与知识库。

语雀连接器让智能体访问语雀中的文档和知识库。数据保留在语雀，调用时实时读取。

语雀是目前唯一使用 API Key 身份验证的 App，不需要在语雀侧注册应用，只要一个 Token。

## 前置条件

-   已有语雀知识库，且使用的是公网版本语雀。
-   一个语雀会员账户。创建个人访问令牌需要会员权益。
-   该账号具备目标知识库的访问权限。

**说明**Token 的权限等级决定 Connector 能读到哪些内容。只需要读取时，不要勾选写入权限。

## 连接步骤

语雀分两步：先建身份验证配置，再用它创建连接。

1.  **获取语雀 Token**：用语雀会员账户打开[个人设置的 Token 页面](https://www.yuque.com/settings/tokens)，创建个人访问令牌并复制保存。令牌只在创建时完整展示一次。详细路径见[API Key 配置](raw/application-user-guide/overview/overview/api-key.md)。
    
2.  **创建身份验证配置**：在控制台左侧导航单击 **身份验证配置**，单击 **创建身份验证配置**。
    
    第一步选择 **语雀**，它的身份验证方法显示为 API Key，单击 **下一步**。
    
    第二步页面提示请输入您的语雀 API Key：
    
    字段
    
    是否必填
    
    说明
    
    配置名称
    
    否
    
    区分同一 App 下的多个配置
    
    API Key
    
    是
    
    上一步复制的语雀 Token
    
    单击 **完成** 保存。
    
3.  **打开连接对话框**：在 **Apps** 页面找到 **语雀** 卡片，单击 **连接**。对话框提示身份认证定义用户如何在当前 App 创建连接，支持认证方式和凭证选择。
    
4.  **选择配置并确定**：在 **选择身份验证配置** 下拉框中选中刚创建的配置，单击 **确定** 完成连接。连接出现在 App 详情页的 **已连接的用户** 区域。
    

**重要**也可以跳过第 2 步单独操作：在连接对话框里展开 **选择身份验证配置**，显示暂无配置时单击下方的 **创建身份验证配置**，控制台会打开创建页面并预先选中语雀。

## 自动生成的工具

连接成功后，Connector 会生成访问语雀内容的工具。在 App 详情页的 **可用的工具** 区域展开工具即可查看实际的入参与出参。

## Token 过期与轮转

语雀 Token 失效后，连接器状态会变为已过期，工具调用随之失败。

处理方式：在语雀重新生成 Token，新建一个身份验证配置填入新值，用新配置重建连接，确认可用后删除旧连接。

## 多个知识库或多个账号

同一个语雀身份验证配置可以支撑多个连接。需要用不同账号访问不同知识库时，为每个账号建一个身份验证配置，再各建一个连接，用连接名称区分。

管理方式见[连接的账户](raw/application-user-guide/overview/overview/connected-accounts.md)。
