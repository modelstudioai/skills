# 数据库

连接 MySQL、PostgreSQL、PolarDB-X 2.0，让智能体实时查询业务数据。

数据库连接器让智能体实时查询业务数据。数据保留在原数据库中，不会复制到平台。

Connector 支持三种数据库：

App

MySQL

## 前置条件

三种数据库的公共要求：

-   已有数据库实例，且网络可达，公网或私网均可。
-   已在 DMS 中完成该实例的录入。

各自的额外要求：

App

额外要求

MySQL

无

PostgreSQL

`wal_level` 参数设置为 `logical`

PolarDB-X 2.0

实例所在地域支持私网访问

**说明**建议为 Connector 单独创建一个只读数据库账号，只授予需要访问的库表权限。

## 连接步骤

1.  **在 DMS 中录入数据源**：先在 DMS 中完成数据库实例的录入。DMS 统一管理各类数据源，Connector 从 DMS 读取已有配置，不需要你在 Connector 里重复填写连接串和密码。
    
2.  **打开连接对话框**：在 **Apps** 页面找到目标数据库卡片，例如 **MySQL**，单击 **连接**。
    
3.  **填写基本信息**：
    
    字段
    
    是否必填
    
    说明
    
    连接器名称
    
    是
    
    使用易于识别的名称，最多 64 个字符。建议标明环境，例如 `订单库-生产`
    
    连接器描述
    
    否
    
    说明库里有什么数据、适合回答什么问题
    
4.  **选择数据来源**：在 **选择数据来源** 中选择 **从 DMS 导入数据源**，然后选中上一步录入的数据源。
    
    首次选择这一项时会弹出 **SLR授权** 页面，要求开通两个服务关联角色：
    
    角色
    
    角色名称
    
    权限策略
    
    用途
    
    RDS 服务管理角色
    
    `AliyunServiceRoleForSFMAccessRDS`
    
    `AliyunServiceRolePolicyForSFMAccessRDS`
    
    允许阿里云百炼平台访问你的 RDS 信息，查询 RDS for MySQL 列表和网络信息
    
    DMS 服务管理角色
    
    `AliyunServiceRoleForAccessDMS`
    
    `AliyunServiceRolePolicyForAccessDMS`
    
    允许阿里云百炼平台访问你 DMS 中的实例信息，查询你在 DMS 中配置的实例信息
    
    ![数据库连接的 SLR 授权页面](https://img.alicdn.com/imgextra/i3/O1CN01k32bmv9BDIK238uC_!!6000000003065-2-tps-1010-882.png)
    
    开通过之后不会再次弹出，回到对话框继续选择数据源即可。
    
5.  **选择数据源**：在 **选择数据源** 区域从 DMS 的数据库列表中选中目标实例。这是必填项。
    
    界面说明：从 DMS 数据库列表中选择合适的数据源导入，DMS 来源的数据源连通性由 DMS 侧保障，每次导入仅支持选择 1 个数据源。
    
    列表是单选的，列出 **实例名称**、**类型**、**实例来源**、**状态** 四列，上方搜索框的提示是请输入实例名称进行搜索。
    
    **说明**列表显示暂无数据，说明当前账号在 DMS 里还没有可用的实例。先回到 DMS 完成录入，再回来刷新。
    
6.  **填写数据库地址与端口**：
    
    字段

    示例
    
    数据库地址
    
    是
    
    `rm-b16***3i.mysql.rds.aliyuncs.com`
    
    数据库端口
    
    是
    
    `3306`
    
7.  **确认创建**：单击 **确认** 完成连接。
    

**说明**执行 SQL 查询的能力仅在通过 DMS 导入数据源的方式下支持。

## 自动生成的工具

连接成功后，Connector 会生成查询数据库的工具。在 App 详情页的 **可用的工具** 区域展开工具即可查看实际的入参与出参。

工具通常先返回表结构，智能体据此构造查询。把库表和字段命名写得清楚，能显著提升智能体生成正确查询的概率。

## 常见问题

### 提示数据库配置校验不通过，表数据量较大

目标表的数据量超出校验阈值。缩小同步或查询范围，例如只选择必要的表，或对大表做分区、限定时间范围。

### 创建数据源时报 CHECK\_BINLOG\_FORMAT、CHECK\_ENFORCE\_GTID\_MODE 或 CHECK\_GTID\_CONSISTENCY

MySQL 实例的 binlog 相关参数不满足要求。按报错指向的参数逐项调整实例配置后重试。

### 私网数据源支持哪些地域

私网访问对 RDS 与 ECS 实例所在地域有要求。连接前确认实例地域在支持范围内，否则改用公网访问。

### RAM 用户如何开通所需的服务关联角色

RAM 用户需要主账号预先授予相应权限，才能完成服务关联角色的开通。由主账号在 RAM 控制台为该用户补齐权限后重试。
