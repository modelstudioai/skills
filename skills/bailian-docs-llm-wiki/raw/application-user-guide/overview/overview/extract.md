# 使用字段抽取控制台

在 ParseX 控制台中准备文档、定义字段、运行抽取、核验结果并保存配置。

通过字段抽取控制台，您可以从文件或已有解析结果开始，调整抽取设置，完成一次字段抽取。

1.  **进入抽取工作区**
    
    打开 [ParseX](https://bailian.console.aliyun.com/cn-beijing/parsex/document-parse)，登录后选择左侧「字段抽取」。工作区包括选择输入文档、设置字段以及查看结果，您可以在同一页面完成一次体验。
    
    ![](https://g-adoc.alcasset.com/media/maas_docs/sfm-cn/common/images/6a4b3c2d1e0f9db4.png)
    
    **工作区**
    
    **用途**
    
    文件区域
    
    选择材料并预览原文
    
    配置区域
    
    定义字段和本次抽取要求
    
    结果区域
    
    任务完成后，查看抽取结果
    
2.  **选择材料**
    
    在输入区域上传文件，或选择内置样例，或者已经解析处理成功的文档。
    
    **材料来源**
    
    **操作**
    
    本地文件
    
    在文件区域上传图文材料，检查文件名称和预览内容
    
    内置样例
    
    选择样例，检查所选材料
    
    已有解析结果
    
    打开**选择已完成的任务列表**，找到目标图文解析任务并选择
    
3.  **设置抽取要求**
    
    1.  在**字段结构**中填写需要字段抽取的信息。
    2.  按[配置信息抽取](raw/application-user-guide/overview/overview/configuration.md)检查字段名称、类型和说明。
    3.  检查抽取设置与补充要求。
    
    已有合适配置时，按[保存与复用配置](raw/application-user-guide/overview/configurations.md)中的方法进入测试并复用。
    
4.  **提交解析**
    
    1.  确认材料与字段要求对应。
    2.  点击「运行字段抽取」，提交任务。
    3.  等待任务完成，在结果区打开**抽取字段详情**或**抽取结果 JSON**。
    
    ![](https://g-adoc.alcasset.com/media/maas_docs/sfm-cn/common/images/6a4b3c2d1e0f9dcb.png)
    
5.  **查看结果并完成验证**
    
    检查要抽取的关键字段是否正确。修改字段结构、说明或输入后，需要重新运行，才能检查新要求对应的结果。
    
6.  **返回历史结果**
    
    进入[任务记录](raw/application-user-guide/overview/configurations/tasks.md)，找到对应抽取任务，查看详情并从结果入口返回查看。
