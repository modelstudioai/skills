# 用量

查看 ParseX 异步任务的公开状态，以及控制台中的任务记录与用量信息。

用量页展示指定时间内的任务数量和处理量，帮助你了解 Agent 应用主要使用了哪些能力，以及每天的使用变化。

## 使用前准备

-   确定需要查看的日期范围。
-   登录 [ParseX 控制台](https://bailian.console.aliyun.com/cn-beijing/parsex/document-parse)，从左侧进入「用量」。

![](https://g-adoc.alcasset.com/media/maas_docs/sfm-cn/common/images/6a4b3c2d1e0f9ddd.png)

_图：从左侧进入「用量」，选择日期范围后查看汇总数据_

## 查看一段时间的使用情况

1.  选择开始日期和结束日期。
2.  查看顶部总览，了解任务数量和总体处理量。
3.  查看分类汇总，找到主要使用的能力和输入类型。
4.  查看每日明细，找到使用变化明显的日期。
5.  需要追查具体文件时，在[任务记录](raw/application-user-guide/overview/configurations/tasks.md)中按对应日期和能力查找。

## 读懂总览指标

**指标**

**含义**

已完成任务

已结束处理的任务数量，包括成功和失败任务

处理成功任务

成功完成处理的任务数量

图文处理页数

图文处理量，分为解析页数和抽取页数

音视频处理秒数

音视频处理时长，分为音频秒数和视频秒数

任务数量表示处理了多少次，页数或秒数表示处理了多少内容。比较使用量时，应分别比较相同单位的数据。

## 查看分类汇总

**分类**

**可以回答的问题**

能力

用量来自文档解析还是字段抽取？

输入类型

主要处理图文、已解析结果、音频还是视频？

处理方式

这些任务使用了哪种处理方式？

单位和数量

各类处理量是多少？

解析页数和抽取页数分别记录两类处理。同一份材料用于两种能力时，应分别查看对应行，不能把两项相加当作上传文件的总页数。

## 查看每日明细

![](https://g-adoc.alcasset.com/media/maas_docs/sfm-cn/zh/images/6a4b3c2d1e0f9dde.png)

_图：按日期查看调用、任务完成及各类处理量。_

**明细内容**

**用途**

调用数、完成任务数

观察每日调用与任务完成情况

解析页数、抽取页数

观察图文处理量变化

音频秒数、视频秒数

观察音视频处理时长变化

例如，发现某天抽取页数明显增加，可以到任务记录中筛选当天的抽取任务，核对新增文件和单次处理量。

完成后，你应能确定主要用量来源和需要进一步检查的日期。费用计算规则见[计量与计费](raw/application-user-guide/overview/configurations/pricing.md)。
