# 插件节点

在工作流中接入插件工具，通过配置插件参数调用外部服务能力，支持配置官方和自定义插件。

## 使用示例

以下工作流接入了一个计算器插件，获取表达式的计算结果，传递给后续节点。

## 接入节点

-   将鼠标悬停在画布上的上游节点（如开始节点）上，节点右侧会出现 + 按钮。
    
-   点击 + 按钮，在弹出的节点列表中选择插件节点。
    
-   在弹出的对话框中，在目标插件中添加需要的工具，每个节点仅可添加一个工具。
    
-   单击确定，节点将自动添加到画布并与上游节点建立连线。
    

## 核心配置

### 工具选择

配置面板顶部显示当前选择的工具名称，右侧开关按钮用于切换插件。切换插件会重新加载该插件的工具和参数，原有配置可能会丢失。

### 输入参数

输入参数会根据选择的插件自动变化。

列名

说明

变量名

参数名称，由插件定义，不可修改。

参数值的来源方式，支持直接输入或通过输入/插入变量引用上游节点的输出。

参数的具体值或引用的变量。

您可以前往组件广场或自定义插件页面，单击插件卡片，查看对应工具的输入参数格式。

### 失败时重试

默认关闭。开启后，节点运行超时或异常时会自动重试。关闭时，节点失败将直接报错。

### 异常处理

默认关闭。开启后，若发生错误，本节点将依据配置执行自定义的处理逻辑。

## 节点输出

不同插件的输出变量不同。选择插件后，输出变量自动加载。您可以前往组件广场或自定义插件页面，单击插件卡片，查看对应工具的输出参数格式。

## 常见问题

### 如何切换插件下的不同工具？

插件节点一次只能接入一个工具。如果需要使用同一插件的不同工具，需要添加多个插件节点，每个节点选择不同的工具。
