# 智能体创建节点

当工作流中需要一个具备对话能力、能调用知识库或插件的智能体来处理任务时，智能体创建节点通过配置模型、Prompt、知识库和插件，在工作流内动态创建一个智能体来处理输入并返回结果。该智能体仅在工作流运行期间存在，不会创建为独立的智能体应用。

## 使用示例

通过智能体创建节点创建一个翻译智能体，将中文翻译为英文后输出。

## 接入节点

### 方法1：使用+按钮添加

-   将鼠标悬停在画布上任意节点上（如开始节点），节点右侧自动显示 + 按钮。
    
-   点击 + 按钮，在弹出的节点列表中选择智能体智能体创建，节点将自动添加到画布并与上游节点建立连线。
    

### 方法2：从节点库拖拽添加

-   在左侧节点库中选择智能体智能体创建。
    
-   拖拽节点到画布合适位置，从上游节点边缘拖拽连线到节点。
    

## 核心配置

### 输入

指定智能体需要处理的内容，通过引用上游节点的输出变量将数据传递给智能体。

### 智能体名称

为智能体设置标识名称，便于在多智能体场景中区分不同智能体的职责。

### 模型配置

#### 模型选择

从模型选择器下拉列表中选择要使用的大模型，如千问系列模型。如果下拉列表中没有目标模型，点击更多模型，在弹出的模型选择对话框中查找并选择目标模型。

### Prompt

即系统提示词，是控制智能体行为的核心手段。通过 Prompt 可以指定智能体的专业领域（如“你是翻译助手”）、输出格式要求（如“只输出 JSON”）、行为约束（如“不要编造信息”）等，使同一模型在不同场景下表现出不同的专业能力。

平台提供 Prompt 优化 功能，可以自动优化 Prompt 内容以提升效果。

### 知识库

为智能体接入知识库，使其能够基于特定知识回答问题，适用于需要领域专业知识的场景。

### 插件

通过调用插件，可完成代码执行、网络搜索、基于文本生成图片等具体任务。支持添加百炼官方插件，同时也支持添加自定义插件

## 常见问题

### 智能体创建节点创建的智能体在哪里？

智能体创建节点创建的智能体仅在当前工作流运行期间存在，不会创建为独立的智能体应用。

### 智能体创建节点和大模型节点有什么区别？

智能体创建节点内置了工具调用能力——可以配置知识库和插件，使其能够检索知识和使用外部工具。大模型节点专注于文本生成和处理，不支持直接调用插件。如果任务只需要文本处理，使用大模型节点更轻量；如果需要知识库检索或工具调用，使用智能体创建节点。
