# 脚本节点

脚本节点用于在工作流中执行自定义代码逻辑，通过编写 JavaScript 或 Python 代码处理输入数据并返回结果。适用于数据转换、格式处理、复杂计算、业务逻辑处理等场景。

## 接入节点

### 方法1：使用+按钮添加

-   将鼠标悬停在画布上任意节点上（如开始节点），节点右侧自动显示 + 按钮。
    
-   点击 + 按钮，在弹出的节点列表中选择逻辑脚本，节点将自动添加到画布并与上游节点建立连线。
    

### 方法2：从节点库拖拽添加

-   在左侧节点库中选择逻辑脚本。
    
-   拖拽节点到画布合适位置，从上游节点边缘拖拽连线到节点。
    

## 核心配置

### 输入

定义脚本节点需要处理的输入变量。点击添加变量可以添加输入参数，每个输入参数包含以下配置：

参数

说明

变量名

输入变量的名称，用于在代码中引用。

引用方式

输入：直接输入固定值；引用：引用上游节点的输出变量。

值

输入变量的值。选择"输入"时直接输入固定值；选择"引用"时，在输入框中输入 / 可触发变量选择，支持引用上游节点的输出变量。

### 代码

编写核心逻辑代码，支持 JavaScript 和 Python 两种语言。

语言

说明

JavaScript

支持 V8 引擎，兼容 ECMAScript 2022 语法。默认选择。

Python

支持 Python 标准库，适用于数据处理和计算。

### 失败时重试

默认关闭。节点运行超时或异常时自动重试。关闭后，节点失败将直接报错。

参数

范围

默认值

说明

最大重试次数

1-10

3

请求失败时的最大重试次数。

重试间隔

300-10000 毫秒

500

每次重试之间的等待时间。

### 异常处理

默认关闭。开启后，节点发生异常时将执行自定义的处理逻辑。

处理方式

说明

默认值

发生异常时输出指定内容。需要配置默认返回值，格式为合法的 JSON 格式。

异常分支

当发生异常时，执行异常分支。选择此方式后，节点会自动创建异常分支，需要为异常分支配置处理流程。

## 节点输出

代码中 return 的字典将作为本节点的输出。输出变量需要在配置面板中手动定义。单击添加变量可以添加输出变量，每个输出变量包含以下配置：

参数

说明

变量名

输出变量的名称，必须与代码中 return 对象的键名完全一致。

类型

输出变量的数据类型，如 Number、String 等。
