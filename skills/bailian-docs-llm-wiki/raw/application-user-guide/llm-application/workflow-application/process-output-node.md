# 流程输出节点

流程输出节点用于在工作流执行过程中的任意位置输出指定的内容，非工作流执行完毕后的最终输出结果。

## 适用场景

-   避免等待：在耗时操作（如调用API、复杂计算）前输出提示信息。
    
-   分段输出：当输出内容较多时，将内容拆分为流程输出和结束节点两部分分步展示。
    
-   调试排查：在开发阶段插入关键路径，输出变量值或流程状态，便于跟踪执行过程。
    

## 使用示例

以下示例展示了在大模型处理前插入流程输出节点，避免长时间等待无响应。

## 节点接入

### 方法1：使用+按钮添加

-   将鼠标悬停在画布上任意节点上（如开始节点），节点右侧自动显示 + 按钮。
    
-   点击 + 按钮，在弹出的节点列表中选择工具流程输出，节点将自动添加到画布并与上游节点建立连线。
    

### 方法2：从节点库拖拽添加

-   在左侧节点库中选择工具流程输出。
    
-   拖拽节点到画布合适位置，从上游节点边缘拖拽连线到节点。
    

## 核心配置

### 输出内容

在文本框中输入要输出的内容，支持以下两种方式：

配置方式

说明

输入固定文本

直接输入要显示的文本内容，在文本框中输入文本，如”正在加载数据，请稍候...”

引用变量

引用上游节点的输出变量。

### 流式输出

默认开启。开启后，生成内容将会逐字流式输出在对话中；关闭后，回复内容将全部生成后一次性输出。

## 节点输出

输出内容中配置的文本或变量的实际值，可作为变量被下游节点引用。

## 常见问题

### 流程输出节点和结束节点有什么区别？

流程输出节点用于在工作流执行过程中输出中间信息，可以插入在工作流的任意位置，且可以添加多个。结束节点用于输出工作流的最终结果，每个工作流只能有一个结束节点。
