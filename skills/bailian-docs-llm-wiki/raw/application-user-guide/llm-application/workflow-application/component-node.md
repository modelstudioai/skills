# 应用组件节点

应用组件节点用于在工作流中引用已发布为组件的智能体或工作流应用，实现功能复用。

## 前提条件

前往组件管理页面创建并发布组件。

## 使用示例

以“调用 Deep Research 智能体组件进行调研”为例。

## 节点接入

### 方法1：使用+按钮添加

-   将鼠标悬停在画布上任意节点上（如开始节点），节点右侧自动显示 + 按钮。
    
-   点击 + 按钮，在弹出的节点列表中选择工具应用组件，选择需要的组件后单击确定。
    
-   节点将自动添加到画布并与上游节点建立连线。
    

### 方法2：从节点库拖拽添加

-   在左侧节点库中选择变量变量赋值。
    
-   拖拽节点到画布合适位置，选择需要的组件后单击确定。
    
-   从上游节点边缘拖拽连线到节点。
    

## 核心配置

### 组件

应用组件节点的所有行为（输入参数、输出变量、执行逻辑）都取决于所选组件。添加节点时必须选择组件，之后也可以切换为其他组件。

### 输入变量

选择组件后，输入变量自动加载，显示该组件所需的所有参数。每个参数都支持直接输入固定值或引用变量。

参数说明：

-   参数名称和类型由组件定义，不同组件的参数数量和类型可能不同，无法修改。
    
-   参数名称右侧有“\*”标记表示必填参数。
    
-   必填参数必须配置值，否则无法保存或运行工作流。非必填参数可以不配置，留空即可。
    

### 记忆

记忆用于多轮对话场景，使组件能够感知历史对话上下文。默认关闭。

缓存类型

说明

本节点缓存

只记住本节点内的对话历史。需配置记忆轮次（1-50，默认 3），一次输入+输出为一轮。

自定义缓存

记住全局的上下文信息。需选择上下文变量，如内置变量 historyList。

### 流式输出

默认关闭。开启时，节点的来源于大模型的内容将会逐字流式输出在对话中。关闭时，回复内容将全部生成后一次性输出。

## 节点输出

组件的输出变量由组件定义，无法修改。选择组件后，输出变量自动加载。

**智能体组件**

变量名

类型

说明

result

String

智能体的回复内容

**工作流组件**

变量名

类型

说明

result

String

组件的主要输出结果，内容由工作流组件的结束节点定义。

completed

Array<Object>

组件内部已执行完成的节点列表。

String

节点执行耗时。

节点ID。

Array
