# 智能体群组节点

智能体群组节点用于将多个已发布的智能体应用组成群组，由决策模型根据任务需求自动规划执行流程、选择并调度所需的子智能体协同处理。决策模型会智能判断任务需要哪些子智能体参与，不一定调用全部子智能体。适用于需要多角色协作或智能任务分解的场景。

## 使用示例

智能体群组节点根据任务需求自动规划执行流程，调度子智能体协同处理。

## 接入节点

### 方法1：使用+按钮添加

-   将鼠标悬停在画布上任意节点上（如开始节点），节点右侧自动显示 + 按钮。
    
-   点击 + 按钮，在弹出的节点列表中选择智能体智能体群组，节点将自动添加到画布并与上游节点建立连线。
    

### 方法2：从节点库拖拽添加

-   在左侧节点库中选择智能体智能体群组。
    
-   拖拽节点到画布合适位置，从上游节点边缘拖拽连线到节点。
    

## 核心配置

### 输入

用户的请求或任务描述，决策模型根据该输入分析意图、规划执行流程并调度子智能体。通过下拉菜单引用上游节点的输出变量，格式为 节点名/变量名，如 开始/query。

### 模型配置

选择决策模型，负责分析用户输入、规划任务执行流程、选择合适的子智能体并调度执行。决策模型本身不回答问题，仅用于决定调用哪些子智能体。

#### 模型选择

从模型选择器下拉列表中选择要使用的大模型，如千问系列模型。如果下拉列表中没有目标模型，点击更多模型，在弹出的模型选择对话框中查找并选择目标模型。

### 群组名称

为智能体群组设置名称，用于标识该群组的具体用途。最大 20 个字符，必填。

### 智能体

从我的应用中选取已发布的智能体，并添加至群组。

每个智能体需要配置描述信息（最大 200 字符），用于告诉决策模型该智能体的能力和适用场景。描述的质量直接影响决策模型的调度准确性，清晰描述智能体的功能边界，有助于决策模型在面对特定任务时选择正确的子智能体。

## 常见问题

### 决策模型会调用所有子智能体吗？

不一定。决策模型会根据任务需求智能选择所需的子智能体。例如群组中有 3 个子智能体，但某个任务可能只需要其中 1 个就能完成，决策模型会自动跳过其他不相关的子智能体。

### 智能体群组节点与智能体创建节点有什么区别？

-   智能体群组节点：调度多个已发布的智能体应用协同工作，由决策模型自动规划和分配任务。
    
-   智能体创建节点：在工作流中动态创建一个新的智能体，仅在画布内使用，不会创建为独立应用。
