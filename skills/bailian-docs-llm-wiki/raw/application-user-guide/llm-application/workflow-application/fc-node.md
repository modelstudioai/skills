# 函数计算节点

函数计算节点用于在工作流中调用阿里云函数计算（FC）服务，执行自定义业务逻辑。适用于需要调用云函数处理数据、对接外部系统、或执行工作流内置节点无法完成的自定义计算等场景。

## 前提条件

-   需要先创建函数计算服务。
    
-   创建函数计算服务的账号需与当前登录的阿里云百炼平台账号一致，或隶属于同一阿里云主账号。
    

## 接入节点

### 方法1：使用+按钮添加

-   将鼠标悬停在画布上任意节点上（如开始节点），节点右侧自动显示 + 按钮。
    
-   点击 + 按钮，在弹出的节点列表中选择云资源函数计算，节点将自动添加到画布并与上游节点建立连线。
    

### 方法2：从节点库拖拽添加

-   在左侧节点库中选择云资源函数计算。
    
-   拖拽节点到画布合适位置，从上游节点边缘拖拽连线到节点。
    

## 核心配置

### 输入

输入参数使用自定义变量结构，用户定义变量名、引用方式和值，支持添加多个变量。

列名

说明

变量名

自定义名称

引用方式

选择“引用”（引用上游节点变量）或“输入”（直接输入固定值）

值

根据引用方式显示变量选择器或输入框

### Region（地域）

选择函数计算服务所在的地域，支持选择：杭州、北京、上海、深圳四个地域。

### 服务配置

选择要调用的函数计算服务。下拉列表显示当前账号在所选 Region 下可用的 FC 服务。

### 超时设置

函数计算节点的超时时间默认为60秒，暂不支持修改。

## 节点输出

输出变量使用自定义变量结构，定义变量名、类型和描述。支持添加多个变量。节点还提供 JSON Schema 生成器，可根据函数返回的 JSON 自动生成输出变量结构。

列名

说明

变量名

自定义名称，对应函数返回值 JSON 中的字段名，供下游节点引用。

类型

变量类型，支持 Array、Object、File、String、Number、Boolean。

## 常见问题

### 服务配置下拉框中没有服务怎么办？

可能原因：

-   尚未在函数计算控制台创建服务，需要先创建 FC 服务。
    
-   FC 服务所在 Region 与节点配置的 Region 不一致，请切换到正确的 Region。
    
-   创建服务的账号与百炼平台登录账号不属于同一主账号，请确认账号关系。
