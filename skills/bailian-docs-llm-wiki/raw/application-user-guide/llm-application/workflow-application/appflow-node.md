# AppFlow节点

AppFlow 节点用于在工作流中调用阿里云 AppFlow 服务，通过配置连接流，将外部系统的操作能力集成到工作流中。适用于需要实现跨系统数据流转、触发外部业务操作等场景。

## 前提条件

使用AppFlow节点前，需要满足以下条件：

-   已。
    
-   创建连接流的账号需与当前登录的阿里云百炼平台账号一致，或隶属于同一阿里云主账号。
    

## 使用示例

以下以“通过 AppFlow 连接流向钉钉发送消息”为例，说明 AppFlow 节点的基本用法。

## 节点接入

### 方法1：使用+按钮添加

-   将鼠标悬停在画布上任意节点上（如开始节点），节点右侧自动显示 + 按钮。
    
-   点击 + 按钮，在弹出的节点列表中选择云资源AppFlow，节点将自动添加到画布并与上游节点建立连线。
    

### 方法2：从节点库拖拽添加

-   在左侧节点库中选择云资源AppFlow。
    
-   拖拽节点到画布合适位置，从上游节点边缘拖拽连线到节点。
    

## 核心配置

### 输入

传递给 AppFlow 连接流的输入变量。输入变量是可选的，是否需要取决于连接流的设计。

### 服务配置

服务配置将 AppFlow 节点与具体的连接流绑定，决定节点实际执行的业务逻辑。

## 节点输出

自定义 AppFlow 节点的输出变量，供下游节点引用。输出变量的名称和类型需要根据连接流实际返回的数据结构来配置。建议先运行一次连接流确认其返回格式，再配置输出变量。

支持的变量类型：String、Number、Boolean、Object、Array、File。

## 常见问题

### 服务配置下拉框中没有连接流怎么办？

-   需要先在 AppFlow 控制台创建连接流。创建完成后，连接流会自动出现在AppFlow节点的服务配置下拉框中。
    
-   确保创建连接流的账号与当前登录的百炼平台账号一致，或隶属于同一阿里云主账号。
    
-   如果已创建连接流但下拉框中仍未显示，可能是页面未及时更新。此时需要刷新浏览器页面，并重新添加一个 AppFlow 节点查看。
    

### AppFlow节点支持流式输出吗？

AppFlow 节点不支持流式输出。如需流式输出，建议将 AppFlow 节点的输出传递给支持流式输出的节点（如大模型节点）进行二次处理。

### 输入变量不配置也能运行吗？

输入变量是否需要取决于连接流的设计。如果连接流本身不需要外部传参（例如固定触发某个操作），则无需配置输入变量，AppFlow 节点也能正常执行。
