# 数据连接器节点

数据连接器节点通过已创建的连接器调用其自动生成的工具，从外部数据源检索或获取数据，并将结果作为变量供后续节点使用。

## 使用示例

在工作流中通过文件连接器搜索文件并获取下载链接，将结果传递给后续节点处理。

> 使用数据连接器节点前，需先在数据连接页面创建连接器并导入数据。创建方法参见[数据连接](raw/application-user-guide/data-connection-overview/data-connection.md)。

## 节点接入

### 方法1：使用+按钮添加

-   将鼠标悬停在画布上任意节点上（如开始节点），节点右侧自动显示 + 按钮。
    
-   点击 + 按钮，在弹出的节点列表中选择数据连接器，节点将自动添加到画布并与上游节点建立连线。
    

### 方法2：从节点库拖拽添加

-   在左侧节点库中选择数据连接器。
    
-   拖拽节点到画布合适位置，从上游节点边缘拖拽连线到节点。
    

## 核心配置

### 工具选择

配置面板顶部显示当前选择的工具名称。如需更换连接器或工具，单击右侧的切换按钮，重新选择连接器和工具。切换后原有参数配置将被清除。

以文件连接器为例，创建文件连接器后系统自动生成以下 2 个工具：

工具名称

功能说明

参数

`searchFile`

根据文件标题的关键词搜索文件列表，返回文件的下载链接。

`keyWord`（String，必填）：文件标题的搜索关键词。`maxCount`（Integer，可选）：返回的最大文件数量，默认值为 5，最大值为 10。

`getFile`

根据文件 ID 获取指定文件，返回文件的下载链接。

`fileId`（String，必填）：目标文件的 ID。

其他类型连接器的工具和参数说明，参见[数据连接](raw/application-user-guide/data-connection-overview/data-connection.md)。

### 输入

输入参数根据选择的工具自动加载，不同工具的参数不同。参数通过下拉框配置，需先选择引用方式，再设置值。

列名

说明

引用方式

参数值的来源方式：**输入**（在值列中直接输入文本内容）、**引用**（引用上游节点的输出变量）。

值

根据引用方式填写：直接输入文本内容，或从下拉列表中选择对应变量。

## 节点输出

字段

类型

说明

result

Object

工具的执行结果。

result.content

Array<Object>

返回内容列表。每个元素包含 `text`（文本内容）和 `type`（内容类型，固定为 `text`）。

result.isError

Boolean

是否执行出错。`false` 表示执行成功，`true` 表示执行出错。
