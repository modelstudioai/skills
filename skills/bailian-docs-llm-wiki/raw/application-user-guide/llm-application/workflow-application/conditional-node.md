# 条件判断节点

条件判断节点用于设置条件分支，当变量满足条件后，流程将选择相应的后续链路执行。

## 使用示例

意图分类节点根据用户输入智能识别问题类型，自动路由到对应的处理分支。例如在智能客服场景中，根据用户问题是产品咨询、售后服务还是投诉建议，分别连接到不同的专业大模型节点进行针对性处理。

## 节点接入

### 方法1：使用+按钮添加

-   将鼠标悬停在画布上任意节点上（如开始节点），节点右侧自动显示 + 按钮。
    
-   点击 + 按钮，在弹出的节点列表中选择逻辑条件判断，节点将自动添加到画布并与上游节点建立连线。
    

### 方法2：从节点库拖拽添加

-   在左侧节点库中选择逻辑条件判断。
    
-   拖拽节点到画布合适位置，从上游节点边缘拖拽连线到条件判断节点。
    

## 核心配置

### 条件组

条件组是条件判断的基本单元，每一个条件组对应一个分支。不同条件组之间为“或”关系，每一个满足条件的条件组分支都会执行。

-   单击节点打开配置面板，单击面板底部的添加条件组。
    
-   新条件组自动添加到列表中，默认名称为“新条件组1”、“新条件组2”等。画布上的节点实时更新，显示新增的分支。
    

在条件组配置区域，通过“当满足以下XX条件时”下拉框选择条件关系：

选项

说明

示例

条件组内所有条件都必须满足

当需要为 VIP 用户提供专属天气服务时，变量需要同时包含“天气”和“会员等级=VIP”，分支才会执行。

### 条件配置

条件是判断变量是否满足要求的规则，每个条件组可包含多个条件。每个条件均包含以下配置项：

配置项

说明

变量

指定用于判断的变量。支持选择会话变量、前置节点变量及内置变量。

比较运算符

设置变量的判断方式。支持等于、不等于、包含、不包含、为空、不为空、长度等于、长度大于、长度小于、长度大于等于、长度小于等于。选择建议：关键词匹配使用包含或不包含；精确匹配使用等于或不等于；存在性检查使用为空或不为空；字符串长度控制使用长度相关的运算符。

比较值

设置用于对比的目标值。支持直接输入或引用变量。

## 节点输出

条件判断节点不输出可供下游引用的数据变量，而是根据条件判断结果控制流程走向不同的分支。

分支类型

数量

命名格式

说明

条件组分支

1 个或多个

条件组名 IF

每个条件组对应一个IF分支，如天气查询 IF、计算问题 IF。

默认分支

1 个

默认 ELSE

所有条件组都不满足时执行的兜底分支。

## 常见用法

配合节点

说明

输入 → 条件判断节点 → 多个大模型节点（文本生成/图片生成）

条件判断节点根据上游节点输出，决定调用不同的大模型节点处理。

条件判断节点 → 多个MCP节点/插件节点

根据条件判断结果，调用不同的插件功能。

条件判断节点 → 变量处理节点（聚合分组模式）

在条件判断节点的多个分支后使用变量处理节点的聚合分组模式，自动选择执行分支产生的有效值输出，避免下游节点接收到空值导致报错。

## 常见问题

### 可以只有其他（ELSE）分支吗？

可以。如果不需要条件判断，可以删除所有自定义条件组，节点会保留默认的 ELSE 分支，此时所有输入都会走 ELSE 分支。适用于需要临时禁用所有条件判断的场景。

### 条件组可以连接多个下游节点吗？

可以。每个条件组分支（IF）和其他分支（ELSE）都可以连接多个下游节点。

适用场景：

-   同时触发多个并行操作
    
-   一个分支需要多步处理
    
-   分支内包含子流程
    

### 每个分支都必须连接下游节点吗？

不需要。只要某个分支不会被执行，即使该分支未连接下游节点，工作流也可以正常运行。适用于仅需判断、过滤或拦截，无需后续处理的场景。
