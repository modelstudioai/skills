# MCP节点

当工作流中需要调用外部服务能力（如时区转换、联网搜索、图像生成）、接入第三方服务（如支付宝支付、高德地图）、或扩展大模型功能（如代码执行、语音合成）时，MCP 节点通过标准化的 MCP 协议接入服务工具，使工作流能够获取实时数据并执行特定操作。

## 使用示例

以下是使用 MCP 节点获取杭州天气的典型工作流，通过调用高德地图 MCP 服务的maps\_weather工具获取天气信息，然后将结果传递给大模型节点进行总结。

## 前提条件

在接入 MCP 节点之前，您需要首先开通或创建 MCP 服务。

-   开通官方 MCP 服务：进入MCP 广场，选择想要开通的 MCP 服务卡片，单击立即开通。
    
-   创建自定义 MCP 服务：在 MCP 管理页面，单击创建 MCP 服务。详情请见。
    

## 接入节点

-   点击画布上任意节点末尾的加号按钮。
    
-   在弹出的节点列表中选择 MCP。
    
-   在弹出的 MCP 服务选择弹窗中：
    
-   MCP 广场：选择阿里云百炼预置的官方 MCP 服务。
    
-   自定义 MCP：选择已部署的自定义 MCP 服务。
    
-   展开服务卡片，选择需要调用的具体工具。
    
-   单击确定，节点自动添加到画布。
    

## 核心配置

### 工具配置

选择 MCP 服务后，需要指定要调用的具体工具。每个 MCP 服务可能包含多个工具，每个 MCP 节点只能调用一个工具。

点击切换按钮可以重新选择 MCP 服务和工具。

### 输入配置

选择工具后，输入区域会自动加载该工具定义的输入参数。

配置项

说明

变量名

由工具定义，不可修改。

引用方式

选择变量值的来源方式：引用或输入。

值

输入固定值或引用上游节点的变量。在输入框中输入 / 可触发变量选择器。

不同的工具有不同的输入参数，您可以前往 MCP 管理页面，点击服务卡片进入详情页，在工具页签查看各工具的参数说明。

## 节点输出

MCP 节点的输出变量结构如下：

变量名

类型

说明

result

Object

工具执行结果

result.content

Array<Object>

返回内容，包含工具的实际输出数据

result.isError

Boolean

是否发生错误，true 表示执行失败

## 常见用法

配合节点

说明

大模型节点

将 MCP 工具的返回结果作为大模型的输入，进行内容生成或分析。

条件判断节点

根据 result.isError 判断工具执行是否成功，实现分支处理。

循环节点

批量调用 MCP 工具处理多条数据。

## 常见问题

### MCP 节点执行失败，提示工具调用错误怎么办？

可能是输入参数格式不正确，或未按工具要求填写必填参数。

-   检查输入参数是否完整填写。
    
-   确认参数格式符合工具要求（如时区格式应为 Asia/Shanghai）。
    
-   前往MCP 管理页面查看工具的参数说明。
