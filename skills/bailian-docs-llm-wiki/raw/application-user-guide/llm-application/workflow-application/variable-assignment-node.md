# 变量赋值节点

变量赋值节点解决的核心问题是：让工作流具备“写回”能力——将某个节点的处理结果写入一个持久化的变量中，包括会话变量和内置变量。在循环体内使用时，还可以更新循环节点的中间变量，实现跨轮次的数据传递。

## 使用示例

变量赋值节点将大模型的输出结果写回会话变量，实现变量回传。

## 节点接入

### 方法1：使用+按钮添加

-   将鼠标悬停在画布上任意节点上（如开始节点），节点右侧自动显示 + 按钮。
    
-   点击 + 按钮，在弹出的节点列表中选择变量变量赋值，节点将自动添加到画布并与上游节点建立连线。
    

### 方法2：从节点库拖拽添加

-   在左侧节点库中选择变量变量赋值。
    
-   拖拽节点到画布合适位置，从上游节点边缘拖拽连线到节点。
    

## 核心配置

### 设置变量

用于指定需要赋值的目标变量以及对应的变量值。

-   变量：变量下拉框中可选择以下类型作为赋值目标：
    
-   会话变量（工作流画布右上角配置，在会话生命周期内持续存在）。
    
-   内置变量（如query、historyList等）。
    
-   中间变量（仅循环体内可用，需在循环节点配置中创建）。
    
-   设置值：变量的新值。支持引用上游节点的输出变量，也支持直接输入固定值。
