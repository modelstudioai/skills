# 变量处理节点

当工作流中需要为输出添加统一格式、将数据组装成JSON对象、或汇总多分支结果避免空值报错时，变量处理节点通过格式化、组合和聚合功能，使数据按期望形式流转到下游节点。

## 接入节点

### 方式一：通过加号按钮添加

-   点击画布上任意节点末尾的加号按钮。
    
-   在弹出的节点列表中选择变量处理节点。
    
-   节点自动添加到画布并与上游节点建立连线。
    

### 方式二：拖拽节点

-   在左侧节点库中找到变量处理节点。
    
-   将节点拖拽到画布上的目标位置。
    
-   手动将节点连接到上游节点（拖拽上游节点的输出端到变量处理节点的输入端）。
    

## 核心配置

### 输出模式

点击输出模式下拉框，可选择目标模式。变量处理节点支持三种输出模式。

## 文本输出

在编辑框中直接输入待处理的内容，或通过输入“/”插入前置节点或会话变量，例如：

-   简单变量引用：插入变量开始节点/query，输出用户输入的内容
    
-   格式化输出：在变量前后添加文本，例如您好！您的问题是：`{{开始节点/query}}`，我会尽快为您解答。
    
-   多变量组合：组合多个变量和文本，例如用户`{{开始节点/name}}`的问题`{{开始节点/query}}`已处理完成，结果：`{{大模型节点/result}}`。

## 聚合分组

聚合分组模式用于从多个变量中选择一个有效值输出。节点会按照预设的策略，从分组内的多个变量中选择一个非空的值输出。

选项

说明

示例

返回每个分组中第一个非空的值

默认选项，按变量顺序返回第一个有值的变量。适用于条件判断节点多分支聚合场景，无论哪个分支执行都能获取到有效的变量值。

分组中有var1（空）、var2（“值2”）、var3（“值3”），输出“值2”。

返回每个分组中最后一个非空的值

按变量顺序返回最后一个有值的变量。适用于需要获取最新值的场景。

分组中有var1（“值1”）、var2（空）、var3（“值3”），输出“值2”。

### 结果返回

默认关闭。仅在API调用应用时生效，用于决定是否输出本节点内容。该功能即将下线。

### 输出变量

本节点的输出结果存储在输出变量中，可作为变量被后续节点引用。

## 文本输出

文本输出模式下，输出变量名为result，类型为String，值为模板内容处理后的文本结果。

聚合分组模式下，每个分组对应一个输出变量，变量名与分组名对应（如Group1、Group2等），类型为String，值为分组策略选择的有效值。

在意图分类节点的多个分支后使用聚合分组模式，将不同意图处理结果统一聚合后传递给下游节点，确保工作流正常执行。

## 常见问题

### JSON输出模式可以生成嵌套的JSON结构吗？

不可以。JSON输出模式生成的是单层键值对结构，所有值的类型均为String。如果需要嵌套结构（如包含数组或子对象的JSON），建议在下游节点中进行二次处理。
