# 开始和结束节点

开始节点用于定义工作流的输入参数，结束节点用于配置工作流最终返回给用户的输出内容。每个工作流自动包含一个开始节点和一个结束节点，无法添加或删除。

## 接入节点

开始节点和结束节点是工作流的必需节点，每个工作流创建时自动包含，无需手动添加。开始节点和结束节点无法删除，也无法通过节点库添加额外的开始或结束节点。

## 核心配置

### 开始节点

开始节点用于定义工作流的输入参数，包括系统预置变量和用户自定义变量。

#### 预置变量

百炼工作流预置了以下变量，用于处理用户输入和维护历史对话：

变量名

类型

说明

query

String

接收用户输入的文本内容。该变量在开始节点配置面板中直接显示，不可编辑、删除或重命名。

historyList

Array

对话历史列表，用于在多轮对话中维护上下文。不在开始节点面板显示，需在支持记忆功能的节点（如大模型、意图分类）中，通过选择自定义缓存来引用。

imageList

Array

图片列表，用于存储用户上传的图片，以支持图像分析或多模态对话。不在开始节点面板显示，需在支持记忆功能的节点中，通过选择自定义缓存来引用。

#### 自定义变量

自定义变量是根据不同工作流需求创建的结构化输入参数，可在测试工作流或 API 调用时接收外部数据，并在后续节点中引用。

### 结束节点

结束节点用于定义工作流的输出内容，将执行结果返回给用户。在输出配置的编辑框中输入 / 可引用任意上游节点的输出变量（如 大模型/result）。

输出模式

适用场景

配置方式

文本输出

直接展示

在文本模板中输入内容或引用变量，输入 / 可选择变量。

JSON输出

API 调用或系统集成

通过表格形式配置输出变量，每行设置变量名、引用方式和值。

流式输出

文本输出模式下的渐进式展示

开启后，大模型节点、应用组件节点的内容会逐字输出，呈现打字机效果；关闭时，回复内容全部生成后一次性输出。流式输出开关仅对文本输出模式生效，JSON输出模式不支持流式输出。

## 常见用法

配合节点

常见用法

开始节点 → 大模型节点

将 query 传入大模型节点作为用户问题。

开始节点 → 知识库节点 → 大模型节点

将 query 用于知识库检索，检索结果与 query 一起传入大模型节点生成回答。

开始节点 → 意图分类节点

将 query 传入意图分类节点，根据分类结果路由到不同的处理分支。

大模型节点 → 代码节点 → 结束节点

对大模型输出进行格式化处理后，再传入结束节点返回。

## 常见问题

### 开始节点可以同时连接多个下游节点吗？

可以。开始节点可以连接多个下游节点，各分支会并行执行。

### 结束节点可以接收多个上游节点的输出吗？

可以。结束节点可以接收多个上游节点的输出，在文本输出模式下可通过输入 / 选择多个变量进行组合输出。
