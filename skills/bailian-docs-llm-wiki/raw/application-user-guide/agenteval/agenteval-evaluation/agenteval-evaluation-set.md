# 评测集

存储和管理所有评测集数据

评测集用于存储和管理所有评测任务数据，可通过空评测集或本地文件上传的方式创建。

## 创建评测集

访问[评测集](https://bailian.console.aliyun.com/loop/app-evaluate/eval-set?name=&pageNum=1)页面，点击**创建评测集**，按以下步骤完成创建：

1.  **填写基本信息**：填写评测集名称、描述。
    
2.  **选择评测集类型**：选择类型：**智能体** / **工作流** / **自定义**。当选择智能体或工作流时，需进一步选择具体的智能体或工作流及其版本。
    
3.  **编辑表结构**：系统会解析所选智能体 / 工作流的输入输出字段，或使用自定义默认字段。可在此基础上编辑表结构，配置列名、数据类型、是否必填、描述等信息。
    
4.  **导入评测集文件**：导入准备好的评测集文件，也可先下载数据模板再填写。
    
    **说明**支持扩展名：xls、xlsx，文件最大 20 MB。
    
5.  **确认上传**：点击**确认**后，将在评测集页面显示上传的文件。
    
6.  **发布评测集**：等待**导入状态**为**导入成功**时，点击**发布**，发布当前评测集。
    
    > 草稿状态的评测集不能用于应用评测，必须发布后再使用。
    

## 管理评测集

访问[评测集](https://bailian.console.aliyun.com/loop/app-evaluate/eval-set?name=&pageNum=1)页面，点击目标评测集的**查看**，进入评测集详情页查看具体内容。详情页支持以下操作：

-   **版本管理**：管理评测集版本，展示草稿版本和最近 10 个版本。
-   **内容搜索**：按评测集内容搜索，可选择**全部字段**或指定的评测集表头字段，再输入搜索内容。
-   **编辑表头**：已添加的表头仅支持修改名称与描述，同时支持新增表头字段。
-   **添加与导出数据**：添加数据支持单条添加和批量导入，也支持导出当前评测集数据。

**警告**评测集完备后需发布才能使用。草稿状态的评测集不能用于应用评测。
