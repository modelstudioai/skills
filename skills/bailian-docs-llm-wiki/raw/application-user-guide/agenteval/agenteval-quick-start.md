# 快速开始

快速了解 Evolution 的各种功能

通过本文档，方便你快速了解 Evolution 的观测、评测等功能。

## 前置准备

1.  访问[Evolution](https://bailian.console.aliyun.com/loop/quick-start)，点击右上角的**登录**。
2.  使用阿里云账号登录。
3.  如尚未注册阿里云账号，先注册并完成登录。

## 观测

Evolution 为开发者提供全链路执行过程的可视化观测能力，完整记录从输入到输出的每个处理环节，同时支持监控统计、限流统计、配置告警规则。

1.  上报&查看 调用链轨迹与模型/工具事件。
2.  观察请求数、Tokens、模型、工具调用等监控指标。
3.  查看应用 QPM、限流次数等限流指标。
4.  基于告警模板配置告警规则，查看告警历史。

更多详细说明，参考[应用观测](raw/application-user-guide/agenteval/agenteval-observability/agenteval-observation.md)与[告警管理](raw/application-user-guide/agenteval/agenteval-observability/agenteval-alert-management.md)。

## 评测

Evolution 为开发者提供系统化的评测能力，能够对应用的输出进行评测。可以通过分析实验结果，深入研究异常案例，并进行有针对性的优化。

1.  创建和管理评测集，整理输入样本与期望结果。
2.  创建或选择评估器，配置规则或模型评分维度。
3.  创建评测任务&查看评测结果，批量运行并生成评分，分析得分分布与回归对比。

更多详细说明，参考[评测任务](raw/application-user-guide/agenteval/agenteval-evaluation/agenteval-evaluation-task.md)。
