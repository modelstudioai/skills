# 记忆库概览

阿里云百炼记忆库 — 为大模型提供跨会话长期记忆的 API 服务

大模型受上下文窗口限制，跨会话无法保留信息。记忆库自动从对话中提取关键信息并持久化存储，在后续对话中基于语义检索相关记忆并注入上下文，使智能体持续理解用户偏好和历史信息。
