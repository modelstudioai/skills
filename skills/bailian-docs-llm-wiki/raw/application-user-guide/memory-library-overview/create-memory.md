# 创建与删除记忆库

创建自定义记忆库并管理记忆库生命周期

每个用户账号下自带一个默认记忆库，无需创建即可直接使用。如需自定义记忆规则或为不同业务场景分别管理记忆，可创建新的记忆库。

## 默认记忆库

默认记忆库无法删除，但可以编辑名称和描述、添加自定义记忆规则。它已预置一条"默认项目"事实记忆规则，默认有效期 180 天，可点击编辑调整。

## 创建记忆库

1.  **进入创建入口**：在[记忆库](https://bailian.console.aliyun.com/cn-beijing/?tab=app#/memory/list)页面，点击右上角的**创建记忆库**。
    
2.  **填写基础信息**：
    
    -   **记忆库名称**：描述记忆库内容的名称
    -   **记忆库描述**：可能会用于指导智能体调用的描述语句
    
    点击**确定**完成创建。
    
3.  **配置记忆规则**：创建成功后，系统会提示**是否立即开始创建记忆规则**。推荐点击**立即创建**，跳转到记忆规则配置页面。也可点击**暂不**，后续通过记忆库卡片上的**查看详情**进入配置。
    

**重要**创建完成后，继续[配置记忆规则](raw/application-user-guide/memory-library-overview/create-memory/configure-rules.md)定义记忆的提取和召回行为。

## 删除记忆库

**警告**删除后记忆库中的所有记忆内容将被清除且不可恢复。

两种方式删除记忆库：

-   在记忆库卡片上点击 `...` 图标，再点击**删除**
-   在记忆库详情页右上角点击 `...` 图标，再点击**删除**

默认记忆库不可删除。
