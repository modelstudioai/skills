# 配置记忆规则

定义事实记忆和用户画像的提取规则

记忆规则定义了如何从对话中提取、存储和检索记忆，包括**事实记忆规则**和**用户画像规则**。每个记忆库最多可配置 50 条事实记忆规则和 50 条用户画像规则。

点击记忆库卡片的**查看详情**，进入记忆库详情页的**记忆规则**标签页。

## 事实记忆规则

事实记忆规则用于从对话内容中提取关键事件和信息片段。

1.  **添加片段规则**：在**事实记忆规则**区域，点击**添加片段规则**。
    
2.  **配置参数**：
    
    参数
    
    说明
    
    **规则名称**
    
    当前记忆抽取规则的唯一标识
    
    **规则指令**
    
    定义记忆抽取策略。可选**默认规则指令**（推荐）或**自定义规则指令**
    
    **自动更新**
    
    开启后模型自动更新记忆内容。默认开启
    
    **记忆过期时间**
    
    记忆有效期。可选 7 天、30 天、180 天、永不过期
    
    **记忆抽取策略版本**
    
    选 **Pro**（推荐，¥0.03/次，开启 Rerank）或 **Lite**（¥0.018/次，关闭 Rerank）。不传默认 Pro
    
3.  **确认**：点击**确认**完成配置。
    

**说明**记忆库已预置一条"默认项目"事实记忆规则，默认有效期 180 天，不可删除但可编辑。

## 用户画像规则

用户画像规则用于持久化存储用户的属性信息。

1.  **添加用户画像**：在**用户画像规则**区域，点击**添加用户画像**。
    
2.  **填写画像规则名称**：输入当前画像规则的唯一标识。
    
3.  **添加画像字段**：点击**添加用户画像字段**，填写以下信息后点击**保存**：
    
    字段
    
    说明
    
    **字段名称**
    
    定义抽取出的画像包含哪些字段
    
    **描述**
    
    描述该字段的含义，引导模型提取相关信息
    
    **初始值**
    
    用户尚未提供信息时的默认值
    
    **记忆抽取策略版本**
    
    选 **Pro**（推荐，¥0.03/次）或 **Lite**（¥0.025/次）。不传默认 Pro
    
4.  **确认**：点击**确认**完成配置。
    

配置后，调用 `AddMemory` 时传入画像模板 ID，系统会自动从对话中提取属性。提取结果可在**记忆详情**标签页查看。

**重要**了解规则配置后，参见[使用用户画像](raw/application-user-guide/memory-library-overview/create-memory/user-profile.md)通过 API 完成画像的创建、提取和获取。
