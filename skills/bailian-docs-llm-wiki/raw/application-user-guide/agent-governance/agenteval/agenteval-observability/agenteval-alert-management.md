# 告警管理

基于告警模板，配置告警规则，查看告警历史

Evolution 提供告警规则、告警模板与告警历史三个功能，分别对应[告警管理](https://bailian.console.aliyun.com/loop/alert-manage)页面的三个页签。

## 告警规则

访问[告警管理](https://bailian.console.aliyun.com/loop/alert-manage)，点击**告警规则**页签，进入告警规则页面。告警规则列表展示当前生效的告警规则，支持创建、编辑、停止、删除操作，并展示通知对象（联系人 / 联系人组），支持邮箱等多种通知渠道。

配置路径：

1.  点击**创建告警规则**，打开创建页面。
2.  按下表字段说明填写告警名称、告警模板、应用选择、持续时间、告警检查周期、告警内容、告警等级。
3.  配置告警通知（告警联系人 / 联系人组、通知时段、重复策略）后，点击**创建**完成。

## 告警模板

告警模板是预设好触发条件的告警配置，可基于模板快速创建告警规则，无需从零配置。可以使用系统预置模板，也可自建模板。

访问[告警管理](https://bailian.console.aliyun.com/loop/alert-manage)，点击**告警模板**页签，进入告警模板页面。点击**创建告警模板**，在弹出的侧边面板中填写以下信息：

-   **模板名称**：必填，最多 20 字符。
-   **参数选择**：最多配置 10 个参数。可选择全部规则符合条件时触发告警（AND），或有一个满足条件即告警（OR）。
-   **指标**：必选，用于选择告警监控的指标，下拉选项包含调用次数、失败次数、失败率、调用时长、首 Token 延时等。
-   **告警阈值**：必填，选择比较符号（`>`、`>=`、`<`、`<=`、`==`、`!=`）和数值。
-   **统计周期**：单位为分钟，合法范围 1~10080 分钟。

系统预置的告警模板在名称后标注**预置**标识，支持查看详情和复制，不支持编辑和删除。自定义的告警模板支持查看详情、编辑、删除和复制。

**重要**优先使用预置模板覆盖常见告警场景，填写参数即可使用；自定义模板用于承载复杂复合条件与业务化规则。

## 告警历史

访问[告警管理](https://bailian.console.aliyun.com/loop/alert-manage)，点击**告警历史**页签，进入告警历史页面，查看告警触发记录。

支持按告警时间（快捷选择和日历选择）、告警规则、告警等级、状态（已恢复 / 告警中）四个条件筛选。

告警历史列表展示以下列：

列名

说明

告警应用

告警规则选择的应用。

告警等级

普通 / 警告 / 错误 / 紧急。

告警时间

告警触发时间。

告警数量

该告警的触发次数。

告警规则

告警规则名称与 ID。

状态

已恢复 / 告警中。

通知对象

告警联系人 / 联系人组。

操作

查看详情，打开告警详情侧边面板。

> 告警历史列表的通知对象仅展示联系人信息，不展示相关的通知渠道信息。

点击列表中的**详情**，打开告警详情侧边面板。详情侧边面板的状态仅有**已恢复**与**告警中**两种。
