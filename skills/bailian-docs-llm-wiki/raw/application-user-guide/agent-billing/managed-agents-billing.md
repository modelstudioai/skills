# 计费说明

Managed Agents 的计费项、免费额度与计费示例。

> **说明**
>
> Managed Agents 自 2026-08-17 09:00:00（UTC+8）起正式商业化计费。以下价格与额度以该版本为准，实际计费时间与金额以控制台账单为准。

## 计费项

Managed Agents 的费用由四部分组成，分别独立计费。

| 计费项 | 计费标准 | 说明 |
| --- | --- | --- |
| 会话运行时费 | 0.5 元/小时 | 基础计费项。按创建并启用（运行中）的会话运行时长计费，不足 1 小时按实际时长精确计算 |
| 模型调用费 | 按所调用模型的实际标准 | 运行时调用大模型（如 Qwen 系列）产生的 token 消耗，不含在运行时费中，按阿里云百炼对应模型的公开按量标准收取 |
| 工具及 MCP 调用费 | 按所调用工具或 MCP 的实际标准 | 调用工具或 MCP 服务产生的费用，单独计费。例如内置工具 `web_search` 按 0.03 元/次计费，`web_fetch` 限时免费 |
| 沙箱持久化 | 0.003 元/个/小时 | 开启沙箱持久化后，按快照实际存在时长计费，不足 1 小时按实际时长精确计算；未开启不收费 |

> **说明**
>
> 会话处于运行中状态即产生运行时费，空闲状态不收取。及时终止不再使用的会话可减少运行时费。会话状态管理详见 [管理会话](../agent-development/managed-agents/managed-agents-session/managed-agents-session-operations.md)。

## 免费额度

正式商业化后，赠送 10 小时的会话运行时免费额度。

| 项目 | 说明 |
| --- | --- |
| 赠送额度 | 总计 10 小时运行时，不限会话数，可任意抵扣 |
| 抵扣范围 | 仅抵扣会话运行时费（0.5 元/小时），不抵扣模型调用费、工具/MCP 调用费及沙箱持久化 |
| 有效期 | 自额度生效日起 30 天内有效，逾期失效 |

## 沙箱持久化

开启沙箱持久化后，每个快照按实际存在时长计费，单价 0.003 元/个/小时；不足 1 小时按实际时长精确计算。再次运行会话时从上一快照恢复，上一快照不会立即释放；本次运行成功生成新快照后，系统释放上一快照。本会话累计的快照保留时长可在会话详情页的**用量**标签页查看。

示例（仅计算快照保留时长，不计运行时长）：快照保留 3 天。某次运行结束后，快照保留 2 天后再次运行；本次运行成功生成新快照后释放上一快照。旧快照保留 2 天，新快照保留 3 天，累计 5 天（120 小时），沙箱持久化费用为 120 × 0.003 = 0.36 元。

## 计费示例

以下示例未开启沙箱持久化。运行 2 个会话，每个运行 5 小时；期间两个会话共调用 qwen-plus 模型，消耗 100 万 Input Token 和 20 万 Output Token（Input 0.004 元/千 Token，Output 0.012 元/千 Token）。

| 项目 | 计算 | 金额 |
| --- | --- | --- |
| 会话运行时费 | (5 + 5) 小时 × 0.5 元/小时 | 5.0 元 |
| 模型调用费 | (1000 × 0.004) + (200 × 0.012) | 6.4 元 |
| **总计** |  | **11.4 元** |

如有计费工具类调用，需在此基础上加上工具调用费用。

## 查看用量

在控制台 [用量](https://bailian.console.aliyun.com/managed-agent/usage) 页面查看运行时长、交互轮数、Token 用量、模型用量和工具调用明细。也可调用 [Usage API](../../application-api-reference/managed-agents-api/usage-api.md) 获取相同口径的数据：`POST /usage/summary` 获取工作空间、Agent 或 Session 的汇总，`POST /usage/trend` 按小时、UTC+8 自然日或自然月查看变化。实际费用以控制台账单为准。
