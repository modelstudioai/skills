# 计费说明

Sandbox 计费项、计费规则与计费示例。

Sandbox 按实际使用量计费，按秒计量。费用分为两部分：

-   **会话运行费**：Sandbox 执行任务产生的费用。
-   **数据保留费**：Sandbox 暂停或保存 Snapshot 时产生的费用。

每个运行中的 Sandbox 默认包含 15 GiB 系统盘，该部分不另行收费。

Sandbox 暂停后保存的内存和磁盘数据，以及独立创建的 Snapshot，以平台统计的实际占用量为准。

## 计费示例

创建一个进阶款的 Sandbox：

-   运行 40 分钟。
-   暂停 2 小时，暂停数据实际占用 8 GiB。
-   恢复后继续运行 20 分钟。
-   期间创建一个 Snapshot，实际占用 6 GiB，保留 3 小时。
