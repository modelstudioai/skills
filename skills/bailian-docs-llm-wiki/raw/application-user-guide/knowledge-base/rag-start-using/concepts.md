# 核心概念

理解 RAG、切片、嵌入、索引、检索与 Wiki 知识组织的工作原理

<a id="rag-是什么"></a>

<a id="h-ragcon-what"></a>

## RAG 是什么

**RAG**（Retrieval-Augmented Generation，检索增强生成）是一种把检索系统与大模型结合的技术。用户提问时，系统先从知识库检索相关片段，再将片段与问题一起送入大模型，生成有依据的回答。

<a id="处理链路"></a>

<a id="h-ragcon-pipeline"></a>

## 处理链路

| 阶段 | 作用 |
| --- | --- |
| **解析** | 识别内容中的标题、段落、表格、图片与公式，结构化存储 |
| **切片**（Chunking） | 将内容拆分为可检索的小片段，通常 256–4096 token |
| **向量化**（Embedding） | 把文本转为向量表示，用于语义匹配 |
| **索引**（Index） | 存储切片与向量，支持快速搜索 |
| **检索**（Retrieval） | 根据查询返回最相关的 Top-K 片段 |
| **重排**（Rerank） | 对初步召回结果二次排序，提升相关性 |
| **生成**（Generation） | 大模型基于检索片段生成最终回答 |

<a id="知识库类型"></a>

<a id="h-ragcon-types"></a>

## 知识库类型

| 类型 | 适用数据 | 检索方式 | 典型场景 |
| --- | --- | --- | --- |
| 文档知识库 | PDF / Word / Markdown / HTML | 向量 + 关键词混合 | 产品手册、合同模板、内部 Wiki |
| 数据知识库 | CSV / Excel / RDS 表格 | 自然语言转 SQL 查询 | 订单数据、库存报表 |
| 图片知识库 | 商品图 / 设计稿 / 海报 | 以图搜图、图文问答 | 图片搜索、视觉问答 |
| 音视频知识库 | 会议录屏 / 培训课程 | 语音转文本后检索 | 视频内容检索 |

> **重要**
>
> 如果不确定选哪种类型，建议从**文档知识库**开始。

## Wiki 与本体知识图谱

旗舰版文档知识库可开启 **Wiki**，将文档整理为可阅读、可检索的主题知识页面（Wiki Page）。开启后，系统使用大模型从文档中提取摘要、实体和概念，生成结构化 Wiki Page，并构建独立索引参与知识检索与问答。

-   **Wiki Page**：按主题组织的知识页面，可阅读、修订并参与检索召回。自动生成的 Page 可通过来源文档追溯原始内容。
-   **Wiki 检索**：基于 Wiki Page 独立索引的检索服务，与切片检索并列，适合主题理解、实体查询、概念解释与关联知识召回。
-   **本体知识图谱**：基于 Wiki Page 之间的关联生成关系视图，用于知识浏览与关系展示。图谱数据本身不参与检索。

Wiki 不替代原有切片与向量索引。对于合同条款、错误码、精确数值等需要严格核对原文的问题，建议同时使用切片检索并查看来源文档。

> **重要**
>
> 了解 Wiki 的开启配置、计费、页面管理与检索问答，请参见[Wiki 与本体知识图谱](../data-connection-overview/rag-wiki.md)。

<a id="关键术语"></a>

<a id="h-ragcon-terms"></a>

## 关键术语

| 术语 | 说明 |
| --- | --- |
| **知识库** | 一组文档的逻辑集合，共享切片、嵌入与索引配置 |
| **文档** | 上传或同步进知识库的原始内容，可以是文件、网页或数据库记录 |
| **切片**（Chunk） | 文档被拆分后的最小检索单元 |
| **Wiki Page** | 旗舰版文档知识库开启 Wiki 后生成的主题知识页面，包含摘要、实体、概念等类型，构建独立索引参与检索召回 |
| **Wiki 检索** | 基于 Wiki Page 独立索引的检索服务，与切片检索并列，返回主题化知识页面及来源信息 |
| **本体知识图谱** | 基于 Wiki Page 关联生成的关系视图，用于知识浏览与关系展示，图谱数据本身不参与检索 |
| **Top-K** | 检索返回的片段数量，常用值 3–10 |
| **相关性分数** | 检索片段与查询的语义相似度，范围 0–1 |
| **数据集** | 外部数据源的接入通道，如 OSS、MySQL、语雀等 |
| **检索服务** | 多知识库联合检索的配置单元，支持独立参数调优 |
| **问答服务** | 在检索基础上叠加大模型生成，返回带引用的自然语言回答 |
| **业务空间** | 资源隔离单元，同一账号下可创建多个空间 |

<a id="检索模式"></a>

<a id="h-ragcon-modes"></a>

## 检索模式

| 模式 | 工作方式 | 适用场景 |
| --- | --- | --- |
| **极速模式** | 单轮直接检索，延迟最低 | 简单事实性问题 |
| **多轮智能模式** | 模型驱动多轮规划搜索，自动改写查询 | 复杂问题、多步推理 |
