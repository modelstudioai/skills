# 计量与计费

了解 ParseX 的分项计量维度、控制台用量查看入口和正式价格信息边界。

Parse 和 Extract 分项记录用量。图文按页计量，音频和视频解析按秒计量。

## 输入计量维度

输入类型

计量维度

PDF、PPT与图片

按实际处理页数计量；图片按页计量，超长图片会进行切割

Word、表格、Markdown、纯文本、HTML、电子书等文本容器

按文本量/2000折算为页数

音频与视频

按实际处理时长，以秒计量
