# 配置文档解析

为 Parse 任务配置解析范围和输出形式。

解析配置决定处理哪些内容、保留哪些辅助信息，以及如何整理音视频内容。先选定文件，再调整与本次目标有关的设置。

## 入口与使用方法

进入 [ParseX](https://bailian.console.aliyun.com/cn-beijing/parsex/document-parse)，选择左侧「文档解析」，在选择文件后打开配置区域。

1.  用一份熟悉的材料保留默认设置运行一次。
2.  对照结果，选择需要调整的项目。
3.  修改后重新运行，并核对这项调整的效果。
4.  效果符合要求后，[保存配置](raw/application-user-guide/getting-started-overview/settings-configurations.md)，用于同类材料。

## 输出设置

“输出解析结果”决定生成的结果文件，支持多选（例如选择 **Markdown 文件** 生成 Markdown 结果文件）；“表格输出格式”决定解析结果中的表格如何表达，可选 **HTML** 或 **Markdown**。

结果区域的 Markdown、JSON 是**查看方式**；这里的设置控制**输出内容**。查看 JSON 无需将输出文件选成 JSON。API 的文件输出选项由独立 API 参考说明。

## 补充解析要求

在高级设置的「自定义 Prompt」中填写补充说明（选填，最多 4000 字符）。

配置完成后提交解析任务，请参见[获取文档解析结果](raw/application-user-guide/getting-started-overview/overview/results-and-best-practices.md)。
