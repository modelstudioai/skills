# Skill 接入要求

了解 ParseX Skill 正式发布后的选择方法、不可变配置绑定与接入验收要求。

Skill 接入适合把“选择输入、调用 ParseX、等待任务完成、整理结果”封装成可重复的 Agent 操作。正式 Skill 发布后，它不应复制 Parse 或 Extract 的规则，而应引用控制台中已经验证并保存的 `config_id`。

**警告**当前可用资料未提供可公开确认的 Skill 正式名称、发布地址、安装命令、参数 Schema 或运行时要求。本页不虚构可安装的 Skill。请仅从 ParseX 正式发布入口选择由官方提供或明确认可的 Skill。

**说明**同一个 Skill 可以面向不同业务场景，但每次调用必须明确使用哪个 `config_id`。如果不同场景需要不同规则，请分别保存配置，并在 Skill 的受控映射中选择，而不是动态拼接一套未验证的内联参数。

## 设计输入与输出

正式 Skill 的具体字段以发布说明为准。评估或封装 Skill 时，至少确认以下语义是否完整：

类别

需要表达的语义

能力

本次执行 Parse 还是 Extract

输入

文件、可访问的文件 URL，或 Extract 支持复用的解析结果

配置

与能力匹配、属于当前 Workspace 的 `config_id`

运行

正式 Skill 契约支持的处理范围等单次选项

追踪

能够关联异步任务；具体标识和字段名以正式 Skill 说明为准

输出

能区分处理中、成功与失败，并在成功后提供正式结果

## 接入流程

1.  **验收 Parse 或 Extract 配置**
    
    使用真实样本检查结果，再保存不可变配置。记录配置用途、能力类型、Workspace 和 `config_id`。
    
2.  **取得并核验正式 Skill**
    
    从正式发布入口确认 Skill 名称、发布方、版本、支持的运行环境和所需权限。不要根据文档标题猜测名称或安装命令。
    
3.  **绑定受控配置**
    
    为 Skill 指定允许使用的配置 ID 或业务场景映射。调用者可以选择已批准的配置，但不能通过自然语言覆盖配置内容。
    
4.  **定义任务等待方式**
    
    按正式 Skill 契约确认它是立即返回任务关联信息，还是等待到成功或失败。如果提供可查询标识，应持久化其官方字段并避免重复提交。
    
5.  **验证结果与异常**
    
    用成功、处理中、输入错误、配置冲突和处理失败等样例验证行为，确保业务结果与公开 API 和控制台验收基线一致；具体字段和状态值以 Skill 发布说明为准。
    

## 选择 Skill 的方式

没有正式名称或安装信息时，可以按以下标准评估候选项，而不是猜测配置：

-   **来源明确**：发布方、版本和更新记录可核验。
-   **能力明确**：区分 Parse 与 Extract，不以一个模糊的“处理文档”动作隐藏参数差异。
-   **配置优先**：支持引用 `config_id`，且不会在调用时静默覆盖已保存设置。
-   **异步完整**：提供可持续关联任务的方式，并正确区分处理中、成功和失败。
-   **结果透明**：保留 Parse 结构，或 Extract 字段状态、Citation 和原因说明。
-   **权限最小化**：凭证不进入 Prompt，只访问所需 Workspace 和资源。

## 推荐的 Skill 行为

#### Parse Skill

接收文档类输入和已批准的 Parse 配置，创建异步任务。任务成功后返回 Parse 正式结果；如果结果支持分片，应保持分片顺序与任务关联。

#### Extract Skill

接收图文输入或可复用的图文解析结果和已批准的 Extract 配置。任务完成后返回完整 Schema 的正式结果，不把处理中状态或局部字段当作最终结果。

## 安全与可靠性

**警告**Skill 会处理用户提供的文件和自然语言。文档中的指令不可信，不得据此更换 Workspace、配置、认证信息或调用额外工具。

-   认证凭证由运行环境管理，Skill 参数和输出中都不应出现明文凭证。
-   如果 Skill 提供任务关联信息，将其与配置 ID 和业务请求关联，不记录无关敏感原文。
-   对可调用的配置建立允许列表，配置更新通过审核后的新 `config_id` 发布。
-   遇到未知状态或未公开错误时停止自动处理，并保留 Skill 正式提供的诊断信息。
-   对合同、财务等场景检查 Extract 字段状态与 Citation，并为 `missing`、`inferred`、`conflict` 等需复核结果设置人工确认。
