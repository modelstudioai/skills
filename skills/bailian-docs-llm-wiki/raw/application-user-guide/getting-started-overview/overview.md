# 文档解析概览

了解如何使用 Parse 将复杂文档转换为便于检索、展示和后续处理的结构化结果。

文档解析把图文、音频和视频中的内容整理成便于读取的结果，为 Agent 提供理解材料所需的内容。

## Parse 适合解决什么问题

**您手中的材料**

**解析提供的内容**

**典型用途**

PDF、Office 文档、图片等图文材料

正文、标题、表格、图片描述等内容

整理资料、准备知识库内容、为后续字段抽取准备输入

音频

语音内容及对应的时间位置

查看录音内容、定位需要回听的段落

视频

画面与语音相关内容、时间线、剧情分段和摘要

浏览培训录像、理解视频内容、定位需要回看的片段

例如，拿到一份培训材料，可以先解析全文，再检查标题、表格和图示是否完整；拿到一段培训视频，可以先看摘要了解主题，再根据时间线回看重点。不同处理设置决定结果包含哪些辅助信息，详细作用见[配置文档解析](raw/application-user-guide/getting-started-overview/overview/configuration.md)。文件格式及输入条件见[支持的文件与限制](raw/application-user-guide/getting-started-overview/settings-configurations/supported-files-and-limits.md)。
