抽取结果包含按字段整理的数据，以及用于核验的来源信息。

## 按字段核对原文

1.  打开**抽取字段详情**。
2.  找到要检查的字段，阅读字段值与来源页码。
3.  点击字段查看来源，并核对字段显示的来源页码。
4.  检查左侧原文当前页码。
5.  阅读数值周围的标题、期间、单位和注释，确认结果含义。
6.  对其他关键字段重复检查。

来源信息用于帮助你找到原文依据。核验时应同时检查来源页码、左侧实际显示的页面和正文内容，不能仅凭点击后的页面变化判断字段值准确。

例如，经营报告同一页可能同时出现本期数、上期数和计划值。核验预算承诺占用率时，还应确认它属于需要的统计期间，而不是只匹配一个相同的百分比。

## 查看并复制 JSON

切换到**抽取结果 JSON**，查看字段按配置组织后的结构。检查字段名、文本与数字表示、对象或列表的层级是否符合后续使用要求，再通过结果区的复制入口取得内容。
