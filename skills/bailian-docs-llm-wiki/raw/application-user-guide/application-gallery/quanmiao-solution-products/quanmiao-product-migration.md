## 2\. 视频理解（`video_postpaid`）— 视频分析与理解服务

### 推荐替代：百炼多模态/全模态模型

场景

推荐模型

能力说明

通用视频理解

qwen3.7-plus

支持文本+图像+视频输入，单视频最长 2 小时 / 2GB，1M 上下文。

成本敏感型

qwen3.6-flash

同样支持 2 小时 / 2GB 视频，效果略降但成本更低。

视频+音频同时理解

qwen3.5-omni-plus / qwen3.5-omni-flash

支持文本、图片、音频、视频组合输入，最长 1 小时视频，适合需要理解视频中人声/音效的场景。

长视频检索/问答

百炼知识库（音视频搜索）

对长视频做 ASR、帧提取、剧情解析，再向量化检索。

### 迁移路径

1.  短视频/单视频分析：直接调用 qwen3.7-plus 或 qwen3.6-flash 的 OpenAI 兼容接口，传入视频 URL 与 Prompt。
2.  长视频库检索：
    -   将视频上传至 OSS；
    -   在百炼知识库创建"音视频搜索"类型知识库；
    -   配置 ASR 转写与向量模型；
    -   通过 `Retrieve` API 做片段召回，再用 qwen3.7-plus 生成答案。
3.  若原接口封装了固定输出格式（标签、摘要、时间戳），可在新接口上通过 Prompt + JSON Mode 复刻输出 Schema。

### 注意事项

-   Qwen-Omni 系列要求 `stream=True`。
-   视频中的视觉信息与音频信息会分开计费，调用前需评估长视频成本。

### 其他可选方案

用户也可根据自身业务选择其他视频理解类产品或开源方案。同生态内可考虑阿里云视觉智能开放平台的视频分析能力。

## 7\. 智能审校 — 文稿内容审查校对

原能力定位：面向客户内容审查校对需求，基于千问模型支持文稿基础质量、安全合规、政敏性、企业专业知识、图片审核等场景，同时支持自定义词库、规则库与可信信源配置。

### 推荐替代：百炼智能审校 API + 通义千问自建

方案

产品/模型

说明

模型自建

qwen3.7-plus / qwen3.6-plus + Prompt 工程

对通用文本纠错、语法检查、政治敏感、合规风险等，通过系统 Prompt 定义审校维度与输出格式，用 JSON Mode 返回错误位置、原文、建议修改与依据。

安全合规

阿里云内容安全（Green）

针对涉政、暴恐、色情、违禁、侮辱、隐私等安全合规审核，可单独调用或与大模型审校串联。

文档/图片输入

阿里云文档智能（DocMind）+ qwen3.5-omni-plus

对 PDF/图片类稿件先解析为文本，再做审校；图片内容审核可直接用视觉模型或内容安全。

### 其他可选方案

开源方案可基于 Qwen、DeepSeek、ChatGLM 等模型通过 Prompt 工程实现文本纠错与合规审核，或结合开源中文文本纠错工具如 pycorrector、ERNIE-CSC、MacBERT-CSC 做错别字/语法检查，再由大模型做语义级审核。
