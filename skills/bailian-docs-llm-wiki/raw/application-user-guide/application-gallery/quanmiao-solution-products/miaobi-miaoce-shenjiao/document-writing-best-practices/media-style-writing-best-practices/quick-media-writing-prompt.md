# 快速写一篇传媒稿（prompt一步式撰写）

文章主题（prompt）

请围绕数字经济释放全新增长动力写一篇新闻

## 具体操作

1.  进入[妙笔](https://aimiaobi.console.aliyun.com/?product_code=g_broadscope_media&from=bailian#/home)首页，选择所需的写作类型（如**传媒写作**）。可选的写作类型还包括**公文写作**、**营销写作**、**办公写作**和**自定义写作**。
    
2.  选择顶部的**直接写作**页签。
    
3.  在直接写作配置面板中，完成以下设置：
    
    -   在**写作内容或主题**输入框中输入主题，例如”请围绕数字经济释放全新增长动力写一篇新闻”。
    -   在**文体**下拉框中选择写作类型，例如**新闻类 / 新闻写作**。
    -   在**文章篇幅**下拉框中选择字数，例如**600 字左右**。
    -   在**输出语言**下拉框中选择语言，例如**中文**。
    -   在**生成文章篇数**中选择篇数（1 篇、2 篇或 3 篇）。
    -   根据需要勾选**自动补充素材**或单击**自定义素材**添加引用素材。
    -   单击**开始写作**。
4.  此外，可在**引用素材**区域勾选**自动补充素材**或添加**自定义素材**。提交后，右侧编辑区显示"AI 妙笔正在处理：检索中……"状态提示，可点击**终止生成**中断操作。
    
    查看系统创建的内容是否符合预期：
    
    -   系统显示**AI 妙笔创作完成**，生成的文章下方展示**和参考资料的相似比**（如 19%）。确认内容符合预期后，单击**采纳**使用生成内容；如不满意可单击**弃用**放弃当前结果。
    -   如需对生成内容进行局部调整，可单击底部的**结果干预**按钮，对指定段落或句子进行修改。界面底部还会显示生成内容与参考资料的相似比（如 19%），供用户参考。
    -   如对整体结果不满意，可使用【换一换】功能对文章内容进行【直接换】（重写）、【扩写】或【缩写】等操作。
    
    **说明**
    
    -   续写：根据选中原文继续延伸。
    -   扩写：根据选中原文改动词汇，扩大字数。
    -   缩写：根据选中原文改动词汇，缩减字数。
    

## AI工具箱

-   单击文档编辑器右上角的**AI 工具箱**，展开功能菜单，其中还包含**全文翻译**、**抽取关键词**、**一键润色**、**文章审核**和**用户评论预测**等功能。
    
-   您可以根据实际的业务需求使用以下功能：
    
    -   **文风改写**：支持抒情、豪放、含蓄、激动、亲切、励志等风格。
    -   **生成标题**
    -   **生成摘要**
    -   **全文续写**
    -   **全文改写**
    -   **全文翻译**
    -   **抽取关键词**
    -   **一键润色**
    -   **文章审核**
    -   **用户评论预测**

## “搜索素材”丰富文章内容

1.  在妙笔首页右上角，单击**搜索素材**进入素材搜索页面。
    
2.  在搜索框内输入您要搜索的内容即可，如：亚运会。
    
    搜索结果生成后，单击右下角**\+ 加入素材库**按钮，在弹出的浮层中勾选**公共素材库**或**我的素材库**，然后单击**添加**按钮，即可将内容加入对应的素材库。
    
3.  在左侧导航栏单击**素材库**，即可在公共文档列表中查看已加入的素材文件，例如**亚运会-总结生成答案**。
