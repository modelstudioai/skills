在使用析言GBI进行数据查询、数据分析以及专属模型定制等操作时，将会产生相关费用。本文为您介绍了析言GBI的计费规则。

**购买产品、查看资源消耗**

-   **标准版MIX**
-   **标准版TURBO**

**产品订阅费**

-   标准版MIX：499元/月，默认包含5 RPM。
-   标准版TURBO：299元/月，默认包含5 RPM。

订阅产品后，每月额外赠送500次免费调用额度。

> RPM：Request Per Minute，每分钟最多处理的问题请求数量。

> 调用：使用自然语言对析言GBI进行一次提问即为一次调用/一个问题请求。若在结果返回前中断请求，调用次数仍会被消耗。

预付费

-   您可以单击[购买链接](https://common-buy.aliyun.com/?commodityCode=sfm_DataAnalysisGBI_public_cn)购买产品。
-   您可以在[首页](https://bailian.console.aliyun.com/xiyan?spm=a2c4g.11186623.0.0.6e316709xwHjvq#/home)左下角点击![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6570921371/p866249.png)图标查看已购买及赠送资源的消耗进度。

**增购RPM**

如果您有增加调用规模的需求，请自行增购RPM。

RPM起售单位为5个一组，1000元/5RPM每月。

预付费

**增购调用次数**

超出免费调用额度的部分，仅按照调用次数计费，不再收取Tokens费用：

-   标准版MIX：0.8元/每次调用
-   标准版TURBO：0.5元/每次调用

这部分费用将以后付费的方式从您的阿里云账户中扣除。

后付费

**定制版TURBO**

定制版TURBO仅用于定制化项目交付（包含使用定制模型进行付费POC项目交付）。若需购买定制版TURBO，请在下单前咨询对接的商务人员或[提交工单](https://smartservice.console.aliyun.com/service/robot-chat)至析言GBI产品研发团队。

## 常见问题

-   **如果当前产品仅支持5RPM，超出5RPM的请求将如何处理？**
    
    超出5RPM的请求会被系统拒绝，超出的问题将不会被处理，需要等待并发释放后重新提问。
    
-   **如何查看析言GBI的费用？**
    
    您可以在[明细账单](https://usercenter2.aliyun.com/finance/expense-report/expense-detail-by-instance)页面中，选择**产品名称**为**大模型服务平台百炼**，**商品名称**为**析言GBI**，然后单击**搜索**，查看析言GBI的费用。
