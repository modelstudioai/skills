# 影视互娱剧本创作

影视互娱剧本创作应用支持创作长篇幅的剧本，内置开放式指令并提供交互式写作体验，通过这些指令，用户可以逐步构建剧本的各个部分，从人物设定、场面设计、剧本主题到剧本构建和创作等，为用户创作剧本提供灵感。

**重要**影视互娱剧本创作应用限时免费，额度用完后再按实际调用模型对应的输入、输出Token以后付费方式来计费。

-   更多关于新用户限时免费福利信息，请参见新用户限时免费福利。
-   关于Token的计算方法和模型的计费详情，请参见计费项。

## 优势特点

支持开放指令和交互式写作。

-   接口标准与OpenAI的标准规范对齐；用法类似于调用大模型的方法，输入prompt即可使用；创作路径更灵活自由。
-   内置agent链路，能有效地解决剧本上下文逻辑对齐、细节遗忘的问题。

## 功能入口

访问**[应用广场](https://bailian.console.aliyun.com/#/app-market)**页面，单击**全妙-影视互娱剧本创作**卡片区域的**查看详情**，即可进入该轻应用控制台。

## 功能介绍

### 写剧本

你可以通过点击**怎么提问？**按钮构建剧本的各部分内容或者直接在对话框输入对剧本的要求。具体操作请参考以下步骤：

-   方式一：点击**怎么提问？**按钮构建剧本。
    
    1.  在**影视互娱剧本创作**的**效果调试**页签，点击**怎么提问？**按钮。
        
    2.  按照指令要求输入对应内容，点击即可开始生成剧本的相关内容。
        
        下图为生成的剧本相关内容示例。
        
-   方式二：直接在对话框中输入对剧本的要求。
    
    下图为生成的剧本相关内容示例。
    

### 整理剧本内容

1.  在**影视互娱剧本创作**的**效果调试**页签，点击**整理剧本**即可将剧本内容整理到对应模块（整理剧本功能实现一边写剧本，一边进行整理合并）。
    
2.  您可以在右侧窗口查看整理的剧本详情。
    
    您也可单击图标进入查看整理剧本的窗口。
    

### 下载剧本&复制剧本

1.  点击**下载剧本**，即可开始下载剧本内容。
    
    您也会看到如下窗口提示。
    
2.  每个段落剧本的内容都支持复制（点击图标）。
    

### 开启新剧本

点击**开启新剧本**并在二次确认对话框中点击**开启新剧本**，原始的剧本内容将被清空，用户可以开始写新的剧本。
