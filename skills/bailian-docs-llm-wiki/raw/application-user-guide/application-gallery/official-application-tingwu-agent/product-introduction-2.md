# 官方应用-通义听悟Agent产品简介

通义听悟 Agent 深度融合智能语音AI与千问大模型技术，面向企业办公（如：会议、面试、培训）、在线教育、销售服务洞察、汽车行业产-供-销（如：购车客户画像、工业语音质量等）分析等垂直行业场景，提供针对性音视频智能分析解决方案。通过“低门槛调用+高精度处理”双引擎驱动，助力企业快速挖掘业务数据价值。

## 应用介绍

-   [汽车销售服务洞察](raw/application-user-guide/application-gallery/official-application-tingwu-agent/tingwu-automotive-service-insights.md)：对汽车电话邀约、门店接待、试乘试驾、售后服务等售车全流程场景进行服务洞察，包含**服务流程、业务要求、优势介绍、竞品应对**等各类对话内容。全流程使用专属的汽车领域语音转文字（ASR）和模型监督微调（SFT）后的洞察模型，转写及洞察准确率高。可支持电话、手机、工牌、车载拾音等多种方式。
-   [购车客户画像](raw/application-user-guide/application-gallery/official-application-tingwu-agent/tingwu-automotive-customer-profile.md)：对客户购车过程中电话、门店、试驾等全流程场景，根据客户提到的问题进行客户画像，包括**车型配置、乘坐体验、用车成本、竞品反馈、订单优惠等各类关注点**，进行全方位的用户画像。为销售运营与销售人员提供推进客户跟进策略支撑，提高售卖转化率。使用强化语义理解与指令遵循的ccai-pro模型，确保高质量画像结果。
-   [通用服务洞察](raw/application-user-guide/application-gallery/official-application-tingwu-agent/tingwu-service-insights.md)：对电销、地推、门店接待、售后、客服、工单等各类场景进行服务洞察，包含服务流程、业务要求、优势介绍、竞品应对等各类对话内容。全流程使用通用语音转文字（ASR）和SFT后的洞察模型，转写及洞察准确率高。可支持电话、手机、工牌等多种方式。
-   [工业生产指令转写](raw/application-user-guide/application-gallery/official-application-tingwu-agent/tingwu-industrial-instruction.md)：对工业生产场景中产品质检或设备语音输入进行指令修正，面向专业词汇使用全链路大模型提升准确率，释放工人双手、提高生产效率。
-   [智能纪要](raw/application-user-guide/application-gallery/official-application-tingwu-agent/tingwu-meeting.md)：基于语音识别和大语言模型，对会议、访谈、课堂等场景下的实时或离线录音进行智能总结分析。支持章节速览、大模型摘要总结（全文摘要、发言总结、要点回顾、思维导图）、要点提炼（关键词、待办事项、场景识别）、PPT提取及摘要、口语书面化、自定义prompt等功能。

-   **大模型全面加持**：支持章节速览、大模型摘要总结（全文摘要、发言总结、要点回顾、思维导图）、要点提炼（关键词、待办事项、场景识别）、PPT提取及摘要、口语书面化、自定义prompt等功能。

## 产品优势

#### 内置业务属性

-   **汽车销售服务洞察**：内置70余个销售服务检查点，全面洞察销售服务质量。
-   **购车客户画像**：内置50余个购车客户关注点，以及3个概要评估分析，完整评估客户购车需求。

#### 完整Agent链路

-   **无代码配置**：支持界面可视化配置业务规则。
-   **界面验证效果**：即刻验证当前配置效果，界面化调整、对比确保应用效果与业务需求的匹配度。
-   **自动生成代码**：根据业务配置，自动生成全链路代码，最低接入成本实现最优效果。

#### 默认最优解与开放可调节

-   **默认最优模型链路集**：专业领域优化的汽车ASR模型，结合qwen-plus，与增强语义理解和指令遵循的ccai-pro模型级联，实现全链路多模型调用的最优解。
-   **模型开放可选**：ASR和分析模型有多种选择，满足各类业务偏好。
