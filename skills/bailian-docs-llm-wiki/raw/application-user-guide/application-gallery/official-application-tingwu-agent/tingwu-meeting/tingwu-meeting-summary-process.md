# 业务流程

本文为您介绍通义听悟-智能纪要 Agent 的业务流程案例。

## 业务流程

**① 明确使用场景：**根据实际业务需求，灵活选择实时转写或离线录音转写模式，确保适用不同会议与沟通场景，提升领域识别准确率。
