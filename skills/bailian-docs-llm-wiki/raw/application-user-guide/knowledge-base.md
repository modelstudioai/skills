# RAG 简介

阿里云百炼 RAG 是企业级知识库与检索服务：上传文档后，平台自动完成解析、切片、向量化与索引，并通过 API 提供知识检索与流式问答，连接你的私有知识与前沿大模型。

阿里云百炼 RAG 提供从数据接入到知识服务的一体化能力：文档上传后自动完成解析、切片、向量化与索引，再通过控制台或 API 提供多路召回检索与基于大模型的流式问答。
