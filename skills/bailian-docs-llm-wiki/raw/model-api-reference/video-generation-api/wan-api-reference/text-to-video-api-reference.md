# 万相2.7-文生视频API参考

万相2.7-文生视频模型基于 文本提示词 ，生成一段流畅的视频。

**相关文档**：[使用指南](../../../_short/text-to-video-guide-99fbc872809463c8.md)

<a id="适用范围"></a>

<a id="1fd78afa5brlj"></a>

## 适用范围

为确保调用成功，请务必保证**模型、Endpoint URL 和 API Key 均属于同一地域**。跨地域调用将会失败。

-   [**选择模型**](https://bailian.console.aliyun.com/cn-beijing/model/market)：前往模型广场选择模型，并确认其所属地域。
-   **选择 URL**：选择对应的地域 Endpoint URL，支持HTTP URL或 DashScope SDK URL。
-   **配置 API Key**：选择地域并[获取与配置 API Key](../../preparations/get-api-key.md)，再[配置API Key到环境变量](https://help.aliyun.com/zh/model-studio/configure-api-key-through-environment-variables)。
-   **安装 SDK**：如需通过SDK进行调用，请[安装DashScope SDK](../../preparations/install-sdk.md)。

> **说明**
>
> 本文的示例代码适用于**北京地域**。

> **重要**
>
> 阿里云百炼为华北2（北京）、新加坡地域推出了业务空间专属域名，**能够为推理请求提供卓越的性能和更高的稳定性**，建议迁移至新域名：
>
> -   华北2（北京）地域：从 `https://dashscope.aliyuncs.com` 迁移至 `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com`
> -   新加坡地域：从 `https://dashscope-intl.aliyuncs.com` 迁移至 `https://{WorkspaceId}.ap-southeast-1.maas.aliyuncs.com`
>
> 其中 `{WorkspaceId}` 为您的业务空间 ID，可在阿里云百炼控制台的**业务空间详情**页面查看。现有域名仍可正常使用。

## HTTP调用

> **重要**
>
> 此接口为**新版协议**，仅支持**wan2.7模型**。

由于文生视频任务耗时较长（通常为1-5分钟），API采用异步调用。整个流程包含 **“创建任务 -> 轮询获取”** 两个核心步骤，具体如下：

## 常见问题

<a id="q-从-wan2-6-升级到-wan2-7-代码需要改哪些地方"></a>

<a id="cd79eb5127f4j"></a>

#### Q: 从 wan2.6 升级到 wan2.7，代码需要改哪些地方？

A: 主要有两处变更，迁移时需调整参数：

-   **调整输出视频分辨率的控制方式**：wan2.7不再使用 `size` 字段，改为通过 `resolution`（分辨率档位）和 `ratio`（宽高比）两个字段组合来定义输出视频分辨率；而早期模型直接使用 `size` 字段。
-   **镜头类型字段移除**：wan2.7不再支持 `shot_type` 字段，该参数已弃用，可直接通过prompt来描述镜头类型；早期模型支持通过该字段控制镜头类型。
