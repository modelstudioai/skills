# 人物写真生成FaceChain

人物写真FaceChain，仅需要某个人物的2张照片，即可训练得到该人物的专属形象，并批量生成各种风格的写真照片。FaceChain基于扩散模型的图像生成能力，结合LoRA训练实现人像和风格融合，并叠加一系列后处理能力，实现兼具相似度、真实感、美观度的写真生成。

**重要**本文档仅适用于华北2（北京）地域，且必须使用该地域的[API Key](https://bailian.console.aliyun.com/model/settings/api-key)。
