# 获取 Skill

查询单个 Skill 的元数据和最新版本号。

## 接口

**GET** `/api/v1/skills/{skill_id}`

查询单个 Skill。自定义 Skill 返回主账号和工作空间下未删除的记录，包含 `checking` 和 `rejected` 状态；官方 Skill 仅返回 `active` 状态。

此接口不返回版本列表和下载地址。

## 请求参数

参数

类型

必填

说明

skill\_id

`string`

是

Skill ID

## 响应

返回 `SkillDTO`。

字段

类型

说明

id

`string`

Skill 唯一标识

display\_name

`string`

展示名称

display\_description

`string`

展示描述

source

`string`

`customer` 或 `official`

status

`string`

Skill 状态

latest\_version

`string`

最新版本号

classification

`string / null`

分类；官方 Skill 有值，自定义 Skill 为 `null`

meta\_info

`object / null`

官方 Skill 的元信息；自定义 Skill 为 `null`

created\_at

`string`

创建时间

updated\_at

`string`

更新时间

## 示例

```
curl "https://{workspace_id}.cn-beijing.maas.aliyuncs.com/api/v1/skills/skill_abc123" \
  -H "Authorization: Bearer $DASHSCOPE_API_KEY"
```

## 错误

HTTP 状态码

error\_code

说明

401

WORKSPACE\_ID\_ILLEGAL

身份信息缺失或无效

400

SKILL\_ID\_IS\_NULL

`skill_id` 为空白

500

SKILL\_NOT\_EXIST

Skill 不存在、已删除、无权访问或官方 Skill 未上架
