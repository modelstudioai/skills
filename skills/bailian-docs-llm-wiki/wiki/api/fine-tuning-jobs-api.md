# [fine tuning](../guides/fine-tuning.md) jobs api

模型调优（Fine-tuning）Jobs API 是阿里云百炼平台提供的用于通过微调训练定制专属模型的接口集合。开发者可以通过该 API 提交训练任务、查询任务状态、获取任务详情以及取消正在执行的训练作业，从而在通用大模型基础上构建面向特定业务场景的定制模型。完整的功能定义见 [模型调优](../../raw/model-api-reference/fine-tuning-jobs-api.md)。

## 核心能力

平台围绕"微调训练任务"这一核心对象，提供以下接口能力：

- **创建训练任务**：指定基座模型、训练文件及超参数，发起一次微调作业。
- **列举训练任务**：按分页查询当前账号下的微调任务列表，便于批量管理与监控。
- **获取任务详情**：根据任务 ID 拉取单次微调作业的完整配置、状态、产物与日志信息。
- **取消训练任务**：终止处于排队或训练中的作业，释放计算资源。

更多接口细节可参考 [模型调优](../../raw/model-api-reference/fine-tuning-jobs-api.md) 的原始描述。

## 关键参数

调用创建类接口时通常需要关注以下字段：

| 参数 | 说明 |
| --- | --- |
| `model` | 基座模型标识，决定微调的目标模型系列（如 Qwen 系列）。 |
| `training_file_ids` | 训练集文件 ID 列表，需先通过文件接口上传至平台。 |
| `validation_file_ids` | 可选的验证集文件 ID，用于训练过程中评估指标。 |
| `hyperparameters` | 训练超参数对象，常见字段包括 `n_epochs`、`learning_rate`、`batch_size` 等。 |
| `suffix` | 可选，训练完成后生成的定制模型后缀名，便于管理多个版本。 |

不同基座模型支持的超参数集合存在差异，提交前请核对目标模型的约束，详见 [模型调优](../../raw/model-api-reference/fine-tuning-jobs-api.md)。

## 任务生命周期

一个微调任务通常经历以下状态流转：

1. **queued** — 任务已提交，等待调度。
2. **running** — 训练进程正在执行。
3. **succeeded** / **failed** — 训练完成或异常终止。
4. **cancelled** — 用户主动取消。

成功完成后，系统会产出对应的微调模型，可在后续推理调用中作为 `model` 参数使用。

## 使用方式

典型的调用流程如下：

1. 准备好训练数据（JSONL 格式的 [prompt](../guides/prompt.md)-completion 对），通过文件接口上传获得 `file_id`。
2. 调用创建接口提交训练任务，传入基座模型、文件 ID 与超参数。
3. 通过列举或详情接口轮询任务状态，直到进入终态。
4. 任务成功后，使用产出的定制模型 ID 进行推理调用。

## 限制与注意事项

> **注意**：原始文档仅给出"通过微调训练定制专属模型"的一句概述，未详列具体限额。以下为平台常见约束，具体数值请以控制台或官方最新文档为准：

- 单次训练的数据条数与文件大小存在上限，超大样本需分批或抽样。
- 并发训练任务数受账号配额限制，高峰期可能需要排队。
- 不同基座模型支持的微调方式（全参数 / LoRA / Ptuning）与超参数范围不同，混用会导致任务失败。
- 训练文件需符合平台规定的格式 schema，否则任务会在数据校验阶段失败。
- 取消操作对已进入终态的任务无效，对 running 状态的任务会尽快终止但不保证立刻生效。
