# file management api

文件管理 API 用于管理上传至百炼平台的文件，提供上传、查询、列举和删除等操作能力。开发者可以通过这些接口将本地文件上传到百炼，并在后续任务（如模型推理、数据处理等）中引用已上传的文件。本文整理该 API 的核心使用方式与注意事项。

## 支持的操作

文件管理 API 围绕上传至百炼平台的文件提供以下四类核心操作，详见 [文件管理](../../raw/model-api-reference/file-management-api.md)：

- **上传文件**：将本地文件上传到百炼平台，上传成功后返回文件的唯一标识，供后续流程引用。
- **查询文件**：根据文件标识查询单个文件的元数据信息，例如文件名、大小、状态等。
- **列举文件**：分页列举当前账号下已上传的文件，便于批量管理与检索。
- **删除文件**：删除不再使用的文件，释放存储空间并保持文件列表整洁。

## 使用方式

调用文件管理 API 时，通常遵循"上传 → 拿到文件标识 → 在业务请求中引用 → 用完删除"的流程。上传是所有后续操作的前提，上传后获取到的文件标识是查询、列举、删除以及业务引用的关键凭证，相关说明可参考 [文件管理](../../raw/model-api-reference/file-management-api.md)。

## 注意事项

- 文件上传后会有生命周期管理，建议在文件不再被业务使用时及时调用删除接口，避免占用存储配额。
- 查询与列举接口返回的文件元数据可用于校验文件状态，确保在引用前文件处于可用状态。
- 文件管理 API 的具体参数、请求方式与返回字段以 [文件管理](../../raw/model-api-reference/file-management-api.md) 中的最新说明为准，本文为概览性整理。
