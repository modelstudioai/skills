# file management api

百炼平台提供文件管理 API，用于将本地文件上传到平台并在后续调用中复用（例如作为 RAG 知识库源、多模态输入等）。主要支持上传、查询、列举和删除四类操作。

## 支持的模型与功能

文件管理 API 属于平台基础能力，不限于某个特定模型，被广泛用于需要附加输入文件的场景，例如：

- **文档解析**：上传 PDF、Word、Markdown 等文档，供知识检索增强（RAG）流水线切块入库。
- **多模态输入**：上传图片、音视频文件，供视觉、语音类模型在对话中使用。
- **微调数据**：上传训练/验证集，用于模型微调任务。
- **批量推理输入**：为 Batch API 提供输入文件。

具体支持的文件类型与大小限制，请参见 [文件管理](../../raw/model-api-reference/file-management-api.md)。

## 关键参数

文件管理 API 的核心参数通常包括：

| 参数 | 说明 |
| --- | --- |
| `file` | 待上传的文件本体（multipart/form-data） |
| `purpose` | 文件用途，例如 `fine-tune`、`assistants`、`batch`、`data-exploration` 等，决定后续可被哪些接口消费 |
| `file_id` | 上传成功后平台返回的文件唯一标识，用于后续查询和删除 |

上传成功后会返回文件元信息（ID、文件名、字节数、创建时间、用途等），后续接口统一通过 `file_id` 引用该文件。

## 使用方式

典型调用流程如下：

1. **上传文件**：调用上传接口，指定 `purpose` 和文件内容，得到 `file_id`。
2. **查询文件**：通过 `file_id` 获取单个文件的元信息，确认状态（如处理中 / 就绪 / 失败）。
3. **列举文件**：按 `purpose` 过滤并分页列出当前账号下的所有文件。
4. **删除文件**：通过 `file_id` 删除不再需要的文件，释放配额。

不同用途（`purpose`）的文件会被路由到不同的下游系统，请根据实际场景选择正确的 `purpose`，否则后续接口可能无法消费该文件。详细的请求示例和返回字段说明见 [文件管理](../../raw/model-api-reference/file-management-api.md)。

## 限制与注意事项

- **文件大小与类型限制**：平台对单个文件的大小和允许的类型有上限，超出限制会上传失败。常见支持类型包括 PDF、DOCX、TXT、MD、PNG、JPG 等，具体以 [文件管理](../../raw/model-api-reference/file-management-api.md) 为准。
- **配额管理**：账号维度有文件总数与总容量上限，建议定期清理不再使用的文件。
- **异步处理**：部分用途的文件上传后需要异步解析（例如文档切块），在此期间文件状态为"处理中"，需轮询查询直到就绪后再投入业务使用。
- **权限与隔离**：文件按账号隔离，`file_id` 不具备跨账号访问能力；请勿将包含敏感信息的文件上传至平台。
- **幂等性**：重复上传同名文件会产生新的 `file_id`，不会自动覆盖，调用方需自行去重。
