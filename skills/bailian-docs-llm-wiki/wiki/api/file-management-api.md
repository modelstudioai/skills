# file management api

百炼平台提供文件管理 API，用于管理上传至平台的文件资源。通过该 API，开发者可以完成文件的上传、查询、列举和删除等操作，是使用百炼平台进行[模型微调](../concepts/fine-tuning.md)、知识库构建等场景的基础能力。详细接口说明请参考[文件管理](../../raw/model-api-reference/file-management-api.md)。

## 核心功能

文件管理 API 提供以下四项核心操作：

- **上传文件**：将本地文件上传至百炼平台，供后续模型训练、知识库等场景使用。
- **查询文件**：根据文件 ID 获取文件的详细信息，包括文件名称、大小、上传时间、状态等元数据。
- **列举文件**：批量获取已上传的文件列表，支持分页查询，便于管理和检索已有文件资源。
- **删除文件**：删除不再需要的文件，释放存储空间。

## 使用方式

开发者可通过 HTTP API 调用文件管理接口。典型的使用流程为：

1. 调用上传接口将文件上传至百炼平台，获取返回的文件 ID。
2. 使用文件 ID 调用查询接口确认文件状态，确保文件已就绪。
3. 在[模型微调](../concepts/fine-tuning.md)、知识库构建等业务流程中引用该文件 ID。
4. 业务完成后，可通过删除接口清理不再使用的文件。

具体的请求参数、响应格式及错误码等信息，请参考[文件管理](../../raw/model-api-reference/file-management-api.md)原始文档。

## 限制与注意事项

- 上传的文件需符合平台对文件格式和大小的限制要求，具体限制请查阅[文件管理](../../raw/model-api-reference/file-management-api.md)中的说明。
- 删除操作不可恢复，请谨慎执行。
- 文件上传后可能需要一定的处理时间，建议通过查询接口确认文件状态后再进行后续操作。
