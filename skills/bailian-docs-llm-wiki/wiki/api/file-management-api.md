# file management api

百炼平台提供文件管理 API，用于管理上传至平台的文件资源。该 API 支持文件的上传、查询、列举和删除四类核心操作，是构建基于百炼平台应用的基础能力之一。开发者可通过这些接口实现对训练数据、知识库文档等文件资源的全生命周期管理。

## 核心功能

文件管理 API 提供以下四类操作，详见[文件管理](../../raw/model-api-reference/file-management-api.md)：

- **文件上传**：将本地文件上传至百炼平台，供后续模型微调、知识库构建等场景使用。
- **文件查询**：根据文件 ID 查询已上传文件的详细信息，包括文件名、大小、上传时间、状态等元数据。
- **文件列举**：批量获取已上传文件的列表，支持分页查询，便于管理大量文件资源。
- **文件删除**：删除不再需要的文件，释放存储空间。

## 使用方式

根据[文件管理](../../raw/model-api-reference/file-management-api.md)文档，文件管理 API 采用 RESTful 风格，开发者可通过 HTTP 请求直接调用。典型的使用流程为：

1. 调用上传接口将文件传至平台，获取文件 ID。
2. 使用文件 ID 进行后续的查询、管理操作。
3. 在模型微调或知识库等场景中引用该文件 ID。
4. 文件不再需要时，调用删除接口清理资源。

## 限制与注意事项

根据[文件管理](../../raw/model-api-reference/file-management-api.md)的说明，使用文件管理 API 时需注意以下事项：

- 上传的文件需符合平台支持的格式和大小限制。
- 文件删除操作不可逆，删除前请确认文件未被其他资源引用。
- 文件上传后可能需要一定的处理时间，建议通过查询接口确认文件状态后再进行后续操作。
- 文件管理 API 的调用频率受平台 QPS 限制约束。
