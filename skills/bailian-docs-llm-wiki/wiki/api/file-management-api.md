# file management api

百炼平台提供文件管理 API，用于管理上传至平台的文件资源。该 API 支持文件的上传、查询、列举和删除四类核心操作，是使用百炼平台进行模型微调、知识库构建等场景的基础能力。开发者可通过 [文件管理](../../raw/model-api-reference/file-management-api.md) 接口完成文件全生命周期管理。

## 核心功能

根据 [文件管理](../../raw/model-api-reference/file-management-api.md) 文档，文件管理 API 提供以下四类操作：

- **上传文件**：将本地文件上传至百炼平台，供后续模型训练、知识库导入等场景使用。
- **查询文件**：根据文件 ID 查询已上传文件的详细信息，包括文件名、大小、上传时间、用途等元数据。
- **列举文件**：批量获取当前账号下已上传的文件列表，支持分页和筛选。
- **删除文件**：删除不再需要的文件，释放存储空间。

## 使用方式

开发者可通过 HTTP 请求调用文件管理 API。典型的使用流程为：

1. 调用上传接口将训练数据或知识库文件上传至平台。
2. 通过列举接口确认文件上传成功，获取文件 ID。
3. 在模型微调或知识库创建时引用对应的文件 ID。
4. 任务完成后，按需调用删除接口清理不再使用的文件。

## 注意事项

- 上传的文件需符合平台对文件格式和大小的限制要求，具体限制请参考 [文件管理](../../raw/model-api-reference/file-management-api.md) 中的说明。
- 删除文件前请确认该文件未被其他任务（如微调任务、知识库）引用，否则可能影响相关任务的正常运行。
- 文件上传后会分配唯一的文件 ID，后续所有操作均通过该 ID 进行引用。
