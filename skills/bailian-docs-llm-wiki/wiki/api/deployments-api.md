# deployments api

模型部署 API 用于将微调或导入的模型部署为在线推理服务，是百炼平台模型生命周期管理的关键环节。通过该 API，开发者可以将训练完成的自定义模型发布为可调用的推理端点，从而在生产环境中使用。详细信息请参考 [模型部署](../../raw/model-api-reference/deployments-api.md) 文档。

## 功能概述

模型部署 API 的核心功能是将以下类型的模型部署为在线服务：

- **微调模型**：通过百炼平台微调训练后产出的模型，可直接部署上线。
- **导入模型**：从外部导入的自定义模型，经过适配后也可通过该 API 完成部署。

部署完成后，模型将以在线推理服务的形式提供，支持通过标准 API 接口进行调用。关于模型部署的基本流程，参见 [模型部署](../../raw/model-api-reference/deployments-api.md) 中的说明。

## 使用方式

开发者可通过调用部署 API 完成模型的上线操作。典型流程如下：

1. 完成模型微调或导入。
2. 调用部署 API 创建推理服务实例。
3. 等待部署就绪后，通过返回的服务端点进行推理调用。

## 注意事项

- 部署前需确保模型已通过训练或导入流程，且状态为可用。
- 部署操作会占用计算资源，建议根据实际业务需求合理规划部署数量。
- 部署后的服务端点需妥善管理访问权限，避免未授权调用。

更多关于部署操作的具体要求和限制，请查阅 [模型部署](../../raw/model-api-reference/deployments-api.md) 原始文档。
