# model production

百炼平台提供一套完整的模型生产 API，覆盖从微调训练到压缩优化再到上线部署的全流程。开发者可以通过这些 API 将基础模型定制为满足业务需求的专属模型，并以在线服务的形式对外提供推理能力。本页汇总模型生产各环节的核心功能与使用方式。

## 模型调优

模型调优（Fine-tuning）是模型生产的第一步，允许开发者基于已有的基础模型进行微调训练，从而获得针对特定场景优化的专属模型。通过 [模型调优](../../raw/model-api-reference/model-production/fine-tuning-jobs-api.md) API，可以提交微调任务、查询任务状态以及管理训练产出的模型。

主要能力：

- 创建微调训练任务，指定基础模型和训练数据
- 查询和管理微调任务的运行状态
- 获取训练完成后的定制模型

## 模型压缩

当微调后的模型体积较大或推理成本较高时，可以使用 [模型压缩](../../raw/model-api-reference/model-production/model-compression-api.md) API 对模型进行量化等压缩处理。压缩能够在保持模型效果的前提下显著降低推理资源消耗，适用于对延迟和成本敏感的生产场景。

主要能力：

- 对微调模型执行量化压缩
- 降低模型推理时的计算资源需求
- 在精度与效率之间取得平衡

## 模型部署

完成调优和（可选的）压缩后，需要通过 [模型部署](../../raw/model-api-reference/model-production/deployments-api.md) API 将模型部署为在线推理服务。部署成功后，即可通过标准的推理 API 调用该模型。

主要能力：

- 将微调或导入的模型部署为在线推理服务
- 管理部署实例的生命周期（创建、查询、删除）
- 配置推理服务的资源规格

## 典型工作流

模型生产的典型流程如下：

1. **准备训练数据** — 整理并上传用于微调的数据集
2. **提交微调任务** — 调用模型调优 API 启动训练
3. **（可选）压缩模型** — 对训练产物执行量化压缩以降低推理成本
4. **部署模型** — 将最终模型部署为在线服务
5. **调用推理** — 通过推理 API 使用已部署的模型

## 注意事项

- 模型调优、压缩、部署均为异步操作，提交后需轮询或通过回调获取最终状态
- 部署服务会持续产生费用，不再使用时应及时删除部署实例
- 并非所有模型都支持压缩，具体支持情况请参考各 API 的模型兼容性说明
