# [model compression](../guides/model-compression.md) api

百炼平台提供模型压缩 API，支持通过量化等技术手段压缩模型体积，从而降低推理成本并提升部署效率。该功能适用于需要在资源受限环境中部署大模型的场景。详细说明请参考[模型压缩](../../raw/model-api-reference/model-compression-api.md)。

## 核心功能

模型压缩的主要目标是在尽量保持模型精度的前提下减小模型体积、降低计算开销。根据[模型压缩](../../raw/model-api-reference/model-compression-api.md)文档，当前支持的核心能力包括：

- **量化压缩**：通过降低模型权重的数值精度（如从 FP16 到 INT8/INT4）来减小模型大小，是最常用的压缩方式。
- **推理成本优化**：压缩后的模型在推理阶段占用更少的显存和计算资源，适合大规模部署。

## 使用方式

调用模型压缩 API 可以对指定模型执行压缩操作。具体的 API 调用方式和参数配置请参考[模型压缩](../../raw/model-api-reference/model-compression-api.md)原始文档获取最新的接口规范。

## 适用场景

- 需要将大规模语言模型部署到边缘设备或资源受限环境
- 希望在保持模型效果的同时降低推理服务的运营成本
- 批量推理场景中需要提升吞吐量

## 注意事项

- 量化压缩可能会对模型精度产生一定影响，建议在压缩后对关键任务进行效果验证
- 不同模型对压缩的兼容性不同，请确认目标模型是否在支持列表中
