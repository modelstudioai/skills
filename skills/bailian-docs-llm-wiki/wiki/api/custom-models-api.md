# custom models api

百炼平台支持将自定义模型导入并进行部署与推理，使开发者能够在统一的平台上管理和调用自有模型。通过模型导入功能，用户可以将外部训练好的模型接入百炼生态，享受平台提供的推理服务与管理能力。详细的导入流程请参考 [模型导入](../../raw/model-api-reference/custom-models-api.md)。

## 功能概述

自定义模型导入功能允许开发者将自行训练或第三方提供的模型部署到百炼平台。根据 [模型导入](../../raw/model-api-reference/custom-models-api.md) 文档，该功能的核心目标是实现自定义模型在百炼平台上的统一部署和推理调用。

## 使用方式

开发者可通过百炼平台的模型导入接口完成自定义模型的接入。具体操作步骤和 API 调用方式请参阅 [模型导入](../../raw/model-api-reference/custom-models-api.md) 原始文档获取最新信息。

## 注意事项

- 导入的模型需符合平台支持的格式和规范要求
- 部署后的模型通过平台统一的推理接口进行调用
- 建议在正式部署前先在测试环境中验证模型的兼容性和推理效果
