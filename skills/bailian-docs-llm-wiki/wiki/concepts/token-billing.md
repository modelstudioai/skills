# Token 计量与计费

Token 是百炼平台衡量模型输入与输出量的基本单位，平台以 Token 为核心构建了覆盖模型调用、模型训练和模型部署的完整计费体系。1 个汉字约折合 1.5–2 个 Token，1 个英文单词约 1.3 个 Token。

## Token 在不同场景中的计量方式

百炼平台根据模型类型和使用场景，采用不同的 Token 计量方式：

| 模型类型 | 计量单位 | 说明 |
|---------|---------|------|
| 大语言模型（文本生成/深度思考/视觉理解） | Token | 按输入和输出 Token 数分别计费 |
| 全模态模型 | Token | 文本按 Token 数，其他模态按对应 Token 数折算 |
| 向量模型 | Token | 按输入文本的 Token 数计费 |
| 图像生成 | 张 | 按成功生成的图像张数计费 |
| 视频生成 | 秒 | 按成功生成的视频秒数计费 |
| 语音模型 | 秒/字符/Token | 视具体模型而定 |

每个模型都有最大输入和最大输出 Token 数限制，超过限制会导致请求失败。

## 按量付费与阶梯计费

模型调用默认按量计费，即按实际消耗的输入/输出 Token 数量乘以对应单价结算。部分模型实行阶梯计费：单价取决于单次请求的输入 Token 总量，该请求的所有 Token 均按对应阶梯的单价结算。

以千问系列为例（华北2-北京）：

| 模型 | 输入单价（每百万 Token） | 输出单价（每百万 Token） |
|------|----------------------|----------------------|
| qwen3.7-max | 12 元 | 36 元 |
| qwen3.7-plus | 2 元（0~256K） | 8 元 |
| qwen-plus | 0.8 元（0~128K） | 2 元（非思考）/ 8 元（思考） |

支持 Batch 调用的模型，输入和输出 Token 单价按实时推理价格的 50% 计费；支持上下文缓存的模型，仅输入 Token 享有折扣。两者不能同时生效。

## 模型训练中的 Token 计费

模型训练按训练过程中消耗的 Token 总量计费：

- **文本生成模型**：训练费用 =（训练数据 Token 总数 + 混合训练数据 Token 总数）x 循环次数 x 训练单价。
- **图像生成模型**：训练费用 = 训练 Token 总量 x 训练单价。Token 总量由 `max_steps` 和每步 Token 消耗量决定。
- **视频生成模型**：涉及视频计费时长、`max_pixels` 和 `n_epochs` 三个因素。

## 模型部署中的 Token 计费

模型部署支持多种计费方式，其中与 Token 直接相关的包括：

- **按 Token 使用量**：按实际推理消耗的 Token 计费。
- **预置吞吐（按时长）**：费用与购买的输入/输出 TPM（Tokens Per Minute）挂钩。若超出购买的 TPM 量，调用自动切换为按量付费（API 返回 `x-dashscope-ptu-overflow:true`）。

## TPM 预留与容量计算

TPM 预留允许为指定模型锁定专属推理吞吐量（单位 kTPM），预留容量内的调用不额外收费。容量计算需考虑：

- **每分钟请求数（RPM）**、平均输入/输出 Token 长度
- **缓存折扣**：Qwen 系列缓存命中部分按 20% 折算容量，deepseek-v4-pro 按 8% 折算
- **长输入阶梯系数**：部分模型在输入超过特定长度后，输入/输出系数有所调整

超出预留容量的请求自动降级为按量计费，服务不中断。

## Token Plan 团队版的 Credits 机制

Token Plan 团队版采用 Credits 统一计量体系，将不同模型的 Token 消耗折算为统一的 Credits 进行抵扣。抵扣顺序为：坐席套餐月度额度 > 共享用量包 > 额度用尽后暂停服务。Credits 消耗量由模型类型、输入/输出/缓存 Token 数量等因素决定。

## 免费额度

首次开通百炼时，平台自动发放各模型的新人免费额度（有效期 30–90 天），仅限华北2（北京）地域的实时推理费用，不支持抵扣 Batch 调用、模型调优和模型部署。额度可在控制台的模型用量页面查看。

## 成本优化建议

- **合理设置 `max_tokens`**：控制输出长度以避免不必要的 Token 消耗。
- **按任务选模型**：简单任务优先选择轻量级模型（如 qwen3.6-flash），降低单价。
- **利用 Batch 调用**：对延迟要求不高的场景，输入/输出 Token 单价降至 50%。
- **购买节省计划**：AI 通用型节省计划通过承诺月消费额换取阶梯折扣，最高 5.3 折。
- **监控 Token 用量**：通过模型监控功能跟踪 Token 消耗趋势，设置告警阈值防止费用异常。

抵扣优先级：免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费。

## 关键参数

| 参数 | 说明 |
|------|------|
| `max_tokens` | 限制单次请求的最大输出 Token 数，直接影响费用 |
| `enable_thinking` | 开启思考模式会产生额外的思考 Token，部分模型思考 Token 单价更高 |
| `model` | 不同模型的 Token 单价差异显著，选型直接影响成本 |
