# Token 计费与成本管理

Token 是百炼平台统一的计量单位。模型推理按输入 / 输出 Token 计费，图像与视频按张 / 秒折算为 Token，语音按秒 / 字符折算为 Token。成本管理围绕"降低单价、压缩用量、预警超额"三条主线展开，贯穿从新人免费额度到生产环境长期运营的全生命周期。

## 新人免费额度

首次开通百炼的用户，平台按模型发放一次性免费推理额度，有效期 30～90 天。免费额度仅抵扣实时推理 Token，不支持 Batch、模型调优、模型部署及任何自定义模型的费用抵扣，主账号与 RAM 子账号共享同一份额度。

额度耗尽后的行为取决于两项配置：

- **免费额度用完即停**：开启后额度耗尽即返回 `AllocationQuota.FreeTierOnly` 错误，停止响应，避免意外扣费。
- **未开启即停**：已认证用户超出部分按输入 / 输出单价直接计入后付费账单。

建议在控制台「模型用量 > 免费额度」页签查看余量与过期时间，并在"我的试用"中配置 20% / 100% 的短信与站内信预警。

## 推理计费模型

### 按量后付费

模型调用按输入 Token 与输出 Token 分别计费，分钟级出账、按月结算。部分模型实行**阶梯计费**——单次请求的输入 Token 总量决定该请求所有 Token 适用的单价档位（例如 0 < Token ≤ 32K 与 32K < Token ≤ 128K 两档，输入 100K Token 时整次请求按第二档结算）。

影响单价的关键因素：

| 因素 | 说明 |
| --- | --- |
| 思考模式 vs 非思考模式 | 部分模型（如 qwen-plus）对思考链路（思维链）输出单独定价，通常高于非思考模式 |
| 地域差异 | 同一模型在华北 2（北京）、新加坡、美国（弗吉尼亚）、德国（法兰克福）的单价不同 |
| 模型规格 | Max > Plus > Turbo 级别，单价依次递减 |

### 降低推理单价的手段

| 手段 | 折扣力度 | 适用场景 |
| --- | --- | --- |
| Batch 调用 | 输入 / 输出单价均按实时推理的 50% 计费 | 非实时大批量任务 |
| 上下文缓存 | 输入 Token 享有折扣，与 Batch 互斥 | 长上下文、重复前缀场景 |
| Token Plan 团队版 | 以 Credits 统一计量，坐席包月 | 团队协作日常办公 |
| Coding Plan Pro | 按调用次数包月，¥200/月 | 个人 AI 编程 |
| 节省计划 / 资源包 | 承诺消费换折扣，或一次性购买固定额度 | 可预估月度用量 |

### 图像、视频、语音的计量单位

| 模型类型 | 统计单位 |
| --- | --- |
| 大语言模型（文本 / 深度思考 / 视觉理解） | Token |
| 图像生成 | 张 |
| 视频生成 | 秒 |
| 语音模型 | 秒、字符或 Token（视模型） |
| 全模态模型 | Token（其他模态折算） |
| 向量模型 | Token |

## 训练与部署计费

### 训练计费

训练按消耗的 Token 总量 × 训练单价计费，最小计费单位 1 Token。不同模态的计算方式：

- **文本生成模型（千问系列）**：费用 = (训练数据 Token + 混合训练数据 Token) × 循环次数 × 单价。
- **图像生成模型（万相）**：训练 Token ≈ max_steps × L_max（由 generation_type 与 max_token_length 决定）。
- **视频生成模型（万相）**：训练 Token = Σ(视频计费时长) × (max_pixels / 1024) × n_epochs。

### 部署计费

训练完成后须做模型部署才能对外调用。部署有两种形态：

- **预置吞吐**：按"输入 TPM × 输入单价 + 输出 TPM × 输出单价 × 时长"计费。后付费按小时、预付费按天结算。超出最长输入 Token 或 TPM 上限时自动降级为按量付费，API Header 返回 `x-dashscope-ptu-overflow: true`。
- **模型单元**：部分模型提供按使用时长或按 Token 使用量两种维度，兼顾文本与多模态场景。

预付费订单支付后立即生效，22:00 后下单到期日自动顺延 1 天；到期后服务延后 2 小时停止，资源再保留 14 小时后释放。

## 节省计划与资源包

对于稳定用量场景，应优先使用承诺消费方案压降单价：

- **AI 通用型节省计划**：承诺一段时间内的消费金额，换取对应模型家族的折扣单价，支持续订。
- **其他模型节省计划**：针对语音、向量与排序等细分模型家族的专用承诺消费计划。
- **资源包**：一次性购买固定 Token / 次数额度，适合可预估用量的场景。

选型思路：先估算月度用量与模型分布，再对比"按量付费 vs 节省计划 vs 资源包"的等效单价。

## 账单查询与成本管控

所有计费统一进入阿里云账户体系，可在控制台通过以下工具核对与管控：

- **费用概览 / 账单详情**：在"费用与成本"页面按"产品名称 = 大模型服务平台百炼"筛选，可下载账单并解读输入 / 输出 / 免费额度抵扣用量。
- **分账管理**：按[业务空间](workspace.md)或项目维度拆分成本，便于多团队共用账号场景下的内部结算。
- **模型监控**：调用结束一小时后可在"模型监控"页面按时段、[业务空间](workspace.md)查看调用量、Token 消耗与错误率，高级监控支持分钟级数据洞察与 Prometheus HTTP API 接入。
- **告警配置**：对监控指标设置阈值，异常时通过短信、邮件、电话、钉钉群机器人等渠道通知团队。
- **高额消费预警**：按产品与日阈值短信提醒，从源头控制意外支出。
- **欠费处理**：账户欠费时所有模型（含仍有免费额度的模型）都停止服务；后付费场景下欠费保留资源继续计费 24 小时后再释放。

若需彻底关停计费，应删除所有 API-Key，避免遗留调用继续产生费用。

## 生产环境成本优化建议

- **控制输出长度**：通过 `max_tokens` 参数限制单次生成长度。
- **按任务选模型**：简单任务优先选用轻量级模型（如 Turbo / Flash）以降低成本。
- **批量推理**：非实时大批量任务使用 Batch 接口，单价减半。
- **优化 Prompt**：简洁清晰的 Prompt 可减少不必要的 Token 消耗。
- **监控与告警**：配置模型监控告警，及时发现用量异常。
- **套餐选型**：团队协作考虑 Token Plan 团队版，个人编程考虑 Coding Plan Pro，避免 API Key 混用导致无法抵扣套餐额度。
