# 业务空间

业务空间（Workspace）是阿里云百炼平台中进行资源隔离、权限管控和费用分账的最小管理单元。每个业务空间归属于一个特定地域，不可跨地域存在，所有模型调用、数据资源和 API Key 均以业务空间为边界进行划分和管理。

## 核心作用

业务空间在百炼平台中承担三个核心职责：

- **资源隔离**：不同业务空间之间的数据、知识库、Prompt 模板、API Key 等资源完全隔离，互不可见。
- **权限管控**：通过业务空间维度控制用户对模型调用、模型训练、[模型部署](model-deployment.md)、控制台页面等功能的访问权限。
- **费用分账**：模型用量和费用按业务空间维度独立统计，便于成本归属和预算管理。

## 使用场景

### API 调用与凭证管理

所有百炼应用组件 API 均以 `WorkspaceId` 作为必传参数，标识操作发生在哪个业务空间。API Key 与业务空间强绑定——单个 API Key 只能归属一个地域内的一个业务空间和一个用户，不可转移。API Key 的可调用模型和限流配额继承自所属业务空间的设定。

RAM 用户在调用 API 前，需要先被加入到目标业务空间中，否则无法访问该空间下的资源。

### 权限管理

业务空间内的权限体系包含三种角色：

| 角色 | 权限范围 |
|------|---------|
| 超级管理员 | 可跨地域、跨空间管理所有权限，包括模型调用与限流、模型调优/部署、用户管理、API Key 管理 |
| 业务空间管理员 | 管理本空间内的用户权限和 API Key，自动拥有该空间全部页面访问权限 |
| 普通用户 | 仅能访问被授权的资源 |

默认业务空间无法设置模型调用、调优和部署的限制，所有支持的模型均可使用且无法限流。非默认业务空间可由超级管理员精细化配置模型权限和限流策略。

### 监控与用量统计

模型用量数据按业务空间维度统计，不支持按阿里云账号维度直接汇总。开发者可在控制台的模型用量页面按空间查看各模型的调用量和费用。如需查看账号总用量，需在账单详情页面导出账单。

监控指标（如 Token 消耗追踪、性能监控、告警配置）同样以业务空间为数据聚合维度，支持按 `workspace_id` 过滤。

### 数据安全与安全存储

百炼支持通过业务空间权限管理实现不同用户间的数据隔离。对安全性要求更高的场景，平台提供**安全存储业务空间**，支持在私有网络环境中部署应用，数据存储在客户自有的 ElasticSearch、AnalyticDB 和 OSS 中。安全存储业务空间需联系商务人员申请开通，且仅支持华北2（北京）地域。

## 关键参数与配置

| 参数/配置 | 说明 |
|----------|------|
| WorkspaceId | 业务空间唯一标识，API 调用时必传 |
| 地域 | 业务空间所属地域，当前支持华北2（北京）和新加坡 |
| 模型调用权限 | 控制哪些模型可在该空间中被调用（控制台和 API） |
| 请求数限流（RPM/QPM） | 限制该空间内模型的每分钟请求数 |
| Token 限流（TPM） | 限制该空间内模型的每分钟 Token 消耗量 |
| 模型训练/部署权限 | 控制该空间是否允许模型调优和部署操作 |

## 最佳实践

- **按环境划分空间**：为开发、测试、生产创建独立业务空间（如 `project-dev-workspace`、`project-prod-workspace`），实现环境隔离。
- **限流配额预留**：将主账号总配额按比例分配给各业务空间，建议预留 10% 作为缓冲应对突发流量。
- **最小权限原则**：使用 RAM 用户而非主账号操作，按需授予 `AliyunBailianDataFullAccess` 或 `AliyunBailianDataReadOnlyAccess` 权限。
- **API Key 归属清晰**：每个 API Key 归属明确的业务空间和用户，便于权限审计和问题排查。
