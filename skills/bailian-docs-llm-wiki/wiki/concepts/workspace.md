# 业务空间

业务空间（Workspace）是阿里云百炼平台的最小管理单元，用于在特定地域内对用户、模型、API Key 和资源进行隔离与权限管控。每个业务空间绑定一个地域，不可跨地域存在。

## 核心特性

- **地域绑定**：单个业务空间只能归属一个地域（如华北2-北京、新加坡等），不同地域的业务空间完全独立。
- **权限隔离**：业务空间内的模型调用、模型训练、模型部署权限可独立配置，实现细粒度管控。
- **资源归属**：API Key、应用、知识库等资源均归属于具体的业务空间，跨空间不可互通。

## 权限体系

百炼基于业务空间提供三级角色模型：

| 角色 | 范围 | 关键能力 |
| --- | --- | --- |
| 超级管理员 | 跨空间 | 管理所有空间的用户、模型调用/训练/部署授权、限流、API Key |
| 业务空间管理员 | 本空间 | 管理本空间的用户、页面权限、API Key |
| 普通用户 | 本空间 | 按授权访问空间内的页面和资源 |

超级管理员包括阿里云主账号和拥有 `AliyunBailianFullAccess` 策略的 RAM 用户。业务空间管理员是拥有该空间「权限管理」页面访问权的 RAM 用户，其权限自动包含空间下所有页面的访问权限。

## 业务空间与 API Key

- 单个 API Key 只能归属**一个地域**内的**一个业务空间**和**一个用户**，不可转移。
- API Key 的可调用模型和限流策略与归属空间保持一致，不受用户控制台页面权限影响。
- 默认业务空间的 Key 可调用所有标准模型；子业务空间的 Key 仅可调用该空间已授权的模型。
- 调优后部署的模型仅能由其所在业务空间的 Key 调用，无需额外授权。
- 无需为不同模型类型（文生文、文生图、语音合成等）创建不同的 API Key。

> 自 2026 年 3 月 25 日起，华北2（北京）地域新建的 API Key 均归属主账号。

## 默认业务空间与子业务空间

- **默认业务空间**：主账号开通百炼后自动创建，无法设置模型调用、调优和部署的限制，所有支持的模型均可使用且无法限流。
- **子业务空间**：由超级管理员创建，可精细配置模型调用权限和限流策略，适用于生产环境的权限隔离。

## 监控与用量

- **用量统计**按业务空间维度聚合，数据延迟约 1 小时。如需按账号维度汇总，需导出账单详情。
- **模型监控**自动采集主账号下所有业务空间的调用数据，支持按 `workspace_id` 维度筛选指标。

## 多空间规划建议

生产环境建议按以下方式划分业务空间：

- **按环境划分（推荐）**：为开发、测试、生产创建独立空间，如 `project-dev-workspace`、`project-prod-workspace`，实现权限与资源隔离。
- **按业务线划分**：为不同部门或业务线创建独立空间，便于权限管理和成本核算。

### 限流分配

将主账号总配额按比例分配给各业务空间，建议预留 10% 作为缓冲。例如总配额 1000 QPM：

| 空间 | 配额 | 占比 |
| --- | --- | --- |
| 生产 | 600 QPM | 60% |
| 测试 | 200 QPM | 20% |
| 开发 | 100 QPM | 10% |
| 缓冲 | 100 QPM | 10% |

## 跨地域调用

新加坡与法兰克福地域的 Base URL 需包含业务空间 ID（`WorkspaceId`），格式如 `https://{WorkspaceId}.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1`。华北2（北京）和美国（弗吉尼亚）地域使用固定域名，无需嵌入空间 ID。
