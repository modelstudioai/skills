# 业务空间

业务空间（Workspace）是阿里云百炼平台中进行精细化权限管理、资源隔离和账单分账的最小管理单元。每个业务空间归属于特定地域，不能跨地域存在，各地域的默认业务空间也是相互独立的空间。

## 核心定位

业务空间在百炼平台中承担三个核心职责：

- **权限隔离**：以业务空间为边界划分用户角色与资源访问权限，实现多地域、多用户的组织架构管控。
- **资源管控**：对模型调用、模型训练、模型部署进行空间级的精细化授权和限流。
- **成本分账**：用量统计按业务空间维度汇总，便于不同团队或项目独立核算费用。

## 角色体系

每个业务空间内定义了三种角色，权限范围自上而下递减：

| 角色 | 权限范围 |
| --- | --- |
| 超级管理员 | 阿里云主账号或拥有 `AliyunBailianFullAccess` 策略的 RAM 用户，可跨空间管理用户、模型授权、限流和 [API Key](api-key.md) |
| 业务空间管理员 | 拥有该空间「权限管理」页面访问权限的 RAM 用户，可管理空间内用户与资源 |
| 普通用户 | 根据分配的权限使用被授权的空间、页面和资源 |

## 默认业务空间与子业务空间

- **默认业务空间**：每个地域自动创建，所有模型均可调用、调优和部署，无法设置模型调用限制、训练限制或部署限制。
- **子业务空间**：由管理员手动创建，可对模型调用、训练、部署进行精细化授权，并设置请求数限流和 [Token](token.md) 限流。适合按环境（dev/test/prod）或业务线划分以实现权限隔离和成本管控。

## 模型与 [API Key](api-key.md) 管理

业务空间内可对模型进行三类精细化授权：

- **限制模型调用**：控制模型是否可在该空间内调用（控制台和 API），并设置请求数和 [Token](token.md) 限流。
- **限制模型训练**：控制模型是否可在该空间内进行调优及调优后部署。
- **限制模型部署**：控制模型是否可在该空间内直接部署。

单个 [API Key](api-key.md) 只能归属一个地域内的一个业务空间和一个用户，且不能转移。API Key 的可调用功能与模型限流继承归属业务空间的权限设置，不受用户控制台权限影响。将 RAM 用户移出业务空间会使其 API Key 失效（重新加入后恢复）。

## 在不同场景中的使用

### 用量统计与监控

模型用量数据按业务空间维度统计，不支持按阿里云账号维度汇总。模型监控列表按"模型 + 业务空间"维度生成，默认业务空间成员可查看所有空间的调用情况，子业务空间成员仅能查看当前空间数据。

### 数据管理

训练集和评测集统一归属于业务空间下管理，用于模型调优和评测。数据管理与数据处理能力仅适用于华北2（北京）地域。

### 应用观测

应用观测功能监控业务空间内的[智能体应用](agent-application.md)、工作流应用和高代码应用的调用链路与指标。被观测应用必须属于当前业务空间且已发布。

### Prompt 工程

Prompt 模板、样例库等功能在业务空间内管理和关联。部分 Prompt 功能仅适用于特定地域，使用前需确认目标业务空间所在地域。

## 生产环境最佳实践

- **空间规划**：推荐按环境（dev/test/prod）划分业务空间实现隔离，或按业务线划分便于权限与成本管理。
- **限流策略**：将主账号总配额按比例分配给各业务空间并预留缓冲。例如总配额 1000 QPM，可分配 prod 600 / test 200 / dev 100，预留 100。
- **API Key 管理**：避免使用默认业务空间的 API Key（权限过大），为不同团队创建子业务空间并仅授权必要模型。
