# 业务空间

业务空间（workspace）是阿里云百炼平台进行精细化权限管理、资源隔离与成本核算的最小管理单元，单个业务空间绑定一个地域，不能跨地域存在。

## 在百炼中的角色

业务空间贯穿百炼的权限、安全、监控、数据与应用等多个场景，是几乎所有平台能力的归属单元：

- **权限与身份管理**：业务空间是模型调用、调优、部署授权以及用户控制台权限管理的最小单元。超级管理员、业务空间管理员、普通用户三种角色围绕空间展开授权。默认业务空间无法设置模型级限制（所有模型均可调用、调优、部署），仅非默认业务空间才能对模型进行精细化授权与限流。
- **安全与合规**：业务空间作为权限隔离边界，配合 AI 安全护栏、传输加密、VPC 私网访问等能力构成完整安全链路。生产环境推荐按 dev/test/prod 环境或业务线划分业务空间，实现隔离并便于成本管理。
- **模型用量与监控**：用量数据按业务空间维度统计，不支持按阿里云账号维度统计。模型监控列表按"模型 + 业务空间"维度生成，默认业务空间成员可查看所有空间的调用情况，子业务空间成员仅能查看当前空间数据。
- **数据管理**：业务空间统一管理其下的大模型相关数据集（训练集与评测集），数据清洗与增强等操作在空间内进行。数据管理能力目前仅适用于华北2（北京）地域。
- **应用观测**：应用观测以业务空间为范围追踪智能体、工作流、高代码应用的处理流程，若列表中看不到应用，常见原因是应用尚未发布或应用不属于当前业务空间。

## 关键参数与配置

- **地域绑定**：业务空间按地理区域划分（北京、新加坡、弗吉尼亚等），各地域的默认业务空间也是不同的空间。同一个 [API Key](api-key.md) 只能归属一个地域内的一个业务空间和一个用户，且不能转移。
- **模型限流**：在非默认业务空间中，可为模型设置请求数限流和 [Token](token.md) 限流。推荐将主账号总配额按比例分配给各空间并预留缓冲，例如总配额 1000 QPM 分配为 prod 600 / test 200 / dev 100，预留 100。
- **[API Key](api-key.md) 归属**：[API Key](api-key.md) 的可调用功能与模型限流与归属业务空间权限保持一致，不受用户控制台权限影响。自 2026 年 3 月 25 日起，华北2（北京）地域所有新创建的 API Key 均归属主账号，并支持设置 IP 访问白名单。将 RAM 账号移出业务空间会使其 API Key 失效（重新加入后恢复），在 RAM 控制台删除账号则永久失效。

## 常用配置流程

1. 由超级管理员为非默认业务空间开通目标模型的调用、调优、部署权限。
2. 通过控制台「权限管理」页签为 RAM 用户添加业务空间管理员或普通用户权限，并配置可访问页面。
3. 在模型列表为空间设置限流策略，将主账号配额按比例分配到各空间。
4. 按环境或业务线规划业务空间划分，实现权限隔离与成本核算。
