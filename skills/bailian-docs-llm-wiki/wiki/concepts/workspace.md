# 业务空间

业务空间（Workspace）是阿里云百炼平台的**最小管理单元**，用于在权限控制、模型调用、计量计费、监控告警等维度实现精细化隔离。所有资源（API Key、模型调用权限、监控数据、用量统计等）均绑定到某个具体的业务空间下。开发者通常按环境（dev / test / prod）或按业务线划分空间，把主账号总配额按比例分配到各空间并预留缓冲。

## 地域与架构约束

- 业务空间按**地理地域**划分，单个业务空间**不能跨地域存在**。
- 支持在单个主账号下创建多个地域、多个空间，形成跨地域的多空间架构。
- 北京、新加坡、弗吉尼亚等地域的 API Key 互相独立，模型调用与监控也按地域隔离。

## 角色体系

百炼在业务空间之上构建了三种角色：

| 角色 | 范围 | 关键能力 |
| --- | --- | --- |
| 超级管理员（主账号 / 拥有 `AliyunBailianFullAccess` 的 RAM 用户） | 跨地域、跨空间 | 管理用户、模型调用/训练/部署授权、限流、API Key |
| 业务空间管理员 | 单个空间 | 管理本空间的用户、页面权限、API Key |
| 普通用户 | 单个空间 | 按授权访问空间、页面和资源 |

> 业务空间管理员权限自动包含该空间下所有页面的访问权，但**不包含**模型调用限流、模型调优 / 部署等超管专属能力。

## 权限与资源绑定

业务空间承载以下核心权限维度：

- **模型调用控制**：管理模型是否可在该空间调用（控制台及 API），并设置请求数（QPM）与 Token（TPM）限流。
- **模型训练控制**：管理模型是否可进行调优及调优后部署。
- **模型部署控制**：管理模型是否可直接部署。
- **用户控制台权限**：管理 RAM 用户对该空间控制台功能的访问权限。

> **注意**：默认业务空间无法设置模型调用、调优和部署的限制，所有支持的模型均可使用且无法限流；生产环境建议使用非默认空间并显式配置。

## API Key 与空间的关系

- 单个 API Key 只能归属**一个地域**内的**一个业务空间**和**一个用户**，不可转移。
- API Key 的可调用模型与限流与归属空间保持一致，**不受用户控制台页面权限影响**。
- 临时 API Key 继承生成它的永久 Key 的全部权限（含模型、知识库访问限制），同样受所属空间约束。
- 自 2026 年 3 月 25 日起，华北 2（北京）地域新建的 API Key 均归属主账号。

## 监控与计量维度

百炼的模型监控与用量统计以业务空间为基本维度：

- **用量统计**：按空间维度聚合 Token / 张 / 秒等消耗，延迟约 1 小时。
- **监控指标**：安全、成本、性能、错误四类指标按空间采集，高级监控可过滤 `workspace_id`。
- **告警规则**：可按特定空间下的模型设置阈值与通知渠道。
- **Prometheus 接入**：通过 `workspace_id` 标签可在 Grafana 中按空间拆分看板。

## 子空间隔离调用

在子业务空间场景下，可通过 API 指定 `workspace_id` 实现隔离调用——单次请求的模型调用、计量、监控均计入目标子空间，而非调用方所在空间。适合 SaaS 平台为下游租户单独核算成本与配额。

## 生产环境规划建议

- **按环境划分（推荐）**：为开发、测试、生产创建独立空间，如 `project-dev-workspace` / `project-prod-workspace`。
- **按业务线划分**：为不同部门创建独立空间，便于权限与成本隔离。
- **配额分配**：将主账号总配额按比例分配给各空间（如生产 60%、测试 20%、开发 10%、缓冲 10%），避免单一空间耗尽全局资源。
- **权限最小化**：生产空间的 API Key 仅颁发给必要服务账号；结合 RAM 策略 `AliyunBailianDataReadOnlyAccess` / `AliyunBailianDataFullAccess` 控制 OpenAPI 调用范围。

## OpenAPI 权限补充

RAM 用户默认**无权**调用百炼应用、知识库、Prompt 工程等 OpenAPI，需由主账号在 RAM 控制台授予 `AliyunBailianDataFullAccess` 或 `AliyunBailianDataReadOnlyAccess` 策略。该授权作用于主账号下所有空间，空间本身不提供 OpenAPI 级别的额外权限切分。
