# 业务空间

业务空间（Workspace）是阿里云百炼平台中资源隔离与权限管理的最小管理单元，用于在逻辑上划分和隔离不同业务场景下的模型、数据、API Key 及用户权限。每个业务空间归属于一个特定地域，不可跨地域存在。

## 核心概念

业务空间在百炼平台中承担多重职责：

- **权限隔离**：不同业务空间内的用户权限、模型授权、API Key 相互独立，互不影响。
- **资源管理**：模型调用、调优、部署等操作的权限均以业务空间为粒度进行管控。
- **成本分账**：用量统计和费用账单按业务空间维度聚合，便于成本归属与核算。
- **限流控制**：可为每个业务空间独立设置请求数限流（QPM）和 Token 限流，实现精细化流量治理。

## 业务空间与权限体系

百炼平台基于业务空间构建了三级角色权限模型：

| 角色 | 说明 |
|------|------|
| 超级管理员 | 阿里云主账号或拥有 `AliyunBailianFullAccess` 策略的 RAM 用户，可跨地域、跨空间管理所有权限 |
| 业务空间管理员 | 拥有某个业务空间「权限管理」页面访问权的 RAM 用户，自动获得该空间下所有页面的访问权限 |
| 普通用户 | 根据管理员分配的权限，使用业务空间内被授权的资源 |

业务空间管理员可管理的权限维度包括：

- **模型调用控制**：管理模型在该空间内是否可被调用（控制台及 API），并设置限流。
- **模型训练控制**：管理模型是否可进行调优及调优后部署。
- **用户控制台权限**：管理 RAM 用户对该空间控制台功能页面的访问权限。

> **注意**：默认业务空间无法设置模型调用、调优和部署的限制，所有支持的模型均可使用且无法限流。

## API Key 与业务空间

API Key 是调用百炼模型和应用的凭证，与业务空间强绑定：

- 单个 API Key 只能归属于**一个地域**内的**一个业务空间**和**一个用户**，不可转移。
- API Key 的可调用功能和模型限流继承其所属业务空间的设置，不受用户控制台权限的影响。
- 用户被移出业务空间后，其名下的 API Key 自动失效；重新加入后恢复。
- 无需为不同模型类型（文生文、文生图、语音合成等）创建不同的 API Key。

## 业务空间在 API 中的使用

在调用百炼应用组件 API（`bailian/2023-12-29`）时，`WorkspaceId` 是大部分接口的必填参数，用于指定操作所在的业务空间。典型场景包括：

- 数据连接管理：在指定业务空间内创建类目、上传文件、管理知识库。
- [Prompt 工程](prompt-engineering.md)：在指定业务空间内管理 Prompt 模板。
- 应用管理：在指定业务空间内创建和管理应用。

子业务空间隔离调用也常用于生产环境，通过为不同环境或业务线分配独立空间来实现资源和权限的物理隔离。

## 安全存储业务空间

百炼还提供一种特殊类型——安全存储业务空间，支持在私有网络环境中部署应用，数据存储在客户自有的 ElasticSearch、AnalyticDB 和 OSS 中。该类型空间需要联系商务人员申请开通，且仅支持华北2（北京）地域。

## 监控与用量

模型用量统计以业务空间为维度展开，开发者可在控制台查看各空间内模型的调用量和费用。监控指标（如调用次数、调用时长、首 Token 延时等）也支持按 `workspace_id` 进行过滤，方便定位特定空间的性能问题。

## 生产环境最佳实践

- **按环境划分（推荐）**：为开发、测试、生产环境创建独立业务空间（如 `project-dev-workspace`、`project-prod-workspace`），实现环境隔离。
- **按业务线划分**：为不同部门或产品线创建独立空间，便于权限管理和成本核算。
- **限流分配**：将主账号总配额按比例分配给各业务空间，建议预留 10% 作为缓冲。例如总配额 1000 QPM 可分配为：生产 600、测试 200、开发 100、缓冲 100。
- **最小权限原则**：为每个空间内的用户仅授予必要的页面和模型权限，避免过度授权。
