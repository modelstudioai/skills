# 业务空间

业务空间（Workspace）是阿里云百炼平台中进行资源隔离和精细化权限管理的最小单元。每个业务空间归属于特定地域，不能跨地域存在，用于承载模型调用、API Key 管理、用量监控和应用观测等业务活动。

## 核心特性

- **地域隔离**：单个业务空间只能属于一个地域，即使各地域的默认业务空间也是彼此独立的。
- **默认空间与自定义空间**：每个地域自动创建一个默认业务空间，默认空间无法限制模型调用、调优和部署权限，所有模型均可使用且无法设置限流。自定义空间则支持完整的权限管控。
- **多租户支持**：通过创建多个业务空间，可以实现不同团队、环境或业务线之间的资源与权限隔离。

## 权限管理中的业务空间

业务空间是百炼权限体系的核心维度，超级管理员和业务空间管理员可在空间内执行以下管控操作：

| 权限维度 | 说明 |
|---------|------|
| 模型调用限制 | 控制特定模型在该空间内的调用权限，并设置 QPM 和 Token 限流 |
| 模型训练限制 | 控制模型在该空间内的调优和调优后部署权限 |
| 模型部署限制 | 控制模型在该空间内的直接部署权限 |
| 用户控制台权限 | 管理 RAM 用户在该空间内可使用的控制台功能页面 |

超级管理员拥有跨空间管理权限，业务空间管理员仅可管理其所在空间内的用户权限和 API Key。

## API Key 与业务空间

API Key 是业务空间中重要的凭证资源，关键规则如下：

- 每个 API Key 只能归属于一个地域内的一个业务空间和一个用户，不可转移。
- API Key 的可调用功能和限流配置与其归属业务空间的权限一致，不受用户控制台权限影响。
- 将用户移出业务空间后，该用户的 API Key 失效；重新加入后恢复。
- 华北2（北京）地域的 API Key 支持设置 IP 访问白名单。

## 应用组件 API 中的业务空间

百炼应用组件 API（`bailian/2023-12-29`）的所有接口均需在业务空间上下文中调用。调用时通过 `WorkspaceId` 参数指定目标空间，接口操作（如文件管理、知识库、Prompt 模板等）的数据均隔离在该空间内。

## 监控与用量统计

业务空间是监控数据的统计维度：

- **模型用量**按业务空间维度统计各模型的调用量和 Token 消耗，不支持按账号维度直接汇总。如需查看账号级总用量，需通过费用与成本页面导出账单。
- **应用观测**在业务空间范围内追踪应用调用链路，查看调用次数、Token 用量、延时等指标。
- **模型监控**的告警和高级监控数据同样按业务空间组织。

## 安全存储业务空间

对于数据隔离要求严格的企业用户，百炼提供安全存储业务空间。该类型空间通过私网终端节点将百炼平台与用户自有的云资源（OSS、AnalyticDB、ElasticSearch）连通，确保数据在用户控制的环境中存储和处理。

## 生产环境空间规划建议

- **按环境划分（推荐）**：为开发、测试、预发和生产环境创建独立业务空间，实现严格的环境隔离。例如 `project-dev-workspace`、`project-test-workspace`、`project-prod-workspace`。
- **按业务线划分**：为不同业务部门创建独立业务空间，便于权限和成本管理。
- **限流分配**：将主账号总配额按比例分配给各业务空间并预留缓冲。例如总配额 1000 QPM 时，生产空间 600 QPM（60%）、测试空间 200 QPM（20%）、开发空间 100 QPM（10%）、预留 100 QPM（10%）。
