# 业务空间

业务空间（Workspace）是阿里云百炼平台中进行精细化权限管理、资源隔离和阿里云账单分账的最小管理单元。每个业务空间按地域划分，单个业务空间不能跨地域存在。

## 核心作用

业务空间在百炼平台中承担以下职责：

- **权限隔离**：以空间为边界控制用户对模型、页面和资源的访问权限
- **模型管控**：限制空间内可调用、可调优、可部署的模型范围，并设置请求数和 [Token](token.md) 限流
- **成本管理**：用量数据按业务空间维度统计，支持分账核算
- **资源归属**：[API Key](api-key.md)、应用、数据集等资源均归属于特定业务空间

## 空间类型

百炼提供两种业务空间：

| 类型 | 特点 |
| --- | --- |
| 默认业务空间 | 每个地域自动创建，所有模型均可调用且无法设置限流，不支持模型调用/训练/部署限制 |
| 子业务空间 | 由超级管理员创建，支持精细化的模型授权与限流配置，适合多团队或多环境隔离 |

## 地域隔离

业务空间严格按地域隔离，各地域的默认业务空间是完全独立的空间。[API Key](api-key.md) 只能归属一个地域内的一个业务空间，不同地域的 [API Key](api-key.md) 不互通。当前支持的地域包括华北2（北京）、新加坡、弗吉尼亚等。

## 权限管理模型

业务空间内的权限管理围绕三种角色展开：

- **超级管理员**：可跨空间管理用户权限、模型授权和限流，包括阿里云主账号和拥有 `AliyunBailianFullAccess` 策略的 RAM 用户
- **业务空间管理员**：管理特定空间内的用户权限和资源，拥有该空间所有页面的访问权限
- **普通用户**：根据分配的权限使用被授权的空间、页面和资源

## 模型授权与限流

在子业务空间中可进行三类精细化模型管控：

- **限制模型调用**：控制模型是否可在该空间调用（控制台和 API），并设置请求数限流和 [Token](token.md) 限流
- **限制模型训练**：控制模型是否可在该空间进行调优及调优后部署
- **限制模型部署**：控制模型是否可在该空间直接部署

## 数据与监控

- **用量统计**：按业务空间维度汇总模型调用量，不支持按阿里云账号维度统计；如需账号级汇总需通过费用与成本页面导出账单
- **模型监控**：系统自动采集主账号下所有业务空间的模型调用数据，默认业务空间成员可查看所有空间数据，子业务空间成员仅能查看当前空间
- **应用观测**：按业务空间管理被观测应用，应用必须属于当前业务空间才会出现在观测列表中

## 生产环境实践

- **按环境划分**：推荐按 dev/test/prod 创建子业务空间实现隔离
- **按业务线划分**：便于权限与成本管理
- **限流策略**：将主账号总配额按比例分配给各业务空间并预留缓冲（如总配额 1000 QPM，可分配 prod 600 / test 200 / dev 100，预留 100）

## 关键参数

| 参数 | 说明 |
| --- | --- |
| workspace_id | 业务空间唯一标识，API 调用时通过请求头或参数指定 |
| 地域 | 业务空间所属地域，决定可用模型和数据存储位置 |
| 模型调用限流 | 请求数限流（QPM）和 [Token](token.md) 限流，仅子业务空间可配置 |
