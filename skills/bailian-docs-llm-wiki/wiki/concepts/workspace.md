# 业务空间

业务空间（Workspace）是阿里云百炼平台中的最小管理单元，用于实现权限控制、资源隔离和账单分账。每个业务空间归属于一个地域，不能跨地域存在，是组织和管理模型调用、用户权限、API Key 及用量统计的核心边界。

## 基本概念

- 业务空间按地理区域划分，单个业务空间不能跨地域存在。
- 每个阿里云账号可在同一地域下创建多个业务空间，用于隔离不同环境或业务线的资源。
- 业务空间是权限管理、模型调用控制、用量统计和费用核算的基本维度。

## 权限管理

业务空间内的权限体系包含三种角色：

| 角色 | 职责范围 |
|------|---------|
| 超级管理员 | 跨地域、跨空间管理所有权限，包括模型调用与限流、模型调优与部署、用户管理等 |
| 业务空间管理员 | 管理本空间内的用户权限、API Key 分配，自动拥有该空间所有页面的访问权限 |
| 普通用户 | 根据分配的权限使用资源 |

超级管理员包括阿里云主账号和拥有 `AliyunBailianFullAccess` 策略的 RAM 用户。业务空间管理员是拥有该空间"权限管理"页面访问权的 RAM 用户。

### 业务空间级权限维度

- **模型调用控制**：管理模型是否可在该空间调用（控制台及 API），并设置请求数限流和 Token 限流。
- **模型训练控制**：管理模型是否可进行调优及调优后部署。
- **模型部署控制**：管理模型是否可直接部署。
- **用户控制台权限**：管理 RAM 用户对该空间控制台功能页面的访问权限。

> 默认业务空间无法设置模型调用、调优和部署的限制，所有支持的模型均可使用且无法限流。

## API Key 与业务空间

- 单个 API Key 只能归属一个地域内的一个业务空间和一个用户，不可转移。
- API Key 的可调用功能和模型限流与归属业务空间一致，不受用户控制台权限管理的影响。
- 华北2（北京）地域的 API Key 支持设置 IP 访问白名单。
- 用户被移出业务空间后，其名下的 API Key 自动失效；重新加入后恢复。

## 用量统计与监控

业务空间是用量统计和模型监控的基本维度：

- **用量统计**：在控制台的模型用量页面，按业务空间维度查看各模型的调用量和费用。
- **Token 消耗追踪**：按业务空间维度汇总模型的历史 Token 消耗，支持按时间范围和 API Key 筛选。
- **告警配置**：支持对调用统计和性能指标设置阈值告警。

> 用量数据按业务空间维度统计，不支持按阿里云账号维度直接统计。如需查看账号总用量，可在账单详情页面导出账单查看。

## 安全存储业务空间

百炼还提供安全存储业务空间，支持在私有网络环境中部署应用，数据存储在客户自有的 ElasticSearch、AnalyticDB 和 OSS 中，适用于对数据安全有更高要求的场景。

## 应用组件 API 中的业务空间

百炼应用组件 API 的所有操作均在业务空间维度下执行。RAM 用户需获取相应权限策略（如 `AliyunBailianDataFullAccess`）并加入业务空间后方可调用 API。子业务空间也可用于隔离不同环境的 API 调用。

## 生产环境最佳实践

### 空间规划

- **按环境划分（推荐）**：为开发、测试、生产环境创建独立空间，如 `project-dev-workspace`、`project-prod-workspace`，实现环境隔离。
- **按业务线划分**：为不同部门创建独立空间，便于权限管理和成本核算。

### 限流策略

将主账号总配额按比例分配给各业务空间，预留缓冲应对突发流量，避免单个空间占满全局配额导致其他空间不可用。
