# 业务空间

业务空间（Workspace）是阿里云百炼平台进行精细化权限管理和账单分账的最小管理单元。每个业务空间按地域隔离，单个业务空间不能跨地域存在，各地域的默认业务空间也是独立的空间。

## 核心作用

业务空间在百炼平台中承担以下职责：

- **权限隔离**：以业务空间为边界划分用户角色与资源访问范围，实现多地域、多用户的组织架构管理。
- **成本管控**：用量统计、费用概览、模型限流均按业务空间维度汇总，是账单分账的基础单元。
- **资源归属**：API Key、应用、数据集、模型调用记录等资源均归属于特定业务空间。

## 角色与权限体系

业务空间的权限管理围绕三种角色展开：

| 角色 | 权限范围 |
| --- | --- |
| **超级管理员** | 阿里云主账号或拥有 `AliyunBailianFullAccess` 策略的 RAM 用户，可跨空间管理用户、模型授权、限流和 API Key |
| **业务空间管理员** | 拥有特定业务空间「权限管理」页面访问权限的 RAM 用户，可管理该空间内的用户与资源 |
| **普通用户** | 根据分配的权限访问和使用被授权的空间、页面及资源 |

默认业务空间成员可查看所有业务空间的模型调用情况；子业务空间成员仅能查看当前空间数据，无法切换查看其他业务空间。

## 模型管控能力

在非默认业务空间中，超级管理员可对模型进行三类精细化授权（默认业务空间无法设置这些限制）：

- **限制模型调用**：控制模型是否可在该空间调用（控制台与 API），并设置请求数限流和 Token 限流。
- **限制模型训练**：控制模型是否可在该空间进行调优及调优后部署。
- **限制模型部署**：控制模型是否可在该空间直接部署。

## API Key 与业务空间

单个 API Key 只能归属一个地域内的一个业务空间和一个用户，且不能转移。API Key 的可调用功能与模型限流与归属业务空间的权限保持一致，不受用户控制台权限管理的影响。将 RAM 账号移出业务空间会使其 API Key 失效（重新加入后恢复），在 RAM 控制台删除账号则会使 API Key 永久失效。

## 监控与观测

- **模型监控**：系统自动采集主账号下所有业务空间的模型调用数据，监控列表按「模型 + 业务空间」维度生成。
- **用量统计**：模型用量数据按业务空间维度统计，不支持按阿里云账号维度统计。如需账号级汇总，需通过费用与成本页面导出账单。
- **应用观测**：应用观测范围限定于当前业务空间内已发布的应用，添加观测时需确认应用属于当前空间。

## 数据管理

业务空间统一管理其下的大模型相关数据集（训练集和评测集），用于模型调优和评测。数据管理与数据处理能力仅适用于华北2（北京）地域。

## 生产环境实践建议

- **空间规划**：推荐按环境（dev/test/prod）或按业务线划分业务空间，实现权限与成本的精细化管理。
- **限流策略**：将主账号总配额按比例分配给各业务空间并预留缓冲。例如总配额 1000 QPM，可分配 prod 600、test 200、dev 100，预留 100。
- **安全合规**：AI 安全护栏、模型监控、应用观测等功能建议使用主账号一次性开通，避免子账号权限不全导致开启失败。
