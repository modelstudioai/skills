# 业务空间

业务空间（Workspace）是阿里云百炼平台中用于权限控制、资源隔离和账单分账的最小管理单元。每个业务空间归属于一个特定地域，不可跨地域存在，是组织多用户、多环境协作的核心抽象。

## 核心作用

业务空间在百炼平台中承担三项关键职责：

- **权限隔离**：不同业务空间之间的用户权限、模型访问权限和 API Key 互相独立，实现细粒度的访问控制。
- **资源管理**：模型调用、调优、部署等操作均以业务空间为边界，超级管理员可按空间分配模型权限和限流配额。
- **费用分账**：模型用量按业务空间维度统计，便于多部门、多项目的成本核算。

## 角色与权限体系

业务空间内的权限管理基于三种角色：

| 角色 | 说明 |
|------|------|
| 超级管理员 | 拥有 `AliyunBailianFullAccess` 策略的主账号或 RAM 用户，可跨地域、跨空间管理所有权限 |
| 业务空间管理员 | 负责特定业务空间内的用户权限和资源管理，自动拥有该空间下所有页面的访问权限 |
| 普通用户 | 根据分配的权限使用资源，无管理权限 |

> **注意**：默认业务空间无法设置模型调用、调优和部署的限制，所有支持的模型均可使用且无法限流。非默认业务空间需由超级管理员显式开通模型权限。

## API Key 与业务空间

单个 API Key 只能归属一个地域内的一个业务空间和一个用户，具有以下特性：

- API Key 不可跨空间转移。
- API Key 的可调用功能和限流策略与归属业务空间一致，不受用户控制台权限管理的影响。
- 用户被移出业务空间后，其名下的 API Key 自动失效；重新加入后恢复。
- 华北2（北京）地域的 API Key 支持设置 IP 访问白名单。

## 监控与用量

业务空间是模型用量统计和监控的基本维度：

- 模型用量页面按业务空间展示各模型的调用量和费用数据。
- 模型监控的 Token 消耗追踪按业务空间汇总，支持按 API Key 进一步筛选。
- 外部监控系统接入时，可通过 `workspace_id` 标签过滤特定业务空间的指标。

> 用量数据不支持按阿里云账号维度直接统计。如需查看账号总用量，可在阿里云费用与成本页面导出账单。

## 安全存储业务空间

百炼提供安全存储业务空间，支持在私有网络环境中部署应用，数据存储在客户自有的 ElasticSearch、AnalyticDB 和 OSS 中，适用于对数据安全有更高要求的场景。

## 空间规划最佳实践

- **按环境划分（推荐）**：为开发、测试、生产环境创建独立业务空间（如 `project-dev-workspace`、`project-prod-workspace`），实现环境隔离。
- **按业务线划分**：为不同部门或项目创建独立空间，便于权限和成本管理。
- **限流策略**：将主账号总配额按比例分配给各业务空间，预留缓冲应对突发流量。

## 多地域注意事项

- 单个业务空间不能跨地域存在，每个地域需独立创建和管理业务空间。
- API Key 按地域隔离，北京、新加坡、弗吉尼亚三个地域的 API Key 互相独立。
- 模型监控告警规则的地域必须与业务空间所在地域一致。
