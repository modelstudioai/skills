# 智能体应用

智能体应用是阿里云百炼平台提供的三种核心应用构建模式之一，采用自然语言配置（零代码），由 AI 自主理解用户意图、动态规划执行路径，并调用知识库、MCP 工具等外部能力完成任务。适合智能客服、知识问答、任务助理等开放式对话场景。

## 版本与架构

百炼智能体应用分为两套架构：

| 维度 | 旧版（Agent 1.0） | 新版（Agent 2.0） |
| --- | --- | --- |
| 规划与调度 | 先检索知识库，再决策是否调用 MCP | 知识库、MCP 统一为工具，自主规划调用顺序 |
| 过程透明度 | 仅展示最终结果 | 完整展示每轮"规划-执行-反思"链路 |
| 适用场景 | 意图单一、流程固定的简单任务 | 从简单问答到复杂规划的各类任务 |

旧版与新版基于不同技术架构，不兼容，不支持直接升级或降级。无旧版依赖时推荐使用 Agent 2.0。

## 创建流程

1. 在百炼控制台进入应用管理，单击 **创建应用** > **智能体应用** > **Agent 2.0**。
2. 填写应用名称，单击 **立即创建**。
3. 在模型选择器中选择模型（推荐具备强工具调用能力的模型，如千问-Max 系列）。
4. 在右侧对话框中验证效果。

## 核心能力配置

- **模型参数**：最长回复长度、temperature、enable_thinking（仅支持思考模式的模型可配置）。
- **系统提示词**：定义角色、行为指令与能力边界，支持嵌入自定义变量（输入 `/` 引用）。
- **预解析文件**：关闭时文件 URL 作为上下文传递，由智能体决策是否调用工具处理；开启时系统自动解析文档、图像、视频、音频并返回文本内容。
- **知识库**：作为工具由智能体自主规划调用，支持通过标签限定查询范围。
- **MCP**：外部工具以 MCP 协议统一接入，包括官方 MCP 广场和自定义 MCP 服务。
- **应用组件**：将已发布的智能体或工作流作为工具接入当前应用。
- **记忆**：短期记忆支持 0–30 轮上下文（0 表示不传递多轮记录）。
- **回复设置**：开启"展示回答来源"后以角标形式展示知识来源和源文件地址。
- **ReAct 最大轮次**：取值 1–50，限制单次会话中工具调用的最大次数。

## 文件问答

文件问答是智能体应用的子能力，支持上传文件后与内容进行智能问答，提供三种处理模式：

| 模式 | 机制 | 适用场景 |
| --- | --- | --- |
| 全文引用 | 文件内容整体传给模型 | 文档总结、全文翻译 |
| 切片检索（RAG） | 文件切片后检索相关片段 | 长文档问答、精确定位 |
| 自定义处理 | 文件信息传给模型，自主调用外部工具 | 图片风格转换、视频分析 |

单次会话上传上限 10 个文件，单文件不超过 10 MB。聊天窗口上传的文件仅当前会话有效。

## API 调用

智能体应用通过 DashScope SDK 或 HTTP API 集成到业务系统，调用接口与工作流应用完全相同：

```
POST https://dashscope.aliyuncs.com/api/v1/apps/{APP_ID}/completion
Authorization: Bearer $DASHSCOPE_API_KEY
Content-Type: application/json

{
  "input": { "prompt": "你的问题" },
  "parameters": {},
  "debug": {}
}
```

多轮对话支持两种方式：使用 `session_id`（系统自动管理历史，有效期 1 小时，最多 50 轮）或自行管理 `messages` 数组（更灵活）。此外，Managed Agents API 提供智能体托管运行时，通过 REST API 管理智能体、会话、环境、技能与文件五类资源，无需自建基础设施。

## 发布与分享

智能体应用支持多种发布渠道：

- **官方网页版**：部署为带有效期的网页应用，默认 7 天。
- **钉钉机器人**：发布为钉钉应用内的机器人，支持群聊 @ 触发。
- **微信公众号**：发布为微信客服，扫码体验。
- **组件化**：发布为可复用组件，供其他智能体或工作流引用。
- **音视频实时互动**：仅支持图文对话类应用，提供 H5/APP 与 SDK 集成。

发布是 API 调用与渠道集成的前提。所有通过分享链接产生的调用费用由应用创建者承担。

## 观测与评测

- **应用观测**：端到端查看应用处理流程，获取延时、[Token](token.md) 消耗等指标。智能体应用的观测节点包括 CHAIN、AGENT、RETRIEVER、LLM、TOOL 等类型，展示完整的决策与工具调用链路。
- **自动评测**：基于应用关联的知识库，由大模型自动生成评测集并评分，产出 BadCase 分析与调优建议。仅面向已发布且配置知识库的智能体应用。
- **手动评测**：人工构建评测集，对应用输出逐条打标，适合领域专家端到端验证。
