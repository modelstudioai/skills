# 智能体应用

智能体应用是阿里云百炼平台的三种核心应用构建模式之一，由提示词驱动，AI 自主理解用户意图并动态规划[知识库](knowledge-base.md)、MCP 等外部工具的调用顺序，适合开放式对话与任务型场景。

## 在百炼平台中的定位

百炼将应用构建模式分为智能体、工作流、高代码应用三类。智能体应用采用自然语言配置（零代码），核心特点是 AI 自主决策与动态规划，开发门槛低，适合业务人员、产品经理、运营等角色构建智能客服、知识问答、任务助理、旅行规划等场景。

智能体应用分旧版（Agent 1.0）与新版（Agent 2.0）两套架构：

| 维度 | 旧版本（Agent 1.0） | 新版本（Agent 2.0） |
| --- | --- | --- |
| 规划与调度 | 检索[知识库](knowledge-base.md)后再决策是否调用 MCP | [知识库](knowledge-base.md)、MCP 统一为工具，自主规划调用顺序 |
| 过程透明度 | 只展示最终结果 | 完整展示每轮"规划-执行-反思"链路 |
| 适用场景 | 意图单一、流程固定的简单任务 | 从简单问答到复杂规划的各类任务 |

两套架构基于不同技术栈，彼此不兼容，不支持直接升级或降级。无旧版本依赖时推荐使用新版。

## 创建与配置流程

1. 在百炼控制台应用管理页面单击「创建应用」>「智能体应用」>「Agent 2.0」。
2. 填写应用名称并立即创建，自动跳转至应用配置界面。
3. 在模型选择器中选择模型，推荐具备强工具调用能力的模型（如千问-Max 系列）。
4. 在右侧对话框中输入问题验证效果。

### 核心能力配置

- **模型参数**：最长回复长度、temperature、enable_thinking（仅支持思考模式的模型可配置）。
- **系统提示词**：定义智能体角色、行为指令与能力边界；支持嵌入自定义变量（输入 `/` 引用）。
- **预解析文件**：关闭时文件 URL 作为上下文传递，由智能体决策是否调用工具；开启时系统使用预置解析器处理文档、图像、视频、音频并返回文本内容。千问-VL 系列模型具备多模态能力，关闭预解析也能直接解析图片和视频。
- **知识库**：作为工具由智能体自主规划调用，支持通过标签限定查询范围以提升回答准确性。
- **MCP**：外部工具统一以 MCP 协议接入，包括官方 MCP 广场和自定义 MCP 服务；插件也支持一键转换为 MCP。
- **应用组件**：将已发布为组件的智能体或工作流作为工具接入。
- **记忆**：短期记忆支持 0–30 轮上下文（0 代表不传递多轮记录）；长期记忆计划在未来迭代支持。
- **回复**：开启"展示回答来源"后以角标形式展示知识来源和源文件/源网页地址，推荐与知识库和联网搜索 MCP 组合使用。

### 运行限制

- **ReAct 最大轮次**：取值范围 1–50，限制单次会话中工具调用的最大次数，超出后自动退出工具调用链路并由智能体生成最终回复。
- **运行轨迹**：复杂请求以卡片流展示决策过程，包含思考（Thinking，仅支持思考模式的模型出现）与工具调用两类步骤。

## 文件问答子能力

文件问答是智能体应用的子能力，上传文件后可与文件内容进行智能问答，提供三种处理模式：

| 模式 | 机制 | 适用场景 | [Token](token.md) 消耗 |
| --- | --- | --- | --- |
| 全文引用 | 文件内容整体提供给模型（上下文长度限制内） | 文档总结、全文翻译、风格润色 | 较大 |
| 切片检索（RAG） | 文件切分成片段，提问时检索最相关片段 | 长文档问答、知识库检索、精确定位信息来源 | 通常远小于全文引用 |
| 自定义处理 | 文件信息提供给模型，自主调用外部工具处理 | 图片风格转换、视频内容分析后生成报告 | 取决于模型与工具交互复杂性 |

文件限制：单次会话上传文件上限 10 个，单文件不超过 10MB；通过聊天窗口上传的文件仅在当前会话有效，刷新或关闭页面会丢失；通过文件上传 API（`session_file_id`）上传的文件有效期通常为 24 小时；通过 URL（`image_list`、`file_list`）传递的文件可访问性由 URL 自身决定。仅适用于中国大陆版（北京地域）。

## API 调用集成

智能体应用发布后即可通过 API 集成到业务系统，提供两套调用方式：

| API 模式 | Endpoint | 适用场景 |
| --- | --- | --- |
| OpenAI 兼容 Responses API | `POST https://dashscope.aliyuncs.com/api/v2/apps/agent/{APP_ID}/compatible-mode/v1/responses` | 复用 OpenAI 代码库与工具链，支持同步/异步、流式、多模态 |
| DashScope 原生 API | `POST https://dashscope.aliyuncs.com/api/v1/apps/{APP_ID}/completion` | 功能更全面，新版智能体、工作流、旧版智能体均支持 |

调用前需准备：应用 ID（APP ID，在应用管理页面复制；子[业务空间](workspace.md)还需 Workspace ID）、[API Key](api-key.md)（通过密钥管理获取，推荐配置到 `DASHSCOPE_API_KEY` 环境变量）、可选的 OpenAI 或 DashScope SDK。上述 Endpoint 仅适用于华北2（北京）地域，其他地域或调用子[业务空间](workspace.md)下的应用时请求必须包含 Workspace ID。

OpenAI 兼容模式的关键参数：`app_id`（必选）、`input`（必选，字符串或消息数组，支持多轮与多模态，消息 role 取 system/user/assistant，多模态 content 子对象 type 含 input_text/input_image/input_file，其中 input_file 仅智能体应用支持）、`stream`（可选，默认 false）、`background`（可选，异步执行，默认 false）。[异步调用](async-invocation.md)暂不支持[流式输出](streaming-output.md)。

## 评测与监控

智能体应用支持系统化的应用评测能力，包含自动评测与手动评测两种范式。自动评测基于应用关联的知识库由大模型自动生成评测集并评分（1-5 分），仅面向已发布且配置知识库的智能体应用，要求开通"应用观测"，单次最多 8 个应用横向评测；手动评测由人工构建评测集逐条打标，适合有领域专家介入的端到端验证。

应用观测功能用于端到端查看智能体应用的处理流程，获取延时、[Token](token.md) 量等关键指标（分钟级更新）。智能体应用在调用过程中会生成 CHAIN、AGENT、RETRIEVER、REWRITER、EMBEDDING、RERANKER、LLM、TOOL、GUARDRAIL 等节点，节点之间可形成嵌套关系。CHAIN 节点表示一次完整的应用内部调用追踪，作为根节点时名称为 AgentApp。首次使用需完成应用观测配置：授权 OpenTelemetry 服务角色权限 → 开通 OpenTelemetry 服务 → 初始化 LogStore。

## 发布与分享

智能体应用在控制台「应用管理」页面单击「发布」进入「发布渠道」页签后，可通过以下渠道分享或发布：

- 官方网页版：部署为带有效期的网页应用，默认有效期 7 天，可调整或下线（仅支持智能体应用）。
- UI 应用（魔笔分享渠道）：通过 UI 设计器构建自定义界面后发布。
- 钉钉机器人：发布为钉钉应用内机器人，支持群聊 @ 触发与流式卡片回复，消息接收模式必须选 HTTP 模式。
- 微信公众号：发布为微信客服二维码，扫码即可体验 AI 客服。
- 组件：将应用发布为可复用组件，供其他智能体或工作流引用。
- 音视频实时互动：仅支持图文对话类应用，提供 H5/APP 扫码与 SDK 集成两种渠道。

所有通过分享链接产生的模型调用费用由应用创建者 UID 账号承担；钉钉、微信、音视频互动等渠道在发布时均需选择目标 [API Key](api-key.md)。若应用对外提供服务，须遵守《生成式人工智能服务管理暂行办法》等法规完成备案。

## 版本管理与合规

发布是后续所有 API 调用与集成的前提，非首次发布时弹窗会展示自上次发布以来的配置变更差异。智能体应用支持编辑历史版本描述或回滚至已发布历史版本（覆盖当前草稿）。
