# Token 与计费

Token 是大语言模型处理文本的基本计量单位，百炼平台以 Token 为核心度量衡构建了完整的计费体系，覆盖模型推理、模型训练和模型部署三大场景。

## Token 基本概念

Token 是模型将输入文本拆分后的最小处理片段。在百炼平台中，平均 1 个汉字约对应 1.5～2 个 Token，1 个英文单词约对应 1.3 个 Token。不同类型模型的计量单位有所差异：

| 模型类型 | 计量单位 |
|---------|---------|
| 大语言模型（文本生成、深度思考、视觉理解） | Token |
| 图像生成 | 张 |
| 视频生成 | 秒 |
| 语音模型 | 秒/字符/Token |
| 向量模型 | Token |

## 推理计费

模型推理采用按量后付费模式，核心公式为：

```
费用 = 输入 Token 数 × 输入单价 + 输出 Token 数 × 输出单价
```

影响实际费用的关键因素：

- **Batch 调用**：输入和输出单价按实时推理的 50% 计费，适合对延迟不敏感的批量任务。
- **上下文缓存**：命中缓存的输入 Token 享有折扣，Batch 与缓存折扣不可叠加。
- **阶梯计费**：部分模型（如 qwen3-max、qwen-plus）根据单次请求的输入 Token 总量确定单价阶梯，所有 Token 按同一阶梯结算。

## 免费额度

首次开通百炼时自动发放各模型的新人免费额度，有效期 30～90 天。免费额度仅限华北2（北京）地域的实时推理，不支持 Batch、模型调优和模型部署。额度耗尽后，已认证用户默认自动转为按量付费；可在控制台开启"免费额度用完即停"防止意外扣费。

## 成本优化方案

百炼提供多层成本优化工具，抵扣优先级为：**免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费**。

| 方案 | 机制 | 适用场景 |
|------|------|---------|
| AI 通用型节省计划 | 承诺月消费额换取阶梯折扣（最高 5.3 折） | 多模型混合使用 |
| 其他模型节省计划 | 按模型系列购买固定金额 | 用量集中于特定模型 |
| 资源包 | 预购特定模型 Token 数量 | 已知用量的单一模型 |

注意：节省计划的月承诺额度当月未用完自动清零，不可累积。三方直供模型（DeepSeek、Kimi、GLM 等 C 类）目前不支持 AI 通用型节省计划抵扣。

## Token Plan 团队版

Token Plan 团队版是面向团队和企业的独立订阅方案，以 Credits 为统一计量单位。单次请求的 Credits 消耗由模型类型、输入/缓存/输出 Token 数量共同决定。提供标准（¥198/月，25,000 Credits）、高级（¥698/月，100,000 Credits）、尊享（¥1,398/月，250,000 Credits）三档坐席，另有共享用量包跨坐席共享。

Token Plan 使用专属 API Key（`sk-sp-xxx` 格式）和专属 Base URL，与百炼通用 API Key（`sk-xxx` 格式）互不相通。

## 训练与部署计费

- **模型训练**：按训练 Token 计费，公式因模型类型而异。文本模型费用与训练数据 Token 总数、循环次数、训练单价相关；图像和视频模型有各自的 Token 换算方式。
- **模型部署**：支持预置吞吐（PTU，按 TPM 和时长）、模型单元（MU，按单元数和时长）、按 Token 用量三种计费方式，创建后不可切换。

## 用量监控与告警

百炼提供模型用量和模型监控两个模块来追踪 Token 消耗：

- **模型用量**：按[业务空间](workspace.md)维度统计各模型调用量和费用，数据延迟约 1 小时。
- **模型监控**：提供调用记录、性能指标（首 Token 延时、RPM、TPM、失败率）和 Token 消耗追踪。
- **应用观测**：在应用维度追踪每次调用的输入/输出 Token 量。
- **告警**：支持设置费用告警和模型指标告警，通过短信、邮件、钉钉等渠道通知。

开启高级监控后，监控数据存储在私有 Prometheus 实例中，可接入 Grafana 进行可视化分析。
