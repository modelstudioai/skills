# Token 与计费

Token 是百炼平台衡量模型输入与输出文本量的基本单位，也是大语言模型推理计费的核心依据。理解 Token 的计算方式和计费规则，是开发者控制成本、优化调用策略的基础。

## Token 基本概念

Token 是模型处理文本时的最小分词单元，并非直接等同于字符或单词。在百炼平台中，经验换算关系为：

- 1 个中文汉字约对应 1.5～2 个 Token
- 1 个英文单词约对应 1.3 个 Token

模型调用时会分别统计输入 Token 和输出 Token，两者独立计价。对于视觉理解模型，图片的 Token 计算公式为 `h × w / (32 × 32) + 2`，即按像素面积折算。

## 不同场景下的计费方式

### 模型推理（按量付费）

这是最常见的计费模式，公式为：

`费用 = 输入 Token 数 × 输入单价 + 输出 Token 数 × 输出单价`

最小计费单位为 1 Token。部分模型实行阶梯计费——单价由单次请求的输入 Token 总量决定。不同模型系列价格差异较大，例如 qwen3.7-max 输入 12 元/百万 Token，而 qwen-plus 低至 0.8 元/百万 Token 起。

### 非文本模型

不同模态的模型采用不同统计单位：

| 模型类型 | 统计单位 |
|---------|---------|
| 大语言模型 / 全模态 / 向量模型 | Token |
| 图像生成 | 张 |
| 视频生成 | 秒 |
| 语音模型 | 秒 / 字符 / Token（视模型而定） |

### Token Plan 团队版

Token Plan 采用 Credits 体系，单次消耗的 Credits 由模型类型、输入/缓存/输出 Token 用量共同决定。提供三档坐席（标准 25,000 Credits/月、高级 100,000 Credits/月、尊享 250,000 Credits/月），另有共享用量包跨坐席弹性抵扣。

### Coding Plan

面向个人开发者，按模型调用次数计费（非 Token），Pro 套餐 200 元/月，限额每 5 小时 6,000 次、每周 45,000 次。

## 降低 Token 成本的策略

### Batch 调用

对延迟不敏感的大量请求可使用批量推理，输入和输出 Token 单价按实时推理的 50% 计费。

### 上下文缓存

重复使用相同前缀上下文时，输入 Token 可享受折扣。Batch 调用与上下文缓存不能同时生效。

### 节省计划与资源包

抵扣优先级为：免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费。AI 通用型节省计划通过承诺月消费额换取最高 5.3 折优惠。

### 模型选型

选择合适的模型层级可显著降低成本：旗舰模型（max）价格最高，均衡模型（plus）性价比好，高性价比模型（flash）成本最低。简单任务无需使用旗舰模型。

## Token 用量监控

百炼提供完整的 Token 消耗追踪能力：

- **用量统计**：在控制台按[业务空间](workspace.md)维度查看各模型的 Token 消耗，支持按时间范围和推理类型筛选。数据延迟约 1 小时。
- **推理日志**：开通后可查看每次调用的 Token 明细（输入/输出），适用于故障排查和成本审计。
- **告警配置**：支持设置 Token 消耗阈值告警，异常消耗时通过短信、邮件、钉钉等渠道通知。
- **外部监控**：开启高级监控后，`model_usage` 等指标可通过 Prometheus API 接入 Grafana 进行可视化分析。

## 新人免费额度

首次开通百炼时自动发放各模型的免费 Token 额度，有效期 30～90 天，仅限华北2（北京）地域的实时推理。免费额度耗尽后，未认证用户服务停止，已认证用户自动转为按量付费。建议开启"免费额度用完即停"功能以避免意外扣费。
