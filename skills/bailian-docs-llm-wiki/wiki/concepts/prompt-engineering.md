# Prompt 工程

Prompt 工程是指通过系统化设计和优化提示词（Prompt），引导大语言模型产出高质量、符合预期结果的技术实践。在百炼平台中，Prompt 工程贯穿应用构建、效果调优和评测迭代的全流程，平台提供了从模板管理到自动优化的完整工具链。

## 核心概念

Prompt 是用户与大模型交互的输入指令。Prompt 工程的目标是让任务描述尽可能清晰、具体、无歧义，从而提升模型输出的准确性和一致性。百炼平台将 Prompt 工程能力封装为可复用的工具和服务，降低开发者的使用门槛。

## Prompt 设计方法

### 文生文场景

百炼推荐使用 Prompt 框架系统化构建提示词，框架包含六个要素：背景、目的、风格、语气、受众、输出。常用优化技巧包括：

- **分隔符**：用 `---` 或 `"""` 分隔指令与待处理内容，避免模型混淆
- **少样本提示（Few-shot）**：在 Prompt 中提供示例，引导模型输出格式和风格
- **思维链（Chain-of-Thought）**：引导模型逐步推理，提升复杂任务的准确性
- **角色扮演**：指定模型身份（如"你是一位资深 Python 工程师"），使输出更专业

### 文生图/文生视频场景

文生图使用 `prompt`（正向）和 `negative_prompt`（反向）两个参数控制画面。提示词公式分为基础公式（`主体 + 场景 + 风格`）和进阶公式（增加景别、视角、镜头类型、光线等维度）。文生视频场景重点描述画面内容和运动过程。

### 结构化设计框架

百炼内置三种 Prompt 工程框架，适用于不同复杂度的任务：

| 框架 | 适用场景 |
|------|----------|
| ICIO | 简单明确的任务（数据分析、内容生成、文本摘要） |
| CRISPE | 需要 AI 扮演特定角色的交互（客服、创意写作） |
| RASCEF | 多步骤复杂业务流程（项目规划、战略分析） |

## Prompt 模板管理

百炼支持通过 Prompt 模板将固定结构与动态变量分离，实现逻辑与内容的解耦：

- **预置模板**：平台提供覆盖营销文案、摘要抽取、文案润色等通用场景的模板
- **自定义模板**：开发者通过控制台或 API 创建，支持文本生成和图片生成两种类型

模板工作流程：创建模板获取模板 ID -> 通过 `GetPromptTemplate` API 拉取模板内容 -> 填入变量生成最终 Prompt -> 发送给模型。核心优势是更新 Prompt 无需修改应用代码。

## 自动优化工具

### 基础自动优化

在控制台提交原始 Prompt，系统通过大模型自动进行结构重组、指令增强和安全边界注入。该功能免费，且提交的数据不会被存储或用于模型训练。

### 基于样例的反馈优化

针对特定业务场景，通过提供输入输出样例（建议 5-10 条），系统经多轮自动化评估和反思生成更贴合场景的 Prompt。操作时需选择推理模型（推荐千问-max）、上传样例数据和评测数据（建议至少 20 条）。

## 在不同场景中的应用

### 智能体应用

智能体的系统提示词（System Prompt）定义了角色、行为指令与能力边界。新版智能体支持配置 `temperature`、`enable_thinking` 等参数，Prompt 质量直接影响智能体的推理和工具调用能力。

### 知识库（RAG）优化

当知识库检索结果不理想时，优化 Prompt 是重要调优手段。可在提示词模板中添加输出限定、Few-Shot 示例和内容分隔标记，帮助模型更好地理解和利用检索到的知识片段。

### 应用评测

百炼的自动评测体系中，LLM 评估器需要配置评估 Prompt 来定义评分标准。评测报告中的调优建议也常涉及 Prompt 优化方向，形成"设计 Prompt -> 评测效果 -> 优化 Prompt"的迭代闭环。

## 最佳实践

| 场景 | 推荐方案 |
|------|----------|
| 快速优化已有 Prompt | Prompt 自动优化（免费） |
| 特定业务场景精准优化 | 基于样例的反馈优化 |
| 团队共享与版本管理 | Prompt 模板（API 管理） |
| 复杂任务结构化设计 | 自定义模板 + ICIO/CRISPE/RASCEF 框架 |
| 知识库问答效果不佳 | 在提示词模板中添加 Few-Shot 示例和输出限定 |

> **注意**：自定义 Prompt 模板功能仅适用于中国大陆版（北京地域）。
