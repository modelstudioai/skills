# Token 计量与计费

Token 是大语言模型处理文本的基本计量单位，也是阿里云百炼平台进行模型推理计费的核心度量。百炼平台围绕 Token 建立了完整的计量、计费与成本管理体系，贯穿模型调用、训练、部署和监控全流程。

## Token 与文本的换算关系

Token 并非直接等同于字符或单词。在百炼平台中，经验换算关系为：

- 1 个汉字约对应 1.5–2 个 Token
- 1 个英文单词约对应 1.3 个 Token

实际 Token 数取决于模型的分词器（Tokenizer），不同模型系列的换算比例可能略有差异。

## 不同模型类型的计量单位

百炼平台根据模型类型采用不同的用量统计口径：

| 模型类型 | 计量单位 | 说明 |
|---------|---------|------|
| 大语言模型（文本生成、深度思考、视觉理解） | Token | 按输入/输出 Token 数分别计量 |
| 全模态模型 | Token | 文本按 Token 数，其他模态按对应 Token 数换算 |
| 向量模型 | Token | 按输入文本的 Token 数计量 |
| 图像生成 | 张 | 按成功生成的图像张数计量 |
| 视频生成 | 秒 | 按成功生成的视频秒数计量 |
| 语音模型 | 秒/字符/Token | 视具体模型而定 |

## 推理计费公式

模型推理采用按量付费，核心公式为：

```
费用 = 输入 Token 数 × 输入单价 + 输出 Token 数 × 输出单价
```

部分模型实行阶梯计费——单价取决于单次请求的输入 Token 总量所处的区间。例如，若模型设有 0–32K 和 32K–128K 两档，当输入 100K Token 时，全部 Token 按第二档单价结算。

### 主要模型定价参考（华北2-北京，每百万 Token）

| 模型系列 | 代表模型 | 输入单价 | 输出单价 |
|---------|---------|---------|---------|
| 千问 Max | qwen3.7-max | 12 元 | 36 元 |
| 千问 Plus | qwen3.7-plus | 2 元 | 8 元 |
| 千问 Flash | qwen-flash 系列 | 较低 | 较低 |

不同地域（美国、新加坡、德国）的定价有所差异，海外地域通常高于北京。Batch 调用可享半价，支持上下文缓存的模型还可进一步降低成本。

## 训练场景的 Token 计费

模型训练同样以 Token 为计量基础：

- **文本生成模型**：训练费用 = (训练数据 Token 总数 + 混合训练数据 Token 总数) × 循环次数 × 训练单价。价格从 Qwen3-0.6B 的 0.003 元/千Token 到 Qwen2.5-72B-Instruct 的 0.15 元/千Token 不等。
- **图像/视频生成模型**：训练 Token 总量由 max_steps、max_token_length、视频时长等超参数决定，单价在 0.06–0.08 元/千Token 之间。

## [模型部署](model-deployment.md)中的 Token 维度

[模型部署](model-deployment.md)提供多种计费方式，其中 TPM（每分钟 Token 数）是核心资源度量：

- **预置吞吐（按 TPM）**：按输入/输出 TPM 和使用时长计费
- **模型单元**：按独占算力资源的使用时长计费
- **按 Token 使用量**：仅限 SFT 训练后的自定义模型

当模型输入超过最长 Token 限制或超出购买的 TPM 量时，调用自动切换为按量付费模式（API 返回 Header 包含 `x-dashscope-ptu-overflow:true`）。

## Token 消耗监控

百炼平台通过模型监控和应用观测两个模块提供 Token 消耗的全链路追踪：

- **汇总统计**：按[业务空间](workspace.md)维度汇总各模型历史 Token 消耗，支持按时间范围和 API Key 筛选
- **逐次追踪**：开通推理日志后，可查看每次调用的输入/输出 Token 用量
- **告警通知**：支持设置 Token 消耗阈值，异常消耗时通过短信、邮件、钉钉等渠道通知
- **应用观测**：在调用链路中展示每个 Span 的 Token 总量、输入 Token、输出 Token，支持按 Token 量过滤和导出

核心 Prometheus 指标 `model_usage` 可用于接入外部监控系统（如 Grafana）进行自定义可视化。

## 免费额度

首次开通百炼时，平台自动发放各模型的新人免费额度：

- 有效期 30–90 天（2025 年 9 月 8 日后新开通用户为 90 天）
- 仅适用于华北2（北京）地域且服务部署范围为中国内地的模型
- 仅抵扣实时推理费用，不支持 Batch 调用、模型调优和[模型部署](model-deployment.md)
- 支持"免费额度用完即停"功能，防止产生意外费用

## 成本优化

百炼提供多层次的 Token 成本优化方案，抵扣优先级为：

```
免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费
```

- **AI 通用型节省计划**：通过承诺每月消费金额获得阶梯折扣，最高可享 5.3 折
- **资源包**：预购 Token 数量抵扣特定模型费用
- **Token Plan 团队版**：以 Credits 为单位的包月方案，按 Token 消耗抵扣 Credits，无欠费风险

## 开发者注意事项

- 用量数据存在约 1 小时延迟，且不支持查看 30 天以前的统计数据
- 主账号与 RAM 子账号共享同一免费额度池
- Token Plan 和 Coding Plan 的 API Key 与通用按量计费的 API Key 互不兼容，请勿混用
- 可通过降低 `temperature`、`top_k`、`top_p` 等参数减少不必要的输出 Token 消耗
