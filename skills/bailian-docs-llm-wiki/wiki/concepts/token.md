# Token 计量与计费

Token 是百炼平台衡量模型输入与输出文本量的基本单位，也是按量付费和额度管理的核心计量维度。所有文本生成、视觉理解、向量嵌入等模型的调用费用均以 Token 为基础计算，不同模型的 Token 单价和计费规则各有差异。

## 什么是 Token

Token 是大语言模型处理文本时的最小分词单位。对于中文，1 个 Token 大约对应 1.5 个汉字；100 万 Token 约等于 70 万汉字。模型的上下文窗口、输入输出限制、费用计算均以 Token 为单位。

不同模态的模型使用不同的计量单位：

| 模型类型 | 计量单位 |
|----------|----------|
| 文本生成 / 深度思考 / 视觉理解 | Token |
| 全模态模型 | Token（文本及其他模态均折算为 Token） |
| 向量模型 | Token |
| 图像生成 | 张 |
| 视频生成 | 秒 |
| 语音模型 | 秒、字符或 Token（视模型而定） |

对于视觉理解模型，图像的 Token 数按 `h × w / (32 × 32) + 2` 公式计算，其中 h 和 w 为图像的像素尺寸。

## 按量付费

百炼的按量付费模式按输入 Token 和输出 Token 分别计价，单价因模型而异。部分模型实行阶梯计费——按单次请求的输入 Token 总量分档，所有 Token 统一按所在阶梯的单价结算，不做拆分。

典型价格示例（华北2-北京，每百万 Token）：

| 模型 | 输入单价 | 输出单价 |
|------|---------|---------|
| qwen3.7-max | 12 元 | 36 元 |
| qwen3-max（0~32K） | 2.5 元 | 10 元 |
| qwen3-max（32K~128K） | 4 元 | 16 元 |

批量推理（Batch）的输入和输出单价均为实时推理价格的 50%。支持上下文缓存的模型，输入 Token 可享额外折扣，但两者不能同时生效。

## 订阅制计费

除按量付费外，百炼还提供基于订阅的计费方式：

- **Token Plan 团队版**：以 Credits 统一计量 Token 消耗，按坐席付费（标准 ¥198/月/25,000 Credits、高级 ¥698/月/100,000 Credits、尊享 ¥1,398/月/250,000 Credits），适合团队协作场景。
- **Coding Plan**：按模型调用次数计费（¥200/月），设有每 5 小时、每周、每月用量上限，面向个人开发。

两类套餐使用专属 API Key（`sk-sp-xxx`）和独立的 Base URL，与通用按量付费的 API Key（`sk-xxx`）互不相通。

## 免费额度

首次开通百炼时自动发放各模型的免费额度（以 Token 为单位），有效期 30~90 天。免费额度仅限中国内地版模型的实时推理，不支持 Batch 调用、模型调优和部署。

建议开启"免费额度用完即停"功能：开启后额度耗尽时服务自动停止（返回 403 错误），避免产生意外按量扣费。

## 成本优化

按 Token 消耗降本的常见策略：

- **AI 通用型节省计划**：承诺月消费金额（1000 元起），最高可享 5.3 折，覆盖模型调用、工具调用、上下文缓存和批量推理。
- **资源包**：一次性购买固定 Token 量，绑定特定模型，适合用量可预测的场景。
- **控制输出长度**：通过 `max_tokens` 参数限制单次生成的 Token 数。
- **按任务选模型**：简单任务优先选用轻量级模型（如 qwen3.6-flash），降低单位 Token 成本。
- **优化 Prompt**：简洁清晰的提示词可减少不必要的输入 Token 消耗。
- **使用批量推理**：非实时场景使用 Batch 调用可节省 50% 费用。

## 限流指标

百炼按主账号维度对 Token 使用量进行限流，核心指标为 TPM（每分钟 Token 数，含输入与输出）。超出限额时返回 `Allocated quota exceeded` 错误。不同模型的 TPM 限额相互独立，所有 RAM 子账号和 API Key 的调用量合并计算。

## 用量监控

在百炼控制台可从多个维度监控 Token 消耗：

- **用量统计**：按模型类型和时间范围查询近 30 天的 Token 消耗，数据延迟约 1 小时。
- **模型监控**：查看平均单次请求 Token 消耗、TPM 趋势等成本相关指标；开启高级监控可获得分钟级数据。
- **告警配置**：对 Token 消耗指标设置阈值，异常时自动通知（短信、邮件、钉钉等）。
- **账单详情**：在阿里云费用中心按 API Key、模型名称等维度查看详细扣费记录。
