# Token 计量与计费

Token 是百炼平台衡量模型输入与输出数据量的基本单位，也是按量付费和额度管理的核心计量维度。不同模态的模型使用不同的统计口径，但 Token 始终是文本类模型最主要的计费基准。

## 什么是 Token

Token 是大语言模型处理文本时的最小分词单元。一个 Token 并不严格等于一个字或一个词，其粒度取决于模型的分词器（Tokenizer）。经验换算关系如下：

- 1 个中文汉字约对应 1.5~2 个 Token
- 1 个英文单词约对应 1.3 个 Token

在百炼平台中，模型调用费用按输入 Token 和输出 Token 分别计价，公式为：

```
费用 = 输入 Token 数 x 输入单价 + 输出 Token 数 x 输出单价
```

## 不同模型类型的计量单位

百炼平台覆盖多种模态，各类模型的用量统计口径有所不同：

| 模型类型 | 计量单位 | 说明 |
|---------|---------|------|
| 大语言模型（文本生成、深度思考、视觉理解） | Token | 按输入/输出 Token 数分别计费 |
| 全模态模型 | Token | 文本按 Token 数，其他模态按对应 Token 数折算 |
| 向量模型（Embedding） | Token | 按输入文本的 Token 数计费 |
| 图像生成 | 张 | 按成功生成的图像张数计费 |
| 视频生成 | 秒 | 按成功生成的视频秒数计费 |
| 语音模型 | 秒/字符/Token | 视具体模型而定 |

## 定价与阶梯计费

百炼平台的模型推理采用按量后付费，不同模型的 Token 单价差异较大。以华北2（北京）地域为例：

| 模型系列 | 代表模型 | 输入单价（每百万 Token） | 输出单价（每百万 Token） |
|---------|---------|----------------------|----------------------|
| 千问 Max | qwen3.7-max | 12 元 | 36 元 |
| 千问 Plus | qwen3.7-plus | 2 元 | 8 元 |
| 千问 Flash | qwen-flash 系列 | 较低 | 较低 |

部分模型实行**阶梯计费**：单价取决于单次请求的输入 Token 总量。例如，若模型有 0~32K 和 32K~128K 两档，输入 100K Token 时所有 Token 均按第二档单价结算。海外地域（美国、新加坡、德国）的单价通常高于北京。

支持 Batch 调用的模型可享受半价优惠，上下文缓存也可进一步降低重复输入的 Token 费用。

## 免费额度

首次开通百炼时，平台自动发放各模型的新人免费额度：

- 有效期 30~90 天（2025 年 9 月 8 日后新开通用户为 90 天）
- 仅抵扣模型实时推理费用，不支持 Batch 调用、模型调优等场景
- 主账号与 RAM 子账号共享同一免费额度池
- 可开启"免费额度用完即停"，额度耗尽时自动停止服务（返回错误码 `AllocationQuota.FreeTierOnly`），避免意外扣费

## Token Plan 与 Coding Plan

除按量付费外，百炼还提供两种订阅套餐，以不同方式管理 Token 消耗预算：

- **Token Plan 团队版**：按 Token 消耗抵扣 Credits，适合团队/企业。标准坐席 25,000 Credits（198 元/月），高级坐席 100,000 Credits（698 元/月），尊享坐席 250,000 Credits（1,398 元/月）。超出坐席额度后可从共享用量包抵扣。
- **Coding Plan**：按模型调用次数计费（非 Token），适合个人开发者。每 5 小时 6,000 次、每周 45,000 次、每月 90,000 次。

两种套餐使用专属 API Key 和 Base URL，与按量计费的通用 API Key 互不相通。

## Token 消耗的监控与管理

百炼提供多层次的 Token 消耗监控能力：

- **用量统计**：在控制台"模型用量"页面按[业务空间](workspace.md)维度查看各模型的 Token 消耗（数据延迟约 1 小时）
- **模型监控**：查看每次调用的 Token 消耗明细（需开通推理日志），支持按 API Key、模型等维度筛选
- **告警配置**：设置 Token 消耗阈值，异常消耗时通过短信、邮件、钉钉等渠道通知
- **外部对接**：开启高级监控后，指标数据存储在 Prometheus 实例中，可接入 Grafana 进行可视化。核心指标包括 `model_usage`（用量总和）、`model_call_count`（调用次数）等

## 费用抵扣优先级

当多种付费方式并存时，扣费按以下优先级：

```
免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费
```

## 成本优化建议

- **控制输出长度**：合理设置 `max_tokens` 参数，避免生成冗余内容
- **选择合适模型**：轻量任务使用 Flash 级别模型，复杂任务再升级到 Plus 或 Max
- **使用 Batch 调用**：对延迟不敏感的批量任务可享受半价
- **利用节省计划**：通过 AI 通用型节省计划承诺月消费额度换取最高 5.3 折
- **关注 Embedding 维度**：向量模型（如 text-embedding-v4）支持自定义维度，降低维度可减少下游存储和计算成本，同时 Token 消耗不变
