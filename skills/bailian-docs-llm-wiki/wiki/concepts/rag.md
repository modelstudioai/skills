# 检索增强生成

检索增强生成（RAG, Retrieval-Augmented Generation）是一种将信息检索与大模型生成相结合的技术范式：先从外部知识源中检索与用户问题最相关的文本片段，再将其注入大模型的上下文，使模型能够基于真实数据生成更准确、更可靠的回答。在百炼平台中，RAG 是知识库问答、私域智能客服和企业文档检索等核心场景的底层技术支撑。

## 基本原理

RAG 的工作流程可以概括为三个阶段：

1. **索引阶段**：将原始文档经过解析、切分后，通过向量模型（Embedding Model）转化为向量表示，存入向量库。
2. **检索阶段**：用户提问时，将查询同样向量化，在向量库中按语义相似度召回最相关的文档切片。
3. **生成阶段**：将召回的切片作为上下文拼接到提示词中，交由大模型生成最终回答。

## 在百炼平台中的使用场景

### 知识库问答

百炼知识库是 RAG 的核心载体。开发者上传 PDF、Word、Markdown、图片、音视频等文件后，平台自动完成解析、切分、向量化和入库。应用调用时按语义相似度召回切片并交由大模型生成答案。知识库支持多种使用场景：

- **基础文档问答**：纯文本语义检索，适合通用文档。
- **图文并茂回复**：从插图抽取摘要，由模型决定是否插图返回。
- **视觉理解（富文本文档）**：使用多模态向量对整页做视觉级理解，保留版面布局。
- **极速问答**：低延迟检索，适合 FAQ、参数表等高度结构化文档。
- **数据查询（NL2SQL）**：结构化 Excel / RDS 表的自然语言查询。
- **音视频搜索**：按时间轴对齐语音识别、视频帧提取与剧情解析。

### 智能体应用集成

在智能体应用中，知识库作为 RAG 工具被集成：

- **旧版智能体（Agent 1.0）**：采用"先检索知识库、再决策是否调用其他工具"的固定流程。
- **新版智能体（Agent 2.0）**：将知识库统一为工具，由模型自主规划调用顺序，支持完整的"规划-执行-反思"链路。
- **文件问答的切片检索模式**：上传文件后按 RAG 方式切分检索，适合长文档精确问答。

### 工作流应用集成

在工作流中，通过拖入"知识库"节点实现 RAG 能力，输入变量绑定到 `query`，支持固定选择或通过 `CodeList` 变量动态引入知识库，下游接大模型节点完成生成。

### 框架集成

百炼支持通过 LlamaIndex（Python）和 Spring AI Alibaba（Java）两大框架构建 RAG 应用：

- **LlamaIndex**：提供 `DashScopeParse`（文件解析）、`DashScopeCloudIndex`（云端知识库）、`DashScopeRerank`（语义重排）等组件，支持从本地文件到云端 RAG 应用的完整流程。
- **Spring AI Alibaba**：通过 `DashScopeDocumentRetriever` 检索百炼知识库文本切片，结合 `DocumentRetrievalAdvisor` 实现 RAG 问答。

### 多渠道接入

RAG 应用可通过 AppFlow 快速接入网站、微信公众号、企业微信、钉钉等渠道，也可基于本地 Python 服务 + 百炼 Embedding API 搭建本地 RAG 应用。

## 关键参数与配置

### 向量模型（Embedding）

| 模型 | 维度 | 适用场景 |
|------|------|---------|
| text-embedding-v4（推荐） | 512 | 文档/数据/音视频类知识库 |
| text-embedding-v3 | 512 | 文档/数据/音视频类知识库 |
| multimodal-embedding-v1 | 1024 | 图片问答类知识库 |
| qwen3-vl-embedding | - | 视觉理解场景（自动使用） |

### 切片策略

| 切分方式 | 说明 |
|---------|------|
| 智能切分（推荐） | 语义自适应，适用于多数文档 |
| 按长度 | 含重叠字符数，建议重叠比例 10%-25% |
| 按页 / 按标题 / 按正则 / 按符号 | 特定文档结构适用 |

单切片上限为 6000 Token。

### 排序模型（Rerank）

排序模型对检索结果进行二次排序，提升召回质量：

- **qwen3-rerank（hybrid）**（推荐）：综合语义 + BM25 双路排序。
- **qwen3-rerank**：仅语义排序。

排序模式支持问答模式（默认）、相似模式和自定义高级模式（支持自然语言指令，限 200 字）。

### 检索参数

| 参数 | 说明 | 备注 |
|------|------|------|
| 相似度阈值 | 仅高于此值的切片被召回 | 应用侧设置会覆盖知识库默认值 |
| 最大召回数量（TopK） | 排序后送入大模型的切片数 | 上限 20 |
| 多轮对话改写 | 用轻量模型基于历史对话补全当前查询 | 默认关闭 |

### LlamaIndex 检索参数

```python
similarity_top_k = 5       # 检索返回的最大结果数
similarity_cutoff = 0.4    # 最低相似度阈值
top_n = 1                  # 重排后返回的结果数
```

## 效果优化要点

- **切片策略调优**：根据文档类型选择合适的切分方式和重叠比例。
- **Rerank 配置**：开启排序模型可显著提升召回精度，同一切片在不同排序模式下分数差异显著。
- **相似度阈值调节**：通过命中测试模拟提问验证召回质量，逐步调优阈值。
- **Meta 信息抽取**：为文档添加结构化元数据（常量、变量、大模型、正则、关键词），提高检索命中率。
- **降低 TopK 控制成本**：适当降低初步向量检索 TopK 和关键词检索 TopK 可减少模型输入 Token 消耗。

## 注意事项

- 向量模型和切片方式在知识库创建后不可修改，需提前规划。
- 排序模型不支持图片问答类知识库；视觉理解和极速问答场景不支持排序模式配置。
- Rerank 配置的优先级因调用方式而异：API 参数 > 应用页面配置 > 知识库默认配置。
- 知识库已正式商业化计费（2026 年 1 月起），费用包含规格费用和模型调用费用。
- LlamaIndex 方案使用默认智能文档切分与官方向量模型，不支持自定义切分方式或自定义嵌入模型。
