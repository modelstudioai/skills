# 检索增强生成

检索增强生成（Retrieval-Augmented Generation, RAG）是一种将外部知识检索与大模型生成相结合的技术范式，通过在推理时动态检索相关文档片段作为上下文，使大模型能够基于私有数据和最新信息生成更准确、更具时效性的回答。

## 在百炼平台中的定位

百炼平台以 RAG 为核心技术构建知识库体系，覆盖从数据导入、文档切分、向量化、检索召回到生成回答的完整链路。开发者可以通过控制台或开放 API 快速搭建基于私有知识的问答系统，无需自建向量数据库或管理检索流程。

RAG 在百炼平台的典型应用场景包括：

- **知识库问答**：将企业文档、产品手册等非结构化数据导入知识库，通过语义检索 + 大模型生成实现精准问答。
- **多渠道接入**：通过 AppFlow 将 RAG 应用接入网站、企业微信、微信公众号、钉钉等渠道，提供智能客服能力。
- **框架集成**：通过 LlamaIndex（Python）或 Spring AI Alibaba（Java）等开源框架，以编程方式构建自定义 RAG 应用。
- **本地检索 + 云端生成**：检索环节在本地执行，生成环节调用通义千问 API，适合需要灵活控制切分与嵌入策略的场景。

## RAG 流程

百炼 RAG 的标准流程分为离线索引和在线检索两个阶段：

**离线索引阶段：**

1. 数据导入：支持 txt、docx、pdf、Excel/CSV、图片、音视频等多种格式。
2. 文档解析：可选电子文档解析、文档智能解析（OCR）、大模型文档解析（千问 VL）等方式。
3. 文档切分：推荐智能切分（基于语义相关性自适应选择切片点），单切片上限 6,000 [Token](token.md)。
4. 向量化：使用 text-embedding-v4/v3 等模型将切片转为数值向量并存储。

**在线检索阶段：**

1. Query 改写：对用户原始问题进行改写以提升检索效果（需创建知识库时开启多轮对话改写）。
2. 混合检索：同时执行向量语义召回和关键词匹配召回。
3. Rerank 排序：使用 qwen3-rerank 等排序模型对召回结果做精排。
4. 生成回答：将排序后的切片与用户问题拼接为 [prompt](../guides/prompt.md)，由大模型生成最终回答。

## 关键参数与配置

### 向量模型

| 模型 | 维度 | 适用场景 |
| --- | --- | --- |
| text-embedding-v4 | 64–2048（默认 1024） | 文档搜索、数据查询、音视频搜索（推荐） |
| text-embedding-v3 | 64–1024（默认 1024） | 同上（上一代） |
| multimodal-embedding-v1 | 1024 | 图片问答 |
| qwen3-vl-embedding | 2560 | 视觉理解场景 |

### 排序模型

| 模型 | 特点 |
| --- | --- |
| qwen3-rerank | 100+ 语种，高性能文本排序，支持自定义排序指令 |
| qwen3-rerank(hybrid) | 混合排序 |
| qwen3-vl-rerank | 多模态，支持图文视频排序 |

### 检索参数

| 参数 | 取值范围 | 说明 |
| --- | --- | --- |
| 初步向量检索 TopK | 1–100（默认 50） | 向量语义召回切片数 |
| 初步关键词检索 TopK | 1–100（默认 50） | 关键词匹配召回切片数 |
| 相似度阈值 | 0.01–1.0 | 过滤低分切片，过高会丢弃全部结果 |
| 最大召回数量 | 1–20 | 最终返回给生成模型的切片数 |

### 知识库规格

- **标准版**：0.03 元/小时，1 QPS，平台存储不超过 100 GB。
- **旗舰版**：0.2 元/RCU/小时，50–10,000 QPS（1–200 RCU），平台存储不超过 9,999 GB。

## 服务接口

百炼提供两条独立的 RAG 服务线（均支持绑定最多 15 个知识库）：

- **知识检索**（`POST /api/v1/indices/knowledge/search`）：仅返回排序后的切片，不生成回答。适合需要自定义生成流程的场景。
- **知识问答**（`POST /api/v2/apps/knowledge/chat`）：在检索基础上叠加生成模型，通过 SSE [流式输出](streaming.md)规划、工具调用、生成三个阶段的结果。支持极速模式和多轮智能模式（Agentic 多轮规划搜索）。

## 效果优化建议

- 建立评估基线：准备至少 100 组覆盖事实/比较/教程/分析型的评测用例。
- 召回不完整时：补充知识库内容，优化源文件排版，统一实体表述，启用多轮对话改写。
- 召回不相关时：为文件添加标签或配置 Meta 元数据做前置过滤。
- 切片不完整时：改用智能切分，人工检查并修正异常切片。
- 重排效果不佳时：通过命中测试反复调整相似度阈值与召回片段数。
