# 检索增强生成

检索增强生成（Retrieval-Augmented Generation, RAG）是一种将外部知识检索与大模型生成相结合的技术范式：先从知识库中检索与用户问题相关的文本片段，再将这些片段作为上下文注入大模型，从而生成更准确、更具时效性的回答。在百炼平台中，RAG 是知识库问答、智能体应用和多渠道 AI 助手的核心技术基础。

## 核心流程

百炼平台的 RAG 流程分为四个阶段：

1. **数据导入与解析**：将非结构化文档（PDF、Word、Markdown、音视频等）导入知识库，经文档解析后切分为语义片段（切片）。
2. **向量化索引**：使用文本向量模型（如 text-embedding-v4）将切片转换为数值向量并建立索引。
3. **检索与排序**：接收用户查询后，通过向量语义检索 + 关键词匹配混合召回候选切片，再用排序模型（如 qwen3-rerank）对结果做二次精排。
4. **生成回答**：将排序后的切片与用户问题拼接为 [prompt](../guides/prompt.md)，送入大模型（如 qwen3.6-plus、qwen-max）生成最终回答。

## 在百炼平台中的使用方式

### 云端知识库 RAG

百炼控制台提供完整的知识库管理能力，支持以下知识库类型：

- **文档搜索类**：适用于企业文档、产品手册等非结构化数据，支持基础问答、图文回复、视觉理解等子场景。
- **数据查询类**：结构化知识库，支持 NL2SQL 查询 Excel/CSV 数据。
- **图片问答类**：基于[多模态](multimodal.md)向量模型 multimodal-embedding-v1 实现以图搜图。
- **音视频搜索类**：对语音做识别、对视频做帧提取与剧情解析，按时间轴结构化对齐。

知识库提供两条独立服务线：

- **知识检索服务**：仅返回检索切片，不生成回答，适合需要自定义生成流程的场景。
- **知识问答服务**：在检索基础上叠加生成模型，支持极速模式（单轮检索 + 生成）和多轮智能模式（Agentic 多轮规划搜索）。

### 框架集成 RAG

百炼支持通过开源框架构建 RAG 应用：

- **LlamaIndex（Python）**：读取本地文件上传到百炼云端知识库，构建检索引擎与 RAG 应用。使用百炼默认的智能文档切分与官方向量模型。
- **Spring AI Alibaba（Java）**：集成百炼智能体应用或工作流应用，并检索百炼知识库。需要 Spring Boot 3.x 和 JDK 17+。

### 本地知识库 RAG

检索环节在本地执行，生成环节调用通义千问 API。适合需要灵活选择切分策略与嵌入模型的场景，可使用本地部署的 GTE 文本向量模型替代百炼 embedding API。

### 多渠道接入

RAG 应用可通过 AppFlow 无代码连接流接入网站、企业微信、微信公众号、钉钉等渠道，实现 AI 智能客服和自动回复。

## 关键参数与配置

### 向量模型

| 模型 | 向量维度 | 单行最大 [Token](token.md) | 适用场景 |
| --- | --- | --- | --- |
| text-embedding-v4 | 64–2048（默认 1024） | 8,192 | 推荐，支持 100+ 语种 |
| text-embedding-v3 | 64–1024（默认 1024） | 8,192 | 支持 50+ 语种 |
| multimodal-embedding-v1 | 1024 | - | 图片问答类知识库专用 |
| qwen3-vl-embedding | 2560 | - | 视觉理解（富文本）场景 |

### 排序模型

| 模型 | 最大文档数 | 特点 |
| --- | --- | --- |
| qwen3-rerank | 500 | 100+ 语种，高性能文本排序 |
| qwen3-rerank(hybrid) | - | 混合排序 |
| qwen3-vl-rerank | 文本 100 / 图片 40 / 视频 4 | [多模态](multimodal.md)排序 |

### 检索参数

| 参数 | 取值范围 | 说明 |
| --- | --- | --- |
| 初步向量检索 TopK | 1–100（默认 50） | 向量语义召回的切片数量 |
| 初步关键词检索 TopK | 1–100（默认 50） | 关键词匹配召回的切片数量 |
| 相似度阈值 | 0.01–1.0 | 过滤低分切片，过高会丢弃全部结果 |
| 最大召回数量 | 1–20 | 最终返回的切片数 |
| 排序模式 | 问答 / 相似 / 自定义高级 | 问答模式按 QA 匹配度排序 |

### 索引配置

- **切片方式**：推荐智能切分，基于语义相关性自适应选择切片点，单切片 [Token](token.md) 上限 6,000。
- **Meta 信息抽取**：创建时一次性配置，后续不可更改。可用于按产品名、日期等做前置过滤。
- **多轮对话改写**：创建时选择是否开启，后续不可更改。开启后可优化多轮对话中的检索效果。

### 文档解析方式

| 解析方式 | 特点 |
| --- | --- |
| 电子文档解析 | 最快，不支持插图与图表 |
| 文档智能解析 | 对插图做 OCR 与摘要 |
| 大模型文档解析 | 用千问 VL 深度理解插图与图表，耗时较长 |
| 音视频解析 | 含录音识别、视频帧提取与剧情解析 |

## 效果优化建议

当 RAG 效果不理想时，建议先建立评估基线（至少 100 组评测用例），再按失败类型针对性改进：

- **没有相关知识**：补充知识库内容，优化源文件排版，统一实体表述，启用多轮对话改写。
- **召回不相关**：为文件添加标签或配置 Meta 元数据做前置过滤。
- **切片不完整**：改用智能切分，人工检查并修正异常切片。
- **重排不佳**：通过命中测试调整相似度阈值与 K 值；对列举/总结/比较类问题适当提高 K 值。
- **模型理解有误**：更换生成模型或优化 [prompt](../guides/prompt.md) 指令。

## 规格与计费

知识库分为两个规格：

- **标准版**：0.03 元/小时，1 QPS，平台存储不超过 100 GB。
- **旗舰版**：0.2 元/RCU/小时，50–10,000 QPS（对应 1–200 RCU），平台存储不超过 9,999 GB。RCU 按"向上取整（峰值 QPS / 50）"估算。

知识库仅在华北2（北京）地域开通和使用。知识检索与问答 API 默认限流为用户维度 25 QPS。
