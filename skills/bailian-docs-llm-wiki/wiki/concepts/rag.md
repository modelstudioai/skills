# 检索增强生成（RAG）

检索增强生成（Retrieval-Augmented Generation, RAG）是一种将信息检索与大语言模型生成相结合的技术范式。它通过在推理时从外部知识库中检索相关文档片段，将其注入上下文后交由大模型生成回答，从而让模型能够利用私有数据和最新信息，解决纯参数化模型知识滞后、幻觉等问题。

## 核心工作流程

RAG 在百炼平台中的标准流程分为三个阶段：

1. **文档解析与索引**：将 PDF、Word、Markdown、图片、音视频等非结构化数据，通过文档解析器提取文本，按照切片策略（智能切分、按长度、按页、按标题等）拆分为语义片段，再由向量模型（如 `text-embedding-v4`）编码为向量，存入向量库建立索引。
2. **语义检索与重排**：用户提问时，将查询同样向量化，从向量库中按相似度召回候选切片；随后可选地使用排序模型（如 `qwen3-rerank(hybrid)`）对候选结果进行语义重排，提升召回质量。
3. **上下文增强生成**：将排序后的 Top-K 切片拼入大模型的上下文窗口，由大模型结合检索到的知识生成最终回答。

## 在百炼平台中的使用场景

### 知识库问答

百炼知识库是 RAG 最核心的落地形态。开发者在控制台创建知识库，上传文档后平台自动完成解析、切分、向量化。知识库可挂载到智能体应用或工作流应用，使大模型具备回答特定领域问题的能力。知识库支持多种类型，包括文档搜索、数据查询（NL2SQL）、图片问答和音视频搜索，覆盖了从非结构化文本到结构化表格、从图片到音视频的完整数据形态。

### 框架集成

百炼通过 LlamaIndex（Python）和 Spring AI Alibaba（Java）两大框架提供 RAG 集成能力。LlamaIndex 方案使用 `DashScopeParse` 解析文档、`DashScopeCloudIndex` 管理云端知识库索引、`DashScopeRerank` 进行语义重排；Spring AI Alibaba 通过 `DashScopeDocumentRetriever` 检索百炼知识库切片，结合 `DocumentRetrievalAdvisor` 自动将检索结果注入对话上下文。

### 多渠道应用接入

RAG 应用可通过 AppFlow 连接流快速接入网站、微信公众号、企业微信、钉钉等渠道，也可通过本地 Python 脚本搭建本地检索 + 云端生成的混合架构。所有方案都基于「百炼智能体应用 + 知识库」的统一架构。

### 数据连接

通过百炼的数据连接功能，可以将企业数据库（MySQL、PostgreSQL、PolarDB-X 2.0）、语雀知识库、OSS 对象存储等外部数据源接入平台，为 RAG 应用提供更丰富的检索数据来源。

## 关键参数与配置

### 索引阶段

| 参数 | 说明 | 推荐值 |
| --- | --- | --- |
| 向量模型 | 将文本编码为向量的模型 | `text-embedding-v4`（512 维） |
| 切片方式 | 文档拆分策略，单切片上限 6000 Token | 智能切分 |
| 切片重叠 | 按长度切分时相邻切片的重叠字符数 | 10%-25% |

### 检索阶段

| 参数 | 说明 | 推荐值 |
| --- | --- | --- |
| 排序模型 | 对召回结果进行语义重排 | `qwen3-rerank(hybrid)`（综合语义 + BM25） |
| 排序模式 | 控制排序策略 | 问答模式（默认） |
| 相似度阈值 | 仅高于此值的切片被召回 | 根据场景调整 |
| 最大召回数量（Top-K） | 排序后送入大模型的切片数，上限 20 | 根据上下文窗口和精度需求调整 |

### 框架集成参数

LlamaIndex 关键参数：

- `similarity_top_k`：检索返回的最大结果数（如 5）
- `similarity_cutoff`：最低相似度阈值（如 0.4）
- `top_n`：重排后返回的结果数（如 1）

Spring AI Alibaba 关键配置：

- `spring.ai.dashscope.api-key`：百炼 API Key
- `INDEX_NAME`：知识库名称，需提前在控制台创建

## 效果优化建议

- **切片策略**：根据文档类型选择合适的切分方式，结构化文档（FAQ、参数表）适合极速问答，富文本文档适合视觉理解模式。
- **排序模型**：开启 Rerank 可显著提升召回质量，但需注意不同调用方式下 Rerank 配置的优先级差异（API 参数 > 应用配置 > 知识库默认值）。
- **命中测试**：利用知识库的命中测试功能，在不调用大模型的前提下验证召回质量、调优相似度阈值。
- **多轮对话改写**：开启后可用轻量模型基于历史对话补全当前查询，提升多轮对话场景下的检索准确性。
- **Meta 信息抽取**：为文档切片附加结构化标签，提高检索命中率。
