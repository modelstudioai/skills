# RAG 检索增强生成

RAG（Retrieval-Augmented Generation，检索增强生成）是一种让大模型在生成回答前先从外部知识库中检索相关内容的技术，通过将检索到的信息作为上下文注入提示词，显著提升回答的准确性和专业性，减少模型"幻觉"。

## 核心工作流程

RAG 的核心流程分为三个阶段：

1. **索引阶段**：将文档切分为语义片段（切片），通过向量模型（如 text-embedding-v4）转换为向量并存入知识库。
2. **检索阶段**：用户提问时，将查询转换为向量，在知识库中检索最相关的切片（Top-K），可选经过重排模型（如 gte-rerank）进一步筛选。
3. **生成阶段**：将检索到的切片作为上下文与用户问题一起送入大模型，生成基于事实的回答。

## 在百炼平台的使用方式

### 云端知识库 RAG

百炼提供标准版和旗舰版两种规格的云端知识库，支持文档搜索、数据查询、图片问答、音视频搜索等多种类型。创建知识库后，可通过以下方式集成：

- **智能体应用**：在应用配置中添加知识库，设置相似度阈值和调用方式（如"必定调用"）。
- **工作流应用**：将知识库节点拖入画布，配置输入变量和 TopK 参数。
- **API 调用**：通过百炼 SDK 直接调用知识库检索能力。

### 本地 RAG

对于需要自定义切分策略或使用本地嵌入模型的场景，可基于 LlamaIndex + Gradio 搭建本地 RAG 应用。检索在本地执行，生成调用百炼云端大模型 API（qwen-max / qwen-plus / qwen-turbo），无需本地 GPU。

### 第三方框架集成

- **LlamaIndex（Python）**：通过 `DashScopeCloudIndex` 构建云端知识库并检索，支持配置相似度阈值、Top-K、重排模型等参数。
- **Spring AI Alibaba（Java）**：通过 `DashScopeDocumentRetriever` 检索已有百炼知识库，结合 `ChatClient` 生成回答。

## 关键参数与配置

### 索引配置

| 参数 | 说明 | 建议 |
|------|------|------|
| 切片方式 | 智能切分（语义自适应）或按长度切分 | 大多数场景推荐智能切分 |
| 向量模型 | text-embedding-v4/v3（512 维）、multimodal-embedding-v1（1024 维） | 文档搜索用 text-embedding-v4 |
| Meta 信息抽取 | 为切片附加元数据，支持常量、变量、大模型提取等方式 | 创建时配置，后续无法更改 |

### 检索参数

| 参数 | 说明 | 调优建议 |
|------|------|----------|
| `similarity_top_k` | 检索返回的最高相似度结果数 | 列举/比较类问题适当增大（如 K=20） |
| `similarity_cutoff` | 最低相似度过滤阈值 | 过高会丢弃相关切片，建议通过命中测试调试 |
| 重排模型 | 对检索结果二次排序（如 gte-rerank） | 提升精度，但增加延迟 |
| 召回策略 | 按片段数或按拼装长度 | 总结类问题建议按拼装长度 |

### 生成参数

| 参数 | 说明 |
|------|------|
| 模型选择 | 简单查询用 qwen-turbo/flash，复杂推理用 qwen-max/QwQ，长文档用 qwen-long/plus |
| 提示词 | 限定输出格式，使用 Few-Shot 示例，`${documents}` 变量只出现一次 |

## RAG 效果优化

当检索效果不佳时，可从以下方向优化：

- **检索无效（未找到相关知识）**：补充知识库内容、优化源文件排版（推荐 Markdown）、统一实体表述、启用多轮对话改写。
- **检索无效（召回不相关）**：使用标签过滤缩小检索范围、通过元数据实现结构化前置过滤。
- **切片质量问题**：采用智能切分策略，导入后人工检查切片内容，避免语义截断。
- **提示词优化**：在提示词中限定行为（如禁止编造答案），提供问答示例。

## 数据源支持

百炼 RAG 支持多种数据源接入：

- **平台托管**：通过文件连接器上传 PDF、Word、Markdown 等文档，或通过表格连接器导入 CSV、Excel 数据。
- **流处理**：连接 MySQL、PostgreSQL、PolarDB-X 2.0 数据库，或接入语雀、OSS 等外部存储。
- **文档解析方式**：电子文档解析、文档智能解析、大模型文档解析、Qwen VL 解析、音视频解析。

## 配额与限制

| 项目 | 限制 |
|------|------|
| 标准版存储 | 100 GB |
| 旗舰版存储 | 9,999 GB |
| 单文本切片长度 | 最大 6,000 Token |
| 单次召回切片数 | 最多 20 个 |
| 标准版检索并发 | 1 QPS |
| 旗舰版检索并发 | 50–10,000 QPS |
