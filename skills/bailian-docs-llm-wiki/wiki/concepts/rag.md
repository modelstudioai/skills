# 检索增强生成

检索增强生成（RAG, Retrieval-Augmented Generation）是一种将外部知识检索与大模型文本生成相结合的技术范式。它通过在推理阶段从知识库中召回与用户查询语义相关的文本切片，将其注入大模型上下文，使模型能够基于最新、准确的私有数据生成回答，从而突破大模型训练数据截止和缺乏领域知识的局限。

## 在百炼平台中的应用场景

RAG 在百炼平台中贯穿多个核心功能模块：

- **知识库问答**：最典型的 RAG 场景。将 PDF、Word、Markdown、音视频等非结构化数据上传至知识库，经解析、切分、向量化后存入向量库。用户提问时，系统按语义相似度召回相关切片，交由大模型生成答案。
- **智能体应用**：智能体可挂载知识库作为工具。新版智能体（Agent 2.0）由模型自主决策是否调用知识库检索，旧版则采用"先检索知识库、再决策"的固定流程。
- **工作流应用**：通过拖入"知识库"节点，将检索变量绑定到 query，下游接大模型节点在提示词中插入检索结果，实现可编排的 RAG 链路。
- **文件问答**：智能体应用支持上传文件后以"切片检索"模式处理，将文件切分为片段按相关性检索，适合长文档精确问答。
- **多渠道接入**：网站、微信公众号、企业微信、钉钉等渠道均可通过 AppFlow 连接百炼 RAG 应用，快速实现智能客服。
- **本地 RAG**：通过 Python 脚本搭建本地检索 + 云端生成的混合方案，支持 LlamaIndex 和 Spring AI Alibaba 等框架。

## RAG 核心流程

RAG 的处理流程可分为离线索引和在线检索两个阶段：

1. **离线索引**：文档上传 -> 解析（支持电子文档、文档智能、大模型、音视频等解析方式）-> 切分（智能切分、按长度、按页、按标题等）-> 向量化（Embedding）-> 存入向量库
2. **在线检索**：用户提问 -> 可选多轮对话改写 -> 向量检索召回候选切片 -> Rerank 重排序 -> 过滤低于相似度阈值的结果 -> 将召回切片注入大模型上下文 -> 生成回答

## 关键参数与配置

### 向量模型

| 模型 | 维度 | 适用场景 |
|------|------|---------|
| text-embedding-v4（推荐） | 512 | 文档/数据/音视频类知识库 |
| text-embedding-v3 | 512 | 文档/数据/音视频类知识库 |
| multimodal-embedding-v1 | 1024 | 图片问答类知识库 |
| qwen3-vl-embedding | - | 视觉理解（富文本文档）场景 |

### 切分参数

- **切分方式**：智能切分（推荐）、按长度（可设重叠字符数，建议 10%-25%）、按页、按标题、按正则、按符号
- **单切片上限**：6000 Token

### 检索与排序参数

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| 排序模型 | 对召回结果进行语义重排 | qwen3-rerank（hybrid），综合语义 + BM25 |
| 排序模式 | 问答模式 / 相似模式 / 自定义高级 | 问答模式 |
| 相似度阈值 | 低于此值的切片不召回 | 视场景调整，视觉理解默认 0.20 |
| 最大召回数量 | 排序后送入大模型的切片数 K | 上限 20 |
| 多轮对话改写 | 用轻量模型补全历史上下文 | 按需开启 |

### 框架集成参数

通过 LlamaIndex 或 Spring AI Alibaba 构建 RAG 应用时的关键参数：

```python
# LlamaIndex 示例
similarity_top_k = 5       # 检索返回的最大结果数
similarity_cutoff = 0.4    # 最低相似度阈值
top_n = 1                  # 重排后返回的结果数
```

## RAG 效果优化要点

- **切分策略**：根据文档类型选择合适的切分方式，结构化文档可按标题切分，通用文档推荐智能切分
- **排序模型**：启用 Rerank 可显著提升召回精度，同一切片在不同排序模式下分数差异显著
- **阈值调优**：通过知识库的"命中测试"功能模拟提问，验证召回质量并调整相似度阈值
- **Meta 信息抽取**：为切片附加元数据（文件名、分类等），可提高检索的精准度
- **Rerank 配置优先级**：API 参数 > 应用配置 > 知识库默认配置，配置不当可能产生非预期费用

## 数据源支持

RAG 知识库支持多种数据源接入：

- **非结构化数据**：PDF、Word、Markdown、图片、音视频等，通过文件连接器或直接上传
- **结构化数据**：Excel、CSV 表格，支持 NL2SQL 查询模式
- **外部数据库**：MySQL、PostgreSQL、PolarDB-X 2.0，通过数据连接器实时访问
- **文档系统**：语雀知识库、OSS 对象存储
