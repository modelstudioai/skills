# 检索增强生成

检索增强生成（RAG, Retrieval-Augmented Generation）是一种将信息检索与大语言模型生成相结合的技术架构。它让大模型在回答用户问题之前，先从外部知识库中检索相关内容作为上下文，从而提升回答的准确性、时效性和专业性，有效缓解大模型的"幻觉"问题。

## 核心原理

RAG 的工作流程分为两个阶段：

1. **检索阶段**：将用户的查询通过向量模型（Embedding Model）转换为向量表示，在知识库的向量索引中查找语义最相似的文本切片，并通过重排模型（Rerank Model）对候选结果进行精排。
2. **生成阶段**：将检索到的相关文本切片与用户原始问题一起组装为提示词，输入大语言模型生成最终回答。模型基于检索到的事实性内容进行推理，而非仅依赖自身参数化知识。

## 在百炼平台中的使用场景

### 云端知识库

百炼平台的知识库服务是 RAG 的核心载体。开发者可以上传企业文档（PDF、Word、Markdown 等），平台自动完成文档解析、切片、向量化和索引构建。知识库支持四种类型：文档搜索、数据查询、图片问答和音视频搜索，覆盖结构化与非结构化数据的检索需求。

知识库可直接关联到智能体应用或工作流应用中。新版智能体（Agent 2.0）将知识库作为工具由模型自主调用，旧版智能体则采用先检索后决策的固定流程。

### 框架集成

百炼提供了与 LlamaIndex（Python）和 Spring AI Alibaba（Java）两个主流框架的 RAG 集成能力：

- **LlamaIndex**：通过 `DashScopeCloudIndex` 管理云端知识库，使用 `DashScopeRerank` 进行结果重排，支持从本地文件一站式构建 RAG 应用。
- **Spring AI Alibaba**：通过 `DashScopeDocumentRetriever` 检索百炼知识库，结合 `DocumentRetrievalAdvisor` 将检索结果注入提示词模板，配合 `ChatClient` 完成问答。

### 本地知识库 RAG

对数据安全有要求的场景，可基于 LlamaIndex + Gradio 在本地构建检索系统，仅将检索结果发送到云端大模型进行生成，兼顾数据隐私与推理质量。

### 文件问答

智能体应用支持用户在对话中上传文件，通过"切片检索"模式实时构建临时 RAG 索引进行问答，适合长文档的即时分析场景。

### 业务渠道集成

RAG 能力可通过 AppFlow 等连接器集成到网站 AI 助手、微信公众号、企业微信、钉钉等业务渠道中，为各渠道的智能客服提供专业领域的准确回答。

## 关键参数与配置

### 索引构建参数

| 参数 | 说明 | 建议 |
|------|------|------|
| 切片方式 | 智能切分或按长度切分 | 推荐智能切分，基于语义自适应选择切片点 |
| 向量模型 | text-embedding-v4 / v3（文档）；multimodal-embedding-v1（图片） | 优先选择 v4 |
| Meta 信息抽取 | 为切片附加元数据键值对 | 配置后可显著提升检索精准度 |
| 文本切片长度上限 | 最大 6,000 Token | 根据文档特性调整 |

### 检索参数

| 参数 | 说明 | 调优建议 |
|------|------|----------|
| 相似度阈值 | 仅高于阈值的结果被召回 | 设置过高会过滤相关内容，建议从较低值开始调整 |
| 召回片段数（TopK） | 返回的文本切片数量，取值 1-20 | 复杂问题（总结、比较类）建议适当增大 |
| 知识库权重 | 关联多个知识库时按重要程度分配 | 核心知识库给予更高权重 |
| 重排模型 | 对初步检索结果进行精排 | LlamaIndex 场景可使用 gte-rerank |

### 生成参数

| 参数 | 说明 |
|------|------|
| 生成模型 | 推荐千问-Max（质量优先）或千问-Plus（性价比） |
| 提示词模板 | 可添加输出限定、Few-Shot 示例、内容分隔标记 |

## RAG 效果优化

当 RAG 应用的回答质量不理想时，可按阶段进行诊断和优化：

### 检索阶段优化

- **无检索结果**：补充知识库内容、优化源文件排版（优先使用 Markdown 格式）、消除实体歧义、启用多轮对话改写。
- **检索结果不相关**：为文件添加标签进行过滤、定义元数据进行结构化搜索。
- **切片不完整**：采用智能切分策略、人工检查和修正切片内容。

### 排序与生成阶段优化

- **重排不佳**：调整相似度阈值、增加召回片段数、使用"按拼装长度"策略。
- **模型理解有误**：更换更强的生成模型、优化提示词模板。

建议在优化前建立评估基线，创建至少 100 组问题的评测集，覆盖事实型、比较型、教程型、分析型问题。

## 规格与计费

百炼知识库提供标准版和旗舰版两种规格：

| 规格 | 并发上限 | 存储空间 | 价格 |
|------|---------|---------|------|
| 标准版 | 1 QPS | 平台存储 100 GB 以内 | 0.03 元/知识库/小时 |
| 旗舰版 | 50-10,000 QPS | 平台存储 9,999 GB 以内 | 0.2 元/RCU/小时 |

费用由规格费用（运行时长）和模型调用费用（向量化 + 排序）两部分构成。新用户享有 720 小时标准版免费额度。关联 N 个知识库时，Token 消耗量按 N 倍计算。可通过关闭排序功能或降低初步召回参数来优化费用。

## 数据连接与来源

RAG 应用的数据可来自多种连接器：

- **文件连接器**：上传 PDF、Word、Markdown 等非结构化文档。
- **表格连接器**：导入 CSV、Excel 等结构化数据。
- **数据库连接器**：连接 MySQL、PostgreSQL、PolarDB-X 2.0，实时查询业务数据。
- **语雀 / OSS 连接器**：直接访问已有文档系统或对象存储中的内容。
