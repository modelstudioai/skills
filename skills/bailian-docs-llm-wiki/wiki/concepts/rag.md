# 检索增强生成

检索增强生成（Retrieval-Augmented Generation, RAG）是一种将外部知识检索与大语言模型生成相结合的技术范式。百炼平台以 RAG 为核心机制，让大模型在回答时能够引用私有数据和最新信息，从而解决模型训练数据滞后、无法访问企业内部知识的问题。

## 工作原理

RAG 的基本流程分为三个阶段：

1. **索引阶段**：将文档经过解析、切分后，通过向量模型转换为数值向量，存入向量数据库。
2. **检索阶段**：用户提问时，将查询同样向量化，按语义相似度从向量库中召回最相关的文档切片。
3. **生成阶段**：将召回的切片作为上下文注入大模型提示词，由模型结合检索结果生成最终回答。

## 在百炼平台中的使用场景

### 知识库

知识库是百炼平台 RAG 能力的核心载体，支持文档搜索、数据查询（NL2SQL）、图片问答和音视频搜索四种类型。创建知识库后可挂载到智能体或工作流应用中使用。知识库在索引阶段通过切片方式（智能切分、按长度、按页等）将文档拆分为片段，使用向量模型（推荐 text-embedding-v4）进行向量化，并可配置排序模型（Rerank）对检索结果做二次排序以提升召回质量。

### 智能体应用

智能体应用可通过绑定知识库获得 RAG 能力。新版智能体（Agent 2.0）将知识库统一为工具，由智能体自主规划何时调用检索，支持通过标签限定查询范围。智能体还支持文件问答的"切片检索"模式，将用户上传的文件临时切分后走 RAG 流程回答问题。

### 工作流应用

工作流中可拖入"知识库"节点，将输入变量绑定到查询参数，支持固定选择或动态引入知识库。检索结果通过 result 变量传递给下游大模型节点进行生成。

### 外部应用集成

通过百炼 SDK 或第三方框架（LlamaIndex、Spring AI Alibaba）可在外部应用中集成 RAG 能力。LlamaIndex 提供从文件解析到云端知识库构建的完整流程；Spring AI Alibaba 通过 DashScopeDocumentRetriever 检索知识库切片并结合大模型生成回答。也可基于本地知识库搭建纯本地检索 + 云端生成的混合 RAG 应用。

### 多渠道接入

百炼 RAG 应用可通过 AppFlow 连接流快速接入网站、微信公众号、企业微信、钉钉等渠道，无需编码即可为这些平台提供基于私有知识的智能问答服务。

## 关键参数与配置

### 向量模型

| 模型 | 向量维度 | 单行最大 Token | 适用场景 |
| --- | --- | --- | --- |
| text-embedding-v4（推荐） | 64 ~ 2048，默认 1024 | 8,192 | 通用文本，100+ 语种 |
| text-embedding-v3 | 64 ~ 1024，默认 1024 | 8,192 | 通用文本 |
| text-embedding-v2 / v1 | 1,536（固定） | 2,048 | 兼容旧索引 |
| multimodal-embedding-v1 | 1,024 | — | 图片问答场景 |
| qwen3-vl-embedding | — | — | 视觉理解（富文本文档） |

### 切片方式

支持智能切分（语义自适应，推荐）、按长度（含重叠字符数，建议 10%~25%）、按页、按标题、按正则、按符号六种方式，单切片上限 6000 Token。

### 排序模型（Rerank）

推荐 qwen3-rerank（hybrid），综合语义与 BM25 评分。排序模式分为问答模式（默认）、相似模式和自定义高级模式。注意：Rerank 不支持图片问答类知识库，视觉理解和极速问答场景不支持排序模式配置。

### 检索参数

| 参数 | 说明 | 备注 |
| --- | --- | --- |
| 相似度阈值 | 仅高于此值的切片被召回 | 应用侧设置会覆盖知识库默认值 |
| 最大召回数量 | 排序后送入大模型的切片数 K | 上限 20 |
| similarity_top_k | LlamaIndex 中的检索返回数 | 默认 5 |
| similarity_cutoff | LlamaIndex 中的最低相似度 | 默认 0.4 |

### 多轮对话改写

可开启轻量模型基于历史对话补全当前查询，提升多轮对话场景下的检索准确度。

## RAG 效果优化要点

- **切片策略**：根据文档类型选择合适的切片方式，结构化文档（FAQ、参数表）适合极速问答模式，富文本文档适合视觉理解模式。
- **Rerank 调优**：通过命中测试对比问答模式与相似模式的分数差异，选择最佳排序策略。注意不同调用方式（应用内配置、知识库配置、API 参数）的优先级差异。
- **向量模型选择**：新建知识库推荐使用 text-embedding-v4，维度可按需降维以平衡精度与性能。
- **Meta 信息抽取**：为切片附加元数据标签，配合标签过滤提升检索精度。
