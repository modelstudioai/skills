# 检索增强生成（RAG）

检索增强生成（Retrieval-Augmented Generation，RAG）是一种让大模型在生成回答前先从外部知识源中检索语义相关内容的技术，从而弥补模型训练数据的滞后性，提升回答的准确性和时效性。在百炼平台中，RAG 是知识库、[智能体应用](agent-application.md)和工作流应用的核心底层能力。

## 工作原理

RAG 的典型流水线包含三个阶段：

1. **索引（Indexing）**：将文档经过解析、切片后，通过向量模型转换为数值向量并存入向量索引。
2. **检索（Retrieval）**：用户提问时，将查询文本同样向量化，从索引中召回语义最相关的文档片段，并可通过排序模型（Rerank）进行二次精排。
3. **生成（Generation）**：将召回的知识片段与用户问题拼接为上下文，送入大模型生成最终回答。

## 在百炼平台中的使用场景

### 知识库集成

百炼知识库是 RAG 能力的主要载体，支持文档搜索、数据查询、图片问答、音视频搜索四种类型。创建知识库后，可通过以下方式将其集成到业务中：

- **[智能体应用](agent-application.md)**：在应用配置页添加知识库，设置相似度阈值和权重。Agent 2.0 架构下，知识库作为工具由智能体自主规划调用。
- **工作流应用**：将知识库节点拖入画布，配置输入变量和 TopK 参数，连接大模型节点。
- **API 调用**：通过百炼 SDK 直接调用知识检索或知识问答服务。

### 文件问答

[智能体应用](agent-application.md)支持切片检索（RAG）模式的文件问答：上传的文件被切分为片段，提问时检索最相关的切片，[Token](token.md) 消耗通常远小于全文引用模式，适合长文档问答和精确定位信息来源。

### 多渠道接入

通过 AppFlow 或本地部署，RAG 应用可接入网站、企业微信、微信公众号、钉钉等渠道，实现基于私有知识库的智能客服和问答服务。

### 框架集成

百炼支持通过主流开源框架构建 RAG 应用：

- **LlamaIndex（Python）**：使用 `DashScopeCloudIndex` 创建云端知识库，通过 `as_retriever()` 或 `as_query_engine()` 实现检索与问答。
- **Spring AI Alibaba（Java）**：在 Spring Boot 工程中集成百炼知识库检索能力，通过配置 [API Key](api-key.md) 和 Workspace ID 即可调用。

## 关键参数与配置

### 索引阶段

| 参数 | 说明 |
|------|------|
| 文档解析方式 | 电子文档解析（最快）、文档智能解析（识别插图）、大模型文档解析（深度理解图表）等 |
| 切片方式 | 推荐智能切分，基于语义相关性自适应切分，单切片最大 6,000 [Token](token.md) |
| 向量模型 | text-embedding-v4（最高 2048 维）、text-embedding-v3（最高 1024 维）等 |
| Meta 信息抽取 | 为切片附加元数据，支持常量、变量、大模型抽取、正则抽取四种方式 |

### 检索阶段

| 参数 | 说明 |
|------|------|
| 召回片段数（TopK） | 越大参考越多但噪声可能增加，单次最大召回 20 个切片 |
| 相似度阈值 | 越高越严格（噪声减少但可能丢失相关内容），设为 0 时不剔除 |
| 排序模型 | 推荐 qwen3-rerank（文本）或 qwen3-vl-rerank（[多模态](multimodal.md)），对召回结果二次精排 |
| 混合检索 | 支持向量检索 + 关键词检索组合，提升召回覆盖率 |
| Query 改写 | 根据多轮对话历史自动补全用户查询，需在创建知识库时开启 |

### 生成阶段

| 参数 | 说明 |
|------|------|
| 大模型选择 | qwen-max（性能优秀）、qwen-plus（均衡）、qwen-turbo（速度快成本低） |
| 检索模式 | 极速模式（单轮检索直接生成）或多轮智能模式（Agentic，自动意图识别和知识库路由） |

## 效果优化

当 RAG 效果不理想时，可从以下维度排查：

- **检索无效**：补充缺失内容、优化源文件排版、统一实体表述、启用多轮对话改写。
- **召回不相关**：使用标签过滤或元数据进行结构化搜索。
- **切片不完整**：采用智能切分策略，人工检查异常切片。
- **重排不佳**：适当降低相似度阈值、增大召回片段数。
- **模型理解有误**：更换更强模型（如从开源版换到千问 Max/Plus）、优化系统提示词。
