# 限流与配额

限流与配额是百炼平台对模型调用吞吐量进行管控的机制，通过 RPS/RPM、TPM 等维度约束单位时间内的请求数与 token 量，以保障共享资源池的稳定；在超出公共限流阈值时可通过预购专属容量获得刚性保障。

## 限流的触发与表现

百炼模型调用受服务整体负载与请求并发影响，限流触发后的等待时间取决于 RPS/RPM 限流值。例如在 120 RPM（每秒 2 次）的限流下，0.2 秒内连续提交 2 次后，第 3 次请求需等待约 0.8 秒才能被处理。生成速度并非固定值，会随并发量和负载波动。

常见限流维度：

- **RPS / RPM**：每秒/每分钟请求数，控制调用频次。
- **TPM（Tokens Per Minute）**：每分钟 token 吞吐量，按输入、输出分别计量。
- **QPS**：部分管理类接口（如异步任务查询、取消）统一限制为 20 QPS，按主账号 + 子账号维度计算。

异步任务的三个通用接口（查询单个任务、批量查询、取消任务）共享 20 QPS 的限流额度；频繁轮询结果接口既浪费资源又容易触达该上限，建议改用事件总线 EventBridge 的任务完成通知方案——通知方案不限流、实时性高、不占用业务系统资源。

## 公共池与专属容量

百炼提供多种推理容量与计费方案，限流行为因方案而异：

- **按量付费**：按 token 计费，共享公共池，无容量保障，超额受公共限流影响，无需改动代码。
- **资源包 / 节省计划**：预付费额度折扣，非专属容量，超出后转按量并受公共限流约束。
- **TPM 预留**：按 kTPM 预付费，专属容量刚性兑付，业务高峰期不受公共限流影响；超出保障额度自动降级为按量计费且不中断服务，仅需将 `model` 参数替换为专属模型 code。
- **PTU 专属部署**：按 kTPM 预付费的专属部署实例，适用于高吞吐高性能场景，超出转按量。

TPM 预留适用于"流量可预估、不能接受限流"的生产场景：预留容量内的调用为业务专属、不与其他用户共享，可在详情页的"超额降级统计"中查看降级次数。

## 关键参数与配置

创建 TPM 预留时的核心参数：

| 参数 | 说明 |
| --- | --- |
| 输入 TPM | 输入吞吐量，单位 kTPM（1 kTPM = 1,000 Tokens/分钟） |
| 输出 TPM | 输出吞吐量，单位 kTPM，与输入分别计价 |
| 付费周期 | 按天计费，预付费一次性支付 |
| 购买时长 | 预留有效时长，到期前一天 08:00 可自动续费 |

容量计算器自动应用以下换算规则：

- **长输入阶梯系数**：部分模型（如 glm-5.1）在输入长度处于 [32K, 200K] 区间时，输入系数 1.33、输出系数 1.17。
- **缓存折扣**：缓存命中部分按比例折算容量——glm-5.1 与 Qwen 系列按 20%，deepseek-v4-pro 按 8%。
- **输入上限**：glm-5.1 为 200K，deepseek-v4-pro 与 Qwen 系列为 256K。

容量计算器输入项包括每分钟请求数（RPM）、平均输入长度、平均输出长度、预估缓存命中率，据此自动推荐输入/输出 TPM。

## 地域与域名对限流的影响

地域决定接入点与数据存储位置，接入域名则直接影响并发上限与超时等服务保障：

- **专属域名** `{WorkspaceId}.{region}.maas.aliyuncs.com`：SLA 99.9%、超时 3600 秒，生产环境推荐。
- **共享域名** `dashscope.aliyuncs.com`：用于存量兼容。
- **试用域名** `trial.{region}.maas.aliyuncs.com`：仅用于快速体验，不建议生产。

各地域的接入域名、API Key、模型列表不能跨地域混用；德国（法兰克福）、日本（东京）通过业务空间区分全球/欧盟或全球/日本部署范围。从共享域名迁移到专属域名只需替换 Base URL 的域名部分，业务代码无需修改。

## 应对限流的实践建议

- **预估并预留容量**：对流量可预估且不能接受限流的核心业务，优先使用 TPM 预留锁定专属吞吐量。
- **做好请求排队与重试**：短时间内请求量快速拉升时系统需短暂预热匹配算力，预热期间部分请求可能延迟波动。
- **避免轮询触发限流**：异步任务场景使用 EventBridge 通知替代轮询，规避 20 QPS 上限。
- **选用稳定版本别名**：生产环境按"选择模型"中的稳定版或带日期快照版本调用，以获得更稳定的限流额度。
- **权限收窄与分账**：将 RAM 用户归入子业务空间并仅授权必要模型，使用子空间 API Key 调用，既缩小爆炸半径也便于按空间核算配额。
