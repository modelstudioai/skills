# 限流与吞吐

限流与吞吐指百炼平台对模型调用并发能力与流量速率的管控机制，涵盖按 Token 计量的吞吐量上限（TPM）、每分钟请求数（RPM）与每秒请求数（QPS）等维度，用于在共享资源池下保障服务稳定、避免超额请求被拒绝（HTTP 429）。

## 限流维度与单位

百炼对不同类型接口采用不同的限流计量单位：

- **模型推理调用**：以 TPM（Tokens Per Minute）为核心计量，按每分钟输入/输出 Token 数计；同时关注 RPM（每分钟请求数）与首包延时等性能指标。
- **异步任务管理接口**：查询单个任务、批量查询、取消任务三个接口统一限流 20 QPS，按主账号 + 子账号维度计算。频繁轮询任务结果会浪费资源并可能触发该限流，建议改用事件总线 EventBridge 完成通知。
- **不同模型类型[计费](billing.md)/统计口径不同**：大语言模型按 Token 计；图像生成按"张"、视频生成按"秒"；语音模型按时长、字符或 Token；向量与重排序模型按输入 Token。限流额度相应与[计费](billing.md)维度对齐。

## 共享池与专属容量

默认按量付费调用共享公共推理资源池，无容量保障，业务高峰期超额会受公共限流影响并返回 429。对于不能接受限流的场景，百炼提供两类专属容量方案：

- **TPM 预留**：按 kTPM 预付费为指定模型锁定专属吞吐量，预留容量内调用为业务专属、不与其他用户共享；超出部分自动降级为按量[计费](billing.md)且不中断服务，仅需将 API 请求中的 `model` 参数替换为详情页提供的专属模型 code。适用于"流量可预估、不能接受限流"的场景。
- **PTU 专属部署**：按 kTPM 预付费获得专属部署实例，适用于高吞吐高性能场景，超出转按量，需替换 `model` 参数。

选型时还应对比按量付费、资源包/节省计划等方案：资源包/节省计划为预付费额度折扣，非专属容量，超出仍转按量。

## 关键参数与配置

创建 TPM 预留时需填写以下参数：

| 参数 | 说明 |
| --- | --- |
| 输入 TPM | 输入吞吐量，单位 kTPM（1 kTPM = 1,000 Tokens/分钟） |
| 输出 TPM | 输出吞吐量，单位 kTPM |
| 付费周期 | 按天计费，输入与输出 TPM 分别计价（Per 1000 TPM） |
| 购买时长 | 预留有效时长 |
| 到期自动续费 | 到期前一天 08:00 自动扣款续费，默认开启 |

容量换算会影响实际消耗：部分模型支持长输入阶梯系数与缓存折扣。例如 glm-5.1 输入长度处于 [32K, 200K] 区间时输入系数 1.33、输出系数 1.17，缓存命中部分按 20% 折算容量；deepseek-v4-pro 缓存命中按 8% 折算；Qwen 系列缓存命中按 20% 折算。容量计算器会根据 RPM、平均输入/输出长度、预估缓存命中率自动推荐输入/输出 TPM。

## 接入域名与地域对并发的决定作用

地域、服务部署范围与接入域名共同决定并发上限：

- **专属接入域名**（`{WorkspaceId}.{region}.maas.aliyuncs.com`）具备更高并发承载能力与网络隔离性，请求超时 3600 秒，支持 HTTP/SSE/WebSocket/WebRTC，提供 99.9% SLA，推荐生产环境使用。
- **共享域名**（`dashscope.aliyuncs.com`）兼容存量业务，建议迁移至专属域名。
- **试用域名**（`trial.{region}.maas.aliyuncs.com`）仅用于快速体验，不建议用于生产。
- 各地域有独立的接入域名、API Key 和模型列表，不能跨地域混用；德国（法兰克福）和日本（东京）地域通过业务空间区分服务部署范围。

## 监控限流与超额降级

模型监控提供与限流直接相关的运行指标，用于稳定性保障：

- **性能指标**：RPM、TPM、调用时长、首 Token 延时、非首 Token 延时。
- **错误指标**：失败次数、失败率、限流错误次数（429）、内容安全错误次数。
- 普通监控延迟通常为小时级，高级监控可达分钟级；告警功能仅支持北京、新加坡地域。
- TPM 预留详情页提供"超额降级统计"，可查看降级为按量计费的次数；短时间内请求量快速拉升时系统需短暂预热，预热期间可能出现延迟波动，应做好请求排队或重试机制。

## 避免限流的实践建议

- 高并发或对实时性要求高的异步任务场景使用 EventBridge 通知方案，避免轮询触发 20 QPS 限流。
- 流量可预估且不能接受限流的业务使用 TPM 预留锁定专属容量，超额自动降级按量不中断。
- 生产环境使用专属接入域名获取更高并发承载能力。
- 在不可信环境（浏览器、移动 App）使用临时 API Key（默认 60 秒、可设 1~1800 秒）下发客户端，降低永久 Key 泄露带来的限流与安全风险。
