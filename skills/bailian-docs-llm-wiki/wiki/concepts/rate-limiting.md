# 限流与吞吐

限流与吞吐是衡量百炼模型服务在单位时间内可处理请求量与 token 数量的核心指标，直接决定业务在高并发场景下的稳定性与可用性。百炼通过 TPM/RPM 配额、TPM 预留、专属部署、异步任务通知等多种手段，帮助开发者在不接受限流的场景获得稳定容量，同时在弹性场景下按量使用公共池。

## 概念与单位

- **TPM（Tokens Per Minute）**：每分钟可处理的 token 数，是模型推理吞吐的主要计量单位。预留容量以 `kTPM` 为步长（1 kTPM = 1,000 Tokens/分钟），并区分为输入 TPM 与输出 TPM。
- **RPM（Requests Per Minute）**：每分钟请求数，反映并发调用频率，RPM 越大通常需要同比增大 TPM。
- **QPS**：每秒请求数，部分管理类接口（如异步任务查询/取消）以 QPS 为限流维度。
- **公共限流**：按量付费场景下所有用户共享公共推理资源池，配额按主账号 + 子账号维度计算，超量请求会被限流。

## 百炼中的典型场景

### 1. 按量付费：弹性共享公共池

默认接入方式，无需额外配置。请求进入公共资源池，按实际消耗的 token 计费。优点是接入简单、可跨业务空间调用，缺点是在业务高峰期可能受公共限流影响，无法保障稳定吞吐。适合流量波动大、短期验证或对延迟不敏感的场景。

### 2. TPM 预留：专属容量刚性兑付

为指定模型预付费锁定专属推理吞吐量，业务高峰期不受公共限流影响。创建时分别填写输入 TPM 与输出 TPM，提交后自动生成专属模型 code，调用时把 API 中的 `model` 参数替换为该 code 即可，无需改动其他代码。超出预留容量时自动降级到公共池按量付费，不会中断服务。

适合流量可预估且不能接受限流的业务。当对极致性能与隔离有更高要求时，可进一步选择 PTU 专属部署。

### 3. PTU 专属部署：独占实例

按 kTPM 预付费获得专属部署实例，资源完全隔离，适合高吞吐、高性能场景。接入方式与 TPM 预留一致，替换 `model` 参数即可。

### 4. 异步任务：避免轮询触发限流

图像生成、视频生成等耗时模型采用异步机制：先创建任务拿到 `task_id`，再查询结果。查询/取消接口的限流均为 **20 QPS**（按主账号 + 子账号维度）。频繁轮询不仅浪费资源，还可能触发限流。推荐接入事件总线 EventBridge 的任务完成通知，任务结束后由事件总线主动推送，收到通知后再查询一次即可。通知方案不限流、实时性高，适合高并发或对实时性要求高的任务。

### 5. 业务空间专属域名：提升吞吐与时延隔离

生产环境推荐使用业务空间专属域名 `https://{WorkspaceId}.{region}.maas.aliyuncs.com`，相比中心化 `dashscope.aliyuncs.com` 域名提供更高的吞吐上限、更长的请求超时（3600 秒）和 SLA 99.9% 保障，并在时延上与其它业务隔离。试用域名 `trial.{region}.maas.aliyuncs.com` 限流较小，仅限快速验证。

## 关键参数与配置

### TPM 预留创建参数

| 参数 | 是否必填 | 说明 |
| --- | --- | --- |
| 预留名称 | 是 | 自定义名称，≤ 50 个字符 |
| 选择模型 | 是 | 选择需预留容量的模型，提交后生成专属模型 code |
| 付费周期 | 是 | 按天 |
| 输入 TPM | 是 | 预留输入吞吐量，单位 kTPM，起步和步长因模型而异 |
| 输出 TPM | 是 | 预留输出吞吐量，单位 kTPM |
| 购买时长 | 是 | 预留有效时长 |
| 到期自动续费 | 否 | 到期前一天 08:00 自动扣款续费，默认开启 |

### 容量换算系数

部分模型支持长输入阶梯系数和缓存折扣，TPM 容量计算器会自动应用：

| 模型 | 输入长度上限 | 缓存折扣 | 长输入阶梯系数 |
| --- | --- | --- | --- |
| glm-5.2 | 1M | 0.25 | 无阶梯（1.0） |
| glm-5.1 | 200K | 0.2 | [0, 32K)：1.0/1.0；[32K, 200K]：1.33/1.17 |
| deepseek-v4-pro | 256K | 0.08 | 无阶梯（1.0） |
| deepseek-v4-flash | 256K | 不支持 | 无阶梯（1.0） |
| Qwen 系列 | 256K | 0.2 | 无阶梯（1.0） |

容量计算器输入项：每分钟请求数（RPM）、平均输入长度、平均输出长度、预估缓存命中率。命中率越高，输入容量消耗越慢，建议输入 TPM 越低；输入越长，阶梯系数越大，建议输入 TPM 越高。

## 选型建议

- **流量波动大 / 短期验证**：按量付费 + 公共池，接入零改动。
- **费用优化**：在按量基础上叠加资源包或节省计划，享受承诺用量折扣，但仍是共享容量。
- **流量可预估、不能接受限流**：TPM 预留，专属容量刚性兑付，超额自动降级公共池不中断。
- **极致性能与隔离**：PTU 专属部署。
- **生产环境**：搭配业务空间专属域名，获得更高吞吐、更长超时与 SLA 保障。
- **耗时异步任务**：用 EventBridge 通知替代轮询，规避 20 QPS 限流并提升实时性。

## 注意事项

- 各地域（北京、新加坡、弗吉尼亚等）的 API Key、模型列表、接入域名**不能跨地域混用**，临时 Key 与生成它的永久 Key 必须属于同一地域。
- 异步任务接口可查询/取消当前 API Key 所属主账号下的所有任务，但无法跨主账号操作；取消接口仅支持 `PENDING` 状态。
- TPM 预留的模型列表、价格、起步与步长以控制台创建页面实际展示为准，会动态调整。
- 从 Dashscope 域名迁移到业务空间专属域名时，需同步更换配套的 API Key，错配会返回 401。
