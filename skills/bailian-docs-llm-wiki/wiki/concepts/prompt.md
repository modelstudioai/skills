# Prompt 工程

Prompt 工程是百炼平台上系统化设计、验证、优化和复用提示词（Prompt）的方法论与技术实践，旨在通过结构化表达、变量注入、样例引导、自动增强与数据驱动迭代等手段，稳定提升大模型在具体业务场景下的输出质量、一致性与可控性。

## 在百炼平台的不同场景中，这个概念如何使用

- **智能体（Agent）与工作流（Workflow）构建**：Prompt 是智能体的“大脑指令”，用于定义角色、任务目标、约束条件与输出格式；在工作流中，Prompt 作为大模型节点的核心输入，可结合 RAG 检索结果、工具调用返回、上下文变量动态组装，实现多步骤逻辑闭环。  
- **模板化应用开发**：通过「Prompt 模板」功能，将通用指令抽象为可复用的模板（如“会议纪要生成”“客服话术润色”），支持 `${variable}` 占位符注入，跨应用、跨团队共享，降低重复开发成本。  
- **多模态生成控制**：在文生图（万相）、文生视频（万相 3.0 / Vidu）等场景中，Prompt 工程体现为正向提示（`prompt`）与负向提示（`negative_prompt`）的协同设计，并可通过 `prompt_extend=true` 启用大模型自动扩写，提升短提示的语义完整性与画面可控性。  
- **评测与优化闭环（[agenteval](../guides/agenteval.md)）**：在 `agenteval` 模块中，Prompt 工程进入量化阶段——支持多版本 A/B 对比调试、基于人工反馈的定向优化、以及基于高质量评测集或线上 Trace 数据的自动迭代，形成“观测 → 评测 → 优化”闭环。  
- **RAG 替代路径**：官方已明确停止维护 Prompt 样例库（few-shot 样例库），所有新项目须迁移至 RAG 表格库；此时 Prompt 工程重点转向设计高效检索指令（如“请基于以下知识片段回答…”）与后处理提示（如“仅输出 JSON，不加解释”），确保 RAG 输出与 Prompt 指令严格对齐。

## 关键参数和配置

| 参数 | 说明 | 实践建议 |
|------|------|----------|
| `promptTemplateId` | 模板唯一标识符，用于 API 动态加载模板内容 | 保存模板后立即记录该 ID，避免硬编码；推荐在环境变量中管理。 |
| `variables` | 模板中声明的占位符列表（如 `${topic}`、`${max_length}`） | 建议命名语义清晰、全小写+下划线；运行时务必校验必填变量是否传入，否则模板渲染失败。 |
| `workspaceId` | 业务空间 ID，所有 Prompt 相关 API 的必需参数 | 需通过控制台或 API 显式获取，不可复用其他 workspace 的 ID。 |
| `prompt_extend` | 图片/视频生成类模型的提示词智能扩写开关（默认 `true`） | 对模糊提示（如“科技感海报”）开启可显著提升效果；对精确控制需求（如“16:9，无文字，蓝白渐变”）建议关闭以避免干扰。 |
| `max_input_tokens`（自动优化） | Prompt 自动优化功能对原始 Prompt 的长度限制 | 输入 Prompt 建议 ≤ 2048 tokens；过长将导致优化失败，可先做关键信息摘要再提交。 |
| `recall_count`（RAG 场景） | RAG 表格库召回片段数（原样例库对应参数） | 默认 5，最大 10；业务复杂度高时可设为 8–10，但需同步加强 Prompt 中的“依据优先级”指令（如“严格按第一条知识作答”）。 |

## 面向开发者，简洁实用

- ✅ **起步推荐路径**：控制台创建模板 → 使用「优化 Prompt」按钮一键增强（含角色设定、指令强化、安全边界）→ 用变量注入适配业务字段 → 在智能体或工作流中绑定调用 → 用 `agenteval` 发起多轮评测验证效果。  
- ✅ **避坑提醒**：  
  - 不再新建 Prompt 样例库，全部迁移至 RAG 表格库；  
  - 图片/视频生成务必区分 `prompt` 与 `negative_prompt`，负向提示建议包含 `low quality, text, watermark, blurry` 等通用抑制项；  
  - 自动优化后的 Prompt 需人工复核逻辑完整性，尤其检查变量名是否被误替换、安全约束是否被弱化。  
- ✅ **调试技巧**：在 `agenteval` 调试窗口中，对同一问题连续测试不同 Prompt 版本，重点关注“格式合规性”“事实准确性”“指令遵循率”三类指标；发现偏差后，直接填写具体反馈（如“遗漏了‘仅输出中文’要求”）触发精准优化。  
- ✅ **生产就绪检查项**：  
  - 所有变量均有默认值或必填校验；  
  - 模板中不含硬编码敏感信息（如 API Key、内部 URL）；  
  - RAG 场景下 Prompt 明确指定知识来源与响应约束（如“若知识中未提及，请回答‘暂无相关信息’”）；  
  - 已通过 `agenteval` 至少 20 条样本评测，核心指标达标率 ≥ 95%。
