# 评测

评测是百炼平台提供的一类质量验证能力，通过对应用输出或模型回答进行多维度量化打分，帮助开发者在模型选型、调优验证、应用上线等环节中以数据驱动决策。按评测对象不同，平台将其分为**应用评测**与**模型评测**两条主线，二者共用"评测集 + 评测任务 + 评估器"的基本范式，但在评测集类型、评估器机制和结果口径上存在差异。

## 在百炼不同场景中的使用

### 应用评测

面向智能体应用与工作流应用，评估其端到端输出质量。覆盖评测集管理、评测任务编排、自动评估器评分、人工标签标注与评测报告分析全流程，支持自动评测与手动评测两种范式。

- **自动评测**：基于应用关联的知识库，由大模型自动生成评测集并按 1-5 分评分，产出评分、BadCase 分析、归因分析和调优建议。仅面向已发布且配置知识库的智能体应用，要求开通"应用观测"，单次最多 8 个应用横向评测。
- **手动评测**：人工构建评测集并对应用输出逐条打标（较差/一般/较好，或 1-5 分），适合有领域专家介入的端到端验证。

当前控制台提供"新版应用评测"与"旧版"两套界面，在评测任务、评估器、标签管理页面左上角单击"返回旧版"可切换。新版评测集支持智能体、工作流、自定义三种类型，按所选应用出入参自动生成数据模板；旧版仅区分对话分析（`.xls`/`.xlsx`）与知识问答（`.jsonl`）两类。使用前请先确认所处版本。

### 模型评测

面向大语言模型本身，基于数据集对模型进行多维度量化评估，最终生成综合得分、通过率与分数分布等评测报告。适用于模型选型、调优验证、能力量化与持续监控。

- **自定义评测**：业务场景评测，需先创建评测维度并准备 Excel 评测数据。提供 5 种评测维度类型——大模型评估-数值型（AI 裁判 1-5 分，推荐度最高）、规则评估-文本相似度、大模型评估-分类型（Pass/Fail）、规则评估-字符串匹配、人工评估-分类型。一个评测任务可组合多个维度。
- **基线评测**：使用系统预置的标准榜单数据集（C-Eval、MMLU、ARC、GSM8K、HellaSwag、BBH）验证模型通用能力，无需自备数据，**仅支持调优后的模型**，不支持预置模型。

### 与模型调优、模型监控的关系

评测贯穿模型生命周期：调优前以评测结果作为选型与基线依据；调优后用相同评测集复测以验证提升幅度；上线后由模型监控接管运行态指标。模型监控提供分钟级运行指标、调用日志与主动告警，与评测的离线质量评估互补——前者保障稳定性，后者保障效果。

## 关键参数与配置

### 评测集

- **数据格式**：应用评测旧版支持 `.xls`/`.xlsx`（对话分析）与 `.jsonl`（知识问答）；新版手动上传支持 `.xls`/`.xlsx`，单文件不超过 20MB，单次最多 10 个文件，存储位置固定为平台存储，创建后类型不可修改。模型评测使用 Excel 格式，分评测数据集（含 Prompt、Completion，系统实时推理生成 Output）与推理结果集（已含 Output，直接评分）两种来源。
- **数据量建议**：小规模验证 50-100 条，正式评测 200-500 条，全面评估 500+ 条。
- **自动生成**仅支持知识问答类型，且仅支持 `qwen-max` 和 `qwen-plus` 模型；手动上传需先下载模板填写，再上传并**发布**后才能用于评测任务，草稿状态不可用。修改通过"增量导入"完成，每次发布生成新版本，评测任务可选特定版本。

### 评测任务

应用评测任务串联评测集、被测应用、评估器与标签，关键限制：

- 任务名称最多 50 字符，任务描述最多 200 字符。
- 关联应用支持三种方式：不关联应用（纯人工标注）、工作流、智能体。
- 每个评测任务最多添加 10 个评估器，建议组合 3-5 个覆盖不同维度（如 LLM + Code 组合），所有变量必须完成参数映射后才能保存。
- 评测任务发起后配置不可修改，如需调整请创建新任务；任务调用大模型产生的 Token 费用正常计费。

模型评测任务状态包括：待执行（高峰排队）、进行中、评测完成、评测失败、评测终止（人工手动终止）。

### 评估器

应用评测的评估器定义"如何评分"，可被多个评测任务复用。预置模板按通用质量、智能体、文本匹配、文本相似度、格式校验五类组织；自定义评估器分三种：

- **LLM 评估器**：用大模型评分，适合相关性、有害性、幻觉检测等语义场景。配置项含模型选择、Prompt、评分范围、通过阈值，建议使用 32B 以上参数量模型并试运行验证。
- **Code 评估器**：用 Python 3.10 函数实现评分逻辑，适合格式校验、数值计算、精确匹配。函数签名须包含所有入参，必须返回数值类型评分。
- **基于评测任务创建**：从已完成标注的历史评测任务中自动抽象出 LLM 评估器，不支持试运行。

模型评测的"评分器 Prompt"仅适用于大模型评估类型（数值型、分类型），裁判模型接收三个核心变量：`${prompt}`（原始输入，必填）、`${output}`（模型输出，必填）、`${completion}`（参考答案，有标准答案时使用）。System Prompt 作用于被评测模型（学生），评分器 Prompt 作用于裁判模型（阅卷老师），二者费用归属不同。

### 评分规则

评分范围决定打分尺度：精细评估用 0-100，快速分类用 0-1 或 1-5；通过阈值决定 Pass/Fail。模型评测系统预置三种评分器模板——综合评测（默认，相关性/文化敏感性/信息丰富性/清晰性/用户参与度 5 维度）、语义相似度、自定义评测。

## 结果查看

任务完成后进入详情页：

- **数据明细**：查看每条数据的 Prompt、Completion、Output 及对应评测维度的评分。应用评测支持普通模式与快速标注两种标注模式。
- **指标统计**：查看综合得分（评测维度的平均分）、通过率（达到阈值的样本占比）、评测集总量、已完成量、未完成量。基线评测还提供分学科得分明细、能力雷达图与业界标准模型的行业对比。

## 限制与注意事项

- **模型支持范围**：模型评测自定义评测支持千问系列（QwQ/Max/Plus/Turbo/Coder/Math）、千问开源版（Qwen3/Qwen2.5/Qwen2/Qwen1.5）、通义法睿及部分第三方文本生成模型；列表可能随时变化，以创建任务页面显示为准。
- **基线评测仅支持调优模型**，需先完成模型调优与部署；不支持预置模型。
- **数据集类型限制**：模型评测仅支持评测集，不支持训练集。
- **版本差异**：应用评测新版与旧版在评测集类型、关联应用范围、评估器机制上有显著差异，使用前请先确认所处版本。
