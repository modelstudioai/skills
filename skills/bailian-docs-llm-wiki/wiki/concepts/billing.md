# 计费

计费是百炼平台针对模型调用、模型训练、模型部署等服务按用量或时长收取费用的机制，开发者可根据业务规模选择按量付费、预付费或订阅制等多种方式灵活控制成本。

## 计费模式

百炼平台提供以下主要计费模式：

- **按量付费**：默认模式，按输入/输出 [Token](token.md) 数计费，部分模型实行阶梯计费规则。采用"预占+月结"模式，分钟级出账。
- **模型训练计费**：按训练 [Token](token.md) 计费，费用 = [Token](token.md) 总数 x 循环次数 x 训练单价。支持文本生成、图像生成、视频生成等模型类型。
- **模型部署计费**：支持预置吞吐（PTU，按 TPM 计费）、模型单元（按使用时长 x 单元数量）和 Token 用量（不使用不计费）三种方式。
- **订阅制**：Token Plan 团队版（198-1398 元/坐席/月）和 Coding Plan（200 元/月），以固定月费提供多模型访问能力。

## 计量单位

不同模型类型的计量维度不同：

| 模型类型 | 计量单位 |
| --- | --- |
| 大语言模型（文本生成/深度思考/视觉理解） | Token |
| 图像生成模型 | 张 |
| 视频生成模型 | 秒 |
| 语音模型 | 秒、字符或 Token |
| 向量模型 | Token |

## 成本优化方案

百炼提供多层次的成本优化工具，抵扣优先级为：免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费。

- **新人免费额度**：首次开通自动发放，有效期 90 天，仅抵扣实时推理费用。
- **AI 通用型节省计划**：承诺每月消费金额换取阶梯折扣（最高 5.3 折），可跨模型使用。
- **专项节省计划**：针对大语言模型、语音模型、向量模型分别提供不同档位的预付费折扣。
- **资源包**：预购固定 Token 数量抵扣特定模型推理用量。
- **TPM 预留**：按 kTPM 预付费获得专属容量保障，超额自动降级为按量计费。

## 账单与费用管理

- **费用概览**：在控制台查看当月总消费、趋势分析、按模型/[API Key](api-key.md) 维度筛选。
- **账单详情**：支持按 [API Key](api-key.md) ID、[业务空间](workspace.md) ID、模型名称、调用渠道等维度查看明细。
- **分账管理**：给[业务空间](workspace.md)绑定标签可按部门或项目归集费用。
- **免费额度用完即停**：开启后额度耗尽自动停止服务，避免意外费用。

## 欠费与停止计费

- 账户可用额度 < 0 视为欠费，除已有节省计划/资源包额度的服务外，其余服务暂停。
- 停止模型推理：停止 API 调用或删除 [API Key](api-key.md)。
- 停止模型部署：下线已部署模型或退订包月预付费。
- 部署后付费欠费资源保留 24 小时，超时底层资源被删除。

## 常见问题

| 问题 | 解答 |
| --- | --- |
| 免费额度用完会怎样？ | 未认证用户停止服务需认证充值；已认证用户如开启"用完即停"则停止，否则自动按量扣费 |
| 按量付费是实时扣款吗？ | 不是，采用"预占+月结"模式，月账期结束后生成最终账单 |
| 部署成功后未调用是否计费？ | 是，部署成功即开始按时长计费 |
| 模型压缩是否收费？ | 压缩功能限时免费，压缩产出模型部署后按标准规格计费 |
