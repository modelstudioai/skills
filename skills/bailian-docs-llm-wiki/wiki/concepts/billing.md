# 计费

计费是阿里云百炼平台对模型推理、训练部署、订阅套餐等各项服务进行计量与结算的机制，贯穿开通、调用、结算与成本控制全流程。开发者需在选型与接入阶段即理解计费维度，以准确预估并控制调用成本。

## 计费构成

百炼平台的费用由若干相互独立结算的部分组成：

- **模型实时推理（调用）费用**：按输入/输出 Token 计费，单价随模型、地域、部署范围、Token 区间、思考模式不同而变化。
- **Batch 调用费用**：异步批量推理单独计价，通常低于实时调用。
- **模型训练与部署费用**：调优（微调）与独占部署按算力资源或运行时长计费，与推理调用费用独立。
- **订阅套餐费用**：Token Plan 团队版、Coding Plan 等按坐席或月费订阅，按 Token 抵扣 Credits 或按调用次数计量。
- **资源包 / 节省计划**：可预先购买以抵扣或折扣上述费用。

## 主要计费方式

不同场景对应不同计费方式，选型时需匹配业务特征：

| 计费方式 | 计费依据 | 适用场景 | 关键约束 |
| --- | --- | --- | --- |
| 按量计费 | 输入/输出 Token 数 × 单价 | 通用、用量波动大 | 共享公共池，无容量保障，超额受公共限流影响 |
| 预置吞吐（PTU） | 使用时长 × 预置吞吐 | 高负载生产、稳定吞吐、低延迟 | 超出额度自动转按量；预付费无法提前退费 |
| 模型单元 | 使用时长 × 模型单元数量 × 单价 | 资源独占、长时任务 | 后付费先到先得；首月内退订按 1.2 倍计费 |
| Token 用量（部署） | 输入/输出 Token × 单价 | 调优后验证、对并发延迟要求不高 | 仅支持部分 LoRA 调优模型；一个月不用自动释放 |
| TPM 预留 | kTPM 预付费 | 流量可预估、不能接受限流 | 专属容量刚性兑付，超额降级按量不中断 |
| 资源包/节省计划 | 预付费额度或折扣 | 长期稳定用量 | 非专属容量，超出转按量 |

> 部署类服务的计费方式在服务创建后无法更改，如需切换必须下线已部署模型后重新部署。

## 关键计费维度

### 模型实时推理

- **模型 ID**：不同模型版本独立计价，带日期后缀的版本（如 `qwen3.7-plus-2026-05-26`）能力等同基础版本，但需用精确 ID 调用并按对应单价计费。
- **服务部署范围**：分"全球"与"国际/新加坡"等，不同部署范围单价不同。
- **Token 区间**：按单次请求输入 Token 范围分档计价（如 `0<Token≤128K`、`128K<Token≤256K`、`256K<Token≤1M`），长上下文请求单价更高。
- **思考模式**：思考模式（思维链+回答）输出单价显著高于非思考模式，可达数倍。
- **上下文缓存折扣**：启用上下文缓存可享受输入单价折扣，命中缓存部分按折扣系数折算。

### 训练与部署

调优产生的模型在调用时仍按对应模型 ID 的推理单价计费；独占部署模型按部署实例规格与运行时长计费。PTU 部署支持长输入阶梯系数与前缀缓存折扣，各模型系数不同（如 `glm-5.1` 在 [32K, 200K] 区间输入系数 1.33、输出系数 1.17，缓存命中按 20% 折算）。API 响应通过 `service_tier`（`ptu-standard`/`default`）、`provisioned_tokens`、`cached_tokens` 字段标识计费方式与额度消耗。

### 订阅套餐

Token Plan 团队版按坐席订阅，每席位绑定一个 API Key，按 Token 消耗抵扣 Credits，抵扣顺序为坐席月度额度 → 共享用量包 → 用尽暂停。Coding Plan 按固定月费订阅，按模型调用次数计量，设有每 5 小时/每周/每月限额。两类套餐的 API Key 与 Base URL 互不相通，与按量计费亦不可混用，否则会导致额度不抵扣或额外扣费。

## 新人免费额度

首次开通百炼时平台自动发放各模型的新人专属免费额度，规则要点：

- **地域与部署范围**：仅华北2（北京）地域且部署范围为"中国内地"的模型享有免费额度。
- **有效期**：30～90 天，自 2025 年 9 月 8 日 11 点起新开通用户统一为 90 天。
- **抵扣范围**：仅抵扣模型实时推理（调用）费用，不支持 Batch 调用、模型调优、模型部署及自定义模型。
- **账号共享**：阿里云主账号与 RAM 子账号共享免费额度。

可在控制台「模型用量」→「免费额度」页签查看余量与过期时间，并提供"免费额度用完即停"开关（开启后额度用尽返回 `403 AllocationQuota.FreeTierOnly`，避免产生额外费用）。

## 成本管理

- **模型用量**：按业务空间汇总 Token/张/秒用量，数据延迟约 1 小时，不支持查看 30 天以前数据，不支持按阿里云账号维度统计（账号级数据需到费用与成本页面导出账单）。
- **费用概览**：提供当前账期总消费、订阅费用、账单费用卡片，及按月/天、产品分类/API Key ID/模型筛选的账单趋势图表。
- **模型监控**：提供分钟级运行指标、调用日志、Token 追踪与主动告警；普通监控小时级、高级监控分钟级。
- **Token 追踪**：记录每次调用的 Token 消耗（需开通推理日志，仅北京地域部分模型），可设置消耗阈值告警。

## 注意事项

- 免费额度仅限实时推理，Batch、调优、部署及自定义模型需单独预算。
- 长上下文请求（>128K、>256K）单价大幅上升，应在业务侧控制上下文长度。
- 思考模式成本可达非思考模式数倍，成本敏感场景应按需关闭思维链。
- TPM 预留缩容与退订按 1.5 倍系数结算退款；到期后 2 小时内可续费，14 小时后实例删除不可恢复。
- TPM 预留部署成功即开始计费，预留容量内调用不额外收费，超出部分自动降级按量计费。
- Coding Plan 不支持退款，订阅前需确认使用范围与数据授权条款。
