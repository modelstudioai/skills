# 图像、视频与 3D 生成对比

百炼平台提供了图像生成、视频生成和 3D 模型生成三大内容生成能力。三者均面向开发者提供 API 接入，但在输入输出格式、支持模型、调用方式、计费粒度和典型应用场景上存在显著差异。本文从技术选型角度对三者进行系统对比，帮助开发者根据业务需求快速选择合适的生成能力。

## 关键维度对比

| 维度 | 图像生成 | 视频生成 | 3D 生成 |
|------|---------|---------|---------|
| **输入格式** | 文本提示词、参考图片 | 文本提示词、首帧/尾帧图片、参考图/视频、音频 | 文本提示词、单张图片、多视角图片（4 张） |
| **输出格式** | PNG 图片（单张或多张） | MP4 视频（含音频轨） | GLB 格式 3D 模型（含 PBR 材质） |
| **调用模式** | 同步为主（新版模型），旧版支持异步 | 仅异步（耗时 1-5 分钟） | 仅异步（需轮询，建议间隔 15 秒） |
| **API 端点** | `/api/v1/services/aigc/...`（多个子路径） | `/api/v1/services/aigc/video-generation/video-synthesis` | `/api/v1/services/aigc/video-generation/3d-generation` |
| **主要模型系列** | Qwen-Image、Wan(万相)、Z-Image、Kling(可灵) | Wan(万相)、HappyHorse、PixVerse、Kling、Vidu | Tripo-H3.1、Tripo-P1.0 |
| **模型数量** | 20+ 款（含编辑、电商场景模型） | 15+ 款（含数字人、人像驱动模型） | 2 款 |
| **输出分辨率/规格** | 512x512 至 4K，可自由指定宽高 | 480P / 540P / 720P / 1080P 等 | 最高 200 万面（H3.1），2 万面（P1.0） |
| **批量生成** | 单次可生成 1-6 张 | 单次生成 1 条视频 | 单次生成 1 个模型 |
| **编辑能力** | 丰富：局部重绘、扩图、擦除、风格迁移、超分 | 支持视频编辑、风格重绘、口型替换 | 不支持编辑 |
| **地域支持** | 北京、新加坡（部分模型仅北京） | 北京为主，HappyHorse 支持多地域 | 仅北京 |
| **开通要求** | 部分模型需单独开通（如可灵） | 部分模型需单独开通（如 PixVerse、Kling、Vidu） | 需在控制台搜索"Tripo"开通 |
| **异步请求头** | 旧版模型需要 `X-DashScope-Async: enable` | 必须设置 `X-DashScope-Async: enable` | 必须设置 `X-DashScope-Async: enable` |

## 功能覆盖对比

| 能力 | 图像生成 | 视频生成 | 3D 生成 |
|------|:-------:|:-------:|:-------:|
| 文本生成 | 支持 | 支持 | 支持 |
| 图片驱动生成 | 支持 | 支持（首帧/首尾帧） | 支持（单图/多图） |
| 参考风格生成 | 支持 | 支持（参考生视频） | 不支持 |
| 编辑/重绘 | 支持 | 支持 | 不支持 |
| 多镜头/分镜 | 支持组图 | 支持多镜头叙事 | 不适用 |
| 数字人/人像驱动 | 人像风格重绘 | 丰富（数字人、口型、舞蹈） | 不支持 |
| 电商场景 | 丰富（虚拟模特、试衣、海报） | 不支持 | 不支持 |
| 文字渲染 | 支持（Qwen-Image 擅长） | 不支持 | 不支持 |
| PBR 材质输出 | 不适用 | 不适用 | 支持 |

## 适用场景建议

### 图像生成

适合需要快速产出静态视觉素材的场景，包括但不限于：

- **营销设计**：电商商品主图、广告海报、创意文字
- **内容创作**：文章配图、社交媒体素材、艺术风格创作
- **电商运营**：虚拟模特换装、商品背景生成、AI 试衣
- **图像后处理**：局部重绘、画面扩展、超分辨率、去水印

图像生成响应速度最快（同步调用秒级返回），模型选择最丰富，编辑能力最强，是三者中最成熟的能力。

### 视频生成

适合需要动态视觉内容的场景：

- **短视频制作**：营销短片、产品展示视频、创意广告
- **数字人应用**：AI 主播、虚拟客服、教学视频
- **内容增强**：图片动态化、视频风格转换、口型同步
- **影视预览**：分镜预览、概念动画、镜头设计

视频生成耗时较长（分钟级），但功能覆盖全面，尤其在数字人和人像驱动方面具有独特优势。

### 3D 生成

适合需要三维模型资产的场景：

- **游戏开发**：快速原型建模、NPC/道具资产生成
- **电商展示**：商品 3D 展示、AR 预览
- **工业设计**：概念验证、外观方案快速迭代
- **教育培训**：三维教学模型、虚拟展品

3D 生成当前模型选择较少，不支持编辑操作，但输出的 GLB 格式可直接用于主流 3D 引擎和 Web 展示。

## 技术选型参考

1. **如果只需静态图片**：优先选择图像生成。同步调用延迟低，模型丰富，Qwen-Image 适合含文字的场景，万相适合高质量艺术创作，Z-Image 适合快速出图。
2. **如果需要动态内容**：选择视频生成。万相 2.7 系列功能最全面，HappyHorse 多地域部署适合全球化业务，可灵支持精细的多镜头控制。
3. **如果需要三维资产**：选择 3D 生成。Tripo-H3.1 适合高精度需求（最高 200 万面），Tripo-P1.0 适合快速生成轻量模型。
4. **如果需要数字人/虚拟人**：选择视频生成中的数字人模型（wan2.2-s2v），可从单张图片加音频生成说话视频。
5. **如果需要电商场景**：选择图像生成中的电商模型（虚拟模特、AI 试衣、背景生成等）。

三种生成能力也可以**组合使用**：例如先用图像生成制作关键帧，再用视频生成的图生视频功能将其动态化；或者先用 3D 生成建模，再渲染为 2D 图片用于后续图像编辑。
