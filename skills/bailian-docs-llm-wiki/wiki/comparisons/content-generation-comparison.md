# 图像生成 vs 视频生成 vs 3D生成 API 对比

百炼平台提供图像生成、视频生成和 3D 模型生成三大内容创作 API 能力。三者均面向 AIGC 场景，但在输入输出格式、调用方式、模型生态和适用场景上存在显著差异。本文从开发者技术选型角度，对三类 API 进行系统对比，帮助快速确定最适合业务需求的方案。

## 基础能力对比

| 维度 | 图像生成 | 视频生成 | 3D生成 |
|------|---------|---------|--------|
| 核心输出 | PNG 图片 | MP4 视频 | GLB 格式 3D 模型 |
| 输入方式 | 文本、参考图、涂鸦、蒙版等 | 文本、图片（首帧/尾帧）、参考视频、音频 | 文本、单图、多图（4视角） |
| 调用模式 | 同步为主（千问/万相2.5+），部分异步 | 全部异步（创建任务 + 轮询） | 全部异步（创建任务 + 轮询） |
| 模型系列数量 | 5+ 系列（千问、万相、可灵、Z-Image 等） | 5+ 系列（万相、HappyHorse、PixVerse、可灵、Vidu 等） | 1 系列（Tripo） |
| 生成耗时 | 秒级（同步接口） | 数十秒至数分钟 | 数十秒至数分钟 |
| 批量输出 | 单次最多 9 张 | 单次 1 条视频 | 单次 1 个模型 |

## 模型与能力矩阵

| 维度 | 图像生成 | 视频生成 | 3D生成 |
|------|---------|---------|--------|
| 推荐模型 | 千问 qwen-image-2.0-pro、万相 wan2.7-image-pro | 万相 wan2.7-t2v/i2v | Tripo/Tripo-H3.1、Tripo/Tripo-P1.0 |
| 文本生成 | 支持（文生图） | 支持（文生视频） | 支持（文生 3D） |
| 图片驱动 | 支持（图像编辑、参考图生图） | 支持（图生视频、首帧/尾帧驱动） | 支持（单图/多图生 3D） |
| 编辑能力 | 局部重绘、风格迁移、扩图、超分、去水印等 | 视频编辑、风格重绘、口型替换 | 不支持 |
| 人像专项 | 人像风格重绘、虚拟模特、AI 试衣 | 数字人、舞动人像、表情包、视频换人 | 不支持 |
| 输出分辨率 | 最高 4K（wan2.7-image-pro） | 最高 1080P | 最高 200 万面（Tripo-H3.1） |
| 第三方模型 | 可灵 | 可灵、PixVerse、Vidu | Tripo |

## API 调用方式对比

| 维度 | 图像生成 | 视频生成 | 3D生成 |
|------|---------|---------|--------|
| 同步接口 | 千问系列、万相 2.5/2.6/2.7 支持 | 不支持 | 不支持 |
| 异步接口 | 万相旧版、创意工具类 | 全部模型 | 全部模型 |
| 异步请求头 | `X-DashScope-Async: enable` | `X-DashScope-Async: enable`（必需） | `X-DashScope-Async: enable`（必需） |
| 任务提交端点 | 因模型而异 | `/api/v1/services/aigc/video-generation/video-synthesis` | `/api/v1/services/aigc/video-generation/3d-generation` |
| 结果查询 | `GET /api/v1/tasks/{task_id}` | `GET /api/v1/tasks/{task_id}` | `GET /api/v1/tasks/{task_id}` |
| task_id 有效期 | 24 小时 | 24 小时 | 24 小时 |
| SDK 支持 | HTTP + [DashScope SDK](../concepts/dashscope-sdk.md) | HTTP + [DashScope SDK](../concepts/dashscope-sdk.md) | HTTP |

## 地域与开通要求

| 维度 | 图像生成 | 视频生成 | 3D生成 |
|------|---------|---------|--------|
| 支持地域 | 华北2（北京）为主，部分模型多地域 | 华北2（北京）、新加坡、美国、德国 | 仅华北2（北京） |
| 第三方模型开通 | 可灵需控制台开通 | PixVerse、可灵、Vidu 需控制台开通 | Tripo 需控制台开通 |
| 跨地域限制 | 部分模型仅限特定地域 | 模型、Endpoint、API Key 必须同地域 | 必须使用北京地域 API Key |

## 计费方式对比

| 维度 | 图像生成 | 视频生成 | 3D生成 |
|------|---------|---------|--------|
| 计费单位 | 按张计费 | 按秒/按任务计费 | 按任务计费 |
| 计费范围 | 0.04 元/张起（部分模型免费体验） | 因模型和分辨率而异 | 因模型而异 |
| 免费体验 | 部分创意工具模型提供免费额度 | 部分模型提供免费额度 | 需开通后使用 |

## 适用场景建议

### 选择图像生成 API

- 需要快速生成营销素材、电商商品图、海报等静态视觉内容
- 需要对已有图片进行编辑（局部重绘、风格迁移、背景替换、扩图）
- 需要图像中的文字翻译并保留排版
- 需要同步接口实现低延迟的实时交互体验
- 电商场景下的虚拟模特、AI 试衣、商品背景生成等专项需求

### 选择视频生成 API

- 需要从文本或图片自动生成短视频内容（广告、宣传片、社交媒体素材）
- 需要数字人播报、舞蹈视频、唱演视频等人像动画能力
- 需要视频编辑功能（风格重绘、口型替换、视频续写）
- 需要多镜头叙事（万相 2.7 支持最长 15 秒多镜头视频）
- 对生成耗时容忍度较高，可接受异步等待

### 选择 3D 生成 API

- 需要将文本描述或图片快速转化为 3D 模型（GLB 格式）
- 游戏、AR/VR、工业设计等需要 3D 资产的场景
- 需要 PBR 材质的高质量 3D 模型用于渲染管线
- 模型生态要求较简单，Tripo 系列即可满足需求

## 技术选型决策要点

1. **实时性要求**：如果需要毫秒级响应，仅图像生成的同步接口能满足；视频和 3D 生成均为异步模式，需设计轮询或回调机制。
2. **模型多样性**：图像生成和视频生成拥有丰富的模型生态（各 5+ 系列），3D 生成目前仅有 Tripo 一个系列，选择空间较小。
3. **地域部署**：如需海外部署，视频生成支持最多地域（4 个）；3D 生成仅限北京地域，国际化场景受限。
4. **编辑能力**：图像和视频均支持丰富的编辑操作，3D 生成目前不支持后编辑，生成后需借助外部工具修改。
5. **集成复杂度**：图像生成（同步模式）集成最简单，一次请求即返回结果；视频和 3D 生成需实现异步任务管理逻辑。
