# 知识库与记忆库对比

百炼平台提供了两种面向不同场景的数据增强机制：**知识库**（Knowledge Base）和**记忆库**（Memory Library）。知识库基于 RAG 技术为大模型补充私有文档与结构化数据，解决的是"模型不知道企业内部信息"的问题；记忆库则通过长期记忆 API 自动提取、持久化并召回对话中的关键信息，解决的是"模型在跨会话场景下丢失上下文"的问题。二者定位互补，理解其核心差异有助于开发者在技术选型时做出合理决策。

## 关键维度对比

| 维度 | 知识库（Knowledge Base） | 记忆库（Memory Library） |
| --- | --- | --- |
| **核心定位** | 为大模型补充私有数据与最新信息，提升特定领域问答准确性 | 解决跨会话上下文丢失问题，使智能体持续理解用户偏好与历史 |
| **底层技术** | RAG（[检索增强生成](../concepts/rag.md)）：向量化 + 关键词混合检索 + Rerank + 生成 | 长期记忆：从对话自动提取关键信息 → 持久化存储 → 语义检索召回 |
| **数据来源** | 企业文档、Excel/CSV、图片、音视频等非结构化/结构化文件，需主动上传 | 对话内容自动提取，或通过 `custom_content` 直接写入 |
| **存储内容** | 文档切片（向量索引 + 原文） | 记忆片段（自动提炼的关键事件/信息）+ 用户画像（结构化属性） |
| **数据粒度** | 文档级 / 切片级（单切片上限 6,000 [Token](../concepts/token.md)） | 记忆条目级（单条关键信息或画像属性） |
| **支持的数据类型** | 文档搜索、数据查询（NL2SQL）、图片问答、音视频搜索 | 文本对话内容、自定义文本内容 |
| **隔离维度** | 按知识库实例隔离，多知识库可按权重组合（最多绑定 15 个） | 按 `user_id` 隔离，同一 user_id 共享记忆空间 |
| **API 端点** | `bailian.cn-beijing.aliyuncs.com`（阿里云百炼 OpenAPI） | `dashscope.aliyuncs.com/api/v2/apps/memory/*`（DashScope） |
| **认证方式** | 阿里云 AccessKey（AK/SK） | DashScope [API Key](../concepts/api-key.md)（`sk-` 开头） |
| **SDK** | `alibabacloud_bailian20231229`（Python） | `agentscope-runtime`（Python） |
| **接入方式** | 控制台配置 + OpenAPI | API 直连 / OpenClaw 记忆插件（零侵入） |
| **向量模型** | `text-embedding-v4`/`v3`（512 维）、`multimodal-embedding-v1`（1024 维）、`qwen3-vl-embedding` | 由服务端自动处理，开发者无需选择 |
| **可用地域** | 仅华北2（北京） | 通过 DashScope 全局接入 |
| **规格与 QPS** | 标准版 1 QPS / 旗舰版 50–10,000 QPS（1–200 RCU） | 无公开 QPS 档位说明 |
| **计费方式** | 标准版 0.03 元/小时；旗舰版 0.2 元/RCU/小时；另含 SLS 日志存储费用 | 按长期记忆 API 调用计费 |
| **数据有效期** | 持久存储，手动删除 | 可配置 7/30/180 天或永不过期（默认 180 天） |
| **典型延迟** | 检索 + 生成链路，与文档量和模型相关 | 记忆写入为异步提取，检索为在线语义匹配 |

## 适用场景

### 选择知识库的场景

- **企业知识问答**：需要基于产品手册、内部文档、FAQ 等进行精准问答。
- **结构化数据查询**：通过 NL2SQL 对 Excel/CSV 数据进行自然语言查询。
- **[多模态](../concepts/multimodal.md)检索**：需要对图片、音视频内容进行搜索和理解。
- **高并发生产环境**：需要可控的 QPS 配额和企业级 SLA 保障。
- **合规与审计**：需要完整的调用日志（SLS 投递）用于审计和问题排查。

### 选择记忆库的场景

- **个性化智能体**：需要记住用户偏好、习惯和历史交互，提供个性化服务。
- **跨会话连续性**：用户多次对话之间需要保持上下文连贯（如客服、健康管理、学习助手）。
- **用户画像积累**：需要从对话中逐步提取并维护结构化的用户属性信息。
- **快速集成**：通过 OpenClaw 插件实现零代码改造的跨会话记忆能力。

### 组合使用

知识库与记忆库可以同时接入同一个智能体应用：知识库提供领域知识的检索增强，记忆库提供用户级的个性化上下文。例如，一个医疗健康助手可以通过知识库检索药品说明书和诊疗指南，同时通过记忆库记住用户的过敏史和用药偏好，从而给出既专业又个性化的建议。

## 技术选型建议

| 决策因素 | 推荐方案 |
| --- | --- |
| 需要基于大量文档做精准问答 | 知识库 |
| 需要跨会话记住用户偏好和历史 | 记忆库 |
| 需要[多模态](../concepts/multimodal.md)内容检索（图片/音视频） | 知识库 |
| 需要零侵入为已有 Agent 添加记忆 | 记忆库（OpenClaw 插件） |
| 需要结构化数据的自然语言查询 | 知识库（数据查询类） |
| 需要同时具备领域知识和用户个性化 | 知识库 + 记忆库组合 |
| 数据来源为企业内部文件 | 知识库 |
| 数据来源为用户对话积累 | 记忆库 |
