# 知识库 vs 长期记忆库

百炼平台同时提供「知识库」和「长期记忆库」两种数据增强能力，分别面向不同的信息管理需求。知识库基于 RAG 技术为大模型补充静态私有数据和领域知识；长期记忆库则解决跨会话上下文丢失问题，通过自动提取和语义检索实现个性化的持续对话记忆。本文从技术架构、数据模型、接入方式等维度做系统对比，帮助开发者根据业务场景选择合适的方案。

## 关键维度对比

| 维度 | 知识库 | 长期记忆库 |
| --- | --- | --- |
| 核心定位 | 为大模型补充私有领域知识，提升特定问答准确性 | 跨会话记忆持久化，使智能体理解用户偏好与历史 |
| 数据来源 | 文档、Excel/CSV、图片、音视频等文件批量导入 | 对话自动提取记忆片段，或通过 custom_content 直写 |
| 数据粒度 | 文档切片（单切片上限 6000 [Token](../concepts/token.md)） | 记忆片段（单条关键信息）+ 用户画像（结构化属性） |
| 数据更新方式 | 重新上传文件 → 解析 → 重建索引 | 对话自动触发增量提取，支持去重与动态更新 |
| 检索机制 | 向量 + 关键词混合检索 → Rerank 排序 | 语义相似度检索，支持 rerank/query 重写/意图判别 |
| 支持的知识类型 | 文档搜索、数据查询（NL2SQL）、图片问答、音视频搜索 | 记忆片段（事件/偏好）、用户画像（结构化属性） |
| API 端点 | `bailian.cn-beijing.aliyuncs.com`（阿里云 SDK） | `dashscope.aliyuncs.com/api/v2/apps/memory/*`（REST） |
| 认证方式 | AccessKey ID + Secret（阿里云 RAM） | DashScope API Key（Bearer [Token](../concepts/token.md)） |
| 多用户隔离 | 通过[业务空间](../concepts/workspace.md)（Workspace）隔离 | 通过 user_id 参数隔离记忆空间 |
| 规格与 QPS | 标准版 1 QPS；旗舰版 50-10000 QPS（按 RCU） | 全接口 3000 QPM；add 120 QPM；search 300 QPM |
| 计费方式 | 标准版 0.03 元/小时；旗舰版 0.2 元/RCU/小时 + 存储费 | 按 DashScope 调用计费 |
| 数据有效期 | 持久存储，手动管理生命周期 | 可配置 7/30/180 天或永不过期（按记忆规则） |
| 接入复杂度 | 较高：需完成文件上传、解析、索引构建等多步流程 | 较低：一次 API 调用即可写入/检索记忆 |
| 零代码接入 | 控制台应用直接挂载知识库 | OpenClaw 插件自动捕获/召回，零侵入接入 |
| 地域限制 | 仅中国站华北2（北京） | 无特殊地域限制（DashScope 全局） |

## 适用场景

### 选择知识库的场景

- **企业知识问答**：需要基于产品手册、技术文档、规章制度等静态文档进行准确回答
- **结构化数据查询**：通过自然语言查询 Excel/CSV 数据（NL2SQL）
- **多模态内容检索**：涉及图片理解、音视频内容搜索的业务场景
- **高并发生产环境**：需要稳定 QPS 保障的线上服务（旗舰版支持万级 QPS）
- **数据量大、更新频率低**：文档库规模大但内容相对稳定

### 选择长期记忆库的场景

- **个性化对话助手**：需要记住用户偏好、习惯、历史约定的智能体
- **跨会话上下文保持**：客服、健康管理、教育辅导等需要连续对话体验的应用
- **用户画像构建**：需要从对话中自动提取并维护用户结构化属性
- **轻量快速接入**：不想管理文件上传和索引流程，仅需对话级记忆能力
- **多 Agent 共享记忆**：通过 OpenClaw 插件让多个 Agent 共享同一用户记忆空间

## 技术选型建议

1. **信息性质判断**：如果需要增强的是客观的、相对静态的领域知识，选知识库；如果需要记住的是主观的、动态演变的用户信息，选长期记忆库。

2. **组合使用**：两者并不互斥。典型模式是知识库提供领域专业知识，长期记忆库提供用户个性化上下文，共同注入 Prompt 实现既专业又个性化的回答。

3. **接入成本考量**：长期记忆库的 API 设计更简洁（写入 + 检索两步），适合快速原型验证；知识库需要完成文件上传、解析、索引等前置流程，但能处理大规模非结构化数据。

4. **数据治理需求**：知识库提供完整的日志监控（SLS）和检索诊断能力，适合对数据质量和调用审计有严格要求的生产环境；长期记忆库侧重自动化管理，通过记忆规则控制有效期和去重策略。
