# 多模态生成 API 对比：图像、视频与3D生成

本文档面向百炼平台开发者，系统对比当前支持的**图像生成、视频生成、3D生成**三类多模态生成 API 的核心能力、技术约束与工程实践差异。对比目的为帮助技术团队在实际项目中（如AIGC内容生产、数字人构建、游戏资产开发等）快速完成模型选型决策，规避常见集成陷阱，提升调用成功率与资源使用效率。

---

## 关键维度对比表

| 维度 | 图像生成（`/v1/images/generations`） | 视频生成（`/v1/services/aigc/video-generation`） | 3D生成（`/v1/models/tripo-1.0/invoke`） |
|------|-------------------------------------|-----------------------------------------------|----------------------------------------|
| **统一端点** | ✅ `/v1/images/generations`（所有图像模型共用） | ✅ `/v1/services/aigc/video-generation`（所有视频模型共用） | ❌ 模型专属端点：`/v1/models/tripo-1.0/invoke` |
| **输入格式** | 文本（`prompt`）、可选参考图（`image_url`，依模型支持）、控制信号（如 `control_type`） | 多模态组合：<br>• 文生视频：`input.text`<br>• 图生视频：`input.image_url`<br>• 人像驱动：`input.image_url` + `input.audio_url`/`input.text` | 二选一：<br>• 文本：`input.prompt`（≤200字符）<br>• 图像：`input.image_url`（公网PNG/JPEG，512×512～1024×1024） |
| **输出格式** | • `data[0].url`（临时直链，有效期 1 小时）<br>• 或 `data[0].b64_json`（Base64 编码 PNG） | • `output.video_url`（MP4 下载链接，有效期 24 小时）<br>• 无流式响应，需等待完整生成后返回 | • `output.model_url`（`.glb` 文件直链，有效期 24 小时）<br>• 输出为带基础材质的网格模型（非源文件如 `.fbx`/`.obj`） |
| **支持模型** | 千问（Qwen-VL）、万相（WanXiang）、Z-Image、可灵（Kling）、Vidu（`image_mode`）、创意工具（inpainting/outpainting/style transfer） | HappyHorse、万相、人像驱动、爱诗（PixVerse）、可灵（Kling）、Vidu、MiniMax | 仅 `tripo-1.0`（Tripo-3D v1.0） |
| **典型分辨率/规格** | • 尺寸：支持 `1024x1024`、`2048x2048`（可灵）、`512x512`（Z-Image 固定）<br>• 长宽比：`1:1`/`16:9`/`4:3`（可灵、万相等支持） | • 时长：严格 ≤ 4 秒（实测上限 4.08s，超限截断）<br>• 分辨率：默认 `1280×720`，部分模型支持 `1920×1080`（需查模型文档）<br>• 比例：`16:9`/`9:16`/`1:1`（依模型而定） | • 输出：`.glb`（二进制 GLTF 2.0）<br>• 网格顶点数：通常 5k–50k，无显式上限声明<br>• 不支持导出 UV/动画/骨骼绑定 |
| **计费方式** | • 按 token（[prompt](../guides/prompt.md)）+ 图片数量（`n`）+ 分辨率阶梯计费<br>• 免费额度覆盖千问、Z-Image；万相/可灵/Vidu 需单独开通付费包 | • 按视频秒数 × 分辨率系数 × 模型权重计费<br>• 免费额度仅覆盖 HappyHorse 与万相基础调用；其余模型需后付费或配额包 | • 按次计费（单次请求 = 1 次调用）<br>• 无免费额度，全部需项目配额或后付费 |
| **典型场景** | • 营销海报设计、电商主图生成<br>• 局部重绘（换装/换背景）、风格迁移（水墨→赛博朋克）<br>• 快速原型草图（Z-Image） | • 短视频广告素材（4s 内）<br>• 数字人口型同步动画（人像驱动）<br>• 动态运镜展示（爱诗/PixVerse） | • 游戏低多边形道具原型（茶壶、椅子、小动物）<br>• AR/VR 场景简易资产填充<br>• 工业设计概念可视化（非精密建模） |

## 各方案适用场景建议

### ✅ 图像生成 —— 推荐用于：
- **高可控性任务**：需 ControlNet 边缘/深度/姿态控制 → 优先选 **万相（WanXiang）**  
- **中文提示词友好 & 多模态理解强**：图文混合理解需求（如“根据这张产品图，生成同款风格的包装盒”）→ 选 **千问（Qwen-VL）**  
- **极致速度 & 批量轻量任务**：Banner 初稿、A/B 测试图生成 → 选 **Z-Image**（注意尺寸与功能限制）  
- **高分辨率 & 英文生态适配**：海外营销、DALL·E 用户迁移 → 选 **可灵（Kling）**  
- **局部编辑刚需**：修图、扩图、风格迁移 → 直接使用 **创意工具（Creative Tools）**，无需写 [prompt](../guides/prompt.md)  

> ⚠️ 注意：Vidu 的 `image_mode` 为视频模型的降级使用，稳定性与图像专用模型存在差距，**不建议用于生产环境图像交付**。

### ✅ 视频生成 —— 推荐用于：
- **通用文生视频（入门级）**：快速验证创意 → 选 **HappyHorse**（免费额度充足，容错率高）  
- **中文语义强 & 复杂动作描述**：如“快递员弯腰递包裹，背景楼宇渐变虚化” → 选 **Vidu**  
- **电影感运镜 & 高帧率动态**：产品展示、品牌短片 → 选 **爱诗（PixVerse）**  
- **数字人驱动**：需口型同步、表情自然 → 严格使用 **人像驱动模型**（须提供合规人脸授权）  
- **长时序一致性要求**：如角色连续行走 4 秒 → **可灵（Kling）** 与 **Vidu** 表现更优  

> ⚠️ 注意：所有视频模型均**不支持超过 4 秒生成**，且无关键帧编辑、分镜控制等高级能力；复杂叙事需拼接多段 4s 视频并人工调色/转场。

### ✅ 3D生成 —— 推荐用于：
- **文本/单图快速生成基础 3D 网格**：概念验证、AR 应用占位模型、教育演示 → **`tripo-1.0` 是唯一选择**  
- **对拓扑/可编辑性无硬性要求**：生成后需导入 Blender/Unity 进行手动优化（修复法线、重拓扑、添加材质）  
- **规避敏感内容风险**：确保输入 [prompt](../guides/prompt.md)/image 不含人脸、文字、商标等可识别元素  

> ⚠️ 注意：**不适用于**：精密机械建模、角色绑定动画、PBR 材质全流程生成、CAD 级精度需求。Tripo 当前本质是“3D 草图生成器”，非工业级建模替代方案。

## 技术选型参考指南（面向开发者）

| 你的需求 | 推荐方案 | 关键理由 | 风险提示 |
|----------|-----------|-----------|-----------|
| 需要 1 小时内生成 1000 张 1024×1024 电商图，预算有限 | Z-Image + 千问（混合调度） | Z-Image 延迟 <3s（P95），千问兜底处理复杂 prompt；两者共享免费额度 | Z-Image 不支持图生图，复杂构图需切回万相（成本上升） |
| 构建数字人直播系统，需实时驱动口型+微表情 | 人像驱动模型 + 可灵（Kling）辅助生成背景视频 | 人像驱动专为语音/文本驱动优化；Kling 提供高质量背景运镜 | 人像驱动强制要求人脸授权，且输入图需 ≥30% 人脸占比，需前置质检模块 |
| 为 Unity 游戏生成 50 个风格统一的低模道具（如科幻按钮、UI 面板） | `tripo-1.0` + 自研 GLB 后处理流水线 | Tripo 支持 `style: "cartoon"`，输出 `.glb` 可直接拖入 Unity；批量调用稳定 | 生成结果需自动检测破面/翻转法线，建议集成 [glTF Validator](https://github.com/KhronosGroup/glTF-Validator) 做 CI 校验 |
| 中文营销团队需每日产出 50+ 张公众号头图（16:9，水墨风） | 万相（WanXiang） + 控制图（边缘图） | 万相中文 prompt 优化最佳，支持 `control_type: "canny"` 精准控构图；输出尺寸灵活 | 若未显式传 `control_type`，即使传了 `image_url` 也会静默忽略——务必在 SDK 封装层做参数校验 |
| 客户要求“生成一段 10 秒产品介绍视频” | **拒绝该需求，拆解为 3 段 4s 视频 + 后期合成** | 平台所有视频模型硬性限制 ≤4 秒；强行提交 `duration: 10` 将被截断为 4.08s | 需在前端明确告知客户限制，并提供分镜脚本模板（每段 ≤4s）以保障质量一致性 |

---

> **最后提醒**：  
> - 所有 API 均依赖百炼平台统一鉴权（`Authorization: Bearer <api_key>`），但**配额隔离**：图像/视频/3D 的调用次数、并发数、额度包完全独立，不可跨域透支。  
> - 错误处理必须覆盖：`429 Too Many Requests`（实现指数退避）、`504 Gateway Timeout`（3D 生成最长 180s）、`503 Service Unavailable`（视频生成高峰降级）。  
> - 输出 URL 均有时效性（图像 1h / 视频&3D 24h），**务必在收到响应后立即下载并转存至自有存储**，避免链接过期导致业务中断。  
> - 模型能力持续迭代，建议订阅 [百炼模型更新日志](https://help.aliyun.com/zh/model-studio/release-notes)，关键升级（如 Vidu 新增 `image_mode` 正式支持）将影响选型结论。
