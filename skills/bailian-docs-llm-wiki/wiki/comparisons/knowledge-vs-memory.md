# 知识库与记忆库对比

百炼平台同时提供知识库（Knowledge Base）和记忆库（Memory Library）两种数据增强能力，二者均旨在为大模型补充上下文之外的信息，但设计目标截然不同：知识库基于 RAG 技术为模型注入组织级的私有文档与结构化数据，解决的是"模型不知道企业专有知识"的问题；记忆库基于长期记忆 API 为模型注入用户级的历史偏好与行为信息，解决的是"模型跨会话遗忘用户上下文"的问题。理解二者的差异与互补关系，是构建高质量智能体应用的关键。

## 关键维度对比

| 维度 | 知识库 | 记忆库 |
| --- | --- | --- |
| **核心定位** | 基于 RAG 为模型补充私有文档与最新信息，提升特定领域问答准确性 | 基于长期记忆 API 解决跨会话上下文丢失，持久化用户偏好与历史信息 |
| **数据来源** | 手动上传文档（PDF/Word/Markdown/Excel/CSV/图片/音视频等） | 从对话中自动提取，或通过 `custom_content` 直接写入 |
| **存储内容** | 文档切片（经向量化与索引） | 记忆片段（关键事件/信息）+ 用户画像（结构化属性） |
| **知识库/记忆库类型** | 文档搜索、数据查询、图片问答、音视频搜索（创建时选定不可更改） | 记忆片段 + 用户画像，二者可独立或组合使用 |
| **检索机制** | 向量 + 关键词混合检索 → Rerank 排序 → 加权返回 | 语义检索（基于 `messages` 内容匹配相关记忆） |
| **支持模型** | 千问全系列 + 第三方文本生成模型（DeepSeek、Llama、Yi 等） | 不绑定特定模型，检索结果注入 Prompt 后可配合任意模型使用 |
| **API 端点** | `bailian.cn-beijing.aliyuncs.com`（阿里云百炼 SDK） | `dashscope.aliyuncs.com/api/v2/apps/memory/*`（DashScope API） |
| **认证方式** | 阿里云 AccessKey（`ALIBABA_CLOUD_ACCESS_KEY_ID/SECRET`） | DashScope API Key（`DASHSCOPE_API_KEY`） |
| **接入方式** | 控制台 + 阿里云百炼 SDK（`alibabacloud_bailian20231229`） | API 直连 + OpenClaw 记忆插件（零侵入） |
| **用户隔离** | [业务空间](../concepts/workspace.md)（Workspace）级别 | `user_id` 级别，不同 `user_id` 完全隔离 |
| **数据有效期** | 持久存储，手动管理生命周期 | 可配置：7 / 30 / 180 天或永不过期（按记忆规则设定） |
| **计费方式** | 标准版 0.03 元/小时（1 QPS）；旗舰版 0.2 元/RCU/小时（50–10,000 QPS） | 随 DashScope API 调用计费 |
| **地域限制** | 仅中国站华北2（北京） | 无特殊地域限制 |
| **绑定上限** | 单服务最多绑定 15 个知识库 | 无明确上限，按 `user_id` 隔离 |

## 适用场景

### 适合使用知识库的场景

- **企业知识问答**：将产品手册、内部文档、政策法规等导入知识库，构建领域专属问答系统。
- **结构化数据查询**：通过 NL2SQL 对 Excel/CSV 数据执行自然语言查询。
- **[多模态](../concepts/multimodal.md)内容检索**：对图片、音视频内容做结构化索引与语义搜索。
- **客服与技术支持**：基于官方文档回答用户技术问题，降低幻觉率。

### 适合使用记忆库的场景

- **个性化助手**：记住用户的饮食偏好、作息习惯、工作风格等，提供个性化服务。
- **连续对话体验**：跨多次会话保持上下文连贯，无需用户重复描述背景。
- **用户画像构建**：自动提取年龄、职业、兴趣等结构化属性，实现精准推荐。
- **智能体长期陪伴**：教育辅导、健康管理等需要持续跟踪用户状态的场景。

### 二者组合使用

在实际生产中，知识库与记忆库往往互补：知识库提供"组织知道什么"（企业文档、产品信息），记忆库提供"对这个用户了解什么"（偏好、历史）。例如，一个客服智能体可以同时挂载知识库获取产品技术文档，并通过记忆库记住该用户的历史工单和沟通偏好，从而给出既准确又个性化的回答。

## 技术选型建议

| 选型考量 | 推荐方案 |
| --- | --- |
| 需要检索大量静态文档 | 知识库 |
| 需要跨会话记住用户信息 | 记忆库 |
| 需要[多模态](../concepts/multimodal.md)内容（图片/音视频）检索 | 知识库 |
| 需要零侵入接入已有 Agent | 记忆库（OpenClaw 插件） |
| 需要精细控制检索参数（TopK、Rerank、阈值等） | 知识库 |
| 需要自动提取和管理用户画像 | 记忆库 |
| 需要高并发（>1 QPS） | 知识库旗舰版（最高 10,000 QPS） |
| 需要同时具备领域知识 + 用户个性化 | 知识库 + 记忆库组合 |
