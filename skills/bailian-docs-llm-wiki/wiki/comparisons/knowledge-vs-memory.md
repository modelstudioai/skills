# 知识库与记忆库对比

知识库和记忆库是百炼平台提供的两种不同定位的数据增强方案。知识库基于 RAG 技术为大模型补充领域知识，侧重静态文档的检索与问答；记忆库则面向用户级长期记忆，自动从对话中提取关键信息并持久化，使智能体具备跨会话的个性化能力。本文从技术架构、数据模型、集成方式等维度对两者进行对比，帮助开发者做出合理的技术选型。

## 关键维度对比

| 维度 | 知识库 | 记忆库 |
|------|--------|--------|
| **核心定位** | 为大模型补充领域知识（RAG） | 为智能体提供跨会话长期记忆 |
| **数据来源** | 手动上传文档（PDF、Word、Markdown、Excel、音视频等） | 自动从对话中提取，或通过 API 写入自定义内容 |
| **数据粒度** | 文档切片（≤6000 Token/片） | 记忆片段（关键事件/信息）或用户画像（结构化属性） |
| **存储方式** | 内置向量库或 ADB-PG | 平台托管存储（账号级别资源） |
| **向量模型** | text-embedding-v4/v3（512 维）、multimodal-embedding-v1（1024 维）、qwen3-vl-embedding | 平台内置（不可配置） |
| **检索方式** | 语义相似度 + 可选 Rerank（qwen3-rerank） | 语义检索（排序模型 gte-rerank-v2） |
| **检索延迟** | 取决于配置与数据规模 | SearchMemory 200–500ms |
| **写入延迟** | 索引构建（批量，分钟到小时级） | AddMemory 500–1000ms（实时） |
| **数据更新** | 手动删除再上传，或 OSS/RDS 自动同步 | 自动更新（模型自动去重与合并） |
| **API 端点** | Retrieve 接口（知识库检索）；ApplyFileUploadLease + AddFile + SubmitIndexJob（文档管理） | AddMemory（写入）、SearchMemory（检索）、ListMemory、UpdateMemory、DeleteMemory 等 |
| **速率限制** | 按知识库版本配额 | AddMemory 120 次/分钟；SearchMemory 300 次/分钟；合计 3000 次/分钟 |
| **计费方式** | 标准版免费（内置存储）；旗舰版按 RCU 计费；Rerank 按调用量计费 | 目前限时免费 |
| **数据过期** | 永久保留（除非手动删除） | 可配置 7 天 / 30 天 / 180 天 / 永不过期 |
| **多租户** | 按工作空间隔离 | 按 user_id 隔离，支持多应用共享同一记忆库 |
| **集成方式** | 智能体应用挂载、工作流节点、SDK 调用 | API 直接调用、插件集成（如 OpenClaw 生命周期钩子） |
| **配置复杂度** | 较高（需选择类型、向量模型、切片方式、排序模式等，创建后不可更改） | 较低（创建记忆库后配置规则即可） |

## 适用场景

### 选择知识库的场景

- **领域知识问答**：企业内部文档、产品手册、技术规范等需要精确检索的场景
- **多模态数据检索**：包含图片、音视频、富文本表格等非纯文本数据
- **结构化数据查询**：需要对 Excel/数据库做自然语言查询（NL2SQL）
- **高精度召回要求**：需要细粒度调控切片策略、排序模式和相似度阈值

### 选择记忆库的场景

- **个性化助手**：需要记住用户偏好、习惯、历史交互的长期陪伴型应用
- **跨会话连续性**：用户期望智能体能"记住"之前说过的话
- **轻量集成**：不需要管理文档上传和索引构建，开箱即用
- **多应用共享记忆**：多个智能体需要共享同一用户的记忆数据

### 组合使用

两者并非互斥。典型的组合模式：用知识库提供领域专业知识（如产品文档、FAQ），用记忆库记录用户的个人偏好和交互历史。例如一个客服智能体可以同时挂载知识库回答产品问题，并通过记忆库记住用户的订单偏好和沟通风格。

## 技术选型建议

| 决策因素 | 推荐方案 |
|----------|----------|
| 需要检索大量静态文档 | 知识库 |
| 需要记住用户个人信息 | 记忆库 |
| 数据量大且需要精细调优 | 知识库 |
| 快速上线、低运维成本 | 记忆库 |
| 需要多模态检索能力 | 知识库 |
| 需要实时写入和更新 | 记忆库 |
| 需要按用户隔离数据 | 记忆库（天然按 user_id 隔离） |
| 需要跨用户共享知识 | 知识库（所有用户共享同一知识源） |
