# 知识库与记忆库对比

百炼平台同时提供知识库（Knowledge Base）和记忆库（Memory Library）两种数据增强能力，但二者的设计目标截然不同。知识库基于 RAG [检索增强生成](../concepts/rag.md)，为大模型补充静态的领域知识与文档资料；记忆库则聚焦于长期记忆，从对话中自动提取并持久化用户偏好与历史信息，使智能体具备跨会话的个性化能力。开发者在技术选型时需根据数据形态、交互模式和业务场景做出选择。

## 关键维度对比

| 维度 | 知识库 | 记忆库 |
|------|--------|--------|
| **核心定位** | 为大模型补充领域知识和私有数据（RAG） | 为智能体提供跨会话的长期记忆能力 |
| **数据来源** | PDF、Word、Markdown、Excel、RDS、图片、音视频等文件上传或数据库同步 | 对话消息自动提取，或通过 `custom_content` 手动写入 |
| **数据类型** | 非结构化文档、结构化表格、图片、音视频 | 记忆片段（事件/信息）和用户画像（结构化属性） |
| **存储粒度** | 文档切片（单片上限 6000 Token） | 记忆片段（关键信息条目）或画像字段 |
| **检索方式** | 向量语义检索 + Rerank 排序模型 | 语义检索（`SearchMemory`） |
| **向量模型** | `text-embedding-v4`（推荐）、`text-embedding-v3`、`multimodal-embedding-v1`、`qwen3-vl-embedding` | 内置，无需用户选择 |
| **排序模型** | `qwen3-rerank（hybrid）`、`qwen3-rerank` 可选配置 | `gte-rerank-v2`（仅此一种） |
| **API 端点** | 通过百炼 SDK 调用 `Retrieve` 接口 | `AddMemory`、`SearchMemory`、`ListMemory` 等 REST API |
| **集成方式** | 挂载到智能体应用或工作流节点；SDK 调用 | API 直接调用；插件集成到第三方 Agent 框架（如 OpenClaw） |
| **数据更新** | 文件重新上传（需先删后传）；OSS+FC 自动更新；RDS 自动同步 | 对话自动提取并去重；支持手动更新和删除 |
| **数据过期** | 无过期机制，持久存储 | 可配置 7 天 / 30 天 / 180 天 / 永不过期 |
| **计费方式** | 向量化、检索、存储均计费（标准版/旗舰版差异定价） | 目前限时免费 |
| **速率限制** | 取决于应用调用频率和知识库规格 | AddMemory 120 次/分钟，SearchMemory 300 次/分钟，合计 3000 次/分钟 |
| **检索延迟** | 取决于切片数量和排序配置 | SearchMemory 200-500ms，AddMemory 500-1000ms |
| **多应用共享** | 同一知识库可被多个应用引用 | 同一记忆库可接入多个应用共享 |

## 适用场景建议

### 选择知识库的场景

- **领域知识问答**：企业内部文档、产品手册、技术规范等需要精准检索和引用的场景。
- **多模态数据检索**：涉及图片、音视频、富文本版面理解等复杂数据形态。
- **结构化数据查询**：Excel 表格、数据库中的结构化数据，需要 NL2SQL 或 Chatbot 式交互。
- **高精度 RAG**：需要精细控制切片策略、排序模型、相似度阈值等参数以优化召回效果。

### 选择记忆库的场景

- **个性化助手**：需要记住用户偏好、习惯、历史指令，提供个性化服务。
- **多轮长周期对话**：对话跨越多个会话，需要持续积累用户信息。
- **用户画像构建**：需要从对话中渐进式提取和维护用户属性（如年龄、职业、偏好）。
- **轻量级集成**：通过简单的 API 调用或框架插件即可实现，无需管理文档和索引。

### 组合使用

知识库与记忆库并非互斥，在复杂应用中可以组合使用：知识库提供通用的领域知识检索，记忆库叠加用户维度的个性化上下文，二者共同注入 Prompt 以生成既专业又贴合用户需求的回答。

## 技术选型参考

| 决策因素 | 推荐方案 |
|----------|----------|
| 需要检索大量文档资料 | 知识库 |
| 需要跨会话记住用户信息 | 记忆库 |
| 数据以文件形式存在 | 知识库 |
| 数据从对话中产生 | 记忆库 |
| 需要多模态（图片/音视频）检索 | 知识库 |
| 需要用户画像提取 | 记忆库 |
| 需要精细的检索参数调优 | 知识库 |
| 需要快速集成且零成本试用 | 记忆库（限时免费） |
| 需要领域知识 + 个性化 | 知识库 + 记忆库组合 |
