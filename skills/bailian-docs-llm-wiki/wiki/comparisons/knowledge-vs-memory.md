# 知识库与记忆库对比

百炼平台同时提供**知识库**和**记忆库**两种数据增强方案，帮助大模型在推理时获取额外信息。两者的设计目标截然不同：知识库基于 RAG 技术为模型补充结构化的领域知识与文档内容；记忆库则面向用户级长期记忆，自动从对话中提取关键信息并持久化存储，使智能体能跨会话引用用户偏好和历史。本文从多个维度对比两者差异，为开发者的技术选型提供参考。

## 关键维度对比

| 维度 | 知识库 | 记忆库 |
|------|--------|--------|
| **核心定位** | 领域知识检索增强（RAG） | 用户级长期记忆管理 |
| **数据来源** | 开发者主动上传的文档、表格、音视频等 | 自动从对话中提取，或通过 API 写入自定义内容 |
| **数据粒度** | 文档切片（最大 6000 Token/片） | 记忆片段（关键事件/信息）、用户画像（结构化属性） |
| **支持的输入格式** | PDF、Word、Markdown、图片、Excel、RDS、MP3、WAV、MP4、MOV 等 | 对话消息列表（messages）或自定义文本（custom_content） |
| **检索方式** | 向量语义检索 + Rerank 排序模型 | 语义检索（SearchMemory），top_k 建议 3~10 |
| **向量模型** | text-embedding-v4/v3（512 维）、multimodal-embedding-v1（1024 维）、qwen3-vl-embedding | 内置，不可选择 |
| **排序模型** | qwen3-rerank（hybrid）、qwen3-rerank | gte-rerank-v2 |
| **集成方式** | 智能体应用挂载、工作流节点、SDK 调用 | API 直接调用、插件集成（如 OpenClaw 生命周期钩子） |
| **API 端点** | 百炼 SDK Retrieve 接口 | REST API（AddMemory / SearchMemory 等） |
| **知识库类型** | 文档搜索、数据查询、图片问答、音视频搜索（创建后不可更改） | 单一类型（记忆片段 + 用户画像） |
| **数据更新** | 手动上传/删除、OSS+FC 自动更新、RDS 同步 | 每轮对话后自动提取、支持 API 增删改 |
| **多用户隔离** | 按知识库维度，不区分终端用户 | 按 user_id 维度，天然支持多用户隔离 |
| **过期机制** | 无自动过期，手动管理生命周期 | 可配置 7 天 / 30 天 / 180 天 / 永不过期 |
| **计费方式** | 向量存储（内置免费 / ADB-PG 自购）+ 模型调用费 | 目前限时免费 |
| **速率限制** | 取决于应用和模型配额 | AddMemory 120 次/分钟、SearchMemory 300 次/分钟、合计 3000 次/分钟 |
| **延迟** | 取决于切片数量和模型推理 | SearchMemory 200~500ms、AddMemory 500~1000ms |
| **规则配置上限** | 无固定条数限制 | 每个记忆库最多 50 条记忆片段规则 + 50 条用户画像规则 |

## 适用场景建议

### 选择知识库的场景

- **企业知识问答**：需要基于大量产品文档、技术手册、FAQ 回答用户问题。
- **多模态检索**：需要对图片、音视频、富文本文档进行语义检索。
- **结构化数据查询**：通过 NL2SQL 查询 Excel 或数据库中的结构化数据。
- **精确度要求高**：需要通过 Rerank、相似度阈值、排序模式等精细调优检索质量。
- **共享知识**：所有用户共享同一份知识库，不需要按用户区分内容。

### 选择记忆库的场景

- **个性化助手**：需要记住每个用户的偏好、习惯、历史指令，跨会话提供连贯服务。
- **用户画像构建**：需要从多轮对话中逐步提取用户的结构化属性（年龄、职业、偏好等）。
- **轻量集成**：不需要上传和管理文档，只需对话即可自动积累记忆。
- **多应用共享用户记忆**：多个应用共享同一记忆库，统一用户画像。

### 两者结合的场景

在实际应用中，知识库和记忆库可以同时使用。例如：智能客服应用通过知识库检索产品文档回答专业问题，同时通过记忆库记住用户的历史咨询记录和偏好，在后续对话中提供更有针对性的服务。两者分别注入 Prompt 的不同位置，互不冲突。

## 技术选型决策

| 决策因素 | 推荐方案 |
|----------|----------|
| 需要检索大量静态文档 | 知识库 |
| 需要跨会话记住用户信息 | 记忆库 |
| 需要多模态（图片/音视频）检索 | 知识库 |
| 需要按用户维度隔离数据 | 记忆库 |
| 需要精细控制检索和排序策略 | 知识库 |
| 需要对话自动积累信息 | 记忆库 |
| 需要两者兼顾 | 同时集成，分别注入 Prompt |
