# 图像、视频、3D 与音乐生成对比

百炼平台提供了覆盖图像、视频、3D 模型和音乐四大媒体类型的生成能力。不同类型在输入方式、输出格式、模型生态、调用模式和计费维度上差异显著。本文从开发者技术选型角度出发，系统对比这四类生成 API 的核心差异，帮助快速判断哪种能力适合当前业务场景。

## 核心维度对比

| 维度 | 图像生成 | 视频生成 | 3D 模型生成 | 音乐生成 |
|------|---------|---------|------------|---------|
| **输入方式** | 文本提示词、参考图片、涂抹蒙版 | 文本提示词、首帧/尾帧图片、参考图/视频、音频驱动 | 文本提示词、单张图片、多视角图片（4张） | 文本提示词、自定义歌词 |
| **输出格式** | PNG 图片 | MP4 视频 | GLB 格式 3D 模型（含 PBR 材质） | MP3 或 WAV 音频 |
| **主要模型** | Qwen-Image、万相 Wan T2I、Z-Image、可灵 Kling | 万相 Wan T2V/I2V/R2V、HappyHorse、PixVerse、可灵 Kling、Vidu | Tripo-H3.1、Tripo-P1.0 | Fun-Music-v1、Fun-Music-preview |
| **模型数量** | 10+ 系列（含编辑、电商专用） | 5 大系列 + 6 类数字人模型 | 2 个模型 | 2 个模型 |
| **调用模式** | 同步为主（新版模型）；旧版异步 | 全部异步（耗时 1-5 分钟） | 全部异步（需轮询） | 同步 + SSE 流式 |
| **API 端点** | `/api/v1/services/aigc/...`（多个子路径） | `/api/v1/services/aigc/video-generation/video-synthesis` | `/api/v1/services/aigc/video-generation/3d-generation` | `/api/v1/services/audio/music/generation` |
| **输出分辨率/规格** | 512x512 至 4K | 480P / 540P / 720P / 1080P 等 | 最高 200 万面（H3.1）/ 2 万面（P1.0） | 48000Hz 立体声 |
| **地域支持** | 北京 + 新加坡（部分模型仅北京） | 北京为主；HappyHorse 支持多地域 | 仅北京 | 仅北京 |
| **开通方式** | 大部分默认可用；可灵需单独开通 | 部分模型需控制台搜索并手动开通 | 需控制台搜索"Tripo"开通 | 邀测阶段，需申请开通 |
| **结果有效期** | 即时返回图片 URL | task_id 24 小时有效 | 下载链接 2 小时有效 | 音频 URL 24 小时有效 |
| **计费单位** | 按张计费 | 按视频时长/分辨率计费 | 按任务类型计费 | 按音乐时长（秒）计费 |

## 输入灵活性对比

| 能力 | 图像生成 | 视频生成 | 3D 模型生成 | 音乐生成 |
|------|---------|---------|------------|---------|
| 纯文本生成 | 支持 | 支持 | 支持 | 支持（[prompt](../guides/prompt.md)） |
| 图片驱动 | 支持（参考图、多图融合） | 支持（首帧/尾帧/参考图） | 支持（单图/多视角图） | 不支持 |
| 音频驱动 | 不支持 | 支持（数字人、音频驱动视频） | 不支持 | 支持（歌词输入） |
| 视频输入 | 不支持 | 支持（视频编辑、风格重绘、换人） | 不支持 | 不支持 |
| 多模态组合输入 | 支持（文+图） | 支持（文+图+音频+视频） | 支持（文或图，互斥） | 支持（[prompt](../guides/prompt.md) 或 lyrics，二选一） |

## 生态成熟度对比

| 维度 | 图像生成 | 视频生成 | 3D 模型生成 | 音乐生成 |
|------|---------|---------|------------|---------|
| 模型丰富度 | 非常丰富（多系列、多版本） | 丰富（5+厂商聚合） | 较少（单厂商 Tripo） | 较少（单系列 Fun-Music） |
| 编辑能力 | 强（局部重绘、扩图、擦除、超分等） | 中等（视频编辑、风格重绘） | 无后编辑 API | 无后编辑 API |
| 行业专用模型 | 丰富（电商虚拟模特、试衣、海报等） | 丰富（数字人、人像驱动等） | 无 | 无 |
| 成熟度 | 高（多代迭代，V1→V2→2.5→2.6→2.7） | 高（快速迭代中） | 中等 | 早期（邀测阶段） |

## 适用场景建议

### 图像生成
- **营销物料**：商品主图、海报、Banner 快速生成
- **电商场景**：虚拟模特换装、商品背景替换、AI 试衣
- **内容创作**：文章配图、社交媒体素材、风格化头像
- **文字设计**：含中文文字的图片（推荐 Qwen-Image 系列，文字渲染准确度高）
- **图片后处理**：去水印、扩图、超分辨率、局部修改

### 视频生成
- **短视频/广告**：文本或图片快速生成视频片段
- **数字人/虚拟主播**：照片驱动说话、唱歌、表演视频
- **动画制作**：图生视频、动作迁移、多镜头叙事
- **视频编辑**：风格重绘、口型替换、视频换人
- **IP 内容生产**：参考图/视频保持人物一致性批量出片

### 3D 模型生成
- **游戏/元宇宙**：快速生成 3D 资产原型
- **电商展示**：商品 3D 展示模型
- **AR/VR 内容**：从图片或文字快速获取 3D 物体
- **设计预览**：概念设计阶段快速可视化

### 音乐生成
- **短视频配乐**：根据场景描述自动生成背景音乐
- **内容创作**：Vlog、播客的原创配乐
- **游戏/应用**：动态生成场景音乐
- **音乐创作辅助**：自定义歌词生成完整歌曲

## 技术选型建议

1. **需要即时响应**：优先选择图像生成（同步模式）或音乐生成（同步/流式），视频和 3D 均为异步，等待时间较长。
2. **需要多地域部署**：图像生成部分模型和 HappyHorse 视频模型支持海外地域，其余能力当前主要限北京地域。
3. **需要丰富的后编辑能力**：图像生成在编辑能力上最为完善（擦除、重绘、扩图等），视频次之，3D 和音乐暂不支持后编辑。
4. **预算敏感**：各类型计费维度不同，图像按张、视频按时长、3D 按任务、音乐按秒。建议根据实际生成量评估成本。部分图像和视频模型提供免费体验额度，但额度用完后可能不支持付费续用。
5. **模型选型稳定性**：图像和视频生成模型迭代快，建议使用最新推荐版本（如 wan2.7 系列）。3D 和音乐模型选择较少，直接使用当前可用版本即可。
6. **多媒体组合场景**：如需"文字 → 图片 → 视频"全链路，可串联图像生成与视频的图生视频能力；如需视频配乐，可组合视频生成与音乐生成。
