# 图像生成、视频生成与3D生成对比

百炼平台在多媒体内容生成领域提供了图像生成、视频生成和 3D 模型生成三大类 API。三者在输入方式、输出产物、模型生态、调用模式和计费策略上各有差异。本文从开发者技术选型角度，对这三类能力进行系统对比，帮助快速定位适合业务场景的方案。

## 核心维度对比

| 维度 | 图像生成 | 视频生成 | 3D 生成 |
|------|---------|---------|---------|
| **输入类型** | 文本提示词、参考图片、蒙版图 | 文本提示词、首帧/尾帧图片、参考图/视频、驱动音频 | 文本提示词、单张图片、多视角图片（4 张） |
| **输出格式** | PNG/JPEG 图片 | MP4 视频 | GLB 3D 模型（含 PBR 材质或基础网格）+ 渲染预览图 |
| **调用模式** | 新版模型支持同步调用；旧版模型仅异步 | 全部异步（创建任务 → 轮询结果） | 全部异步（创建任务 → 轮询结果） |
| **主要模型** | 千问图像系列、万相系列、Z-Image、可灵 | 万相 Wan、HappyHorse、PixVerse、可灵、Vidu | Tripo-H3.1、Tripo-P1.0 |
| **模型数量** | 20+ 款（含垂直场景模型） | 30+ 款（含人物驱动类模型） | 2 款 |
| **典型耗时** | 同步模型秒级返回；异步模型数秒至数十秒 | 1–10 分钟 | 数十秒至数分钟 |
| **分辨率/规格** | 512×512 至 4K（2048×2048），部分模型支持自由尺寸 | 480P / 540P / 720P / 1080P | 最高 200 万面（H3.1）；最高 2 万面（P1.0） |
| **地域限制** | 多数模型北京地域；千问/万相 2.6+ 支持多地域 | 北京为主，部分模型支持新加坡、美国、德国 | 仅北京地域 |
| **计费方式** | 按张计费（0.02–0.18 元/张不等），部分模型免费体验 | 按秒计费或按次计费 | 按任务计费 |

## API 端点与协议对比

| 维度 | 图像生成 | 视频生成 | 3D 生成 |
|------|---------|---------|---------|
| **同步端点** | `/api/v1/services/aigc/multimodal-generation/generation` | 不支持 | 不支持 |
| **异步创建端点** | `/api/v1/services/aigc/text2image/image-synthesis` 等（按模型不同） | `/api/v1/services/aigc/video-generation/video-synthesis` | `/api/v1/services/aigc/video-generation/3d-generation` |
| **异步轮询端点** | `/api/v1/tasks/{task_id}` | `/api/v1/tasks/{task_id}` | `/api/v1/tasks/{task_id}` |
| **异步请求头** | 需设置 `X-DashScope-Async: enable` | 需设置 `X-DashScope-Async: enable` | 需设置 `X-DashScope-Async: enable` |
| **task_id 有效期** | 24 小时 | 24 小时 | 24 小时 |

三者异步轮询端点和协议完全一致，均遵循 DashScope [异步任务](../concepts/async-task.md)规范。

## 功能能力对比

| 能力 | 图像生成 | 视频生成 | 3D 生成 |
|------|---------|---------|---------|
| 文本生成 | 支持（文生图） | 支持（文生视频） | 支持（文生 3D） |
| 图像/图片输入 | 支持（图像编辑、参考生图） | 支持（首帧/尾帧/参考图生视频） | 支持（单图/多图生 3D） |
| 多图输入 | 部分模型支持多图融合 | 支持多参考图 | 支持 4 视角多图 |
| 视频输入 | 不支持 | 支持（视频编辑、续写） | 不支持 |
| 音频输入 | 不支持 | 支持（驱动音频、自定义配音） | 不支持 |
| 批量输出 | 部分模型支持 1–6 张 | 单次单视频（万相 2.7 支持多镜头） | 单次单模型 |
| 风格控制 | 支持多种艺术风格、风格重绘 | 支持视频风格重绘 | 通过贴图质量参数控制 |
| 文字渲染 | 千问图像、Z-Image 支持中英文文字渲染 | 不支持 | 不支持 |

## 模型生态对比

### 图像生成

图像生成拥有最丰富的模型生态，覆盖通用文生图、图像编辑和多个垂直场景：

- **千问图像系列**：文生图 + 图像编辑 + 图像翻译，Pro 系列文字渲染能力突出
- **万相系列**：从 1.0 到 2.7 持续迭代，2.7 支持 4K 输出和组图生成
- **Z-Image**：轻量极速，支持智能思考扩展提示词
- **可灵**：支持 4K 分辨率和分镜组图
- **垂直模型**：虚拟试衣、背景生成、海报生成、人像风格重绘等

### 视频生成

视频生成聚合多家厂商模型，功能覆盖最广：

- **万相 Wan**（推荐首选）：文生视频 / 图生视频 / 参考生视频 / 视频编辑全链路，2.7 版支持多镜头叙事
- **HappyHorse**：四种能力全覆盖，参考生视频支持占位符引用
- **PixVerse**：c1 / v6 / v5.6 三档，部分支持多镜头和自带音频
- **可灵 Kling**：v3 / v2 / v1.6 多版本，支持人物驱动和口型替换
- **Vidu**：文生视频和参考生视频
- **人物驱动类**：数字人、动作迁移、唱演/播报/表情包等专用模型

### 3D 生成

3D 生成目前仅有 Tripo 一家模型提供方：

- **Tripo-H3.1**：高精度，最高 200 万面
- **Tripo-P1.0**：专业版，速度更快，最高 2 万面

## 适用场景建议

| 场景 | 推荐方案 | 说明 |
|------|---------|------|
| 营销素材、电商商品图 | 图像生成 | 万相/千问文生图 + 背景生成模型，成本低、速度快 |
| AI 试衣、虚拟模特 | 图像生成 | aitryon / 虚拟模特专用模型 |
| 图片中文字翻译 | 图像生成 | 千问图像翻译（qwen-mt-image）专用 |
| 短视频创作、广告片 | 视频生成 | 万相 2.7 文生视频 + 多镜头叙事 |
| 数字人播报、虚拟主播 | 视频生成 | 人物驱动模型（数字人、口型替换） |
| 视频二次编辑、风格化 | 视频生成 | 万相 2.7 视频编辑 / wanx2.1-vace-plus |
| 游戏/电商 3D 资产生成 | 3D 生成 | Tripo-H3.1（高精度）或 Tripo-P1.0（快速） |
| 产品 3D 展示、AR 预览 | 3D 生成 | 单图生 3D 配合 PBR 材质 |

## 技术选型要点

1. **响应速度优先**：选择图像生成（同步调用秒级返回），适合实时交互场景。视频和 3D 均为异步且耗时较长，需要设计轮询或回调机制。

2. **模型丰富度**：图像生成和视频生成模型生态成熟，可选方案多；3D 生成目前仅 Tripo 两款模型，选择面较窄。

3. **多地域部署**：如需海外部署，视频生成支持新加坡、美国、德国等地域；图像生成部分新版模型支持多地域；3D 生成仅限北京。

4. **成本控制**：图像生成按张计费，单价最低；视频生成按时长或次数计费，单次成本较高；3D 生成按任务计费。建议根据产出量级评估总成本。

5. **[异步任务](../concepts/async-task.md)管理**：三者共享相同的[异步任务](../concepts/async-task.md)轮询协议（`task_id` 有效期 24 小时），可复用同一套任务管理基础设施。但需注意 API Key、Endpoint、模型必须属于同一地域，跨地域调用会失败。
