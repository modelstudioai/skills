# 应用监控与模型监控对比

百炼平台提供两套互补的监控体系：**应用监控（应用观测）** 和 **模型监控**。前者面向应用层，追踪完整的调用链路与处理流程；后者面向模型层，关注单个模型的调用量、性能与成本。理解两者的定位差异，有助于开发者根据排查目标选择合适的监控入口，或将二者结合使用以实现端到端的可观测性。

## 关键维度对比

| 维度 | 应用监控（应用观测） | 模型监控 |
|------|----------------------|----------|
| **监控粒度** | 应用级，追踪单次请求的完整调用链路（含多个 Span 节点） | 模型级，统计单个模型的调用量与性能指标 |
| **核心目标** | 调用链路追踪、端到端延时分析、节点级问题定位 | 用量统计、成本管控、性能基线监控、异常告警 |
| **支持范围** | 智能体应用、工作流应用、高代码应用（Assistant API 创建的智能体暂不支持） | 模型列表中所有模型及自定义模型；高级监控/告警/日志受地域限制 |
| **数据延迟** | 分钟级 | 用量统计约 1 小时；监控指标分钟级 |
| **底层技术** | 可观测链路 OpenTelemetry 服务 | 私有 Prometheus 实例（高级监控） |
| **告警能力** | 无内置告警 | 支持主动告警（短信、邮件、电话、钉钉、企业微信、Webhook） |
| **日志查看** | 可查看每个 Span 的 Prompt 输入/输出、延时、Token 用量 | 开通推理日志后可查看每次模型调用的输入/输出、Token 消耗、耗时 |
| **数据导出** | 支持导出为 JSONL 或 EXCEL | 支持接入 Grafana 或自建系统（Prometheus HTTP API） |
| **外部集成** | 不支持 | 支持 Prometheus HTTP API，可接入 Grafana |
| **操作入口** | 控制台应用观测页面（暂无 API） | 控制台模型监控页面 + Prometheus API |
| **计费** | 功能免费，存储费由 OpenTelemetry 服务收取 | 功能免费，高级监控依赖 Prometheus 实例 |

## 监控指标对比

| 指标类别 | 应用监控 | 模型监控 |
|---------|----------|----------|
| 调用次数 | 应用维度的调用次数趋势 | 模型维度的调用次数总和（`model_call_count`） |
| Token 用量 | 总量、输入/输出 Token、平均单次 Token | 按模型统计的用量总和（`model_usage`），区分输入/输出 |
| 延时 | 平均首 Token 耗时、平均调用时长 | 调用时长均值、首包时长均值、非首包时长均值 |
| 失败统计 | 失败次数与失败率 | 失败次数、失败率、限流错误次数、内容安全错误次数 |
| 成本 | 不直接提供成本视图 | 平均单次请求调用量，可辅助成本估算 |

## 适用场景建议

**优先使用应用监控的场景：**

- 排查某次用户请求的端到端处理链路，定位是检索、重排还是大模型环节出现瓶颈
- 分析工作流应用中各节点的执行顺序与耗时分布
- 对线上调用数据进行标注，并批量导入评测集用于应用效果评估
- 需要按 Request ID / Trace ID / Span ID 精确定位特定请求

**优先使用模型监控的场景：**

- 统计某个模型在[业务空间](../concepts/workspace.md)内的整体调用量和 Token 消耗趋势
- 设置告警规则，在模型调用失败率上升或 Token 消耗突增时及时通知
- 将监控数据接入 Grafana 等外部可视化平台，构建统一运维大盘
- 对比不同模型的性能基线（首 Token 延时、调用时长），辅助模型选型
- 管理免费额度，开启"用完即停"避免意外扣费

**组合使用建议：**

在生产环境中，建议同时启用两套监控。模型监控负责宏观层面的用量告警与成本管控，应用监控负责微观层面的链路追踪与问题定位。当模型监控告警触发（如失败率突增）时，可切换到应用监控查看具体失败请求的调用链路，快速定位根因。

## 前置条件对比

| 条件 | 应用监控 | 模型监控 |
|------|----------|----------|
| 服务开通 | 需开通可观测链路 OpenTelemetry 服务并初始化 LogStore | 基础监控无需额外开通；高级监控需手动开启 |
| 权限要求 | 建议主账号操作；子账号需 `AliyunBailianFullAccess` 等权限 | 常规权限即可 |
| 地域限制 | 无特殊限制 | 高级监控限北京、新加坡、弗吉尼亚；告警限北京、新加坡；日志限北京、新加坡部分模型 |
