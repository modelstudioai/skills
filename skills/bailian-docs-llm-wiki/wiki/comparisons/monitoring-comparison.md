# 应用监控与模型监控对比

阿里云百炼平台提供两套互补的可观测能力：**应用观测**聚焦于应用内部的调用链路追踪与 Span 级分析，帮助开发者理解一次请求在智能体、工作流或高代码应用中的完整执行过程；**模型监控**则从模型维度出发，提供调用量、性能指标、用量统计与告警能力，帮助开发者管理成本并及时发现服务异常。两者的监控粒度和使用场景不同，理解其差异有助于开发者选择合适的观测手段。

## 关键维度对比

| 维度 | 应用观测 | 模型监控 |
|------|----------|----------|
| **监控对象** | 应用（智能体、工作流、高代码应用） | 模型（含基础模型与调优后的自定义模型） |
| **核心能力** | 调用链路追踪、Span 级细节查看、数据标注 | 调用指标监控、用量统计、告警通知 |
| **数据粒度** | 单次请求的完整调用链（CHAIN → AGENT → LLM → RETRIEVER 等） | 模型维度的聚合指标（调用次数、延时、RPM、TPM） |
| **数据更新频率** | 分钟级 | 普通监控小时级；高级监控分钟级 |
| **主要指标** | 调用次数、失败率、Token 总量、平均首 Token 耗时、平均调用时长 | 调用次数、失败率、Token 消耗、调用时长 p50/p99、首 Token 延时 p50/p99、RPM、TPM |
| **API 接口** | 暂无 API | 高级监控支持 Prometheus HTTP API |
| **外部集成** | 不支持 | 支持 Grafana、自建应用通过 Prometheus 接入 |
| **告警能力** | 无 | 支持阈值告警（短信、邮件、电话、钉钉、企业微信、Webhook） |
| **日志功能** | 通过 Span 详情查看输入/输出 | 独立模型日志功能，记录每次调用的请求与响应 |
| **数据导出** | 支持导出为 JSONL / EXCEL | 通过 Prometheus API 或阿里云账单导出 |
| **适用地域** | 无地域限制说明 | 高级监控限北京、新加坡、弗吉尼亚；告警限北京、新加坡；日志限北京 |
| **费用** | 功能免费，存储依赖 OpenTelemetry 服务计费 | 功能免费，含免费额度管理（超额可自动停服或按量付费） |
| **前置条件** | 需开通可观测链路 OpenTelemetry 服务并完成初始化 | 高级监控与日志需手动开启 |

## 功能特色对比

| 特色功能 | 应用观测 | 模型监控 |
|----------|----------|----------|
| 调用链路可视化 | 支持，展示完整的 Span 树结构 | 不支持 |
| Span 筛选（Root/All/Model） | 支持 | 不适用 |
| 数据标注与评测集 | 支持自定义标签标注，可批量添加到评测集 | 不支持 |
| 免费额度管理 | 不涉及 | 支持，可设置额度用完即停 |
| 多维度告警 | 不支持 | 支持四级告警（紧急/错误/警告/普通） |
| Prometheus 集成 | 不支持 | 支持标准 Prometheus HTTP API |

## 适用场景建议

**优先使用应用观测的场景：**

- 需要排查某次应用调用失败的具体原因（如哪个节点报错、哪个插件超时）
- 需要了解智能体或工作流内部的执行顺序和各环节耗时
- 需要查看模型推理的思考过程和具体输入/输出内容
- 需要对调用数据进行标注并导入评测集，用于应用质量评估
- 开发调试阶段需要细粒度的链路追踪

**优先使用模型监控的场景：**

- 需要从全局视角监控模型调用量和成本趋势
- 需要设置告警规则，在调用失败率或延时异常时自动通知团队
- 需要管理免费额度，控制超额消费风险
- 需要将监控数据接入 Grafana 等自建可视化平台
- 生产环境中需要持续关注模型服务的 RPM、TPM 等性能指标

**建议结合使用：** 在生产环境中，模型监控提供全局视角的指标看板与告警能力，应用观测则在发现异常后提供深入到单次请求的链路排查能力。两者配合使用可实现从宏观监控到微观诊断的完整可观测闭环。
