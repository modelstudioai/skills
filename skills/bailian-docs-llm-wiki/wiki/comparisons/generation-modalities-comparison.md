# 图像生成 vs 视频生成 vs 3D 生成

百炼平台在生成式 AI 领域提供了三大内容生成能力：图像生成、视频生成和 3D 模型生成。三者在输入方式、输出产物、模型生态和适用场景上各有侧重。本文从开发者技术选型的角度，对这三种生成模态进行系统对比，帮助开发者根据业务需求快速选择合适的生成能力。

## 关键维度对比

| 维度 | 图像生成 | 视频生成 | 3D 生成 |
|------|---------|---------|---------|
| **输入格式** | 文本提示词、参考图片 | 文本提示词、首帧/尾帧图片、参考图片/视频、音频 | 文本提示词、单张/多张图片（前左后右四视角） |
| **输出格式** | PNG 图片（单张或多张） | MP4 视频（含音频） | GLB 3D 模型文件（含 PBR 材质）、预览渲染图 |
| **输出分辨率/规格** | 512x512 至 4K，可控宽高比 | 480P/540P/720P/1080P，时长 5-10 秒 | 最高 200 万面（H3.1）/ 2 万面（P1.0） |
| **主要模型系列** | 千问 Qwen-Image、万相 Wan、Z-Image、可灵 Kling | 万相 Wan、HappyHorse、PixVerse、可灵 Kling、Vidu | Tripo（H3.1 / P1.0） |
| **API 调用模式** | 同步（新版模型）+ 异步（旧版模型） | 仅异步（所有模型） | 仅异步 |
| **典型耗时** | 秒级（同步）至分钟级（异步） | 1-5 分钟 | 分钟级 |
| **API 端点路径** | `/api/v1/services/aigc/...`（因模型而异） | `/api/v1/services/aigc/video-generation/video-synthesis` | `/api/v1/services/aigc/video-generation/3d-generation` |
| **计费方式** | 按生成张数计费 | 按视频时长和分辨率计费 | 按任务次数计费 |
| **编辑能力** | 丰富：局部重绘、扩图、擦除、风格迁移、超分辨率 | 支持视频编辑、风格重绘、口型替换 | 不支持编辑 |
| **多地域支持** | 北京、新加坡（部分模型） | 北京为主，HappyHorse 支持多地域 | 仅北京 |
| **需单独开通** | 可灵需单独开通 | PixVerse、可灵、Vidu 需单独开通 | Tripo 需单独开通 |

## 功能特色对比

| 特色能力 | 图像生成 | 视频生成 | 3D 生成 |
|---------|---------|---------|---------|
| 文本渲染 | 支持（千问、Z-Image 擅长复杂文字渲染） | 不适用 | 不适用 |
| 多图/组图 | 支持（万相 2.7 文生组图、图生组图） | 不适用 | 支持多图输入（四视角） |
| 电商场景 | 丰富（虚拟模特、试衣、背景生成、海报） | 有限 | 不适用 |
| 数字人/人像 | 人像风格重绘、人物写真 | 丰富（数字人、说话视频、舞蹈迁移、口型替换） | 不适用 |
| 多镜头叙事 | 不适用 | 支持（万相 2.7、可灵智能分镜） | 不适用 |
| 音频驱动 | 不适用 | 支持（驱动音频、音色参考） | 不适用 |
| PBR 材质 | 不适用 | 不适用 | 支持（物理渲染材质输出） |

## 适用场景建议

### 选择图像生成的场景

- **营销素材制作**：海报、广告图、商品展示图的快速生成与迭代
- **电商场景**：虚拟模特换装、商品背景替换、创意海报生成
- **内容创作**：文章配图、社交媒体图片、艺术风格转换
- **图文排版**：需要在图片中嵌入精确文字的场景（推荐千问 Qwen-Image）
- **图像后处理**：已有图片的局部修改、超分辨率增强、去水印、扩图

### 选择视频生成的场景

- **短视频内容**：根据脚本或提示词快速生成短视频素材
- **数字人应用**：虚拟主播、产品介绍视频、在线教育场景
- **动态展示**：将静态图片转化为动态视频（图生视频）
- **创意视频**：多镜头叙事视频、风格化视频转换
- **人像驱动**：基于音频驱动的说话视频、舞蹈迁移视频

### 选择 3D 生成的场景

- **3D 资产快速原型**：游戏、AR/VR 应用的 3D 模型快速创建
- **电商 3D 展示**：商品 3D 模型生成，支持交互式展示
- **工业设计预览**：根据文字描述或参考图快速生成 3D 概念模型
- **多视角建模**：需要从多个角度照片重建 3D 模型的场景

## 技术选型建议

1. **如果需求是静态视觉内容**，优先选择图像生成。图像生成模型生态最丰富、调用延迟最低（新版模型支持同步调用），且编辑能力最完善，适合需要快速迭代的场景。

2. **如果需求涉及动态内容或时序表达**，选择视频生成。视频生成在数字人、动态展示和叙事类内容方面具有不可替代的优势，但需注意所有调用均为异步，生成耗时较长。

3. **如果需求涉及三维空间表达**，选择 3D 生成。当前百炼平台的 3D 生成能力由 Tripo 提供，模型选择较少但输出质量较高，适合需要 GLB 格式 3D 资产的应用场景。

4. **组合使用**：在实际项目中，三种能力可以互补。例如先用图像生成制作参考图，再用图生视频或图生 3D 将其转化为动态或三维内容。万相 2.7 系列在图像和视频生成之间实现了较好的生态统一，可以降低多模态切换的学习成本。
