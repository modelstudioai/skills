# 模型监控与应用监控对比

百炼平台提供两套互补的可观测体系——**模型监控**和**应用监测**。前者聚焦于单个模型的调用量、性能与成本管理，后者则面向应用层的端到端调用链路追踪。理解二者的定位差异，有助于开发者在不同场景下选择合适的监控手段，甚至组合使用以获得全方位的可观测能力。

## 关键维度对比

| 维度 | 模型监控 | 应用监控 |
|------|---------|---------|
| **监控对象** | 单个模型的调用行为与资源消耗 | 应用内部的完整调用链路（含多个模型、插件、检索等节点） |
| **观测粒度** | 模型级别（按模型名、API Key、[业务空间](../concepts/workspace.md)筛选） | Span 级别（CHAIN → AGENT → LLM → TOOL 等层层展开） |
| **支持范围** | 模型列表中的所有模型及调优后的自定义模型 | 智能体应用、工作流应用、高代码应用（不含 Assistant API 创建的智能体） |
| **核心指标** | 调用次数、Token 消耗、首 Token 延时、调用时长、RPM/TPM、失败率、内容安全错误 | 调用次数、失败率、Token 总量（输入/输出）、平均首 Token 耗时、平均调用时长 |
| **用量统计** | 按模型类型区分（Token/张/秒/字符），支持按[业务空间](../concepts/workspace.md)维度汇总 | 不直接提供用量统计，聚焦链路级 Token 消耗 |
| **日志能力** | 推理日志（需开通，仅限部分模型和地域） | 调用链路自动追踪，支持按 Request ID / Trace ID / Span ID 搜索 |
| **告警机制** | 费用告警 + 模型指标告警（需开启高级监控），支持短信/邮件/电话/钉钉/企业微信/Webhook | 无内置告警（依赖 OpenTelemetry 服务侧能力） |
| **外部集成** | 高级监控数据存储于私有 Prometheus，支持 Grafana 及 Prometheus HTTP API | 基于可观测链路 OpenTelemetry 服务 |
| **数据导出** | 不支持直接导出（可通过 Prometheus API 查询） | 支持导出 JSONL 或 EXCEL 格式 |
| **数据标注** | 不支持 | 支持对 Span 添加自定义标签，可关联应用评测 |
| **API 接口** | 通过 Prometheus HTTP API 访问指标 | 暂无 API 接口 |
| **计费** | 高级监控需开通 Prometheus 实例（产生存储费） | 功能免费，存储依赖 OpenTelemetry 服务产生费用 |
| **地域限制** | 高级监控限北京/新加坡/弗吉尼亚；告警限北京/新加坡 | 无特别地域限制说明 |

## 适用场景

### 优先使用模型监控

- **成本管控**：需要按模型维度追踪 Token 消耗趋势、管理免费额度、配置费用告警时。
- **模型选型评估**：对比不同模型的性能指标（首 Token 延时、调用时长），辅助选择最具性价比的模型。
- **生产稳定性保障**：需要对模型调用失败率、限流错误等设置阈值告警，及时发现异常。
- **接入自建监控体系**：已有 Grafana 或 Prometheus 体系，希望将百炼模型指标纳入统一看板。

### 优先使用应用监控

- **调用链路排查**：应用响应异常时，需要查看完整的 CHAIN → AGENT → LLM → TOOL 调用链路定位瓶颈。
- **RAG 管线调优**：需要观测 RETRIEVER、EMBEDDING、RERANKER 等检索节点的行为和耗时。
- **应用质量评估**：需要对 Span 数据添加标注、导出到评测集，进行系统化的应用效果评估。
- **工作流调试**：工作流应用中需要查看各节点（API、分类器、脚本、条件判断等）的执行状态。

### 组合使用

在生产环境中，建议同时启用两套监控：

- 用**模型监控**做宏观的成本与稳定性管理，配置告警防止异常消耗。
- 用**应用监控**做微观的链路级诊断，在问题发生时快速定位根因。

## 技术选型建议

| 选型因素 | 建议 |
|---------|------|
| 仅通过 API 直接调用模型 | 使用模型监控即可满足需求 |
| 使用智能体或工作流应用 | 两者配合使用，模型监控管成本，应用监控管链路 |
| 需要自动化告警 | 优先依赖模型监控的告警体系 |
| 需要数据导出与标注 | 使用应用监控的 JSONL/EXCEL 导出和标注功能 |
| 需要对接外部监控平台 | 模型监控通过 Prometheus API 对接，应用监控通过 OpenTelemetry 服务 |
