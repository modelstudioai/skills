# 图像、视频与 3D 生成对比

百炼平台围绕视觉内容生成提供了三条独立的能力线：图像生成、视频生成与 3D 资产生成。三者虽同属"AIGC 视觉"范畴，但在调用方式、模型家族、地域限制、输出产物和典型场景上差异显著。本文横向对比这三类能力的关键维度，帮助开发者在技术选型时快速判断应选用哪条能力线，以及各自的接入成本与约束。

## 关键维度对比

| 维度 | 图像生成 | 视频生成 | 3D 生成 |
| --- | --- | --- | --- |
| 核心定位 | 文生图、图像编辑、图像翻译、创意工具 | 文生/图生/参考生视频、视频编辑、人像动画 | 文生 3D、单图/多图生 3D 资产 |
| 输入格式 | 文本提示词 / 单图或多图参考 | 文本、首帧/首尾帧图像、参考图片/视频/音频 | 文本（≤1024 字符）、单图 URL、多图数组（前左后右 4 视角） |
| 输出格式 | PNG 图片（1~9 张，最高 4K/2048px） | 视频文件（多镜头、含音频等） | 带贴图 PBR 材质 GLB 或无贴图基础模型 + 预览渲染图 |
| 调用方式 | 多为同步/快速返回（部分工具异步） | 全部**异步调用**（创建任务 → 轮询） | 全部**异步调用**（创建任务 → 轮询，约 15s 间隔） |
| 主要模型家族 | 千问 Qwen-Image、万相 Wan/Wanx、Z-Image、可灵 Kling | 万相 Wan、HappyHorse、爱诗 PixVerse、Vidu、可灵 Kling、人像动画 | Tripo（H3.1 / P1.0） |
| API 端点示例 | 图像合成接口（HTTP / [DashScope SDK](../concepts/dashscope-sdk.md)） | `.../aigc/video-generation/video-synthesis`（需 `X-DashScope-Async: enable`） | `.../aigc/video-generation/3d-generation`（需 `X-DashScope-Async: enable`） |
| 地域限制 | 主力模型多地域；部分创意工具/可灵仅北京 | 万相/HappyHorse 多地域；PixVerse/Vidu/可灵仅北京 | **仅华北2（北京）**，须用北京地域 API Key |
| 产物有效期 | 依接口而定 | 任务 `task_id` 有效期 24 小时 | 下载链接仅 **2 小时**，`task_id` 24 小时 |
| 计费方式 | 按张计费；部分工具已商业化、部分仅免费体验 | 按视频任务/模型计费 | 按任务计费（`text-to-3d` / `image-to-3d` / `multi-image-to-3d`），仅成功计数 |
| 典型场景 | 海报、电商配图、AI 试衣、图像翻译、风格化 | 短视频、数字人、口播、动作迁移、唱演动画 | 游戏/3D 资产、商品建模、AR/VR 素材 |

## 各方案适用场景建议

### 图像生成

适用于需要**静态视觉素材**的场景：文字渲染要求高时选千问 Qwen-Image 系列；追求真实质感与自由尺寸选万相 Wan 系列；需要极速轻量出图选 Z-Image；多图参考/分镜组图可用可灵 Kling。电商垂直场景（AI 试衣、虚拟模特、商品背景、海报）可直接选用创意工具模型，但需注意部分工具仅限北京地域且仅提供免费体验。调用相对轻量，多数可快速返回，接入成本最低。

### 视频生成

适用于需要**动态内容**的场景。通用文生/图生视频优先选万相 wan2.7（支持多镜头叙事、参考生视频与视频编辑）；数字人口播、唱演、动作迁移等人物场景可选万相 s2v/animate 或人像动画模型（AnimateAnyone / EMO / LivePortrait / VideoRetalk）。注意：所有视频接口均为异步，需实现"创建任务 + 轮询"逻辑；人像动画类模型还需先调用 detect 接口做合规检测；PixVerse/Vidu/可灵等第三方家族仅限北京地域并需单独开通服务。

### 3D 生成

适用于需要**三维资产**的场景，如游戏建模、商品 3D 展示、AR/VR 素材。仅 Tripo 一个家族：高精度需求（最高 200 万面）选 `Tripo/Tripo-H3.1` 并配合 `geometry_quality=ultra`；追求速度选 `Tripo/Tripo-P1.0`。输入的 `prompt`/`image`/`images` 三者互斥。约束最严格：仅北京地域、异步调用、产物下载链接仅 2 小时有效，需在拿到结果后立即下载并转存。

## 技术选型参考

- **接入复杂度**：图像生成最低（多为快速返回）；视频与 3D 均为异步，需实现轮询或回调机制，工程成本更高。
- **地域约束**：若业务不在华北2（北京）地域，3D 生成完全不可用，视频生成的第三方家族（PixVerse/Vidu/可灵）也受限，选型前务必确认地域与 API Key 匹配。
- **产物时效**：3D 产物下载链接仅 2 小时，务必在任务成功后立即下载并落库，避免链接过期。
- **合规检测**：视频人像动画类（AnimateAnyone/EMO/s2v 等）需先走 detect 接口，选型时预留这步流程。
- **计费预期**：三类能力计费粒度不同——图像按张、视频按任务、3D 按任务且仅对成功结果计数；部分创意工具仅免费体验，商业化前需确认额度与付费状态。
