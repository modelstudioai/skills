# 图像生成、视频生成与3D生成对比

为帮助开发者快速理解百炼平台多模态生成能力的定位差异，明确技术选型边界，本文从输入输出、模型生态、调用机制、计费逻辑及适用场景等维度，系统对比图像生成（Image Generation）、视频生成（Video Generation）与3D生成（3D Generation）三大核心AIGC能力。本对比基于2024年Q3平台最新文档与API规范，面向实际工程集成需求设计，不涉及模型内部架构或训练细节。

| 维度 | 图像生成 | 视频生成 | 3D生成 |
|------|----------|----------|--------|
| **输入格式** | 文本（`prompt`）、单图/多图（URL 或 Base64）、涂鸦草图、文字+图像组合（如FaceChain/WordArt）；支持最多10张参考图（千问3.0） | 文本（≤5000字符）、单帧图（首帧/首尾帧）、参考视频/图像序列（`ref_video_url`/`ref_img_urls`）、音频（数字人驱动）、模板ID；**仅支持异步提交** | 文本（英文，≤100字符；中文自动翻译）或**单张RGB图像URL**（JPG/PNG，≤5MB）；不支持多图、点云、深度图、视频输入 |
| **输出格式** | PNG/JPEG（含透明通道支持）、Base64编码图像、扩图/编辑后图像；部分工具输出JSON元数据（如分割掩码） | MP4（H.264编码）、720P/1080P/4K可选；输出含`video_url`（有效期24小时）及元数据（时长、FPS、分辨率）；**无原始帧序列流式返回** | GLB（glTF Binary，含网格、纹理、PBR材质） + JSON元数据（bbox尺寸、面数、生成耗时）；**仅提供下载链接，不支持流式或分片传输** |
| **支持模型/功能体系** | 多模型并存：<br>• 通用：`qwen-image-3.0-pro`（文生图+图生图）、`wan2.7-image-pro`（4K文生图）、`kling-v3-omni-image-generation`（分镜组图）<br>• 垂直：FaceChain（人物写真）、WordArt（文字艺术）、AI试衣（商品图换模）、`wanx-x-painting`（局部重绘） | 全栈视频模型家族：<br>• 通用生成：`happyhorse-text2video`、`wan3-video-generation`（All-in-One）、`pixverse-v6-t2v`<br>• 人像驱动：`emo-v1`（唱演）、`liveportrait-v1`（播报）、`animateanyone-v1`（舞蹈）<br>• **无纯3D或物理仿真模型** | 单一模型：`tripo-1.0`（text-to-3D / image-to-3D）；**暂无其他3D模型接入计划**；不支持网格优化、UV展开、LOD生成等进阶功能 |
| **API端点与调用模式** | **同步与异步双模支持**：<br>• 同步：适用于低延迟预览（如Z-Image、千问基础文生图），需 `X-DashScope-Async: disable`<br>• 异步：强制用于编辑/扩图/精修类任务（如FaceChain、`wanx-x-painting`），需轮询 `task_id` | **强制异步调用**：<br>• 所有模型均仅支持 `X-DashScope-Async: enable`<br>• 统一端点 `/api/v1/services/aigc/video-generation/video-synthesis`（万相3.0/爱诗/HappyHorse）；数字人等旧模型仍用 `/image2video/xxx` 路径<br>• `task_id` 有效期24小时 | **标准REST同步风格（实为短时异步）**：<br>• 端点固定：`POST /v1/models/tripo-1.0:generate`<br>• 请求后立即返回任务状态（`status=processing`），需轮询 `GET /v1/tasks/{task_id}`（超时180秒）<br>• **无专用SDK封装，纯HTTP调用** |
| **计费方式** | 按**成功生成图片张数**计费（如 `wan2.7-image-pro`: ¥0.80/张；`wordart-semantic`: ¥0.24/张）；AI试衣等采用阶梯定价；免费额度按90天滚动计算 | 按**生成视频秒数**计费（如 `wan2.2-s2v` 720P ¥0.90/秒；`pixverse-v6-t2v` ¥1.20/秒）；数字人模型按“音频时长×分辨率系数”计费；并发任务数受严格限制（如LivePortrait上限1个） | 按**单次请求成功次数**计费（¥3.50/次）；无时长/分辨率细分；项目级API Key配额独立管理，控制台可查剩余额度 |
| **典型场景** | • 电商主图/详情页批量生成<br>• 社媒海报与Banner设计<br>• 个性化头像/写真定制（FaceChain）<br>• UI组件图标生成与风格迁移<br>• 图像擦除、扩图、局部重绘（营销修图） | • 短视频广告创意脚本可视化（文生视频）<br>• 产品演示动画（图生视频+特效）<br>• 数字人直播/课程播报（音频驱动）<br>• 口型同步短视频（VideoRetalk）<br>• 动作模仿与表情包生成（AnimateAnyone/Emoji） | • 游戏原型资产快速搭建（如道具、场景小物件）<br>• 工业设计概念验证（如灯具、家具草模）<br>• AR/VR内容工作流中的初始3D占位符生成<br>• 教育/科普可视化模型（如分子结构、解剖器官） |

## 各方案适用场景建议

- **选择图像生成，当您需要**：  
  ✅ 快速产出高精度静态视觉内容（如商品图、海报、头像）；  
  ✅ 对生成延迟敏感（如实时设计预览、低代码平台内嵌）；  
  ✅ 需要细粒度编辑控制（局部重绘、透明通道、多图融合）；  
  ❌ 不适合：需要时间维度表达（运动、过渡）、三维空间理解或物理交互模拟的场景。

- **选择视频生成，当您需要**：  
  ✅ 将文本/图像转化为动态叙事（广告、教程、社交短视频）；  
  ✅ 驱动数字人完成口型、表情、肢体动作同步；  
  ✅ 基于现有素材（首帧图、参考视频）生成连贯运动序列；  
  ❌ 不适合：生成静态高质量图像、构建可交互3D模型、或对帧率/编解码有定制化要求（如WebRTC流）。

- **选择3D生成，当您需要**：  
  ✅ 在AIGC工作流中快速获得可导入Blender/Unity/Unreal的GLB资产；  
  ✅ 以极低成本验证3D概念（如设计评审、AR原型测试）；  
  ✅ 输入简洁文本或单张正向照片即可启动3D建模流程；  
  ❌ 不适合：生成高精度工业级模型（需CAD兼容）、拓扑复杂的角色模型、带骨骼绑定的动画模型，或需要实时渲染优化（LOD、实例化）的场景。

## 面向开发者的选型参考

1. **优先确认输出形态本质**：  
   - 若最终交付物是**静态画面** → 图像生成；  
   - 若需**时间轴连续性与运动表现** → 视频生成；  
   - 若需**三维空间坐标、可旋转缩放、可编程交互** → 3D生成。

2. **评估输入数据完备性**：  
   - 仅有文本描述？三者均支持，但图像生成质量最稳定，3D生成对提示词专业性要求最高；  
   - 已有高质量单图？图像生成（编辑）与3D生成均可，但视频生成需额外指定运动意图；  
   - 拥有视频/音频/多视角图？仅视频生成支持，3D生成明确拒绝此类输入。

3. **关注工程集成成本**：  
   - 需要同步响应？→ 仅图像生成提供可靠同步路径；  
   - 已有异步任务队列？→ 视频生成与3D生成天然适配；  
   - 需多地域部署？→ 图像/视频生成支持北京/新加坡/美东/德/日/港六地，3D生成当前仅支持北京地域（`tripo-1.0` Endpoint限定）。

4. **警惕隐性约束**：  
   - 图像生成中，`wanx-virtualmodel`等垂直工具已停更，应迁移到千问或万相通用编辑接口；  
   - 视频生成中，数字人模型（EMO/LivePortrait）必须前置图像检测，且仅限北京地域；  
   - 3D生成中，输入图像质量直接影响几何保真度——避免透视畸变、强遮挡、低对比度素材。

> **决策树速查**：  
> 输入是文本？→ 看输出：静态图→图像生成；动态视频→视频生成；可旋转3D模型→3D生成  
> 输入是单图？→ 看目标：改风格/换背景→图像生成；加运动→视频生成；转三维→3D生成  
> 需要多人并发/低延迟？→ 优先图像生成（同步）；接受2–60秒等待？→ 视频/3D生成皆可  

本对比持续更新，最新模型支持状态与地域可用性请以[百炼控制台](https://bailian.console.aliyun.com)及各模型API参考文档为准。
