# 图像、视频与3D生成API对比

百炼平台在[多模态](../concepts/multimodal.md)内容生成领域提供了图像生成、视频生成和3D模型生成三大类API。三者均通过DashScope网关统一接入、使用[API Key](../concepts/api-key.md)鉴权，但在输入输出形态、模型生态、调用模式和适用场景上各有侧重。本文从开发者技术选型角度，对这三类生成API进行系统对比。

## 核心维度对比

| 维度 | 图像生成 | 视频生成 | 3D生成 |
| --- | --- | --- | --- |
| **输出形态** | 静态图像（PNG/JPEG） | 视频文件（MP4） | 3D模型文件（GLB），可附带PBR材质 |
| **主要模型** | 通义千问图像、万相2.6/2.7、Z-Image、可灵 | 万相wan2.7、HappyHorse、PixVerse、Vidu、可灵 | Tripo-H3.1、Tripo-P1.0 |
| **输入方式** | 文本[prompt](../guides/prompt.md)、参考图、蒙版、涂鸦 | 文本[prompt](../guides/prompt.md)、首帧图、首尾帧图、参考图/视频/音频 | 文本[prompt](../guides/prompt.md)、单图、多图（4视角） |
| **调用模式** | 同步（OpenAI兼容）+ 异步（DashScope原生） | 仅异步（必须携带X-DashScope-Async头） | 仅异步（必须携带X-DashScope-Async头） |
| **典型响应时间** | 同步：秒级；异步：10-60秒 | 1-5分钟 | 数分钟（高精度模型更长） |
| **协议支持** | OpenAI兼容模式 + DashScope原生 | DashScope原生 | DashScope原生 |
| **支持地域** | 多地域 | 万相/HappyHorse多地域；PixVerse/Vidu/可灵仅华北2 | 仅华北2（北京） |
| **模型数量** | 20+（含创意工具） | 10+（含人像动画特效） | 2个（高精度 / 专业快速） |
| **内容安全审核** | 内置，违规自动拦截 | 内置 | 内置 |
| **产物有效期** | 临时URL，需及时下载 | 临时URL，需及时下载 | 下载链接有效期2小时 |
| **task_id有效期** | 异步任务24小时 | 24小时 | 24小时 |

## 输入与输出格式对比

| 能力 | 图像生成 | 视频生成 | 3D生成 |
| --- | --- | --- | --- |
| **文本输入** | 中英文prompt，支持负面词 | 中英文prompt，支持多镜头分镜描述 | 中英文prompt，最大1024字符 |
| **图像输入** | 公网URL或Base64 | 公网URL（首帧/尾帧/参考图） | 公网URL（JPEG/PNG，20-6000px） |
| **视频输入** | 不支持 | 支持（参考视频、待编辑视频） | 不支持 |
| **音频输入** | 不支持 | 支持（数字人、口型替换等） | 不支持 |
| **多图输入** | 部分支持（参考图引导） | 支持（多参考图融合） | 固定4视角（前/左/后/右） |
| **输出控制** | 尺寸、长宽比、风格、采样参数 | 分辨率（480P/540P/720P）、时长 | 贴图质量、几何精度、是否PBR材质 |

## API端点对比

| 类型 | 端点路径 |
| --- | --- |
| 图像生成（OpenAI兼容） | `/compatible-mode/v1/images/generations` |
| 图像生成（DashScope原生） | `/api/v1/services/aigc/text2image/image-synthesis` |
| 视频生成（主流） | `/api/v1/services/aigc/video-generation/video-synthesis` |
| 视频生成（早期模型） | `/api/v1/services/aigc/image2video/video-synthesis` |
| 3D生成 | `/api/v1/services/aigc/video-generation/3d-generation` |
| 异步任务轮询（通用） | `/api/v1/tasks/{task_id}` |

## [计费](../concepts/billing.md)与配额

三类API均按调用次数或生成量[计费](../concepts/billing.md)，具体费率因模型而异。共同点包括：

- 统一使用[API Key](../concepts/api-key.md)鉴权，在百炼控制台获取
- 存在QPS/并发限制，超限返回429错误
- 部分模型需在控制台模型市场搜索并开通后才能调用
- 支持通过[业务空间](../concepts/workspace.md)专属域名获得更好的性能隔离

## 模型生态丰富度

| 类别 | 自研模型 | 第三方/合作模型 | 垂类工具 |
| --- | --- | --- | --- |
| 图像 | 通义千问图像、万相系列 | Z-Image、可灵 | 虚拟模特、AI试衣、创意海报、人物写真等11种 |
| 视频 | 万相wan系列 | HappyHorse、PixVerse、Vidu、可灵 | 舞动人像、悦动人像、灵动人像、声动人像、表情包、视频风格重绘 |
| 3D | 无自研 | Tripo | 无 |

## 适用场景建议

**选择图像生成API的场景：**

- 电商商品图、营销海报、社交媒体配图等需要静态视觉素材的场景
- 需要对已有图像进行编辑、局部重绘、背景替换、风格转换的场景
- 人像相关应用：写真、虚拟模特、AI试衣、风格重绘
- 对响应速度要求高（秒级返回）的实时交互场景
- 需要OpenAI兼容协议以降低迁移成本的场景

**选择视频生成API的场景：**

- 短视频内容创作、广告素材生成
- 数字人直播、虚拟主播、有声视频制作
- 需要从静态素材（图片）生成动态内容的场景
- 人物动作迁移、视频换人等特效需求
- 多镜头叙事和分镜视频创作

**选择3D生成API的场景：**

- 游戏/AR/VR应用中快速生成3D资产
- 电商商品的3D展示和交互预览
- 从概念草图或参考图快速生成3D原型
- 需要PBR材质的高质量3D模型（选Tripo-H3.1，最高200万面）
- 追求生成速度时选Tripo-P1.0（最高2万面）

## 技术选型决策参考

1. **按输出形态选择**：需要静态图选图像API，需要动态内容选视频API，需要三维模型选3D API。
2. **按响应时效选择**：图像生成支持同步调用（秒级），适合实时交互；视频和3D均为异步，适合离线或后台处理。
3. **按地域要求选择**：图像生成和部分视频模型支持多地域部署；3D生成和部分视频模型仅限华北2（北京），海外业务需注意地域限制。
4. **按模型丰富度选择**：图像和视频生态成熟，模型选择多；3D目前仅有Tripo系列，选择较少但能力聚焦。
5. **按集成复杂度选择**：图像API提供OpenAI兼容模式，集成最简单；视频和3D均需实现异步轮询逻辑。
