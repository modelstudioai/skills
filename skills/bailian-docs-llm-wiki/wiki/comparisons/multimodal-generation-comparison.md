# 图像生成、视频生成与 3D 生成对比

百炼平台提供图像生成、视频生成和 3D 生成三大[多模态](../concepts/multimodal.md)内容创作能力，分别面向静态视觉素材、动态影像和三维资产的生产需求。三者在输入方式、输出格式、模型生态、调用模式和计费体系等方面存在显著差异。本文从开发者技术选型的角度，对这三类能力进行系统对比，帮助开发者根据业务场景选择合适的生成方案。

## 关键维度对比

| 维度 | 图像生成 | 视频生成 | 3D 生成 |
|------|---------|---------|---------|
| **核心模型** | 千问(Qwen-Image)、万相(Wan/Wanx)、Z-Image、可灵(Kling) | 万相(Wan) 2.7、HappyHorse、Pixverse、Vidu、Kling | Tripo (Tripo-H3.1 / Tripo-P1.0) |
| **输入方式** | 文本 [prompt](../guides/prompt.md)、参考图片、涂鸦草图 | 文本 [prompt](../guides/prompt.md)、首帧图片、参考图/视频、关键帧序列、音频 | 文本 [prompt](../guides/prompt.md)、单张图片、多图(4视角) |
| **输出格式** | PNG 图片（512x512 至 4K） | MP4 视频（通常 5-10 秒） | GLB 三维模型（含/不含 PBR 贴图） |
| **调用模式** | 同步调用为主，部分模型支持异步 | 全部异步（创建任务 → 轮询获取） | 全部异步（创建任务 → 轮询获取） |
| **典型响应时间** | 秒级（数秒至十余秒） | 分钟级（1-5 分钟） | 分钟级（需轮询，建议间隔 15 秒） |
| **单次产出数量** | 1-9 张（模型不同） | 1 段视频 | 1 个 3D 模型 + 1 张渲染预览图 |
| **SDK 支持** | HTTP / [DashScope SDK](../concepts/dashscope-sdk.md) / OpenAI 兼容 SDK | HTTP / [DashScope SDK](../concepts/dashscope-sdk.md) / OpenAI 兼容 SDK（部分模型） | HTTP（仅异步） |
| **支持地域** | 部分模型仅限华北2（北京） | 部分模型仅限华北2（北京）或新加坡 | 仅限华北2（北京） |
| **计费方式** | 按张计费，部分模型免费体验 | 按任务/时长计费 | 按任务计费 |
| **产物有效期** | 即时返回，永久可用 | 任务 ID 有效期内下载 | 下载链接有效期 2 小时，task_id 有效期 24 小时 |

## 能力矩阵对比

| 子能力 | 图像生成 | 视频生成 | 3D 生成 |
|--------|---------|---------|---------|
| 文本驱动生成 | 支持（文生图） | 支持（文生视频） | 支持（文生 3D） |
| 图片驱动生成 | 支持（图生图/图像编辑） | 支持（图生视频/首帧驱动） | 支持（单图/多图生 3D） |
| 内容编辑 | 支持（局部重绘、风格迁移、扩图、超分） | 支持（视频重绘、风格转换、口型替换） | 不支持（需重新生成） |
| 文字渲染 | 支持（千问系列擅长） | 不适用 | 不适用 |
| 图像翻译 | 支持（qwen-mt-image 系列） | 不适用 | 不适用 |
| 数字人/动作 | 不适用 | 支持（AnimateAnyone、LivePortrait、EMO、数字人 S2V） | 不适用 |
| PBR 材质输出 | 不适用 | 不适用 | 支持（可选开关） |

## 适用场景建议

### 图像生成

适合需要快速产出高质量静态视觉素材的场景：

- **电商运营**：商品背景生成、海报排版、AI 试衣、虚拟模特
- **内容创作**：插画生成、艺术风格转换、涂鸦转精细图
- **多语言场景**：图片中文字的精准翻译与排版保持
- **图像后处理**：局部重绘、画面扩展、超分辨率增强

图像生成响应速度最快（秒级），模型选择最丰富，适合对实时性要求较高、需要大批量素材生产的业务。

### 视频生成

适合需要动态影像内容的场景：

- **短视频制作**：基于文本或图片快速生成短视频片段
- **数字人直播/营销**：音频/文本驱动虚拟主播，口型同步
- **服装/产品展示**：让静态商品图变为动态展示视频
- **创意广告**：风格化转换、关键帧精确控制镜头运动

视频生成耗时较长（分钟级），但模型生态丰富，覆盖从基础文生视频到精细编辑的全链路需求。多个模型厂商（万相、HappyHorse、Pixverse、Vidu、Kling）可按效果和成本灵活选择。

### 3D 生成

适合需要三维资产的场景：

- **游戏/XR 开发**：快速原型建模，生成带 PBR 材质的可用资产
- **电商 3D 展示**：从商品图片一键生成 3D 展示模型
- **工业设计预览**：文本描述或草图快速转为三维概念模型

3D 生成当前模型选择较少（仅 Tripo 系列），地域限制最严格（仅北京），但产出的 GLB 格式模型可直接用于主流 3D 引擎和渲染管线。高精度模型（Tripo-H3.1）最高支持 200 万面，能满足较高质量要求。

## 技术选型参考

在选择[多模态](../concepts/multimodal.md)生成能力时，建议从以下维度综合评估：

1. **输出类型**：明确业务需要的是静态图片、动态视频还是三维模型，这是最基本的筛选条件。
2. **实时性要求**：如果需要秒级响应（如在线编辑器），优先选择图像生成；如果可以接受分钟级延迟（如离线批处理），视频和 3D 生成均可考虑。
3. **地域限制**：3D 生成仅支持北京地域，部分图像和视频模型也有地域限制，需确保 [API Key](../concepts/api-key.md) 和调用域名与模型所在地域一致。
4. **编辑需求**：如果需要对已有内容进行精细编辑（局部修改、风格转换），图像生成和视频生成的编辑能力更成熟；3D 资产目前不支持增量编辑。
5. **模型成熟度**：图像生成模型迭代最快，选择最多；视频生成次之；3D 生成仍处于相对早期阶段，模型数量有限。
6. **成本控制**：三者均按任务或产出数量计费，实际单价差异较大。建议先使用免费额度或体验版模型进行效果验证，再决定正式接入方案。
