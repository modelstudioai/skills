# [多模态](../concepts/multimodal.md)内容生成 API 对比

百炼平台提供图像生成、视频生成和 3D 模型生成三大类[多模态](../concepts/multimodal.md)内容生成能力。三者在输入形式、输出产物、模型生态、调用方式和适用场景上存在显著差异。本文从开发者技术选型角度，对这三类 API 进行系统对比，帮助快速定位最适合业务需求的接口。

## 核心维度对比

| 维度 | 图像生成 | 视频生成 | 3D 模型生成 |
| --- | --- | --- | --- |
| **输入形式** | 文本 [prompt](../guides/prompt.md)、参考图片、涂鸦草图、待编辑图片 | 文本 [prompt](../guides/prompt.md)、首帧图片、参考图/视频、音频、关键帧序列 | 文本 [prompt](../guides/prompt.md)、单张图片、多图（4 视角） |
| **输出产物** | PNG 图片（512x512 至 4K） | MP4 视频（通常 5-10 秒） | GLB 3D 模型（含 PBR 材质贴图或无贴图基础模型）+ 预览渲染图 |
| **调用模式** | 同步或异步（视模型而定） | 全部异步（创建任务 + 轮询获取） | 全部异步（创建任务 + 轮询获取） |
| **典型响应时间** | 秒级至数十秒 | 1-5 分钟 | 数分钟（建议 15 秒间隔轮询） |
| **主力模型系列** | 千问 Qwen-Image、万相 Wan/Wanx、Z-Image、可灵 Kling | 万相 Wan 2.7、HappyHorse、Pixverse、Vidu、Kling | Tripo H3.1、Tripo P1.0 |
| **模型数量** | 20+ 款（含创意工具） | 10+ 款（含数字人、动作、表情类） | 2 款 |
| **可用地域** | 部分模型限北京地域，核心模型多地域可用 | 部分模型限北京地域 | 仅限华北2（北京） |
| **鉴权方式** | DashScope API Key（Bearer Token） | DashScope API Key（Bearer Token） | DashScope API Key（Bearer Token） |
| **SDK 支持** | HTTP / [DashScope SDK](../concepts/dashscope-sdk.md) | HTTP / OpenAI 兼容 SDK（部分模型） | HTTP |
| **产物有效期** | 即时返回，无过期限制 | 异步结果 URL 有时效 | 下载链接有效期 2 小时，task_id 有效期 24 小时 |
| **批量输出** | 单次可生成 1-9 张（视模型） | 单次生成 1 条视频 | 单次生成 1 个模型 |

## 能力细分对比

| 子能力 | 图像生成 | 视频生成 | 3D 生成 |
| --- | --- | --- | --- |
| 文本直接生成 | 支持（文生图，模型最丰富） | 支持（文生视频） | 支持（文生 3D） |
| 图片驱动生成 | 支持（图生图、图像编辑、风格迁移） | 支持（图生视频、首帧驱动） | 支持（单图/多图生 3D） |
| 多参考输入 | 支持（多图参考生成、组图） | 支持（多参考图/视频驱动） | 支持（4 视角多图，前/左/后/右） |
| 内容编辑 | 支持（局部重绘、扩图、超分、文字替换） | 支持（视频重绘、风格转换、口型替换） | 不支持 |
| 文字渲染 | 支持（中英文字渲染是优势能力） | 不适用 | 不适用 |
| 数字人/动作 | 不适用 | 支持（AnimateAnyone、LivePortrait、EMO、数字人 S2V） | 不适用 |
| 材质与质量控制 | 分辨率、张数可配置 | 分辨率、时长、种子可配置 | 贴图质量（standard/detailed）、几何精度（standard/ultra）、PBR 材质开关 |

## 计费模式对比

| 维度 | 图像生成 | 视频生成 | 3D 生成 |
| --- | --- | --- | --- |
| 计费单位 | 按张计费（部分模型如扩图 0.18 元/张） | 按任务/时长计费 | 按任务计费 |
| 免费体验 | 部分创意工具模型仅提供免费体验额度 | 部分模型提供免费体验 | 需在控制台开通服务 |
| 商业化状态 | 核心模型已商业化，部分垂直工具仅免费体验 | 核心模型已商业化 | 已商业化 |

## 适用场景建议

**选择图像生成 API 的场景：**

- 需要快速生成营销素材、产品展示图、海报、插画等静态视觉内容
- 需要对已有图片进行精细编辑（局部修改、扩图、风格迁移、文字替换）
- 电商场景下的商品背景生成、虚拟试衣、虚拟模特
- 需要在图片中精准渲染中英文文字
- 对响应速度要求高（秒级返回）

**选择视频生成 API 的场景：**

- 需要生成短视频广告、产品展示动画、创意视频内容
- 数字人驱动场景（虚拟主播、AI 说话人、音频驱动口型）
- 需要将静态图片转为动态视频（图生视频）
- 需要对已有视频进行风格化处理或口型替换
- 多关键帧控制的精细视频生成需求

**选择 3D 模型生成 API 的场景：**

- 需要快速生成 3D 资产用于游戏、AR/VR、电商 3D 展示
- 从产品照片自动生成可交互的 3D 模型
- 需要带 PBR 材质的高精度 3D 模型（最高 200 万面）
- 3D 内容创作流水线中的原型快速生成

## 技术选型决策参考

1. **产物类型决定方向**：需要静态图选图像生成，需要动态内容选视频生成，需要三维资产选 3D 生成。
2. **响应时间敏感度**：图像生成响应最快（秒级），视频和 3D 均为分钟级异步任务。如果业务对实时性要求高，优先考虑图像生成。
3. **模型丰富度**：图像生成的模型和子能力最为丰富，视频生成次之，3D 生成目前仅有 Tripo 系列 2 款模型。
4. **地域限制**：3D 生成仅限北京地域，图像和视频生成的核心模型多地域可用。部署在海外的服务需注意地域兼容性。
5. **集成复杂度**：图像生成部分模型支持同步调用，集成最简单；视频和 3D 均需实现异步轮询逻辑，建议封装统一的任务管理层。
6. **组合使用**：三类 API 可串联使用。例如先用图像生成产出高质量概念图，再用图生视频将其动态化，或用单图/多图生成 3D 模型，构建完整的[多模态](../concepts/multimodal.md)内容生产流水线。
