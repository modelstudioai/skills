# 模型评测与模型监控对比

模型评测与模型监控是百炼平台中两个容易混淆但目标截然不同的能力。**模型评测**关注"模型好不好"——基于数据集对大语言模型进行多维度量化评估，输出综合得分、通过率等质量指标，服务于模型选型、调优验证和能力量化；**模型监控**关注"模型跑得稳不稳"——围绕模型调用量与运行状态提供分钟级指标、调用日志、Token 追踪与主动告警，服务于成本核算与稳定性保障。前者是上线前的"质量验收"，后者是上线后的"运行观测"。本文从输入输出、支持模型、计费方式、典型场景等维度做对比，供开发者在技术选型时参考。

## 关键维度对比

| 维度 | 模型评测 | 模型监控 |
| --- | --- | --- |
| 核心目标 | 模型质量验证（好不好） | 模型运行观测（稳不稳） |
| 所处阶段 | 上线前 / 选型 / 调优验证 | 上线后 / 持续运行 |
| 输入 | 评测数据集（Excel，含 Prompt / Completion 列）或预置基线数据集 | 模型实际调用产生的运行数据（系统自动采集，无需用户准备） |
| 输出 | 评测报告：综合得分、通过率、分数分布、明细数据；基线评测含分学科得分、能力雷达图、行业对比 | 监控看板：调用总量、失败量、失败率、平均调用时长、平均首包时长、Token 消耗、告警通知 |
| 评测/监控类型 | 自定义评测（5 种维度）、基线评测（学科/数学/推理预置数据集） | 普通监控、高级监控、告警、日志（推理/审计日志） |
| 支持模型 | 自定义评测：千问系列、开源版、通义法睿及部分第三方文本模型；基线评测仅支持调优后模型 | 用量统计：所有模型；普通监控：所有地域所有模型；高级监控：北京/新加坡/弗吉尼亚；告警：仅北京/新加坡；日志：仅北京地域部分模型 |
| 数据粒度 | 按数据集样本条数（建议 50–500+ 条）评分 | 分钟级（高级监控）/ 小时级（普通监控、用量统计） |
| 数据延迟 | 任务执行完毕即出结果（高峰时段排队） | 用量约 1 小时；普通监控小时级；高级监控分钟级 |
| 费用归属 | System Prompt 产生被评测模型推理费用；评分器 Prompt 产生裁判模型评分费用 | 用量统计本身不计费，仅按模型调用的实际 Token/张/秒计费；高级监控与告警不额外计费 |
| 操作入口 | 模型评测页面，创建评测任务 | 模型用量页 / 模型监控页（按"模型 + 业务空间"列表） |
| 结果查看 | 数据明细 Tab + 指标统计 Tab（综合得分、通过率） | 监控详情页：安全/成本/性能/错误四类指标；调用统计页签；Token 消耗汇总与追踪 |
| 业务空间维度 | 不按业务空间维度统计 | 按业务空间维度统计；用量不支持按阿里云账号维度汇总 |
| 历史数据范围 | 任务结果长期保留 | 用量/调用统计近 30 天；更早数据需到费用与成本页面查询 |
| 主动通知能力 | 无（需手动查看结果） | 支持主动告警（Token 消耗阈值、超时、突增等静默失败） |

## 适用场景建议

### 选模型评测的场景

- 上线前需要量化对比多个候选模型（如 Qwen3-Max vs Qwen-Plus vs 开源版）的问答质量、安全性、专业能力。
- 调优后验证模型在特定业务数据集上的表现是否达标。
- 验证模型通用能力（学科、数学、推理）与业界标准榜单对比，使用基线评测。
- 需要 AI 裁判按数值/分类维度自动打分，或对 Function Calling、NL2SQL 做精确字符串匹配验证。
- 需要人工对创意性、专业判断类输出打标签。

### 选模型监控的场景

- 模型已上线运行，需要观测调用失败率、平均调用时长、首 Token 延时、RPM/TPM 等稳定性指标。
- 需要按业务空间或 API Key 核算 Token / 张 / 秒的用量成本。
- 需要在 Token 消耗突增、超时、限流（429）等异常时主动告警，避免静默失败。
- 需要审计具体调用的输入输出内容（推理日志、历史对话），用于故障排查或内容审计。
- 需要管理免费额度，开启"用完即停"避免意外费用。

### 二者互补使用

实际工程中两者往往配合使用：上线前用模型评测完成质量验收与选型决策，上线后用模型监控保障运行稳定性与成本可控。当监控发现线上质量退化（如失败率上升、用户反馈变差）时，可回到模型评测用新数据集复测，形成"评测 → 上线 → 监控 → 复测"的闭环。

## 技术选型参考

- 如果你的问题是"哪个模型更好"或"调优有没有效果"——用模型评测。
- 如果你的问题是"模型现在跑得稳不稳、花了多少钱"——用模型监控。
- 如果既要做质量验证又要做运行保障——两者并用，评测负责事前把关，监控负责事中事后观测。
- 注意地域与模型限制：基线评测仅支持调优模型；高级监控与告警仅支持北京/新加坡等地域；推理日志仅支持北京地域部分模型。具体支持清单以创建任务/监控页面显示为准。
