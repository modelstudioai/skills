# 模型评测与应用评测对比

百炼平台提供两套独立的评测体系——模型评测和应用评测，分别面向不同的验证目标。模型评测聚焦于大语言模型本身的能力验证与选型决策，而应用评测关注智能体应用和工作流应用的端到端输出质量。两者在评测对象、数据格式、评分机制和适用场景上存在显著差异，开发者需根据实际需求选择合适的评测路径。

## 核心维度对比

| 对比维度 | 模型评测 | 应用评测 |
| --- | --- | --- |
| 评测对象 | 大语言模型（千问系列、第三方文本生成模型及其调优版本） | 智能体应用、工作流应用 |
| 入口位置 | 模型评测页面 | 应用评测页面（新旧版共存，可切换） |
| 评测模式 | 自定义评测 + 基线评测 | 旧版：自动评测 + 手动评测；新版：评测集 + 评测任务 + 评估器 + 标签 |
| 数据集格式 | Excel（Prompt / Completion / Output 列） | 旧版：Excel 或 JSONL；新版：根据应用出入参自动生成或自定义列 |
| 评分体系 | 评测维度（5 种类型：大模型数值型/分类型、规则文本相似度/字符串匹配、人工分类型） | 旧版：大模型 1-5 分打分 / 人工较差-一般-较好；新版：评估器（LLM / Code / 预置模板，评分范围可自定义） |
| 裁判模型 | 自行选择裁判模型（如千问-Max），仅大模型评估类维度需要 | 旧版自动评测内置大模型评分；新版 LLM 评估器使用平台评估模型（限时免费） |
| 基准评测 | 支持基线评测（C-Eval、MMLU、ARC、GSM8K 等公开榜单） | 不支持，无预置基准数据集 |
| 结果指标 | 综合得分、通过率、分数分布、学科得分明细、能力雷达图 | 旧版：BadCase 归因分析、评测报告；新版：综合得分、评测进度、标签统计分析 |
| 排行榜 | 支持（创建任务时勾选参与排行榜） | 不支持 |
| 多版本管理 | 无评测集版本概念 | 新版评测集支持多版本发布，任务可指定具体版本 |
| 人工标注 | 支持（人工评估-分类型维度） | 旧版手动评测支持；新版通过标签系统支持（分类/布尔值/数字/文本四种标签类型） |

## 数据准备对比

| 对比项 | 模型评测 | 应用评测 |
| --- | --- | --- |
| 数据来源 | 自备 Excel 评测数据集或推理结果集；基线评测使用系统预置数据集 | 旧版：上传 Excel/JSONL 或从知识库自动生成；新版：手动上传或从应用观测拉取真实数据 |
| 建议数据量 | 小规模验证 50-100 条；正式评测 200-500 条；全面评估 500+ 条 | 无明确建议条数，视应用复杂度而定 |
| 数据集限制 | 仅支持评测集类型，不支持训练集 | 旧版单次最多 10 个文件、单文件不超过 20 MB；新版评测集类型一旦创建不可修改 |

## 评分机制对比

模型评测采用「评测维度」作为评分标准，每个维度独立配置评分方式和通过阈值，裁判模型 Prompt 支持 `${prompt}`、`${output}`、`${completion}` 三个内置变量。评分器 Prompt 与 System Prompt 分属不同配置环节，分别作用于裁判模型和被评测模型。

应用评测新版采用「评估器」作为评分标准，分为 LLM 评估器、Code 评估器和预置模板三类。评估器独立于评测任务存在，可被多个任务复用。LLM 评估器适合语义理解类场景（相关性、幻觉检测），Code 评估器适合确定性场景（格式校验、精确匹配），两者可组合使用。单个评测任务最多挂载 10 个评估器。

## 适用场景建议

**选择模型评测的场景：**

- 需要在多个候选模型之间做横向对比选型
- 调优后想量化验证能力提升幅度
- 需要用公开榜单（C-Eval、MMLU 等）评估模型通用能力
- 需要建立定期评测机制追踪模型表现趋势
- 关注模型本身的推理质量，尚未构建上层应用

**选择应用评测的场景：**

- 已构建智能体应用或工作流应用，需要验证端到端输出质量
- 需要将应用观测中的真实用户数据导入做回归评测
- 需要多人协作进行人工标注（借助标签系统）
- 希望将评分逻辑沉淀为可复用的评估器，建立长期评测体系
- 需要同时使用自动评分与人工标注混合评测

**最佳实践：** 在开发早期使用模型评测完成模型选型和调优验证，在应用构建完成后切换到应用评测进行端到端质量保障。两套评测体系互补使用，可覆盖从模型能力到应用质量的完整验证链路。

## 计费差异

| 计费项 | 模型评测 | 应用评测 |
| --- | --- | --- |
| 被评测对象推理 | 使用评测数据集时产生被评测模型推理费用 | 调用智能体/工作流时产生应用调用费用 |
| 评分模型费用 | 大模型评估类维度按裁判模型 Token 计费 | 旧版自动评测消耗 Token（失败任务已消耗部分仍计入）；新版 LLM 评估器评估模型限时免费 |
| 规则/代码评分 | 规则评估类维度无额外费用 | Code 评估器无额外费用 |
| 人工评估 | 无平台费用，但需投入人力成本 | 标签标注无平台费用，但需投入人力成本 |
