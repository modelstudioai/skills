# 模型评测与应用评测对比

百炼平台提供两套独立的评测体系：**模型评测**和**应用评测**。前者聚焦于大语言模型本身的能力验证与选型，后者面向智能体应用和工作流应用的端到端输出质量。两者在评测对象、数据准备、评分机制和适用阶段上存在显著差异，开发者需根据当前所处的开发阶段选择合适的评测方式。

## 核心维度对比

| 对比维度 | 模型评测 | 应用评测 |
| --- | --- | --- |
| 评测对象 | 大语言模型（预置模型或调优后模型） | 智能体应用、工作流应用 |
| 评测目标 | 验证模型本身的生成能力与通用能力 | 验证应用整体输出质量（含 RAG、Prompt、检索策略） |
| 评测模式 | 自定义评测 + 基线评测 | 自动评测（单应用/多应用横向）+ 手动评测 + 新版评测任务 |
| 数据来源 | 自备 Excel 评测集（Prompt/Completion/Output）或系统预置榜单数据 | 知识库自动生成评测集、手动上传、应用观测导入 |
| 数据格式 | Excel（Prompt + Completion 列） | Excel/JSONL（旧版）；智能体/工作流/自定义评测集（新版） |
| 评分机制 | 评测维度（5 种类型）：大模型评估、规则评估、人工评估 | 评估器（LLM/Code/基于历史标注）+ 人工标签 |
| 裁判模型 | 任选千问系列（如千问-Max）作为裁判 | 仅支持 qwen-max 和 qwen-plus |
| 评估器/维度数量 | 一个任务可组合多个评测维度 | 每个任务最多 10 个评估器 |
| 归因分析 | 无（仅输出得分与通过率） | 支持 BadCase 自动归因（模型理解、重排、检索、切片、知识缺失） |
| 横向对比能力 | 支持多模型在相同数据集上对比 | 多应用横向评测（最多 8 个应用） |
| 前提条件 | 模型可用即可（基线评测需先完成调优部署） | 应用已发布 + 已配置知识库 + 已开通应用观测 |
| 费用组成 | 被评测模型推理费用 + 裁判模型评分费用 | 评测 Token 费用（按 qwen-max/qwen-plus 单价计费） |
| 结果呈现 | 综合得分、通过率、数据明细、排行榜 | 评测报告、调优建议、归因分析、版本对比 |

## 评测模式详细对比

| 维度 | 模型评测 — 自定义评测 | 模型评测 — 基线评测 | 应用评测 — 自动评测 | 应用评测 — 手动评测 |
| --- | --- | --- | --- | --- |
| 需要自备数据 | 是 | 否（预置榜单） | 否（从知识库生成） | 是（人工构建评测集） |
| 支持的对象范围 | 千问系列、第三方文本生成模型及调优版 | 仅调优后模型 | 已发布的智能体应用 | 已发布的智能体应用 |
| 评分方式 | AI 裁判 + 规则 + 人工 | 预置评测规则 | 大模型自动打分 | 人工标注 |
| 自定义灵活度 | 高（自定义评分标准） | 低（行业标准） | 中（可选评估器组合） | 高（自由定义标签） |
| 输出产物 | 得分、通过率、明细 | 学科得分、雷达图、业界对比 | 评测报告 + 归因 + 调优建议 | 评测报告 |

## 适用场景建议

### 选择模型评测的场景

- **模型选型阶段**：需要在多个候选模型之间做横向能力对比，用数据驱动决策。
- **模型调优后验证**：量化调优前后的能力提升幅度（如综合得分从 75 提升到 85）。
- **通用能力基线建立**：使用 C-Eval、MMLU、GSM8K 等公开榜单验证调优模型的通用能力是否退化。
- **团队汇报**：需要综合得分、通过率等量化指标向管理层展示模型表现。

### 选择应用评测的场景

- **应用上线前质量把关**：评估智能体应用的端到端回答质量，而不仅是模型本身的能力。
- **RAG 流程优化**：通过归因分析定位问题环节（检索、重排、切片、模型理解），进行针对性优化。
- **版本迭代验证**：对比应用不同版本在同一评测基准下的表现变化。
- **多应用选型**：在最多 8 个应用之间做横向对比，选择最优方案。
- **持续监控**：在知识库更新、Prompt 调整、模型升级后触发回归评测。

### 组合使用建议

推荐的工作流为：

1. 先用**模型评测**完成底座模型选型与调优验证，确定最优模型。
2. 将模型集成进应用后，用**应用评测**验证整条链路的端到端效果。
3. 持续迭代时，模型层面的变更用模型评测验证，应用层面的变更（Prompt、知识库、检索策略）用应用评测验证。

## 技术选型速查

| 决策问题 | 推荐方案 |
| --- | --- |
| 我想对比几个模型谁更强 | 模型评测（自定义评测） |
| 我调优了模型，想看效果 | 模型评测（基线评测 + 自定义评测结合） |
| 我的智能体回答质量不稳定 | 应用评测（自动评测 + 归因分析） |
| 我想让领域专家评判回答好坏 | 应用评测（手动评测 / 标签标注） |
| 我更新了知识库，想验证影响 | 应用评测（自动评测，对比前后版本） |
| 我想建立定期质量巡检机制 | 模型评测（固定数据集月度对比）+ 应用评测（回归评测） |
