# 模型评测 vs 应用评测

百炼平台提供两套独立的评测体系——模型评测和应用评测，分别面向不同的评估对象和使用场景。模型评测聚焦于大语言模型本身的能力验证，帮助开发者在选型和调优阶段做出数据驱动的决策；应用评测则面向构建在模型之上的智能体应用和工作流应用，评估端到端的应用输出质量。理解两者的差异，是正确规划评测策略的前提。

## 关键维度对比

| 维度 | 模型评测 | 应用评测 |
|------|----------|----------|
| **评测对象** | 大语言模型（预置模型或调优模型） | 智能体应用、工作流应用 |
| **核心目标** | 量化模型在特定任务上的能力表现 | 评估应用端到端的输出质量与 RAG 效果 |
| **评测模式** | 自定义评测、基线评测 | 自动评测（单应用/多应用横评）、手动评测、新版评测任务 |
| **评测数据来源** | 评测数据集（含 [prompt](../guides/prompt.md) + 参考答案）或推理结果集 | 知识问答集（自动生成）、对话分析集（手动上传）、新版评测集（智能体/工作流/自定义） |
| **数据格式** | Excel 文件 | `.xls`/`.xlsx`（对话分析）、`.jsonl`（知识问答）、新版支持按应用出入参定义 |
| **评分机制** | 大模型裁判打分、规则评估（文本相似度/字符串匹配）、人工评估 | LLM 评估器、Code 评估器、基于历史标注的评估器、人工标签标注 |
| **评分维度上限** | 可组合多个评测维度（无明确上限） | 每个评测任务最多 10 个评估器 |
| **支持的模型** | 千问系列、千问开源版、通义法睿及部分第三方文本生成模型 | 评测执行仅支持 qwen-max 和 qwen-plus |
| **归因分析** | 不支持 | 支持自动归因（模型理解有误、重排不佳、检索无效、切片不完整、未获取知识） |
| **排行榜** | 支持多模型同维度排行对比 | 支持多应用横向评测对比 |
| **前提条件** | 需准备评测数据集或推理结果集 | 应用必须已发布、已配置知识库、已开通应用观测（自动评测） |
| **计费方式** | 被评测模型推理费用 + 裁判模型评分费用 | 评测产生的 Tokens × 模型调用单价 |
| **产物输出** | 综合得分、通过率、分数分布、数据明细、排行榜 | 评测报告、归因分析、调优建议、版本对比 |

## 评测流程对比

| 阶段 | 模型评测 | 应用评测 |
|------|----------|----------|
| **准备** | 定义评测维度 + 准备测试数据 | 发布应用 + 配置知识库 + 开通应用观测 |
| **创建任务** | 选择模型 → 选择数据 → 选择维度 | 选择应用 → 配置评测集 → 添加评估器/标签 |
| **执行** | 系统自动推理并评分 | 自动评测由系统完成，手动评测需人工标注 |
| **结果分析** | 查看得分、通过率、分数分布 | 查看报告、归因分析、获取调优建议 |

## 适用场景建议

### 选择模型评测的场景

- **模型选型**：需要在多个候选模型之间横向对比，选出最适合业务的基座模型。
- **调优验证**：完成模型微调后，量化验证调优前后的效果差异。
- **基线能力验证**：使用标准数据集（C-Eval、MMLU、GSM8K 等）快速评估调优模型的通用能力。
- **能力量化汇报**：需要生成包含综合得分和分数分布的评测报告，作为团队决策依据。

### 选择应用评测的场景

- **RAG 应用质量保障**：评估智能体在知识检索、理解、生成各环节的端到端表现。
- **应用版本迭代验证**：对同一应用的不同版本进行横向对比，验证优化效果。
- **问题定位与归因**：需要定位应用输出质量问题的具体环节（检索、重排、模型理解等）。
- **多应用选型**：在多个智能体应用之间对比，选择最优方案。
- **领域专家评审**：需要人工标注和主观判断的专业场景。

### 建议组合使用

在实际项目中，两种评测往往需要配合使用：先通过模型评测选定基座模型并完成调优验证，再将模型集成到应用中后，通过应用评测验证端到端效果并持续优化。模型评测解决"模型够不够好"的问题，应用评测解决"应用整体表现是否达标"的问题。

## 技术选型参考

| 决策问题 | 推荐方案 |
|----------|----------|
| 在千问 Max、Plus、Turbo 之间选一个 | 模型评测（自定义评测） |
| 验证微调模型是否比基线更好 | 模型评测（基线评测 + 自定义评测） |
| 智能体回答质量下降，排查原因 | 应用评测（自动评测 + 归因分析） |
| 对比两个版本的智能体应用 | 应用评测（多应用横向评测） |
| 知识库更新后验证应用效果 | 应用评测（自动评测） |
| 评估输出格式是否符合规范 | 应用评测（Code 评估器） |
| 需要领域专家主观打分 | 应用评测（手动评测 / 标签标注） |
