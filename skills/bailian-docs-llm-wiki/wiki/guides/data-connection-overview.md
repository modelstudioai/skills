# data connection overview

数据连接是阿里云百炼平台管理外部数据源的统一入口。通过创建数据连接器，百炼应用可以安全地访问企业数据库、文档系统和对象存储中的数据，在对话中实时查询和引用外部信息。连接器分为**平台托管**（文件、表格）和**流处理**（MySQL、PostgreSQL、PolarDB-X 2.0、语雀、OSS）两大类，详见[数据连接](../../raw/application-user-guide/data-connection-overview/data-connection.md)。

## 连接器类型

| 类别 | 连接器 | 数据存储方式 | 适用场景 |
|------|--------|-------------|---------|
| 平台托管 | 文件 | 百炼平台或自有 OSS | 上传管理非结构化文档（PDF、Word、Markdown 等） |
| 平台托管 | 表格 | 百炼平台或自有 OSS | 导入查询结构化表格数据（CSV、Excel 等） |
| 流处理 | MySQL | 数据保留在原库，实时访问 | 连接 MySQL 并执行 SQL 查询（仅 DMS 导入方式） |
| 流处理 | PostgreSQL | 数据保留在原库，实时访问 | 连接 PostgreSQL 并执行 SQL 查询（仅 DMS 导入方式） |
| 流处理 | PolarDB-X 2.0 | 数据保留在原库，实时访问 | 连接阿里云 PolarDB-X 2.0 分布式数据库 |
| 流处理 | 语雀 | 数据保留在语雀，实时访问 | 访问语雀文档和知识库（仅公网版本） |
| 流处理 | OSS | 数据保留在 OSS，实时访问 | 访问对象存储中的文件 |

> **注意**：MySQL、PostgreSQL、PolarDB-X 2.0 三种流处理连接器，仅通过**从 DMS 导入数据源**方式创建时才支持执行 SQL 查询。通过"创建自定义数据源"方式添加的连接器不支持直接执行 SQL。

## 前置条件

使用数据连接功能需要主账号或具有数据连接管理权限的 RAM 用户。各连接器的数据源准备要求如下：

- **文件/表格**：已准备好文档或表格文件，或已创建 OSS Bucket
- **MySQL**：已有 MySQL 实例（阿里云 RDS 或自建），网络可达
- **PostgreSQL**：已有 PostgreSQL 实例，且 `wal_level` 参数设置为 `logical`
- **PolarDB-X 2.0**：已有阿里云 PolarDB-X 2.0 实例，所在地域支持私网访问
- **语雀**：已有语雀知识库（仅公网版本），并获取个人访问 Token
- **OSS**：已创建 OSS Bucket 并开通向量检索服务

## 创建连接器

在百炼控制台的[数据连接](../../raw/application-user-guide/data-connection-overview/data-connection.md)页面，点击**创建连接器**后选择类型并填写配置。

### 文件与表格连接器

文件和表格连接器均属于平台托管类型，创建流程相似：

1. 填写连接器名称和描述（描述会影响应用调用准确度，建议写明数据内容和用途）
2. 选择存储位置：
   - **平台存储**：文件连接器提供最大 100,000 个文件 / 1 TB 额度（限时免费）；表格连接器提供 1 TB 免费额度
   - **自有 OSS**：需完成授权，目标 Bucket 添加 `bailian-connector-access` 标签（值为 `ReadAndWrite`）

### 数据库连接器（MySQL / PostgreSQL / PolarDB-X 2.0）

三种数据库连接器均支持两种数据来源方式：

- **创建自定义数据源**：手动配置连接信息，通过 SLR 授权关联数据库实例
- **从 DMS 导入数据源**：快速导入 DMS 已有数据源，首次使用需完成相应 SLR 授权

关键差异：

| 差异项 | MySQL | PostgreSQL | PolarDB-X 2.0 |
|--------|-------|------------|----------------|
| 默认端口 | 3306 | 5432 | 自动获取 |
| 网络类型 | 公网/私网 | 公网/私网 | 仅私网 |
| 数据源范围 | RDS 或自建 | RDS 或自建 | 仅阿里云 PolarDB-X 2.0 |
| 连通性检测 | EventBridge | DTS | EventBridge |
| 特殊要求 | 无 | `wal_level` 设为 `logical` | 需 DTS + PolarDB-X SLR 授权 |

### 语雀连接器

仅支持公网版本语雀。创建时需填写从语雀开放 API 获取的 Tenant access token，并通过连接检测验证有效性。

### OSS 连接器

选择要连接的 OSS Bucket 即可。需注意：

- 目标 Bucket 需添加 `bailian-datahub-access` 标签（值为 `read`）
- 需开通向量检索服务，否则调用时会报错
- 不支持归档、冷归档或深度冷归档存储类型
- 支持内容加密和私有 Bucket
- 使用了 Referer 防盗链的 Bucket 需将 `*.console.aliyun.com` 加入白名单

## 导入数据

### 文件导入

进入文件连接器详情页后，在类目下选择或新建类目，然后导入数据。支持多种解析方式：

| 解析方式 | 说明 |
|----------|------|
| 电子文档解析 | 基础解析，不支持插图与图表 |
| 文档智能解析 | 识别插图文本并生成摘要，参与知识库检索 |
| 大模型文档解析 | 支持用户对插图和图表内容提问 |
| Qwen VL 解析 | 仅支持图片格式，可通过 Prompt 指定识别内容 |
| 音视频解析 | 语音识别 + 视频帧提取 + 剧情解析，按时间轴对齐 |

可选配置标签，通过 API 调用应用时在 `tags` 参数中指定标签可提高检索效率。

> **注意**：平台不支持直接导入 JSON、CSV、YAML 格式文件，需先转换为 XLSX 或 XLS 格式。

### 表格导入

进入表格连接器详情页后，可导入到新数据表或已有数据表：

- **直接上传 Excel**：平台自动识别表头创建数据表结构
- **自定义表头**：手动配置列名（必填）、描述（选填）、类型（必填）

> **注意**：数据表结构一旦确定无法修改，上传文件的列数和列名必须与数据表完全一致。若字段类型设为 `image_url`，需确保链接是公开可访问的图片 URL。

## 限制与注意事项

- 文件导入后作为独立副本存储，与原始数据无关联
- 仅支持查看最近 **90 天**内导入的文件（超期不可查看但不删除）
- 导入的文件仅供当前[业务空间](../concepts/workspace.md)使用，不对外公开
- 在请求高峰时段，文件解析可能需要数小时

更多详细操作步骤和配置说明，请参阅[数据连接](../../raw/application-user-guide/data-connection-overview/data-connection.md)原始文档。
