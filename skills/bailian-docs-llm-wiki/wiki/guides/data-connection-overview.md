# data connection overview

数据连接是阿里云百炼平台管理外部数据源的统一入口。通过创建数据连接器，百炼应用可以安全地访问企业数据库、文档系统和对象存储中的数据，在对话中实时查询和引用这些数据。详细概念与操作流程参见[数据连接](../../raw/application-user-guide/data-connection-overview/data-connection.md)。

## 连接器类型

数据连接器按数据存储和访问方式，分为**平台托管**与**流处理**两大类，共 7 种连接器类型：

| 类别 | 连接器类型 | 数据存储方式 | 适用场景 |
| --- | --- | --- | --- |
| 平台托管 | 文件 | 百炼平台或自有 OSS | 上传管理非结构化文档（PDF、Word、Markdown 等） |
| 平台托管 | 表格 | 百炼平台或自有 OSS | 导入和查询结构化表格数据（CSV、Excel 等） |
| 流处理 | MySQL | 数据保留在原数据库，实时访问 | 连接 MySQL 数据库，执行 SQL 查询 |
| 流处理 | PostgreSQL | 数据保留在原数据库，实时访问 | 连接 PostgreSQL 数据库，执行 SQL 查询 |
| 流处理 | PolarDB-X 2.0 | 数据保留在原数据库，实时访问 | 连接阿里云 PolarDB-X 2.0 分布式数据库 |
| 流处理 | 语雀 | 数据保留在语雀，实时访问 | 访问语雀文档和知识库 |
| 流处理 | OSS | 数据保留在 OSS，实时访问 | 访问对象存储中的文件 |

> **注意**：MySQL、PostgreSQL、PolarDB-X 2.0 三种数据库连接器仅通过**从 DMS 导入数据源**方式创建时才支持执行 SQL 查询；通过**创建自定义数据源**方式添加的连接器不支持直接执行 SQL。

## 前置条件

创建数据连接器前需满足：

- **账号权限**：主账号或具有数据连接管理权限的 RAM 用户。RAM 用户需主账号授权，授权方法参见[数据连接](../../raw/application-user-guide/data-connection-overview/data-connection.md)中的权限管理说明。
- **数据源准备**：
  - 文件/表格连接器：准备好要上传的文件，或已创建 OSS Bucket。
  - MySQL 连接器：已有 MySQL 实例（阿里云 RDS 或自建），并确保网络可达。
  - PostgreSQL 连接器：已有 PostgreSQL 实例，且已将 `wal_level` 参数设置为 `logical`。
  - PolarDB-X 2.0 连接器：已有阿里云 PolarDB-X 2.0 实例，所在地域支持私网访问。
  - 语雀连接器：已有语雀知识库（仅支持公网版本），并获取个人访问 Token。
  - OSS 连接器：已创建 OSS Bucket，并开通向量检索服务。

## 关键参数与差异

### MySQL vs PostgreSQL

| 差异项 | MySQL | PostgreSQL |
| --- | --- | --- |
| 默认端口 | 3306 | 5432 |
| 额外必填字段 | 无 | 需填写 dbName（数据库名称） |
| 连通性检测服务 | EventBridge | DTS（数据传输服务） |
| 特殊配置要求 | 无 | 需将 `wal_level` 修改为 `logical` |

PostgreSQL 自建实例还需配置 `listen_addresses`，允许 `100.64.0.0/16` 网段访问：在 `pg_hba.conf` 顶部添加 `host [数据库名] [用户名] 100.64.0.0/16 md5`，并 `sudo systemctl reload postgresql` 重载配置。

### PolarDB-X 2.0 与 MySQL 的差异

- **网络类型**：仅支持私网，不支持公网。
- **数据源**：仅支持阿里云 PolarDB-X 2.0 实例，不支持自建数据库。
- **SLR 授权**：首次使用需显式同意 DTS 与 PolarDB-X 服务管理角色（DMS 方式还需 DMS 角色）的授权。

### OSS 连接器限制

- 目标 Bucket 需添加 `bailian-datahub-access` 标签（值为 `read`）。
- 不支持归档、冷归档或深度冷归档存储类型的 Bucket。
- 支持内容加密的 Bucket 和私有 Bucket。
- 如需使用开启 Referer 防盗链的 Bucket，须将域名 `*.console.aliyun.com` 添加到白名单 Referer 中。
- 未开通向量检索服务时，无法使用 `searchOSSFile` 与 `searchOSSFileByFileName` 工具查询文件。

### 自有 OSS 存储授权（文件/表格连接器）

文件与表格连接器选择"使用自有 OSS 存储"时，目标 Bucket 需添加 `bailian-connector-access` 标签（值为 `ReadAndWrite`），首次使用需按界面提示完成授权。

## 使用方式

### 创建连接器

1. 访问数据连接页面，单击右上角**创建连接器**。
2. 选择连接器类型，填写基本信息（连接器名称、描述）和存储位置。
   - **描述**会用于指导应用调用的准确度，建议写明数据内容和用途。
   - 文件/表格连接器需选择**使用平台存储**或**使用自有 OSS 存储**。
   - 数据库连接器需配置数据来源（创建自定义数据源 / 从 DMS 导入数据源）、网络类型（公网/私网）、数据库连接信息（实例、地址、端口、用户名、密码）。
3. 单击**确认**完成创建。

### 导入数据

**导入文件**：进入文件连接器详情 → 选择类目 → 导入数据 → 选择本地上传 → 配置解析方式与标签 → 确认。

解析方式可选默认设置或自定义设置，包括电子文档解析、文档智能解析、大模型文档解析、Qwen VL 解析、音视频解析等。具体说明见[数据连接](../../raw/application-user-guide/data-connection-overview/data-connection.md)。

**导入表格**：进入表格连接器详情 → 选择或新建数据表 → 选择直接上传 Excel 或自定义表头 → 导入数据。

## 限制和注意事项

- 平台存储额度：文件连接器提供最大 100,000 个文件、1 TB 存储（限时免费）；表格连接器提供 1 TB 免费额度，超出后按量付费。
- 文件导入后作为独立副本存储，与原始数据无关联；仅支持查看最近 90 天内导入的文件，超期无法查看但不会被删除。
- 导入的文件仅供当前业务空间的用户使用，百炼不会将其用于商业用途或对外公开。
- 平台不支持直接导入 JSON、CSV、YAML 格式文件，需先转换为 XLSX 或 XLS 格式。
- 数据表结构（列名、描述、类型）一旦确定无法修改；上传文件表结构必须与数据表结构完全一致，否则导入失败。
- 流量高峰或并发较高时，文件解析可能因资源排队而延长耗时，偶现解析超时，需耐心等待或稍后重试。
- 公网连接数据库时，请务必将指定 IP 段加入数据库实例的白名单中；生产环境建议使用私网连接。
