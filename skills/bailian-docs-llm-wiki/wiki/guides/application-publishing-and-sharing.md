# application publishing and sharing

百炼平台支持将已构建的智能体应用（Agent 1.0）、工作流应用及 UI 应用以多种方式发布与共享，包括对外提供 Web 访问入口、集成至钉钉/微信等第三方平台、封装为可复用组件、或嵌入音视频实时互动场景。所有发布行为均需基于已发布的应用实例，并受制于 Agent 版本、业务空间归属及权限配置等约束条件。开发者应根据目标使用场景选择适配的发布路径。

## 支持的模型/功能

- **适用应用类型**：  
  - 智能体应用（仅限 **Agent 1.0**）：支持全部发布渠道（魔笔 UI、钉钉、微信、组件、音视频实时互动）；  
  - 工作流应用：支持发布为组件、UI 应用、音视频实时互动（图文类），**不支持**钉钉/微信机器人渠道；  
  - **Agent 2.0 应用仅支持 API 调用，不支持任何 UI 或渠道类发布方式** [分享智能体应用](../../raw/application-user-guide/application-publishing-and-sharing/share-an-application.md)。  

- **核心发布能力**：  
  - **UI 应用**：基于魔笔低代码平台生成网页界面，支持开发/生产双环境部署；  
  - **第三方平台集成**：钉钉机器人（需配置卡片模板与权限）、微信公众号客服（扫码接入）；  
  - **组件化复用**：将智能体或工作流发布为可被其他智能体/工作流引用的模块化组件；  
  - **音视频实时互动**：支持 H5/APP 扫码体验及 SDK 集成，适用于语音/视频对话类应用 [UI设计器](../../raw/application-user-guide/application-publishing-and-sharing/ui-designer.md)。  

> **注意**：文档 1 中称“音视频实时互动仅支持图文对话类应用（含智能体应用和工作流应用）”，而文档 3 在 UI 设计器章节未明确限制该能力适用范围；但结合上下文及控制台实际能力边界，该限制仍以文档 1 为准，即不支持纯非对话型工作流（如批处理任务流）接入音视频通道。

## 关键参数

| 参数 | 说明 | 约束与注意事项 |
|------|------|----------------|
| `API KEY` | 调用百炼服务的身份凭证，用于 UI、钉钉、微信、音视频等渠道鉴权 | 必须与目标应用、UI 设计器位于**同一业务空间**；未配置时需先创建 [UI设计器](../../raw/application-user-guide/application-publishing-and-sharing/ui-designer.md) |
| `query` / `imageList` | 组件预设系统参数：`query`（String，必填）传递用户文本输入；`imageList`（Array<String>，非必填）传递图像公网地址 | `imageList` 仅在组件内启用多模态模型时生效；二者不可删除，但可通过“是否可见”设为隐藏 |
| `传参方式`（业务透传 / 模型识别） | 决定参数值由调用方显式传入，还是由大模型从上下文自动推断 | **模型识别在工作流中无效**：即使配置为该模式，也必须由上游节点显式传值 [使用智能体或工作流作为组件](../../raw/application-user-guide/application-publishing-and-sharing/use-agent-or-workflow-as-component.md) |
| `回调地址`（钉钉）、`二维码`（微信）、`应用地址`（UI） | 各渠道对外暴露的服务入口 | 钉钉回调地址需配置至钉钉机器人 HTTP 模式；微信二维码有效期无说明，但 UI 开发环境链接明确为 24 小时失效 |

## 使用方式

1. **前置检查**：确保目标应用已完成发布（非草稿状态），且所属业务空间与所需 API KEY、UI 设计器一致。  
2. **进入发布入口**：  
   - 在应用管理页 → 目标应用卡片 → 点击 **发布**；  
   - 或在应用编辑页 → 切换至 **发布渠道** 页签。  
3. **按需选择渠道并配置**：  
   - **UI 应用**：填写应用名称、描述、绑定 API KEY 与智能体 → 发布至开发/生产环境 → 获取 `应用地址` 分享；  
   - **钉钉/微信**：完成平台授权（SLR + API KEY）→ 填写第三方凭据（Client ID/Secret、模板 ID、AppID）→ 获取回调地址或二维码；  
   - **组件**：在“组件”区域点击 **+ 创建** → 设置组件名称、描述、参数别名/可见性/传参方式 → 确认发布；  
   - **音视频实时互动**：配置 API KEY → 生成临时体验二维码（24 小时）→ 正式发布后开通智能媒体服务并完成 SLR 授权。  
4. **引用组件**：  
   - 在智能体中：于“技能”中选择已发布组件，大模型依据描述与上下文自动触发；  
   - 在工作流中：拖入“组件节点” → 显式连接上游节点输出至组件输入参数。  

## 限制和注意事项

- **Agent 版本强约束**：Agent 2.0 应用完全不支持除 API 外的任何发布渠道，此为硬性限制，不可绕过 [分享智能体应用](../../raw/application-user-guide/application-publishing-and-sharing/share-an-application.md)。  
- **环境时效性**：UI 开发环境链接、音视频临时体验二维码均 **24 小时后失效**，生产环境需订阅付费套餐并绑定自定义域名。  
- **组件调用风险**：  
  - 禁止嵌套调用（A→B→A），会导致无限循环；  
  - 多级调用（A→B→C）易触发运行超时，建议单跳深度 ≤2；  
  - 组件更新后自动同步至所有引用处，无版本隔离机制。  
- **权限与计费归属**：所有通过分享链接产生的模型调用、存储等费用，均由**应用创建者 UID 账号承担**；匿名访问需单独配置权限组，不影响计费主体。  
- **跨空间隔离**：API KEY、智能体、UI 设计器必须处于同一业务空间，否则无法在 UI 设计器中下拉选择目标资源。
