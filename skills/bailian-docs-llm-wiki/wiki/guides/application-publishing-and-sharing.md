# application publishing and sharing

阿里云百炼支持将已构建并发布的智能体 / 工作流应用以多种渠道对外提供：官方网页版与 UI 应用、钉钉与微信公众号机器人、可被其他应用复用的"组件"、以及音视频实时互动。本页汇总各类发布方式的前置条件、关键参数与限制，便于在开发阶段为应用选择合适的分发形态。

## 支持的发布与分享方式

针对智能体应用，目前共支持 5 类发布渠道，工作流应用支持其中的部分形态：

| 渠道 | 适用应用类型 | 形态 | 是否需要外部账号 |
| --- | --- | --- | --- |
| 官方网页版 | 仅智能体 | 临时网页链接，默认 7 天有效 | 否 |
| UI 应用 / 魔笔 | 智能体、工作流 | 拖拽式 UI 网页，开发环境 24h、生产环境长期 | 否（生产环境需付费套餐） |
| 钉钉机器人 | 智能体、工作流 | 通过 AppFlow 桥接的 HTTP 机器人 | 钉钉开发者账号 |
| 微信公众号 | 智能体、工作流 | 微信客服二维码 | 微信公众号 AppID |
| 组件 | 智能体、工作流 | 被其他智能体或工作流引用的可复用模块 | 否 |
| 音视频实时互动 | 仅图文对话类应用 | H5/APP 扫码或 AICallKit SDK | 需开通智能媒体服务 |

完整的渠道清单与操作步骤见 [分享智能体应用](../../raw/application-user-guide/application-publishing-and-sharing/share-an-application.md)。

> **注意**：官方网页版仅支持智能体应用，**不支持工作流应用**；工作流应用如需网页化分发，需走 UI 应用路径。

## 前置条件

- 已在百炼控制台中构建并**发布**目标应用（智能体或工作流）。
- 钉钉 / 微信渠道首次使用时，需要授权阿里云 SLR 关联计算巢 AppFlow，并允许 API-KEY 加密传输给 AppFlow（在创建首个钉钉或微信渠道时一次性弹出）。
- UI 应用要求百炼应用、API Key、UI 设计必须归属于**同一[业务空间](../concepts/workspace.md)**，否则在 UI 设计器内无法选择到目标 API Key 与应用，详见 [UI设计器](../../raw/application-user-guide/application-publishing-and-sharing/ui-designer.md)。

## 官方网页版与 UI 应用

### 官方网页版

- 在控制台 **应用管理** → 目标智能体卡片 → **发布** → **官方网页版** 单击 **创建** 即可生成网页链接。
- 默认有效期 7 天，可在 **有效期7天** 下拉框中调整；**网页下线** 可立即终止服务。
- 谁能访问：应用创建者（主账号）、其 RAM 用户以及持有链接的其他阿里云用户。**所有调用费用由创建者 UID 承担**。
- 可启用 **应用观测** 统计 Token 消耗，并随时关闭。

### UI 应用（魔笔渠道）

UI 应用基于阿里云[多端低代码开发平台魔笔](../../raw/application-user-guide/application-publishing-and-sharing/ui-designer.md)，提供拖拽式可视化编辑器、内置登录、权限组以及与百炼智能体/数据库/HTTP 的直接集成。

- 进入路径有两条：
  1. **从已有应用发布**：在应用 **发布渠道** → **UI 应用** → **创建**，系统会自动回填标题、API Key、智能体、预设问题等。
  2. **从 UI 设计器创建**：在 **UI 设计器** → **创建 UI**，从空白模板或预置模板（智能出行助手、智能体门户、AI 基础对话、企业 AI 知识库 Lite）开始。
- 发布环境对比：

  | 维度 | 开发环境 | 生产环境 |
  | --- | --- | --- |
  | 用途 | 开发、调试、验证 | 终端用户实际使用 |
  | 访问域名 | 平台内置域名 | 内置域名 + 自定义域名 |
  | 链接有效期 | **24 小时后失效** | 长期有效 |
  | 是否收费 | 免费 | 需订阅团队版或更高套餐 + 配置域名 |

> **注意**：对于工作流应用，如配置了文件类型自定义参数，需在 UI 设计器中显式指定 `{{{file_name:files[0]}}}`（把 `file_name` 替换为实际变量名）才能让应用正确读取用户在 UI 中上传的文件。

- 部分 UI 模板自带运行时数据库表（如 `kb_chat_list` 会话记录），结构固定不可改；映射已有表时必须**保证结构完全一致**，否则运行时会报错。
- 默认仅持有链接的阿里云用户可访问；通过 **登录配置** → **允许匿名访问** + 权限组，可放开页面级匿名访问。

## 钉钉与微信公众号

钉钉、微信渠道都由计算巢 AppFlow 在百炼与第三方平台之间桥接，**只支持 HTTP 模式**，Stream 模式无法返回消息。

### 钉钉机器人

整体流程为：在百炼侧选择 API KEY → 在钉钉开放平台创建应用 / 卡片模板 / 申请权限 → 把模板 ID、Client ID、Client Secret 填回百炼。关键配置如下：

| 参数 | 来源 | 说明 |
| --- | --- | --- |
| 钉钉 Client ID / Secret | 钉钉开放平台 **凭证与基础信息** | 用于 AppFlow 调钉钉 OpenAPI |
| 钉钉模板 ID | 钉钉卡片平台 → 新建消息卡片（AI 卡片场景） | 用于流式返回机器人答复 |
| 权限 | 钉钉应用 **权限管理** | 必须申请 `Card.Streaming.Write` 与 `Card.Instance.Write` |
| 回调地址 | 百炼 **发布渠道** | 粘贴到钉钉机器人配置的 **消息接收地址** |

完成后还要在钉钉侧 **版本管理与发布** 中创建新版本并发布，群成员才能 @机器人 触发对话。详细操作步骤见 [分享智能体应用](../../raw/application-user-guide/application-publishing-and-sharing/share-an-application.md)。

> **注意**：创建钉钉应用要求账号具备开发者权限，否则会在创建应用一步被卡住，需联系组织管理员授予。

### 微信公众号

- 在 **发布平台** → **微信公众号** → **创建**，依次选择 API KEY 与微信凭据。
- 微信凭据来源：在微信公众号后台 **设置与开发** → **开发接口管理** → **基本配置** 复制 **开发者 ID（AppID）**，回填到百炼对话框并完成授权。
- 配置完成后，渠道卡片显示 **已创建**，可悬停复制二维码或单击 **扫码使用** 验证。

> **注意**：如果创建钉钉时已经完成 SLR / API-KEY 授权，创建微信渠道时**不需要再次授权**。

## 应用组件

把智能体或工作流以**组件**形式发布，可被其他智能体或工作流应用通过工具或组件节点引用，实现功能复用。

### 发布入口

- **发布应用时同步勾选**：编辑器内 **发布应用** → 选中 **发布应用组件**，发布成功对话框中点击 **立即发布**。
- **发布渠道页**：智能体 / 工作流的 **发布渠道** → **组件** → **创建**。
- **组件管理面板**：控制台 **组件管理** 可统一创建、查看、修改或删除组件。

发布与使用流程的完整示例（以"天气分析智能体"为例）见 [使用智能体或工作流作为组件](../../raw/application-user-guide/application-publishing-and-sharing/use-agent-or-workflow-as-component.md)。

### 关键参数

| 字段 | 用途 |
| --- | --- |
| 组件名称 | 建议使用业务语义命名，便于在引用方下拉中识别 |
| 组件描述 | 智能体引用时，大模型据此**自动判断是否调用**；工作流引用时仅作说明 |
| 参数名称 | 系统预设 `query`（用户输入文本）、`imageList`（图像 URL 列表，仅视觉模型生效），**不能删除**，不需要时设 **是否可见 = 否** |
| 别名 | 调用方仅能看到别名，避免与外层参数同名 |
| 参数描述 | 在 **模型识别** 传参方式下，大模型据此从上下文中推断参数值 |
| 是否必填 | 按业务定义 |
| 是否可见 | 控制是否对外暴露 |
| 传参方式 | `业务透传`：调用者 / 上游节点提供；`模型识别`：仅在**智能体**中由大模型推断 |
| 默认值 | 可选 |

> **注意**：**模型识别**在工作流中**不会真正自动推断**——即便设置为 `模型识别`，仍必须像 `业务透传` 一样从上游节点显式提供值，否则组件节点将收不到入参。两份原文对此措辞一致，是已知限制而非冲突。

### 引用方式

- **智能体应用**：在 **技能** 中加入组件，作为工具由大模型按需调用；若参数为 `业务透传`，可在测试时手动填 **入参变量配置**，或在 API 调用中通过 `biz_param` 传入。
- **工作流应用**：拖入 **组件** 节点，选中已发布组件，从开始节点连线传入 `query` 等参数，并将组件输出（`result`）接入结束节点。[流式输出](../concepts/streaming.md)需在节点上手动开启。

### 限制与注意事项

- **组件自动更新**：原应用重新发布后，对应组件**自动跟随更新**，引用方无须重新发布。
- **避免嵌套调用**：A 调 B、B 调 A 会进入死循环，导致功能不可用。
- **避免多级调用**：A→B→C 这类长链会受运行最长时长限制而超时。

## 音视频实时互动

- 仅支持**百炼的图文对话类应用**（智能体应用与工作流应用），其他模态应用无该入口。
- 操作路径：**AI 实时互动** → **语音互动 / 视频互动** → 选择 API KEY → **去配置** → 生成临时体验二维码（有效期 24h）→ **发布** → **确认发布**。
- 发布后在 **发布渠道** 中需完成**智能媒体服务开通**与 SLR 授权，再创建互动智能体。
- 提供两种分发渠道：
  - **H5 / APP 扫码**：生成分享链接并设置 Token 有效期；iOS 安装时需在 **设置 → 通用 → VPN 与设备管理** 中信任 Taobao 描述文件。
  - **SDK 集成**：基于 AICallKit SDK，支持 **快速集成**（WEB / iOS / 安卓，使用分享 ID 免 AppServer 调试，仅限测试）与 **开发集成**（含 UI / 不含 UI 两种方案，适合生产）。

## 计费与配额

- 所有渠道产生的模型调用费用归属于**应用创建者 UID**，与访问者无关。
- UI 应用本身免费，但生产环境发布需订阅团队版及以上套餐；UI 应用数据中文件存储默认 1GB、内置数据库 0.3GB，超出按量计费。
- 钉钉、微信渠道经由计算巢 AppFlow，需要先授权 SLR 及 API-KEY 加密传输，无独立费用。
