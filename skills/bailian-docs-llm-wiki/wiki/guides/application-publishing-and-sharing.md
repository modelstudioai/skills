# application publishing and sharing

阿里云百炼平台支持将已构建的智能体或工作流应用通过多种渠道发布和分享，包括网页链接、钉钉机器人、微信公众号、可复用组件以及音视频实时互动。此外，平台还提供 UI 设计器，支持通过低代码拖拽方式构建自定义应用界面并发布为网页 UI 应用。本文汇总了百炼应用的发布、分享和组件化复用的完整流程与注意事项。

## 应用分享渠道概览

百炼智能体应用发布后，可通过以下五种方式分享或发布，详见[分享智能体应用](../../raw/application-user-guide/application-publishing-and-sharing/share-an-application.md)：

| 渠道 | 适用场景 | 关键说明 |
|------|----------|----------|
| 官方网页版 | 快速生成可分享链接 | 仅支持智能体应用，默认有效期 7 天，可调整 |
| UI 应用（魔笔） | 需要自定义界面的场景 | 通过 UI 设计器搭建后发布 |
| 钉钉机器人 | 企业内部群聊 AI 助手 | 需授权 AppFlow、创建钉钉应用并配置消息卡片 |
| 微信公众号 | 面向微信用户的 AI 客服 | 需提供微信 AppID 并完成授权 |
| 组件 | 应用间功能复用 | 发布后可被其他智能体/工作流引用 |

> **注意**：所有通过分享链接产生的费用由应用创建者（UID 账号）承担，而非访问者。

## 应用组件化

智能体或工作流应用可发布为模块化组件，供其他应用接入复用，避免重复开发。完整流程参见[使用智能体或工作流作为组件](../../raw/application-user-guide/application-publishing-and-sharing/use-agent-or-workflow-as-component.md)。

### 发布组件

有两种方式将应用发布为组件：

1. **发布应用时同步发布**：在应用编辑界面点击"发布应用"时，选择"发布应用组件"。
2. **在组件管理面板发布**：通过控制台的"组件管理"页面，对已发布的应用创建组件。

### 组件参数配置

组件预设了两个系统参数：

- **query**（String，必填）：传递用户输入的文本。
- **imageList**（Array\<String\>，非必填）：传递用户输入的图像公网地址列表，仅在组件使用图像与视频理解模型时有效。

每个参数需配置以下属性：

| 配置项 | 说明 |
|--------|------|
| 别名 | 避免参数名冲突，调用者只能看到别名 |
| 参数描述 | 模型识别模式下，大模型根据描述自动填充参数 |
| 是否可见 | 可隐藏不需要的参数（如文本模型隐藏 imageList） |
| 传参方式 | **业务透传**：由调用方/上游节点提供；**模型识别**：由大模型自动推断填充 |

> **注意**：在工作流中引用组件时，即使参数的传参方式设置为"模型识别"，也不会自动推断参数值，必须从上游节点明确提供输入。

### 接入组件

- **接入智能体**：组件作为工具被智能体调用，大模型根据用户问题和组件描述自动判断是否调用。
- **接入工作流**：通过组件节点接入，需手动为组件配置输入参数并将输出传递到下游节点。

### 组件使用限制

1. **避免嵌套调用**：A 调用 B、B 调用 A 会导致循环调用，功能不可用。
2. **避免多级调用**：A 调用 B、B 调用 C 的链路容易因运行时间限制产生超时错误。
3. **自动更新**：应用重新发布后，对应组件会自动更新。

## 钉钉集成

将百炼应用发布到钉钉需要完成以下关键步骤：

1. **授权 AppFlow**（首次发布时）：授权 SLR 关联计算巢 AppFlow，并授权 API-KEY 加密传输。
2. **创建钉钉应用**：在钉钉开放平台创建应用，获取 Client ID 和 Client Secret。需要钉钉开发者权限。
3. **创建消息卡片**：在钉钉卡片平台创建 AI 卡片模板，获取模板 ID。需授予应用 `Card.Streaming.Write` 和 `Card.Instance.Write` 权限。
4. **配置机器人**：选择 HTTP 模式（不支持 Stream 模式），将百炼提供的回调地址填入消息接收地址。
5. **发布版本**：设置应用可见范围并发布，添加到群聊后通过 @机器人 进行交互。

## 微信公众号集成

将百炼应用发布到微信公众号相对简单：

1. 选择 API KEY。
2. 配置微信凭据（需提供微信公众号的 AppID，在微信公众号后台"设置与开发 > 开发接口管理"获取）。
3. 创建完成后扫码即可体验 AI 机器人客服功能。

## UI 设计器

百炼 UI 设计器集成了阿里云魔笔低代码平台能力，支持可视化拖拽搭建应用界面。详细操作参见 [UI设计器](../../raw/application-user-guide/application-publishing-and-sharing/ui-designer.md)。

### 核心能力

- **低代码搭建**：通过拖放组件构建页面，提供按钮、输入框、导航栏等 UI 元素。
- **服务集成**：支持接入百炼智能体、大模型、数据库和 HTTP 服务。
- **权限管理**：内置测试账号体系，支持钉钉/企业微信一键登录，兼容 OIDC/OAuth 2.0。
- **一键发布**：默认免费发布至开发环境，生产环境需订阅付费套餐。

### 创建 UI 应用

有两种入口：

1. **从已有应用发布**：在应用的发布渠道页面选择"UI 应用"，系统自动填充基础信息。
2. **通过 UI 设计器创建**：选择预置模板（智能出行助手、智能体门户、AI 基础对话、企业 AI 知识库 Lite）或空白模板。

### 发布环境

| 环境 | 有效期 | 费用 | 访问方式 |
|------|--------|------|----------|
| 开发环境 | 24 小时后失效，需重新发布 | 免费 | 平台域名 |
| 生产环境 | 长期有效 | 需订阅付费套餐 | 支持自定义域名 |

### 访问权限

UI 应用默认仅持有链接的阿里云用户可访问。如需允许匿名用户访问，可在 UI 设计器的"登录配置"中开启"允许匿名访问"，并通过权限组配置控制可访问的页面。

## 音视频实时互动

百炼支持通过音视频方式与智能体应用实时互动，支持语音互动和视频互动两种模式。发布渠道包括：

- **H5/APP 扫码**：生成分享链接，支持微信、钉钉扫码或手机浏览器打开。
- **SDK 集成**：基于 AICallKit SDK，提供快速集成（WEB/iOS/Android）和开发集成两种方式。

## 计费说明

- **模型调用费用**：AI 对话产生的模型调用按 Token 用量计费，新用户有免费额度。
- **UI 应用数据**：默认提供 1GB 免费文件存储和 0.3GB 免费数据库容量，超出后按量计费。
- **生产环境发布**：需订阅团队版或更高级别套餐。
- **分享链接费用**：由应用创建者账号承担。

> **注意**：百炼应用、API Key 和 UI 设计需归属于同一业务空间，否则在 UI 设计器中无法选择对应的 API Key 和应用。
