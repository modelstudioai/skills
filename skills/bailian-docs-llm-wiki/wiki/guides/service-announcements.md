# service announcements

服务公告（Service Announcements）是百炼平台面向开发者发布的、影响接口行为、计费模型、模型可用性或基础设施的正式变更通知。所有公告均按发布时间倒序排列，涵盖产品调整、调价、升级、网络优化及其他类变更。开发者应定期查阅以确保应用兼容性与成本可控性；关键变更（如下线、商业化、网关变更）通常附带明确生效时间点。最新公告可直接在控制台「消息中心」或[产品公告](../../raw/product-updates/service-announcements/product-announcements.md)中获取。

## 支持的模型/功能

服务公告覆盖以下核心能力范围：
- **模型生命周期管理**：包括主线/快照模型下线（如 `qwen-turbo` 资源包退市、`Qwen3.5` 系列旧版本下线）、MCP 服务下线（如 MCP 广场网页解析 WebParser、天气通、4个MCP服务等）、语音/图像类模型停服（如 `sensevoice-v1`、`灵汐快速图片识别`、部分历史语音主线/快照模型）；
- **功能模块调整**：[长期记忆](../concepts/long-term-memory.md)（Agent1.0）、数据库安全访问（DMS）、企业知识库（旧）、夸克搜索组件、全妙商品等已下线；知识库 Metadata 抽取、联网检索 Agent、PPT生成、作文批改、标书生成、车机热点问答等已商业化；
- **基础设施与平台能力**：智能路由入口及权限调整、北京地域公网出口 IP 扩容、美国（弗吉尼亚）部署模式变更、DashScope 域名维护、网关变更（多次通告，含 MSE 有损变更）、PTU 能力升级、API Key 加密存储与专属推理域名升级等。

> **注意**：文档中存在多处“网关变更通告”（如 2026-11-03、2026-09-16、2026-07-13、2025-12-16），但未说明具体变更内容或兼容性影响，建议结合[产品公告](../../raw/product-updates/service-announcements/product-announcements.md)中的链接公告及控制台运维通知进一步确认。

## 关键参数

公告本身不定义 API 参数，但直接影响以下运行时参数与行为：
- **模型标识（model）**：下线模型（如 `qwen3.5-7b-chat`、`gte-rerank`）将返回 `404 Not Found` 或 `400 InvalidModel` 错误；新模型（如 `Qwen3-VL-Flash`、`Qwen3-Coder-Plus`）需使用更新后的 model name；
- **计费字段**：新增 `cache_hit`（缓存命中）、`ptu_used`（预置吞吐消耗）、`metadata_extraction`（Metadata 抽取独立计费项）等账单维度；部分模型（如 `qwen-doc-turbo`）新增 Cache 计费项；
- **响应字段变更**：部分模型字段变更通知（2026-04-09、2026-04-01）表明输出结构可能调整，需校验 `output.text`、`output.choices` 等字段稳定性；
- **SLA 相关参数**：《SLA 变更公告》（2026-08-26）调整了可用性承诺与赔偿条款，影响服务等级协议执行逻辑。

## 使用方式

- **订阅与发现**：登录百炼控制台 → 左侧导航栏「消息中心」→ 开启「服务公告」推送；或定期访问 [产品公告](../../raw/product-updates/service-announcements/product-announcements.md) 页面；
- **自动化集成**：通过阿里云 OpenAPI 的 `DescribeServiceAnnouncements`（非公开接口，需工单申请）或轮询官网公告 RSS（https://www.aliyun.com/notice/feed）获取变更摘要；
- **生效时间处理**：所有下线/商业化/升级类公告均标注明确生效日期（如“2026年6月30日商业化”、“2026年10月21日升级”），开发者须在截止日前完成适配；
- **验证路径**：模型下线前可通过 `ListModels` API 检查可用模型列表；商业化功能开通后需确认对应商品已购买并授权至业务空间。

## 限制和注意事项

- **时效性**：公告为单向发布，不提供回滚机制。例如 `Agent1.0 长期记忆功能下线`（2026-09-11）后无法恢复，需迁移至新版记忆方案；
- **地域差异**：部分升级（如 `美国（弗吉尼亚）部署模式变更`、`北京地域公网出口 IP 扩容`）仅影响指定 Region，跨地域调用需单独验证；
- **兼容性风险**：`模型字段变更通知`（2026-04-09）与 `Qwen3-VL-Plus 调用参数更新`（2025-10-11）表明输入/输出 schema 可能变动，建议对关键字段做 `null` 安全检查；
- **缓存与计费耦合**：`DeepSeek-V4.1-Flash 缓存命中价格调整`（2026-11-10）与 `隐式缓存调价`（2026-04-29）说明缓存策略直接影响账单，需结合 `cache_control` 参数合理控制；
- **MCP 相关服务已全面收缩**：从 `MCP 下线通知`（2026-09-03）、`MCP 广场 MCP 下线通知`（2026-01-05）到 `MCP 广场部分 MCP 服务下线`（2026-09-23），MCP 生态已实质性终止，存量集成应尽快迁移。

> **注意**：`部分老旧模型延期下线通知`（2026-07-06）与 `部分历史主线/快照模型下线通知`（2026-06-08、2026-04-13、2025-12-25）存在时间重叠，表明下线计划存在动态调整。开发者不应依赖“延期”作为长期兼容保障，仍需按最早公告日期（如 2026-04-13）完成迁移。相关详情请参阅[产品公告](../../raw/product-updates/service-announcements/product-announcements.md)。
