# service announcements

`service announcements` 是百炼平台面向开发者发布的正式变更通知集合，涵盖模型上下线、功能升级、计费调整、网络与网关变更、协议更新等关键运营动作。所有公告均按发布日期倒序排列，确保开发者可及时掌握服务依赖的时效性变化。公告内容直接影响 API 行为、计费逻辑、权限模型及基础设施稳定性，建议集成方定期查阅并建立自动化监控机制。完整原始公告列表见 [产品公告](../../raw/product-updates/service-announcements/product-announcements.md)。

## 支持的模型/功能

- **模型生命周期管理**：包括主线模型（如 `Qwen3.5` 系列）、快照模型、语音模型（`Fun-ASR`、`Qwen3-asr-flash`）、多模态模型（`Qwen-Image-2.0-Pro`、`Qwen3-VL-Plus`）、嵌入模型（`tongyi-embedding-vision-flash`）等的下线、退市或升级。例如，`部分Qwen3.5系列旧版本模型下线通知`（2026-10-19）和 `部分历史主线模型下线通知`（2026-06-08）明确终止对旧版模型的调用支持。
- **MCP 相关服务**：MCP 广场整体进入收缩期，已发生多次集中下线，包括 `MCP下线通知`（2026-09-03）、`百炼MCP广场部分MCP服务下线通知`（2026-09-23）及 `百炼MCP广场4个MCP服务下线通知`（2026-03-26）。当前 MCP 已不作为推荐架构路径，新项目应避免依赖。
- **配套能力**：知识库（RAG）经历架构迭代，`企业知识库（旧）下线通知`（2026-07-16）标志旧版 RAG 服务终止；`Managed Agents 商业化通知`（2026-07-16）表明智能体托管能力已转为正式计费服务；`Token Plan 升级通知`（2026-05-08）同步更新了配额与限流策略。

> **注意**：文档中存在多处“延期下线”与“启动退市”表述并存的情况，例如 `部分老旧模型延期下线通知`（2026-07-06）与早前 `部分老旧模型下线通知`（2026-07-10）时间矛盾。实际生效以最新公告为准，建议以 [产品公告](../../raw/product-updates/service-announcements/product-announcements.md) 中日期最晚的同主题条目为最终依据。

## 关键参数

- **生效时间**：所有公告均标注精确到日的生效时间（如 `2026-11-10`），部分商业化通知含明确截止日（如 `【联网搜索】2026年5月7日商业化通知`），需在该日期前完成适配。
- **影响范围标识**：公告标题中明确分类为「产品调整」「升级」「调价」「其他」「网络优化」，便于快速识别技术影响层级。
- **模型/服务标识符**：使用标准模型名（如 `DeepSeek-V4.1-Flash`、`GLM-5.2 Fast mode`）和组件名（如 `WebParser`、`析言GBI`），与控制台、OpenAPI 文档命名严格一致，不可模糊匹配。
- **变更类型字段**：部分公告（如 `部分模型字段变更通知`，2026-04-09 和 2026-04-01）涉及请求/响应结构变更，需关注 `input` 或 `output` schema 的兼容性说明——此类细节仅在对应公告正文中展开，不在本汇总页体现。

## 使用方式

- **获取渠道**：公告通过阿里云官网 notice 页面发布，URL 格式统一为 `https://www.aliyun.com/notice/{id}`；控制台「消息中心」同步推送，但不保证实时性。
- **订阅机制**：开发者可通过阿里云「消息订阅」服务配置关键词（如 `百炼`、`Qwen3`、`MCP`）实现邮件/短信告警；也可调用 `DescribeServiceAnnouncements` OpenAPI（需开通对应权限）批量拉取近 90 天公告元数据（ID、标题、类型、时间）。
- **验证与适配**：对模型下线类公告，应在调用前检查 `ListModels` 接口返回的 `status` 字段（`active` / `deprecated` / `offline`）；对计费变更，需比对账单明细中的 `charge_type` 与公告中定义的新计费项（如 `Cache`、`PTU`、`ManagedAgent`）是否匹配。参考 [产品公告](../../raw/product-updates/service-announcements/product-announcements.md) 中的链接可直达具体变更细则。

## 限制和注意事项

- **时效性约束**：公告无回溯期，所有变更自生效日起强制执行。例如 `qwen-turbo 资源包启动退市通知`（2026-06-28）后，新购请求将直接拒绝，存量资源包到期后不可续费。
- **地域与环境隔离**：部分升级（如 `百炼美国（弗吉尼亚）业务空间部署模式变更通知`，2026-09-16）仅影响特定地域，跨地域调用不受影响，但需确认 endpoint 是否需切换。
- **网关与域名变更风险**：多次 `网关变更通告`（2026-11-03、2026-09-16、2026-07-13）及 `DashScope 域名进入维护状态通知`（2026-09-20）要求客户端必须支持 HTTP 重定向（301/302）或主动更新 host 配置，硬编码 IP 或旧域名将导致连接失败。
- **协议与 SLA 变更**：`《大模型服务平台百炼模型推理服务等级协议（SLA）》变更公告`（2026-08-26）调整了可用性承诺阈值与赔偿条款，直接影响 SLA 对赌场景；`《阿里云百炼服务协议》更新通知`（2026-02-13）涉及数据主权与审计权条款，企业客户须重新签署。

> **注意**：`百炼智能路由产品公告`（2026-09-15）与 `大模型服务平台百炼智能路由入口及权限调整通知`（2026-10-28）存在入口路径与鉴权方式双重变更，但后者未明确说明是否覆盖前者。建议以 [产品公告](../../raw/product-updates/service-announcements/product-announcements.md) 中 2026-10-28 条目为最终实施标准，并验证 `X-Routing-Key` 请求头与 `routing_policy` 参数的最新行为。
