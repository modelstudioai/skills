# service announcements

`service announcements` 是百炼平台面向开发者发布的正式变更通知集合，涵盖模型上下线、功能升级、计费调整、网络与网关变更、协议更新等关键运营动作。所有公告均按发布日期倒序排列，确保开发者可及时掌握服务依赖的时效性变化。公告内容直接影响 API 行为、计费逻辑、权限模型及基础设施稳定性，建议集成方定期查阅并建立自动化监控机制。完整原始公告列表见 [产品公告](../../raw/product-updates/service-announcements/product-announcements.md)。

## 支持的模型/功能

- **模型生命周期管理**：包括主线模型（如 `Qwen3.5` 系列）、快照模型、语音模型（`Fun-ASR`、`Qwen3-asr-flash`）、多模态模型（`Qwen-Image-2.0-Pro`、`Qwen3-VL-Plus`）、嵌入模型（`tongyi-embedding-vision-flash`）等的下线、退市或升级。例如，`部分Qwen3.5系列旧版本模型下线通知`（2026-10-19）和 `部分历史主线模型下线通知`（2026-06-08）明确划定了废弃边界。
- **MCP 相关能力**：MCP 广场整体进入退化阶段，已发生多次集中下线，包括 `MCP下线通知`（2026-09-03）、`百炼MCP广场部分MCP服务下线通知`（2026-09-23）及 `百炼MCP广场4个MCP服务下线通知`（2026-03-26）。当前 MCP 已不作为推荐架构路径。
- **商业化功能模块**：知识库（RAG）、Managed Agents、联网检索 Agent、PPT生成、全妙系列（作文批改、标书生成、视频混剪）、妙笔智能审校等均已启动或完成商业化，详见 [产品公告](../../raw/product-updates/service-announcements/product-announcements.md) 中“调价”与“产品调整”分类。

## 关键参数

- **生效时间**：所有公告均标注精确到日的生效/变更时间（如 `2026-11-09`），部分商业化通知含明确截止节点（如 `【联网搜索】2026年5月7日商业化`）。
- **影响范围标识**：公告标题中明确类型标签，如 `产品调整`（功能不可用）、`调价`（计费项变更）、`升级`（能力增强）、`其他`（协议/字段/权限等非功能变更）、`网络优化`/`有损变更`（需客户适配的基础设施变更）。
- **模型标识一致性**：模型名称严格遵循平台命名规范（如 `DeepSeek-V4.1-Flash`、`GLM-5.2 Fast mode`），避免使用别名或简称；字段变更类公告（如 `2026-04-09` 和 `2026-04-01`）需同步检查 API 响应结构。

## 使用方式

- **主动订阅**：通过阿里云官网「产品动态」页或百炼控制台「通知中心」订阅邮件/SMS 提醒。
- **程序化拉取**：可定时抓取 [产品公告](../../raw/product-updates/service-announcements/product-announcements.md) 的原始 Markdown 内容，解析 `### YYYY-MM-DD` 时间节与 `**[...]**` 标题，结合正则匹配类型标签（`产品调整|调价|升级|其他`）构建本地变更知识库。
- **API 兼容性检查**：在模型下线前（如 `qwen-turbo 资源包启动退市通知`，2026-06-28），须验证调用链中是否硬编码该模型 ID；商业化功能上线后（如 `知识库 Metadata 抽取功能计费方式调整通知`，2026-11-09），需确认账单接口返回的 `charge_item` 字段是否新增对应条目。

## 限制和注意事项

- > **注意**：同一模型存在多次矛盾状态声明。例如 `部分老旧模型下线通知`（2026-07-10）与后续 `部分老旧模型延期下线通知`（2026-07-06）时间顺序倒置且结论冲突，实际执行应以**最新发布时间的公告为准**，即优先采信 `2026-07-10` 的下线决定。
- > **注意**：网关类通告存在重复发布但内容未明确关联。`网关变更通告` 出现在 `2026-11-03`、`2026-09-16`、`2026-07-13` 三个日期，但各链接指向不同编号（`118792`/`118670`/`118436`），未说明是否为同一事件的分阶段通告。开发者需逐条核对变更细节，不可假设连续编号即为同一事件。
- 所有 `有损变更通告`（如 `2026-06-18`、`2026-06-02`、`2026-04-09`）均可能引发短暂连接中断或超时，要求客户端实现重试+指数退避，并监听 `503 Service Unavailable` 或 `504 Gateway Timeout` 响应码。
- 商业化通知中“起始日期”为计费生效日，**非功能停用日**；例如 `【全妙-作文批改】12月25日商业化通知`（2025-11-28）仅表示当日开始计费，功能本身仍可用，但未开通付费能力的账号将被拒绝调用。
