# service announcements

服务公告（Service Announcements）是百炼平台面向开发者发布的、影响 API 行为、计费模型、功能可用性或基础设施的正式变更通知。所有公告均按发布时间倒序排列，涵盖产品调整、调价、升级、下线、网络变更等类型。开发者应定期查阅以确保应用兼容性与成本可控性。最新公告可直接在 [产品公告](../../raw/product-updates/service-announcements/product-announcements.md) 中获取。

## 支持的模型/功能

服务公告覆盖以下核心能力范围：
- **模型生命周期管理**：包括主线/快照模型下线（如 `qwen-turbo` 资源包退市、`Qwen3.5` 旧版本下线）、模型升级（如 `Qwen-Image-2.0-Pro`、`Qwen3-VL-Flash`）、以及商业化启动（如 `千问联网检索 Agent`、`全妙-视频混剪`）；
- **MCP 相关服务**：MCP 广场整体演进，含 `WebParser` 下线、`天气通MCP` 下线、`4个MCP服务下线` 及 `部分MCP服务下线` 等多轮调整；
- **配套能力变更**：知识库（`企业知识库（旧）下线`、`Metadata 抽取功能计费调整`）、Agent（`Agent1.0长期记忆功能下线`）、语音（`语音系列历史模型批量下线`）、多模态（`多模态交互开发套件计费模式升级`）等；
- **基础设施与网关**：公网出口 IP 扩容、[智能路由](../concepts/model-routing.md)入口调整、`网关变更通告`（多次发布，含 `2026-11-03`、`2026-09-16`、`2026-07-13` 等）、`MSE有损变更` 等。

> **注意**：文档中存在多处“下线”与“延期下线”并存的情况，例如 `部分老旧模型下线通知`（2026-07-10）与后续 `部分老旧模型延期下线通知`（2026-07-06），表明实际执行窗口可能动态调整。请以 [产品公告](../../raw/product-updates/service-announcements/product-announcements.md) 中最新日期条目为准。

## 关键参数

公告本身不定义运行时参数，但直接影响以下关键配置项的语义或有效性：
- **模型名称（`model`）**：下线模型（如 `kimi-k2.5`、`GTE-RERANK`）将返回 `404 Not Found`；升级模型（如 `Qwen3.8-Max`）可能引入新字段或弃用旧字段；
- **计费单元（`pricing_unit`）**：`Token Plan`、`PTU`、`Managed Agents` 等套餐的单价、权益、适用范围均受调价/商业化公告约束；
- **API 域名与路由**：`百炼DashScope 域名进入维护状态`（2026-09-20）、`智能路由入口调整`（2026-10-28）等直接影响请求 endpoint；
- **字段兼容性**：`部分模型字段变更通知`（2026-04-09、2026-04-01）明确提示响应结构可能变化，需校验 `output`、`usage` 等字段。

## 使用方式

- **主动订阅**：通过阿里云官网「百炼产品公告页」或 RSS 订阅更新；
- **程序化检查**：建议在 CI/CD 流程中集成对 [产品公告](../../raw/product-updates/service-announcements/product-announcements.md) 的解析，提取 `id="announcement-XXXXXX"` 锚点及对应日期，识别影响自身依赖模型/功能的条目；
- **变更响应**：  
  - 模型下线前：迁移至推荐替代模型（公告中常附带迁移指引链接）；  
  - 调价生效后：更新成本预算与用量告警阈值；  
  - 网关变更时：切换至新域名或更新 DNS 解析策略；  
  - 字段变更后：适配 SDK 或响应解析逻辑。

## 限制和注意事项

- 公告无统一 API 接口，全部以静态 HTML 页面形式发布，不可编程查询历史快照；
- 部分公告（如 `网关变更通告`）在不同日期重复出现（`2026-11-03`、`2026-09-16`、`2026-07-13`），需逐条确认影响范围是否叠加或覆盖；
- 商业化类公告（如 `【联网搜索】2026年5月7日商业化通知`）通常设过渡期，但免费额度/试用权限可能在生效日零点立即终止；
- 下线类公告（如 `Agent1.0长期记忆功能下线`）不提供向后兼容开关，调用将直接失败；
- 所有公告均以阿里云官网链接为准，[产品公告](../../raw/product-updates/service-announcements/product-announcements.md) 仅作索引同步，原始权威来源为 `https://www.aliyun.com/notice/XXXXXX`。
