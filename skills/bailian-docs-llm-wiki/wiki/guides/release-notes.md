# release notes

本页面汇总百炼平台的功能更新动态与模型上下架记录。平台功能涵盖模型调优、模型部署、API 接口、应用组件、评测、观测等模块的持续迭代；模型方面则追踪推理模型、多模态模型、视频生成模型等各品类的上架与版本更新。开发者可通过本页快速了解平台最新能力变化，及时调整接入方案。

## 平台公告

百炼平台不定期发布计费调整、优惠活动等重要公告，包括：

- **降价通知**：千问系列、千问 VL 系列模型多次降价，部分模型降幅超过 80%。上下文缓存也有专项降价。
- **免费额度调整**：新人免费额度有效期调整，启用"用完即停"可避免超额计费。
- **模型下线机制**：平台已制定统一的[模型下线机制说明](https://help.aliyun.com/zh/model-studio/model-depreciation)，建议开发者关注模型生命周期以提前迁移。
- **高校计划**："云工开物"高校计划面向教育场景提供专项支持。

详细公告列表参见[模型平台功能更新](../../raw/model-user-guide/release-notes/model-release-notes.md)。

## 2026 年重点功能更新

### 模型调优与训练

- **强化学习训练（邀约制）**（5 月）：支持基于奖励信号优化模型策略的 RL 训练能力。
- **图像生成模型调优**（5 月）：支持 Wan/Wanx 等图像生成模型定制训练。
- **模型压缩**（5 月）：使用量化算法将全精度微调模型转为低精度版本，降低部署成本。
- **0 代码安全合规强化**（5 月）：无需编码即可强化大模型安全合规能力。
- **视觉理解模型调优**（1 月）：qwen2.5-VL 系列支持 SFT 调优与部署。
- **视频生成模型调优**（1 月）：万相系列视频模型支持定制训练。

### 模型导入与部署

- **模型导入 API**（6 月）：新增模型导入任务与自定义模型对象的完整 API 接口。
- **模型导入国际站上线**（6 月）：支持从 OSS 导入 LoRA 微调模型。
- **模型部署按模型单元计费**（2025 年 10 月起）：支持按 MU 时长计费，可灵活调整性能并获得可预测成本。

### API 与协议

- **Responses API 异步调用**（6 月）：通过 `background=true` 提交长耗时任务并轮询结果。
- **临时 API Key**（6 月）：在不可信环境下生成临时 API Key，避免永久密钥泄露。
- **文本生成 API 入口聚合**（5 月）：统一提供 OpenAI Responses 与 Anthropic Messages 接口分类。
- **异步任务支持事件总线回调**（4 月）：通过 EventBridge 主动推送任务完成事件，无需轮询。

### 应用与组件

- **记忆库 Memory 2.0**（3 月）：自动从对话提取记忆片段与用户画像，支持多应用共享。
- **UI 设计器**（4 月）：集成魔笔低代码能力，可视化拖放构建网页 UI 应用。
- **[Prompt 工程](../concepts/prompt-engineering.md) API**（4 月）：提供 Prompt 模板管理能力。
- **MCP 服务**（2 月）：上线官方 MCP 服务，支持平台内集成与外部第三方接入。
- **Spring AI Alibaba 集成**（6 月）：支持通过 Spring AI Alibaba 框架调用百炼智能体和工作流应用。

### 评测与观测

- **模型评测排行榜与综合评测**（6 月）：提供 Leaderboard 管理入口，支持 BLEU_4 等评分方法。
- **模型观测**：支持推理日志查看、告警通知、高级监控模式（分钟级低延时数据刷新）。

### 全模态模型

- **qwen3.5-omni-plus / qwen3.5-omni-flash**（3 月）：支持长视频分析、会议纪要、音视频交互，处理 3 小时音频和 1 小时视频，支持 113 种语言识别。
- **qwen3.5-omni-plus-realtime / flash-realtime**（3 月）：实时多模态模型，原生支持联网搜索，支持语音打断。

### 视频生成模型

2026 年视频生成模型大幅扩展，覆盖文生视频、图生视频、首尾帧生视频、参考生视频、视频编辑等任务类型：

- **万相 2.7 系列**：wan2.7-t2v / i2v / r2v / videoedit，支持多模态输入与多任务。
- **爱诗 PixVerse**：v6 和 C1 两代产品线，支持智能分镜和打斗特效。
- **Vidu 系列**：viduq3-pro / turbo / viduq2 多档位覆盖文/图/首尾帧/参考生视频。
- **可灵 Kling V3**：支持文/图/首尾帧/参考生视频及视频编辑。
- **HappyHorse**：支持有声视频生成，720P/1080P 输出。

### 图像与 3D 生成

- **qwen-image-2.0-pro**（4 月）：图片生成与编辑融合，纹理细节/光影/材质提升，支持多语言图内文字。
- **万相 2.7 图像系列**（4 月）：支持文生图、组图、编辑、交互式编辑，Pro 版支持 4K 输出。
- **Tripo 3D 模型**（4 月）：Tripo-H3.1（高精度 200 万面）与 Tripo-P1.0（专业级 2 万面）。

### 语音与音乐

- **qwen3.5-livetranslate-flash-realtime**（5 月）：音视频实时翻译，识别 60 种语言，翻译为 29 种语言音频。
- **fun-music-v1**（5 月）：百聆音乐生成大模型，支持歌曲创作要求或歌词输入生成演唱歌曲。
- **Fun-ASR 升级**（4 月）：覆盖汉语七大方言，支持 30 个语种。

## 2025 年功能亮点回顾

- **Context Cache**（12 月）：减少重复运算、提升响应速度、降低成本，首批支持 qwen-plus。
- **模型部署按调用量计费**（12 月）：支持 qwen2.5 多规格及 qwen2-7B 调优后模型。
- **模型用量看板**（12 月）：集中展示免费额度与调用量统计。
- **模型评测排行榜与多评估器**（12 月）：横向对比模型性能，覆盖字符串匹配/文本相似度/模型打分等场景。
- **模型观测上线**（1 月）：监测模型使用情况和性能变化，支持问题定位与性能优化。
- **DPO 偏好训练**（9 月）：千问 3 和千问 2.5 系列支持 DPO，降低幻觉输出。

更多历史功能更新详见[模型平台功能更新](../../raw/model-user-guide/release-notes/model-release-notes.md)。

## 模型下线与迁移

平台已建立统一的模型下线机制。模型下线前会提前通知，开发者应关注下线清单并及时迁移到推荐的替代模型。具体规则和当前下线清单参见[模型下线机制说明](https://help.aliyun.com/zh/model-studio/model-depreciation)。

> **注意**：模型上下架信息以[模型上下架与更新](../../raw/model-user-guide/release-notes/newly-released-models.md)页面为准，功能动态以[模型平台功能更新](../../raw/model-user-guide/release-notes/model-release-notes.md)为准。两份文档的更新频率不同，如发现时间线差异属正常现象。
