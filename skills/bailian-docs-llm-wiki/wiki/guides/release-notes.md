# release notes

百炼平台持续迭代，涵盖模型上新、功能模块升级和计费调整等多个维度。本页面汇总了[模型平台功能更新](../../raw/model-user-guide/release-notes/model-release-notes.md)中的平台能力动态，以及[模型上下架与更新](../../raw/model-user-guide/release-notes/newly-released-models.md)中的模型变更记录，帮助开发者快速了解平台最新进展。

### 视频生成模型

百炼汇聚了万相、爱诗 PixVerse、Vidu、可灵、HappyHorse 等多个视频生成系列，支持文生视频、图生视频、首尾帧生视频、参考生视频和视频编辑等任务。

- **万相 2.7**（2026-04）：覆盖文生视频、图生视频、参考生视频、视频编辑全流程，支持多模态输入和分辨率自定义
- **爱诗 PixVerse**：C1 / V6 / V5.6 多代模型，支持分镜、打斗特效等进阶能力
- **Vidu**：Q3 / Q2 系列，支持文生视频、首帧/首尾帧生视频、参考生视频
- **可灵 V3**（2026-03-24）：图像生成与视频生成全系列
- **HappyHorse 1.0**（2026-04-27）：支持有声视频生成，720P/1080P，3~15 秒

### 全模态模型

- **qwen3.5-omni-plus / flash**（2026-03-30）：支持长视频分析、113 种语言识别、36 种语言音频生成，可处理 3 小时音频及 1 小时视频输入
- **qwen3.5-omni-plus-realtime**（2026-03-30）：实时多模态模型，原生联网搜索，支持语音打断

### 其他模态

- **图像生成**：万相 2.7 图像 Pro（支持 4K 输出）、千问 Image 2.0 Pro、可灵 V3
- **音乐生成**：fun-music-v1（2026-05-06），支持整首歌曲创作
- **3D 生成**：Tripo H3.1（最高 200 万面）/ P1.0（最高 2 万面）
- **语音识别**：Fun-ASR 升级，覆盖七大方言、30 个语种
- **音视频翻译**：qwen3.5-livetranslate-flash-realtime，支持 60 种语言识别、29 种语言实时翻译

### 第三方直供模型

- **智谱**：GLM-5 / GLM-5.1

## 平台功能更新

### 模型调优与训练

- **强化学习训练**（2026-05，邀约制）：基于奖励信号优化模型策略
- **图像生成模型调优**（2026-05）：支持 Wan / Wanx 系列定制训练
- **视觉理解模型调优**（2026-01）：支持 VL 模型定制训练
- **视频生成模型调优**（2026-01）：支持万相系列视频模型定制训练
- **DPO 偏好训练**（2025-09）：千问 3 和千问 2.5 系列支持，通过负反馈降低幻觉
- **0 代码安全合规强化**（2026-05）：无需编码的安全合规训练流程

### 模型部署

- **模型单元（MU）部署**（2025-10）：按时间计费，灵活调整性能，成本可预测
- **按调用量计费部署**（2024-12）：支持 qwen2.5 全系列调优模型部署
- **预置模型 API 部署**（2026-01）：支持 qwen-flash/qwen-plus 等预置模型

### 模型导入与压缩

- **模型导入**（2026-06）：支持从 OSS 导入 LoRA 微调模型，提供完整 API 接口，国际站同步上线
- **模型压缩**（2026-05）：量化算法将全精度模型转为低精度版本，降低部署成本

### 模型评测

- **排行榜功能**（2025-12 / 2026-06 升级）：多模型多维度对比，支持 BLEU_4 等评分方法
- **多种评估器**（2025-12）：字符串匹配、文本相似度、模型打分、人工分类等

### 模型观测

- **推理日志**（2025-11）：查看历史对话内容，辅助提示词优化
- **告警与通知**（2025-06）：监控指标异常时自动通知
- **高级监控模式**（2025-04）：分钟级低延时刷新，详细失败信息

### API 能力

- **Responses API 异步调用**（2026-06）：通过 `background=true` 提交长耗时任务
- **临时 API Key**（2026-06）：在不可信环境避免永久 Key 泄露
- **异步任务 EventBridge 回调**（2026-04）：无需轮询，支持 HTTP 回调与 RocketMQ
- **上下文缓存（Context Cache）**（2024-12）：减少重复运算，降低成本

### 应用与组件

- **记忆库 Memory 2.0**（2026-03）：自动从对话提取记忆片段与用户画像，多应用共享
- **多模态交互开发套件**：覆盖 Java SDK、Android SDK、Linux C++ SDK、iOS Lite SDK、RTOS C SDK
- **通义听悟 Agent**：特惠 ASR 资源包、工业生产指令转写 WebSocket
- **UI 设计器**（2026-04）：集成魔笔低代码，可视化拖放构建应用
- **联网检索 Agent**（2026-03）：官方应用上线
- **MCP 服务**（2026-02）：支持平台内集成与第三方接入
- **[Prompt 工程](../concepts/prompt-engineering.md) API**（2026-04）：应用组件新增 Prompt 模板管理
- **知识库日志与监控**（2026-04）：检索调用全量投递至 SLS

### Token Plan 与计费

- **Token Plan 团队版**（2026-05）：支持 SSO/钉钉登录、席位分配、Credits 监控
- **免费额度用完即停**（2025-07）：避免额度耗尽后产生额外费用
- **免费额度与用量统计看板**（2025-12）：集中展示各模型额度与调用量

## 计费调整历史

百炼平台多次对主力模型进行降价，详情参见[模型平台功能更新](../../raw/model-user-guide/release-notes/model-release-notes.md)中的计费动态：

| 时间 | 调整内容 |
|------|---------|
| 2026-06 | 部分模型上下文缓存降价 |
| 2025-02 | qwen-max 输入降价 88%、输出降价 84% |
| 2025-01 | qwen2.5-14b/7b-instruct 降价 50%；部分模型由免费转计费 |
| 2024-12 | 千问 VL 系列降幅最高 85% |

## 模型下线机制

模型存在生命周期管理，下线规则及清单请参考模型下线机制说明文档。使用快照版本（如 `qwen3.7-max-2026-06-08`）可锁定特定版本，避免指向别名（如 `qwen3.7-max`）自动切换带来的兼容性风险。

> **注意**：模型上下架信息以模型广场实时数据为准，本页面可能存在滞后。如需获取最新模型列表和计费详情，请查阅百炼控制台模型广场。
