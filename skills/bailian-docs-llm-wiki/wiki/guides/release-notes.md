# release notes

本页汇总阿里云百炼平台的功能更新与模型上下架记录，覆盖模型平台能力演进（调优、部署、评测、观测、计费等模块）和模型市场的新增/迭代清单。开发者可据此跟踪可用模型版本、付费策略与新功能的可用时间点，避免使用已下线或被新版本替代的能力。

## 信息来源与维护节奏

- 平台侧功能动态（控制台 / API / 计费 / 观测等模块）按月份维护在 [模型平台功能更新](../../raw/model-user-guide/release-notes/model-release-notes.md)，每一条记录都标注了**日期、功能模块、功能点、功能说明**四个字段。
- 模型市场的上架记录（含阿里直供、三方直供与各厂商旗舰快照）按时间倒序维护在 [模型上下架与更新](../../raw/model-user-guide/release-notes/newly-released-models.md)，并按部署范围（如"中国内地"等地域）分段。
- **模型下线**不在上述上架表里展示，统一参见 [模型下线机制说明](https://help.aliyun.com/zh/model-studio/model-depreciation)；接到下线通知后须按平台给出的替代模型名进行迁移。

> **注意**：原始上架表中包含部分"快照版本"（形如 `qwen3.7-max-2026-05-20`）与"主线别名"（形如 `qwen3.7-max`）。生产调用建议固定到快照版本以保证行为稳定；只有在希望自动随版本升级时，才使用不带日期后缀的主线别名。

## 模型平台能力演进概要

下面按"功能模块"维度归纳近期的关键能力变更，详细日期与说明以 [模型平台功能更新](../../raw/model-user-guide/release-notes/model-release-notes.md) 为准。

### 模型调优与部署

- 2026-01-22：qwen3 系列、qwen3-vl 系列、万相系列的更多参数量模型支持模型调优。
- 2025-10-24：模型部署新增"按模型单元"方式（按时间计费），可灵活调整性能并锁定固定成本。
- 2025-10-21：千问3-VL-8B-Instruct / Thinking 支持 SFT 调优与调优后部署，SFT 同时支持全参与 LoRA。
- 2025-09-12：千问3 系列（32B/14B/8B）与千问 2.5 系列（72B/32B/14B/8B）新增 DPO 偏好训练，用于降低幻觉、对齐人类偏好。
- 2025-08-14：千问2.5-VL（72B/32B/7B）支持调优与部署。
- 2024-12-27：qwen2.5-7b-instruct 支持 SFT 全参与高效调优；模型部署支持按调用量计费（qwen2.5-7B/14B/32B/72B、qwen2-7B 调优后模型）。
- 2024-08-07：qwen2-7b-instruct、qwen2-72b-instruct 支持自定义训练与独立部署。

### 模型观测

- 2025-11-06：支持查看用户与模型的历史对话（推理日志），可用于提示词优化与故障排查。
- 2025-06-05：模型监控新增告警与通知（指标异常自动推送）。
- 2025-04-18：新增高级监控模式，提供分钟级数据刷新与更细的 4xx/5xx 错误统计。
- 2025-01-21：模型观测能力首次上线。

### 模型评测

- 2025-12-15：新增排行榜功能，可一次选多个模型并基于 BLEU、ROUGE 等多个维度横向对比。
- 2025-12-15：新增字符串匹配、文本相似度、基于模型分类/打分、人工分类等多种评估器。
- 2024-08-08：上线"自动化评测"能力。

### 计费与免费额度

- 2025-07-29：新增"免费额度用完即停"开关；启用后新人免费额度耗尽即返回 `AllocationQuota.FreeTierOnly` 错误，避免产生意外费用。
- 2025-02-07：qwen-max 实时调用输入价降至 0.0024 元/千 Token、输出价降至 0.0096 元/千 Token；Batch 调用价格降至实时调用的一半。
- 2025-01-22：qwen2.5-14b-instruct / 7b-instruct 全线降价 50%；qwen2.5-3b-instruct、qwen2-vl-72b-instruct 由免费体验转为计费。
- 2024-12-31：千问 VL 系列降价，最高降幅 85%（详情参考通义千问 VL 系列降价通知）。
- 2024-09-20：模型推理支持预付费节省计划，可抵扣超出免费额度后的推理费用。
- 2024-09-19：部分千问模型免费额度有效期从 30 天延长至 180 天。

### OpenAI 接口兼容与上下文能力

- 2024-12-24：模型广场上线 Context Cache（仅 qwen-plus 起步），可在不影响回复效果的前提下减少重复算力开销。
- 2024-12-20：OpenAI 兼容 Batch 接口支持任务完成通知（Callback 回调与 EventBridge），并新增 qwen-vl-max / qwen-vl-plus / qwq-32b-preview 等模型。
- 2024-12-20：模型广场新增 `search_options` 参数，可配置联网搜索的来源与数量，目前可用于 qwen-max / qwen-plus / qwen-turbo。
- 2024-08-27：OpenAI 兼容新增 Vision 调用模式，原有 OpenAI 框架仅需切换 API-KEY / BASE_URL / model 即可调用千问视觉模型。
- 2024-08-23：OpenAI 兼容新增 Batch 调用模式，24 小时内异步返回结果，费用为实时调用的一半。

> **注意**：千问 max 类模型曾经历 `qwen-max-1201`（2024-04-22 下线，建议迁移到 `qwen-max`）和 `qwen-max-longcontext`（2024-10-17 下线，建议迁移到 `qwen-max`）两轮关停事件。新代码不要再硬编码这两个模型名。

## 使用方式与注意事项

1. **跟踪能力变更**：优先以 [模型平台功能更新](../../raw/model-user-guide/release-notes/model-release-notes.md) 作为"功能可用性"事实源；该页同时挂着公告通知（含降价、免费额度调整、合作活动等）。
2. **决定调用哪个模型**：以 [模型上下架与更新](../../raw/model-user-guide/release-notes/newly-released-models.md) 上架表的"模型规格"字段为准；规格名带日期后缀的是**快照**，不带日期后缀的是**主线别名**。
3. **关注地域**：上架记录按"部署范围 + 地域"分段。当前主要部署范围"中国内地"对应华北 2（北京），跨区域调用前需要核对当前业务空间是否可达。
4. **关注下线**：上架表不展示下线模型，必须配合 [模型下线机制说明](https://help.aliyun.com/zh/model-studio/model-depreciation) 与平台站内通知一起看；下线前会给出迁移建议（如 `qwen-max-1201 → qwen-max`、`qwen-max-longcontext → qwen-max`）。
5. **关注计费与免费额度**：DeepSeek 部分模型已经由"免费体验"转为计费，新人免费额度有效期与"用完即停"开关都会影响实际可用预算，开发前请阅读 [模型平台功能更新](../../raw/model-user-guide/release-notes/model-release-notes.md) 中"计费"相关条目。

> **注意**：本页是对原始 release notes 的二次组织，仅截取了关键条目；任何价格、参数、能力描述若与原文不一致，**以原文为准**。原文也会随官方更新发生回填或修订。
