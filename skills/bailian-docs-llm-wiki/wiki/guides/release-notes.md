# release notes

## 平台功能动态

按月份组织的关键功能更新（摘自 [模型平台功能更新](../../raw/model-user-guide/release-notes/model-release-notes.md)），按模块归类：

### [模型调优](../concepts/fine-tuning.md)与训练

- **强化学习训练（邀约制）**：2026-05-31 上线，基于奖励信号优化模型策略。
- **图像生成[模型调优](../concepts/fine-tuning.md)**：2026-05-28 支持 Wan/Wanx 系列定制训练。
- **视觉理解[模型调优](../concepts/fine-tuning.md)**：2026-01-22 新增 VL 模型 SFT 支持。
- **视频生成模型调优**：2026-01-21 新增万相系列视频模型定制训练。
- **0 代码安全合规强化**：2026-05-04 上线文本生成模型安全合规训练流程。
- **模型压缩**：2026-05-25 上线，量化全精度微调模型为低精度版本以降低部署成本。

### 模型部署与 API

- **API 部署预置模型**：2026-01-23 新增 qwen-flash/qwen-plus 等预置模型部署，并支持按模型单元（MU）时长计费。
- **模型单元部署**：2025-10-24 上线按时间计费方式，可灵活调整性能、固定成本可预测。
- **按调用量计费部署**：2024-12-27 支持 qwen2.5-7B/14B/32B/72B 与 qwen2-7B 调优后模型。
- **文本生成 API 入口聚合**：2026-05-15 新增 OpenAI Responses 与 Anthropic Messages 接口分类。
- **Responses API 异步调用**：2026-06-01 上线，通过 `background=true` 提交长耗时任务并轮询结果。
- **异步任务事件回调**：2026-04-23 支持事件总线 EventBridge HTTP 回调与 RocketMQ 主动推送，无需轮询。

### 应用与 SDK

- **新版智能体应用 DashScope API**：2026-05-11 首发，支持单轮/多轮、流式、文件问答、视觉理解。
- **多模态交互开发套件**：陆续上线服务端 Java SDK（4-28）、移动端 Android SDK（4-14）、Linux C++ SDK（2-28）、Android/iOS Lite SDK（2-06）、RTOS C SDK License 模式（4-09）。
- **通义听悟 Agent**：2026-06-01 新增特惠 ASR 资源包；2026-05-21 工业生产指令转写 WebSocket 协议上线。
- **通义多模态翻译**：2026-05-26 API 目录上线，覆盖文本/图片/文档/网页翻译；2026-02-06 网页翻译 JSSDK 上线。
- **Spring AI Alibaba**：2026-06-01 调用百炼智能体、[工作流](../concepts/workflow.md)应用文档上线。

### 平台能力

- **API Key 加密存储**：2026-06-29 升级业务空间专属推理 API 域名。
- **临时 API Key**：2026-06-03 新增生成临时 API Key 文档，避免不可信环境下永久 Key 泄露。
- **模型导入 API**：2026-06-03 上线，涵盖导入任务与自定义模型对象接口；2026-06-05 国际站支持从 OSS 导入 LoRA 微调模型。
- **模型评测**：2026-06-09 新增排行榜（Leaderboard）与综合评测，支持 BLEU_4 等评分方法。
- **知识库 RAG**：2026-04-24 检索调用全量投递至 SLS 日志服务；2026-02-05 Retrieve 接口新增排序模型与指令干预模式。
- **记忆库 Memory 2.0**：2026-03-20 上线，自动提取记忆片段与用户画像，支持多应用共享。
- **UI 设计器**：2026-04-01 上线，集成魔笔低代码能力，可视化拖放构建网页 UI 应用。
- **MCP 服务**：2026-02-06 上线官方 MCP 服务，支持平台内集成与外部第三方接入。
- **Token Plan 团队版**：2026-05-08 新增团队管理，支持 SSO/钉钉登录、席位分配、Credits 用量监控。

## 模型观测与监控

- **推理日志**：2025-11-06 支持查看用户与模型历史对话内容，用于提示词优化与故障排查。
- **告警与通知**：2025-06-05 上线，监控指标异常时通知运维团队。
- **高级监控模式**：2025-04-18 支持分钟级低延时数据刷新，记录 4xx/5xx 详细失败信息。
- **模型观测能力**：2025-01-21 上线，监测模型使用情况与性能变化。
- **免费额度与用量看板**：2025-12-22 集中展示各模型免费额度（已用/剩余）及调用量统计。

## 计费调整

- **qwen-turbo 资源包退市**：2026-06-28 启动退市通知。
- **[上下文缓存](../concepts/prompt-caching.md)降价**：见阿里云百炼部分模型[上下文缓存](../concepts/prompt-caching.md)降价通知。
- **deepseek-v4-pro 缓存计费**：2026-04-29 起 `cached_token` 单价调整为 1 元/百万 token，标准 `input_token` 单价不变。
- **qwen-max 降价**：2025-02-07 输入价格降低 88%，输出价格降低 84%。
- **千问系列降价**：2025-01-22 qwen2.5-14b/7b-instruct 降价 50%；qwen2.5-3b-instruct、qwen-vl-72b-instruct 由免费体验转为计费。
- **千问 VL 模型降价**：2024-12-31 降幅最高 85%。
- **免费额度用完即停**：2025-07-29 上线，新人免费额度耗尽返回 `AllocationQuota.FreeTierOnly` 错误，避免额外费用。
- **DeepSeek 系列计费调整**：2025-02-08 部分模型由免费体验转为计费。

> **注意**：原文提及“千问系列模型降价通知”与“通义千问VL系列模型降价通知”两条公告，分别对应不同模型族，使用时请按模型族核对最新价格，不要混淆。

## 限制与注意事项

- **模型单元部署**：核心优势为可灵活调整性能、高服务稳定性、可预测的固定成本，但需按模型单元（MU）时长计费。
- **qwen3.6-max-preview**：仅支持纯文本输入，不支持图像与视频输入；支持思考模式（默认开启）、显式缓存与 Function Calling。
- **qwen3.7-max 早期快照**（2026-05-17/05-20）：仅支持纯文本输入，仅/默认支持思考模式。
- **kimi/kimi-k2.7-code**：仅支持思考模式。
- **Context Cache**：当前支持 qwen-plus 模型（2024-12-24 上线），通过减少重复运算量降低成本。
- **模型下线机制**：模型下线遵循统一规则，清单见[模型下线机制说明](https://help.aliyun.com/zh/model-studio/model-depreciation)，使用前请确认模型是否处于退市流程。
- **Batch 任务**：执行时间可能较长，可通过查询接口获取状态；2024-12-20 起支持任务通知。
