# support

本页汇总阿里云百炼平台的常见问题解答与相关服务协议，帮助开发者快速定位使用过程中遇到的问题并了解平台的法律条款。内容涵盖计费、API/SDK、模型训练、幻觉处理等高频问题，以及百炼平台的服务协议与 SLA 承诺。

## 计费与付费

百炼平台采用**按量后付费**模式，按分钟级出账、按月结算。部分模型另支持预付费（节省计划与资源包）。

- 模型价格参见百炼控制台的模型市场页面，详细计费规则见[常见问题](../../raw/model-user-guide/support/faq-about-alibaba-cloud-model-studio.md)中的计费章节。
- 开通服务要求阿里云账户余额不小于 0 元，且需完成实名认证。
- 扣款明细可在阿里云「费用与成本」控制台查看；发票在「发票管理」页面申请。

> **注意**：万相会员与百炼 API 的计费体系相互独立，万相会员权益不适用于百炼 API 调用。

## API 与 SDK

百炼目前提供 Java 和 Python SDK，API 调用返回标准状态码和错误码。

关键排查要点：

| 问题 | 说明 |
|------|------|
| 错误码 100004 | 必须参数缺失或格式不正确，检查请求体 JSON 结构 |
| `doc_reference_type` 不生效 | 该参数仅在旧版应用中生效，新版需在应用页面开启「展示回答来源」开关 |
| Assistant API function call | 暂不支持单次调用中依次调用两个本地函数，需创建两个 Assistant 分别处理 |
| Assistant API memory | 当前暂不支持 memory 配置 |

错误码完整列表和 SDK 安装方式详见[常见问题](../../raw/model-user-guide/support/faq-about-alibaba-cloud-model-studio.md)中的 API/SDK 章节。

## 模型选择与训练

### 模型选型

- **qwen-turbo**：注重速度与成本，适合对响应延迟敏感的场景，费用较低。
- **qwen-max**：注重精度与复杂任务处理能力，适合对质量要求严格的场景。
- 千问系列支持 14 种语言（中、英、日、韩、法、德、俄等）。

### 训练注意事项

- 仅使用垂直领域数据做 SFT 可能导致模型遗忘通用知识，建议混入通用 SFT 数据。
- 训练数据应保证**任务定义清晰、数据质量高、数据多样**，避免过拟合和重复输出。
- 循环次数等超参数无固定规律，需根据具体任务实验确定；不应仅通过 loss 判断过拟合，最终效果以人工评估为准。
- 训练完成的模型目前不支持导出；本地训练的模型不支持上传到百炼平台。
- 图片训练已支持，qwen-vl-plus 模型支持训练微调。

### 模型限流

生成速度受服务整体负载和请求并发影响，不固定。限流触发后的等待时间取决于具体 RPS/RPM 限额，例如 120 RPM 下连续快速提交会触发短暂等待（约 0.8 秒级别）。

## 降低模型幻觉

模型幻觉指 LLM 无中生有、虚构事实的现象。推荐的缓解策略（按实施难度排序）：

1. **提示词工程**：在 [prompt](prompt.md) 中要求模型仅基于提供内容回答，引导分步推理，设定严谨角色。
2. **RAG（检索增强生成）**：让模型回复有据可依，严格限制在检索结果范围内。
3. **参数调优**：降低 `temperature`、`top_k`、`top_p` 减少随机性；适当控制 `max_tokens` 防止冗余生成。
4. **选择更强模型**：Max > Plus > Turbo，更大模型通常幻觉更少。
5. **插件/MCP**：将数值计算等任务交给外部工具，避免模型直接处理。
6. **后处理验证**：用 AI 二次校验回复，代价是增加成本和延迟。

详细方案参见[常见问题](../../raw/model-user-guide/support/faq-about-alibaba-cloud-model-studio.md)中的模型幻觉章节。

## 数据安全与隔离

- 阿里云不会将用户数据用于模型训练，传输数据经 AES-256 加密。
- 根据法律法规要求，调用时产生的数据会被存储，具体条款见[相关协议](../../raw/model-user-guide/support/related-agreements.md)。
- 通过子账号 + [业务空间](../concepts/workspace.md)权限管理可实现不同用户间的数据隔离。
