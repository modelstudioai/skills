# support

本页汇总百炼平台的常见问题解答、服务协议与技术支持渠道，帮助开发者快速定位问题并获取官方帮助。内容涵盖计费、API/SDK、模型训练、模型幻觉等高频问题，以及平台相关的法律协议和 SLA 承诺。

## 计费与账单

百炼平台采用**按量后付费**模式，按分钟级出账、按月结算。部分模型另支持预付费（节省计划与资源包）。开通服务要求阿里云账户余额不小于 0 元。

关键要点：

- 模型调用价格和部署/训练计费分别独立，详见[常见问题](../../raw/model-user-guide/support/faq-about-alibaba-cloud-model-studio.md)中的计费章节。
- 万相会员与百炼 API 调用的计费体系**相互独立**，万相会员权益不适用于百炼 API 调用。
- 扣款明细可在阿里云「费用与成本」控制台查看，发票在「发票管理」页面申请。

## API 与 SDK

百炼目前提供 Java 和 Python 两种语言的 SDK。调用时需注意以下常见问题：

- **参数缺失（错误码 100004）**：检查必填参数是否齐全、格式是否正确。完整错误码列表见官方错误码文档。
- **`doc_reference_type` 不生效**：该参数仅在旧版应用中有效，新版应用需在操作页面开启「展示回答来源」开关。
- **Assistant API 限制**：暂不支持单次调用中依次执行两个 function call，也暂不支持 memory 配置功能。

更多细节参见[常见问题](../../raw/model-user-guide/support/faq-about-alibaba-cloud-model-studio.md)的 API/SDK 章节。

## 模型训练与选型

### 模型选择

- **qwen-turbo**：注重速度与资源效率，费用较低，适合对响应速度要求高的场景。
- **qwen-max**：聚焦顶级性能，适合对精度和复杂任务处理能力有严格要求的场景。
- 千问系列支持 14 种语言（中、英、日、韩、法、德、俄等）。
- qwen-vl-plus 已支持图片训练微调。

### 训练注意事项

- 仅使用垂直领域数据做 SFT 可能导致模型遗忘通用知识。建议保证数据质量高、任务定义清晰、[prompt](prompt.md) 表达多样化。
- 数据量较少时（约 100 条），增加循环次数通常有正向效果；数据量大时（1000+ 条），需通过实验确定超参，避免过拟合。
- 评估大模型不应仅看 loss 值，最终效果以人工评估为准。
- 训练完成的模型目前**不支持导出**；本地自训模型也**不支持上传**到百炼平台。

## 模型幻觉及应对

模型幻觉指 LLM 在生成内容时无中生有、虚构事实的现象。降低幻觉的主要手段包括：

| 方法 | 说明 |
|------|------|
| 选择更强模型 | Max > Plus > Turbo，参数规模越大幻觉越少 |
| 提示词工程 | 添加约束指令，如"仅基于文档回答""引用数据支持结论" |
| RAG | [检索增强生成](../concepts/rag.md)，严格限制回答范围 |
| 插件/MCP | 将数值计算等任务交给外部工具，避免模型直接处理 |
| 参数调优 | 降低 temperature / top_k / top_p，输出更保守 |
| 后处理验证 | 用 AI 二次校验回答是否存在幻觉（会增加延迟和成本） |

详细说明参见[常见问题](../../raw/model-user-guide/support/faq-about-alibaba-cloud-model-studio.md)中的模型幻觉章节。

## 服务开通与数据安全

- 使用阿里云主账号访问百炼控制台即可自动开通，需先完成实名认证。服务开通后**暂不支持关闭**，但可通过删除 API-Key 停止调用。
- 阿里云**不会将用户数据用于模型训练**，传输数据均经过 AES-256 加密。根据法律法规要求，平台会存储调用产生的数据。
- 通过[业务空间](../concepts/workspace.md)权限管理可实现不同用户间的数据隔离。
- 控制台最多展示 100 条历史对话记录，无时间限制；未登录状态和推理报错时的对话不保存。

## 限流与并发

模型生成速度不固定，受服务整体负载和请求并发量影响。触发限流后的等待时间取决于具体限流值（RPS/RPM）。例如 120 RPM 的限流下，0.2 秒内提交 2 次请求后，第 3 次需等待约 0.8 秒。
