# support

阿里云百炼平台为开发者提供了完善的支持体系，涵盖计费说明、API/SDK 使用指导、模型训练与调优建议、幻觉问题应对策略，以及服务协议与合规信息。本页面整合了平台使用中的高频问题与关键资源入口，帮助开发者快速定位解决方案。

## 计费与付费

百炼平台采用按量后付费模式，按分钟级出账、按月结算。部分模型支持预付费（节省计划与资源包）。开通服务前需确保阿里云账户余额不小于 0 元。

关键要点：

- **模型调用计费**：不同模型单价不同，详见百炼控制台模型市场页面
- **[模型部署](../concepts/model-deployment.md)与训练**：单独计费，具体规则参见[模型部署](../concepts/model-deployment.md)计费文档
- **发票与账单**：可在阿里云费用与成本控制台查看扣款明细并申请开票
- **万相会员**：与百炼 API 调用的计费体系相互独立，会员权益不适用于百炼 API 调用

详细计费问题请参考[常见问题](../../raw/model-user-guide/support/faq-about-alibaba-cloud-model-studio.md)中的计费相关章节。

## API 与 SDK 使用

百炼目前支持 Java 和 Python 语言的 SDK。调用 API 时需注意参数格式的正确性，常见错误码可通过平台错误码文档查询解决方案。

常见问题及注意事项：

- **参数缺失报错（错误码 100004）**：检查必须参数是否齐全，参数格式书写是否正确
- **Assistant API**：目前不支持在单次调用中分别调用两个本地函数（function call），也暂不支持 memory 配置功能
- **doc_reference_type 参数**：仅在旧版本应用中生效，新版本应用需在应用操作页面直接开启"展示回答来源"开关

## 服务开通与数据安全

使用阿里云主账号前往百炼控制台即可自动开通服务（需完成实名认证）。服务开通后暂不支持关闭，但可通过删除 API-Key 避免后续调用产生费用。

数据安全方面：

- 阿里云**不会**将用户数据用于模型训练
- 传输数据经 AES-256 加密
- 根据法律法规要求，平台会存储模型与应用调用时产生的数据，具体条款参见《阿里云百炼服务协议》
- 支持通过[业务空间](../concepts/workspace.md)权限管理实现不同用户间的数据隔离
- 控制台最多展示 100 条历史对话记录，不设时间限制

更多产品相关问答可参考[常见问题](../../raw/model-user-guide/support/faq-about-alibaba-cloud-model-studio.md)中的产品相关章节。

## 模型训练与调优

百炼支持文字和图片训练（qwen-vl-plus 模型支持训练微调），但训练完的开源模型目前不支持导出。千问系列模型支持中文、英文等 14 种语言。

训练建议：

- **模型选择**：qwen-turbo 注重速度与资源效率，费用较低；qwen-max 聚焦顶级性能，适用于复杂任务
- **数据质量**：任务定义要清晰，答案要准确简洁，同一语义用多种 [prompt](prompt.md) 表达以增加多样性
- **超参调优**：循环次数需根据具体任务通过实验确定，不应仅通过 loss 判断是否过拟合，最终效果以人工评估为准
- **SFT 训练**：仅使用垂直领域数据可能导致模型遗忘通用知识，建议混入通用 SFT 数据
- **限流处理**：生成速度受服务负载影响，限流触发后等待时间取决于具体限流值（RPS/RPM）

## 降低模型幻觉

模型幻觉是指大语言模型在生成内容时虚构事实或产生逻辑矛盾的现象。可通过以下策略降低：

1. **选择更强的模型**：Max 级别 > Plus 级别 > Turbo 级别
2. **提示词工程**：在 [prompt](prompt.md) 中限定回答范围、要求引用依据、设定严谨角色
3. **RAG（[检索增强生成](../concepts/rag.md)）**：让模型基于检索到的知识回答，严格限制回答范围
4. **插件/MCP**：对需要精确计算的任务，通过工具调用完成计算后再交给模型总结
5. **参数调优**：降低 `temperature`、`top_k`、`top_p` 等随机性参数
6. **后处理验证**：通过 AI 二次校验回复内容的正确性（会增加成本）

## 服务协议与合规

使用百炼平台需遵守相关服务协议，包括服务协议、推理服务 SLA、服务特别说明、开源模型协议条款及三方模型服务协议等。如需申请千问系列模型的合作协议（如上架微信小程序等应用商店），可通过阿里云工单申请。完整协议清单请参见[相关协议](../../raw/model-user-guide/support/related-agreements.md)。
