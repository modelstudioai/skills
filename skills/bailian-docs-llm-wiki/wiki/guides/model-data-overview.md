# model data overview

模型数据是百炼平台对训练集与评测集的统一管理能力，支撑模型调优、评测及数据增强等核心场景。它提供数据集全生命周期管理（创建、版本控制、发布）和可视化数据流处理能力，所有操作均通过百炼控制台「数据管理」页面完成。该功能面向开发者设计，强调可复现性与协作性。

## 支持的模型/功能

- **数据集类型**：明确区分**训练集**（用于[模型调优](https://help.aliyun.com/zh/model-studio/model-training-overview)）和**评测集**（用于[模型评测](https://help.aliyun.com/zh/model-studio/model-evaluation-overview)），二者在用途、使用流程和权限约束上不同。  
- **数据流处理**：支持通过可视化画布进行清洗与增强，适用于预处理阶段的数据转换；相关能力详见 [数据清洗或增强](https://help.aliyun.com/zh/model-studio/data-processing)。  
- **统一管理入口**：所有数据集与数据流操作集中于控制台 [百炼控制台·数据管理](https://bailian.console.aliyun.com/cn-beijing/model/data)，该页面为实际操作唯一权威入口，其功能定义以 [原文标题](../../raw/model-user-guide/model-data-overview.md) 为准。

## 关键参数

- **数据集元信息**：包括名称、类型（训练集/评测集）、最新版本号、数据量（行数）、导入状态、发布状态、存储位置（OSS 路径）、导入方式（控制台上传、API 导入、日志回流等）。  
- **版本标识**：每个数据集支持多版本，版本号自增（如 `v1`, `v2`），未发布的版本不可被模型训练或评测任务引用。  
- **发布状态**：仅已发布版本可用于下游任务；发布操作不可逆，且需人工确认，详情见 [原文标题](../../raw/model-user-guide/model-data-overview.md) 中「数据集 Tab」说明。

## 使用方式

1. 登录百炼控制台，进入 [百炼控制台·数据管理](https://bailian.console.aliyun.com/cn-beijing/model/data)；  
2. 在「数据集」Tab 点击右上角 **创建数据集**，选择类型（训练集/评测集），上传原始文件或配置导入源；  
3. 创建后可点击操作列的「新增版本」迭代数据，完成后点击「发布」使该版本生效；  
4. 如需清洗或增强，切换至「数据流」Tab 搭建处理流程，并将输出结果导出为新数据集版本。完整操作指引请参考 [原文标题](../../raw/model-user-guide/model-data-overview.md)。

## 限制和注意事项

- 单个数据集最大支持 1000 万行文本数据（按 UTF-8 字节数计算，单行 ≤ 1 MB）；超限需分片或预过滤。  
- 评测集不支持直接用于模型调优，训练集亦不可用于评测任务——该约束由平台强制校验，违反将导致任务提交失败。  
- > **注意**：原始文档中提及「日志回流」为相关能力，但当前版本（v2024.07）中日志回流功能尚未开放给全部用户，其接入方式与权限范围与 [日志回流](https://help.aliyun.com/zh/model-studio/model-log-backflow) 文档描述存在差异，请以控制台实际可用选项为准。  
- 数据集删除后，所有关联版本及元数据不可恢复；已发布的版本若被正在运行的评测任务引用，平台将阻止删除操作。
