# model data overview

阿里云百炼平台提供完整的数据管理功能，支持创建和管理模型训练与评测所需的数据集。数据集分为训练集（用于模型调优）和评测集（用于模型评测）两大类。平台还提供数据清洗与增强能力，帮助开发者在模型调优前获取更高质量的训练数据。

## 数据集类型

百炼数据管理将数据集分为两类：

- **训练集**：用于模型调优（SFT/DPO/CPT），通过有监督训练提升模型在特定任务上的表现。目前支持文本生成、多模态理解、图生视频（首帧）、图生视频（首尾帧）训练集。
- **评测集**：用于评估调优后模型的泛化能力。目前仅支持文本生成评测集（Excel 格式，包含 Prompt 和 Completion 两列）。

详细格式说明参见 [训练集与评测集](../../raw/model-user-guide/model-data-overview/training-set-and-evaluation-set.md)。

## 训练集格式

### SFT 训练集

采用 ChatML 格式，支持多轮对话和多种角色（system/user/assistant）。数据为 JSONL 文件，每行一个 JSON 对象：

```json
{"messages": [
  {"role": "system", "content": "系统输入"},
  {"role": "user", "content": "用户输入"},
  {"role": "assistant", "content": "期望的模型输出"}
]}
```

支持的变体包括：

| 变体 | 说明 |
|------|------|
| **SFT 标准** | 所有 assistant 输出均被训练 |
| **SFT 思考模型（thinking）** | 仅训练最后一个 assistant 输出，使用 `<think>` 标签包裹思考内容 |
| **SFT 视觉理解（千问VL）** | content 使用数组格式，支持图片和视频输入 |

> **注意**：SFT 训练集不支持 OpenAI 的 `name` 和 `weight` 参数。

所有 SFT 变体的 assistant 行均支持 `loss_weight` 参数（范围 0.0~1.0），用于设置该行在训练时的相对重要性，但该参数属于邀测功能。

### DPO 训练集

DPO 格式在标准 ChatML 基础上增加了 `chosen` 和 `rejected` 字段，用于训练模型的正负反馈偏好。训练集通常需要上百条人类偏好数据。

### CPT 训练集

CPT 采用纯文本格式 `{"text":"文本内容"}`，最少需要一千万 Token 的优质预训练数据。

### 视觉理解训练集（压缩包）

千问VL 训练集需要打包为 ZIP 文件（最大 2GB），包含 `data.jsonl` 和图片/视频文件。关键要求：

- `data.jsonl` 必须位于压缩包根目录
- 图片单张宽高均不超过 4096px，最大 10MB
- 图片文件名全局唯一（即使在不同文件夹中）
- 支持 BMP/JPEG/PNG/TIFF/WEBP 格式

### 图生视频训练集

支持基于首帧和基于首尾帧两种模式，训练集均为 ZIP 包格式，包含图像、视频和 `data.jsonl` 标注文件。验证集为可选项，仅需图像和标注文件，训练时会自动生成预览视频。具体格式和样例详见 [训练集与评测集](../../raw/model-user-guide/model-data-overview/training-set-and-evaluation-set.md)。

## 数据处理

百炼提供数据清洗和数据增强两种处理能力，帮助提升训练集质量。目前仅支持处理 SFT 文本生成训练集（ChatML 格式），不支持视觉理解和 DPO 训练集。详细操作流程参见 [数据清洗或增强](../../raw/model-user-guide/model-data-overview/data-processing.md)。

### 数据清洗

修正训练数据中的规范性、合规性、一致性及重复问题，已支持的算子包括：

- 特殊内容移除（URL、特殊字符等）
- 敏感信息打码
- 文章相似度去重
- 敏感词过滤
- 毒性消除

清洗算子的执行顺序按编排顺序依次执行，建议每个数据清洗节点只开启一个算子，便于检测和纠正错误。

### 数据增强

用于增加训练数据的多样性、均衡性或扩展数据规模。底层通过千问-Max 大模型，使用 Few-Shot 策略从种子池中抽样生成新数据。支持四种场景：

- **数据增强-通用**：适用于通用 SFT 训练集增强
- **数据增强-文本分类**：针对分类任务优化
- **数据增强-文本抽取**：针对抽取任务优化
- **数据增强-文本创作**：针对创作任务优化

每次最多生成 2000 条样本。增强后的训练集会自动生成新版本，不覆盖原训练集。

## 数据流搭建

数据处理通过可视化的数据流画布实现，核心节点包括：

| 节点 | 用途 |
|------|------|
| **开始/结束** | 接收待处理训练集 / 输出处理结果 |
| **数据清洗** | 执行清洗算子 |
| **数据增强** | 执行增强策略 |
| **条件判断** | 基于 `dataSetCount` 等变量进行分支控制 |

典型流程：开始 → 数据清洗 → 条件判断（数据量是否足够） → 数据增强 → 结束。

> **注意**：目前暂未提供数据处理 API，仅支持在控制台操作。数据流任务执行期间不支持手动终止。

## 训练集规模建议

| 训练方式 | 最低数据量 |
|----------|-----------|
| CPT | 一千万 Token 优质预训练数据 |
| SFT | 上千条优质微调数据 |
| DPO | 上百条人类偏好数据 |

如果模型调优效果不佳，最直接的改进方法是收集更多数据。可以利用大模型模拟生成特定场景的数据来辅助扩充训练集，同时建议准备一份与训练集不重叠的评测集来评估调优效果。

## 限制与注意事项

- 数据管理功能仅适用于中国大陆版（北京地域）
- 数据处理仅支持 SFT 文本生成训练集（ChatML 格式）
- 数据增强使用千问-Max 模型，暂不支持选择其他模型
- `loss_weight` 参数属于邀测功能，需联系商务经理开通
- 处理后的训练集自动生成新版本，不会覆盖原始数据
- 如训练数据本身不适合清洗与增强（如法律文件、医学记录、文学作品等），建议跳过数据处理步骤
