# model data [overview](overview.md)

百炼平台的模型数据管理功能为大模型调优与评测提供统一、可控的数据基础设施。它支持训练集（SFT/DPO/CPT）和评测集两类数据集的创建、版本化管理与结构化处理，覆盖文本生成、视觉理解、图生视频等多种场景。所有数据集均默认启用 OSS 服务端加密（SSE-OSS），并可通过控制台或 API 全流程操作。

## 支持的模型/功能

- **训练集**：支持 SFT（监督微调）、DPO（直接偏好优化）、CPT（持续预训练）三种训练方法，对应文本生成、视觉理解、图生视频（首帧/首尾帧）四类训练场景；其中 DPO 和 CPT 仅限北京地域使用 [训练集与评测集](../../raw/model-user-guide/model-data-overview/training-set-and-evaluation-set.md)。
- **评测集**：仅支持文本生成场景，可用于模型泛化能力评估 [训练集与评测集](../../raw/model-user-guide/model-data-overview/training-set-and-evaluation-set.md)。
- **数据处理**：支持对已发布的 SFT-文本生成训练集（ChatML 格式）进行清洗（如敏感信息打码、特殊内容移除）与增强（如 Few-Shot 生成），暂不支持 DPO、CPT 或视觉类训练集 [数据清洗或增强](../../raw/model-user-guide/model-data-overview/data-processing.md)。
- **日志回流**：支持将 SLS 推理日志自动转化为结构化 JSONL 数据集，适用于训练集（SFT/DPO/CPT）和评测集（文本生成），当前仅在北京和新加坡地域可用 [日志回流](../../raw/model-user-guide/model-data-overview/model-log-backflow.md)。

> **注意**：文档 2 明确指出“数据处理暂不支持 SFT-图片理解训练集和 DPO-文本生成训练集”，但文档 1 中“训练方法与场景”表格未排除 DPO 训练集用于数据处理。此处以文档 2 的明确限制为准——DPO 训练集**不可用于数据清洗或增强**。

## 关键参数

| 参数 | 说明 | 是否必填 | 取值范围/约束 |
|------|------|----------|----------------|
| 数据集名称 | 唯一标识符 | 是 | ≤50 字符，支持中文、英文、数字、下划线、连字符、点（文档 1）或斜杠（文档 3）；命名建议含功能场景\_模型名\_时间 |
| 数据集类型 | 创建后不可变更 | 是 | `训练集` 或 `评测集` |
| 训练场景 | 仅训练集需选 | 是 | `文本生成` / `视觉理解` / `图生视频（首帧）` / `图生视频（首尾帧）`；评测集固定为文本生成 |
| 训练方法 | 仅训练集需选 | 是 | `SFT`（全地域）、`DPO`（仅北京）、`CPT`（仅北京） |
| 数据格式 | 导入文件格式 | 是 | `Jsonl 格式` 或 `Excel 格式`（文档 1）；日志回流产出固定为 `JSONL`（文档 3） |
| 存储位置 | 影响计费与权限 | 是 | `平台 OSS 存储`（免费，自动发布）或 `云存储挂载`（需 OSS 授权，仅训练集可用，评测集禁用） |
| 导入方式 | 决定前置条件 | 是 | `本地上传`（无依赖）、`从 OSS 导入`（Bucket 需标签 `bailian-datahub-access=read`）、`日志回流`（需 SLS 授权+审计/推理日志开启）、`API 上传` |

## 使用方式

- **创建数据集**：在控制台 **[数据管理](https://bailian.console.aliyun.com/cn-beijing/model/data)** > **数据集** 页面点击 **创建数据集**，按向导填写参数并选择导入方式；提交即发布，不支持草稿保存（历史草稿除外）。
- **数据处理**：仅支持 SFT-文本生成训练集（ChatML 格式）。在 **数据管理 > 数据流** 页签创建数据流任务，选择目标训练集，系统自动生成新版本（如 V1 → V2），原版本不受影响 [数据清洗或增强](../../raw/model-user-guide/model-data-overview/data-processing.md)。
- **日志回流**：需先在 **模型监控 > 日志服务** 完成审计日志与推理日志的授权及开通（顺序不可逆），再通过模型监控页、模型详情页或数据管理页入口配置时间范围、API Key、模型等参数；单次上限 10 万条，可多次追加至不同版本 [日志回流](../../raw/model-user-guide/model-data-overview/model-log-backflow.md)。
- **API 集成**：通过 `training_file_ids` 参数在模型调优 API 中引用已发布训练集 ID；数据集 CRUD 当前仅支持控制台操作（文档 1 明确说明）。

## 限制和注意事项

- **地域限制**：DPO/CPT 训练、数据处理功能、日志回流均**仅限华北2（北京）地域**；日志回流额外支持新加坡地域（文档 3）。
- **格式与兼容性**：
  - 数据处理仅接受 ChatML 格式的 SFT-文本生成训练集，不支持 Excel 或其他格式（文档 2）；
  - 评测集不支持 OSS 导入和 OSS 挂载（文档 1、文档 3）；
  - 日志回流产出数据为 JSONL，不可直接用于视觉/图生视频训练（需人工转换）。
- **版本与变更**：
  - 数据集类型、训练场景、训练方法、存储位置、数据格式**创建后不可变更**；
  - 新增版本采用“新建模式”，需重新导入全部数据，不支持增量修改（文档 1）；
  - OSS 挂载数据集**不支持“新增版本”操作**，只能通过“导入数据”页追加（文档 3）。
- **安全与合规**：
  - 所有导入数据默认启用 SSE-OSS 加密；
  - 敏感信息打码等清洗操作需人工校验输出，确保语义完整性未被破坏（文档 2 强调）；
  - 日志回流涉及 SLS 和 OSS 多角色授权，关闭日志后已有数据不可复原（文档 3）。
- **用量边界**：
  - 单次日志回流上限 10 万条（可多次执行）；
  - 数据增强-通用节点单次最多生成 2000 条样本（文档 2）；
  - 数据集创建数量无上限，但推荐按业务场景合理划分（如 `qa_sft_qwen2_202410`）。
