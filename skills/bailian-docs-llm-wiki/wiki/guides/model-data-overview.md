# model data overview

阿里云百炼平台提供统一的数据管理功能，帮助开发者高效创建和管理模型训练与评测所需的数据集。数据集分为训练集（用于模型调优）和评测集（用于模型评测）两类，同时平台还提供数据清洗与数据增强能力，用于提升训练数据的质量和规模。本页面汇总了百炼平台支持的数据集类型、格式规范及数据处理流程。

> **注意**：数据管理功能仅适用于中国大陆版（北京地域）。

## 训练集类型与格式

百炼平台支持多种训练集类型，详见[训练集与评测集](../../raw/model-user-guide/model-data-overview/training-set-and-evaluation-set.md)。

### SFT 训练集（文本生成）

采用 ChatML 格式，支持多轮对话和 system/user/assistant 三种角色。每行一个 JSON 对象：

```json
{"messages": [
  {"role": "system", "content": "系统输入"},
  {"role": "user", "content": "用户输入"},
  {"role": "assistant", "content": "期望的模型输出"}
]}
```

关键参数：

- `loss_weight`（0.0~1.0）：设置 assistant 行在训练中的相对重要性（邀测参数，需联系商务经理开通）
- 支持 `.jsonl` 和 `.xlsx` 格式（xlsx 仅支持单轮对话）
- 不支持 OpenAI 的 `name`、`weight` 参数

### SFT 思考模型（Thinking）

在标准 ChatML 基础上，仅对最后一个 assistant 输出进行训练，思考内容用 `<think>` 标签包裹：

```json
{"role": "assistant", "content": "<think>\n思考内容\n</think>\n\n最终输出"}
```

> **注意**：思考标签前后的 `\n` 必须保留。如果训练样本中不添加 `<think>` 标签，模型训练完成后不建议再开启思考模式调用。

### SFT 视觉理解（千问 VL）

支持图片和视频输入，`content` 字段使用数组格式。图片通过 `{"image": "文件名.jpg"}` 引用，视频通过 `{"video": "文件名.mp4"}` 或图片帧列表模式引用。视频文件路径模式仅 qwen3.5 及以后的 VL 模型支持。

压缩包要求：

- 格式：ZIP，最大 2GB
- 训练文本数据固定命名为 `data.jsonl`，位于压缩包根目录
- 图片单张宽高均不超过 1024px，最大 10MB
- 图片文件名全局唯一（即使分布在不同文件夹中）

### DPO 训练集

用于人类偏好对齐，在标准对话基础上增加 `chosen` 和 `rejected` 字段：

```json
{
  "messages": [...],
  "chosen": {"role": "assistant", "content": "赞同的输出"},
  "rejected": {"role": "assistant", "content": "反对的输出"}
}
```

训练集通常需要上百条人类偏好数据。`chosen` 模块同样支持 `loss_weight` 参数。

### CPT 训练集

纯文本格式，用于持续预训练，最少需要一千万 Token 优质数据：

```json
{"text": "文本内容"}
```

### 图生视频训练集

支持两种模式：

- **基于首帧**：提供首帧图像 + 训练视频 + `data.jsonl` 标注文件
- **基于首尾帧**：提供首帧图像 + 尾帧图像 + 训练视频 + `data.jsonl` 标注文件

两种模式均可选提供验证集（无需视频，系统自动生成预览视频）。图像最大分辨率 4096x4096，视频支持 MP4/MOV 格式。

## 评测集

目前仅支持文本生成评测集，采用 Excel 格式，包含 Prompt 和 Completion 两列。评测时模型基于 Prompt 推理，评分员参考 Completion 进行评分。

## 数据处理

当训练数据质量不足时，可通过百炼的[数据清洗或增强](../../raw/model-user-guide/model-data-overview/data-processing.md)功能进行预处理。

> **注意**：数据处理目前仅支持 SFT 文本生成训练集（ChatML 格式），不支持 SFT 图片理解训练集和 DPO 训练集。目前暂未提供 API，只能通过控制台操作。

### 数据清洗

修正训练数据中的规范性、合规性、一致性及重复问题。支持的算子包括：

- 特殊内容移除（URL、特殊字符等）
- 敏感信息打码（脱敏处理）
- 文章相似度去重
- 敏感词过滤
- 毒性消除

建议每个数据清洗节点只开启一个算子，便于检测和纠正错误。

### 数据增强

通过 Few-Shot 策略调用千问-Max 模型生成新数据（暂不支持选择其他模型），支持四种场景：

| 场景 | 说明 |
|------|------|
| 数据增强-通用 | 适用于通用 SFT 训练集增强，每次最多生成 2000 条样本 |
| 数据增强-文本分类 | 针对文本分类场景优化 |
| 数据增强-文本抽取 | 针对文本抽取场景优化 |
| 数据增强-文本创作 | 针对文本创作场景优化 |

关键参数：

- **生成样本数**：需要生成的数据条数
- **指令生成依赖样本数**：从训练集中抽取的种子数量
- **过滤相似度阈值**：控制生成数据与已有数据的相似度
- **Prompt 配置**：定义增强任务的输入输出要求，支持自定义模板

### 数据流搭建

数据处理通过可视化的数据流画布实现，支持以下节点类型：

1. **开始/结束节点**：数据流的入口与出口
2. **数据清洗节点**：执行清洗算子，支持拖拽调整执行顺序
3. **数据增强节点**：执行增强操作
4. **条件判断节点**：根据 `dataSetCount` 等变量控制分支逻辑

操作流程：创建数据流 → 发布 → 创建数据流任务 → 选择训练集 → 执行。处理后的训练集会自动生成新版本，不会覆盖原数据。

## 数据集规模建议

根据[训练集与评测集](../../raw/model-user-guide/model-data-overview/training-set-and-evaluation-set.md)中的说明，不同训练方式对数据量的最低要求为：

| 训练方式 | 最低数据量 |
|----------|-----------|
| CPT | 一千万 Token 优质预训练数据 |
| SFT | 上千条优质微调数据 |
| DPO | 上百条人类偏好数据 |

如果模型调优后效果不佳，最简单的改进方法是收集更多数据进行训练。建议在准备训练集的同时，准备一份不重叠的评测集用于评估调优效果。
