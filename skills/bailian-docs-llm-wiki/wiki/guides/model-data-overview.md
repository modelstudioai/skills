# model data [overview](overview.md)

百炼平台的模型数据管理功能为大模型训练与评测提供统一的数据集生命周期支持，涵盖训练集（SFT/DPO/CPT）、评测集的创建、导入、版本管理及后处理。所有数据集均需在业务空间下统一管理，存储与下游使用紧密耦合，开发者应根据训练目标、地域限制和数据质量要求谨慎选型与配置。

## 支持的模型/功能

- **训练集类型**：支持文本生成、视觉理解、图生视频（首帧）、图生视频（首尾帧）四类训练场景；其中 SFT、DPO、CPT 仅适用于文本生成场景，视觉与图生视频暂无官方推荐数据量指引。  
- **评测集类型**：仅支持文本生成场景，不可用于视觉或视频类任务。  
- **数据处理能力**：仅支持对 **SFT-文本生成训练集（ChatML 格式）** 进行清洗与增强，不支持 DPO 训练集、视觉理解训练集或评测集的数据处理 [数据清洗或增强](../../raw/model-user-guide/model-data-overview/data-processing.md)。  
- **日志回流能力**：支持将 SLS 推理日志转化为结构化训练集（SFT/DPO/CPT）或评测集（文本生成），但仅限华北2（北京）和新加坡 Region；单次上限 10 万条，可多次追加至不同版本 [日志回流](../../raw/model-user-guide/model-data-overview/model-log-backflow.md)。  
> **注意**：文档 2 明确声明“暂不支持[SFT-图片理解训练集]和[DPO-文本生成训练集]”，而文档 1 表述为“训练集支持4种训练场景”，未限定数据处理适用范围。此处以文档 2 的明确排除为准，避免误用。

## 关键参数

| 参数 | 说明 | 必填 | 取值约束 |
|------|------|------|-----------|
| 数据集名称 | 唯一标识符 | 是 | ≤50 字符，支持中文、英文、数字、下划线、连字符、点（文档 1）或斜杠（文档 3）；建议按 `功能_模型_时间` 命名 |
| 数据集类型 | 创建后不可变更 | 是 | `训练集` 或 `评测集` |
| 训练场景 | 仅训练集可见 | 是 | `文本生成` / `视觉理解` / `图生视频（首帧）` / `图生视频（首尾帧）` |
| 训练方法 | 仅训练集可见 | 是 | `SFT`（全站点）、`DPO`（仅北京）、`CPT`（仅北京） |
| 数据格式 | 导入文件格式 | 是 | `Jsonl 格式` 或 `Excel 格式` |
| 存储位置 | 影响计费与操作权限 | 是 | `平台 OSS 存储`（免费，自动发布）或 `云存储挂载`（需 OSS 授权，仅训练集可用，不支持评测集） |
| 导入方式 | 决定前置条件与适用性 | 是 | `本地上传`（无依赖）、`从 OSS 导入`（Bucket 需标签 `bailian-datahub-access=read`）、`日志回流`（需 SLS 授权）、`API 上传` |

## 使用方式

- **创建流程**：在 [数据管理](https://bailian.console.aliyun.com/cn-beijing/model/data) > 数据集列表页点击「创建数据集」，严格按顺序填写参数（修改时间范围等会联动重置其他字段）。提交即发布，不再保留草稿状态（历史草稿仍可编辑）[训练集与评测集](../../raw/model-user-guide/model-data-overview/training-set-and-evaluation-set.md)。  
- **日志回流专用路径**：可通过模型监控列表页、模型监控详情页或数据管理页的「日志回流」入口进入专属表单，需先完成审计日志与推理日志的分步授权 [日志回流](../../raw/model-user-guide/model-data-overview/model-log-backflow.md)。  
- **数据处理（清洗/增强）**：仅支持控制台操作，需先创建数据流（含开始→数据清洗→数据增强→结束节点），再基于该数据流启动任务；处理结果自动生成新版本，不覆盖原数据集 [数据清洗或增强](../../raw/model-user-guide/model-data-overview/data-processing.md)。  
- **版本管理**：所有数据集支持多版本，新增版本需重新导入全部数据（非增量），OSS 挂载数据集不支持「新增版本」按钮，须通过「导入数据」页追加。

## 限制和注意事项

- **地域限制**：DPO/CPT 训练、数据清洗/增强、日志回流（除新加坡外）均仅支持华北2（北京）Region；OSS 挂载存储也仅限北京。  
- **数据量约束**：  
  - SFT 建议 ≥1000 条，DPO 建议 ≥100 条，CPT 建议 ≥5000 万 [Token](../concepts/token.md)；  
  - 日志回流单次上限 10 万条（可多次执行）；  
  - 数据集创建数量与总数据量无硬性上限，但单次 API 上传或本地上传受网络与内存限制。  
- **格式与兼容性**：  
  - 数据处理仅接受 ChatML 格式的 SFT 文本训练集，其他格式（如纯 prompt-completion）或非文本训练集不支持；  
  - 评测集导出为 `.xlsx`，SFT 训练集导出为 `.jsonl`，视觉训练集导出为 `.zip`；  
  - 所有导入数据默认启用 SSE-OSS 加密。  
- **不可逆操作**：发布、删除（含整个数据集及其所有版本）均不可恢复；已发布版本不可编辑，仅历史草稿版本可删改。  
- **计费提示**：数据管理功能本身免费，但平台 OSS 存储、OSS 挂载、SLS 日志服务分别计入对应产品账单，请提前查阅最新计费文档。
