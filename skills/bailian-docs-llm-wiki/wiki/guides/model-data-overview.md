# model data [overview](overview.md)

百炼平台的模型数据管理功能为大模型调优与评测提供统一、可复用的数据集基础设施。它支持训练集（SFT/DPO/CPT）和评测集两类数据集的创建、版本管理、清洗增强及日志回流，覆盖文本生成、视觉理解、图生视频等多场景。所有数据集均默认启用 OSS 服务端加密（SSE-OSS），存储与下游使用遵循地域与权限约束。

## 支持的模型/功能

- **数据集类型**：仅支持**训练集**（用于模型调优）和**评测集**（用于模型评测），创建后类型不可变更。  
- **训练场景**：训练集支持文本生成、视觉理解、图生视频（首帧）、图生视频（首尾帧）；**评测集仅支持文本生成**。  
- **训练方法**：SFT（监督微调）、DPO（直接偏好优化）、CPT（持续预训练）。其中 DPO 和 CPT **仅限北京地域**可用；SFT 全站点支持。  
- **高级功能**：  
  - **日志回流**：将 SLS 推理日志自动转化为结构化训练/评测数据集，支持北京和新加坡 Region [日志回流](../../raw/model-user-guide/model-data-overview/model-log-backflow.md)；  
  - **数据处理**（清洗与增强）：仅支持 **SFT-文本生成训练集（ChatML 格式）**，不支持 DPO、CPT 或视觉类训练集 [数据清洗或增强](../../raw/model-user-guide/model-data-overview/data-processing.md)；  
  > **注意**：文档 2 明确限定数据处理“仅适用于华北2（北京）地域”，但未说明是否与 DPO/CPT 的地域限制一致；而文档 1 和 3 均指出 DPO/CPT 仅限北京。因此，数据处理功能实际也仅在北京可用，该隐含约束需开发者主动确认。

## 关键参数

| 参数 | 说明 | 是否必填 | 取值范围/约束 |
|------|------|----------|----------------|
| 数据集名称 | 标识符，最长 50 字符 | 是 | 中文、英文、数字、下划线、连字符、点（文档 1）或斜杠（文档 3） |
| 数据集类型 | 训练集 / 评测集 | 是 | 创建后不可变更 |
| 训练场景 | 文本生成 / 视觉理解 / 图生视频（首帧/首尾帧） | 是 | 评测集仅允许“文本生成” |
| 训练方法 | SFT / DPO / CPT | 是 | 仅训练集显示；DPO/CPT 仅北京可用 |
| 数据格式 | Jsonl 格式 / Excel 格式 | 是 | 模板需严格匹配场景要求 [训练集与评测集](../../raw/model-user-guide/model-data-overview/training-set-and-evaluation-set.md) |
| 存储位置 | 平台 OSS 存储 / 云存储挂载 | 是 | 评测集不支持云存储挂载；OSS 挂载需 Bucket 标签 `bailian-datahub-access=read` |
| 导入方式 | 本地上传 / 从 OSS 导入 / 日志回流 / API 上传 | 是 | 评测集不支持“从 OSS 导入”；日志回流单次上限 10 万条 |

## 使用方式

- **创建流程**：在控制台 **[数据管理](https://bailian.console.aliyun.com/cn-beijing/model/data)** > **数据集** 页面点击「创建数据集」，按向导填写参数并选择导入方式。  
- **导入方式选择指南**：  
  - 小批量数据 → **本地上传**（支持多文件）；  
  - 大批量已有数据 → **从 OSS 导入**（需提前配置 Bucket 标签）；  
  - 从线上推理反馈闭环构建数据 → **日志回流**（需先开通审计日志+推理日志并授权角色）；  
  - 自动化集成 → **API 上传**（通过 `training_file_ids` 引用已发布数据集 ID）。  
- **数据处理（清洗/增强）**：仅对已发布的 SFT-文本生成训练集生效，在 **数据管理 > 数据流** 页签创建任务，输出为独立新版本（如 V1 → V2），不覆盖原数据。  
- **版本管理**：新增版本需重新导入全部数据（无增量编辑）；历史草稿版本可在线编辑 Prompt/Completion，但新建数据集提交即发布，不再产生草稿。

## 限制和注意事项

- **地域限制**：DPO/CPT 训练、数据处理、日志回流（除新加坡外）均**仅限北京地域**；OSS 挂载存储也仅限北京。  
- **数据量约束**：  
  - 日志回流单次最多回流 10 万条（可多次追加至不同版本）；  
  - SFT 推荐数据量 ≥1000 条，DPO ≥100 条，CPT ≥5000 万 Token；  
  - 数据集创建数量与总数据量无硬性上限，但受存储配额与计费约束。  
- **格式与兼容性**：  
  - 数据处理仅接受 ChatML 格式的 SFT-文本生成训练集，不支持 DPO、CPT 或视觉类数据；  
  - 评测集必须为独立、数据不重叠的集合，且仅支持文本生成场景。  
- **操作不可逆**：  
  > **注意**：发布和删除操作均不可逆；已发布版本不可编辑；删除整个数据集将移除其下所有版本，**请务必谨慎执行**。  
- **计费提示**：数据管理功能本身免费，但平台 OSS 存储、OSS 挂载、SLS 日志服务等下游资源按各自产品计费。
