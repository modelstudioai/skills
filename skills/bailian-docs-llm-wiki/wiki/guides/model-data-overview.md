# model data overview

百炼平台的模型数据管理功能为大模型调优与评测提供统一、可版本化、可扩展的数据基础设施。它支持训练集（SFT/DPO/CPT）和评测集两类数据集，覆盖文本生成、视觉理解、图生视频等多模态场景，并提供本地上传、OSS 导入、日志回流、API 上传等多种数据接入方式。所有数据集均默认启用 OSS 服务端加密（SSE-OSS），存储与处理行为受地域、训练方法及数据格式约束。

## 支持的模型/功能

- **数据集类型**：仅支持创建**训练集**（用于模型调优）和**评测集**（用于模型评测），创建后类型不可变更。  
- **训练场景**：训练集支持文本生成、视觉理解、图生视频（首帧）、图生视频（首尾帧）；**评测集仅支持文本生成**。  
- **训练方法支持**：  
  - **SFT**（监督微调）：全部站点可用，推荐数据量 ≥1000 条；  
  - **DPO**（直接偏好优化）：**仅北京地域可用**，推荐数据量 ≥100 条；  
  - **CPT**（持续预训练）：**仅北京地域可用**，推荐数据量 ≥5000 万 Token。  
- **日志回流**：支持将 SLS 推理日志转化为结构化训练集或评测集，**当前仅在北京和新加坡 Region 可用**，单次上限 10 万条，可多次回流至不同版本积累数据 [日志回流](../../raw/model-user-guide/model-data-overview/model-log-backflow.md)。  
- **数据处理（清洗与增强）**：**仅支持 SFT-文本生成训练集（ChatML 格式）**，不支持 DPO、CPT、视觉理解类训练集，且**仅限北京地域** [数据清洗或增强](../../raw/model-user-guide/model-data-overview/data-processing.md)。  

> **注意**：文档 2 明确指出“数据处理暂不支持 SFT-图片理解训练集和 DPO-文本生成训练集”，但文档 1 表格中“训练方法与场景”一栏未标注此限制，实际以文档 2 的明确声明为准。

## 关键参数

| 参数 | 说明 | 是否必填 | 取值范围/约束 |
|------|------|----------|----------------|
| 数据集名称 | 唯一标识符 | 是 | ≤50 字符，支持中文、英文、数字、下划线、连字符、点（文档 1）；文档 3 允许斜杠，建议按 `功能场景_模型名_时间` 命名 |
| 数据集类型 | 训练集 / 评测集 | 是 | 创建后不可变更 |
| 训练场景 | 数据适用的下游任务类型 | 是 | 文本生成 / 视觉理解 / 图生视频（首帧）/ 图生视频（首尾帧）；评测集固定为文本生成 |
| 训练方法 | 仅训练集需选 | 是 | SFT / DPO / CPT；DPO/CPT 仅北京可用 |
| 数据格式 | 文件组织形式 | 是 | Jsonl 格式 或 Excel 格式（推荐下载模板校验格式） |
| 存储位置 | 数据物理存放方式 | 是 | 平台 OSS 存储（免费，自动发布）或云存储挂载（需 Bucket 标签 `bailian-datahub-access=read`，仅训练集可用） |
| 导入方式 | 数据来源路径 | 是 | 本地上传 / 从 OSS 导入 / 日志回流 / API 上传；其中评测集**不支持 OSS 导入** [训练集与评测集](../../raw/model-user-guide/model-data-overview/training-set-and-evaluation-set.md) |

## 使用方式

- **创建流程**：进入 [数据管理 > 数据集](https://bailian.console.aliyun.com/cn-beijing/model/data) → 点击**创建数据集** → 按顺序填写名称、类型、场景、方法、格式、存储、导入方式 → 提交即**立即发布**（无草稿模式，历史草稿仅限编辑）。  
- **日志回流专用入口**：除数据管理页外，还可通过 [模型监控列表页](https://bailian.console.aliyun.com/model/telemetry) 或模型监控详情页顶部的**日志回流**按钮快速进入配置表单，自动预填时间/模型等字段。  
- **数据处理（清洗/增强）**：在数据管理 > **数据流**页签创建自定义工作流，支持敏感信息打码、去重、毒性消除等清洗算子，以及基于千问-Max 的 Few-Shot 数据增强；处理结果自动生成新版本，**不覆盖原数据集** [数据清洗或增强](../../raw/model-user-guide/model-data-overview/data-processing.md)。  
- **API 集成**：通过 `training_file_ids` 参数在模型调优 API 中引用已发布训练集 ID；日志回流暂无对应 API，仅支持控制台操作。

## 限制和注意事项

- **地域限制**：DPO/CPT 训练、数据处理（清洗/增强）、日志回流（部分能力）均**仅限华北2（北京）地域**；日志回流额外支持新加坡 Region。  
- **格式强约束**：SFT/DPO/CPT/评测集均有严格数据格式要求（如 ChatML、JSONL 结构），务必使用官方模板准备数据，否则导入失败。  
- **不可逆操作**：  
  - 发布后的数据集版本**不可编辑、不可删除**；  
  - 删除整个数据集将**永久移除其所有版本**；  
  - 仅历史创建的草稿版本可删除或在线编辑。  
- **OSS 挂载限制**：  
  - 评测集**不支持** OSS 挂载；  
  - OSS 挂载数据集**不支持“新增版本”操作**，追加数据须通过“导入数据”页完成。  
- **日志回流限制**：  
  - 仅支持最近 30 天内日志；  
  - 单次最多回流 10 万条（非总量上限，可分批累积）；  
  - 预估数据量为近似值，实际条数可能略有偏差。  
- **计费提示**：数据管理功能本身免费，但平台 OSS 存储、OSS 挂载、SLS 日志服务等下游资源按各自产品计费。
