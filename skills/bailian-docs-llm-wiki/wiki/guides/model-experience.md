# model experience

模型体验（Model Experience）是百炼平台提供的统一交互界面，用于快速试用、调试和评估各类大模型能力。开发者可通过该功能在不编写代码的前提下，直观验证模型输入输出行为、参数影响及[多模态](../concepts/multi-modal.md)支持效果。所有体验均基于真实部署的在线服务，与生产调用保持一致行为。

## 支持的模型/功能

当前支持以下模型类型与功能模块：
- 文本生成（包括对话、补全、摘要等）
- 视觉理解（图像分类、OCR、图文理解等）
- 图片生成与编辑（文生图、图生图、局部重绘等）
- 视频生成与编辑（文生视频、视频风格迁移等）
- 3D模型生成（TriPo 等结构化3D输出）
- 语音合成（TTS）、语音识别（ASR）、语音转语音（V2V）
- 音乐生成（FunMusic）
- 全模态理解与生成（支持文本+图像+音频联合输入输出）
- 向量嵌入（Embedding）与重排序（Rerank）

详细能力说明请参阅 [模型体验](../../raw/model-user-guide/model-experience.md)。

## 关键参数

各模型体验页提供可调节的核心参数，常见参数包括：
- `temperature`：控制输出随机性（0.0–2.0），默认值依模型而异；
- `top_p`：核采样阈值（0.0–1.0），与 `temperature` 协同使用；
- `max_tokens`：最大生成长度，上限受模型上下文窗口限制；
- `seed`：固定随机种子以复现结果（部分模型支持）；
- [多模态](../concepts/multi-modal.md)任务中额外支持 `image_size`、`audio_format`、`video_fps` 等专用参数。

参数范围与默认值以实际体验页面为准；部分参数在 [模型体验](../../raw/model-user-guide/model-experience.md) 中未明确列出，建议结合具体模型文档确认。

## 使用方式

1. 登录百炼控制台 → 进入「模型体验」页；
2. 在左侧导航栏选择目标模型类型（如“图片生成与编辑”）；
3. 从模型列表中选择已开通的实例（如 `qwen-vl-plus`、`wanx-video`）；
4. 输入提示词（Prompt）或上传媒体文件，调整参数后点击「运行」；
5. 查看实时输出结果，并可导出请求/响应 JSON 或复制 cURL 命令用于后续开发。

> **注意**：部分新上线模型（如 `qwen-audio-2.5`）在 [模型体验](../../raw/model-user-guide/model-experience.md) 中尚未列出对应入口，需通过控制台搜索或查看最新公告获取支持状态。

## 限制和注意事项

- 每次体验调用受配额限制（默认 100 次/日/账号），超出后需申请提升；
- 视频与3D生成类任务耗时较长，超时阈值为 120 秒，超时将返回错误；
- 所有上传文件须符合安全策略：禁止可执行文件、压缩包内嵌脚本，图片/音频/视频格式需在白名单内；
- 体验环境不支持自定义系统提示词（system [prompt](prompt.md)）或工具调用（function calling），如需完整能力请直接调用 API；
- [多模态](../concepts/multi-modal.md)输入（如图文混合）需严格遵循模型要求的格式（如 Base64 编码或 URL 引用），详见对应模型文档。

如需了解底层服务协议与错误码含义，请参考 [模型体验](../../raw/model-user-guide/model-experience.md)。
