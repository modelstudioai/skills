# model experience

模型体验（Model Experience）是百炼平台提供的统一交互界面，用于快速试用、调试和评估各类大模型能力。开发者可通过该功能在不编写代码的前提下，直观验证模型输入输出行为、参数影响及多模态支持效果。所有体验均基于真实部署的在线服务，与生产调用保持一致行为。

## 支持的模型/功能

当前支持以下模型类型与功能模块：
- 文本生成（包括对话、补全、摘要等）
- 视觉理解（图像分类、OCR、图文理解等）
- 图片生成与编辑（文生图、图生图、局部重绘等）
- 视频生成与编辑（文生视频、视频风格迁移等）
- 3D模型生成（TriPo 等结构化3D输出）
- 语音合成（TTS）、语音识别（ASR）、语音转语音（V2V）
- 音乐生成（FunMusic）
- 全模态理解与生成（支持文本+图像+音频联合输入输出）
- 向量嵌入（Embedding）与重排序（Rerank）

详细能力说明请参阅 [模型体验](../../raw/model-user-guide/model-experience.md)。

## 关键参数

各模型体验页提供可调节的核心参数，常见参数包括：
- `temperature`：控制输出随机性（0.0–2.0），默认值依模型而异；
- `top_p`：核采样阈值（0.0–1.0），与 `temperature` 协同使用；
- `max_tokens`：最大生成长度，上限受模型上下文窗口限制；
- `seed`：固定随机种子以复现结果（部分模型支持）；
- 多模态任务中额外支持 `image_size`、`audio_format`、`video_duration` 等专用参数。

> **注意**：部分旧版文档（如 [模型体验](../../raw/model-user-guide/model-experience.md) 中未明确列出 `seed` 参数支持范围）与实际控制台行为存在差异——目前仅 Qwen-VL、Qwen-Audio、Qwen2-Audio 等新版多模态模型支持 `seed`；文本模型暂不支持。建议以控制台实时参数面板为准。

## 使用方式

1. 登录百炼控制台 → 进入「模型体验」页面；
2. 在左侧模型目录中选择目标模型（支持按模态或模型名筛选）；
3. 输入提示词（Prompt）或上传媒体文件（图片/音频/视频）；
4. 调整参数后点击「运行」，实时查看响应与耗时；
5. 可导出请求/响应 JSON、复制 cURL 命令，或一键跳转至 API 调用示例页。

该流程与 [模型体验](../../raw/model-user-guide/model-experience.md) 所述一致，但需注意：部分新上线模型（如 Qwen2-VL）可能尚未在该文档中更新入口链接，建议通过控制台搜索栏直接查找。

## 限制和注意事项

- 每次体验调用受配额限制（免费用户默认 100 次/日，企业版按实例规格分配）；
- 视频与3D生成任务单次请求最大等待时间 180 秒，超时将返回错误；
- 上传文件大小限制：图片 ≤ 20 MB，音频 ≤ 100 MB，视频 ≤ 500 MB，3D 输入格式仅支持 `.obj` / `.glb`；
- 所有体验数据默认不落库，但日志会留存 7 天供审计（符合 [模型体验](../../raw/model-user-guide/model-experience.md) 的隐私声明）；
- 不支持批量提交或多轮会话状态持久化（如需完整对话管理，请使用 SDK 或 API）。
