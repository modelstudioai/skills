# model experience

模型体验（Model Experience）是百炼平台提供的统一交互界面，用于快速试用、调试和评估各类大模型能力。开发者可通过该功能在不编写代码的前提下，直观验证模型输入输出行为、参数影响及多模态支持效果。所有体验均基于真实部署的在线服务，与 API 调用行为一致。

## 支持的模型与功能

当前支持以下模型类型及对应能力：
- 文本生成（如 Qwen 系列）
- 视觉理解（图文理解、OCR、目标检测等）
- 图片生成与编辑（文生图、图生图、局部重绘）
- 视频生成与编辑（文生视频、视频扩时、关键帧编辑）
- 3D 模型生成（TriPo 3D）
- 语音合成（TTS）、语音识别（ASR）、语音转语音（S2S）
- 音乐生成（FunMusic）
- 全模态理解与生成（Omni-Modal）
- 向量嵌入（Embedding）与重排序（Rerank）

详细能力说明见 [模型体验](../../raw/model-user-guide/model-experience.md)。

## 关键参数

各模型体验页提供可调节的核心参数，常见参数包括：
- `temperature`：控制输出随机性（0.0–2.0），默认 1.0  
- `top_p`：核采样阈值（0.0–1.0），默认 0.8  
- `max_tokens`：最大生成长度，按模型能力动态限制（如 Qwen2-72B 最高支持 32768）  
- `seed`：固定随机种子，确保结果可复现  
- 多模态专属参数（如图像分辨率、视频时长、语音语速/音色 ID）需参考具体模型文档，例如 [视觉理解](../../raw/model-user-guide/model-experience.md) 和 [语音合成](../../raw/model-user-guide/model-experience.md) 中所列能力均依赖对应参数组合生效。

> **注意**：部分旧版文档中 `repetition_penalty` 默认值标注为 1.0，但实际平台当前默认为 1.1；请以控制台实时参数面板为准。

## 使用方式

1. 登录百炼控制台 → 进入「模型体验」页  
2. 在左侧模型目录中选择目标模型（支持按模态或模型名筛选）  
3. 输入 [prompt](prompt.md) 或上传媒体文件（图片/音频/视频）  
4. 调整参数后点击「运行」，实时查看响应与耗时、[Token](../concepts/token.md) 统计  
5. 可保存历史会话、导出 cURL 命令或一键跳转至 API 调用示例页  

完整操作指引参见 [模型体验](../../raw/model-user-guide/model-experience.md)。

## 限制和注意事项

- 单次请求最大输入长度受模型上下文窗口限制（如 Qwen-VL-Max 为 8192 tokens，视频模型通常限制单帧分辨率与总帧数）  
- 免费体验额度按账号每日发放，超出后需绑定付费方式或使用已购资源包  
- 视频与 3D 生成任务排队时间较长，建议避开高峰时段提交  
- 所有体验调用均计入账号的 API 调用量配额，与正式 API 共享限流策略  
- 不支持自定义模型权重上传或私有化部署环境下的本地体验（该能力仅限「模型训练」与「[模型部署](../concepts/model-deployment.md)」模块）
