# plug in

百炼平台提供插件机制，通过将外部工具（API）集成到大模型应用中，弥补大模型在实时信息获取、精确计算、代码执行等方面的不足。插件分为官方插件、第三方插件和自定义插件三类，支持通过智能体应用、工作流应用和 Assistant API 等多种方式调用。

## 插件类型

### 官方插件

百炼组件广场预置了一系列官方插件，无需配置输入输出参数即可直接使用。主要包括：

| 插件名称 | 工具 ID | 功能 | 计费 |
|---------|---------|------|------|
| Python 代码解释器 | `code_interpreter` | 执行 Python 代码，支持数学计算、数据分析与可视化 | 免费 |
| 计算器 | `calculator` | 复杂数学计算 | 免费 |
| 图片生成 | `text_to_image` | 基于文本生成图片 | 限时免费，需申请开通 |
| 夸克搜索 | `quark_search` | 搜索实时信息（仅返回网页标题、关键词和摘要，不支持访问网页详情） | 限时免费，需申请开通 |
| 生成二维码 | `generate_qrcode` | 根据链接地址生成二维码 | 免费 |
| GitHub 搜索 | `github_search` | 在 GitHub 中搜索项目 | 免费 |

> **注意**：Python 代码解释器不支持对外访问网络及上传本地文件，可用依赖列表有限。详见[官方和第三方插件](../../raw/application-user-guide/plug-in/plugins.md)文档。

### 第三方插件

第三方插件涵盖商业服务、图像视频、学习教育等领域，经过效果测试后可在开通后直接调用，无需额外配置。开通流程：在[插件](https://bailian.console.aliyun.com/#/plugin-market)页面找到目标插件，选择套餐后购买或免费试用。

### 自定义插件

当官方和第三方插件无法满足业务需求时，可以创建自定义插件扩展大模型能力。详细流程参见[自定义插件](../../raw/application-user-guide/plug-in/custom-plug-ins.md)文档。

## 支持的模型

以下模型支持插件调用：

| 模型 | 模型标识符 |
|------|-----------|
| 通义千问-Turbo | `qwen-turbo` |
| 通义千问-Plus | `qwen-plus` |
| 通义千问-Max | `qwen-max` |
| 通义千问VL-Max | `qwen-vl-max` |
| 通义千问VL-Plus | `qwen-vl-plus` |

> **注意**：各模型对插件的兼容性可能有差异，以控制台实际执行结果为准。

## 插件调用机制

调用插件的本质是调用插件下的工具。百炼支持三种调用方式：

1. **智能体应用**：在应用编排页面添加插件工具，大模型根据用户输入和工具描述自动判断是否调用。
2. **工作流应用**：将插件作为工作流节点，按编排顺序执行，而非由大模型主动规划调用。
3. **Assistant API**：通过 `tools` 参数指定工具 ID 进行调用。

调用流程：大模型根据用户输入、工具名称和工具描述判断是否需要调用插件。如需调用，选择合适的工具完成调用后，将工具返回结果和用户内容合并，再由大模型生成最终输出。详见[插件概述](../../raw/application-user-guide/plug-in/plug-in-overview.md)。

## 创建自定义插件

自定义插件的完整流程包括四个阶段：

### 1. 创建插件

在[插件](https://bailian.console.aliyun.com/?tab=app#/component-manage)页面点击"创建插件"，填写以下信息：

- **插件名称**：具有语义的名称，支持中英文
- **插件描述**：功能和使用场景的简要说明，帮助大模型判断是否调用
- **插件 URL**：插件的访问域名（同一插件下不同工具共用同一域名）
- **鉴权配置**（可选）：支持服务级鉴权和用户级鉴权，鉴权信息可放在 Header 或 Query 中，Token 类型支持 basic/bearer/appcode

### 2. 添加工具

每个工具对应一个 API 端点，需配置：

- **工具路径**：相对于插件 URL 的路径（以 `/` 开头）
- **请求方法**：GET 或 POST
- **输入参数**：参数名称、描述、类型、传参方式（大模型识别或业务透传）
- **输出参数**：参数名称、描述、类型
- **高级配置**（可选）：为大模型提供调用示例，减少误召回

> **注意**：GET 请求方法下的输入参数不支持 Object 类型；Object 类型的子属性不能为空。

### 3. 调试与发布

配置完成后保存草稿，使用"测试工具"功能在线调试 API 连通性。测试通过后点击"发布"，只有已发布状态的工具才能被应用调用。

### 4. 从云市场导入

除手动创建外，也可以从阿里云云市场导入已开通的 API 作为插件。导入后需要手动调试并发布工具。

## 在应用中使用插件

### 控制台方式

- **通过 MCP 服务**：将插件发布为 MCP 服务，然后在智能体应用的 MCP 区块中添加该服务
- **直接添加插件**：在插件页面选择工具并添加至智能体应用，或在应用编排页面手动添加

### API 方式

通过 API 调用时，需获取工具 ID（在插件详情页的"插件工具"下获取），并在请求中正确传递。如果插件存在业务透传参数或启用了用户级鉴权，需通过 `biz_params` 参数传递相关信息。

## 权限配置

首次访问插件页面需要授权 `AliyunServiceRoleForSFMAccessCloudAPI` 服务关联角色。主账号可直接在插件页面授权；RAM 用户（子账号）需先由主账号在 RAM 控制台创建 `ram:CreateServiceLinkedRole` 权限策略并授权给子账号，之后子账号才能访问插件页面。

## 夸克搜索与联网搜索的区别

- **夸克搜索插件**：模型直接调用插件执行搜索，返回网页标题、关键词和摘要（不支持访问网页详情）
- **联网搜索（enable_search）**：同样基于夸克搜索，但模型会利用搜索结果丰富生成内容，不完全依赖搜索结果

## 管理插件

- **编辑插件**：修改插件 URL、Header、鉴权信息后需重新测试并发布工具
- **编辑工具**：修改工具信息后需重新测试并发布才能生效
- **删除插件/工具**：删除操作不可撤回，关联的应用会失效
