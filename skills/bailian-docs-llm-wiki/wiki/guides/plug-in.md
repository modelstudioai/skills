# plug in

插件是百炼平台用于扩展大模型能力的核心机制。通过将插件集成到应用中，可以弥补大模型在实时信息获取、精确计算、代码执行等方面的局限性。百炼支持官方插件、第三方插件及自定义插件三种类型。

## 插件类型

### 官方插件

百炼预置的官方插件无需配置输入输出参数即可直接使用，详见[插件概述](../../raw/application-user-guide/plug-in/plug-in-overview.md)。当前可用的官方插件：

| 插件名称 | 工具 ID | 功能 | 计费 |
|---------|---------|------|------|
| Python 代码解释器 | `code_interpreter` | 执行 Python 代码片段（数学计算、数据分析与可视化） | 免费 |
| 计算器 | `calculator` | 复杂数学计算 | 免费 |
| 图片生成 | `text_to_image` | 基于文本生成图片 | 限时免费，需申请开通 |
| 夸克搜索 | `quark_search` | 搜索实时信息（返回网页标题、关键词和摘要，不支持访问网页详情） | 限时免费，需申请开通 |
| 生成二维码 | `generate_qrcode` | 根据链接生成二维码 | 免费 |
| GitHub 搜索 | `github_search` | 搜索 GitHub 项目列表 | 免费 |

> **注意**：Python 代码解释器不支持对外访问网络及上传本地文件，仅可使用预装依赖（matplotlib、pandas、scipy、sympy 等）。

### 第三方插件

第三方插件涵盖商业服务、图像视频、学习教育等领域，经过效果测试，开通后即可调用，无需额外配置。开通流程：在插件页面找到目标插件 → 选择套餐 → 免费试用或购买。

### 自定义插件

当官方和第三方插件无法满足需求时，可创建自定义插件接入自有 API，完整流程参见[自定义插件](../../raw/application-user-guide/plug-in/custom-plug-ins.md)。自定义插件的创建方式：

1. **个性化开发**：手动创建插件并配置 API 路径、请求参数和返回数据
2. **从云市场导入**：选择已开通的云市场 API 直接导入

## 支持的模型

| 模型 | 模型标识符 |
|------|-----------|
| 通义千问-Turbo | `qwen-turbo` |
| 通义千问-Plus | `qwen-plus` |
| 通义千问-Max | `qwen-max` |
| 通义千问VL-Max | `qwen-vl-max` |
| 通义千问VL-Plus | `qwen-vl-plus` |

> **注意**：各模型对插件的兼容性可能有差异，以控制台实际执行结果为准。

## 插件调用机制

调用插件的本质是调用插件下的工具。百炼支持三种调用方式：

- **智能体应用**：大模型根据用户输入、工具名称和工具描述自动判断是否调用
- **工作流应用**：将插件作为工作流节点，按编排方式执行，而非由大模型主动规划
- **Assistant API**：通过 `tools` 参数指定工具 ID 进行调用

同一任务中支持组合调用多个工具（最多 10 个），大模型会根据输入自动选择调用一个或多个。

## 自定义插件开发要点

创建自定义插件时需要配置以下核心参数：

- **插件 URL**：API 的访问域名（同一插件下的工具共享域名）
- **工具路径**：相对于插件 URL 的路径，如 `/query`、`/delete`
- **鉴权配置**：支持服务级鉴权和用户级鉴权，Token 可放在 Header 或 Query 中
- **输入参数**：设置传参方式为"大模型识别"（从用户输入提取）或"业务透传"（外部主动传入）
- **输出参数**：定义 API 返回的数据结构，大模型据此筛选和组合结果

工具创建后需在线调试通过并发布，只有"已发布"状态的工具才能在应用中被调用。

## 使用方式

### 控制台调用

1. 在插件页面将工具添加至智能体应用（官方插件需与应用位于相同[业务空间](../concepts/workspace.md)）
2. 或将插件发布为 MCP 服务，然后在智能体应用的 MCP 区块中添加

### API 调用

通过 Assistant API 的 `tools` 参数传递工具 ID。若插件存在业务透传参数或用户级鉴权，需通过 `biz_params` 传递相关信息。获取工具 ID 的方式：插件详情页 → 插件工具 → 复制工具 ID。

## 夸克搜索与联网搜索的区别

两者底层均基于夸克搜索，但行为不同：

- **夸克搜索插件**：模型直接调用插件执行搜索，将结果以文本形式返回，用于生成输出
- **联网搜索（enable_search）**：模型尝试利用互联网信息丰富生成内容，但不完全依赖搜索结果

## 权限配置

首次访问插件页面需授权 `AliyunServiceRoleForSFMAccessCloudAPI` 服务关联角色。RAM 用户需主账号先授予 `ram:CreateServiceLinkedRole` 权限，具体操作参见[官方和第三方插件](../../raw/application-user-guide/plug-in/plugins.md)中的授权说明。
