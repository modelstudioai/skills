# plug in

插件（Plugin）是百炼平台用于扩展大模型能力的工具集合机制。通过将插件集成到大模型应用中，可以弥补大模型在获取实时信息、精确计算、代码执行等方面的不足。百炼支持官方插件、三方插件和自定义插件三种类型，可通过智能体应用、工作流应用或 Assistant API 进行调用。

## 插件类型

根据 [插件概述](../../raw/application-user-guide/plug-in/plug-in-overview.md) 的说明，百炼提供以下三类插件：

### 官方插件

组件广场中预置，无需配置输入输出参数即可调用。

| 插件名称 | 工具 ID | 功能 | 计费 |
|---------|---------|------|------|
| Python 代码解释器 | `code_interpreter` | 执行 Python 代码片段（数学计算、数据分析与可视化） | 免费 |
| 计算器 | `calculator` | 复杂数学计算 | 免费 |
| 图片生成 | `text_to_image` | 基于文本生成图片 | 限时免费，需申请开通 |
| 夸克搜索 | `quark_search` | 搜索实时信息、网络知识 | 限时免费，需申请开通 |
| 生成二维码 | `generate_qrcode` | 根据 URL 生成二维码 | 免费 |
| GitHub 搜索 | `github_search` | 搜索 GitHub 项目列表 | 免费 |

> **注意**：夸克搜索仅支持检索网页标题、关键词和摘要，不支持直接访问网页详情。GitHub 搜索同样仅返回项目标题、链接和摘要，不支持访问项目详情。

### 三方插件

涵盖商业服务、图像视频、学习教育等领域，经过效果测试，开通后可直接调用。详细使用方式见 [官方和第三方插件](../../raw/application-user-guide/plug-in/plugins.md)。

### 自定义插件

当官方和三方插件无法满足需求时，可自行创建插件集成所需 API。支持两种创建方式：

- **个性化开发**：手动定义插件 URL、工具路径、输入输出参数、鉴权配置
- **从云市场导入**：开通云市场 API 后导入百炼，系统自动填充参数信息

完整流程参见 [自定义插件](../../raw/application-user-guide/plug-in/custom-plug-ins.md)。

## 支持的模型

| 模型 | 模型标识符 |
|------|-----------|
| 通义千问-Turbo | `qwen-turbo` |
| 通义千问-Plus | `qwen-plus` |
| 通义千问-Max | `qwen-max` |
| 通义千问VL-Max | `qwen-vl-max` |
| 通义千问VL-Plus | `qwen-vl-plus` |

> **注意**：各模型对插件的兼容性可能存在差异，请以控制台实际执行结果为准。

## 插件调用机制

调用插件的本质是调用插件下的工具。大模型根据**用户输入内容**、**工具名称**和**工具描述**判断是否需要调用工具：

- **需要调用**：大模型选择合适的工具，应用内部完成调用后，将工具返回结果与用户内容合并再次输入大模型，生成最终结果
- **无需调用**：大模型直接生成结果输出

在工作流应用中，插件作为节点按编排方式执行，而非由大模型主动规划调用。

## 使用方式

### 控制台调用

1. **通过插件页面添加**：在插件页面将工具添加至智能体应用（官方插件需与应用位于相同业务空间）
2. **通过应用管理页面添加**：在智能体或工作流应用内添加插件
3. **发布为 MCP 服务**（自定义插件）：将插件发布为 MCP 服务后，在智能体应用的 MCP 区块中添加

### API 调用

- **应用 API**：通过 `biz_params` 传递业务透传参数或用户级鉴权信息
- **Assistant API**：在调用时通过 `tools` 参数指定工具

### 获取工具 ID

通过 API 调用工具时需要传递工具 ID。在插件页面找到目标插件，点击**查看详情**，在**插件工具**下获取工具 ID。

## 自定义插件关键参数

### 插件级参数

| 参数 | 说明 |
|------|------|
| 插件名称 | 具有语义的名称，帮助大模型理解插件功能 |
| 插件描述 | 功能和使用场景的简要说明，影响大模型对插件的调用判断 |
| 插件 URL | 插件的访问域名，工具路径拼接在此之后构成完整 URL |
| 鉴权配置 | 支持服务级和用户级鉴权，可放在 Header 或 Query 中；Token 类型支持 basic / bearer / appcode |

### 工具级参数

| 参数 | 说明 |
|------|------|
| 工具路径 | 相对于插件 URL 的路径，必须以 `/` 开头 |
| 请求方法 | GET 或 POST |
| 提交方式 | `application/json` 或 `application/x-www-form-urlencoded` |
| 输入参数 | 传参方式分为**大模型识别**（从用户输入中提取）和**业务透传**（外部主动传入） |
| 输出参数 | 大模型根据出参定义对 API 返回结果进行筛选和重组 |

## 限制和注意事项

- 每个智能体应用最多支持添加 **10 个工具**
- Python 代码解释器**不支持对外访问网络和上传本地文件**，仅支持预置的依赖库
- GET 请求方法下的输入参数**不支持 Object 类型**
- Object 类型参数的子属性不能为空
- 删除插件或工具会导致关联应用失效，且**不可撤回**
- 编辑插件的 URL、Header 或鉴权信息后，需重新测试并发布工具
- 从云市场导入的插件可能存在参数信息缺失，发布前需检查并补充
- 子业务空间调用官方插件前需先完成授权
- RAM 用户首次访问插件页面需由主账号授予 `CreateServiceLinkedRole` 权限

### 夸克搜索与联网搜索（enable_search）的区别

- **夸克搜索插件**：模型直接调用插件执行搜索，以文本形式返回搜索结果用于生成输出
- **联网搜索（enable_search）**：同样基于夸克搜索，但模型会尝试利用互联网信息丰富生成内容，不会完全依赖或返回搜索结果
