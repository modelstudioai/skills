# plug in

插件是百炼平台用于扩展大模型能力的核心机制。通过将插件集成到应用中，可以弥补大模型在实时信息获取、精确计算、外部服务调用等方面的局限性。百炼支持官方插件、第三方插件和自定义插件三种类型，每个插件包含一个或多个工具（API），各工具实现特定功能。

## 插件类型

### 官方插件

百炼预置了多个官方插件，无需额外配置即可直接使用。主要包括：

| 插件名称 | 工具 ID | 功能 | 计费 |
|---------|---------|------|------|
| Python 代码解释器 | `code_interpreter` | 执行 Python 代码，支持数学计算、数据分析与可视化 | 免费 |
| 计算器 | `calculator` | 复杂数学计算 | 免费 |
| 图片生成 | `text_to_image` | 基于文本生成图片 | 限时免费，需申请开通 |
| 夸克搜索 | `quark_search` | 搜索实时信息（仅返回标题、关键词和摘要，不支持访问网页详情） | 限时免费，需申请开通 |
| 生成二维码 | `generate_qrcode` | 根据链接生成二维码 | 免费 |
| GitHub 搜索 | `github_search` | 搜索 GitHub 项目列表 | 免费 |

详细说明参见[官方和第三方插件](../../raw/application-user-guide/plug-in/plugins.md)。

### 第三方插件

第三方插件涵盖商业服务、图像视频、学习教育等领域，经过效果测试。开通后可直接调用，无需额外配置。开通方式：在插件页面找到目标插件，选择套餐后免费试用或购买。

### 自定义插件

当官方和第三方插件无法满足需求时，可以创建自定义插件扩展大模型能力。自定义插件支持两种创建方式：

- **个性化开发**：手动创建插件并配置 API 路径、请求参数和返回数据
- **从云市场导入**：直接导入云市场已开通的 API

完整的创建流程参见[自定义插件](../../raw/application-user-guide/plug-in/custom-plug-ins.md)。

## 支持的模型

| 模型 | 模型标识符 |
|------|-----------|
| 通义千问-Turbo | `qwen-turbo` |
| 通义千问-Plus | `qwen-plus` |
| 通义千问-Max | `qwen-max` |
| 通义千问VL-Max | `qwen-vl-max` |
| 通义千问VL-Plus | `qwen-vl-plus` |

> **注意**：各模型对插件的兼容性可能有差异，最新兼容性状态以控制台实际执行结果为准。

## 插件调用机制

调用插件的本质是调用插件下的工具。百炼支持通过以下方式调用插件：

1. **智能体应用**：大模型根据用户输入、工具名称和工具描述自动判断是否调用工具。如需调用，模型选择合适的工具，完成调用后将结果与用户内容合并再次输入大模型生成最终结果。
2. **工作流应用**：将插件作为工作流节点，按编排方式执行特定任务，而非由大模型主动规划调用。
3. **Assistant API**：通过 `tools` 参数指定工具进行调用。

支持在同一任务中组合使用多个插件，例如同时使用夸克搜索、图片生成和二维码生成完成复合任务。

更多调用机制参见[插件概述](../../raw/application-user-guide/plug-in/plug-in-overview.md)。

## 自定义插件开发要点

### 插件配置

- **插件名称**：使用具有语义的名称（中英文均可），帮助大模型判断是否需要调用
- **插件描述**：使用自然语言描述功能和使用场景
- **插件 URL**：插件的访问地址（同一插件下不同工具共享域名，通过工具路径区分 API）
- **鉴权**：支持服务级鉴权和用户级鉴权，鉴权信息可放在 Header 或 Query 中，Token 类型支持 basic/bearer/appcode

### 工具配置

- **输入参数**：传参方式分为"大模型识别"（从用户输入中提取）和"业务透传"（外部直接传递）
- **输出参数**：大模型根据出参定义对 API 返回结果进行筛选和重组
- **高级配置**：可提供调用示例减少漏召回和误召回

### 发布为 MCP 服务

自定义插件支持发布为 MCP 服务，然后在智能体应用的 MCP 区块中添加使用，提供更灵活的集成方式。

## 权限与授权

首次访问插件页面需要授权 `AliyunServiceRoleForSFMAccessCloudAPI` 服务关联角色。主账号可直接授权；RAM 用户需要主账号先授予 `ram:CreateServiceLinkedRole` 权限，之后才能完成授权。

> **注意**：官方插件只能与位于相同[业务空间](../concepts/workspace.md)的智能体应用关联。在子[业务空间](../concepts/workspace.md)调用官方插件时，需要先为子[业务空间](../concepts/workspace.md)单独授权。

## 常见问题

**夸克搜索与联网搜索（enable_search）的区别**：

- **夸克搜索插件**：模型直接调用插件执行搜索，返回文本结果。支持检索网页标题、关键词和摘要，不支持访问网页详情。
- **联网搜索（enable_search）**：也基于夸克搜索，但模型会尝试利用互联网信息丰富生成内容，不会完全依赖或返回搜索结果。

## 限制与注意事项

- 每个智能体应用最多添加 10 个工具
- Python 代码解释器不支持对外访问网络和上传本地文件
- 自定义插件中 GET 请求不支持 Object 类型的输入参数
- Object 类型参数的子属性不能为空
- 工具名称不能超过 20 个字符
- 删除插件或工具后，已关联的应用会失效，操作不可撤回
