# model compression

模型压缩是百炼平台提供的量化能力，可将全精度微调模型转换为低精度版本，从而降低推理时的显存占用，使模型能够部署到更小规格的部署单元上，实现降本增效。压缩产出的模型可直接用于模型部署。

## 适用场景与前提条件

模型压缩适用于希望降低部署成本、提升推理吞吐的场景。使用前需满足以下条件：

- 当前工作空间内至少有一个**支持压缩的自定义微调模型**（通过模型调优产出）。
- 已量化的模型不支持二次压缩。如需迭代，需回到上游全精度模型重新训练后再压缩。

详细的前提说明参见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 操作流程

1. 登录百炼控制台，进入 **模型 > 模型训练 > 模型压缩** 页面。
2. 点击 **+ 创建压缩任务**，填写以下配置：
   - **基本信息**：任务名称（必填）、任务描述（可选）。
   - **选择源模型**：从当前工作空间的自定义微调模型中选择。
   - **量化产出模型名后缀**：仅支持小写字母和数字，长度不超过 8 位。
   - **量化模板**：模板名称包含目标部署规格（如 MU5、MU8），选择模板即决定压缩后可部署的规格。
   - **校准数据**（部分模板要求）：从已发布数据集中选择，用于统计权重和激活值的数值分布。OSS 挂载的数据集暂不支持作为校准数据。通过 OpenAPI 调用时可使用 `custom_calibration_file_ids` 字段传入。
3. 点击 **开始压缩**。
4. 任务成功后，在任务列表中点击压缩后的模型名称跳转至 **我的模型** 页面，点击 **部署** 即可上线。

关于校准数据和量化模板的详细说明，参见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中的操作步骤部分。

## 关键限制与注意事项

- **不可逆操作**：压缩产出的模型不支持继续训练，也不支持二次压缩。
- **部署规格**：压缩后模型的部署单元规格由所选量化模板决定，部署数量在 **模型部署** 中配置。
- **任务状态管理**：任务状态包括待开始、排队中、运行中、停止中、压缩成功、压缩失败、已取消。仅排队中或运行中的任务可取消；终态任务可删除。
- **删除任务**：删除任务记录仅删除任务本身，已生成的产出模型保留在 **我的模型** 中。
- **校准数据限制**：控制台 UI 仅支持选择"内部上传"类型且已发布状态的数据集，不支持 OSS 挂载类型。

## 计费说明

模型压缩功能当前限时免费，具体截止时间以控制台公告为准。压缩产出的模型部署上线后，按所选部署单元的标准规格计费。更多计费细节参见 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中的计费说明。
