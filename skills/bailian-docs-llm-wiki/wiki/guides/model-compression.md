# model compression

模型压缩是百炼平台提供的量化能力，可将全精度微调模型转换为低精度版本，从而降低推理时的显存占用、减小所需部署单元规格、降低部署成本并提升推理吞吐。用户可通过百炼控制台或 OpenAPI 创建压缩任务，压缩产出的模型可直接用于模型部署。详细介绍参见[模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)。

## 使用前提

创建压缩任务前，工作空间中必须至少存在一个**支持压缩的自定义微调模型**（通过模型调优产出）。当前仅部分基础模型对应的微调模型支持压缩，具体列表以控制台「模型压缩」页面为准。

## 操作步骤

1. 登录百炼控制台，进入 **模型 > 模型训练 > 模型压缩**。
2. 单击 **+ 创建压缩任务**，填写以下配置：
   - **任务名称**（必填）和 **任务描述**（可选）。
   - **选择源模型**：从当前工作空间的自定义微调模型中选择。
   - **量化产出模型名后缀**：仅支持小写字母和数字，长度不超过 8 位。
   - **量化模板**：模板名称中包含目标部署规格（如 MU5、MU8），选择模板即决定压缩后可部署的规格。
   - **校准数据**（部分模板需要）：用于统计权重和激活值的数值分布。需使用「数据管理」中已发布的内置数据集，OSS 挂载数据集暂不支持。OpenAPI 调用时通过 `custom_calibration_file_ids` 字段传入。
3. 单击 **开始压缩**，在任务列表中跟踪进度。
4. 任务成功后，单击产出模型名称跳转至「我的模型」，单击 **部署** 即可上线。

## 关键限制

根据[模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)文档，使用时需注意以下限制：

- **仅支持自定义微调模型**：基础模型或非微调模型不可直接压缩。
- **不可逆操作**：压缩产出的模型不支持继续训练，也不支持二次压缩。如需迭代，需回到上游全精度模型重新训练后再压缩。
- **部署规格由量化模板决定**：模板名称中包含目标规格（如 MU5、MU8），部署数量在「模型部署」中配置。
- **任务管理**：仅「排队中」或「运行中」状态的任务可取消；终态任务（成功/失败/已取消）可删除。删除任务记录不影响已产出的模型。
- **校准数据限制**：控制台 UI 不支持选择 OSS 挂载数据集，需使用内置上传类型的已发布数据集。

## 计费说明

模型压缩功能当前限时免费，免费截止时间以控制台公告为准。压缩产出的模型部署后，按所选部署单元的标准规格计费。
