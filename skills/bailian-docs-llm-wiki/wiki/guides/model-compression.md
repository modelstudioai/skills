# model compression

模型压缩使用量化算法将自定义微调后的全精度模型转换为低精度版本，从而降低显存占用、缩小部署单元规格，达到降本与提升推理吞吐的目的。压缩任务可在百炼控制台的 **模型训练 > 模型压缩** 页面创建，也支持通过 OpenAPI 调用；压缩产出的模型可直接用于 **[模型部署](../concepts/model-deployment.md)**。

## 适用范围与支持的模型

模型压缩仅作用于**通过模型调优产出的自定义微调模型**，并且基础模型必须在支持列表内。已量化的模型不支持二次压缩。

当前可被压缩的基础模型（以控制台为准）：

| 模型系列 | 模型名称 | 压缩前部署规格 | 压缩后部署规格 |
| --- | --- | --- | --- |
| 千问 | qwen3.5-flash-2026-02-23 | MU1 × 2（¥108/小时） | MU8 × 1（¥47/小时） |

> **注意**：上表中「压缩前部署」「压缩后部署」两列原文档列名重复，按上下文应理解为「压缩前 / 压缩后」对照。具体规格与价格请以[模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md)控制台页面实时显示为准。

使用前请确保当前工作空间至少存在一个支持压缩的自定义微调模型；微调链路详见百炼 [模型调优](https://help.aliyun.com/zh/model-studio/fine-tuning/) 文档。

## 创建压缩任务的关键字段

在控制台「模型训练 > 模型压缩」单击 **+ 创建压缩任务**，根据 [模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 的操作说明填写：

- **任务名称 / 任务描述**：任务名称必填，描述可选。
- **选择源模型**：从弹窗中选取当前工作空间内符合条件的自定义微调模型。
- **量化产出模型名后缀**：用于拼接生成产出模型 ID。
- **量化模板**：从所选源模型支持的模板列表中选择；模板名称中包含目标部署规格（如 MU5、MU8 等），决定了产出模型可用的部署单元。
- **校准数据**（仅在所选模板需要时显示）：用于统计权重和激活值数值分布，决定量化时的缩放范围与分块大小。从「数据管理」中已发布的数据集中按「数据集 → 版本」选择。

提交后任务进入列表，可在任务列表查看 **排队中 / 运行中 / 压缩成功 / 压缩失败 / 已取消** 等状态；任务详情页的「日志」页签可查看运行日志。任务成功后，单击产出模型名跳转至 **我的模型**，再点 **部署** 即可上线。

## OpenAPI 调用

除控制台外，[模型压缩](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 也支持通过 OpenAPI 创建压缩任务。其中校准数据通过 `custom_calibration_file_ids` 字段传入数据集组 ID，由后端校验。

## 校准数据的限制

- 必须使用 **数据管理** 中「内部上传」类型且处于「已发布」状态的数据集。
- **OSS 挂载的数据集暂不支持作为校准数据**（控制台 UI 不可选）。
- OpenAPI 调用可通过 `custom_calibration_file_ids` 字段直接传入数据集组 ID。

## 限制与注意事项

- **仅支持列表内的自定义微调模型**：基础模型不在支持列表内的微调模型、以及已量化的模型，均不可压缩，也不支持二次压缩。
- **任务不可逆**：压缩产出的模型不支持继续训练，也不支持二次压缩；如需迭代请回到上游全精度模型重新训练后再压缩。
- **任务取消**：仅「排队中」或「运行中」状态的任务可取消；终态任务（压缩成功 / 压缩失败 / 已取消）不能取消，但可删除。
- **删除任务的影响**：删除任务记录仅删除任务本身，已生成的产出模型仍保留在 **我的模型** 中。
- **部署规格受模板约束**：产出模型可使用的部署单元由所选量化模板决定，部署数量在 **[模型部署](../concepts/model-deployment.md)** 中配置。

## 计费

当前模型压缩功能**限时免费**，具体免费截止时间以控制台公告为准。

> **注意**：免费政策可能调整，正式定价请以控制台公告为准。

压缩产出的模型在 **部署上线后**，按所选部署单元的标准规格计费，计费详情参见百炼 [模型部署](https://help.aliyun.com/zh/model-studio/model-deployment-1/) 文档。
