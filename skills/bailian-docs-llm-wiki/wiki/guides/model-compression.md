# model compression

模型压缩是百炼平台提供的量化能力，用于将全精度微调模型转换为低精度版本，在可控精度损失下显著降低部署所需的 MU 规格与推理成本。该功能属于模型生产链路中的可选环节，位于[模型调优](raw/model-user-guide/fine-tuning.md)之后、[模型部署](raw/model-user-guide/model-deployment-index.md)之前。压缩操作不可逆，产出模型不支持继续微调或二次压缩。

## 支持的模型与功能

- **支持模型**：仅限通过百炼平台完成微调训练的自定义模型（即“微调产出模型”），不支持基础模型、第三方模型或未完成训练的中间态模型。当前明确支持 `qwen3.5-flash-2026-02-23` 等 Qwen 系列微调模型，具体以控制台实时展示为准。  
- **功能范围**：当前仅支持**后训练量化（PTQ）**，不包含结构剪枝、知识蒸馏等其他压缩技术。详见 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“功能概述”章节。  
- **地域限制**：仅华北2（北京）地域可用。

## 关键参数

创建压缩任务时需配置以下必填参数：

| 参数 | 说明 |
|------|------|
| **任务名称** | 最长 50 字符；建议含模型简称、量化方式和版本号，便于追踪。 |
| **量化产出模型名后缀** | 仅小写字母+数字，最长 8 位；将自动拼接至源模型名后（如 `my-qwen-ft-v1` + `-int4` → `my-qwen-ft-v1-int4`）。 |
| **量化模板** | 卡片式选择；模板名中 MU 编号越大（如 `MU8` > `MU4`），部署规格越小、成本越低，但潜在精度损失可能增加。切换源模型会清空已选模板。 |
| **校准数据（条件选填）** | 仅当所选模板要求校准时显示；最多选 5 个已发布数据集（不支持 OSS 挂载），应与目标推理场景语义一致（如客服场景优先选对话类数据集）。 |

> **注意**：参数配置在任务创建后不可修改，请在单击“开始压缩”前确认。详情请参考 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) 中“创建压缩任务”章节。

## 使用方式

1. **前提**：确保工作空间中存在状态为“成功”的微调模型（参见 [原文标题](../../raw/model-user-guide/model-compression/model-compression-introduction.md) “前提条件”部分）。
2. **入口**：控制台左侧导航栏 → **模型压缩** → **创建压缩任务**。
3. **配置并提交**：按上述关键参数完成填写，所有必填项校验通过后，“开始压缩”按钮方可点击。
4. **监控进度**：任务列表页点击任务名称进入详情页，通过 **详情** 页签查看状态与配置，通过 **日志** 页签实时跟踪执行过程（支持 ERROR 搜索、全量日志下载等）。
5. **结果使用**：任务状态为 `SUCCEEDED` 后，压缩后模型将出现在模型中心，可直接用于部署。

## 限制和注意事项

- **不可逆性**：压缩后的模型**不支持继续微调**，也**不支持二次压缩**；若需调整，必须回退至原始微调模型重新发起压缩任务。
- **模型来源限制**：仅支持百炼平台内微调产出的模型，基础模型（如 `qwen3.5-flash` 原始版本）或外部导入模型均不可压缩。
- **任务管理限制**：
  - 仅 `PENDING` 和 `RUNNING` 状态可停止；
  - 仅终态（`SUCCEEDED`/`FAILED`/`CANCELED`）可删除；
  - `QUEUING` 状态不可删除。
- **计费说明**：压缩任务本身限时免费（截止时间以控制台公告为准）；压缩后模型的部署费用按 MU 规格单独计费，与压缩免费期无关。
- **精度权衡**：量化必然引入精度损失。建议在免费期内对同一微调模型尝试多个量化模板，并用业务测试集验证效果后再正式部署。
