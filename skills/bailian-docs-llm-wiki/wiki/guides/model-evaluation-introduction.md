# model evaluation introduction

模型评测是百炼平台提供的核心模型能力评估功能，支持通过标准化或自定义方式对文本生成类模型进行量化打分与横向对比。它覆盖模型选型、调优验证、能力基线建立和持续质量监控等关键研发场景，提供从数据准备、维度定义、任务执行到结果分析的端到端闭环。当前功能仅面向文本生成类模型，不支持多模态或语音类模型。

## 支持的模型/功能

- **支持的模型类型**：预置模型（如千问系列）及用户调优后的文本生成模型（详见[预置模型列表](raw/model-user-guide/model-deployment-index/model-deployment-introduction.md)），**不支持非文本生成类模型**。
- **两大评测模式**：
  - **自定义评测**：使用用户上传的评测数据集（EvaluationSet 类型）或已有推理结果集，配合自定义评测维度（含大模型评估、规则评估、人工评估三类共五种类型），实现业务导向的精细化评估。
  - **基线评测**：内置通用知识、数学、代码、上下文推理、领域专项五大类共13个公开标准 Benchmark（如 MMLU-Pro、GSM8K、HumanEval），开箱即用，**仅在北京地域可用**（> **注意**：文档1中“全地域”描述与文档2及控制台实际行为矛盾，以文档2及控制台为准：基线评测地域限制为北京）。
- **核心复用单元**：评测维度作为评分规则模板，可被多个评测任务引用，确保评估标准统一；排行榜支持在相同维度下横向对比多个模型表现。

## 关键参数

| 参数类别 | 关键参数 | 说明 | 约束/建议 |
|----------|----------|------|-----------|
| **评测维度** | 维度类型 | 必填，5 种之一：大模型评估-数值型/分类型、规则评估-字符串匹配/文本相似度、人工评估-分类型。创建后不可修改。 | 选错需删除重建；详见[评测维度](../../raw/model-user-guide/model-evaluation-introduction/evaluation-metrics.md) |
| | 裁判模型 | 大模型评估类型必填，推荐千问-Max（推理能力强）。 | 影响评分质量与费用 |
| | 评分器 Prompt | 大模型评估类型必填，须至少包含 `${prompt}`、`${output}` 或 `${completion}` 之一。 | 长度 ≤ 50,000 字符；自定义时需明确定义评判逻辑与输出格式 |
| | 评分范围 & 通过阈值 | 数值型维度必填（默认 0–5，阈值默认 3.0）；文本相似度维度必填（阈值 0–1，步长 0.01）。 | 范围过宽（如 >10）会降低 LLM 评分一致性 |
| **评测任务** | 数据来源 | 二选一：**评测数据集**（触发被测模型推理，产生推理费）或**推理结果集**（仅评分，无推理费）。 | 推理结果集需严格按模板上传，且已含 `output` 字段 |
| | System Prompt | 可选，作用于被评测模型，用于设定角色或行为规范；多数场景可留空。 | 与评分器 Prompt（作用于裁判模型）严格区分，二者费用归属不同 |

## 使用方式

1. **准备数据**：在数据管理模块上传类型为 `EvaluationSet` 的评测数据集（含 `prompt` 和 `completion` 列），或准备已含 `output` 的推理结果集文件。
2. **创建维度**：进入**评测维度**页签 → **创建评测维度** → 选择类型并完成配置（如大模型评估需选裁判模型、Prompt 模板；规则评估需选算法/匹配规则）。参见[评测维度](../../raw/model-user-guide/model-evaluation-introduction/evaluation-metrics.md)获取完整配置指南。
3. **创建任务**：
   - 自定义评测：**评测任务**页签 → **创建评测任务** → 选“自定义” → 选择模型 + 数据来源 + 关联维度 → （可选）开启排行 → **开始评测**。
   - 基线评测：同上路径 → 选“基线评测” → 选模型 + 勾选 Benchmark → （可选）设置采样比例 → **开始评测**。详细流程见[模型评测产品概览](../../raw/model-user-guide/model-evaluation-introduction/model-evaluation-overview.md)。
4. **查看结果**：任务状态为“评测完成”后，点击任务名进入详情页：
   - 自定义评测：查看**指标统计**（综合得分、通过率、分布图）和**数据明细**（逐条评分）。
   - 基线评测：查看**任务总览**（雷达图）、**基线评分明细**、**Case 分析**及**多任务对比**。

## 限制和注意事项

- **地域限制**：基线评测功能**仅在北京地域（华北2）可用**；其他地域控制台不显示该选项，属正常现象（> **注意**：文档1中“全地域”描述与实际不符，应以控制台行为及文档2为准）。
- **模型限制**：当前**仅支持文本生成类模型**评测，不支持图像生成、语音合成等非文本模态模型。
- **维度不可变性**：评测维度的类型创建后不可修改，选错需删除重建；删除维度前需确认无排行榜绑定（否则阻止新任务创建）。
- **费用说明**：
  - 费用由两部分构成：**被评测模型推理费**（使用评测数据集时产生）和**裁判模型评分费**（仅大模型评估维度产生）。
  - 规则评估与人工评估无裁判模型费用；使用推理结果集可规避被测模型推理费。
  - 成本优化建议：先用 50–100 条数据小规模验证配置，再扩量；保存并复用推理结果集；优先选用规则评估。
- **结果解读**：综合得分是各维度平均分，可能掩盖维度间差异；建议结合分数分布图与明细逐维度分析短板；1–3% 的分数差异通常属评测噪声，不宜作为决策依据。
