# model evaluation introduction

模型评测是百炼平台提供的核心模型能力评估功能，支持通过标准化流程对文本生成类模型进行量化打分与横向对比。它提供自定义评测（基于用户数据与业务标准）和基线评测（基于公开标准数据集）两种范式，覆盖从快速选型到深度调优验证的全场景需求。该功能面向开发者设计，强调可复用、可配置、可归因的评测实践。

## 支持的模型/功能

- **支持模型类型**：仅限文本生成类模型（Text Generation），包括百炼预置模型（如千问系列）及用户调优后的模型；不支持多模态、语音、向量等非文本生成模型 [模型评测](../../raw/model-user-guide/model-evaluation-introduction/model-evaluation-overview.md)。
- **评测方式**：
  - **自定义评测**：完全由用户控制数据集、评测维度与评分逻辑，支持大模型评估、规则评估、人工评估三类共五种维度类型；
  - **基线评测**：内置 5 大类、13 个公开 Benchmark（如 MMLU-Pro、GSM8K、HumanEval），自动执行、无需准备数据或配置维度，但**仅在北京地域可用** [模型评测](../../raw/model-user-guide/model-evaluation-introduction/model-evaluation-overview.md)。
- **核心功能模块**：评测维度（模板化评分规则）、评测任务（执行单元）、排行榜（跨模型横向对比）、人工标注（支持人工评估维度）、结果分析（指标统计 + 数据明细 + Case 下钻）。

> **注意**：文档 1 称基线评测“仅北京地域可用”，而文档 2 未提及地域限制——以文档 1 的明确声明为准，其他地域用户创建基线评测选项将不可见，属正常行为。

## 关键参数

| 参数类别 | 关键项 | 说明 | 约束/建议 |
|----------|--------|------|-----------|
| **评测维度** | 维度类型 | 必选且**创建后不可修改**：大模型评估-数值型/分类型、规则评估-字符串匹配/文本相似度、人工评估-分类型 | 选错需删除重建；已关联任务不受影响 [评测维度](../../raw/model-user-guide/model-evaluation-introduction/evaluation-metrics.md) |
| | 裁判模型 | 仅大模型评估类型需指定（如千问-Max），影响评分质量与费用 | 推荐千问-Max用于高要求场景 |
| | 评分器 Prompt | 仅大模型评估类型支持，须含至少一个变量 `${prompt}` / `${output}` / `${completion}` | 长度 ≤ 50,000 字符；切换预置模板将覆盖当前内容 |
| | 评分范围 & 通过阈值 | 数值型：整数区间（默认 0–5），阈值步长 0.1；相似度型：0–1 区间，阈值步长 0.01 | 建议数值范围 ≤ 10；阈值按业务容忍度设定（如 3.0 表示 ≥60% 质量达标） |
| **评测任务** | 数据来源 | 二选一：<br>• **评测数据集**：含 `Prompt`+`Completion`，系统调用被测模型推理 → 产生推理费用<br>• **推理结果集**：已含 `Output`，仅评分 → 无推理费用 | 小规模验证推荐 50–100 条；正式评测建议 200–500 条 [模型评测](../../raw/model-user-guide/model-evaluation-introduction/model-evaluation-overview.md) |
| | System Prompt | 配置于任务级，为被测模型设定角色；**与评分器 Prompt 作用对象不同**（后者指导裁判模型） | 多数场景可留空 |

## 使用方式

1. **准备数据**：在数据管理模块上传 `EvaluationSet` 类型数据集（含 `Prompt` 和 `Completion` 列），或准备已含 `Output` 的推理结果集。
2. **创建维度**：进入「评测维度」页签 → 「创建评测维度」→ 选择类型并完成配置（如大模型评估需选裁判模型+Prompt；规则评估需选算法/匹配规则）。
3. **创建任务**：
   - 自定义评测：选「评测数据集」或「推理结果集」→ 关联已建维度 → 设置被测模型与推理参数（Temperature/TopP 等）→ 提交；
   - 基线评测：选「基线评测」→ 选模型 → 勾选 Benchmark（支持多选及子维度筛选）→ 可选开启数据采样 → 提交。
4. **查看结果**：
   - 自定义任务：详情页含「数据明细」（逐条评分）与「指标统计」（综合得分、通过率、分布图）；
   - 基线任务：含「任务总览」「基线评分明细」「Case 分析」「多任务对比」四页签，支持雷达图与 Bad Case 定位。

## 限制和注意事项

- **模型限制**：仅支持文本生成类模型；多模态、Embedding、ASR 等模型暂不支持评测。
- **地域限制**：基线评测功能**仅在北京地域（华北2）可用**，其他地域控制台不显示该选项 [模型评测](../../raw/model-user-guide/model-evaluation-introduction/model-evaluation-overview.md)。
- **维度约束**：维度类型创建后不可更改；删除维度前需确保无排行榜绑定（否则阻止新任务创建）；人工评估维度任务需全部标注完成后才标记为“评测完成”。
- **费用说明**：
  - 被测模型推理费：使用「评测数据集」时产生；「推理结果集」方式无此费用；
  - 裁判模型评分费：仅大模型评估维度产生；规则评估与人工评估无此费用；
  - 成本优化建议：先小样本验证 → 复用推理结果集 → 优先规则评估 [模型评测](../../raw/model-user-guide/model-evaluation-introduction/model-evaluation-overview.md)。
- **结果解读**：综合得分是各维度平均值，可能掩盖维度间差异；建议结合分数分布与 Bad Case 分析短板，而非仅依赖单一数值。1–3% 的分差通常属评测噪声，不宜作为决策依据。
