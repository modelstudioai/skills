# test 1

本页汇总阿里云百炼平台的计费体系，涵盖新人免费额度、模型推理按量计费、模型训练与部署计费、节省计划与资源包优惠方案，以及账单查询与成本管理的完整流程。开发者可通过本页快速了解各环节的费用构成和优化策略，避免意外扣费。

## 新人免费额度

首次开通阿里云百炼时，平台自动发放各模型的新人免费额度，有效期 30～90 天（2025 年 9 月 8 日后新开通用户统一为 90 天）。免费额度仅限**华北2（北京）地域、中国内地服务部署范围**的模型，且仅抵扣**实时推理**费用，不支持 Batch 调用、模型调优、[模型部署](../concepts/model-deployment.md)及自定义模型。主账号与 RAM 子账号共享额度。

查看剩余额度的方式：

- 控制台 **模型用量 > 免费额度** 页签
- 模型广场目标模型详情页的 **免费额度** 区域

免费额度耗尽后的行为取决于用户认证状态：未认证用户直接停止服务（错误码 `AllocationQuota.FreeTierOnly`），已认证用户若未开启"免费额度用完即停"则自动转为按量付费。建议通过控制台开启**免费额度用完即停**功能，防止产生意外费用。详见 [新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)。

## 模型推理按量计费（调用价格）

### 计费规则

模型推理按 Token 计费：`费用 = 输入 Token 数 × 输入单价 + 输出 Token 数 × 输出单价`，最小计费单位为 1 token。部分模型实行**阶梯计费**——单价由单次请求的输入 Token 总量决定，所有 Token 按同一阶梯单价结算。

影响计费的因素：

- **Batch 调用**：输入和输出 Token 单价按实时推理的 50% 计费
- **上下文缓存**：仅输入 Token 享有折扣
- 两者不能同时生效

### 典型价格区间（华北2-北京，中国内地部署）

| 模型系列 | 输入单价（每百万Token） | 输出单价（每百万Token） | 免费额度 |
|---------|----------------------|----------------------|---------|
| qwen3.7-max | 12 元 | 36 元 | 100 万 Token |
| qwen3-max | 2.5～7 元（按阶梯） | 10～28 元 | 100 万 Token |
| qwen3.7-plus | 2～6 元（按阶梯） | 8～24 元 | 100 万 Token |
| qwen-plus | 0.8～4.8 元（按阶梯） | 2～48 元 | 100 万 Token |

> **注意**：海外地域（新加坡、美国、德国）的价格与北京地域不同，部分模型的服务部署范围标注为"全球"或"国际"/"欧盟"/"美国"，适用不同价格体系。具体请参阅 [模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)。

## 模型训练计费

训练费用按训练 Token 计费，公式和单价因模型类型而异：

### 文本生成模型（千问）

`训练费用 = (训练数据 Token 总数 + 混合训练数据 Token 总数) × 循环次数 × 训练单价`

代表价格：Qwen3.6-Flash 为 0.05 元/千Token，Qwen3-8B 为 0.006 元/千Token，Qwen2.5-72B-Instruct 为 0.15 元/千Token。

### 图像生成模型（万相）

`训练费用 = 训练 Token 总量 × 训练单价`，Token 总量由 max_steps、max_token_length 和 generation_type 共同决定。wan2.7-image-pro/wan2.7-image 训练价格为 0.08 元/千Token。

### 视频生成模型（万相）

训练 Token 总量与视频时长、max_pixels、n_epochs 相关。wan2.2-i2v-flash 为 0.06 元/千Token，wan2.5-i2v-preview 为 0.32 元/千Token。

训练完成后的新模型需**先完成[模型部署](../concepts/model-deployment.md)**才能评测和调用。详见 [模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)。

## [模型部署](../concepts/model-deployment.md)计费

部署计费分为三种模式：

### 按使用时长计费（预置吞吐）

`费用 = 使用时长 × (输入 TPM 单价 × 输入 TPM + 输出 TPM 单价 × 输出 TPM)`

后付费按小时、预付费按天计算。超出购买 TPM 量的调用自动切换为按量付费模式（返回 Header 包含 `x-dashscope-ptu-overflow:true`）。

### 按使用时长计费（模型单元）

`费用 = 使用时长(小时) × 模型单元数量 × 模型单元单价`

支持后付费（按小时）和预付费（按月）。部分模型支持 PD 分离模式以降低首 Token 延迟、提高吞吐。

### 按模型 Token 使用量

仅对完成 SFT 高效训练后的自定义模型适用，按实际使用的输入/输出 Token 计费。

## 节省计划与资源包

百炼提供多种成本优化方案，抵扣顺序为：**免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费**。

### AI 通用型节省计划（推荐）

通过承诺每月消费金额换取阶梯折扣，最高可享 **5.3 折**。覆盖阿里直供的全部模型，承诺周期可选 3/6/12/24 个月，月承诺额度 1000 元起。

- A 类（千问等）：全预付 12 个月万元档可享 8 折
- B 类（图像/语音/视频）：折扣力度更大
- C 类（DeepSeek/Kimi/GLM 等三方模型）：目前无折扣

> **注意**：每月承诺额度为独立额度，当月未用完自动清零，不可累积到下月。三方直供模型不支持抵扣。

### 其他模型节省计划

按模型系列购买固定金额，适合用量集中于特定模型的场景。包括大语言模型推理节省计划（无折扣）、千问语音模型节省计划（最高 8 折）、向量及排序模型节省计划（最高 7 折）。

### 资源包

预购具体 Token 数量，抵扣特定模型超出免费额度后的实时推理用量。目前提供 qwen-plus、qwen-max、qwen-turbo 三款资源包。资源包有效期内未用完自动作废，支持退订未使用部分。

详见 [节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)。

## 账单查询与成本管理

### 查询账单

- **费用概览**：控制台 **用量 & 费用 > 费用概览** 查看总消费、订阅购买与账单费用构成，支持按模型或 API Key 筛选
- **账单详情**：通过阿里云费用中心下载明细账单，`实例 ID（出账粒度）`字段以分号分隔，包含 `ApiKeyID;业务空间ID;模型名称;输入/输出类型;调用渠道;免费额度用完即停标识`

出账时效：大模型推理分钟级（通常 2～10 分钟），批量推理/模型训练/知识库小时级。

### 分账管理

给[业务空间](../concepts/workspace.md)绑定标签，可按部门或项目归集费用。在标签管理中将标签与 Workspace ID 绑定，启用费用标签后 T+1 天生效。

### 欠费处理

账户可用额度 < 0 时视为欠费。仍有免费额度、节省计划、资源包或 Token Plan 的服务可继续使用，否则服务暂停。

### 停止计费

- 模型推理：停止 API 调用，删除 API Key
- [模型部署](../concepts/model-deployment.md)：下线已部署模型，预付费实例需退订
- Coding Plan / Token Plan：到期自动停止，关闭自动续费

详见 [账单查询与成本管理](../../raw/model-user-guide/test-1/bill-query-and-cost-management.md)。

## 常见问题

**免费额度用完后如何继续使用？** 未认证用户需完成认证并充值；已认证用户免费额度耗尽后自动按量扣费（除非开启了"用完即停"）。

**为什么没怎么用却产生了欠费？** 联网搜索等附加功能按调用次数单独计费。检查应用代码中 `enable_search` 参数是否开启，不需要时设为 `false`。

**如何避免意外扣费？** 开启免费额度用完即停、设置高额消费预警、配置预算管理，并在不使用时删除 API Key。

**按量付费是实时扣款吗？** 不是，采用"预占+月结"模式，月账期结束后生成最终账单并实际扣款。
