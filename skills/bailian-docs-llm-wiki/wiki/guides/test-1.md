# test 1

阿里云百炼平台提供多层次的[计费](../concepts/billing.md)体系，涵盖模型推理按量付费、模型训练与部署[计费](../concepts/billing.md)、新人免费额度、节省计划和资源包等优惠方案，以及完善的账单查询与成本管理工具。开发者可根据使用规模灵活选择[计费](../concepts/billing.md)方式，有效控制成本。

## 计费模式概览

百炼平台的计费模式主要分为以下几类：

- **按量付费**：模型调用默认按量计费，按输入/输出 [Token](../concepts/token.md) 数计费，部分模型实行阶梯计费规则
- **模型训练计费**：按训练 [Token](../concepts/token.md) 计费，训练费用 = [Token](../concepts/token.md) 总数 x 循环次数 x 训练单价
- **模型部署计费**：支持按使用时长（预置吞吐）和按模型单元两种计费方式，可选后付费或预付费
- **免费额度**：首次开通百炼自动发放，有效期 30~90 天，仅抵扣实时推理费用

详细的按量计费价格请参考 [模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)。

## 新人免费额度

首次开通百炼时平台自动发放各模型的免费额度，核心规则如下：

- **适用范围**：仅限华北2（北京）地域且服务部署范围为中国内地的模型
- **有效期**：2025年9月8日后开通的用户为 90 天，之前开通的用户为 30 天
- **抵扣限制**：仅抵扣实时推理费用，不支持 Batch 调用、模型调优、模型部署、自定义模型
- **共享机制**：主账号与 RAM 子账号共享免费额度

可在控制台的 [模型用量] > [免费额度] 页签查看剩余额度和有效期。建议开启「免费额度用完即停」功能防止产生意外费用。详情参考 [新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)。

## 模型训练与部署计费

### 训练计费

支持文本生成模型（千问系列）、图像生成模型（万相系列）、视频生成模型的训练计费：

| 模型类型 | 计费公式 |
|---------|---------|
| 文本生成（千问） | (训练数据 Token + 混合训练数据 Token) x 循环次数 x 训练单价 |
| 图像生成（万相） | 训练 Token 总量 x 训练单价，其中 Token 总量 ≈ max_steps x Lmax |
| 视频生成（万相） | 训练 Token 总量 x 训练单价，Token 总量与视频时长、max_pixels、n_epochs 相关 |

### 部署计费

模型部署支持两种计费模式：

1. **预置吞吐（按 TPM 计费）**：费用 = 使用时长 x (输入 TPM 单价 x 输入 TPM + 输出 TPM 单价 x 输出 TPM)，支持后付费（按小时）和预付费（按天）
2. **模型单元**：费用 = 使用时长 x 模型单元数量 x 模型单元单价，支持后付费（按小时）和包月预付费

> **注意**：当模型输入超过最长输入 Token 或超出购买的 TPM 量时，相关调用将自动切换为按量付费模式，推理性能可能下降。

详细价格表请参考 [模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)。

## 成本优化方案

### AI 通用型节省计划（推荐）

通过承诺每月消费金额换取阶梯式折扣，最高 5.3 折：

- **覆盖范围**：可抵扣阿里直供的全部模型（A/B/C 三类），跨模型使用
- **承诺周期**：3/6/12/24 个月，周期越长折扣越大
- **月承诺金额**：1000 元起，以 10 元为单位调整
- **付费方式**：全预付（享最大折扣）或零预付（需开通白名单）
- **抵扣范围**：模型调用（含 Batch）、原生工具调用、上下文缓存等；不含模型调优和部署

### 其他节省计划

- **大语言模型推理节省计划**：20~500,000 元多档位，无折扣，适用已上架的文本生成模型
- **千问语音模型节省计划**：20~5,000 元五档，最高 8 折，适用 CosyVoice/Qwen-TTS/ASR 等语音模型
- **向量及排序模型节省计划**：100~10,000 元五档，最高 7 折，适用 text-embedding/rerank 等模型

### 资源包

预购固定 Token 数量抵扣特定模型的推理用量，目前支持 qwen-plus、qwen-max、qwen-turbo 三类资源包。购买后立即生效，支持余量预警。

抵扣优先级为：**免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费**。

详情参考 [节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)。

## 账单查询与成本管理

### 查询账单

- **费用概览**：在控制台 [用量 & 费用] > [费用概览] 页面查看当月总消费、趋势分析
- **账单详情**：在阿里云费用中心按 ApiKeyID、[业务空间](../concepts/workspace.md)ID、模型名称、调用渠道等维度查看明细
- **出账时间**：大模型推理 2~10 分钟出账；批量推理、训练、知识库等小时级出账

### 分账管理

给[业务空间](../concepts/workspace.md)绑定标签可按部门或项目归集费用，配置后 T+1 天生效。

### 欠费处理

账户可用额度 < 0 视为欠费。已有节省计划/资源包/Coding Plan/Token Plan 额度的商品可继续使用，其余服务暂停。需在费用与成本页面充值结清。

### 停止计费

- 停止模型推理：停止 API 调用、删除 [API Key](../concepts/api-key.md)
- 停止模型部署：下线已部署模型（按时长计费）或退订（包月预付费）
- 取消订阅：Coding Plan 到期自动停止；Token Plan 按席位退订

详细操作参考 [账单查询与成本管理](../../raw/model-user-guide/test-1/bill-query-and-cost-management.md)。

## 常见问题

| 问题 | 解答 |
|------|------|
| 免费额度用完会怎样？ | 未认证用户停止服务需认证充值；已认证用户如开启「用完即停」则停止，否则自动按量扣费 |
| 还有额度为何调用失败？ | 检查阿里云账户是否欠费，欠费时即使有免费额度也无法调用 |
| 同一模型为何有多行账单？ | 按输入 Token、输出 Token、缓存命中等类型和调用渠道分别出账 |
| 没怎么用为何产生费用？ | 检查是否开启了联网搜索等附加功能，这些功能按调用次数单独计费 |
| 按量付费是实时扣款吗？ | 不是，采用"预占+月结"模式，月账期结束后生成最终账单 |
