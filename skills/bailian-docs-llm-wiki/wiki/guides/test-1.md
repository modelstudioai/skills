# test 1

本主题汇总阿里云百炼平台与[计费](../concepts/billing.md)相关的五类信息：新人免费额度、模型训练与部署[计费](../concepts/billing.md)、账单查询与成本管理、节省计划与资源包、模型调用价格。面向需要预估和控制百炼平台调用成本的开发者，帮助你在开通服务、选型、调用与结算各环节做出正确决策。

## 整体[计费](../concepts/billing.md)框架

百炼平台的费用主要由以下几部分构成，彼此独立结算：

- **模型实时推理（调用）费用**：按输入/输出 Token 计费，单价随模型、地域、部署范围与 Token 区间不同而变化，详见 [模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)。
- **模型训练与部署费用**：调优（微调）与独占部署按算力资源或时长计费，详见 [模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)。
- ** Batch 调用费用**：异步批量推理单独计价，通常低于实时调用。
- **资源包 / 节省计划**：可预先购买以抵扣或折扣上述费用，详见 [节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)。

## 新人免费额度

首次开通阿里云百炼时，平台会自动发放各模型的新人专属免费额度，规则要点如下（详见 [新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)）：

- **地域与部署范围**：仅华北2（北京）地域且服务部署范围为"中国内地"的模型享有免费额度，其他地域和部署范围无免费额度。
- **有效期**：免费额度有效期为 30～90 天，从开通百炼或模型申请通过之日起计算。自 **2025 年 9 月 8 日 11 点** 起，首次开通的用户获赠额度有效期统一调整为 90 天；此前已开通的用户不受影响。
- **抵扣范围**：免费额度**仅抵扣模型实时推理（调用）费用**，不支持抵扣 Batch 调用、模型调优、模型部署以及自定义模型（调优后模型、已部署模型）产生的费用。
- **账号共享**：阿里云主账号与其 RAM 子账号共享免费额度。例如 qwen-max 总免费额度为 100 万 Token，主账号消耗 10 万、子账号消耗 20 万，则剩余 70 万。

**查看剩余额度**：
1. 控制台「模型用量」→「免费额度」页签，查看所有模型余量及过期时间。
2. 控制台「模型广场」→ 目标模型系列详情页中查看。

额度到期或耗尽后，继续调用模型推理服务将产生计费。

## 模型调用价格

模型实时推理按输入/输出 Token 分别计价，关键维度包括：

- **模型 ID（Model ID）**：不同模型版本独立计价，如 qwen-plus、qwen3.7-plus、qwen3.6-plus 等，部分模型附带日期后缀版本（如 `qwen-plus-2025-07-28`、`qwen3.7-plus-2026-05-26`），能力等同但需用精确 ID 调用。
- **服务部署范围**：分"全球"与"国际/新加坡"等，不同部署范围单价不同。
- **Token 区间**：按单次请求的输入 Token 范围分档计价，常见档位为 `0<Token≤128K`、`128K<Token≤256K`、`256K<Token≤1M`，长上下文请求单价更高。
- **思考模式**：部分模型区分"非思考模式"与"思考模式（思维链+回答）"，思考模式输出单价显著高于非思考模式。
- **上下文缓存折扣**：启用 [上下文缓存](https://help.aliyun.com/zh/model-studio/context-cache) 可享受输入单价折扣。

以 qwen-plus 系列为例（全球部署，单位：每百万 Token）：

| 输入 Token 区间 | 输入单价 | 非思考输出单价 | 思考模式输出单价 |
| --- | --- | --- | --- |
| 0<Token≤128K | 0.8 元 | 2 元 | 8 元 |
| 128K<Token≤256K | 2.4 元 | 20 元 | 24 元 |
| 256K<Token≤1M | 4.8 元 | 48 元 | 64 元 |

新加坡（国际）部署的 qwen3.7-plus 等模型采用不同单价档位，例如 `0<Token≤256K` 输入 2.998 元、非思考/思考输出 11.991 元。完整价目表以 [模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md) 为准。

## 模型训练与部署计费

模型调优（微调）与模型独占部署按算力资源或运行时长计费，与实时推理调用费用相互独立。调优产生的模型在调用时仍按对应模型 ID 的推理单价计费；独占部署模型按部署实例规格与运行时长计费。具体计费维度与计价规则详见 [模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)。

## 账单查询与成本管理

平台提供账单查询与成本管理能力，用于核对各模型/服务的实际消耗与应收费用：

- 按模型、按服务维度查看账单明细。
- 设置费用预警与预算通知。
- 导出账单用于内部成本分摊。

操作入口与字段说明详见 [账单查询与成本管理](../../raw/model-user-guide/test-1/bill-query-and-cost-management.md)。

## 节省计划与资源包

为降低长期调用成本，可预先购买节省计划或资源包：

- **资源包**：按模型或 Token 量预先购买，调用时优先抵扣，用尽后按量计费。
- **节省计划**：承诺在一定周期内消费一定金额，换取对应折扣，适用于用量稳定且可预测的场景。

购买策略、抵扣优先级与有效期规则详见 [节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)。

## 限制与注意事项

- **免费额度仅限实时推理**：Batch 调用、模型调优、模型部署及自定义模型均不享受免费额度，需单独预算。
- **地域限制**：免费额度仅覆盖华北2（北京）/中国内地部署范围的模型；其他地域调用从一开始即产生计费。
- **Token 分档计价**：长上下文请求（>128K、>256K）单价大幅上升，应在业务侧控制上下文长度。
- **思考模式成本**：思考模式输出单价可达非思考模式的数倍，对成本敏感场景应按需关闭思维链。
- **版本与计价绑定**：带日期后缀的模型版本（如 `qwen3.7-plus-2026-05-26`）能力等同基础版本，但需使用精确 ID 调用并按对应单价计费。

> **注意**：各模型的单价、免费额度规则与有效期可能随平台政策调整而变化。本页所述价格与规则仅为示例，实际计费请以控制台「模型用量」「账单」页与 [模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md) 最新数据为准。
