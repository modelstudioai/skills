# test 1

本页汇总阿里云百炼平台的计费与成本管理相关内容，覆盖新人免费额度、模型调用与训练部署价格、账单查询与分账、以及节省计划与资源包等优惠方案。面向开发者梳理计费规则、抵扣顺序和常见问题，帮助你在控制成本的前提下稳定使用大模型推理服务。

## 计费总览

百炼的模型调用默认按量计费，部分模型实行阶梯计费：单价取决于单次请求的输入 [Token](../concepts/token.md) 总量，该请求的所有 [Token](../concepts/token.md) 均按对应阶梯的单价结算。例如某模型设有 `0 < Token ≤ 32K` 与 `32K < Token ≤ 128K` 两档，若输入 100K [Token](../concepts/token.md)，因落在第二区间，全部 Token 按第二档单价结算。详细价格表见 [模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)。

除实时推理外，以下场景独立计费：

- **Batch 调用**：若模型支持 Batch，其输入和输出 Token 单价均按实时推理价格的 50% 计费。
- **上下文缓存**：仅输入 Token 享有折扣。Batch 半价与上下文缓存折扣不能同时生效。
- **联网搜索等附加功能**：按调用次数单独计费（后付费），与模型推理费用分开出账，即使未主动操作控制台，历史代码若开启 `enable_search` 仍会产生费用。
- **模型训练**：按训练 Token 计费，公式为 `(训练数据 Token 总数 + 混合训练数据 Token 总数) × 循环次数 × 训练单价`，最小计费单位 1 token。
- **模型部署**：按模型调用量、算力使用时长或包月预付费三种方式之一计费。

> **注意**：账单的"计费项"统一显示为"大模型文本消耗量"，未直接展示模型名称。需在 [账单查询与成本管理](../../raw/model-user-guide/test-1/bill-query-and-cost-management.md) 的"实例 ID（出账粒度）"列中区分，该字段以英文分号分隔，紧跟[业务空间](../concepts/workspace.md) ID 之后的字段即为模型名称。

## 新人免费额度

首次开通阿里云百炼时，平台自动发放各模型的新人专属免费额度。规则要点：

- **地域限制**：仅华北2（北京）地域且服务部署范围为"中国内地"的模型享有免费额度，其他地域和部署范围无免费额度。
- **有效期**：30~90 天，从开通或模型申请通过之日起计算。自 2025年9月8日11点起，首次开通的用户获赠额度有效期调整为 90 天，此前已开通的用户不受影响。
- **适用范围**：仅抵扣模型**实时推理**费用。不支持抵扣 Batch 调用、模型调优、模型部署、自定义模型（调优后模型、已部署模型）。
- **账号共享**：阿里云主账号与其 RAM 子账号共享免费额度。
- **耗尽行为**：全新未认证用户额度耗尽后停止响应并返回 `AllocationQuota.FreeTierOnly`，需认证并充值后才能按量付费；已认证用户继续调用会直接扣费。

可开启"**免费额度用完即停**"功能（默认关闭），开启后额度耗尽时停止响应不继续扣费。该功能需在控制台显示"免费额度用完"后才可关闭。余量降至 20% 或完全耗尽时，系统通过短信、站内信、邮件发送通知，预警比例可在"我的试用"页面配置。详见 [新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)。

## 抵扣顺序与优惠方案

当免费额度、资源包、节省计划并存时，按以下顺序抵扣：

**免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费**

同类多个优惠：优先抵扣先到期的，到期时间相同则优先抵扣先购买的；同类全部到期或额度用完后，超出部分自动转为按量付费。详见 [节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)。

### AI 通用型节省计划（推荐）

通过承诺 3/6/12/24 个月的月消费金额换取阶梯式折扣，最高 5.3 折。覆盖阿里直供的全部模型，一次购买即可跨模型使用，是绝大多数场景的首选。

- **抵扣范围**：支持模型调用（输入输出 Tokens）、模型原生工具调用（Function Call、网页抓取等）、上下文缓存、批量推理；**不支持**模型调优、模型部署费用。
- **承诺周期**：以月为单位，月承诺周期结束时剩余额度自动过期，不可累积到下一周期。例如订阅 3 个月、月承诺 1000 元，并非获得 3000 元总额度，而是每月独立 1000 元。
- **付费方式**：全预付（一次性支付全部承诺金额，享最大折扣）或零预付（按月支付，需联系商务经理开通白名单）。
- **折扣档位**：按模型分 A 类（千问、向量、排序、行业模型、工具调用等）、B 类（图像生成、语音、视频）、C 类（qwen3.6-max-preview、DeepSeek、Kimi、GLM、MiniMax、HappyHorse）。三方直供模型不支持抵扣。月承诺金额 1000 元起、以 10 元为单位调整、不设上限，承诺越高、周期越长折扣越大。

### 其他模型节省计划

适合用量较小或集中于某一特定模型的场景，购买后立即生效。

- **大语言模型节省计划**：20/100/1,000/5,000/10,000/20,000/50,000/100,000/200,000/300,000/500,000 元档，**均无折扣**，按模型调用价格扣费。有效期 1 个月~1 年不等。仅华北2（北京）。不支持向量模型和排序模型。
- **千问语音模型节省计划**：20/100/500/1,000/5,000 元档，折扣 9.8~8 折。ASR 按秒计费、TTS 按字符计费。
- **向量及排序模型节省计划**：100/500/2,000/5,000/10,000 元档，折扣为无折扣~7 折。

### 资源包

预先购买具体的 Token 数量，用于抵扣特定模型超出免费额度后的实时推理用量。购买后立即生效，有效期到期后剩余 Tokens 自动作废。例如 qwen-plus 资源包仅支持抵扣单次请求输入 `0 < Token ≤ 128K` 阶梯范围内的实时推理费用（非思考模式），`Token > 128K` 阶段的费用不支持抵扣。未发生使用的部分可申请退款，已使用部分无法退款。

## 账单查询与成本管理

### 出账时延

仅在实际发生调用结束后生成账单：大模型推理分钟级出账（通常 2~10 分钟），批量推理、模型训练、[知识库](../concepts/knowledge-base.md)等小时级出账，业务高峰期以系统最终出账时间为准。按量付费采用"预占+月结"模式——系统先冻结部分额度，月账期结束后（次月初）生成最终账单并实际扣款，并非实时扣款。

### 查询入口

- **费用概览**（百炼控制台 > 模型 > 用量 & 费用 > 费用概览）：展示当月总消费金额，拆分订阅购买费用与账单费用。该页面仅展示大模型推理费用，训练和[知识库](../concepts/knowledge-base.md)费用需通过账单详情查看。可设置月度消费限额与告警。
- **账单详情**（费用与成本 > 账单详情）：产品名称选"大模型服务平台百炼"，可按 ApiKeyID、[业务空间](../concepts/workspace.md)ID、模型名称、输入/输出类型、调用渠道、实例标签拆分查看，支持导出本地。
- **模型用量**（百炼控制台 > 模型 > 用量 & 费用 > 模型用量）：查看模型调用次数和统计，含免费额度余量页签。

### 实例 ID 字段解读

账单"实例 ID（出账粒度）"字段以英文分号分隔，完整格式为 `ApiKeyID;业务空间ID;模型名称;输入/输出类型;调用渠道;免费额度用完即停标识`。

- 标准调用（含 ApiKeyID）：`12xxx;llm-xxx;qwen-max;output_token;app;0`
- 控制台调用（不含 ApiKeyID）：`;llm-xxx;qwen-max;output_token;app;0`，通常表示通过控制台产生而非代码调用。

调用渠道：`app`（应用程序代码调用）、`bmp`（控制台模型体验）、`assistant-api`（Assistant API 调用）。同一模型在账单中多行记录是因为按计费类型（输入 Token、输出 Token、缓存命中）和调用渠道分别出账。

### 分账管理

给[业务空间](../concepts/workspace.md)绑定标签可按部门或项目归集费用：在业务空间管理获取 Workspace ID → 在标签管理页面将标签绑定到"大模型服务平台百炼:业务空间"资源 → 在费用标签页面启用该标签。配置完成后分账账单 T+1 天生效。

### 欠费处理

账户可用额度 < 0 视为欠费（可用额度 = 现金余额 + 信控额度 - 当月未结清 - 历史未结清）。欠费影响按账单商品名称维度判定：仍有免费额度/节省计划/资源包额度可继续使用；已购 Coding Plan 或 Token Plan 套餐额度独立于账户余额，欠费期间可继续使用但会导致自动续费失败；以上额度均无则该商品服务暂停，需结清欠费后恢复。账户欠费时即使其他模型仍有免费额度也无法调用。

### 停止计费

- 模型推理：停止 API 调用、关闭控制台模型体验，可删除 [API Key](../concepts/api-key.md) 防止意外调用。
- 模型训练：无正在进行的训练任务即不产生费用。
- Coding Plan：到期自动停止，中途不支持取消和退款，已开自动续费需手动关闭。
- Token Plan 团队版：按席位退订，未产生用量消耗的席位可退订。
- 模型部署：按调用量计费的下线模型或删除 [API Key](../concepts/api-key.md)；按时长计费的下线模型；包月预付费的下线后到退订管理页面退订。

## 关键参数与限制

- **阶梯计费的输入 Token 阈值**：常见为 32K、128K、256K、1M 分档，超阈值后单价上升；资源包可能仅覆盖低阶梯（如 qwen-plus 资源包仅抵扣 `Token ≤ 128K`）。
- **思考模式**：部分模型区分非思考模式与思考模式（思维链+回答），思考模式输出单价更高。
- **免费额度数据更新**：控制台免费额度为分钟级更新且需手动刷新，未及时刷新可能显示仍有额度但实际已耗尽，导致产生费用，操作前请刷新页面以最新显示为准。
- **地域与部署范围**：免费额度、节省计划、资源包的适用地域各不相同，AI 通用型节省计划支持华北2（北京）、美国（弗吉尼亚）、新加坡、德国（法兰克福）；其他模型节省计划与资源包多仅支持华北2（北京）。中国内地之外的地域（新加坡、法兰克福等）价格通常更高。
- **模型调用记录**：调用完约一小时后可在模型监控页面查询统计，数据按小时更新，高峰期可能有小时级延迟。

## 常见问题速查

- **为什么产生了费用**：模型已无免费额度；免费额度不支持抵扣 Batch 调用；控制台额度数据未刷新导致实际已耗尽；联网搜索等附加功能按次计费与推理费用分开出账。
- **如何避免扣费**：删除已创建的 [API Key](../concepts/api-key.md)；设置高额消费预警（按百炼大模型部署/推理/训练分别设置阈值，达阈值每天短信提醒一次）；开启免费额度用完即停；检查应用代码是否开启了 `enable_search` 并按需关闭。
- **还有剩余额度为何调用失败**：检查阿里云账户是否欠费，欠费时即使模型仍有免费额度也无法调用。
- **为什么没怎么用却欠费**：联网搜索按调用次数单独计费，历史创建的应用或代码若开启 `enable_search`，每次被调用仍会产生费用。需在账单详情中确认产生费用的模型和调用渠道，并排查是否有其他 API Key 或应用仍在运行。
- **按量付费是否实时扣款**：不是，采用"预占+月结"模式，次月初生成最终账单并实际扣款。
