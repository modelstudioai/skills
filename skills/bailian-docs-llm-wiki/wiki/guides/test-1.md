# test 1

阿里云百炼平台的计费体系涵盖模型推理（按量付费）、模型训练、模型部署三大场景，同时提供免费额度、节省计划、资源包等多种成本优化手段。本文汇总百炼平台的计费规则、账单管理方式和省钱策略，帮助开发者快速理解费用构成并做出合理的成本决策。

## 计费模式概览

百炼平台的费用主要由以下部分构成：

- **模型推理（按量付费）**：按输入/输出 [Token](../concepts/token.md) 数量计费，部分模型支持阶梯计费（单价取决于单次请求的输入 [Token](../concepts/token.md) 总量）。详见[模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)。
- **模型训练**：按训练 [Token](../concepts/token.md) 计费，费用 = [Token](../concepts/token.md) 总量 x 循环次数 x 训练单价。支持千问文本、万相图像、万相视频三类模型的微调训练。
- **模型部署**：支持按使用时长计费（预置吞吐）和按模型单元计费两种方式，可选后付费（按小时）或预付费（按天/月）。

费用抵扣优先级为：**免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费**。

## 新人免费额度

首次开通百炼时，平台自动发放各模型的免费推理额度（通常每个模型 100 万 [Token](../concepts/token.md)），有效期 90 天。关键规则如下：

- 仅限华北2（北京）地域且服务部署范围为中国内地的模型
- 仅抵扣实时推理费用，不支持 Batch 调用、模型调优、模型部署
- 主账号与 RAM 子账号共享额度，不同模型的额度相互独立
- 带日期后缀的快照版本（如 `qwen-max-2026-05-17`）与最新版本（如 `qwen-max`）视为独立模型，各有独立额度

已认证用户免费额度耗尽后会直接按量扣费。可开启**免费额度用完即停**功能防止意外费用。详见[新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)。

> **注意**：[Token](../concepts/token.md) Plan / Coding Plan 专属 [API Key](../concepts/api-key.md) 不消耗免费额度，使用专属 [API Key](../concepts/api-key.md) 调用模型将直接按量付费。如需使用免费额度，请改用通用 [API Key](../concepts/api-key.md)。

## 模型调用价格要点

### 阶梯计费

部分模型实行阶梯计费，单价取决于**单次请求**的输入 Token 总量。例如千问 Max 系列：

| 模型 | 输入 Token 范围 | 输入单价（每百万 Token） | 输出单价（每百万 Token） |
|------|----------------|----------------------|----------------------|
| qwen3.7-max | 0 < Token <= 1M | 12 元 | 36 元 |
| qwen3-max | 0 < Token <= 32K | 2.5 元 | 10 元 |
| qwen3-max | 32K < Token <= 128K | 4 元 | 16 元 |
| qwen3-max | 128K < Token <= 256K | 7 元 | 28 元 |

### 降低推理成本的方式

- **Batch 调用**：支持的模型输入/输出 Token 单价均按实时推理价格的 50% 计费
- **上下文缓存**：支持的模型仅输入 Token 享有折扣
- Batch 调用与上下文缓存不能同时生效

完整价格表请参考[模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)。

## 模型训练与部署计费

### 训练计费

训练按 Token 计费，不同模型类型的计算公式不同：

- **千问文本模型**：费用 = （训练数据 Token + 混合训练 Token）x 循环次数 x 训练单价
- **万相图像模型**：费用 = 训练 Token 总量 x 训练单价，其中 Token 总量 = max_steps x L_max
- **万相视频模型**：费用 = 训练 Token 总量 x 训练单价，Token 总量与视频时长、max_pixels、n_epochs 相关

### 部署计费

部署分为两种计费模式：

1. **预置吞吐**：费用 = 使用时长 x（输入 TPM 单价 x 输入 TPM + 输出 TPM 单价 x 输出 TPM）。当模型输入超过最长输入 Token 或超出购买的 TPM 量时，自动切换为按量付费。
2. **模型单元**：费用 = 使用时长 x 模型单元数量 x 模型单元单价。支持后付费（按小时）和预付费（包月）。

详见[模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)。

## 成本优化方案

### AI 通用型节省计划（推荐）

通过承诺每月消费金额换取阶梯式折扣，最高可享 **5.3 折**优惠。核心特点：

- 可抵扣阿里直供的全部模型（A/B/C 三类），一次购买跨模型使用
- 承诺周期：3/6/12/24 个月，月承诺金额 1000 元起
- 付费方式：全预付（折扣更大）或零预付（需商务经理申请）
- 每月额度独立，未使用部分自动清零，不可累积
- 支持抵扣 Token 调用、工具调用、上下文缓存、批量推理等费用
- 不支持抵扣模型调优和模型部署费用

### 其他模型节省计划

面向特定模型系列（语音模型、向量及排序模型、万相模型等），折扣通常不如 AI 通用型节省计划。适合用量较小或需求集中于某一模型的场景。

### 资源包

预先购买具体 Token 数量，用于抵扣特定模型超出免费额度后的实时推理用量。购买后立即生效，无需手动激活。详见[节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)。

## 账单查询与成本管理

### 查询账单

- **费用概览**：在百炼控制台的「用量 & 费用 > 费用概览」页面查看当月总消费及构成
- **账单详情**：在阿里云费用中心的「账单详情」页面，按产品名称筛选「大模型服务平台百炼」
- 账单的「实例 ID（出账粒度）」字段以分号分隔，格式为 `ApiKeyID;业务空间ID;模型名称;输入/输出类型;调用渠道;免费额度用完即停标识`

### 出账时效

| 场景 | 出账时效 |
|------|---------|
| 大模型推理 | 分钟级（通常 2~10 分钟） |
| 批量推理、模型训练、知识库 | 小时级 |

### 分账管理

通过给[业务空间](../concepts/workspace.md)绑定标签，可按部门或项目归集费用。在标签管理页面绑定标签后，分账账单 T+1 天生效。

### 欠费处理

账户可用额度 < 0 视为欠费。欠费时即使模型仍有免费额度也无法调用。已购 Coding Plan 或 Token Plan 的套餐额度独立于账户余额，欠费期间可继续使用。详见[账单查询与成本管理](../../raw/model-user-guide/test-1/bill-query-and-cost-management.md)。

## 停止计费

不再使用百炼时，按场景关停对应服务：

- **模型推理**：停止 API 调用，删除已创建的 API Key
- **模型训练**：确保无进行中的训练任务
- **模型部署**：下线已部署模型；包月预付费需额外在退订管理页面退订实例
- **Coding Plan**：到期自动停止，中途不支持取消；如已开启自动续费，需手动关闭
- **Token Plan**：在控制台按席位退订，未产生用量消耗的席位可退订

## 常见问题

**调用后查不到账单？** 模型推理账单通常 2~10 分钟出账，批量推理、训练等按小时出账。公测或邀测模型不产生账单记录。

**没怎么用却产生了欠费？** 检查应用代码或配置中是否开启了 `enable_search` 参数，联网搜索等附加功能按调用次数单独计费。

**如何避免意外扣费？** 开启「免费额度用完即停」、设置高额消费预警、删除不再使用的 API Key。
