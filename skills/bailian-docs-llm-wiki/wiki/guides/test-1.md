# test 1

阿里云百炼平台的计费体系围绕「按量付费」为核心，叠加免费额度、节省计划、资源包等多种优惠方案，覆盖模型调用、模型训练、模型部署等场景。本主题汇总了百炼平台计费、账单与成本管理的全链路要点，帮助您理解计费规则、查询与分摊费用、并选择最优的成本优化方案。

## 计费体系总览

百炼的计费按**商品名称**维度划分，主要包括：

- **大模型推理**：模型实时调用（输入/输出 Token）按量计费，分钟级出账（通常 2~10 分钟）。
- **批量推理（Batch）**：按小时级出账，单价为实时推理的 50%。
- **模型训练**：按训练 Token 计费，小时级出账。
- **模型部署**：按使用时长或模型单元计费，支持预付费与后付费。
- **附加功能**：如联网搜索（`enable_search`）按调用次数单独计费，与推理费用分开出账。

按量付费采用"预占 + 月结"模式：系统先冻结部分额度，月账期结束后（次月初）生成最终账单并实际扣款。

## 免费额度（新人专属）

首次开通阿里云百炼时，平台自动发放各模型的免费额度。

- **适用范围**：仅华北2（北京）地域且服务部署范围为**中国内地**的模型享有免费额度；仅抵扣模型**实时推理**费用，不支持抵扣 Batch 调用、模型调优、模型部署、自定义模型。
- **有效期**：30~90 天，自开通或模型申请通过之日起计算。自 **2025 年 9 月 8 日 11 点**起，首次开通的用户获赠额度有效期统一调整为 90 天。
- **共享规则**：阿里云主账号与其 RAM 子账号共享免费额度。
- **查看方式**：控制台「模型用量 > 免费额度」页签，或在「模型广场」模型详情页的「免费额度」区域查看（分钟级更新，需手动刷新）。

### 免费额度用完即停

为防止意外扣费，可开启「免费额度用完即停」功能。开启后额度耗尽时停止响应并返回错误码 `AllocationQuota.FreeTierOnly`，不再继续扣费。

- **开启入口**：「模型用量 > 免费额度」页签（支持单个或批量开启，可一键开启所有模型），或模型广场模型详情页的开关。
- **关闭时机**：需等到控制台显示「免费额度用完」后才可关闭。
- **耗尽影响**：全新未认证用户耗尽后无法继续调用，需完成认证并充值；已认证用户若未开启此功能，超出额度将自动按量扣费，可能导致欠费。账户欠费时，即使其他模型仍有免费额度也无法调用。

## 模型调用价格（按量计费）

模型调用默认按量计费，单价取决于**模型版本、服务部署范围（地域）、模式（思考/非思考）、单次请求输入 Token 总量**等因素。部分模型实行**阶梯计费**：单价由单次请求的输入 Token 总量决定，该请求的所有 Token 均按对应阶梯单价结算（区间中 K=1,000，M=1,000,000）。

### 计费维度

- **文本生成（千问系列）**：分为 Max、Plus、Flash、Turbo、Long、QwQ 等档位，价格递减。例如华北2（北京）中国内地范围下，qwen3.7-max 输入 12 元/百万 Token、输出 36 元/百万 Token；qwen-turbo 输入 0.3 元、输出 0.6 元。
- **多模态模型**：千问 VL、千问 Omni、千问 OCR、QVQ 等按各自模态的 Token 计费，Omni 系列区分文本/图片/视频、音频等不同输入类型。
- **图像/视频生成（万相）**：按生成张数或视频时长计费。
- **语音模型**：CosyVoice、Qwen-TTS、Paraformer 等，TTS 按字符、ASR 按秒计费。
- **第三方模型**：DeepSeek、GLM、Kimi、MiniMax 等独立计费。

### 影响价格的因素

- **Batch 调用**：输入和输出 Token 单价均按实时推理价格的 **50%** 计费。
- **[上下文缓存](../concepts/prompt-caching.md)**：仅输入 Token 享有折扣，与 Batch 折扣不能同时生效。
- **思考模式**：部分模型（如 qwen-plus）区分非思考与思考模式，思考模式输出单价更高（思维链 + 回答）。
- **地域差异**：同一模型在华北2（北京）原价最低，海外地域（新加坡、弗吉尼亚、法兰克福、东京）按汇率上浮。

> 本文仅展示原价，限时优惠等活动信息请前往百炼控制台模型广场查看。

## 模型训练计费

模型训练按训练 Token 计费，公式为：

- **千问文本**：`训练费用 = (训练数据 Token 总数 + 混合训练数据 Token 总数) × 循环次数 × 训练单价`（最小计费单位 1 Token）
- **万相图像生成**：`训练费用 = 训练 Token 总量 × 训练单价`，其中 `训练 Token 总量 ≈ max_steps × Lstep`，Lstep 由 generation_type（t2i/i2i）与 max_token_length（1k/2k）共同决定。
- **万相视频生成**：`训练 Token 总量 = Σ(视频计费时长) × (max_pixels/1024) × n_epochs`，单条视频计费时长上限因模型而异（wan2.5 最多 10 秒，wan2.2 最多 5 秒）。

主动取消训练会按已消耗 Token 收费；其他原因导致的中断不收费。训练完成的新模型须先完成部署才能评测和调用。

## 模型部署计费

模型部署提供三种计费方式：

### 1. 按使用时长计费（预置吞吐）

`费用 = 使用时长 × (输入 TPM 单价 × 输入 TPM + 输出 TPM 单价 × 输出 TPM)`

- 后付费按小时计算，预付费按天计算。
- 当输入超过最长输入 Token 或超出购买的 TPM 量时，相关调用自动切换为按量付费模式（响应 Header 含 `x-dashscope-ptu-overflow:true`）。
- 后付费欠费时资源继续保留并计费 24 小时，超 24 小时停止计费、底层资源被删除，补足欠费后重新分配资源。

### 2. 按使用时长计费（模型单元）

`费用 = 使用时长（小时）× 模型单元数量 × 模型单元单价`

预付费按月计费时改为 `包月数 × 模型单元数量 × 月单价`。首月提前退订，日单价按 1.2 倍计费。支持 PD 分离模式（降低首 Token 延迟、提高吞吐）。

### 3. 按模型 Token 使用量

仅当对基础模型完成 SFT 高效训练并得到自定义模型后支持：`费用 = 输入 Token 数 × 输入单价 + 输出 Token 数 × 输出单价`。

### 部署计费起点

模型状态为**运行中**时开始计费；**部署中**、**欠费**、**部署失败**状态不计费。包月预付费自运行中状态开始消耗包月时间。

## 节省计划与资源包

为优化成本，百炼提供多种优惠方案。**抵扣顺序统一为：免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费**。

### AI 通用型节省计划（推荐）

通过承诺每月消费金额换取阶梯式折扣，最高 5.3 折。

- **核心优势**：覆盖阿里直供的全部模型，一次购买跨模型使用；承诺金额越高、周期越长折扣越大；自动抵扣，支持自动续费。
- **承诺周期**：3 个月、6 个月、12 个月、24 个月。以月为单位，当月未用完部分自动清零，不可累积。
- **抵扣范围**：支持模型调用（输入/输出 Token）、模型原生工具调用（Function Call、网页抓取）、[上下文缓存](../concepts/prompt-caching.md)、批量推理；**不支持**模型调优、模型部署。
- **付款方式**：全预付（一次支付全部承诺金额，折扣最大）或零预付（按月支付，需联系商务经理开通）。
- **模型分档**：A 类（千问文本/向量/排序/行业模型/工具调用）、B 类（图像/语音/视频）、C 类（qwen3.6-max-preview、DeepSeek、Kimi、GLM、MiniMax、HappyHorse）。三方直供模型不支持抵扣。
- **金额范围**：1,000 元起，以 10 元为单位调整，不设上限。

### 其他模型节省计划

适合用量较小或集中于特定模型的场景，购买后立即生效，超出有效期剩余金额作废、不支持退款。

- **大语言模型节省计划**：11 档（20 元~500,000 元），均无折扣，有效期 1 个月~1 年。适用于文本生成与多模态模型，**不支持**向量与排序模型。
- **千问语音模型节省计划**：5 档（20~5,000 元），折扣 9.8~8 折，适用于 CosyVoice、Qwen-TTS、Paraformer、Fun-ASR 等。
- **向量及排序模型节省计划**：5 档（100~10,000 元），折扣 9~7 折，适用于 text-embedding、gte-rerank 等。
- **万相模型节省计划**：5 档（20~30,000 元），折扣 9.8~9 折，适用于图像/视频生成模型。

### 资源包

预先购买具体 Token 数量或图片张数，用于抵扣特定模型**超出免费额度后**的实时推理用量。

- **生效与有效期**：购买后立即生效，无需手动激活；有效期随套餐而定，到期后余量作废。
- **退订**：未发生使用的部分可申请退款，已使用部分无法退款。
- **大语言模型推理资源包**：qwen-plus、qwen-max、qwen-turbo 三种，仅抵扣非思考模式实时推理，不支持 Batch、[上下文缓存](../concepts/prompt-caching.md)、调优、部署。qwen-plus 资源包对单次输入超过 128K Token 的部分无法抵扣。
- **图像生成模型资源包**：qwen-image（文生图消耗 1 张额度，图片编辑消耗 1.2 张）、qwen-image-plus（生成/编辑均消耗 1 张），容量耗尽后自动转按量付费。

### 常见抵扣失败原因

- **模型不匹配**：如购买大语言模型节省计划却调用万相或向量模型。
- **使用了不支持的功能**：调优、部署费用所有节省计划均不抵扣；[上下文缓存](../concepts/prompt-caching.md)、批量推理、工具调用仅 AI 通用型节省计划抵扣。
- **免费额度未用完**：节省计划/资源包仅抵扣免费额度用尽后的账单。
- **Token 长度超限**：qwen-plus 资源包对超过 128K 的部分不抵扣。

## 账单查询与成本管理

### 出账时机

仅在实际调用**结束**后生成账单：大模型推理分钟级出账（2~10 分钟）；批量推理、模型训练、知识库等小时级出账；业务高峰期可能进一步延迟。公测、邀测模型不产生账单记录。

### 费用概览

百炼控制台「模型 > 用量 & 费用 > 费用概览」展示当月总消费，拆分为**订阅购买费用**（Token Plan、预置吞吐、模型单元、节省计划等）与**账单费用**（按量产生的调用与训练）。支持按模型或 API Key 筛选、对比支出趋势、设置月度费用告警。该页面仅展示大模型推理费用，训练与知识库费用需查账单详情。

### 账单详情与字段解读

在「费用与成本 > 账单详情」页面，产品名称选择「大模型服务平台百炼」可下载明细。**实例 ID（出账粒度）**字段以英文分号 `;` 分隔，格式为：

- 标准调用：`ApiKeyID;业务空间ID;模型名称;输入/输出类型;调用渠道;免费额度用完即停标识`
- 控制台调用：`;业务空间ID;模型名称;输入/输出类型;调用渠道;免费额度用完即停标识`（不含 ApiKeyID）

调用渠道说明：`app`（应用程序调用）、`bmp`（控制台模型体验）、`assistant-api`（Assistant API）。账单的"计费项"统一显示为"大模型文本消耗量"，需通过实例 ID 字段区分具体模型。同一模型按计费类型（输入/输出/缓存命中）和调用渠道分别出账，会产生多行记录。

### 分账管理

给**业务空间**绑定**标签**可按部门或项目归集费用：在「业务空间管理」获取 Workspace ID，在「标签管理」页面对「大模型服务平台百炼:业务空间」资源绑定标签，再在「费用标签」页面启用该标签。配置完成后分账账单 T+1 天生效，可在账单详情的「实例标签」列验证。

### 模型调用统计

控制台「模型 > 用量 & 费用 > 模型用量」查看调用次数与统计；「模型监控」页面（北京/新加坡/弗吉尼亚）支持按时间范围、推理类型筛选，展示总调用次数、失败次数、平均调用时长、平均首包时长等指标，数据按小时更新。模型调用完约一小时后可查看监控统计。

## 欠费处理与停止计费

### 欠费判定与影响

账户可用额度 < 0 视为欠费（`可用额度 = (现金余额 + 信控额度) - (当月未结清 + 历史未结清)`）。按账单**商品名称**维度判定影响：

- 仍有免费额度、节省计划或资源包额度：可继续使用。
- 已购 Coding Plan 或 Token Plan：套餐额度独立于账户余额，欠费期间可继续使用，但自动续费失败，到期后无法续用。
- 以上额度均无：该商品下服务暂停，需结清欠费后恢复。

### 预防与停止

- **预防欠费**：在「高额消费预警」页面设置消费阈值；在费用概览页设置月度限额告警；删除不再使用的 API Key 防止意外调用；检查应用代码中是否开启了 `enable_search` 等按次计费参数。
- **停止模型推理**：停止代码调用、关闭控制台模型体验，或删除 API Key。
- **停止模型训练**：无正在进行的训练任务即不产生费用。
- **取消订阅**：Coding Plan 到期自动停止（不支持中途退订）；Token Plan 团队版按席位退订；模型部署按计费方式分别下线或退订实例。

## 成本优化建议

1. **优先用尽免费额度**：抵扣顺序最高，开通百炼后自动生效。
2. **常规场景首选 AI 通用型节省计划**：覆盖广、折扣大、灵活性高，承诺周期越长折扣越大。RAG 等同时涉及文本与向量/排序模型的场景，可选 AI 通用型或额外购买向量及排序模型节省计划。
3. **特定模型高用量**：可叠加资源包（抵扣优先级高于节省计划）。
4. **避免不支持功能的扣费**：Batch、[上下文缓存](../concepts/prompt-caching.md)等仅 AI 通用型节省计划抵扣；调优、部署费用所有优惠方案均不抵扣。
5. **关注出账延迟**：免费额度与控制台余量为分钟级更新且需手动刷新，操作前以最新显示为准，避免"看似有额度实际已耗尽"导致意外扣费。
6. **海外地域注意汇率上浮**：同一模型在新加坡、弗吉尼亚、法兰克福、东京等地域单价高于华北2（北京）。
