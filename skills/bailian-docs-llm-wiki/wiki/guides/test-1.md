# test 1

阿里云百炼的计费与成本管理覆盖模型调用按量计费、新人免费额度、模型训练与部署计费、节省计划与资源包抵扣、账单查询与分账、欠费与停服处理。开发者需理解计费规则、抵扣顺序与成本优化方案，才能在保留按量付费灵活性的同时有效控制调用成本。本文汇总上述各环节的关键规则与注意事项，原始细节请参见 [模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)、[新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)、[模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)、[节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md) 与 [账单查询与成本管理](../../raw/model-user-guide/test-1/bill-query-and-cost-management.md)。

## 计费模式与价格

模型调用默认**按量计费**，价格以 [模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md) 为准。关键规则：

- **阶梯计费**：部分模型按单次请求的输入 Token 总量分档，该请求的所有 Token 均按命中档的单价结算（不是分段累计）。例如某模型 0<Token≤32K 与 32K<Token≤128K 两档，输入 100K Token 时全部按第二档单价计费。
- **文本生成模型**：输入 Token 与输出 Token 分别计价；千问 Max、Plus 等在华北2（北京）等服务部署范围下提供免费额度，其他部署范围无免费额度。
- **Batch 调用**：支持的模型输入和输出 Token 单价均按实时推理价格的 50% 计费。
- **上下文缓存**：仅输入 Token 享有折扣。
- **两者不叠加**：Batch 半价与上下文缓存折扣不能同时生效。

模型训练计费公式为 `(训练数据 Token 总数 + 混合训练数据 Token 总数) × 循环次数 × 训练单价`，最小计费单位 1 Token，可在训练控制台查看预估费用。[模型部署](../concepts/model-deployment.md)则支持三种计费方式：按模型调用量计费、按算力使用时长计费、包月预付费，详见 [模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)。

## 抵扣顺序

多类优惠同时存在时，按以下顺序抵扣：

**免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费**

同类多个节省计划/资源包：优先抵扣先到期的；到期时间相同则优先抵扣先购买的。超出部分自动转为按量付费。

## 新人免费额度

首次开通阿里云百炼时自动发放各模型的免费额度，规则见 [新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)：

- **地域限制**：仅华北2（北京）地域且服务部署范围为中国内地的模型享有免费额度，其他地域和部署范围无免费额度。
- **有效期**：30～90 天，自开通或模型申请通过之日起计算。自 2025 年 9 月 8 日 11 点起，首次开通的用户获赠额度有效期调整为 90 天，此前已开通用户不受影响。
- **抵扣范围**：仅抵扣模型实时推理（调用）费用，不支持 Batch 调用、模型调优、[模型部署](../concepts/model-deployment.md)、自定义模型。
- **共享**：阿里云主账号与 RAM 子账号共享同一免费额度。
- **免费额度用完即停**：默认关闭。开启后额度耗尽时停止响应并返回错误码 `AllocationQuota.FreeTierOnly`，不再扣费。全新未认证用户额度耗尽后无法继续调用，需完成认证并充值后方可按量付费。

## 成本优化方案

### AI 通用型节省计划（推荐）

通过承诺一定期限（3/6/12/24 个月）的月消费金额换取阶梯式折扣，最高 5.3 折。覆盖阿里直供的全部模型，一次购买跨模型使用，支持自动续费。承诺周期以月为单位，每月额度独立、当月未用完自动清零不可累积。付费方式分全预付（享最大折扣）与零预付（需联系商务经理开通白名单）。

抵扣范围：支持模型调用（输入和输出 Tokens）、模型原生工具调用、上下文缓存、批量推理等费用；不支持模型调优、[模型部署](../concepts/model-deployment.md)费用。

折扣按模型分类不同：A 类（千问、千问-开源、文本向量、多模态向量、排序模型、行业模型、工具调用等）折扣最优；B 类（图像生成、语音合成、语音识别与翻译、视频生成与编辑）次之；C 类（qwen3.6-max-preview、DeepSeek、Kimi、GLM、MiniMax、HappyHorse）折扣较弱。三方直供模型不支持抵扣。

### 其他模型节省计划

适合用量较小或需求集中于特定模型的场景，购买后立即生效，有效期按档位而定，超出有效期剩余金额作废不支持退款。抵扣范围仅模型调用费用（输入和输出 Tokens），不支持工具调用、上下文缓存、批量推理、模型调优、模型部署。包含：

- **大语言模型节省计划**：各档位均无折扣，按模型调用价格扣费，仅华北2（北京），不支持向量与排序模型。
- **千问语音模型节省计划**：5 档（20/100/500/1000/5000 元），折扣 9.8 折～8 折，覆盖 CosyVoice、Qwen-TTS、Paraformer、Fun-ASR、Qwen-ASR 等。
- **向量及排序模型节省计划**：5 档（100/500/2000/5000/10000 元），折扣从无折扣到 7 折，覆盖 text-embedding、multimodal-embedding、qwen3-rerank、gte-rerank 等。

### 资源包

预先购买具体 Token 数量，抵扣特定模型超出免费额度后的实时推理用量，购买后立即生效。现有 qwen-plus、qwen-max、qwen-turbo 三类，仅华北2（北京），仅抵扣非思考模式、单次请求输入 `0<Token≤128K` 阶梯的实时推理费用（含输入和输出）。思考模式、单次输入 `Token>128K`、Batch 调用等产生的费用不支持抵扣。未发生使用的部分可申请退款，已使用部分不退。

## 账单查询与分账

- **出账时延**：大模型推理分钟级出账（通常 2～10 分钟），批量推理、模型训练、知识库等小时级出账，业务高峰可能进一步延迟。
- **费用概览**：百炼控制台「用量 & 费用 > 费用概览」，仅展示大模型推理相关费用；模型训练和知识库费用需通过账单详情查看。
- **账单详情**：在费用与成本的账单详情页，产品名称选「大模型服务平台百炼」。可按 ApiKeyID、业务空间ID、模型名称、输入/输出类型、调用渠道、实例标签拆分。
- **实例 ID 字段解读**：以英文分号分隔，格式为 `ApiKeyID;业务空间ID;模型名称;输入/输出类型;调用渠道;免费额度用完即停标识`。不含 ApiKeyID 通常表示控制台调用。调用渠道 `app` 为代码调用、`bmp` 为控制台模型体验、`assistant-api` 为 Assistant API。
- **分账**：给业务空间绑定标签后可按部门或项目归集费用，分账账单 T+1 天后生效，需在费用标签页启用对应标签。
- **按量付费扣款时点**：采用「预占+月结」模式，系统先冻结部分额度，月账期结束后（次月初）生成最终账单并实际扣款，并非实时扣款。

## 欠费与停止计费

账户可用额度 < 0 视为欠费，可能导致服务暂停。可用额度 =（现金余额 + 信控额度）-（当月未结清 + 历史未结清）。欠费影响按账单商品名称维度判定：

- 仍有免费额度、节省计划或资源包额度的商品可继续使用至额度耗尽。
- 已购 Coding Plan 或 Token Plan 套餐额度独立于账户余额，欠费期间可继续使用，但自动续费会失败，到期后无法续用。
- 以上额度均无的商品服务暂停，需结清欠费后恢复。

预防与停服：在「高额消费预警」设置消费阈值；停止模型推理可删除已创建的 API-Key；停止模型部署需下线已部署模型（包月预付费还需在退订管理页退订实例）；Coding Plan 到期自动停止不支持中途取消，需关闭自动续费；Token Plan 团队版可在控制台按席位退订。

## 注意事项

> **注意**：控制台免费额度数据为分钟级更新且需手动刷新。若未及时刷新，页面可能仍显示有额度但实际已耗尽，超出部分会直接从账户余额扣费。操作前请刷新页面以最新显示为准。

> **注意**：资源包仅抵扣非思考模式且单次输入 ≤128K 的实时推理费用。思考模式、单次输入 >128K 阶梯、Batch 调用、模型调优、模型部署等费用均不支持资源包抵扣，容易误判可用余量。

> **注意**：联网搜索等附加功能按调用次数单独计费，与模型推理费用分开出账。即使近期未主动操作控制台，历史创建的应用或代码中若开启了 `enable_search` 参数，每次被调用仍会产生联网搜索费用，可能导致"没怎么用却欠费"。

> **注意**：账单的"计费项"统一显示为"大模型文本消耗量"，未直接展示模型名称。需通过账单详情页的"实例 ID（出账粒度）"列定位模型，紧跟业务空间 ID 之后的字段即为模型名称。同一模型也会按计费类型（输入 Token、输出 Token、缓存命中等）和调用渠道分多行出账。
