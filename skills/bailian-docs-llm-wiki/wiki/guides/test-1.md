# test 1

阿里云百炼平台提供完整的模型计费与成本管理体系，涵盖按量付费、模型训练与部署计费、免费额度、节省计划及资源包等多种方案。开发者可根据自身用量和预算，灵活选择最优的计费策略来控制成本。

## 计费模式概览

百炼平台的计费主要分为三大类：

- **模型调用（按量付费）**：按实际消耗的输入/输出 Token 数量计费，是最基础的计费方式。详见[模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)。
- **模型训练**：按训练过程中消耗的 Token 总量计费，费用 = Token 总数 x 循环次数 x 训练单价。
- **模型部署**：支持按使用时长（预置吞吐/模型单元）和按 Token 使用量两种计费方式。

## 按量付费与阶梯计费

模型调用默认按量计费。部分模型实行**阶梯计费**：单价取决于单次请求的输入 Token 总量，该请求的所有 Token 均按对应阶梯的单价结算。

以千问系列为例（华北2-北京，中国内地部署范围）：

| 模型系列 | 输入单价（每百万Token） | 输出单价（每百万Token） | 免费额度 |
|---------|----------------------|----------------------|---------|
| qwen3.7-max | 12元 | 36元 | 100万Token |
| qwen3.7-plus | 2元（0~256K） | 8元（非思考）/ 8元（思考） | 100万Token |
| qwen3.5-plus | 0.8元（0~128K） | 4.8元 | 100万Token |
| qwen-plus | 0.8元（0~128K） | 2元（非思考）/ 8元（思考） | 100万Token |

> **注意**：支持 Batch 调用的模型，输入和输出 Token 单价均按实时推理价格的 50% 计费；支持上下文缓存的模型，仅输入 Token 享有折扣。两者不能同时生效。

百炼在多个地域提供服务，包括华北2（北京）、美国（弗吉尼亚）、新加坡、德国（法兰克福）、日本（东京）等，不同地域的价格可能有所差异。

## 新人免费额度

首次开通阿里云百炼时，平台会自动发放各模型的新人专属免费额度，有效期为 30~90 天。根据[新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)文档，关键规则如下：

- **适用范围**：仅限华北2（北京）地域且服务部署范围为中国内地的模型，仅抵扣**实时推理**费用。
- **不支持抵扣**：Batch 调用、模型调优、模型部署、自定义模型。
- **共享机制**：主账号与 RAM 子账号共享免费额度。
- **额度耗尽后**：未认证用户需完成认证并充值；已认证用户可开启「免费额度用完即停」功能防止意外扣费。

查看剩余额度可在控制台的[模型用量](https://bailian.console.aliyun.com/?tab=model#/model-usage/free-quota)页面或模型广场详情页查看。

## 模型训练计费

模型训练按训练 Token 计费，具体规则因模型类型而异，详见[模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)：

### 文本生成模型（千问）

训练费用 = （训练数据 Token 总数 + 混合训练数据 Token 总数）x 循环次数 x 训练单价。例如 Qwen3.5-27B 训练单价为 0.05元/千Token，Qwen3.5-9B 为 0.02元/千Token。

### 图像生成模型（万相）

训练费用 = 训练 Token 总量 x 训练单价。Token 总量由 max_steps 和每步 Token 消耗量决定，受 max_token_length 和 generation_type 影响。wan2.7-image-pro 和 wan2.7-image 的训练价格均为 0.08元/千Token。

### 视频生成模型（万相）

训练费用涉及视频计费时长、max_pixels 和 n_epochs 三个因素。wan2.5 模型单条视频最多按 10 秒计算，wan2.2 模型最多按 5 秒计算。

## 模型部署计费

模型部署支持多种计费方式：

- **预置吞吐（按时长）**：费用 = 使用时长 x（输入 TPM 单价 x 输入 TPM + 输出 TPM 单价 x 输出 TPM），支持后付费（按小时）和预付费（按天）。
- **模型单元（按时长）**：费用 = 使用时长 x 模型单元数量 x 单价，支持后付费（按小时）和预付费（包月）。
- **按 Token 使用量**：按实际推理消耗的 Token 计费。

部署时如果输入超过最长输入 Token 或超出购买的 TPM 量，调用将自动切换为按量付费模式（API 返回 Header 包含 `x-dashscope-ptu-overflow:true`）。

## 成本优化方案

根据[节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)文档，百炼提供以下成本优化选项：

### AI 通用型节省计划（推荐）

通过承诺每月消费金额换取阶梯式折扣，最高可享 **5.3 折**。核心特点：

- 覆盖阿里直供的全部模型，支持跨模型使用
- 承诺周期可选 3/6/12/24 个月，支持全预付和零预付
- 支持抵扣模型调用、工具调用、上下文缓存、批量推理等费用
- 不支持抵扣模型调优和模型部署费用

折扣示例：12 个月全预付、月承诺 10,000 元时，A 类模型（千问系列）享 8 折，B 类模型（图像/语音/视频）享 7.1 折。

抵扣顺序：**免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费**。

### 其他模型节省计划

针对特定模型系列的一次性购买方案，包括大语言模型推理、千问语音模型、向量及排序模型三类。适合用量较小或需求高度集中于某一特定模型的场景。

### 资源包

预先购买具体 Token 数量，用于抵扣特定模型超出免费额度后的实时推理用量。目前提供 qwen-plus、qwen-max、qwen-turbo 三种资源包。

## 账单查询与成本管理

根据[账单查询与成本管理](../../raw/model-user-guide/test-1/bill-query-and-cost-management.md)文档，百炼提供以下管理能力：

### 查询账单

- **费用概览**：在控制台[费用概览](https://bailian.console.aliyun.com/?tab=model#/costing-balance/overview)页面查看总消费、按模型或 API Key 查询费用。
- **账单详情**：在[账单详情](https://usercenter2.aliyun.com/finance/expense-report/expense-detail)页面下载账单，通过「实例 ID（出账粒度）」字段区分 ApiKeyID、业务空间、模型名称、调用渠道等。
- **出账时间**：大模型推理分钟级出账（2~10 分钟），批量推理和模型训练小时级出账。

### 分账管理

通过给业务空间绑定标签，可按部门或项目归集费用。在[标签管理](https://resourcemanager.console.aliyun.com/tags#/)页面绑定标签后，分账账单 T+1 天生效。

### 欠费处理

账户可用额度小于 0 视为欠费。欠费时：有免费额度的模型可继续使用至耗尽；有节省计划或资源包额度的可继续使用；Coding Plan 和 Token Plan 套餐额度独立于账户余额，欠费期间可继续使用但会导致自动续费失败。

### 停止计费

- 停止模型推理：停止 API 调用，删除 API Key 防止意外调用
- 停止模型部署：下线已部署的模型，预付费需在退订管理页面退订
- 取消订阅产品：关闭 Coding Plan / Token Plan 的自动续费

## 常见问题

| 问题 | 解决方案 |
|------|---------|
| 免费额度用完会怎样？ | 未认证用户需认证充值；已认证用户可开启「用完即停」 |
| 为什么产生了费用？ | 检查模型是否已无免费额度、是否使用了 Batch 调用、控制台额度显示是否已刷新 |
| 同一模型账单有多行记录？ | 按输入/输出 Token 和调用渠道分别出账 |
| 没怎么用却产生欠费？ | 检查是否有应用开启了 `enable_search` 联网搜索（按次计费） |
| 按量付费是实时扣款吗？ | 不是，采用「预占+月结」模式 |
