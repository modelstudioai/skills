# test 1

阿里云百炼平台的计费体系涵盖模型推理调用、模型训练、模型部署三大场景，同时提供免费额度、节省计划、资源包等多种成本优化手段。本文从计费规则、费用查询、成本优化三个维度，帮助开发者快速理解百炼平台的费用结构并做出合理选择。

## 计费模式概览

百炼平台的计费按使用场景分为三类：

- **模型推理（调用）**：默认按量付费，按输入/输出 Token 数计费。部分模型支持阶梯计费，单价取决于单次请求的输入 Token 总量。详见[模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)。
- **模型训练**：按训练 Token 计费，费用 = 训练数据 Token 总数 x 循环次数 x 训练单价。支持文本生成（千问）、图像生成（万相）、视频生成（万相）等模型的微调训练。
- **模型部署**：支持按使用时长计费（预置吞吐）和按模型单元计费两种方式，可选后付费或预付费（按天/包月）。

> **注意**：免费额度仅抵扣模型实时推理费用，不支持抵扣 Batch 调用、模型调优、模型部署及自定义模型的费用。

## 免费额度

首次开通百炼时，平台自动发放新人免费额度，有效期 30~90 天（2025年9月8日后开通的用户为 90 天）。免费额度仅适用于华北2（北京）地域且服务部署范围为中国内地的模型。主账号与 RAM 子账号共享额度。

关键操作：

- **查看余量**：在控制台[免费额度](https://bailian.console.aliyun.com/?tab=costing-balance#/costing-balance/free-quota)页面查看，或在模型广场详情页的"免费额度"区域查看（分钟级更新，需手动刷新）。
- **用完即停**：已认证用户免费额度耗尽后会自动扣费。可开启"免费额度用完即停"功能，额度耗尽时返回 `AllocationQuota.FreeTierOnly` 错误码，避免意外扣费。全新未认证用户则默认额度耗尽后停止服务。

详细规则参见[新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)。

## 模型调用价格

模型推理按量计费，不同模型系列和地域的单价不同。以千问 Max 系列为例（华北2-北京，中国内地部署）：

| 模型 | 输入单价（每百万Token） | 输出单价（每百万Token） | 免费额度 |
|------|----------------------|----------------------|---------|
| qwen3.7-max | 12元 | 36元 | 100万Token |
| qwen3-max（≤32K） | 2.5元 | 10元 | 100万Token |
| qwen3-max（32K~128K） | 4元 | 16元 | - |
| qwen3-max（128K~256K） | 7元 | 28元 | - |

千问 Plus 系列（华北2-北京）：

| 模型 | 输入单价（每百万Token） | 非思考输出 | 思考输出 | 免费额度 |
|------|----------------------|-----------|---------|---------|
| qwen3.7-plus（≤256K） | 2元 | 8元 | 8元 | 100万Token |
| qwen-plus（≤128K） | 0.8元 | 2元 | 8元 | 100万Token |

部分模型支持 Batch 调用（输入输出均半价）和上下文缓存（输入 Token 享折扣），两者不能同时生效。海外地域（美国、新加坡、德国、日本）的单价通常高于北京地域。

## 模型训练与部署计费

### 训练计费

训练费用因模型类型而异，详见[模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)：

- **文本模型（千问）**：费用 = (训练数据 Token + 混合训练数据 Token) x 循环次数 x 单价。例如 qwen3-32b 训练单价为 0.04元/千Token。
- **图像模型（万相）**：费用 = 训练 Token 总量 x 单价。Token 总量 = max_steps x Lstep，Lstep 由 max_token_length 和 generation_type 决定。wan2.7-image-pro 训练单价 0.08元/千Token。
- **视频模型（万相）**：Token 总量与视频时长、max_pixels、n_epochs 相关。wan2.2-i2v-flash 训练单价 0.06元/千Token。

### 部署计费

部署支持两种计费模式：

1. **预置吞吐（按 TPM）**：费用 = 时长 x (输入 TPM 单价 x 输入 TPM + 输出 TPM 单价 x 输出 TPM)。超出购买的 TPM 量时自动切换为按量付费（返回 Header 包含 `x-dashscope-ptu-overflow:true`）。
2. **模型单元**：费用 = 时长(小时) x 单元数量 x 单元单价。支持后付费（按小时）和预付费（包月）。部分模型支持 PD 分离模式以降低首 Token 延迟。

## 成本优化方案

百炼提供三种成本优化方案，抵扣优先级为：**免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费**。

### AI 通用型节省计划（推荐）

通过承诺每月消费金额换取阶梯折扣，最高 5.3 折。覆盖阿里直供全部模型，灵活性最高。

- **承诺周期**：3/6/12/24 个月，月承诺额度 1000 元起（10 元为单位递增）
- **付费方式**：全预付（最大折扣）或零预付（需商务开通）
- **抵扣范围**：模型调用（输入输出 Token）、工具调用（Function Call 等）、上下文缓存、批量推理。不支持抵扣训练和部署费用
- **折扣示例**：12个月全预付、月承诺 10,000 元，A 类模型（千问文本）享 8 折

> **注意**：C 类模型（DeepSeek、Kimi、GLM、MiniMax 等第三方模型）当前不享受节省计划折扣。每月未用完的额度自动清零，不可累积。

### 其他模型节省计划

针对特定模型系列的一次性购买方案，适合用量集中于单一模型的场景：

- **大语言模型推理**：20元~500,000元多档，无折扣，按原价扣费
- **千问语音模型**：20元~5,000元五档，最高 8 折
- **向量及排序模型**：100元~10,000元五档，最高 7 折
- **万相模型**：20元~30,000元五档，最高 9 折

### 资源包

预购具体 Token 数量，抵扣特定模型超出免费额度后的实时推理用量。购买后立即生效，到期未用完自动作废。详见[节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)。

## 账单查询与费用管理

### 查询账单

- **费用概览**：在控制台"用量 & 费用 > 费用概览"查看当月总消费（订阅购买 + 按量账单），支持按模型或 API Key 筛选
- **账单详情**：在[账单详情](https://usercenter2.aliyun.com/finance/expense-report/expense-detail)页面，产品名称选"大模型服务平台百炼"。实例 ID 格式为 `ApiKeyID;业务空间ID;模型名称;输入输出类型;调用渠道;免费额度用完即停标识`
- **出账延迟**：推理账单通常 2~10 分钟出账，训练/批量推理/知识库按小时出账

### 分账管理

给[业务空间](../concepts/workspace.md)绑定标签，可按部门或项目归集费用。在标签管理页面为"大模型服务平台百炼:[业务空间](../concepts/workspace.md)"资源绑定标签键值，启用后 T+1 天生效。

### 欠费与停止计费

- **欠费判定**：账户可用额度 < 0 时欠费，即使有免费额度也可能无法调用（视具体商品而定）
- **停止计费**：停止 API 调用并删除 API-Key 即可停止推理费用；部署资源需手动下线；Token Plan/Coding Plan 需关闭自动续费或退订

详细操作步骤参见[账单查询与成本管理](../../raw/model-user-guide/test-1/bill-query-and-cost-management.md)。

## 常见问题

**为什么产生了意外费用？**
常见原因包括：免费额度已耗尽但未开启用完即停、控制台额度显示未及时刷新（分钟级更新需手动刷新）、代码中开启了联网搜索（`enable_search`）等附加功能产生单独计费。

**按量付费是实时扣款吗？**
不是。阿里云采用"预占+月结"模式，先冻结部分额度，次月初生成最终账单并实际扣款。

**如何选择节省计划？**
大多数场景优先选择 AI 通用型节省计划（覆盖面广、折扣力度大）。仅当用量高度集中于语音、向量排序或万相模型时，考虑对应的专项节省计划。资源包适合小额试用或精确预算控制的场景。
