# test 1

阿里云百炼（Model Studio）围绕"模型调用—模型训练—模型部署"三条主线提供计费与成本管理手段。首次开通可领新人免费额度用于实时推理；日常按量付费的调用费用可借助节省计划、资源包、Batch 半价、上下文缓存等方式压降；训练与预置吞吐部署则按资源占用单独计费。所有费用统一进入阿里云账户体系，可在控制台通过账单与监控工具进行核对与预警。

## 新人免费额度

首次开通阿里云百炼（中国内地版）的用户，平台会按模型发放一次性免费推理额度，有效期 30～90 天（2025 年 9 月 8 日 11 点后新开通的用户统一为 90 天）。免费额度**仅抵扣实时推理 Token**，不支持 Batch 调用、模型调优、模型部署以及任何自定义模型（调优/部署后模型）的费用抵扣，主账号与其 RAM 子账号共享同一份额度。

免费额度查看有两处入口：控制台的"模型用量 > 免费额度"页签（可看到余量与过期时间），以及"模型广场"单个模型详情页的"免费额度"区域。页面显示为分钟级更新，需手动刷新。

**额度耗尽后的行为差异**：
- 全新未认证用户：直接停止响应并返回错误码 `AllocationQuota.FreeTierOnly`，必须完成实名认证并充值后才能继续按量付费。
- 已认证用户：未开启"免费额度用完即停"时，超出部分按输入/输出单价直接计入后付费账单；开启后则停止响应，不再产生费用。

为避免意外扣费，建议开启[免费额度用完即停](../../raw/model-user-guide/test-1/new-free-quota.md)，并在"我的试用"中配置余量 20% / 100% 的短信、站内信与邮件预警。

## 模型调用价格

模型调用（推理）按输入 Token 与输出 Token 分别计费，部分模型还实行**阶梯计费**：单次请求的输入 Token 总量决定该请求所有 Token 适用的单价档位（例如 0 < Token ≤ 32K 与 32K < Token ≤ 128K 两档，输入 100K Token 时整次请求按第二档单价结算）。

降低推理单价的主要手段：
- **Batch 调用**：兼容 OpenAI 的批量接口，输入与输出单价均按实时推理的 50% 计费；
- **上下文缓存**：对输入 Token 享有折扣，与 Batch 半价互斥，两者只能择一；
- **思考模式 vs 非思考模式**：部分模型（如 qwen-plus）对思考链路（思维链）输出单独定价，通常高于非思考模式输出；
- **地域差异**：同一模型在华北 2（北京）、新加坡、美国（弗吉尼亚）、德国（法兰克福）的单价不同，详见模型广场对应地域页签。

完整模型 ID、阶梯档位与分地域单价列表见[模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)。

## 模型训练与部署计费

### 训练计费

训练按消耗的 Token 总量 × 训练单价计费，最小计费单位为 1 Token。

- **文本生成模型（千问系列）**：费用 = (训练数据 Token + 混合训练数据 Token) × 循环次数 × 单价；
- **图像生成模型（万相）**：训练 Token 总量 ≈ max_steps × L_max（L_max 由 generation_type 与 max_token_length 决定）；
- **视频生成模型（万相）**：训练 Token 总量 = Σ(视频计费时长) × (max_pixels / 1024) × n_epochs，单条视频 wan2.5 最多按 10 秒计、wan2.2 最多按 5 秒计。

训练完成后必须做**模型部署**，才能对外评测与调用。训练与部署的模型代码与单价见[模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)。

### 部署计费

部署支持两种形态：
1. **预置吞吐（按使用时长）**：按"输入 TPM × 输入单价 + 输出 TPM × 输出单价 × 时长"计费，后付费以小时、预付费以天结算。超出最长输入 Token 或 TPM 上限时自动切换为当前模型的按量付费模式，此时 API Header 会返回 `x-dashscope-ptu-overflow: true`，推理性能下降且受公共流量限流约束。
2. **模型单元（按使用时长 / 按 Token 使用量）**：部分模型（如部分千问、GLM、DeepSeek 与多模态模型）提供模型单元维度计费，兼顾文本与多模态场景。

预付费订单支付后立即生效，22:00 后下单到期日自动顺延 1 天；到期后服务延后 2 小时停止，资源再保留 14 小时后释放，期间无法提前终止。

## 节省计划与资源包

对于稳定用量场景，应优先使用节省计划或资源包压降单价。

- **AI 通用型节省计划**：承诺一段时间内的消费金额，换取对应模型家族（千问文本、千问 VL、万相图像/视频、DeepSeek 等）的折扣单价，支持续订与折扣查询。
- **其他模型节省计划**：针对语音、向量与排序等细分模型家族的专用承诺消费计划。
- **资源包**：一次性购买固定 Token / 次数额度，大语言模型推理资源包适合可预估用量的场景。

具体支持的模型家族、折扣档位与生命周期管理规则见[节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)。选型时先估算月度用量与模型分布，再对比"按量付费 vs 节省计划 vs 资源包"的等效单价。

## 账单查询与成本管理

所有计费统一进入阿里云账户体系，可通过以下工具进行核对与管控：

- **费用概览 / 账单详情**：在"费用与成本"页面按"产品名称 = 大模型服务平台百炼"筛选，可下载账单并按字段解读输入/输出/免费额度抵扣用量。费用类型标注为"免费额度"的账单项即对应免费抵扣部分。
- **分账管理**：按[业务空间](../concepts/workspace.md)或项目维度拆分成本，便于多团队共用账号场景下的内部结算。
- **模型监控**：调用结束一小时后可在"模型监控"页面按时段、[业务空间](../concepts/workspace.md)查看调用量与错误率，数据按小时更新，高峰期可能再延后一小时。
- **欠费处理**：账户欠费时所有模型（含仍有免费额度的模型）都会停止服务；后付费场景下欠费会保留资源继续计费 24 小时后再释放。
- **停止计费**：若需彻底关停，应删除 API-Key，避免遗留调用继续计费。

推荐同时配置[高额消费预警](../../raw/model-user-guide/test-1/bill-query-and-cost-management.md)（按产品与日阈值短信提醒）与预算管理，从源头控制意外支出。完整查询、分账与欠费规则见[账单查询与成本管理](../../raw/model-user-guide/test-1/bill-query-and-cost-management.md)。

## 限制与注意事项

- 免费额度与调用价格均以**中国内地版**为准，其他地域（新加坡、美国、德国）的免费额度、单价与可用模型均不相同。
- Batch 调用半价与上下文缓存折扣**不可叠加**，同一请求只能二选一。
- 预置吞吐在超 TPM / 超 Token 上限时自动降级到按量付费，性能与限流规则与公共流量一致，不应作为弹性扩容手段。
- 控制台免费额度显示为分钟级更新，未及时刷新可能导致"页面有额度但实际已耗尽"而产生扣费，操作前务必手动刷新。
- 主账号与 RAM 子账号的免费额度共享，但计费、欠费与资源释放均以主账号为粒度处理。
- 模型代码（如 `qwen3.7-max-2026-05-20`）会持续迭代，调用时建议使用不带日期的稳定 ID（如 `qwen3.7-max`）以自动指向最新能力版本，同时关注价格表中的"当前能力等同于"标注。
