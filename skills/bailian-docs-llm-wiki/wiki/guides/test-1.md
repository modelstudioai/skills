# test 1

阿里云百炼平台的计费体系涵盖模型调用（按量付费）、模型训练、模型部署三大场景，并提供免费额度、节省计划、资源包等多种成本优化方案。开发者在接入前应了解各计费维度的规则，合理选择付费方式以控制成本。

## 计费模式总览

百炼平台的费用主要由以下部分构成：

- **模型调用（按量付费）**：按输入/输出 Token 数计费，部分模型实行阶梯计费。详见[模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)。
- **模型训练**：按训练 Token 总量计费，公式为 `训练数据 Token 总数 × 循环次数 × 训练单价`。
- **模型部署**：支持按使用时长（预置吞吐/模型单元）或按 Token 使用量计费。

抵扣优先级为：**免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费**。

## 免费额度

首次开通百炼时，平台自动发放各模型的新人免费额度，有效期 30~90 天（2025 年 9 月 8 日后新开通用户为 90 天）。免费额度仅限**中国内地版**模型的**实时推理**场景，不支持 Batch 调用、模型调优、模型部署及自定义模型。主账号与 RAM 子账号共享额度。

关键注意事项：

- 已认证用户额度耗尽后会**直接扣费**，建议开启「免费额度用完即停」功能防止意外支出。
- 未认证用户额度耗尽后无法继续调用，需完成认证并充值。
- 账户欠费时，即使仍有免费额度也无法调用。

额度余量可在控制台的「模型用量 > 免费额度」或「模型广场 > 模型详情」中查看。更多细节参见[新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)。

## 模型调用价格

### 阶梯计费规则

部分模型按单次请求的输入 Token 总量分档计价。所有 Token 统一按所在阶梯的单价结算，不做拆分。例如输入 100K Token 落在 32K~128K 区间，则全部按该档单价计费。

### 主要模型价格示例（华北2-北京，每百万 Token）

| 模型 | 输入单价 | 输出单价 | 免费额度 |
|------|---------|---------|---------|
| qwen3.7-max | 12 元 | 36 元 | 100 万 Token |
| qwen3-max（0~32K） | 2.5 元 | 10 元 | 100 万 Token |
| qwen3-max（32K~128K） | 4 元 | 16 元 | - |
| qwen-plus（0~128K） | 0.8 元（非思考 2 元/思考 8 元） | - | 100 万 Token |

Batch 调用的输入和输出单价均为实时推理价格的 **50%**。支持上下文缓存的模型，输入 Token 可享有额外折扣。两者不能同时生效。

> **注意**：不同地域（北京、新加坡、弗吉尼亚、法兰克福）的价格差异较大。国际站（新加坡/欧盟部署范围）的单价通常为中国内地版的 1.5~4 倍，且无免费额度。选择服务部署范围时请注意成本影响。

## 模型训练与部署计费

### 训练计费

训练按 Token 计费，支持千问文本模型、千问 VL、万相图像/视频生成模型。以千问文本模型为例：

- **计费公式**：`(训练数据 Token + 混合训练数据 Token) × 循环次数 × 训练单价`
- 典型单价范围：Qwen3-0.6B 为 0.003 元/千 Token，Qwen2.5-72B 为 0.15 元/千 Token

训练完成后需先完成**模型部署**才能评测和调用。详见[模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)。

### 部署计费

部署支持三种计费方式：

1. **预置吞吐（按 TPM 时长计费）**：`使用时长 × (输入 TPM 单价 × 输入 TPM + 输出 TPM 单价 × 输出 TPM)`，支持后付费（按小时）和预付费（按天）。当输入超过最长输入 Token 或超出购买 TPM 量时，自动切换为按量付费。
2. **模型单元（按时长计费）**：`使用时长 × 模型单元数量 × 模型单元单价`，支持后付费（按小时）和包月预付费。
3. **按 Token 使用量**：仅限对基础模型完成 SFT 高效训练后的自定义模型。

## 成本优化方案

### AI 通用型节省计划（推荐）

承诺月消费金额（1000 元起），换取阶梯式折扣，最高 **5.3 折**。核心特点：

- 覆盖阿里直供的全部模型（A/B/C 三类），一次购买跨模型使用
- 承诺周期可选 3/6/12/24 个月，全预付折扣最大
- 月额度不累积，当月未用完自动清零
- 支持抵扣模型调用、工具调用（Function Call、联网搜索等）、上下文缓存、批量推理
- 不支持抵扣模型调优、模型部署、MCP 广场联网搜索

> **注意**：C 类模型（DeepSeek、Kimi、GLM、MiniMax 等第三方模型及 qwen3.6-max-preview）目前在 AI 通用型节省计划中**无折扣**，需评估是否值得通过此方案管理。

### 其他模型节省计划

面向特定模型系列的定额方案，包括大语言模型推理节省计划（无折扣，但可锁定预算）、千问语音模型节省计划（最高 8 折）、向量及排序模型节省计划（最高 7 折）。仅支持抵扣模型调用（输入/输出 Token），不支持工具调用、缓存、批量推理。

### 资源包

一次性购买固定 Token 量，绑定特定模型（如 qwen-plus、qwen-max、qwen-turbo）。适合用量可预测的场景，但灵活性最低。详细方案参见[节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)。

## 账单查询与成本管理

### 查询账单

- **费用概览**：控制台「用量 & 费用 > 费用概览」，可按模型或 API Key 筛选查看当月费用。
- **账单详情**：在阿里云费用中心的账单详情页，按 `实例 ID（出账粒度）` 字段解读：格式为 `ApiKeyID;业务空间ID;模型名称;输入/输出类型;调用渠道;免费额度用完即停标识`。
- **出账时间**：模型推理分钟级出账（2~10 分钟），批量推理/训练/知识库小时级出账。

### 分账管理

给[业务空间](../concepts/workspace.md)绑定标签，可按部门或项目归集费用。在标签管理中为[业务空间](../concepts/workspace.md)绑定标签键值，然后在费用标签中启用，T+1 天后生效。

### 欠费与停止计费

账户可用额度 < 0 时视为欠费。欠费后：有免费额度可继续使用至耗尽；有节省计划/资源包额度可继续使用；Coding Plan/Token Plan 套餐额度独立，可继续使用但自动续费会失败。以上均无时服务暂停。

停止计费的方式：删除 API Key 阻止推理调用、下线已部署模型、关闭自动续费。详见[账单查询与成本管理](../../raw/model-user-guide/test-1/bill-query-and-cost-management.md)。

## 常见问题

| 问题 | 解答 |
|------|------|
| 为什么产生了费用？ | 模型免费额度已耗尽或过期；Batch 调用不支持免费额度抵扣；控制台数据为分钟级更新需手动刷新 |
| 按量付费是实时扣款吗？ | 不是，采用「预占+月结」模式，次月初生成最终账单并扣款 |
| 如何避免意外扣费？ | 开启「免费额度用完即停」、删除不用的 API Key、设置高额消费预警 |
| 节省计划和资源包如何选？ | 优先 AI 通用型节省计划（覆盖广、折扣大）；特定模型大量使用可叠加资源包 |
