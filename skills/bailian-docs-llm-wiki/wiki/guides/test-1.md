# test 1

本页汇总阿里云百炼平台在计费与成本管理方面的关键知识，覆盖新人免费额度、模型调用价格、模型训练与部署计费，以及节省计划、资源包等成本优化方案与账单查询、欠费处理流程。面向需要控制大模型使用成本的开发者，帮助你理解各项费用如何产生、如何抵扣以及如何监控和止损。

## 计费全景与抵扣优先级

百炼的费用主要由三类活动产生：**模型调用（实时推理）**、**模型训练（调优）** 和 **模型部署**。模型调用默认按量计费，涵盖各类模型的输入/输出 Token 单价，详见 [模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)。

当一次调用发生时，系统按固定优先级自动抵扣费用，无需手动设置：

**免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费**

> **注意**：[新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md) 文档中给出的抵扣优先级为"免费额度 > 资源包 > 节省计划 > 按量付费"，而 [节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md) 进一步区分了"其他模型节省计划"与"AI 通用型节省计划"的先后顺序。以后者的更细粒度顺序为准。

## 新人免费额度

首次开通阿里云百炼时，平台会为各模型自动发放新人专属免费额度（通常每个模型 100 万 Token）。核心规则：

- **地域限制**：仅华北2（北京）地域且服务部署范围为「中国内地」的模型享有免费额度。
- **有效期**：30～90 天。自 2025 年 9 月 8 日 11 点起首次开通的用户，有效期统一调整为 90 天；额度过期自动作废，不支持补发、延期或重置。
- **适用范围**：仅抵扣**实时推理**费用，不抵扣 Batch 调用、模型调优、模型部署及自定义模型。
- **额度独立**：不同模型（含同一模型的不同快照版本，如 `qwen-max` 与 `qwen-max-2026-05-17`）额度相互独立，不共享、不自动切换。
- **主子账号共享**：主账号与其 RAM 子账号共享同一份免费额度。

**免费额度用完即停**：已认证用户可提前开启该开关，额度耗尽时停止响应并返回错误码 `AllocationQuota.FreeTierOnly`，避免意外扣费。全新未认证用户额度耗尽后需先完成实名认证并充值方可继续按量付费。相关开启方式、查看余量与预警配置详见 [新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)。

> **注意**：**Token Plan / Coding Plan 专属 API Key** 不消耗免费额度，使用专属 Key 调用会直接按量付费；如需使用免费额度请改用通用 API Key。

## 模型调用价格（按量付费）

- **计费方式**：按输入 Token 和输出 Token 分别计费，单价以「每百万 Token」为单位。
- **阶梯计费**：部分模型按单次请求的输入 Token 总量分档定价，落入某一区间后该请求所有 Token 均按对应档位结算。例如 `qwen3-max` 华北2（北京）划分为 `0<Token≤32K`（2.5 元/16 元起）、`32K<Token≤128K`、`128K<Token≤256K` 三档。
- **折扣因素**：支持 [Batch 调用](https://help.aliyun.com/zh/model-studio/batch-interfaces-compatible-with-openai/) 的模型，输入/输出单价按实时推理价的 50% 计费；支持上下文缓存的模型仅输入 Token 享折扣，两者不能同时生效。
- **地域差异**：同一模型在华北2（北京）、美国（弗吉尼亚）、新加坡、德国、日本等地域单价不同，境外地域通常无免费额度。

完整分模型价目表参见 [模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)。

## 模型训练与部署计费

免费额度和节省计划均**不抵扣**训练与部署费用，需单独关注。

**模型训练**：按训练 Token 计费。文本模型公式为 `(训练数据 Token + 混合数据 Token) × 循环次数 × 训练单价`；图像/视频生成模型的训练 Token 总量由 `max_steps`、`max_pixels`、`n_epochs` 等超参决定。训练完成的新模型需先完成**部署**才能评测和调用。

**模型部署**：提供两种计费模式：

- **按使用时长计费（预置吞吐）**：`费用 = 使用时长 × (输入 TPM 单价 × 输入 TPM + 输出 TPM 单价 × 输出 TPM)`，区分后付费（按小时）和预付费（按天）。
- **按使用时长计费（模型单元）**：`费用 = 使用时长 × 模型单元数量 × 模型单元单价`，支持后付费按小时或预付费按月（`包月数 × 单元数 × 月单价`）。

各模型（千问、DeepSeek、GLM、千问 VL 等）的具体单价表见 [模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)。

> **注意**：后付费部署时若账户欠费，资源仍会保留并计费 24 小时；超时后停止计费并删除底层资源，但部署任务保留，补足欠费后会重新分配资源并**继续产生费用**。不再使用时应主动下线部署任务。

## 成本优化：节省计划与资源包

对于稳定用量的场景，可通过预付费方案降低成本：

- **AI 通用型节省计划（推荐）**：承诺每月消费金额（1000 元起）换取阶梯折扣，最高 5.3 折，可抵扣阿里直供的全部模型；月承诺额度**不可跨月累积**。支持抵扣模型调用、原生工具调用、上下文缓存、批量推理，但**不抵扣**模型调优与部署。
- **其他模型节省计划**：一次性购买固定金额，抵扣特定模型系列（如大语言模型、千问语音、向量排序、万相），折扣通常不如通用型。
- **资源包**：预购具体 Token/图片数量，仅抵扣单个特定模型超出免费额度后的实时推理用量。

选型、折扣表、适用模型与地域详见 [节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)。

## 账单查询与欠费处理

- **出账时效**：大模型推理分钟级出账（通常 2～10 分钟）；批量推理、模型训练、知识库等小时级出账。
- **账单溯源**：在账单详情的「实例 ID（出账粒度）」列，按 `ApiKeyID;业务空间ID;模型名称;输入/输出类型;调用渠道;免费额度用完即停标识` 格式解读每行记录。
- **分账管理**：给业务空间绑定标签，可按部门/项目归集费用，T+1 天生效。
- **欠费判定**：`可用额度 = (现金余额 + 信控额度) - (当月未结清 + 历史未结清) < 0` 即视为欠费；欠费按商品维度判定，仍有免费额度/节省计划/资源包的商品可继续使用。
- **止损方式**：删除 API Key、下线部署模型、关闭自动续费、设置高额消费预警等。

完整流程、字段解读与常见问题见 [账单查询与成本管理](../../raw/model-user-guide/test-1/bill-query-and-cost-management.md)。

## 关键注意事项汇总

- 免费额度、节省计划、资源包**均不抵扣模型调优与部署费用**。
- 控制台免费额度为分钟级更新且需手动刷新，显示"仍有额度"时实际可能已耗尽而产生费用。
- 联网搜索（`enable_search`）等附加功能按调用次数单独计费，可能在无感知情况下导致欠费。
- 账户欠费时，即使模型仍有免费额度也无法调用。
- 按量付费采用"预占 + 月结"模式，实际扣款发生在次月初生成最终账单时，而非实时扣款。
