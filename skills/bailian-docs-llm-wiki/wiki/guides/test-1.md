# test 1

阿里云百炼平台提供完整的计费体系，涵盖模型推理按量付费、模型训练与部署计费、新人免费额度，以及节省计划和资源包等多种成本优化方案。开发者在使用百炼服务前，应充分了解各项计费规则，合理规划用量与预算，避免意外费用。

## 计费模式概览

百炼平台的计费主要分为三大类：

- **模型推理（按量付费）**：按输入/输出 Token 数量计费，部分模型实行阶梯计费，单价取决于单次请求的输入 Token 总量。详见[模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)。
- **模型训练**：按训练 Token 计费，费用 =（训练数据 Token 总数 + 混合训练数据 Token 总数）x 循环次数 x 训练单价。
- **模型部署**：支持按调用量计费、按算力使用时长计费、包月预付费三种方式。

详细的训练与部署价格请参考[模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)。

## 新人免费额度

首次开通阿里云百炼时，平台会自动发放各模型的新人专属免费额度，有效期为 30~90 天（2025 年 9 月 8 日后新开通用户为 90 天）。

**适用范围**：仅抵扣华北2（北京）地域、中国内地部署范围下的模型实时推理费用。不支持抵扣 Batch 调用、模型调优、模型部署及自定义模型。

**关键注意事项**：

- 主账号与 RAM 子账号共享免费额度
- 未认证用户额度耗尽后无法继续使用，需完成认证并充值
- 已认证用户额度耗尽后会自动按量扣费，建议开启"免费额度用完即停"功能防止意外费用
- 余量降至 20% 或完全耗尽时，系统会通过短信、站内信、邮件发送通知

更多细节请参考[新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)。

## 模型推理价格

### 文本生成模型（千问系列）

百炼平台提供多层级的千问模型，价格差异明显：

| 模型系列 | 代表模型 | 输入单价（每百万 Token） | 输出单价（每百万 Token） | 新人免费额度 |
|---------|---------|----------------------|----------------------|------------|
| 千问 Max | qwen3.7-max | 12 元 | 36 元 | 100 万 Token |
| 千问 Max | qwen3-max（0~32K） | 2.5 元 | 10 元 | 100 万 Token |
| 千问 Plus | qwen3.7-plus（0~256K） | 2 元 | 8 元 | 100 万 Token |
| 千问 Flash | - | 更低 | 更低 | 有 |
| 千问 Turbo | - | 最低 | 最低 | 有 |

> **注意**：部分模型实行阶梯计费，输入 Token 越多单价越高。例如 qwen3-max 在 0~32K 范围为 2.5 元/百万 Token，32K~128K 范围为 4 元/百万 Token，128K~256K 范围为 7 元/百万 Token。

支持 Batch 调用的模型，其 Batch 价格为实时推理价格的 50%。支持上下文缓存的模型，缓存命中的输入 Token 享有折扣。两者不能同时生效。

### 模型训练价格

训练费用因模型规模不同差异较大：

- **大规模模型**（如 qwen2.5-72b-instruct）：0.15 元/千 Token
- **中等规模**（如 qwen3-32b）：0.04 元/千 Token
- **小规模模型**（如 qwen3-0.6b）：0.003 元/千 Token
- **视觉模型**（如 qwen2.5-vl-72b-instruct）：0.05 元/千 Token
- **图像生成模型**（万相系列）：按训练 Token 总量计费

### 模型部署价格

部署支持三种计费方式：

- **按模型调用量计费**：按实际调用的 Token 数量计费
- **按算力使用时长计费**：按 GPU 卡时计费，最小计费单位 1 秒
- **包月预付费**：按月购买专属算力资源

## 成本优化方案

百炼提供多种成本优化方案，按推荐优先级排列如下，详见[节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)：

### AI 通用型节省计划（推荐）

通过承诺每月消费金额换取阶梯式折扣，最高可享 5.3 折，核心特点：

- **覆盖范围广**：可抵扣阿里直供的全部模型（A/B/C 三类），一次购买跨模型使用
- **承诺周期**：3/6/12/24 个月可选，1000 元起步（以 10 元为单位调整）
- **付费方式**：全预付（最大折扣）或零预付（需联系商务开通）
- **折扣示例**：12 个月全预付、月承诺 10000 元，A 类模型享 8 折

> **注意**：每月承诺额度独立计算，当月未用完自动清零，不可累积到下月。

**抵扣顺序**：免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费。

### 其他模型节省计划

针对特定模型系列的节省计划：

- **大语言模型推理节省计划**：20 元~500000 元多档位，无折扣，适用已上架的 Token 计费文本生成模型
- **千问语音模型节省计划**：20~5000 元五档，最高 8 折，适用于 ASR/TTS 模型
- **向量及排序模型节省计划**：100~10000 元五档，最高 7 折

### 资源包

预先购买具体 Token 数量，用于抵扣特定模型超出免费额度后的实时推理用量。购买后立即生效，无需手动激活。

## 账单查询与费用管理

### 查看费用

- **费用概览**：在百炼控制台的"用量 & 费用 > 费用概览"页面查看总消费、趋势和按模型/API Key 维度的费用明细
- **账单详情**：可按 API Key ID、[业务空间](../concepts/workspace.md) ID、模型名称、输入/输出类型、调用渠道等维度拆分查看

### 分账管理

给[业务空间](../concepts/workspace.md)绑定标签，可按部门或项目归集费用。在标签管理中选择"大模型服务平台百炼:[业务空间](../concepts/workspace.md)"，绑定 Workspace ID 与标签键值对，分账账单 T+1 天后生效。

详细操作步骤请参考[账单查询与成本管理](../../raw/model-user-guide/test-1/bill-query-and-cost-management.md)。

### 欠费处理

账户可用额度 < 0 视为欠费。欠费后各服务的影响：

- 仍有免费额度/节省计划/资源包额度的服务可继续使用
- 已购 Coding Plan 或 Token Plan 的套餐额度独立于账户余额，欠费期间可继续使用
- 以上额度均无的服务将暂停，需结清欠费后恢复

### 停止计费

不再使用时，停止代码中的 API 调用并删除 API Key 即可停止模型推理计费。模型部署需在控制台下线已部署模型。Coding Plan 到期自动停止，中途不支持取消和退款。

## 常见问题

**调用后查不到账单？**
模型推理账单通常 2~10 分钟出账，批量推理/训练/知识库按小时出账，高峰期可能延迟。

**同一模型多行记录？**
同一模型按计费类型（输入/输出 Token、缓存命中等）和调用渠道（API/控制台）分别出账。

**如何避免意外扣费？**
开启"免费额度用完即停"、设置高额消费预警、配置预算管理，并在不使用时删除 API Key。

**按量付费是实时扣款吗？**
不是。阿里云采用"预占+月结"模式，月账期结束后生成最终账单并实际扣款。
