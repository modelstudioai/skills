# test 1

阿里云百炼平台提供完整的[计费](../concepts/billing.md)体系，覆盖模型推理调用、模型训练、模型部署三大场景。平台为新用户提供免费额度，同时支持按量付费、节省计划、资源包等多种付费方式，开发者可根据使用规模灵活选择成本优化方案。本文梳理百炼平台的[计费](../concepts/billing.md)规则、费用管理和成本优化手段。

## [计费](../concepts/billing.md)模式概览

百炼平台的计费分为三大类：

- **模型推理调用**：默认按量计费，按输入/输出 [Token](../concepts/token.md) 分别计价。部分模型支持阶梯计费，单价取决于单次请求的输入 [Token](../concepts/token.md) 总量。详见 [模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)。
- **模型训练**：按训练 [Token](../concepts/token.md) 计费，公式为（训练数据 Token + 混合训练数据 Token）× 循环次数 × 训练单价。图像和视频生成模型的训练费用计算方式有所不同。
- **模型部署**：支持按使用时长计费（预置吞吐）和按模型单元计费两种方式，后者可选后付费（按小时）或预付费（按天/按月）。

详细的训练与部署定价请参考 [模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)。

## 免费额度

首次开通百炼时，平台自动发放新人免费额度，有效期为 30~90 天。

关键规则：

- 仅适用于**华北2（北京）**地域、**中国内地**服务部署范围的模型实时推理
- 不支持抵扣 Batch 调用、模型调优、模型部署、自定义模型
- 主账号与 RAM 子账号共享免费额度
- 全新未认证用户额度耗尽后无法继续调用，需完成认证并充值

可在控制台的**模型用量 > 免费额度**页签查看剩余额度和过期时间。建议开启**免费额度用完即停**功能，防止额度耗尽后自动扣费。详见 [新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)。

> **注意**：自 2025 年 9 月 8 日 11 点起，新开通用户的免费额度有效期调整为 90 天，此前已开通的用户不受影响。

## 模型调用定价要点

### 文本生成模型

以千问系列为例，主要按输入和输出 Token 分别计价：

| 模型 | 输入单价（每百万Token） | 输出单价（每百万Token） | 免费额度 |
|------|------------------------|------------------------|----------|
| qwen3.7-max | 12 元 | 36 元 | 100 万 Token |
| qwen3.7-plus | 2 元 | 8 元（非思考）/ 8 元（思考） | 100 万 Token |
| qwen3-max | 2.5~7 元（阶梯） | 10~28 元（阶梯） | 100 万 Token |
| qwen-plus | 0.8~4.8 元（阶梯） | 2~48 元（阶梯） | 100 万 Token |

**阶梯计费规则**：单价取决于单次请求的输入 Token 总量所在区间，该请求的所有 Token 按对应阶梯统一结算。

**Batch 调用优惠**：支持 Batch 调用的模型，输入和输出 Token 单价均按实时推理价格的 50% 计费。

**上下文缓存折扣**：部分模型支持上下文缓存，仅输入 Token 享有折扣。Batch 调用与上下文缓存不能同时生效。

### 多地域部署

同一模型在不同地域的价格可能不同。华北2（北京）使用人民币定价；新加坡等国际地域按国际价格结算，通常高于国内价格。

## 成本优化方案

### 费用抵扣顺序

**免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费**

### AI 通用型节省计划（推荐）

通过承诺每月消费金额获取阶梯折扣，最高可享 5.3 折。核心优势：

- 覆盖阿里直供的全部模型，无需绑定特定模型
- 承诺金额 1,000 元起，以 10 元为单位调整
- 支持 3/6/12/24 个月购买周期
- 全预付比零预付折扣更大

模型分为 A/B/C 三类，不同类别对应不同折扣档位。C 类（DeepSeek、Kimi、GLM 等）当前无折扣。

> **注意**：节省计划按月独立结算，当月未用完的额度自动清零，不可累积到下一周期。

### 其他节省计划

- **大语言模型推理节省计划**：一次性购买固定金额，无折扣，适合小额场景
- **千问语音模型节省计划**：最高 8 折，适用于 ASR/TTS 场景
- **向量及排序模型节省计划**：最高 7 折
- **万相模型节省计划**：最高 9 折，适用于图像/视频生成

### 资源包

预先购买具体 Token 数量，用于抵扣特定模型超出免费额度后的实时推理用量。购买后立即生效，超出有效期后剩余 Token 作废。适合用量明确且集中在单一模型的场景。

详见 [节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)。

## 账单查询与费用管理

### 查看费用

- **费用概览**：在控制台 **用量 & 费用 > 费用概览** 查看当月总消费，支持按模型或 [API Key](../concepts/api-key.md) 筛选
- **账单详情**：在阿里云费用中心下载明细账单，通过 `实例 ID（出账粒度）` 字段区分模型、调用渠道等信息

### 出账时间

- 大模型推理：分钟级出账（通常 2~10 分钟）
- 批量推理、模型训练、知识库：小时级出账

### 分账管理

给[业务空间](../concepts/workspace.md)绑定标签后，可按部门或项目归集费用。配置完成后分账账单 T+1 天生效。

### 欠费处理

账户可用额度小于 0 时视为欠费。若仍有免费额度、节省计划或资源包余额可继续使用对应服务，否则服务暂停。Token Plan 和 Coding Plan 的套餐额度独立于账户余额，欠费期间可继续使用。

详见 [账单查询与成本管理](../../raw/model-user-guide/test-1/bill-query-and-cost-management.md)。

## 停止计费

- **模型推理**：停止 API 调用，删除不再使用的 [API Key](../concepts/api-key.md)
- **模型训练**：无进行中的训练任务即不产生费用
- **模型部署**：在控制台下线已部署模型；包月预付费需额外退订实例
- **Coding Plan / Token Plan**：关闭自动续费，到期自动停止

## 常见问题

**为什么产生了意外费用？** 检查是否有历史应用开启了 `enable_search`（联网搜索按次计费），或免费额度已耗尽但未开启"用完即停"。

**按量付费是实时扣款吗？** 不是，采用"预占+月结"模式，月账期结束后生成最终账单并扣款。

**如何避免扣费？** 删除不再使用的 [API Key](../concepts/api-key.md)，设置高额消费预警，开启免费额度用完即停功能。
