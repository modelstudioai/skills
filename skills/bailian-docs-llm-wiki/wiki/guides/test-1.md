# test 1

阿里云百炼平台提供多层次的计费体系，涵盖模型推理按量付费、模型训练与部署计费、新人免费额度以及多种成本优化方案（节省计划、资源包）。本文汇总了平台计费相关的核心规则、价格体系和费用管理方式，帮助开发者合理规划用量与成本。

## 计费模式概览

百炼平台的费用主要分为三大类：

- **模型推理（按量付费）**：按输入/输出 Token 数量计费，部分模型实行阶梯计费，单价取决于单次请求的输入 Token 总量。支持 Batch 调用半价、上下文缓存折扣等优惠，详见[模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)。
- **模型训练**：按训练 Token 计费，公式为 `(训练数据 Token 总数 + 混合训练数据 Token 总数) x 循环次数 x 训练单价`，支持文本（千问）、图像（万相）、视频（万相）等模型类型，详见[模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)。
- **[模型部署](../concepts/model-deployment.md)**：支持按使用时长计费（预置吞吐）和按模型单元计费两种方式，预付费/后付费可选。

## 新人免费额度

首次开通百炼时，平台自动发放各模型的免费推理额度，有效期 30~90 天（2025 年 9 月 8 日后开通的用户为 90 天）。免费额度仅限华北2（北京）地域中国内地部署范围的模型，且仅抵扣实时推理费用，不支持 Batch 调用、模型调优和部署场景。主账号与 RAM 子账号共享额度。

关键注意事项：

- 已认证用户额度耗尽后继续调用会直接扣费，建议开启**免费额度用完即停**功能防止意外费用
- 未认证用户额度耗尽后无法继续使用，需完成认证并充值
- 余量降至 20% 或耗尽时系统会发送通知

详细规则参见[新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)。

## 模型推理价格

### 阶梯计费规则

部分模型按单次请求输入 Token 总量分阶梯定价，该请求所有 Token 均按对应阶梯单价结算。例如输入 100K Token 落在 32K~128K 区间，则全量按该档单价计费。

### 主要模型定价示例（华北2北京 / 中国内地，每百万 Token）

| 模型 | 输入单价 | 输出单价 | 免费额度 |
|------|---------|---------|---------|
| qwen3.7-max | 12 元 | 36 元 | 100 万 Token |
| qwen3-max（0~32K） | 2.5 元 | 10 元 | 100 万 Token |
| qwen3.7-plus（0~256K） | 2 元 | 8 元 | 100 万 Token |
| qwen-plus（0~128K） | 0.8 元 | 2 元（非思考）/ 8 元（思考） | 100 万 Token |

> **注意**：不同地域（北京、美国弗吉尼亚、新加坡、德国法兰克福）的定价存在差异，国际地域价格通常高于中国内地。具体价格以控制台为准。

## 模型训练与部署计费

### 训练计费

- **文本模型（千问）**：按训练 Token 计费，价格从 0.003 元/千 Token（Qwen3-0.6B）到 0.15 元/千 Token（Qwen2.5-72B-Instruct）不等
- **图像模型（万相）**：按训练 Token 计费，0.08 元/千 Token
- **视频模型（万相）**：按训练 Token 计费，0.06~0.32 元/千 Token

### 部署计费

部署计费支持两种模式：

1. **预置吞吐**：按 TPM（每分钟 Token 数）和使用时长计费，支持后付费（按小时）和预付费（按天）
2. **模型单元**：按模型单元数量和使用时长计费，支持后付费（按小时）和预付费（包月）

> **注意**：当输入超过最长输入 Token 或超出购买的 TPM 量时，调用将自动切换为按量付费模式，此时 API 返回 Header 包含 `x-dashscope-ptu-overflow:true`。

## 成本优化方案

百炼提供三种成本优化手段，抵扣顺序为：**免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费**。

### AI 通用型节省计划（推荐）

通过承诺每月消费金额换取阶梯折扣，最高 5.3 折，覆盖阿里直供全部模型。核心特点：

- 月承诺金额 1000 元起，承诺周期 3/6/12/24 个月可选
- 支持全预付和零预付（需商务开通）
- 按模型分 A/B/C 三类，折扣不同（C 类如 DeepSeek、Kimi 等三方模型目前无折扣）
- 每月额度独立，未使用部分自动清零，不可累积

详见[节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)。

### 其他模型节省计划

针对特定模型系列的专项节省计划，包括大语言模型、千问语音模型、向量及排序模型三类：

- **大语言模型**：20~500,000 元档位，无折扣，有效期 1 个月~1 年
- **千问语音模型**：20~5,000 元档位，最高 8 折，有效期 6~12 个月
- **向量及排序模型**：100~10,000 元档位，最高 7 折，有效期 3~12 个月

### 资源包

预购固定 Token 数量，仅抵扣特定模型（如 qwen-plus、qwen-max、qwen-turbo）的实时推理用量。购买后立即生效，到期自动作废，未使用部分可按规则申请退款。

## 账单查询与费用管理

### 查询账单

- **费用概览**：在百炼控制台左侧菜单"用量 & 费用"查看总消费金额、订阅购买费用与账单费用的构成
- **账单详情**：在阿里云费用中心按 ApiKeyID、[业务空间](../concepts/workspace.md)、模型名称等维度拆分查看，大模型推理通常 2~10 分钟出账
- **实例 ID 解读**：格式为 `ApiKeyID;业务空间ID;模型名称;输入/输出类型;调用渠道;免费额度用完即停标识`

### 分账管理

通过给[业务空间](../concepts/workspace.md)绑定标签实现按部门/项目归集费用，配置后 T+1 天生效，详见[账单查询与成本管理](../../raw/model-user-guide/test-1/bill-query-and-cost-management.md)。

### 欠费与停止计费

- 账户可用额度小于 0 即为欠费，有免费额度/节省计划/资源包的模型仍可使用，否则服务暂停
- 停止计费需停止 API 调用、下线已部署模型、关闭自动续费等，建议删除不再使用的 API Key 防止意外调用
- 建议设置高额消费预警和账户余额预警，避免欠费停服

## 常见问题

| 问题 | 解答 |
|------|------|
| 免费额度用完会怎样？ | 已认证用户未开启"用完即停"会自动扣费；未认证用户直接停服 |
| 为什么产生了意外费用？ | 常见原因：免费额度已耗尽、Batch 调用不享免费额度、控制台数据有分钟级延迟 |
| 按量付费是实时扣款吗？ | 不是，采用"预占+月结"模式，月初生成最终账单扣款 |
| 如何避免意外扣费？ | 开启"免费额度用完即停"、设置高额消费预警、删除不用的 API Key |
