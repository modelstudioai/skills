# start using

阿里云百炼提供了零代码构建 AI 应用的完整流程，开发者可以在约 5 分钟内完成从创建智能体应用、构建知识库到发布上线的全过程。平台持续迭代应用能力，涵盖智能体应用、工作流应用、知识库、MCP 集成等多个模块。

## 快速上手：零代码构建知识问答应用

大语言模型无法直接回答私有知识领域的问题。通过百炼的智能体应用 + 知识库，可以零代码构建一个具备私有知识问答能力的应用。完整教程参见 [0代码构建私有知识问答应用](../../raw/application-user-guide/start-using/build-knowledge-base-qa-assistant-without-coding.md)。

整个流程分为三步：

### 1. 创建智能体应用（约 1 分钟）

1. 访问应用管理页面，点击 **创建应用** > **智能体应用** > **立即创建**
2. **选择模型**：建议选择 **千问-Max**（使用大模型会产生计费，百炼提供限时免费额度）
3. **设计 Prompt**：编写 System Prompt 定义应用的角色和任务
4. **配置欢迎语和预设问题**：设置引导性的对话开场白

> **注意**：在未配置知识库时，模型对私有领域问题的回答可能不准确甚至产生幻觉。

### 2. 构建知识库（约 3 分钟）

1. 在数据连接页面创建文件类型连接器，上传知识文档
2. 进入知识库页面，创建标准版知识库
3. 选择数据类目并使用 **智能切分** 策略完成创建

智能切分为系统预置策略，经评测对多数文档可获得最佳检索效果。

### 3. 关联知识库并发布（约 1 分钟）

1. 在应用配置界面，通过 **技能** > **知识库** 添加已创建的知识库
2. 测试验证后点击 **发布**

## 应用类型

百炼支持多种应用类型，开发者可根据场景选择：

- **智能体应用**：支持知识库、MCP 工具、长期记忆、Prompt 模板等能力。2025 年 12 月上线 Agent 2.0，将知识库和 MCP 统一为工具，由智能体自主规划调用顺序
- **工作流应用**：支持可视化节点编排，适用于复杂任务流程。支持大模型节点、知识库节点、多模态生成节点、批量节点等
- **高代码应用**：基于 Python 项目结构部署 AI 后端服务，内置自动化运维和可观测性

## 支持的模型

根据 [应用功能动态](../../raw/application-user-guide/start-using/application-release-notes.md)，智能体应用和工作流应用已陆续支持以下模型系列：

- **通义千问系列**：千问-Max、千问-Plus、千问-Turbo 等
- **QwQ 系列**：具备强推理能力，支持思考过程输出（qwq-plus、qwq-32b）
- **Qwen-VL 系列**：多模态视觉语言模型（qwen-vl-plus-latest 等），支持图像和视频理解
- **DeepSeek 系列**：可结合知识库和长期记忆构建问答应用

## 知识库能力

知识库是百炼应用的核心组件之一，近期功能演进包括：

- **数据源**：支持本地文件、OSS、DMS、云数据库 RDS、自建 MySQL 等多种数据源
- **文件格式**：支持文档（docx/pdf/md/txt/ppt/html）、Excel、图片、音视频
- **Embedding 模型**：已升级至 text-embedding-v4，支持更多语种和代码片段向量化
- **检索增强**：支持图文检索、多模态回复增强、知识库权重设置、检索参数调优
- **计费**：2026 年 1 月 4 日起正式商业化计费，提供按量付费和资源包两种方式

> **注意**：知识库已于 2026 年 1 月正式商业化计费，使用前请了解 [应用功能动态](../../raw/application-user-guide/start-using/application-release-notes.md) 中的计费说明。

## API 调用与集成

- **Responses API**：支持同步和异步两种调用方式，兼容 OpenAI 代码库
- **工作流异步模式**：系统立即返回 Task ID，可通过任务中心查询结果
- **MCP 集成**：支持官方预置 MCP 服务和自定义 MCP 服务，可一键配置到第三方应用
- **应用分享**：支持 Web（PC/H5）、钉钉 AI 机器人、微信公众号 AI 机器人等渠道
