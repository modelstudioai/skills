# start using

阿里云百炼平台支持零代码构建智能体应用，结合知识库实现私有领域的问答能力。本页面汇总了快速入门的核心流程和平台最新功能动态，帮助开发者快速上手并了解可用能力的演进。

## 核心流程概览

根据 [0代码构建私有知识问答应用](../../raw/application-user-guide/start-using/build-knowledge-base-qa-assistant-without-coding.md) 的指引，构建一个带有私有知识库的问答应用主要分为三步：

1. **创建智能体应用**（约 1 分钟）：在应用管理页面创建空白应用，选择模型（推荐千问-Max），配置 System Prompt、欢迎语和预设问题。
2. **构建知识库**（约 3 分钟）：通过数据连接器上传知识文档，创建知识库并选择切分策略（推荐"智能切分"）。
3. **关联知识库并发布**（约 1 分钟）：在应用配置中添加知识库技能，测试验证后发布。

## 支持的模型与功能

平台持续扩展模型和功能支持，以下为关键能力（详见 [应用功能动态](../../raw/application-user-guide/start-using/application-release-notes.md)）：

| 功能模块 | 关键能力 |
|---------|---------|
| 智能体应用 | 支持千问系列、QwQ 系列、DeepSeek 系列模型；支持知识库、MCP 工具、长期记忆、文件问答、音视频实时互动 |
| 工作流应用 | 支持多模态生成节点、批量节点、异步运行模式；支持 Dify 工作流导入 |
| 知识库 | 支持文档/音视频/结构化数据；支持 text-embedding-v4 模型；支持图文检索、权重设置 |
| MCP | MCP 市场、自定义 MCP 服务、外部调用集成 |

## 关键参数与配置

### 应用配置

- **模型选择**：建议使用千问-Max 或根据场景选择 QwQ（推理场景）、qwen-vl（多模态场景）等
- **Prompt 设计**：通过 System Prompt 定义角色和任务边界
- **知识库检索配置**：支持设置回答范围、是否展示来源、多模态回复增强、初步召回 TopK 等参数

### 知识库配置

- **切分策略**：推荐使用"智能切分"（系统预置，适用于多数文档）
- **Embedding 模型**：支持 text-embedding-v4（推荐）、v3、v2
- **数据源**：文件上传、OSS、DMS、自建 MySQL、云数据库 RDS
- **文件格式**：docx、pdf、Excel、HTML、图片、音视频

## 使用方式

### 控制台零代码方式

适合快速验证和非技术用户，按照 [0代码构建私有知识问答应用](../../raw/application-user-guide/start-using/build-knowledge-base-qa-assistant-without-coding.md) 的步骤即可在约 5 分钟内完成搭建。

### API 调用方式

- **智能体应用调用**：支持同步/异步模式，兼容 OpenAI Responses API 格式
- **工作流应用调用**：支持文本生成模式下的异步运行，通过 Task ID 查询结果
- **知识库 API**：支持通过 API 创建知识库（含音视频类型）、更新配置、获取监控数据

## 计费注意事项

- **模型调用**：使用大模型会产生费用，平台提供限时免费额度，可在模型广场查询
- **知识库**：自 2026 年 1 月 4 日起正式商业化计费，费用由规格费用和模型调用费用构成，支持按量付费和资源包两种方式

> **注意**：知识库计费已正式启动，建议通过降低初步向量检索 TopK 和关键词检索 TopK 来控制成本。

## 限制和注意事项

- 文档解析时间与文件大小相关，通常需要 1-6 分钟
- 知识库创建后解析内容通常需要 1-2 分钟
- QwQ 系列模型在智能体应用中不支持插件、流程和音视频交互能力
- 新版智能体应用（Agent 2.0，2025年12月上线）将知识库和 MCP 统一为工具，由智能体自主规划调用
- 智能体编排应用已于 2025 年 8 月下线，功能由工作流应用承接
