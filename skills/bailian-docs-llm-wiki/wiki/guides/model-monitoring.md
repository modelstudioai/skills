# model monitoring

阿里云百炼提供模型用量查看与模型监控两大能力，帮助开发者全面掌握模型调用的成本、性能和稳定性。通过[模型用量](../../raw/model-user-guide/model-monitoring/model-usage-statistics.md)功能可查看各模型的 Token 消耗和费用概览，而[模型监控](../../raw/model-user-guide/model-monitoring/model-telemetry.md)则提供调用记录查看、性能指标监控、告警配置以及历史对话日志等深度运维能力。两者结合使用，可实现从成本管控到故障排查的完整可观测闭环。

## 支持的模型

- **用量查看**：模型列表中的所有模型均支持查看用量，包括基于它们调优后的自定义模型。
- **普通监控**：支持模型列表中的所有模型及调优后的自定义模型。
- **高级监控**：支持北京、新加坡、弗吉尼亚地域下的所有模型。
- **告警功能**：支持北京、新加坡地域下的所有模型。
- **日志功能**：目前仅支持北京和新加坡地域的部分模型（如 qwen3-max、qwen-plus、qwen-flash、deepseek-v3 系列等）。

## 查看模型用量

在控制台的模型用量页面，可按业务空间维度查看各模型的调用用量。数据延迟约 1 小时，支持最近 30 天的统计数据。

- 按模型类型（大语言模型、视觉模型、语音模型等）页签查看。
- 大语言模型页签支持按推理类型（实时推理/批量推理）筛选。
- 可通过搜索框按模型名称（如 `qwen-plus`）筛选特定模型数据。
- 如需查看 30 天以前的数据，请通过阿里云费用与成本页面查询。

### 用量统计单位

不同类型模型的计量单位不同，详见[模型用量](../../raw/model-user-guide/model-monitoring/model-usage-statistics.md)：

| 模型类型 | 统计单位 | 计费说明 |
|---------|---------|---------|
| 大语言模型（文本生成/深度思考/视觉理解） | Token | 按输入和输出 Token 数计费 |
| 图像生成 | 张 | 按成功生成的图像张数计费 |
| 视频生成 | 秒 | 按成功生成的视频秒数计费 |
| 语音模型 | 秒/字符/Token | 视模型而定 |
| 全模态模型 | Token | 文本按 Token 数，其他模态按对应 Token 数计费 |
| 向量模型 | Token | 按输入文本的 Token 数计费 |

> **注意**：Token 的估算经验为 1 个汉字约 1.5-2 个 Token，1 个英文单词约 1.3 个 Token。每个模型有最大输入和输出 Token 数限制，超过限制会导致请求失败。

## 免费额度管理

在控制台免费额度页面可查看各模型的免费额度使用情况，并可配置**免费额度用完即停**开关。开启后，免费额度用尽时服务将自动停止（返回 403 错误），避免产生额外费用。

## 监控模型运行

系统自动采集主账号下所有业务空间的模型调用数据，并同步至模型监控列表。监控数据看板汇总展示模型总量、总调用次数、总失败次数、平均调用时长和平均首包时长。

针对每个模型，可查询以下 4 类监控指标：

- **安全**：内容安全错误次数等。
- **成本**：平均单次请求调用量等。
- **性能**：调用时长、首 Token 延时、RPM、TPM 等。
- **错误**：失败次数、失败率、限流错误次数等。

支持按 API Key、推理类型、时间范围和时间精度（按分钟/按小时）进行筛选。

### 普通监控 vs 高级监控

| 对比项 | 普通监控（默认） | 高级监控（需手动开启） |
|-------|---------------|-------------------|
| 数据延时 | 小时级 | 分钟级 |
| 查看失败调用详情 | 不支持 | 支持 |
| 作用范围 | 主账号下所有业务空间 | 仅在开启的业务空间内生效 |
| 计费 | 免费 | 收费（云监控 CMS 费用） |

## 查看 Token 消耗

模型监控提供三个层次的 Token 消耗管理：

1. **汇总**：在模型详情页的调用统计页签查看最近 30 天的 Token 消耗。
2. **单次追踪**：开通推理日志后，可在日志页签查看每次调用的 Token 消耗（目前仅支持北京地域部分模型）。
3. **异常告警**：设置 Token 消耗阈值，出现异常时系统立即通知。

## 查看历史对话（模型日志）

开通推理日志后，可在模型监控的日志页签查看每次调用的输入和输出，用于故障排查和内容审计。开通步骤：

1. 在模型监控页面点击**模型监控配置**，依次开通审计日志和推理日志。
2. 在模型监控列表中找到目标模型，点击**日志**查看调用记录。

> **注意**：该功能目前仅适用于华北2（北京）地域的部分模型，日志记录存在分钟级延迟。

## 建立主动告警

模型监控支持对成本、失败率、响应延迟等指标设置告警规则。配置步骤：

1. 在模型监控配置中开启高级监控（性能和用量指标监控）。
2. 在模型告警页面创建告警规则，选择要监控的模型和监控模板。

通知方式支持短信、电子邮件、电话、钉钉群机器人、企业微信机器人及 Webhook。告警等级分为普通（INFO）、警告（WARNING）、错误（ERROR）和紧急（CRITICAL），不同等级对应不同通知渠道。

## 接入 Grafana 与自建应用

开启高级监控后，监控指标数据存储在私有 Prometheus 实例中，支持标准 Prometheus HTTP API。可通过以下方式接入外部系统：

- **Grafana**：在 Grafana 中添加 Prometheus 类型数据源，填入 HTTP API 地址并配置 Basic Auth（AccessKey/AccessKeySecret）。
- **自建应用**：直接调用 Prometheus HTTP API 查询指标数据。

可用的监控指标包括：`model_call_count`（调用次数）、`model_call_duration`（调用时长）、`model_first_token_duration`（首包时长）、`model_usage`（用量）等，支持按 `workspace_id`、`model`、`apikey_id`、`protocol` 等维度筛选。

## 生产环境最佳实践

- **控制输出长度**：合理设置 `max_tokens` 参数和限制思考长度以控制费用。
- **按任务选模型**：简单任务优先选择轻量级模型。
- **监控与告警**：通过[模型监控](../../raw/model-user-guide/model-monitoring/model-telemetry.md)跟踪用量趋势并配置告警。
- **优化 Prompt**：简洁清晰的 Prompt 可减少输入 Token 消耗。
- **使用批量推理**：大批量非实时任务使用批量推理更具成本优势。

## 限制和注意事项

- 模型用量数据按业务空间维度统计，不支持按阿里云账号维度统计（可通过账单详情页面导出按账号汇总的数据）。
- 普通监控和高级监控的数据默认保留 30 天。
- 每个业务空间最多可创建 100 个告警模板。
- 高级监控和推理日志会产生额外的云监控 CMS 和日志服务 SLS 费用。
- 默认业务空间成员可查看所有业务空间数据；子业务空间成员仅能查看当前空间数据。
