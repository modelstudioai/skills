# model monitoring

百炼平台的 model monitoring 是面向生产环境的模型可观测性能力，提供分钟级延迟的调用统计、性能指标、审计日志及告警配置，帮助开发者实时掌握模型健康度、排查异常并控制成本。监控数据按业务空间隔离，不作为计费依据；用量与费用核对请以[模型用量](../../raw/model-user-guide/model-monitoring/model-usage-statistics.md)和账单为准。核心能力覆盖调用规模、失败分析、延迟诊断、安全拦截与限流识别等场景。

## 支持的模型/功能

- **支持范围**：全部在模型列表中可见的官方模型（含文本、视觉、语音、全模态、向量模型）及其[调优后的模型](../../raw/model-user-guide/model-high-speed-inference/model-deployment-index/model-deployment-introduction.md)，但语音、图片、视频生成及三方直连等部分模型**不支持监控告警**（具体以控制台实际可选模型为准）。
- **核心功能模块**：
  - **监控概览与详情**：查看整体调用次数、失败率、首 [Token](../concepts/token.md) 延时、调用时长等指标趋势；
  - **审计日志**：默认开启，记录 Request ID、模型、[Token](../concepts/token.md) 用量、状态码、延迟等元信息（不含 Prompt/Response）；
  - **推理日志**：需手动开启，记录完整 Prompt/Response 与中间步骤，仅支持北京和新加坡地域；
  - **告警配置**：支持为关键指标（如失败次数、失败率、Total[Token](../concepts/token.md) 数、限流错误次数等）设置阈值告警；
  - **数据投递**：可将监控指标投递至云监控 Prometheus 实例，日志投递至 SLS 日志库（用于长期留存或对接自有运维系统）。

> **注意**：文档 1 中“失败次数、失败率、限流错误次数已移至[模型监控](../../raw/model-user-guide/model-monitoring/model-telemetry.md)页面”与文档 2 的实际功能定位一致，但文档 1 的标题“模型用量”易引发歧义；实际生产中应以[监控告警](../../raw/model-user-guide/model-monitoring/model-telemetry.md)文档为准进行异常排查。

## 关键参数

| 参数名 | 含义 | 是否支持告警 | 说明 |
|--------|------|----------------|------|
| `调用次数` | 模型被成功/失败调用的总次数 | ✅ | 包含预置吞吐单元、独占吞吐单元等调用 |
| `失败次数` / `失败率` | 调用失败次数及失败占比（失败次数 ÷ 总次数） | ✅ | 排查突增首选指标；失败率告警模板已预置（如“1分钟占比大于1%”） |
| `模型消耗 TotalToken 数` | 按模型维度统计的 Token 消耗总量 | ✅ | **推荐用于成本告警**，预置模板支持“1分钟总和大于10000” |
| `首 Token 延时` | 请求发起到返回首个 Token 的耗时 | ✅ | 衡量模型响应启动性能，预置模板支持“1分钟均值大于10秒” |
| `调用时长` | 完整请求-响应耗时 | ✅ | 综合性能指标，预置模板支持“1分钟均值大于60秒” |
| `限流错误次数`（429） | 触发限流的次数 | ✅ | 直接关联配额瓶颈，预置模板覆盖“1分钟总和大于10”等场景 |
| `内容安全错误次数` | 内容安全拦截次数 | ❌ | 仅展示，不可配置告警（见[监控告警](../../raw/model-user-guide/model-monitoring/model-telemetry.md)指标表说明） |
| `非首 Token 延时` | 首 Token 后每 Token 平均生成耗时 | ❌ | 不支持告警，仅作性能分析参考 |

## 使用方式

1. **访问入口**：登录百炼控制台 → 左侧导航栏 **运维管理 > 模型监控**（[直达链接](https://bailian.console.aliyun.com/cn-beijing/model/telemetry)）。
2. **快速排查**：
   - 在**概览页**查看整体调用规模与健康度（总调用、失败次数、平均首包时长等）；
   - 在**模型列表**点击目标模型的 **查看详情** 进入监控详情页，结合时间/推理类型/API-Key 筛选，定位异常时段；
   - 点击 **查看日志** 进入审计日志页签，通过 Request ID 或状态码（如 `429`, `500`）筛选失败请求。
3. **配置告警**：
   - 在监控详情页图表上点击 **告警铃铛图标**，快速为当前模型+指标创建规则；
   - 或进入 [模型告警页面](https://bailian.console.aliyun.com/cn-beijing/model/alert) → **告警规则** 页签，使用预置模板（如“模型调用失败占比1分钟总和大于1%”）创建；
   - 创建前需先完成[监控数据投递](../../raw/model-user-guide/model-monitoring/model-telemetry.md)中的云监控服务角色授权。
4. **开启推理日志**：
   - 在日志页面切换至 **推理日志** 页签 → 点击 **开始配置**；
   - 需先完成日志投递授权（SLS 角色 + 日志库），且仅北京/新加坡地域可用。

## 限制和注意事项

- **数据延迟与范围**：监控数据分钟级更新，但**不作为计费依据**；用量核对请参考[模型用量](../../raw/model-user-guide/model-monitoring/model-usage-statistics.md)页面（Token/费用延迟约10分钟）及账单中心。
- **地域限制**：美国（弗吉尼亚）地域**不展示调用次数**；推理日志**仅支持北京和新加坡地域**。
- **告警能力限制**：
  - 仅特定指标支持告警（详见[监控告警](../../raw/model-user-guide/model-monitoring/model-telemetry.md)指标表），如 `RPM`、`TPM`、`内容安全错误次数` 等不可配置；
  - 告警检查周期最小为 60 秒（设为 0 表示触发即告警，但不推荐）；
  - 告警规则依赖云监控服务角色授权，未授权时按钮禁用。
- **日志限制**：
  - 审计日志默认开启，保留最近 30 天；
  - 推理日志 Prompt/Response 截断上限为 128KB，超长内容不可见；
  - 关闭审计日志投递将**自动关闭推理日志投递**，且关闭期间日志无法补录。
- **用量统计差异**：  
  > **注意**：文档 1 明确说明“调用次数包含预置吞吐单元、独占吞吐单元等调用”，而文档 2 的监控指标未区分调用来源类型；实际使用中，若需精确归因（如区分 API 调用 vs 批量推理），应在[模型用量](../../raw/model-user-guide/model-monitoring/model-usage-statistics.md)页面按“推理类型”筛选，而非仅依赖监控详情页。
