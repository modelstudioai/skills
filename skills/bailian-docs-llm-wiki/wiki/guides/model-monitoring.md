# model monitoring

百炼平台的模型监控（Model Monitoring）是一套面向生产环境的可观测性能力，提供分钟级延迟的调用统计、性能指标、失败分析与告警能力，帮助开发者实时掌握模型服务健康度、排查异常并控制成本。监控数据按业务空间隔离，不作为计费依据；用量统计与费用核对请参考[模型用量](../../raw/model-user-guide/model-monitoring/model-usage-statistics.md)文档。核心能力覆盖调用规模、质量、性能三大维度，并支持审计日志与可选的推理日志。

## 支持的模型与功能

- **适用模型范围**：绝大多数百炼内置模型均支持监控，但语音、图片、视频生成及三方直连等部分模型不支持（具体以控制台实际展示为准）[原文标题](../../raw/model-user-guide/model-monitoring/model-telemetry.md)。  
- **核心功能模块**：
  - **调用统计**：调用次数、失败次数、失败率、限流错误次数（429）、内容安全拦截次数等；
  - **性能指标**：调用时长、首 Token 延时、非首 Token 延时、TPS、缓存命中率等；
  - **用量指标**：Token 总量、模型消耗 TotalToken 数、平均单次请求调用量等；
  - **日志能力**：默认开启审计日志（含 Request ID、状态码、延迟、用量等，不含 Prompt/Response）；推理日志需手动开启，记录完整 Prompt/Response（仅北京、新加坡地域支持）[原文标题](../../raw/model-user-guide/model-monitoring/model-telemetry.md)；
  - **告警与投递**：支持基于关键指标配置告警规则，并可将监控数据投递至云监控 Prometheus 实例、日志投递至 SLS 日志库。

> **注意**：文档 1 中提到“失败次数、失败率、限流错误次数和内容安全拦截次数已移至[模型监控](raw/model-user-guide/model-monitoring/model-telemetry.md)页面”，而文档 2 明确这些指标在监控详情页中持续提供且支持告警；二者一致，无矛盾。但文档 1 的“模型用量”页面已**不再展示**上述失败类指标——该信息为准确状态说明，非过时内容。

## 关键参数与指标

| 指标名称 | 含义 | 是否支持告警 | 说明 |
|----------|------|----------------|------|
| 调用次数 | 模型被调用的总次数 | ✅ | 包含预置/独占吞吐单元调用；批量离线/在线推理不展示调用次数 [原文标题](../../raw/model-user-guide/model-monitoring/model-usage-statistics.md) |
| 失败次数 / 失败率 | 失败调用数 / 占比 | ✅ | 排查突增需重点关注；失败率告警推荐阈值 ≥1% |
| 限流错误次数（429） | 触发配额限流的次数 | ✅ | 直接反映资源瓶颈，建议配置告警 |
| 首 Token 延时 | 请求到首个 Token 返回的耗时 | ✅ | 关键用户体验指标，预置模板阈值 ≥10 秒 |
| 模型消耗 TotalToken 数 | 按模型维度聚合的 Token 消耗总量 | ✅ | **控制 Token 成本的核心告警指标**，预置模板阈值 ≥10000/分钟 |
| 内容安全错误次数 | 内容安全拦截次数 | ❌ | 仅用于排查，不支持告警配置 |
| 缓存命中率 | 缓存命中 Token 数 / 输入 Token 数 | ❌ | 用于评估缓存策略有效性 |

## 使用方式

1. **访问入口**：登录百炼控制台 → 左侧导航栏 **运维管理 > 模型监控**（概览页）[原文标题](../../raw/model-user-guide/model-monitoring/model-telemetry.md)；或直接访问 `https://bailian.console.aliyun.com/cn-beijing/model/telemetry`。
2. **筛选与查看**：
   - 按时间（支持分钟级精度）、推理类型（在线/批量离线/批量在线）、API Key 筛选；
   - 在模型列表点击 **查看详情** 进入单模型监控详情页（含图表+告警铃铛）；
   - 点击 **查看日志** 进入审计日志页签（默认开启），或切换至推理日志页签（需先完成日志投递配置）。
3. **配置告警**：
   - 在监控详情页图表上点击告警铃铛图标，快速为当前指标创建规则；
   - 或前往 **运维管理 > 模型告警**（`https://bailian.console.aliyun.com/cn-beijing/model/alert`）进行全量规则管理；
   - **前提**：必须先在监控投递中授权云监控服务角色（否则“创建告警规则”按钮不可用）。
4. **开启日志投递**（可选）：
   - 审计日志投递：在日志页面右上角点击 **日志投递配置** → 授权日志服务角色 + 创建 SLS 日志库；
   - 推理日志投递：**必须先开启审计日志投递**，再于推理日志页签点击 **开始配置**；
   - 投递后日志将写入自有 SLS 日志库，可用于长期留存或对接自有运维系统。

## 限制和注意事项

- **数据时效性**：监控数据延迟约 1 分钟（调用次数）至数分钟（用量类指标），**不作为计费依据**；计费以账单为准 [原文标题](../../raw/model-user-guide/model-monitoring/model-telemetry.md)。
- **地域与时间限制**：
  - 模型用量数据仅支持查询 **2026 年 9 月及之后**的数据（美国弗吉尼亚地域为 2026 年 10 月起）[原文标题](../../raw/model-user-guide/model-monitoring/model-usage-statistics.md)；
  - 推理日志仅支持 **北京、新加坡地域**，其他地域暂不支持。
- **权限与隔离**：所有监控数据按**业务空间**维度隔离，不支持跨空间或按阿里云账号维度汇总。
- **告警限制**：
  - 仅表中明确标注 ✅ 的指标支持告警配置；
  - 告警检查周期最小为 60 秒（0 表示“触发即告警”，但平台实际限制为 ≥60 秒）；
  - 预置告警模板不可编辑，但可复制后自定义。
- **投递风险**：
  - 关闭审计日志投递将**自动关闭推理日志投递**，且关闭期间日志**无法补录**；
  - 不要删除百炼自动创建的 SLS 日志库，否则导致投递失败；
  - 在 SLS 中修改索引会导致查询失败。
- **用量优化提示**：为控制成本，建议结合[模型用量](../../raw/model-user-guide/model-monitoring/model-usage-statistics.md)页面的“控制模型输出长度”“根据任务类型选择模型”等实践，配合 TotalToken 数告警实现主动治理。
