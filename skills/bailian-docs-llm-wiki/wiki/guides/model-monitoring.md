# model monitoring

阿里云百炼提供模型监控与用量统计功能，帮助开发者追踪模型调用情况、管理成本并及时发现异常。监控覆盖调用记录、性能指标（延时/RPM/TPM）、Token 消耗统计及告警，用量统计则提供免费额度管理和历史用量查询。两项功能结合使用，可实现对模型服务的全方位可观测性。

## 支持范围

**模型用量统计**支持[模型列表](../../raw/model-user-guide/model-monitoring/model-usage-statistics.md)中的所有模型，包括基于其调优后的自定义模型。数据按[业务空间](../concepts/workspace.md)维度统计，延迟约 1 小时。

**模型监控**的覆盖范围因功能而异：

| 功能 | 支持范围 |
|------|----------|
| 普通监控 | 模型列表中的所有模型（含调优后的自定义模型） |
| 高级监控 | 北京、新加坡、弗吉尼亚地域下的所有模型 |
| 告警 | 北京、新加坡地域下的所有模型 |
| 日志 | 仅北京和新加坡地域的部分模型（qwen 系列、deepseek 系列等） |

## 用量统计

### 免费额度管理

在控制台的「模型用量：免费额度」页面可查看各模型的免费额度使用情况，并可通过**免费额度用完即停**开关控制超额行为：

- **开启**：免费额度用尽后服务自动停止（返回 403 错误 `AllocationQuota.FreeTierOnly`），避免产生额外费用。
- **关闭**：免费额度用尽后继续服务，按实际用量付费。

> **注意**：只有在账户内仍有未消耗的免费额度时才能开启此功能；开启后需在免费额度完全消耗后才能关闭。

### 用量统计单位

不同模型类型的计费单位不同，详见[模型用量](../../raw/model-user-guide/model-monitoring/model-usage-statistics.md)原文：

| 模型类型 | 统计单位 |
|----------|----------|
| 大语言模型（文本生成/深度思考/视觉理解） | Token |
| 图像生成 | 张 |
| 视频生成 | 秒 |
| 语音模型 | 秒、字符或 Token（视模型而定） |
| 全模态模型 | Token（文本及其他模态均折算为 Token） |
| 向量模型 | Token |

### 查看用量

- **近 30 天用量**：在「模型用量：用量统计」页面按模型类型和时间范围查询，支持按模型名称搜索。
- **30 天以前**：通过阿里云「费用与成本」页面导出账单查询。
- **按账号维度汇总**：用量统计页面仅支持按[业务空间](../concepts/workspace.md)维度，如需按账号汇总，需导出账单详情。

## 监控指标

系统自动采集主账号下所有[业务空间](../concepts/workspace.md)的模型调用数据。监控指标分为四类：

- **安全**：内容安全错误次数等
- **成本**：平均单次请求调用量、Token 消耗等
- **性能**：调用时长、首 Token 延时、RPM、TPM 等
- **错误**：失败次数、失败率、限流错误次数等

高级监控开启后可获得分钟级数据洞察（普通监控为小时级延迟），并支持通过 Prometheus HTTP API 获取所有指标数据。可用的指标包括 `model_call_count`、`model_call_duration`（含 p50/p99）、`model_first_token_duration`（含 p50/p99）、`model_usage` 等。

## 模型日志

> **注意**：日志功能目前仅适用于华北2（北京）地域的部分模型。

开通步骤：

1. 使用主账号或有权限的子账号登录，在模型监控页面点击「模型监控配置」。
2. 按指引依次开通审计日志和推理日志。
3. 开通后系统自动记录每次模型调用的输入与输出（存在分钟级延迟）。

日志页面展示每次调用的请求和响应内容、Token 消耗等信息，可用于故障排查和内容审计。如需停止记录，在模型监控配置中关闭推理日志即可。

## 告警配置

告警功能支持对监控指标设置阈值，当出现异常时自动通知团队。详细配置方式参见[模型监控](../../raw/model-user-guide/model-monitoring/model-telemetry.md)原文。

**配置步骤**：

1. 开启高级监控（在模型监控配置中手动开启「性能和用量指标监控」）。
2. 在模型告警页面创建告警规则，选择目标模型和监控模板。

**通知方式**：短信、邮件、电话、钉钉群机器人、企业微信机器人、Webhook。

**告警等级与通知渠道**：

| 等级 | 通知渠道 |
|------|----------|
| 紧急（CRITICAL） | 电话、短信、邮件 |
| 错误（ERROR） | 短信、邮件 |
| 警告（WARNING） | 短信、邮件 |
| 普通（INFO） | 邮件 |

## 接入 Grafana 与自建应用

高级监控的数据存储在私有 Prometheus 实例中，支持标准 Prometheus HTTP API。接入步骤：

1. 在模型监控配置中获取 HTTP API 地址（区分公网/VPC 访问）。
2. 使用 `Authorization: Basic base64Encode(AccessKey:AccessKeySecret)` 进行鉴权。
3. 通过 `query_range` 接口查询指标，支持按 `workspace_id`、`model`、`apikey_id`、`protocol` 等维度筛选。

## 生产环境建议

- **控制输出长度**：通过 `max_tokens` 参数限制单次生成长度，控制费用。
- **按任务选模型**：简单任务优先选用轻量级模型以降低成本。
- **监控与告警**：配置模型监控告警，及时发现用量异常。
- **优化 Prompt**：简洁清晰的 Prompt 可减少不必要的 Token 消耗。
- **使用批量推理**：非实时大批量任务使用批量推理通常更具成本优势。
