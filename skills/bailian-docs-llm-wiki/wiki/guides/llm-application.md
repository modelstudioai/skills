# llm application

阿里云百炼平台提供三种核心应用构建模式来突破大模型的原生局限：智能体（Agent）、工作流（Workflow）和高代码应用。通过集成知识库检索增强、外部工具调用、记忆等能力，开发者可以快速构建解决真实业务问题的 AI 应用。三种模式分别面向不同开发门槛和使用场景，从零代码到专业编码均有覆盖。

## 应用类型与选型

百炼平台的三种应用类型各有侧重，选型时可参考 [应用类型介绍](../../raw/application-user-guide/llm-application/application-introduction.md) 中的对比：

| 对比维度 | 智能体（Agent） | 工作流（Workflow） | 高代码应用 |
|---------|---------------|-------------------|-----------|
| 开发方式 | 自然语言配置（零代码） | 可视化节点编排（低代码） | Python 编码（专业代码） |
| 核心特点 | AI 自主决策、动态规划 | 预定义流程精确控制 | 完全由代码控制 |
| 适合人群 | 业务人员、产品经理 | IT 运维、业务分析师 | AI 工程师、开发者 |
| 开发门槛 | 低 | 中 | 高 |

- **智能体**：由提示词驱动，自主理解意图并调用知识库、MCP 等工具完成任务。适合智能客服、知识问答、任务助理等开放式对话场景。
- **工作流**：通过可视化节点编排，将多步骤任务串联成稳定可控的执行链路。适合报告生成、订单处理、审批流等固定流程自动化。
- **高代码应用**：基于 Python 项目结构部署 AI 后端服务，支持 Serverless Function 和 K8s 两种部署方式。适合私有算法部署、复杂系统集成。

## 智能体应用

### 新版智能体（Agent 2.0）

新版智能体将知识库、MCP 等能力统一为工具，由模型自主规划调用顺序，能完整展示"规划-执行-反思"链路。详细配置方法参见 [新版智能体应用](../../raw/application-user-guide/llm-application/new-single-agent-application.md)。

核心能力配置：

- **模型选择**：推荐千问-Max 系列，支持配置 `temperature`、`enable_thinking`（思考模式）、最长回复长度等参数。
- **系统提示词**：定义角色、行为指令与能力边界，支持嵌入自定义变量。
- **知识库**：作为工具由智能体自主调用，支持通过标签限定查询范围以提升检索精度。
- **MCP**：外部工具均以 MCP 协议接入，支持官方 MCP 和自定义 MCP 服务，插件可一键转换为 MCP。
- **应用组件**：可将已发布的智能体或工作流作为工具接入。
- **记忆**：支持短期记忆（0-30 轮上下文），长期记忆计划未来支持。
- **ReAct 最大轮次**：限制单次会话工具调用次数（1-50），超出后自动生成最终回复。

> **注意**：旧版智能体（Agent 1.0）和新版智能体基于不同技术架构，无法直接升级或切换。如需使用新版功能，需重新创建应用。

### 旧版智能体（Agent 1.0）

旧版智能体采用"先检索知识库、再决策是否调用其他工具"的固定流程，适用于意图单一的简单任务。核心能力包括知识库（RAG）和插件调用。详见 [智能体应用](../../raw/application-user-guide/llm-application/single-agent-application.md)。

### 文件问答

智能体应用支持上传文件进行智能问答，提供三种处理模式：

- **全文引用**：将文件内容整体提供给模型，适合文档总结、全文翻译。受限于模型上下文长度。
- **切片检索（RAG）**：将文件切分为片段并检索最相关内容，适合长文档问答。
- **自定义处理**：将文件信息传给模型，由模型调用外部工具处理，适合图片转换、视频分析等。

支持的文件格式包括文档（`.doc`/`.docx`/`.pdf`/`.md` 等）、图片（`.png`/`.jpg` 等）、视频和音频。单会话最多上传 10 个文件，单文件不超过 10MB。超过 10MB 的文件可通过文件上传 API 处理。

> **注意**：通过聊天窗口上传的文件仅在当前会话有效，刷新或关闭页面将导致文件丢失。

## 工作流应用

工作流应用通过可视化节点编排将复杂任务拆分为有序步骤。详细创建方法参见 [工作流应用](../../raw/application-user-guide/llm-application/workflow-application.md)。

### 核心节点类型

- **开始/结束节点**：定义输入输出参数结构，预置 `query`、`historyList`、`imageList` 等变量。
- **大模型节点**：配置模型、提示词和用户提示词，执行 LLM 推理。
- **意图分类节点**：根据用户输入自动分类意图，路由到不同处理分支。
- **智能体群组节点**：编排多个子智能体协同完成复杂任务。
- **变量处理节点**：处理和转换变量数据。

### 会话变量

工作流支持会话变量作为全局变量，在工作流全生命周期内记录参数信息，可在各节点中引用。

### 典型场景

- 诈骗信息识别：大模型节点分析短信内容判断诈骗嫌疑
- 智能导购：意图分类 + 多个大模型节点分别处理不同商品咨询
- 日程管理：智能体群组节点编排信息收集和数据整理两个子智能体

## 高代码应用

高代码应用面向专业开发者，支持基于 Python 项目部署 AI 后端服务。详细开发部署流程参见 [高代码应用](../../raw/application-user-guide/llm-application/rich-code-application.md)。

关键特性：

- **部署方式**：Serverless Function（无状态、低成本）和 K8s（有状态、高性能）两种选择。
- **代码提交**：支持使用预置模板（基础对话 Agent、工具调用 Agent、深度研究 Agent）或上传 `.whl` 代码包。
- **MCP 工具接入**：控制台一站式关联知识库、工作流、插件等 MCP 服务。
- **自定义前端**：支持直接体验、自定义交互卡片、基于 Spark Design 框架的 WebUI。
- **网关**：通过云原生 API 网关配置自定义域名和 Token 鉴权，用于生产环境访问。
- **企业级能力**：自动化运维、可观测、日志服务、API 网关。

## 发布与 API 调用

所有类型的应用都需要先**发布**才能通过 API 调用或集成。发布时会展示自上次发布以来的配置变更差异。

- 智能体应用的 API 调用频率上限为 100 次/分钟（所有请求共享配额）。
- 如果应用由 RAM 账号创建，发布前需确认拥有 `ram:CreateServiceLinkedRole` 权限。
- 自定义插件的超时限制为 5 秒。
- 若应用对外提供服务，需完成应用合规备案。

## 计费说明

- **创建应用**：不收费。
- **模型调用**：按模型类型和 Token 用量计费。
- **知识库**：按量付费，检索到的文本切片会增加模型输入 Token。
- **MCP/插件**：部分官方 MCP 按模型调用计费（如文生图、语音合成），第三方 MCP 服务费用由第三方收取。
- **高代码应用部署**：函数计算、API 网关、存储等资源按阿里云账单计费，时延敏感业务建议最小实例数 >= 1。
- **长期记忆**：数据存储不收费，记忆体内容占用的 Token 暂不计费。

## 支持的模型

智能体应用支持千问系列模型（千问-Max、千问-Plus、千问-Turbo、千问-Long 等）、千问 VL 视觉理解模型、千问-QwQ 推理模型、DeepSeek 模型以及自定义部署模型。具体支持情况以应用内显示为准。
