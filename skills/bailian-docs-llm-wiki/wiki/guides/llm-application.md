# llm application

阿里云百炼提供三种核心应用构建模式——智能体（Agent）、工作流（Workflow）和高代码应用，用于突破大模型在访问私有知识、获取实时信息和处理复杂流程方面的局限。开发者可根据场景复杂度和技术栈选择合适的应用类型，通过集成知识库、MCP 工具、记忆等能力快速构建 AI 应用。

## 应用类型与选型

百炼平台的三种应用类型在开发方式、适用人群和核心能力上各有侧重，详见[应用类型介绍](../../raw/application-user-guide/llm-application/application-introduction.md)。

| 对比维度 | 智能体（Agent） | 工作流（Workflow） | 高代码应用 |
|---------|---------------|-------------------|----------|
| 开发方式 | 自然语言配置（零代码） | 可视化节点编排（低代码） | Python 编码 |
| 核心特点 | AI 自主决策、动态规划 | 预定义流程精确控制 | 完全由代码控制 |
| 适合人群 | 业务人员、产品经理 | IT 运维、业务分析师 | AI 工程师、开发者 |
| 开发门槛 | 低 | 中 | 高 |

**选型建议**：

- 需要模型自主决策和动态调用工具时，选择**智能体**（如智能客服、知识问答、旅行规划）。
- 需要固定流程、可复现执行链路时，选择**工作流**（如自动化报告、订单处理、数据标注）。
- 需要深度定制、部署私有算法或集成复杂系统时，选择**高代码应用**。

## 智能体应用

### 新版与旧版对比

百炼智能体目前存在两个版本，推荐使用新版（Agent 2.0），详见[新版智能体应用](../../raw/application-user-guide/llm-application/new-single-agent-application.md)。

| 对比维度 | 旧版（Agent 1.0） | 新版（Agent 2.0） |
|---------|------------------|------------------|
| 规划与调度 | 知识库检索后再决策是否调用工具 | 知识库、MCP 统一为工具，自主规划调用 |
| 过程透明度 | 仅展示最终结果 | 完整展示"规划-执行-反思"链路 |
| 适用场景 | 意图单一、流程固定的简单任务 | 从简单问答到复杂规划的各类任务 |

> **注意**：旧版与新版基于不同技术架构，不支持直接升级或降级，需重新创建应用。

### 核心能力配置

**模型选择**：支持千问系列模型和自定义部署模型。新版智能体推荐选用具备强工具调用能力的模型（如千问-Max 系列）。可配置的参数包括：

- **最长回复长度**：模型生成的长度限制（不含提示词）
- **temperature**：控制生成随机性，数值越高随机性越强
- **enable_thinking**：是否开启思考模式（仅部分模型支持）

**系统提示词**：定义智能体角色、行为指令和能力边界。支持嵌入自定义变量，在提示词中通过 `/` 引用已配置的变量。

**知识库（RAG）**：连接外部知识库，基于私有数据回答问题。新版智能体中知识库作为工具由智能体自主规划调用，并支持通过标签限定查询范围。

**MCP 工具**：新版智能体中外部工具均以 MCP 协议接入，支持官方 MCP 广场和自定义 MCP 服务。智能体可在多步推理中动态调用 MCP。

**记忆**：短期记忆支持 0-30 轮上下文；长期记忆暂未上线。

**ReAct 最大轮次**：取值 1-50，限制单次会话中工具调用的最大次数。

### 文件问答

智能体支持上传文件进行智能问答，提供三种处理模式，详见[文件问答](../../raw/application-user-guide/llm-application/file-q-a.md)：

- **全文引用**：将文件内容整体提供给模型，适合文档总结、全文翻译。受限于上下文长度。
- **切片检索（RAG）**：将文件切分为片段后检索最相关内容，适合长文档问答。
- **自定义处理**：将文件信息传递给模型，由模型自主调用工具处理，适合图片转换、视频分析等任务。

**文件限制**：单会话最多 10 个文件，单文件不超过 10MB。支持文档（doc/docx/pdf/md/txt 等）、图片（png/jpg 等）、视频（mp4/mkv 等）、音频（mp3/wav 等）格式。通过聊天窗口上传的文件仅在当前会话有效。

## 工作流应用

工作流通过可视化节点编排将复杂任务串联为有序步骤，详见[工作流应用](../../raw/application-user-guide/llm-application/workflow-application.md)。

### 核心节点类型

- **开始/结束节点**：定义输入输出参数，预置 `query`（用户输入）、`historyList`（对话历史）、`imageList`（图片列表）等变量
- **大模型节点**：调用千问等大模型执行推理任务，支持系统提示词和用户提示词配置
- **意图分类节点**：根据用户输入自动分类意图，路由到不同分支
- **智能体群组节点**：将多个已发布的智能体作为子智能体协作完成任务
- **变量处理节点**：处理和格式化中间变量

### 会话变量

会话变量作为全局变量，在工作流全生命周期内记录参数信息，可在各节点中引用。

## 高代码应用

高代码应用面向专业开发者，支持基于 Python 项目结构部署 AI 后端服务，详见[高代码应用](../../raw/application-user-guide/llm-application/rich-code-application.md)。

**部署方式**：

- **Serverless Function**（默认）：适用于低负载、无状态、快速拉起场景，部署花销低
- **K8s**：适用于高性能、有状态、长程任务场景，需开通 ACK 容器服务

**关键能力**：

- 一站式 MCP 工具接入（知识库、工作流、插件等）
- 支持自定义前端 WebUI（基于 Spark Design 框架）
- 集成企业级运维能力（API 网关、日志服务、应用观测）
- 提供预置模板：基础对话 Agent、工具调用 Agent、深度研究 Agent

## 发布与 API 调用

所有应用类型均需**先发布后调用**。发布后可通过 API 集成到现有系统：

- **智能体应用 API**：每个应用默认调用频率上限为 100 次/分钟
- **工作流应用 API**：发布后通过专用 API 调用
- **高代码应用**：支持通过 API 网关配置自定义域名和 Token 鉴权访问

> **注意**：如果应用由 RAM 账号创建，发布前需确认已拥有 `ram:CreateServiceLinkedRole` 权限。

## 计费说明

- **创建应用不收费**，仅在调用时按模型类型和 Token 用量计费
- **知识库**按量付费，检索召回的文本切片会增加模型输入 Token 消耗
- **MCP 工具**：部分官方 MCP 按模型调用计费（如文生图、语音合成），第三方 MCP 费用由第三方收取
- **文件上传**本身不收费，问答消耗按所选模型标准计费
- **高代码应用**部署后函数、网关、存储均会产生费用

## 常见问题

**自定义插件是否有超时限制？** 有，超时限制为 5 秒。

**配置了知识库但回答无关？** 先进行知识库命中测试检查相似度得分，在提示词中明确要求仅基于知识库内容回答，必要时更换模型。

**智能体未按预期调用工具？** 从以下四个层面排查：技能是否正确挂载、系统提示词是否清晰描述了工具功能、用户意图是否明确指向该工具、是否达到 ReAct 轮次上限。
