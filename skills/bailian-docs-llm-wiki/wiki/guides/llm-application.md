# llm application

阿里云百炼提供智能体、工作流和高代码应用三种核心构建模式，结合[知识库](../concepts/knowledge-base.md)检索增强、外部工具调用、记忆等能力，帮助开发者快速构建能够解决真实业务问题的 AI 应用。本文汇总四类应用的能力边界、关键参数、使用方式与[计费](../concepts/billing.md)要点，便于开发者快速选型与集成。

## 应用类型与选型

百炼将应用构建模式分为三类，选型维度见 [应用类型介绍](../../raw/application-user-guide/llm-application/application-introduction.md)：

| 对比维度 | 智能体（Agent） | 工作流（Workflow） | 高代码应用 |
| --- | --- | --- | --- |
| 开发方式 | 自然语言配置（零代码） | 可视化节点编排（低代码） | Python 编码（专业代码） |
| 核心特点 | AI 自主决策、动态规划 | 预定义流程精确控制 | 完全由代码控制 |
| 适合人群 | 业务人员、产品经理、运营 | IT 运维、业务分析师、实施顾问 | AI 工程师、开发者 |
| 开发门槛 | 低 | 中 | 高 |

- **智能体**：由提示词驱动，自主理解用户意图并调用[知识库](../concepts/knowledge-base.md)、MCP 等外部工具。适合智能客服、知识问答、任务助理、旅行规划等开放式对话场景。
- **工作流**：将复杂任务拆分为有序步骤串联成稳定可控、可复现的执行链路。适合自动化报告生成、订单处理、多步骤审批流、数据标注等固定流程自动化场景。
- **高代码应用**：基于完整 Python 项目结构部署 AI 后端服务，支持 Serverless Function 与 K8s 两种部署方式。适合部署私有算法、集成复杂系统、构建专业级 AI 后端服务等需要深度定制的场景。

## [智能体应用](../concepts/agent-application.md)

智能体分旧版（Agent 1.0）与新版（Agent 2.0）两套架构，详细差异见 [新版智能体应用](../../raw/application-user-guide/llm-application/new-single-agent-application.md)：

| 维度 | 旧版本（Agent 1.0） | 新版本（Agent 2.0） |
| --- | --- | --- |
| 规划与调度 | 检索[知识库](../concepts/knowledge-base.md)后再决策是否调用 MCP | 知识库、MCP 统一为工具，自主规划调用顺序 |
| 过程透明度 | 只展示最终结果 | 完整展示每轮"规划-执行-反思"链路 |
| 适用场景 | 意图单一、流程固定的简单任务 | 从简单问答到复杂规划的各类任务 |

> **注意**：旧版与新版本基于不同技术架构，彼此不兼容，**不支持直接升级或降级**。如需体验新版功能，请重新创建一个新版[智能体应用](../concepts/agent-application.md)。在没有旧版本依赖时，推荐使用新版。

### 创建流程

1. 访问百炼控制台应用管理，单击**创建应用** > **[智能体应用](../concepts/agent-application.md)** > **Agent 2.0**。
2. 填写应用名称，单击**立即创建**，自动跳转至应用配置界面。
3. 在模型选择器中选择模型（推荐具备强工具调用能力的模型，如 `千问-Max` 系列）。
4. 在右侧对话框中输入问题验证效果。

### 核心能力配置

- **模型参数**：最长回复长度、temperature、enable_thinking（仅支持思考模式的模型可配置）。
- **系统提示词**：定义智能体角色、行为指令与能力边界；支持嵌入自定义变量（输入 `/` 引用）。
- **预解析文件**：关闭时文件 URL 作为上下文传递，由智能体决策是否调用工具；开启时系统使用预置解析器处理文档、图像、视频、音频，返回文本内容作为参考。
  > 千问-VL 系列模型具备[多模态](../concepts/multimodal.md)能力，即使关闭预解析也能直接解析图片和视频文件。
- **知识库**：作为工具由智能体自主规划调用；支持通过标签限定查询范围，提升回答准确性。
- **MCP**：外部工具统一以 MCP 协议接入，包括官方 MCP 广场和自定义 MCP 服务；插件也支持一键转换为 MCP。
- **应用组件**：将已发布为组件的智能体或工作流作为工具接入。
- **记忆**：短期记忆支持 0–30 轮上下文（0 代表不传递多轮记录）；长期记忆计划在未来迭代支持。
- **回复**：开启"展示回答来源"后以角标形式展示知识来源和源文件/源网页地址，推荐与知识库和联网搜索 MCP 组合使用。

### 运行与限制

- **ReAct 最大轮次**：取值范围 1–50，限制单次会话中工具调用的最大次数，超出后自动退出工具调用链路并由智能体生成最终回复。
- **运行轨迹**：复杂请求以卡片流展示决策过程，包含思考（Thinking，仅支持思考模式的模型出现）与工具调用两类步骤。
- **应用发布**：发布是后续所有 API 调用与集成的前提。非首次发布时弹窗会展示自上次发布以来的配置变更差异。
- **版本管理**：支持编辑历史版本描述或回滚至已发布历史版本（覆盖当前草稿）。
- **应用合规备案**：若应用对外提供服务，须遵守《生成式人工智能服务管理暂行办法》等法规完成备案。

## 文件问答

文件问答是智能体应用的子能力，上传文件后可与文件内容进行智能问答。详见 [文件问答](../../raw/application-user-guide/llm-application/file-q-a.md)。三种处理模式：

| 模式 | 机制 | 适用场景 | [Token](../concepts/token.md) 消耗 |
| --- | --- | --- | --- |
| 全文引用 | 文件内容（上下文长度限制内）整体提供给模型 | 文档总结、全文翻译、风格润色 | 较大 |
| 切片检索（RAG） | 文件切分成片段，提问时检索最相关片段 | 长文档问答、知识库检索、精确定位信息来源 | 通常远小于全文引用 |
| 自定义处理 | 文件信息（URL 或内容）提供给模型，自主调用外部工具处理 | 图片风格转换、视频内容分析后生成报告 | 取决于模型与工具交互复杂性 |

### 文件限制

- 单次会话上传文件上限 10 个，单文件不超过 10MB。
- 通过聊天窗口上传的文件仅在**当前会话**有效，刷新或关闭页面将丢失。
- 通过文件上传 API（`session_file_id`）上传的文件有效期通常为 24 小时。
- 通过 URL（`image_list`、`file_list`）传递的文件可访问性由 URL 自身决定。
- 支持格式：文档（`.doc/.docx/.wps/.ppt/.pptx/.xls/.xlsx/.md/.txt/.pdf`）、图片（`.png/.jpg/.jpeg/.bmp/.gif`）、视频（`.mp4/.mkv/.avi/.mov/.wmv/.webm/.flv`）、音频（`.aac/.amr/.flac/.m4a/.mp3/.mpeg/.ogg/.opus/.wav/.wma`）。
- 仅适用于中国大陆版（北京地域）。

### 全文引用参数

- **单文件最大解析长度（token）**：超出部分从文件末尾截断。
- **最大拼装长度（token）**：所有文件内容拼接后的总 token 限制，超出部分从最后拼接文件的末尾开始截断。

### 切片检索参数

- **召回片段数**：模型回答时引用的相关文本片段的最大数量。
- **最大拼装长度**：所有被召回片段拼接后的总 token 限制，超出时根据相关性得分从低到高依次丢弃片段。
- 支持混合检索上传文件与已关联知识库内容。

### 自定义处理

- 添加所需工具（MCP、插件等），通过对话指令让模型调用工具处理文件。
- 千问-VL 系列模型在自定义处理模式下，图片可选择"模型处理"（仅用视觉能力直接回答）或"模型处理 + 规划"（看懂图片后判断是否调用外部工具）。

### API 调用

- 调用前应用须已发布；处理模式按智能体应用中保存的配置执行，API 调用时**无法动态切换**。
- 调用频率遵循所属智能体应用统一限流策略，默认 100 次/分钟，与其他 API 请求共享配额。
- 文件传递方式：`image_list`（图片 URL，限 10MB）、`file_list`（通用文件 URL，限 10MB）、`session_file_id`（生产环境推荐，先调文件上传 API 获取 ID 再传入对话 API）。

## 工作流应用

工作流通过可视化节点编排将复杂任务串联成稳定可控的执行链路。开始节点预置变量：`query`（用户输入文本）、`historyList`（对话历史列表，用于多轮上下文）、`imageList`（用户上传图片列表）。会话变量作为全局变量，可在工作流全生命周期内记录参数并在各节点引用。常用节点包括开始/结束、大模型、意图分类、变量处理、智能体群组等。

> **注意**：在支持记忆功能的节点（如大模型、意图分类）中，选择"自定义缓存"可让模型记得全局聊天内容；选择"本节点缓存"则只记得当前节点内的聊天内容。

工作流测试正常后须单击右上角**发布**，才能通过 API 调用。

## 高代码应用

高代码应用允许开发者基于完整 Python 项目结构部署 AI 后端服务，单条命令即可部署为公网可访问的云上 API 服务。

- **创建方式**：控制台创建（选择模板、配置资源、一键部署，推荐初次使用）或命令行创建（通过 AgentScope-AI 命令行工具上传 `.whl` 代码包部署）。
- **部署方式**：Serverless Function（默认，适用于低负载、无状态、快速拉起）或 K8s（适用于高性能、有状态、长程任务，需开通 ACK 容器服务并完成授权）。
- **应用模板**：基础对话 Agent、工具调用 Agent（内置联网搜索、计算器等 MCP 工具）、深度研究 Agent（基于 AgentScope 组件搭建）。
- **资源规格**：配置 vCPU、内存、磁盘大小、最小实例数、单实例并发度、部署地域。时延敏感业务建议最小实例数 ≥ 1，实现毫秒级热启动。
- **MCP 工具**：在工具 Tab 中关联知识库、工作流、插件等 MCP 服务。
- **网关**：应用稳定后建议开启网关功能，通过自定义域名和网关路由在生产环境访问；应用部署地域须与网关所在地域相同。
- **前端体验**：直接体验、自定义交互卡片、自定义前端 WebUI（基于 AgentScope Spark Design 框架，提供 `@agentscope-ai/design` 与 `@agentscope-ai/chat` 两个核心包）。

> **注意**：部署后将开始[计费](../concepts/billing.md)，函数、网关、存储、模型调用均会产生费用。生产环境推荐打开测试域名的"禁止公网访问"开关。

## [计费](../concepts/billing.md)说明

各类应用的计费构成：

- **模型调用**：按所选模型类型与输入/输出 [Token](../concepts/token.md) 数量计费。文件问答的全文引用模式输入 [Token](../concepts/token.md) 消耗较大，切片检索模式通常远小于全文引用，自定义处理模式取决于模型与工具交互复杂性。
- **知识库**：按量付费；从知识库召回的文本切片会增加模型输入 Token 数量，可能导致模型调用费用增加。
- **MCP**：部分官方 MCP（如文生图、文生视频、语音合成）按模型调用计费；部分 MCP 涉及第三方 API 调用，费用由第三方收取，百炼不另行收费。
- **长期记忆**（旧版智能体）：数据存储不收费；记忆体内容合并到 Prompt 中传递给大模型增加 Token 消耗，**记忆体内容占用的 Token 暂不计费**。
- **文件上传**：文件上传操作本身不收费。

> **注意**：仅创建应用不收费，调用应用进行问答时才根据所用模型收取模型调用费用。

## 常见问题排查

- **智能体未按预期调用已配置工具**：依次排查技能是否成功挂载、系统提示词是否清晰描述技能功能与适用场景、用户意图是否明确指向该技能、是否已达 ReAct 轮次上限。
- **知识库回答与内容无关**：先进行知识库命中测试查看相似度得分，调整检索配置；在提示词中明确要求模型仅基于知识库内容回答；必要时更换模型。
- **文件回答不完整或不准确**：全文引用模式下调高单文件最大解析长度与最大拼装长度；超长文件切换至切片检索模式；优化提问使其更具指向性；提供内容清晰、结构简单的源文件。
- **自定义插件超时**：超时限制为 5 秒。
- **API 创建智能体**：支持使用 Assistant API 创建功能类似智能体应用的大模型应用，但 Assistant API 创建的应用**不支持控制台管理**。
