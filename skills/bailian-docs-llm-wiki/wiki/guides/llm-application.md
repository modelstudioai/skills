# llm application

阿里云百炼提供三种核心应用构建模式——智能体（Agent）、工作流（Workflow）和高代码应用，用于突破大模型在处理私有知识、获取实时信息、遵循固定流程及规划复杂任务等方面的原生局限。三种模式分别面向零代码、低代码和专业代码开发者，通过集成知识库检索增强、外部工具调用、记忆等核心能力，帮助快速构建解决真实业务问题的 AI 应用。

## 应用类型与选型

百炼应用分为三类，开发门槛与灵活度依次递增：

| 对比维度 | 智能体（Agent） | 工作流（Workflow） | 高代码应用 |
|---------|----------------|-------------------|-----------|
| 开发方式 | 自然语言配置（零代码） | 可视化节点编排（低代码） | Python 编码（专业代码） |
| 核心特点 | AI 自主决策、动态规划 | 预定义流程精确控制 | 完全由代码控制 |
| 适合人群 | 业务人员、产品经理 | IT 运维、业务分析师 | AI 工程师、开发者 |
| 典型场景 | 智能客服、知识问答、任务助理 | 自动化报告、订单处理、审批流 | 私有算法部署、复杂系统集成 |

详细的选型说明参见 [应用类型介绍](../../raw/application-user-guide/llm-application/application-introduction.md)。

## 智能体应用

### Agent 2.0（推荐）

新版智能体（Agent 2.0）将知识库、MCP 等多种能力统一为工具，由智能体自主思考和规划调用顺序，能完整展示每一轮"规划-执行-反思"链路。与旧版相比，新版在规划调度、过程透明度和适用场景广度上均有显著提升。

核心能力配置：

- **模型选择**：推荐具备强工具调用能力的模型（如千问-Max 系列）。支持配置最长回复长度、temperature、enable_thinking（思考模式）等参数。
- **提示词**：支持静态文本和自定义变量（通过 `/` 插入），定义角色、行为指令和能力边界。
- **内置工具**：提供沙箱环境中的 `bash`、`write`、`read`、`edit`、`glob`、`grep`、`download_file` 等工具，默认关闭，按需开启。
- **知识库**：作为工具由智能体自主规划调用，支持通过标签限定查询范围。
- **MCP**：外部工具以 MCP 协议接入，支持动态非固定顺序调用。插件可一键转换为 MCP 服务。
- **应用组件**：可将其他智能体或工作流发布为组件后作为工具接入。
- **技能（Skill）**：可添加能力包，智能体自动识别匹配任务并调用。
- **记忆**：支持短期记忆（0-30 轮上下文），长期记忆计划未来支持。
- **预解析文件**：控制上传文件处理方式，千问-VL 系列模型即使关闭预解析也能直接解析图片和视频。

**ReAct 最大轮次**（1-50）用于限制单次会话中工具调用最大次数，超出后自动生成最终回复。

详细配置参见 [新版智能体应用（Agent 2.0）](../../raw/application-user-guide/llm-application/new-single-agent-application.md)。

> **注意**：旧版智能体（Agent 1.0）与新版基于不同技术架构，不支持直接升级或切换。如需使用新版功能，需在控制台重新创建 Agent 2.0 应用。

### Agent 1.0（旧版）

旧版智能体通过知识库（RAG）和插件两类核心能力扩展模型。知识库检索到的文本会占用模型上下文窗口，需注意调整检索策略避免超限。自定义插件有 5 秒超时限制。

旧版智能体的能力详情参见 [智能体应用](../../raw/application-user-guide/llm-application/single-agent-application.md)。

## 工作流应用

工作流通过可视化节点编排将复杂任务串联为稳定可控的执行链路。核心节点包括：

- **开始/结束节点**：定义输入输出参数结构，预置 `query`、`historyList`、`imageList` 等变量。
- **大模型节点**：配置模型、提示词和用户提示词，支持变量插入（`${sys.query}`）。
- **意图分类节点**：根据用户意图分流到不同处理分支。
- **智能体群组节点**：将多个子智能体组合，由决策模型分派任务。
- **变量处理节点**：静态文本输出或变量转换。
- **会话变量**：全局变量，贯穿工作流全生命周期，可跨节点引用。

工作流支持记忆功能（本节点缓存或自定义缓存），适用于诈骗识别、智能导购、日程管理等多步骤场景。详细节点说明和案例参见 [工作流应用](../../raw/application-user-guide/llm-application/workflow-application.md)。

## 高代码应用

面向专业开发者，支持基于完整 Python 项目结构部署 AI 后端服务。关键特性：

- **部署方式**：Serverless Function（低负载、无状态）和 K8s（高性能、有状态长程任务）。
- **代码提交**：可使用预置模板（基础对话 Agent、工具调用 Agent、深度研究 Agent）或上传 `.whl` 代码包。
- **MCP 工具接入**：在控制台直接关联知识库、工作流、插件等 MCP 服务。
- **前端体验**：支持直接体验、自定义交互卡片、基于 Spark Design 框架的自定义 WebUI。
- **网关配置**：通过云原生 API 网关配置自定义域名和路由，支持 Token 鉴权。
- **企业级能力**：自动化运维、可观测、日志服务、API 网关等。

详细创建和部署流程参见 [高代码应用](../../raw/application-user-guide/llm-application/rich-code-application.md)。

## 文件问答

智能体应用支持上传文件（文档、图片、音视频）进行智能问答，提供三种处理模式：

| 模式 | 原理 | 适用场景 |
|------|------|---------|
| 全文引用 | 解析文件内容整体传入模型 | 文档总结、全文翻译、风格润色 |
| 切片检索（RAG） | 切分文件为片段，检索最相关内容 | 长文档问答、精确定位信息来源 |
| 自定义处理 | 文件信息交由模型自主调用工具处理 | 图片风格转换、视频分析等 |

支持的文件格式包括 `.doc`/`.docx`/`.pdf`/`.xlsx`/`.md`/`.txt` 等文档，`.png`/`.jpg` 等图片，`.mp4`/`.mkv` 等视频和 `.mp3`/`.wav` 等音频。单会话最多 10 个文件，单文件不超过 10MB（API 方式可支持更大文件）。

关键参数：
- **全文引用**：可配置单文件最大解析长度（token）和最大拼装长度（token），超出部分从末尾截断。
- **切片检索**：可配置召回片段数和最大拼装长度，超限时按相关性得分从低到高丢弃。

文件问答的详细使用方法参见 [文件问答](../../raw/application-user-guide/llm-application/file-q-a.md)。

## 发布与集成

所有应用类型均需先在控制台发布后才能进行 API 调用或第三方集成。发布时会展示自上次发布以来的配置变更差异。

- **智能体应用**：支持通过 API/SDK 调用，也可发布到钉钉、微信公众号等平台，或发布为可复用组件。RAM 账号发布前需确认拥有 `ram:CreateServiceLinkedRole` 权限。
- **工作流应用**：发布后通过工作流应用 API 调用。
- **高代码应用**：部署后通过触发器或 API 网关访问。

## 计费说明

百炼应用创建本身不收费，费用主要来自以下方面：

- **模型调用**：按模型类型和 Token 用量计费。上传文件的问答会额外消耗输入 Token（全文引用模式消耗最大，切片检索模式相对较少）。
- **知识库**：按量付费，检索到的文本切片会增加模型输入 Token 消耗。
- **MCP/插件**：部分官方 MCP（文生图、文生视频等）按模型调用计费；涉及第三方 API 的费用由第三方收取。
- **高代码应用**：部署后函数计算、API 网关、存储等资源均会产生费用。
- **长期记忆**：数据存储不收费，记忆体内容占用的 Token 暂不计费。
