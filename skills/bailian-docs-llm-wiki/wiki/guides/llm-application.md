# llm application

百炼提供智能体（Agent）、工作流（Workflow）和高代码应用三种核心应用构建模式，配合知识库、MCP、插件等能力，帮助开发者快速构建可解决真实业务问题的 LLM 应用。三种模式在开发方式、可控性和适用人群上互补，可单独使用或组合集成。

## 应用类型与选型

百炼应用分为三类，详细对比见 [应用类型介绍](../../raw/application-user-guide/llm-application/application-introduction.md)。

| 维度 | 智能体（Agent） | 工作流（Workflow） | 高代码应用 |
| --- | --- | --- | --- |
| 开发方式 | 自然语言配置（零代码） | 可视化节点编排（低代码） | Python 编码（专业代码） |
| 核心特点 | 由大模型根据提示词自主规划 | 由预定义节点精确控制流程 | 完全由代码定义逻辑 |
| 适合人群 | 业务人员、产品经理 | IT 运维、业务分析师 | AI 工程师、开发者 |
| 适用场景 | 智能客服、知识问答、任务助理 | 报告生成、订单处理、审批流 | 私有算法部署、深度定制 |

- **智能体**适合需要 AI 自主决策、动态规划的场景。
- **工作流**适合流程固定、要求稳定可复现的场景。
- **高代码应用**适合需要深度定制、部署私有算法的场景。

## 智能体应用

智能体由提示词驱动，能够自主理解用户意图并调用知识库、MCP 等工具完成任务。当前推荐使用新版智能体（Agent 2.0），它将知识库、MCP 统一为工具，由智能体自主规划调用顺序，并能完整展示每轮"规划-执行-反思"链路，详见 [新版智能体应用](../../raw/application-user-guide/llm-application/new-single-agent-application.md)。

> **注意**：旧版智能体与新版本基于不同技术架构，彼此不兼容，**不支持**直接升级、降级或版本切换。如需体验新版，需在控制台重新创建一个新版智能体应用。

### 关键配置

- **模型选择**：推荐选用具备强工具调用能力的模型（如 `千问-Max` 系列）。可配置最长回复长度、`temperature`、`enable_thinking`（开启思考模式以提升反思效果，仅支持思考模式模型）。
- **系统提示词**：定义智能体角色、行为指令与能力边界；支持嵌入自定义变量（通过 `/` 引用）。
- **预解析文件**：关闭时文件 URL 作为上下文传递给智能体自主决策；开启时由预置解析器返回文本内容。千问-VL 系列模型即使关闭预解析，也能直接解析图片和视频。
- **内置工具**：`bash`、`write`、`read`、`edit`、`glob`、`grep`、`download_file`，在隔离沙箱中运行，默认关闭、按需开启。
- **知识库**：作为工具由智能体自主规划调用；支持通过标签限定查询范围以提升准确性。
- **MCP**：外部工具以 MCP 协议接入，支持动态、非固定顺序调用；插件可一键转换为 MCP。
- **记忆**：短期记忆支持 0–30 轮上下文；长期记忆计划在后续迭代支持。
- **ReAct 最大轮次**：1–50，限制单次会话工具调用次数，超出后自动退出并生成最终回复。

### 创建流程

1. 控制台 → 应用管理 → 创建应用 → 智能体应用 → Agent 2.0。
2. 填写名称 → 配置模型、系统提示词、工具、知识库等。
3. 右侧对话框调试。
4. 右上角"发布"（发布是后续 API 调用与集成的前提）。

旧版智能体的能力与配置可参考 [智能体应用](../../raw/application-user-guide/llm-application/single-agent-application.md)。

## 工作流应用

工作流通过可视化节点编排将复杂任务拆分为有序步骤，逻辑确定、可复现，详见 [工作流应用](../../raw/application-user-guide/llm-application/workflow-application.md)。

### 核心节点

- **开始/结束**：定义输入/输出参数。开始节点预置 `query`（用户输入）、`historyList`（对话历史）、`imageList`（图片）等变量。
- **大模型节点**：执行 LLM 推理，配置模型、提示词、用户提示词、记忆等。
- **意图分类节点**：根据输入分流到不同下游分支，支持多意图。
- **变量处理节点**：文本输出或变量加工。
- **智能体群组节点**：将任务分解给多个已发布的子智能体协同完成。

### 会话变量

会话变量作为全局变量在工作流全生命周期内记录参数，可在各节点中引用，在画布右上角配置。

### 典型案例

- **诈骗信息识别**：开始 → 大模型（提示词判定诈骗嫌疑）→ 结束。
- **智能导购**：意图分类分流到手机/电视/冰箱大模型分支，未命中走变量处理。
- **日程管理助手**：通过智能体群组节点串联"信息收集"和"数据整理"两个子智能体。

## 高代码应用

高代码应用基于完整 Python 项目结构部署 AI 后端服务，详见 [高代码应用](../../raw/application-user-guide/llm-application/rich-code-application.md)。

- **部署方式**：Serverless Function（无状态、快速拉起、低成本）或 K8s（高性能、有状态、长程任务，需开通 ACK）。
- **代码提交**：使用预置模板（基础对话 Agent / 工具调用 Agent / 深度研究 Agent）或上传本地 `.whl` 代码包。
- **MCP 工具接入**：控制台直接关联知识库、工作流、插件等 MCP 服务。
- **前端体验**：直接体验、自定义交互卡片、自定义前端 WebUI（基于 AgentScope Spark Design）。
- **网关**：应用稳定后建议开启网关，通过自定义域名和路由在生产环境访问；推荐关闭测试域名的公网访问。
- **运维**：自动集成日志、可观测、API 网关等企业级能力；支持重新部署、调整资源、停止服务。

## 文件问答

文件问答是智能体应用内的文件处理能力，支持三种处理模式，详见 [文件问答](../../raw/application-user-guide/llm-application/file-q-a.md)。

| 模式 | 机制 | 适用场景 |
| --- | --- | --- |
| 全文引用 | 解析整个文件作为上下文（受 token 限制截断） | 文档总结、全文翻译、风格润色 |
| 切片检索（RAG） | 文件切片后按相关性检索最相关片段 | 长文档问答、精确定位信息来源 |
| 自定义处理 | 文件信息交由模型自主调用工具处理 | 图片风格转换、视频分析后生成报告 |

- **文件格式**：文档（doc/docx/ppt/xls/pdf/md/txt 等）、图片（png/jpg/bmp/gif）、视频（mp4/mkv/mov 等）、音频（mp3/wav/flac 等）。
- **限制**：单会话最多 10 个文件，单文件不超过 10MB；聊天窗口上传的文件仅在当前会话有效。生产环境推荐使用文件上传 API 获取 `session_file_id`（有效期 24 小时）。
- **千问-VL 系列**：具备多模态能力，可自定义"模型处理"或"模型处理+规划"两种图片处理方式。
- **API 限制**：调用遵循所属智能体应用的统一限流，默认 100 次/分钟，与文件问答共享配额。

## 支持的模型

智能体与文件问答支持千问系列（Max/Plus/Turbo/Long、千问3-Coder-Plus、千问开源系列）、千问-QwQ、DeepSeek 等文本模型，以及千问VL-Max/Plus/OCR 等视觉理解模型。高代码应用通过代码自行接入任意模型。

> **注意**：模型支持情况可能存在数据延迟，以智能体应用内显示为准。

## 计费说明

- **模型调用**：按所选模型的输入/输出 Token 计费。知识库召回内容会增加输入 Token，可能推高调用费用。
- **知识库**：按量付费，详见知识库计费说明。
- **MCP/工具**：部分官方 MCP（文生图、文生视频、语音合成等）按模型调用计费；部分第三方 MCP 调用产生第三方费用，百炼不另行收费。
- **高代码应用**：部署后开始计费，函数、网关、存储、模型调用均产生费用，以阿里云账单为准。
- **文件上传**：上传操作本身不收费；基于文件问答消耗 Token 按模型标准计费。切片检索模式输入 Token 消耗通常远小于全文引用。
- **长期记忆**：数据存储不收费；记忆体内容占用 Token 暂不计费。

## 限制与注意事项

- 应用**必须先发布**才能通过 API 调用或集成到业务系统。
- RAM 账号创建的应用发布前需具备 `ram:CreateServiceLinkedRole` 权限。
- 自定义插件超时限制为 5 秒。
- 智能体未按预期调用工具时，排查：技能是否正确挂载、系统提示词是否清晰引导、用户意图是否相关、是否触及 ReAct 轮次上限。
- 文件问答在 API 调用时**无法**动态切换处理模式，按控制台保存的配置执行。
- 文件问答 API 仅适用于中国大陆版（北京地域）。
- 高代码应用的部署地域应与网关所在地域相同。
