# llm application

阿里云百炼提供三种核心应用构建模式：智能体（Agent）、工作流（Workflow）和高代码应用，帮助开发者将大模型与外部工具、知识库等能力集成，快速构建解决真实业务问题的 AI 应用。三种模式分别面向不同开发能力和场景需求，从零代码到专业编码均有覆盖。

## 应用类型与选型

百炼平台支持以下三种应用类型，详见[应用类型介绍](../../raw/application-user-guide/llm-application/application-introduction.md)：

| 对比维度 | 智能体（Agent） | 工作流（Workflow） | 高代码应用 |
|---------|----------------|-------------------|-----------|
| 开发方式 | 自然语言配置（零代码） | 可视化节点编排（低代码） | Python 编码（专业代码） |
| 核心特点 | AI 自主决策、动态规划 | 预定义流程精确控制 | 完全由代码控制 |
| 适合人群 | 业务人员、产品经理 | IT 运维、业务分析师 | AI 工程师、开发者 |
| 开发门槛 | 低 | 中 | 高 |

## 智能体应用

### 新版智能体（Agent 2.0）

新版智能体将知识库、MCP 等多种能力统一为工具，由智能体自主规划调用顺序，能完整展示"规划-执行-反思"链路。相比旧版（Agent 1.0），新版在复杂任务规划和过程透明度上有显著提升，推荐优先使用。详见[新版智能体应用](../../raw/application-user-guide/llm-application/new-single-agent-application.md)。

**核心能力配置：**

- **模型选择**：推荐具备强工具调用能力的模型（如千问-Max 系列）。支持配置最长回复长度、temperature、enable_thinking（思考模式）等参数。
- **系统提示词**：定义角色、行为指令与能力边界，支持嵌入自定义变量。
- **预解析文件**：控制上传文件的处理方式。开启后系统自动解析文档/图像/音视频；关闭后文件 URL 作为上下文信息传递给智能体。
- **知识库**：作为工具由智能体自主规划调用，支持通过标签限定查询范围。
- **MCP**：外部工具均以 MCP 协议接入，支持 MCP 广场官方服务和自定义 MCP，插件可一键转换为 MCP。
- **应用组件**：将已创建的智能体或工作流作为工具接入（需先发布为组件）。
- **记忆**：支持短期记忆（0-30 轮上下文），长期记忆计划未来支持。

**运行与调试：**

新版智能体以卡片流形式展示决策过程，包含思考（Thinking）和工具调用两种步骤。通过 ReAct 最大轮次（1-50）限制单次会话中工具调用的最大次数。

### 旧版智能体（Agent 1.0）

旧版智能体采用知识库检索先行、再决策是否调用其他工具的模式，适用于意图单一、流程固定的简单任务。详见[智能体应用](../../raw/application-user-guide/llm-application/single-agent-application.md)。

核心能力包括：
- **知识库（RAG）**：连接外部知识库，基于私有数据回答问题
- **插件**：调用平台预置工具（代码执行、图像生成、天气查询等）

> **注意**：旧版智能体与新版智能体基于不同技术架构，不支持直接升级或版本切换。如需使用新版功能，需重新创建新版智能体应用。

## 工作流应用

工作流通过可视化节点编排，将复杂任务拆分为有序步骤，适合需要固定流程和确定性输出的场景（如诈骗信息识别、智能导购、日程管理等）。详见[工作流应用](../../raw/application-user-guide/llm-application/workflow-application.md)。

**核心节点类型：**

- **开始/结束节点**：定义输入输出参数，预置 query、historyList、imageList 等变量
- **大模型节点**：配置模型、提示词和用户提示词
- **意图分类节点**：根据用户意图将请求路由到不同分支
- **智能体群组节点**：将多个子智能体组合使用，由决策模型分配任务
- **变量处理节点**：处理和转换变量

**关键特性：**

- 支持会话变量作为全局变量，在工作流全生命周期内可用
- 支持记忆功能（本节点缓存或自定义缓存）
- 发布后可通过 API 调用集成

## 高代码应用

面向专业开发者，支持基于 Python 项目构建和部署 AI 后端服务。详见[高代码应用](../../raw/application-user-guide/llm-application/rich-code-application.md)。

**核心能力：**

- **部署方式**：Serverless Function（低负载、无状态）和 K8s（高性能、有状态长程任务）
- **代码提交**：支持模板代码快速开始或上传本地 .whl 代码包
- **MCP 工具接入**：控制台直接关联知识库、工作流、插件等 MCP 服务
- **自定义前端**：支持直接体验、自定义交互卡片、基于 Spark Design 框架的 WebUI
- **网关管理**：通过云原生 API 网关配置自定义域名和路由
- **企业级运维**：自动化运维、可观测、日志服务、API 网关等

**应用模板：**

| 模板 | 说明 |
|-----|------|
| 基础对话 Agent | LLM 对话基础示例，适合快速体验 |
| 工具调用 Agent | 内置联网搜索、计算器等 MCP 工具 |
| 深度研究 Agent | 基于 AgentScope 的互联网调研 Agent |

## 文件问答

智能体应用支持上传文件进行智能问答，提供三种处理模式：

- **全文引用**：将文件内容整体提供给模型，适合文档总结、全文翻译等全局理解任务。受模型上下文长度限制。
- **切片检索（RAG）**：将文件切分为片段并检索最相关内容，适合长文档问答和精确定位信息场景。
- **自定义处理**：由模型自主调用外部工具处理文件，适合图片风格转换、视频分析等任务。

支持文档（doc/docx/pdf/md/txt 等）、图片（png/jpg 等）、视频（mp4/mkv 等）、音频（mp3/wav 等）格式，单文件不超过 10MB，单会话最多 10 个文件。详见[文件问答](../../raw/application-user-guide/llm-application/file-q-a.md)。

## 发布与集成

所有应用类型在发布后均可通过 API 调用集成到现有系统：

- **智能体应用**：通过发布渠道页签查看 API 调用方法，新版智能体参考新版智能体应用 API
- **工作流应用**：发布后调用工作流应用 API
- **高代码应用**：通过触发器 URL 或配置云原生 API 网关访问

> **注意**：应用发布是所有后续调用、集成的前提条件。

## 计费说明

- **模型调用**：根据模型类型、输入和输出 Token 数量计费
- **知识库**：按量付费，检索到的文本切片会增加模型输入 Token 消耗
- **MCP/插件**：部分官方 MCP 按模型调用计费（如文生图、文生视频），部分涉及第三方 API 费用
- **高代码应用**：部署后函数计算、API 网关、存储等均会产生费用
- **文件问答**：上传免费，问答按模型 Token 计费；全文引用模式 Token 消耗较大，切片检索模式通常更经济

## 常见问题

**自定义插件是否有超时限制？**
有，超时限制为 5 秒。

**是否支持通过 API 创建智能体应用？**
支持使用 Assistant API 创建功能类似于智能体的应用，但该方式创建的应用不支持控制台管理。

**为什么智能体未按预期调用已配置的工具？**
可从以下方面排查：技能是否正确挂载、系统提示词是否清晰描述了技能功能、用户意图是否明确指向特定技能、是否达到 ReAct 轮次上限。

**配置了知识库但回答与知识库无关？**
先进行知识库命中测试检查相似度得分，调整检索配置，并在提示词中明确要求模型仅基于知识库内容回答。
