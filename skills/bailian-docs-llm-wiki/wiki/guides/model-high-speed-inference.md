# model high speed inference

百炼平台通过 TPM（[Token](../concepts/token.md)s Per Minute）预留机制为模型推理提供专属容量保障，确保业务高峰期不受公共限流影响。开发者可以为指定模型锁定专属吞吐量，预留容量内的调用独享资源，超出部分自动降级为按量[计费](../concepts/billing.md)，服务不中断。

## 功能特性

TPM 预留的核心机制包括以下三点（详见 [TPM 预留](../../raw/model-user-guide/model-high-speed-inference/tpm-reservation.md)）：

- **容量保障**：预留的 TPM 容量为业务专属，不与其他用户共享。
- **专属模型 code**：创建预留后系统自动生成专属模型 code，需将 API 请求中的 `model` 参数替换为该 code。
- **超额不中断**：超出预留容量的请求自动降级为按量[计费](../concepts/billing.md)处理，无需修改代码。

## 方案对比

百炼提供四种推理容量方案，根据业务场景选择：

| 方案 | [计费](../concepts/billing.md)单位 | 容量保障 | 适用场景 | 超额处理 | 代码改动 |
|------|---------|---------|---------|---------|---------|
| 按量付费 | 按 token | 无（共享公共池） | 流量波动大/短期 | 受公共限流 | 无需改动 |
| 资源包/节省计划 | 预付费额度 | 承诺用量折扣 | 费用优化 | 超出转按量 | 无需改动 |
| TPM 预留 | 按 kTPM 预付费 | 专属容量刚性兑付 | 流量可预估、不能接受限流 | 超出自动降级按量 | 替换 model 参数 |
| PTU 专属部署 | 按 kTPM 预付费 | 专属部署实例 | 高吞吐高性能 | 超出转按量 | 替换 model 参数 |

如果业务流量可预估且不能接受限流，推荐使用 TPM 预留；如果需要更高性能和隔离度，可考虑 PTU 专属部署。

## 创建与接入

### 创建 TPM 预留

1. 登录百炼控制台，进入 TPM 预留页面，单击**创建 TPM 预留**。
2. 填写参数：预留名称、选择模型、付费周期（按天）、输入/输出 TPM（单位 kTPM）、购买时长。
3. 确认费用后单击**立即购买**并完成支付。

创建页面右侧提供**容量计算器**，可根据每分钟请求数（RPM）、平均输入/输出长度、预估缓存命中率自动计算推荐的 TPM 额度。

### 接入方式

创建成功后，在详情页**概览** Tab 复制专属模型 code，替换 API 请求中的 `model` 参数即可：

```python
import dashscope

response = dashscope.Generation.call(
    api_key="your-api-key",
    model="your-dedicated-model-code",   # 替换为专属模型 code
    messages=[{"role": "user", "content": "你好"}],
)
print(response.output.text)
```

> **注意**：短时间内请求量快速拉升时，系统需要短暂预热以匹配所需算力，预热期间部分请求可能出现延迟波动。建议做好请求排队或重试机制。

## 管理操作

TPM 预留支持以下管理操作（详见 [TPM 预留](../../raw/model-user-guide/model-high-speed-inference/tpm-reservation.md)）：

- **扩缩容**：在详情页调整输入/输出 TPM，变配期间服务不中断。
- **续费**：手动续订或开启到期自动续费（到期前一天 08:00 自动扣款）。
- **退订**：通过费用中心完成退订，退订不可恢复，专属模型 code 将失效。

### 缩容退费计算

已使用部分按 1.5 倍系数结算：

```
退款 = 降量部分预付费 - (降量部分预付费 x 已用时长/购买时长 x 1.5)
```

### 实例生命周期

| 状态 | 说明 |
|------|------|
| 运行中 | 正常运行，可调用 |
| 待生效 | 已创建，等待生效 |
| 变配中 | 正在扩缩容，服务不中断 |
| 已停止 | 到期 2~14 小时，续费可恢复 |
| 已过期 | 到期 14 小时后，资源已释放 |
| 已取消 | 退订完成，不可恢复 |

> **注意**：服务到期后 2 小时内实例仍为运行中，可继续调用和续费；2~14 小时转为已停止，不可调用但可续费；超过 14 小时实例将被删除且不可恢复。建议提前开启自动续费。

## 常见问题

**超出预留容量怎么办？** 超额请求自动降级为按量计费，服务不中断。在详情页**超额降级统计**中可查看降级次数，频繁降级时建议扩容。

**如何判断是否需要扩容？** 查看详情页的 TPM 用量趋势图和超额降级统计。利用率持续接近 100% 或频繁降级，说明需要扩容。

**预留到期后怎么办？** 专属模型 code 失效，后续请求回退到公共资源按量计费。建议提前开启到期自动续费。
