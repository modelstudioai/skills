# model high speed inference

TPM 预留是百炼平台提供的推理容量保障能力，通过为指定模型锁定专属吞吐量，确保业务高峰期不受公共限流影响。预留容量内的调用为业务专属、不与其他用户共享，超出部分自动降级为按量计费且不中断服务，详见 [TPM 预留](../../raw/model-user-guide/model-high-speed-inference/tpm-reservation.md)。

## 方案选型

百炼提供多种推理容量与计费方案，TPM 预留适用于"流量可预估、不能接受限流"的场景：

- **按量付费**：按 token 计费，共享公共池，无容量保障，超额受公共限流影响，无需改动代码。
- **资源包/节省计划**：预付费额度折扣，非专属容量，超出转按量。
- **TPM 预留**：按 kTPM 预付费，专属容量刚性兑付，超额自动降级公共池按量不中断，仅需替换 `model` 参数。
- **PTU 专属部署**：按 kTPM 预付费，专属部署实例，适用于高吞吐高性能场景，超出转按量，需替换 `model` 参数。

选型依据可参考 [TPM 预留](../../raw/model-user-guide/model-high-speed-inference/tpm-reservation.md) 中的方案对比表。

### 容量换算参数

部分模型支持长输入阶梯系数与缓存折扣，容量计算器会自动应用：

- **glm-5.1**：输入上限 200K；缓存命中部分按 20% 折算容量；输入长度在 [32K, 200K] 区间时输入系数 1.33、输出系数 1.17。
- **deepseek-v4-pro**：输入上限 256K；缓存命中部分按 8% 折算；无阶梯系数。
- **Qwen 系列**：输入上限 256K；缓存命中部分按 20% 折算；无阶梯系数。

## 计费与使用说明

- 部署成功即开始计费，预留容量内的调用不额外收费。
- 预付费一次性支付，从购买成功起连续生效；详细费用以控制台为准。
- 缩容与退订退费按 1.5 倍系数结算：`退款 = 降量部分预付费 - (降量部分预付费 × 已用时长/购买时长 × 1.5)`。
- 超出保障额度自动降级为按量计费，可在详情页**超额降级统计**中查看降级次数。
- 到期处理：到期后 2 小时内实例仍运行中、可调用、可续费；2~14 小时转为已停止、不可调用但仍可续费；14 小时后实例删除、不可恢复。

## 创建 TPM 预留

前提条件：已开通百炼模型服务，已创建[业务空间](../concepts/workspace.md)。登录百炼控制台，单击**创建 TPM 预留**。

> 创建 TPM 预留需一次性支付预付费用，建议先用容量计算器估算所需 TPM 并确认费用后再提交。

填写以下参数后单击**立即购买**并完成支付：

| 参数 | 说明 | 必填 |
| --- | --- | --- |
| 预留名称 | 自定义名称，便于识别，≤50 字符 | 是 |
| 选择模型 | 选择需预留容量的模型，提交后自动生成专属 model code | 是 |
| 付费周期 | 计费周期（按天） | 是 |
| 输入 TPM | 输入吞吐量，单位 kTPM（1 kTPM = 1,000 [Token](../concepts/token.md)s/分钟） | 是 |
| 输出 TPM | 输出吞吐量，单位 kTPM | 是 |
| 购买时长 | 预留有效时长 | 是 |
| 到期自动续费 | 到期前一天 08:00 自动扣款续费，默认开启 | 否 |
| 单次续费时长 | 每次自动续费时长，与购买时长取值一致 | 否 |

### 容量计算器

创建页面右侧提供容量计算器，输入以下参数后自动输出推荐的输入/输出 TPM：

- **每分钟请求数（RPM）**：业务高峰期每分钟请求数，越大建议购买容量同比增大。
- **平均输入长度（token）**：输入越长，所处阶梯越高、系数越大，建议输入 TPM 越高。
- **平均输出长度（token）**：输出越长，建议输出 TPM 越高。
- **预估缓存命中率（%）**：命中率越高，输入容量消耗越慢，建议输入 TPM 越低（仅影响输入 TPM）。

## 接入调用

创建成功后，在 TPM 预留详情页**概览** Tab 复制**专属模型 code**，并将 API 请求中的 `model` 参数替换为该 code。前提：预留实例状态为**运行中**。

短时间内请求量快速拉升时，系统需短暂预热以匹配所需算力，预热期间部分请求可能出现延迟波动，请做好请求排队或重试机制。

Python（dashscope）示例：

```python
import dashscope

response = dashscope.Generation.call(
    api_key="your-api-key",
    model="your-dedicated-model-code",   # 替换为专属模型 code
    messages=[{"role": "user", "content": "你好"}],
)
print(response.output.text)
```

curl 示例（OpenAI 兼容模式）：

```bash
curl -X POST https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions \
  -H "Authorization: Bearer $DASHSCOPE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"your-dedicated-model-code","messages":[{"role":"user","content":"你好"}]}'
```

## 查看与管理

在控制台预留列表页可按模型、时间、状态筛选所有预留实例。详情页包含三个 Tab：

- **概览**：基本信息（预留名称、专属 model code、基座模型、输入/输出容量）、近 7 天统计卡片（生效预留数、TPM 总量与峰值用量、平均利用率）、TPM 用量趋势图（可切换输入/输出方向）、超额降级统计。
- **监控**：利用率、配额用量（输入/输出）、配额内/外调用次数、缓存命中量等运行监控数据。
- **API 接入**：展示专属模型 code 与调用示例。

### 管理操作

- **扩缩容**：在弹窗中调整输入/输出 TPM。
- **续费**：选择续费时长并完成支付；已开启自动续费时系统在到期前一天 08:00 自动扣款。
- **退订**：跳转费用中心完成退订。退订不可恢复，专属 model code 失效，已有请求回退至公共资源处理。

### 实例状态

| 状态 | 说明 |
| --- | --- |
| 运行中 | 正常运行，可使用专属 model code 调用 |
| 待生效 | 已创建，等待生效 |
| 变配中 | 正在执行扩缩容，期间服务不中断 |
| 已停止 | 因欠费等原因停止，续费后可恢复 |
| 已过期 | 到期且未续费，资源已释放 |
| 已取消 | 退订完成，不可恢复 |

## 常见问题

**超出预留容量时会怎样？** 超出部分自动降级为按量计费，服务不中断；可在详情页概览 Tab 的**超额降级统计**查看降级次数和时间，频繁降级时建议扩容。

**专属模型 code 怎么获取？** 创建 TPM 预留后系统自动生成，在详情页**概览** Tab 可复制；必须将 API 请求中的 `model` 参数替换为此 code 才能使用预留容量。

**预留到期后会怎样？** 专属 model code 失效，后续请求自动回退到公共资源处理（按量计费），建议提前开启到期自动续费避免服务影响。

**如何判断是否需要扩容？** 在详情页概览 Tab 查看 TPM 用量趋势图与超额降级统计；若利用率持续接近 100% 或频繁降级，建议扩容输入/输出 TPM。

更多创建、管理、退订与状态流转细节参见 [TPM 预留](../../raw/model-user-guide/model-high-speed-inference/tpm-reservation.md)。
