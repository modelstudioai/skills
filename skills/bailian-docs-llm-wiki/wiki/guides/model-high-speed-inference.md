# model high speed inference

TPM 预留为指定模型锁定专属推理吞吐量，确保业务高峰期不受公共限流影响。本文介绍百炼平台高速推理方案的选型、TPM 预留的创建与接入、监控管理以及常见问题，帮助开发者在不能接受限流的场景下获得稳定的容量保障。详见 [TPM 预留](../../raw/model-user-guide/model-high-speed-inference/tpm-reservation.md)。

## 方案对比与选型

百炼为推理调用提供多种容量与计费方案，常见包括按量付费、资源包与节省计划、TPM 预留、PTU 专属部署。不同方案在计费单位、容量保障强度、超额处理方式与接入改动上各有侧重。

| 方案 | 计费单位 | 容量保障 | 适用场景 | 超额处理 | 代码改动 |
| --- | --- | --- | --- | --- | --- |
| 按量付费 | 按 token | 无（共享公共池） | 流量波动大/短期 | 自动服务，受公共限流 | 无需改动 |
| 资源包/节省计划 | 预付费额度 | 承诺用量折扣（非专属容量） | 费用优化 | 超出转按量 | 无需改动 |
| TPM 预留 | 按 kTPM 预付费 | 专属容量刚性兑付 | 流量可预估、不能接受限流 | 超出自动降级公共池按量，不中断 | 替换 model 参数即可 |
| PTU（模型部署） | 按 kTPM 预付费 | 专属部署实例 | 高吞吐高性能 | 超出转按量 | 替换 model 参数即可 |

当业务流量可预估且不能接受限流时，优先选择 TPM 预留；对极致性能与隔离有更高要求时，可考虑 PTU 专属部署。

## 关键参数与容量换算

部分模型支持长输入阶梯系数和缓存折扣，TPM 容量计算器会自动应用这些参数。

| 模型 | 输入长度上限 | 缓存折扣 | 长输入阶梯系数 |
| --- | --- | --- | --- |
| glm-5.2 | 1 Million | 0.25（缓存命中部分按 25% 折算） | 无阶梯（1.0） |
| glm-5.1 | 200K | 0.2（缓存命中部分按 20% 折算） | [0, 32K)：输入 1.0 / 输出 1.0；[32K, 200K]：输入 1.33 / 输出 1.17 |
| deepseek-v4-pro | 256K | 0.08（缓存命中部分按 8% 折算） | 无阶梯（1.0） |
| deepseek-v4-flash | 256K | 不支持缓存 | 无阶梯（1.0） |
| Kimi-K2.6 | 256K | 不支持缓存 | 无阶梯（1.0） |
| Qwen 系列 | 256K | 0.2（缓存命中部分按 20% 折算） | 无阶梯（1.0） |

容量计算器输入参数说明：

- **每分钟请求数（RPM）**：业务高峰期每分钟请求数，RPM 越大建议 TPM 同比增大。
- **平均输入长度（token）**：输入越长，阶梯系数越大，建议输入 TPM 越高。
- **平均输出长度（token）**：输出越长，建议输出 TPM 越高。
- **预估缓存命中率（%）**：命中率越高，输入容量消耗越慢，建议输入 TPM 越低；仅影响输入 TPM。

## 创建与接入 TPM 预留

前提条件：已开通百炼模型服务、已创建业务空间。登录[百炼控制台](https://bailian.console.aliyun.com/#/efm/tpm_reservation)后单击 **创建 TPM 预留**，参考 [TPM 预留](../../raw/model-user-guide/model-high-speed-inference/tpm-reservation.md) 的流程完成配置。

创建时需填写以下参数：

| 参数 | 是否必填 | 说明 |
| --- | --- | --- |
| 预留名称 | 是 | 自定义名称，便于识别，≤ 50 个字符 |
| 选择模型 | 是 | 选择需预留容量的模型，提交后自动生成专属模型 code |
| 付费周期 | 是 | 按天 |
| 输入TPM | 是 | 预留输入吞吐量，单位 kTPM（1 kTPM = 1,000 Tokens/分钟），起步和步长因模型而异 |
| 输出TPM | 是 | 预留输出吞吐量，单位 kTPM，起步和步长因模型而异 |
| 购买时长 | 是 | 预留有效时长，支持多种选择 |
| 到期自动续费 | 否 | 到期前一天 08:00 自动扣款续费，默认开启 |
| 单次续费时长 | 否 | 与购买时长取值一致 |

创建成功后，在详情页 **概览** Tab 复制 **专属模型 code**，并将 API 请求中的 `model` 参数替换为该 code：

```python
# 短时间内请求量快速拉升时，系统需要短暂预热以匹配所需算力
# 预热期间部分请求可能出现延迟波动，预热完成后恢复稳定。
# 请做好请求排队或重试机制。

import dashscope

response = dashscope.Generation.call(
    api_key="your-api-key",
    model="your-dedicated-model-code",   # 替换为专属模型 code
    messages=[{"role": "user", "content": "你好"}],
)
print(response.output.text)
```

## 计费与退订规则

- 部署成功即开始计费，预留容量内的调用不额外收费。
- 预付费一次性支付，从购买成功起连续生效。
- 缩容与退订退费：已使用部分按 1.5 倍系数结算，公式为 `退款 = 降量部分预付费 - (降量部分预付费 × 已用时长/购买时长 × 1.5)`。
- 超出保障额度后自动降级为标准按量计费，服务不中断，可在详情页 **超额降级统计** 中查看降级次数。

实例到期后的状态流转：

- 到期后 **2 小时内**：实例运行中，可继续调用，可续费。
- 到期后 **2~14 小时**：实例已停止，不可调用，仍可续费。
- 到期 **14 小时后**：实例已删除，不可恢复。

## 查看与管理

在控制台预留列表页，以模型卡片形式展示所有预留实例，支持按模型、时间、状态筛选。进入详情页后包含三个 Tab，详见 [TPM 预留](../../raw/model-user-guide/model-high-speed-inference/tpm-reservation.md)：

- **概览**：基本信息（预留名称、专属模型 code、基础模型、输入/输出容量）、近 7 天统计卡片（生效预留数、TPM 总量与峰值用量、平均利用率）、使用率趋势、超额降级统计。
- **监控**：利用率、配额用量（输入/输出）、配额内/外调用次数、缓存命中量等详细监控数据。
- **API 接入**：展示专属模型 code 和调用示例。

### 管理操作

- **扩缩容**：在详情页概览 Tab 的预留列表中单击 **扩缩容**，调整输入/输出 TPM，变配期间服务不中断。
- **续费**：单击 **续订** 选择续费时长并完成支付；如已开启 **到期自动续费**，系统在到期前一天 08:00 自动扣款续费。
- **退订**：单击 **退订** 跳转至费用中心完成退订流程。退订不可恢复，专属模型 code 失效，已有请求回退至公共资源处理。

预留实例状态说明：

| 状态 | 说明 |
| --- | --- |
| 运行中 | 正常运行，可使用专属模型 code 调用 |
| 待生效 | 已创建，等待生效 |
| 变配中 | 正在执行扩缩容，期间服务不中断 |
| 已停止 | 因欠费等原因停止，续费后可恢复 |
| 已过期 | 到期且未续费，资源已释放 |
| 已取消 | 退订完成，不可恢复 |

## 常见问题

**Q: 超出预留容量时会怎样？**
超出预留容量的请求自动降级为按量计费处理，服务不中断。可在详情页概览 Tab 的 **超额降级统计** 中查看降级次数和时间。频繁降级时建议扩容。

**Q: 专属模型 code 怎么获取？**
创建 TPM 预留后系统自动生成专属模型 code，在 TPM 预留详情页的 **概览** Tab 可复制。必须将 API 请求中的 `model` 参数替换为此 code 才能使用预留容量。

**Q: 预留到期后会怎样？**
预留到期后专属模型 code 失效，后续请求自动回退到公共资源处理（按量计费）。建议提前开启 **到期自动续费** 避免服务影响。

**Q: 如何判断是否需要扩容？**
在详情页概览 Tab 查看 TPM 用量趋势图和超额降级统计。如果利用率持续接近 100% 或频繁出现降级，建议扩容输入/输出 TPM。
