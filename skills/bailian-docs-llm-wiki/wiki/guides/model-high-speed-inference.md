# model high speed inference

百炼平台提供 TPM（Tokens Per Minute）预留功能，允许用户为指定模型锁定专属推理吞吐量，确保业务高峰期不受公共资源限流影响。通过预留机制，开发者可以获得稳定可预期的推理性能，超出预留额度的请求会自动降级为按量计费，服务不中断。

## 功能概述

TPM 预留的核心价值在于**容量保障**。根据 [TPM 预留](../../raw/model-user-guide/model-high-speed-inference/tpm-reservation.md) 文档，预留容量为业务专属，不与其他用户共享。创建预留后系统自动生成**专属模型 code**，开发者需将 API 请求中的 `model` 参数替换为该 code 即可接入。超出预留容量的请求自动降级为按量计费处理，无需修改代码。

## 方案选型

百炼提供多种推理容量方案，适用于不同业务场景：

| 方案 | 计费单位 | 容量保障 | 适用场景 | 超额处理 | 代码改动 |
|------|---------|---------|---------|---------|---------|
| 按量付费 | 按 token | 无（共享公共池） | 流量波动大/短期 | 受公共限流 | 无需改动 |
| 资源包/节省计划 | 预付费额度 | 承诺用量折扣（非专属） | 费用优化 | 超出转按量 | 无需改动 |
| TPM 预留 | 按 kTPM 预付费 | 专属容量刚性兑付 | 流量可预估、不能接受限流 | 降级公共池按量 | 替换 model 参数 |
| PTU 专属部署 | 按 kTPM 预付费 | 专属部署实例 | 高吞吐高性能 | 超出转按量 | 替换 model 参数 |

如果业务对延迟和吞吐有刚性要求且流量可预估，推荐选择 TPM 预留；如果需要更高性能隔离，可考虑 PTU 专属部署。

## 支持的模型

TPM 预留目前支持华北2（北京）和新加坡两个地域。支持的模型包括 Qwen 系列（qwen3.5-plus、qwen3.6-plus、qwen3.6-flash、qwen3.7-max、qwen3.7-plus）、GLM 系列（glm-5.1、glm-5.2）、DeepSeek 系列（deepseek-v4-flash、deepseek-v4-pro）以及 kimi-k2.6 等。不同地域支持的模型和定价有所不同，新加坡地域价格普遍高于北京地域。具体模型列表和价格以 [TPM 预留](../../raw/model-user-guide/model-high-speed-inference/tpm-reservation.md) 文档中的最新信息为准。

部分模型支持特殊的容量换算参数：

- **缓存折扣**：Qwen 系列缓存命中部分按 20% 折算容量，deepseek-v4-pro 按 8% 折算，glm-5.1 按 20% 折算。
- **长输入阶梯系数**：glm-5.1 在输入超过 32K token 后，输入系数为 1.33、输出系数为 1.17；其他模型无阶梯。

## 创建与接入

### 创建 TPM 预留

1. 登录百炼控制台，进入 TPM 预留页面，单击**创建 TPM 预留**。
2. 填写关键参数：
   - **选择模型**：选择需要预留容量的模型（仅支持已开放 TPM 预留的模型）。
   - **输入 TPM / 输出 TPM**：预留的吞吐量，单位 kTPM（1 kTPM = 1,000 Tokens/分钟），起步和步长因模型而异。
   - **购买时长**和**付费周期**（按天）。
   - 可选开启**到期自动续费**。
3. 确认并支付后，在详情页**概览** Tab 复制**专属模型 code**。

### 接入方式

将 API 请求中的 `model` 参数替换为专属模型 code 即可：

```python
import dashscope

response = dashscope.Generation.call(
    api_key="your-api-key",
    model="your-dedicated-model-code",   # 替换为专属模型 code
    messages=[{"role": "user", "content": "你好"}],
)
print(response.output.text)
```

> **注意**：短时间内请求量快速拉升时，系统需要短暂预热以匹配所需算力，预热期间部分请求可能出现延迟波动。建议做好请求排队或重试机制。

### 容量计算器

创建页面提供容量计算器，输入每分钟请求数（RPM）、平均输入/输出长度（token）和预估缓存命中率后，可自动输出推荐的输入和输出 TPM 额度。

## 管理与运维

创建后可在控制台进行以下管理操作，详见 [TPM 预留](../../raw/model-user-guide/model-high-speed-inference/tpm-reservation.md) 文档：

- **监控**：详情页提供 TPM 用量趋势图、利用率、超额降级统计、缓存命中量等监控数据。如果利用率持续接近 100% 或频繁出现降级，建议扩容。
- **扩缩容**：在详情页调整输入/输出 TPM，变配期间服务不中断。
- **续费**：支持手动续费和到期自动续费（到期前一天 08:00 自动扣款）。
- **退订**：退订后专属模型 code 失效，不可恢复。已使用部分按 1.5 倍系数结算退款。

## 计费与注意事项

- 部署成功即开始计费，预留容量内的调用不额外收费。
- 缩容退费公式：`退款 = 降量部分预付费 - (降量部分预付费 x 已用时长/购买时长 x 1.5)`。
- 到期后状态变化：运行中（到期后 2 小时内，可续费）-> 已停止（2~14 小时，不可调用但可续费）-> 已过期/已删除（14 小时后，不可恢复）。
- 预付费一次性支付，具体费用以百炼控制台为准。
